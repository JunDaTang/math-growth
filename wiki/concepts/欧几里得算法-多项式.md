# 欧几里得算法（多项式）

欧几里得算法在本来源中用于求两个多项式的最大公因子（gcd）。设 $N(x)$ 和 $D(x)$ 是两个次数至少为 $1$ 的多项式，类似于 (2.19) 得到带余项的除法链：

```
N(x)   = D(x)Q(x)    + R_1(x),
D(x)   = R_1(x)Q_1(x) + R_2(x),
R_1(x) = R_2(x)Q_2(x) + R_3(x),   等等。
```

## 终止性论证

由关系式 $\deg(R_{j+1}) < \deg(R_j)$，得知经有限步后将在某一步余项多项式为零，亦即

```
R_m(x) = R_{m+1}(x)Q_{m+1}(x).
```

于是 $R_{m+1}(x)$ 是 $N(x)$ 和 $D(x)$ 的最大公因子。

终止性的依据是余项**次数**的严格递减：次数是非负整数，不可能无限严格递减。这是本算法在全节中最有结构价值的部分之一。

## 算例（例 5）

$N(x) := x^3 - 1$，$D(x) := x^2 - 1$：

```
x^3 - 1 = (x^2 - 1)x + x - 1,      (第一步：Q = x, R_1 = x - 1)
x^2 - 1 = (x - 1)(x + 1),          (第二步：余项为 0)
```

得 gcd 为 $x - 1$。
