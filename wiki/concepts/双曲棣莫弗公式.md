# 双曲棣莫弗公式

《数学指南——实用数学手册》0.2.10 节给出：

$$
(\cosh x \pm \sinh x)^{n} = \cosh n x \pm \sinh n x, \qquad n = 1, 2, \dots .
$$

## 说明

- 因 $\cosh x \pm \sinh x = \mathrm{e}^{\pm x}$，本式等价于 $\mathrm{e}^{\pm nx} = \cosh nx \pm \sinh nx$，即 [[双曲正弦]] 与 [[双曲余弦]] 定义的直接重写。手册以 [[棣莫弗]] 之名命名该式，与三角形式的棣莫弗公式 $(\cos x \pm \mathrm{i}\sin x)^{n} = \cos nx \pm \mathrm{i}\sin nx$ 通过 [[双曲函数与三角函数的关系]] 相互对应。
- 正文此处的小标题「棣莫弗公式」在排版上被置于 $\cosh \frac{x}{2}$ 半角公式之后，归属错位，详见 [[0210节半角与棣莫弗公式小标题错位]]。
- 源文档未给出 $n$ 为负整数或非整数时的推广，仅声明 $n = 1, 2, \dots$。
