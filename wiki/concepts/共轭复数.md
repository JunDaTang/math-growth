# 共轭复数

1.1.2 节定义：数 `x − iy` 称为 `x + iy` 的**共轭复数**，记作

```latex
\overline{x + \mathrm{i}y} := x - \mathrm{i}y.
```

## 基本恒等式

对所有实数 x, y，

```latex
(x + \mathrm{i}y)(x - \mathrm{i}y) = x^{2} + y^{2}\tag{1.8}
```

成立。由此可得除法的一般方法：用分母的共轭复数通分。例：

```latex
\frac{1 + 2\mathrm{i}}{3 + 2\mathrm{i}}
= \frac{(1 + 2\mathrm{i})(3 - 2\mathrm{i})}{(3 + 2\mathrm{i})(3 - 2\mathrm{i})}
= \frac{1}{13}(7 + 4\mathrm{i}).
```

## 共轭的运算法则

对任意复数 a, b, c, d（d ≠ 0）：

```latex
\overline{a \pm b} = \bar{a} \pm \bar{b}, \quad
\overline{ab} = \bar{a} \cdot \bar{b}, \quad
\overline{\left(\frac{c}{d}\right)} = \frac{\bar{c}}{\bar{d}}.
```

## 实部与虚部

设 z = x + iy，则 x（y）称为 z 的**实部**（**虚部**），记作 x = Re z（y = Im z），且

```latex
\operatorname{Re} z = \frac{1}{2}(z + \bar{z}), \quad
\operatorname{Im} z = \frac{1}{2\mathrm{i}}(z - \bar{z}).
```

几何上，从 z 到 z̄ 的转变是关于实轴的反射（见 [[concepts/复数运算的几何表示]]）。
