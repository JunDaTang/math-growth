# 矩阵加法与标量乘法

## 矩阵加法

如果 `A` 和 `B` 均属于 `Mat(m,n)`，那么把 A 的元素与 B 的元素的和作为元素所形成的矩阵定义为和矩阵 `A + B`。这个矩阵仍然属于 `Mat(m,n)`。

来源例 1：

```
( a b c )   ( α β γ )   ( a+α  b+β  c+γ )
( d e z ) + ( δ ε ζ ) = ( d+δ  e+ε  z+ζ )

(a, b) + (α, β) = (a+α, b+β),      (1, 2) + (3, 1) = (4, 3)
```

## 标量乘法

设 `A ∈ Mat(m,n)`，`α` 是一个（实或复）数。把用数 `α` 乘矩阵 A 的每个元素所得到的矩阵定义为标量 `α` 与矩阵 A 的积 `αA`。这个矩阵仍属于 `Mat(m,n)`。

来源例 2：

```
    ( a b c )   ( αa αb αc )
α   ( d e z ) = ( αd αe αz )

    ( 1 3 2 )   ( 4 12 8 )
4   ( 1 2 1 ) = ( 4  8 4 )
```

## 运算法则

对于 `A, B, C ∈ Mat(m,n)` 及标量 `α`，有

```
A + B = B + A
(A + B) + C = A + (B + C)
A + O = A
α(A + B) = αA + αB
```

其中 `O` 是 [[零矩阵]]。来源由此得出结论：集合 `Mat(m,n)` 形成一个**复数域上的线性空间**（来源指向其 2.3.2 节）。

## 关联

- 这两类运算使 `Mat(m,n)` 成为线性空间，而 [[矩阵乘法]] 才引入非交换性；二者的差异是 [[矩阵环与矩阵代数]] 一页的核心议题。
