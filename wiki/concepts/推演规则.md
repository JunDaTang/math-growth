# 推演规则

4.4.1.2 节给出的四条规则，$A, B, C$ 表示任意表达式：

```
(R1) 任何一个公理能够被推演出。
(R2) （肯定前件式——分离规则）如果 (A → B) 和 A 是从公理可推演出的，则 B 也是从公理可推演出的。
(R3) （替换规则）若 A 可以从公理推演出，并且若 B 是通过将 A 中的某个命题变元 q_j
     全部替换为一个固定的表达式 C 产生的，则 B 也可以从公理推演出。
(R4) 一个表达式能够从公理推演出，当且仅当它是根据规则 (R1)、(R2) 和 (R3) 被推演出的。
```

其中 (R2) 就是 [[concepts/分离规则]]（modus ponens），与 4.1 节同名概念对应；(R3) 是替换规则；(R4) 是把「可推演」封闭化的元语言约定。

与 [[concepts/命题逻辑公理系统]] 合起来构成命题逻辑的形式系统；其完备性由 [[concepts/命题逻辑主要定理]] 的 (i) 保证。
