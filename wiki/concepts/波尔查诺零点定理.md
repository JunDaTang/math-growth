# 波尔查诺零点定理

## 单变量形式（1.3.1.2，「波尔查诺定理」）

如果函数 $f: [a, b] \to \mathbb{R}$ 连续，且 $f(a)f(b) \leqslant 0$，那么方程

```
f(x) = 0,   x ∈ [a, b]
```

有一个解（图 1.22）。

## 推广形式（1.3.3.2，「波尔查诺零点定理」）

设 $f: M \to \mathbb{R}$ 是连续函数，定义域 $M$ 是一个度量空间的**弧连通**子集。如果存在 $M$ 的两个点 $a, b$ 满足 $f(a)f(b) \leqslant 0$，那么方程

```
f(x) = 0,   x ∈ M
```

有一个解。

推广形式表明，零点存在性并不依赖定义域是区间，只依赖它的**弧连通性**；这正是不变性原理「连续映射把弧连通集映成弧连通集」的一个推论。
