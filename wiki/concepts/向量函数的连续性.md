# 向量函数的连续性

向量函数 r = r(t) 称为**连续的**，如果

```
lim_{s→t} r(s) = r(t)
```

这一表述是把实值函数的连续性逐字搬到向量情形：此处右端的极限由 [[concepts/向量序列的极限]] 定义，即

```
lim_{s→t} r(s) = r(t)  ⟺  lim_{s→t} |r(s) − r(t)| = 0
```

因此连续性在几何上就是「当参数趋于 t 时，轨迹点与 r(t) 的距离趋于 0」——即轨道无跳跃。

在 [[concepts/笛卡儿坐标系]] 中，若把 r(t) 写成 r(t) = x(t) i + y(t) j + z(t) k，则 r 连续等价于三个分量函数 x(t), y(t), z(t) 各自连续（参见 [[findings/向量极限的坐标收敛性判据]]）。

连续性也是 [[concepts/速度向量]] 定义的前提：只有轨道连续，才谈得上切线方向的极限。
