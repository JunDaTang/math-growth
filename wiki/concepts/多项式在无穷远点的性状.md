# 多项式在无穷远点的性状

## 陈述

当 $x \to \pm\infty$ 时，(0.43) 中的函数 $y = f(x)$ 的性状与函数 $y = ax^n$ 的相同。也就是说，当 $n \geqslant 1$ 时有（原文带脚注标记「1)」）：

```latex
\lim_{x \to +\infty} f(x) = \begin{cases} +\infty, & a_n > 0, \\ -\infty, & a_n < 0, \end{cases}
```

```latex
\lim_{x \to -\infty} f(x) = \begin{cases}
+\infty, & a_n > 0 \text{ 且 } n \text{ 为偶数，或 } a_n < 0 \text{ 且 } n \text{ 为奇数}, \\
-\infty, & a_n > 0 \text{ 且 } n \text{ 为奇数，或 } a_n < 0 \text{ 且 } n \text{ 为偶数}.
\end{cases}
```

## 要点

- 判据由两个量完全决定：首项系数 $a_n$ 的**符号**与次数 $n$ 的**奇偶性**。低次项与中间项只影响有限范围内的形态，不改变无穷远处的极限方向。
- $x \to +\infty$ 一侧只看 $a_n$ 的符号；$x \to -\infty$ 一侧还要叠加 $n$ 的奇偶性（偶数次时 $x^n \to +\infty$，奇数次时 $x^n \to -\infty$）。
- **归属注意**：该陈述是对**多项式**的断言（多项式与单项式在无穷远处性状相同），不可反向读作对幂函数 $y = ax^n$ 的性质断言。同一判据在 [[concepts/幂函数]] 与 [[findings/幂函数图像形状由指数奇偶性与系数符号决定]] 中用于描述单项式图像形状，两处主语不同。
- 该结论是 [[多项式的全局极值]] 的前提：偶次多项式在两端同号地发散，故至少存在一个全局极值。
- 手册在此处附有脚注标记「1)」，但脚注正文未收录于本节，见 [[queries/多项式无穷远性状处的脚注内容缺失]]。
