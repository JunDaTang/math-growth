# 误差估计

## 定义与动机

**误差估计**指把函数自变量的误差与函数值的误差定量地联系起来。原书指出，物理学中的测量总包含测量误差，而理论误差估计的任务正是刻画这种传递关系。

对一元实变量函数 $y = f(x)$：

- $\Delta x$ 为自变量 $x$ 的误差；
- $\Delta f = f(x + \Delta x) - f(x)$ 为函数值 $f(x)$ 的误差，即**绝对误差**；
- $\Delta f / f(x)$ 为函数值 $f(x)$ 的**相对误差**。

## 基本结论

由泰勒定理立即得到误差展开

```text
Δf = f′(x)Δx + (f″(x + ϑΔx)/2)(Δx)²,   0 < ϑ < 1
```

由此得到可用的误差估计（二阶量级的界）：

```text
|Δf − f′(x)Δx| ≤ (Δx)²/2 · sup_{0<η<1} |f″(x + ηΔx)|
```

当 $\Delta x$ 足够小时，通常使用一阶近似

```text
Δf = f′(x)Δx
```

在多变量情形下，同一思想给出

```text
Δf = Σ_{j=1}^{N} (∂f(x)/∂x_j) Δx_j
```

## 传播结构

误差在复合函数下的传播沿用链式法则的结构：

```text
ΔH = Σ_{k=1}^{m} (∂F/∂f_k) Δf_k
```

具体化为加法、乘法、除法三种法则时分别得到绝对误差相加、相对对数误差相加、相对对数误差相减（见 [[误差传播法则-加减乘除]]）。把误差视为随机量时，同一传播结构升级为方差传播，即 [[误差传播的高斯定律]]。

## 与已有概念的关系

- 误差估计的推导工具是 [[多元泰勒定理]] 与 [[泰勒余项]]；本节是 1.5.8 节结论的应用性延伸。
- 一阶近似 $\Delta f \approx f'(x)\Delta x$ 本质上是 [[线性化与线性近似]] 在误差传播语境下的用法。
- 误差传播公式与 [[多元链式法则]] 结构相同但语义不同：前者传播的是误差量，后者给出的是导数关系。
