# 高斯插值公式（I）与（II）

## 提法

7.3.1.3 节指出：某些情况下取区间中点（而非第一个或最后一个插值点）为初值来展开插值多项式是有意义的。此时等距插值点 $x_{j} = x_{0} + jh,\ j = 0, \pm 1, \pm 2, \cdots, \pm m$，插值点个数 $n = 2m+1$ 为奇数。

源文档从直观拟设多项式出发：

$$
\begin{array}{c}
I_{n}^{(\mathrm{I})}(x) = c_{0} + c_{1}(x - x_{0}) + c_{2}(x - x_{0})(x - x_{1}) + c_{3}(x - x_{0})(x - x_{1})(x - x_{-1}) + \dots,\\
I_{n}^{(\mathrm{II})}(x) = \gamma_{0} + \gamma_{1}(x - x_{0}) + \gamma_{2}(x - x_{0})(x - x_{-1}) + \gamma_{3}(x - x_{0})(x - x_{-1})(x - x_{1}) + \dots
\end{array}
$$

设 $x = x_{0} + th$，得到两个**高斯插值公式**：

$$
\begin{array}{l}
I_{n}^{(\mathrm{I})}(x) = y_{0} + \binom{t}{1}\delta^{1} y_{0.5} + \binom{t}{2}\delta^{2} y_{0} + \binom{t + 1}{3}\delta^{3} y_{0.5} + \dots + \binom{t + m - 1}{n}\delta^{n} y_{0},\\
I_{n}^{(\mathrm{II})}(x) = y_{0} + \binom{t}{1}\delta^{1} y_{-0.5} + \binom{t}{2}\delta^{2} y_{0} + \binom{t + 1}{3}\delta^{3} y_{-0.5} + \dots + \binom{t + m}{n}\delta^{n} y_{0}.
\end{array}
$$

两式的差别在于奇阶中心差分取自 $y_{0.5}$ 还是 $y_{-0.5}$，末项二项式系数也不同（$\binom{t+m-1}{n}$ 对 $\binom{t+m}{n}$）。

## 关系

- 高斯公式建立在 [[中心差分]] 与中心差分格式之上。
- 二者取算术平均得到 [[斯特林插值公式]]。
- 与 [[牛顿-格雷戈里插值公式]] 同属等距节点上的差分型插值公式。
