# 共轭梯度法（CG）

## 适用场景

《数学指南——实用数学手册》7.2.2.2 节指出：若用迭代法求解很大的稀疏方程组 $Ax + b = 0$，其中 $A$ **对称正定**（这是椭圆边值问题离散化产生的矩阵类型），共轭梯度法尤为适用。

与[[concepts/经典迭代法]]的差别在于：经典迭代法基于[[concepts/不动点形式]]，而 CG 基于**逼近泛函的极小化**——即[[concepts/二次泛函]] $F(v)$ 的极小点恰为解 $x$。

## 算法（逐字保留源文算法块）

```
开始：选取 x^(0), r^(0) = A x^(0) + b, p^(1) = -r^(0)
迭代 (k = 1, 2, ...)
  若 k > 1:
    e_{k-1} = r^{(k-1)^T} r^{(k-1)} / r^{(k-2)^T} r^{(k-2)},
    p^{(k)} = -r^{(k-1)} + e_{k-1} p^{(k-1)},
  z = A p^{(k)},   q_k = r^{(k-1)^T} r^{(k-1)} / p^{(k)^T} z,
  x^{(k)} = x^{(k-1)} + q_k p^{(k)},   r^{(k)} = x^{(k-1)} + q_k z,
  检验收敛.
```

迭代过程可以概括为：$F(v)$ 的极小是这样逐次确定的——从某个向量 $x^{(0)}$ 出发，沿着负梯度方向，找到第 $k$ 步的共轭下降方向 $p^{(k)}$，使 $F(v)$ 在该方向极小化。

## 正交性与有限终止性

CG 方法中：

- 剩余向量 $r^{(k)}$ **两两正交**；
- 下降方向 $p^{(k)}$ **两两共轭**，即有 $(p^{(k)})^{\mathrm{T}} A p^{(j)} = 0,\ j = 1, 2, \dots, k-1$。

因此该方法对 $n$ 个未知量的线性方程组 $Ax + b = 0$ **最多经过 $n$ 次迭代**就可以得到解 $x$。这一性质见[[concepts/共轭方向与剩余正交性]]。

源文进一步指出，第 $k$ 次迭代的解 $x^{(k)}$ 是 $F(v)$ 关于子空间

$$
S_k := \operatorname{span}(\{p^{(1)}, p^{(2)}, \dots, p^{(k)}\}) = \operatorname{span}(\{p^{(0)}, p^{(1)}, \dots, p^{(k-1)}\})
$$

的全局极小：

$$
\boxed{F(x^{(k)}) = \min_{c_i} F\left(x^{(0)} + \sum_{i=1}^{k} c_i p^{(i)}\right).}
$$

误差 $e^{(k)} := x^{(k)} - x$ 类似地是按[[concepts/能量范数]] $\|z\|_A^2 = z^{\mathrm{T}}Az$ 关于 $S_k$ 的极小。

## 收敛性估计

$$
\frac{\|e^{(k)}\|_A}{\|e^{(0)}\|_A} \leqslant 2\left(\frac{\sqrt{\kappa(A)} - 1}{\sqrt{\kappa(A)} + 1}\right)^{k}.
$$

由此可估计保证 $\|e^{(k)}\|_A / \|e^{(0)}\|_A \leqslant \varepsilon$ 的 CG 步数 $k$ 为

$$
k \leqslant \frac{1}{2}\sqrt{\kappa(A)} \cdot \ln\left(\frac{2}{\varepsilon}\right) + 1.
$$

该上界由容许值 $\varepsilon$ 和[[concepts/线性方程组的条件数|条件数]] $\kappa(A)$ 的**平方根**决定——这是 CG 与直接法在条件数影响上的关键区别：误差界随 $\sqrt{\kappa(A)}$ 而非 $\kappa(A)$ 增长。

## 预条件

CG 的收敛性可以通过[[concepts/预条件]]而显著改进：用 $n \times n$ 的正规矩阵 $C$ 把方程组 $Ax + b = 0$ 变换为 $\tilde{A}\tilde{x} + \tilde{b} = 0$，使 $\kappa_2(M^{-1}A) \ll \kappa_2(A)$，其中 $M = CC^{\mathrm{T}}$ 必须是 $A$ 的逼近。源文对预条件矩阵的选取方法引用了文献 [425]。

## 已记录的疑点

源文算法块中 $r^{(k)}$ 的更新式写作 $r^{(k)} = x^{(k-1)} + q_k z$，与常见的剩余向量递推形式不一致；该疑点记录于[[queries/7222节共轭梯度算法中剩余向量r-k更新式疑为r-k-1减q_k z]]。子空间 $S_k$ 的两个生成向量组之间的一致性亦存疑，见[[queries/7222节子空间S_k的两个生成向量组不一致]]。
