# 多元回归

## 一般形式

设有随机变量

```
X_1, …, X_n  和  Y_1, …, Y_m.
```

**多元回归**寻找形如

```
Y_j = F_j(X_1, …, X_n) + ε_j,   j = 1, …, m
```

的函数对应关系。为了在一个给定的函数类中估计（未知）函数 $F_1, \cdots, F_m$，使用测量值 $X_1, \cdots, X_n$ 和 $Y_1, \cdots, Y_m$。随机量 $\varepsilon_j$ 表示**微扰**（扰动项）。

即：自变量有 $n$ 个（$X_1, \dots, X_n$），因变量有 $m$ 个（$Y_1, \dots, Y_m$），属于「多因变量、多自变量」的回归。

## 线性回归（多元形式）

如果假定所有函数 $F_j$ 都是线性的，那么就得到了一个（线性）方程组：

```
Y_j = ∑_{k=1}^{m} a_{jk} X_k + b_j + ε_j,   j = 1, …, m.
```

假定所有的系数 $a_{jk}$ 和 $b_j$ 都取实数值，需要根据观测数据对它们进行估计。

> 原文此处求和上限写作 $k = 1, \dots, m$，而自变量个数为 $n$；这一记号疑点见 [[636节线性回归求和上限m疑为n]]。

## 与 6.2.3.3 的关系

源文档指出，在这里要做的就是将 6.2.3.3 中讨论过的**回归度和相关系数的概念进行推广**。也就是说，[[回归直线与最小二乘法]]、[[相关曲线与回归曲线]]、[[协方差与相关系数]] 中的两变量回归，是本节多元回归的退化情形（$n = m = 1$）。相关的高斯分布情形见 [[6233节协方差相关系数与回归直线]]。

## 计算与因子筛选

计算机程序具有很大的灵活性，能够通过**删掉某些充分小的系数** $a_{jk}$ 和 $b_j$ **确定出最重要的因子**。这与方差分析、因子分析中「确定重要因子」的目标相呼应。
