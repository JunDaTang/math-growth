# 代数（代数结构）

「代数」在本文中指**域 $\mathbb{K}$ 上的代数**这一代数结构：一个**线性空间**，其上还定义了满足双线性（分配律）与结合律的**乘法**。它是 [[多线性代数]] 体系的上位框架，[[张量积]]、[[外积]]、[[克利福德乘法]] 所构造的张量代数、外代数、克利福德代数都是它的特例。

> 注：中文语境下「代数」也指学科（algebra）。本页讨论的是代数结构，不是学科。见 query [[24节结合与非结合代数约定]]。

## 定义

$\mathbb{K}$ 上的代数 $\mathcal{A}$ 是一个线性空间，其中定义了乘法分配律和结合律。

更明显地说，对于每个 $\mathcal{A}$ 中元素 $a$ 和 $b$ 的有序对 $(a, b)$，$\mathcal{A}$ 中存在唯一确定的与它们相关的第三个元素，记作 $ab$，使得对于所有 $a, b, c \in \mathcal{A}$ 及 $\alpha, \beta \in \mathbb{K}$，有

$$
(\mathrm{i})\; (\alpha a + \beta b) c = \alpha (a c) + \beta (b c), \quad c (\alpha a + \beta b) = \alpha (c a) + \beta (c b).
$$

$$
(\mathrm{ii})\; a(bc) = (ab)c.
$$

## 公理解读

- **公理 (i) 是双线性（分配律）**：乘法对左边因子的加法与标量乘法线性，也对右边因子线性。即左侧分配律与右侧分配律同时成立。它并不等同于通常所说的「乘法分配律」这一句话，而是左右两侧都要求线性。
- **公理 (ii) 是结合律**：$a(bc) = (ab)c$，因此本节所定义的代数默认是**结合代数**（associative algebra）。
- **乘法的唯一性要求**：对每一有序对 $(a,b)$ 存在唯一确定的元素 $ab$，即乘法是一个映射 $\mathcal{A}\times\mathcal{A}\to\mathcal{A}$。

## 与相邻概念的关系

- **底层结构是 [[线性空间]]**：代数 = 线性空间 + 满足 (i)(ii) 的乘法。因此代数上的一切线性空间性质（基、维数、线性算子等）都适用。
- **保持结构的映射是 [[代数同态与同构]]**：代数同态既要是线性映射，又必须保持乘积。
- **公理 (i) 与 [[线性性思想]]**：乘法在每一个变量上都是线性的，这正是线性性思想在二元运算上的体现。
- **特例**：张量代数、外代数、克利福德代数等均在 2.4 后续小节中给出，见 [[多线性代数]]、[[张量积]]、[[外积]]、[[克利福德乘法]]。

- 本节**只定义了结合代数**。交换代数、非结合代数（如李代数、约当代数）未在 2.4.1 给出；若后续小节引入这些特例，需与本页的默认约定区分，见 [[24节结合与非结合代数约定]]。
