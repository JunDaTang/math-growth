# 标量积

本手册 1.8.3 节定义：两个向量 $a, b$ 的**标量积**，记作 $ab$，定义为数

```latex
ab := |a| |b| cos φ,
```

其中 $\varphi$ 是两个向量 $a, b$ 之间的夹角，它如此选取，以使 $0 \leqslant \varphi \leqslant \pi$（图 1.91）。

由此得到**正交性**：两个向量 $a, b$ 称为正交的（原书此处带脚注 1），如果

```latex
ab = 0.
```

如果 $a \neq 0$ 且 $b \neq 0$，那么当且仅当 $\varphi = \pi/2$ 时这个条件成立。另有一条约定：零向量 $0$ 垂直于所有向量。

标量积的运算法则（与向量积并列给出）：

- $ab = ba$（交换律成立）；
- $\alpha(ab) = (\alpha a)b$；
- $a(b + c) = ab + ac$（对加法分配）；
- $a^2 := aa = |a|^2$。

在笛卡儿坐标下 $ab = a_1 b_1 + a_2 b_2 + a_3 b_3$；在一般坐标系下 $ab = a_1 b^1 + a_2 b^2 + a_3 b^3$，即一向量取共变坐标、另一向量取反变坐标配对求和。

标量积参与定义 [[格拉姆行列式]]，也是 [[三重积]] 的构造元件。
