# 复数的极坐标表示与辐角

1.1.2.1 节：对复数 z = x + iy，使用极坐标可写成

```latex
z = r(\cos \varphi + \mathrm{i} \cdot \sin \varphi), \quad -\pi < \varphi \leqslant \pi, \quad r = |z|.
```

其中 φ 表示向量与 x 轴的夹角（图 1.7）。由欧拉公式 (1.7)（见 [[concepts/欧拉公式]]）得到

```latex
z = r \mathrm{e}^{\mathrm{i}\varphi}, \quad -\pi < \varphi \leqslant \pi, \quad r = |z|.
```

## 辐角

称角 `arg z := φ` 为 z 的**辐角的主值**，限定 −π < φ ≤ π 使得 φ 由 z 唯一决定。

满足 `z = r e^{iψ}` 的所有角 ψ 称为 z 的**辐角**，且

```latex
\psi = \varphi + 2\pi k, \quad k = 0, \pm 1, \pm 2, \dots
```

例：`i = e^{iπ/2}`，`−1 = e^{iπ}`，|i| = |−1| = 1，arg i = π/2，arg(−1) = π。

该表示是求复数根的基础，见 [[concepts/复数的n次根]]。
