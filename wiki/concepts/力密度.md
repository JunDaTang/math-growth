# 力密度

在 1.9.7 节中，$F(x,t)$ 被称作「产生物质的力密度」，定义为「单位体积单位时间生成的质量」。它作为源项出现在 [[concepts/质量平衡方程]]

```
ρ_t + div J = F
```

的右端，并在热流方程 (1.170) 中表示「单位时间内单位体积产生的热量」（放热功率密度）。

## 记号重载提示

此处的 $F$ 与 1.9.6 节中作为质点所受外力的 $F$ 含义不同：前者是连续介质的源项（标量密度），后者是多体系统中的力向量。跨节阅读时须按上下文区分，参见 [[queries/197节符号F在源项与力之间重载]]。
