# 向量位势

向量位势是 1.9.9 显式解构造中的积分算子，把一个涡（电流）密度场 $J$ 映为一个向量场 $C$。

## 定义

```
C(x) = ∫_{R^3} J(y) dy / (4π|x − y|).
```

与 [[体积位势]] 的差别仅在于被积对象由标量 $\rho$ 换成向量 $J$，因此积分结果逐分量为标量体积位势，整体构成向量场。

## 使用前提

- 域取 $D = \mathbb{R}^3$；
- $J$ 在 $\mathbb{R}^3$ 上为 $C^3$ 类，并在某一球外为零；
- 在整个 $\mathbb{R}^3$ 上 $\operatorname{div} J \equiv 0$（[[相容性条件]]）。

## 用途

令 $H_{par} := \operatorname{curl} C$，则

```
div H_par = 0,  curl H_par = J,  在 R^3 上.
```

这给出 [[涡流的规定]] 中的显式特解，也是电磁学中由电流密度求磁矢量势的标准构造。
