# 切比雪夫不等式

## 陈述

《数学指南——实用数学手册》6.1.4 节：对于任意的 $\beta > 0$，

```
P( |X − X̄| > β ΔX ) ≤ 1/β²
```

特别地，当 $\Delta X = 0$ 时，有

```
P(X = X̄) = 1
```

即退化情形下随机变量以概率 1 取均值。

## 用途

本节用该不等式推出 [[concepts/置信区间]]：设 $0 < \alpha < 1$，则 $X$ 的测量值落入

```
[ X̄ − ΔX/√α ,  X̄ + ΔX/√α ]
```

的概率大于 $1 - \alpha$。例 1 取 $\alpha = 1/16$，得到落入 $[\overline{X} - 4\Delta X, \overline{X} + 4\Delta X]$ 的概率大于 $15/16$。该结论使均值与标准差的含义更精确。

## 边界

本节只把该不等式作为集中程度的工具使用，未给出其证明，也未讨论它相对其他集中不等式（如大偏差界）的紧性；本节也未把它与同名的切比雪夫多项式等其他数学对象建立联系。
