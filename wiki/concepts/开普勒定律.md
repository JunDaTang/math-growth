# 开普勒定律

开普勒定律是《数学指南——实用数学手册》1.12.5.2 节的落点。本源以二体问题的解（轨道方程 (1.295) 与面积积分 (1.298)）为工具，逐条给出并证明开普勒（Kepler, 1571—1630）的三条行星运动定律（图 1.141）。

## 三条定律及其在本源中的形式

### 第一定律：椭圆轨道

行星沿着椭圆轨道运行，太阳位于椭圆的焦点之一的位置。

证明：在笛卡儿坐标 x、y 中，轨道方程 (1.295) 归为方程

```text
( x + ε a )² / a² + y² / b² = 1.
```

其中 $a := p/(1 - \varepsilon^{2})$，$b := p/\sqrt{1 - \varepsilon^{2}}$，太阳位于椭圆的焦点 $(0, 0)$。详见 [[开普勒第一定律椭圆轨道]]。

### 第二定律：等面积

在相等的时间中，行星的轨道扫过相等的面积。

证明：在时间区间 $[s, t]$ 中，面积

```text
(1/2) ∫_s^t r² φ' dt = (t - s) |N| / (2 m₂)              (1.298)
```

被扫过。详见 [[开普勒第二定律面积积分1298]] 与 [[面积速度]]。

### 第三定律：周期与长半轴

对于所有行星而言，周期 T 的平方与长半轴 a 的 3 次方之比是一个常数。

证明：椭圆轨道所围成的面积为 $\pi a b$。在 (1.298) 中令 $t = T$ 和 $s = 0$，得到 $\frac{1}{2}\pi a b = \frac{T |N|}{2 m_2}$。从 $a = p/(1 - \varepsilon^2)$ 和 (1.297) 得到

```text
T² / a³ = 4 π² / ( G (m₁ + m₂) ).                        (1.299)
```

详见 [[开普勒第三定律1299]]。

## 近似性与历史评注

本源明确指出，因为太阳的质量 $m_1$ 比行星的质量 $m_2$ 大得多，在初级近似时在 (1.299) 中不妨忽略 $m_2$，因此「开普勒第三定律只是一个近似」。开普勒从对行星的大量观察数据的研究中得出了这个定律；他凭经验得到的定律，和以后由牛顿所发现的数学推导，是当时数学和物理学的伟大成就。
