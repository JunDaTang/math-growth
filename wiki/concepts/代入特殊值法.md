# 代入特殊值法

## 定义

代入特殊值法是求 [[concepts/部分分式分解|部分分式分解]] 中待定系数的另一种方法：在去分母后的恒等式中代入若干精心选取的 $x$ 值，直接得到关于系数的方程组，通常比 [[concepts/比较系数法|比较系数法]] 更快。

## 在 2.1.7 节中的操作

从式 (2.30) 出发：

```latex
x = A(x-2)^{2} + B(x-1)(x-2) + C(x-1).
```

取 $x = 2, 1, 0$（其中 $2$ 与 $1$ 恰为分母的零点），产生线性方程组

```latex
2 = C,      1 = A,      0 = 4A + 2B - C,
```

有解

```
A = 1,  C = 2,  B = -1.
```

## 为何更快

代入分母零点时，式 (2.30) 右端只剩一项非零，可立即读出对应系数（如 $x=2$ 直接给出 $C=2$，$x=1$ 直接给出 $A=1$）；只有用剩余方程才需解出其余系数。原书评价：「通常，方法二要快一些。」

## 适用条件

该方法的有效性依赖去分母后的恒等式对**所有** $x$ 成立（除分母零点外），因此可自由选取方便的 $x$ 值。
