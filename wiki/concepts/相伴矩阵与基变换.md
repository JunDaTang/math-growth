# 相伴矩阵与基变换

2.3.3.4 节。设 $A: X \to Y$ 是线性算子，X、Y 是 K 上的有限维线性空间，分别取定基 $b_1,\dots,b_n$ 和 $c_1,\dots,c_m$。对 $u \in X$、$v \in Y$ 有唯一分解 $u = u_1 b_1 + \dots + u_n b_n$、$v = v_1 c_1 + \dots + v_m c_m$，并且

```text
Ab_k = Σ_{j=1}^m a_{jk} c_j,   k = 1, …, n
```

称 $m \times n$ 矩阵 $\mathscr{A} := (a_{jk})$ 为与线性算子 A（关于所选基）相伴的矩阵。引进坐标列矩阵 $\mathcal{U} := (u_1,\dots,u_n)^{\mathrm{T}}$、$\mathcal{V} := (v_1,\dots,v_m)^{\mathrm{T}}$，则算子方程 $Au = v$ 对应于矩阵方程

```text
𝒜𝒰 = 𝒱
```

定理：线性算子的和（或积）对应于相应矩阵的和（或积）；线性算子的秩与相应矩阵的秩相同（与基选取无关）。

基的变换：借助变换公式 $b_k = \sum_r t_{rk} b_k'$、$c_j = \sum_i s_{ij} c_i'$ 过渡到新基，其中 $\mathcal{T} = (t_{rk})$、$\mathcal{S} = (s_{ij})$ 可逆。坐标变换与算子矩阵变换为

```text
𝒰 = 𝒯𝒰′,   𝒱 = 𝒮𝒱′
𝒜′ = 𝒮⁻¹𝒜𝒯
```

特殊情形 $X = Y$ 且 $b_j = c_j$（所有 j），有 $\mathcal{S} = \mathcal{T}$，得到相似变换

```text
𝒜′ = 𝒯⁻¹𝒜𝒯
```

相关矩阵概念见 [[矩阵]]、[[逆矩阵]]、[[矩阵的秩]]；迹与行列式见 [[线性算子的迹与行列式]]。
