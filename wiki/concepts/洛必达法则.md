# 洛必达法则

《数学指南——实用数学手册》1.3.1.3 节给出洛必达法则（式 (1.28)），用于计算 $\frac{0}{0}$、$\frac{\infty}{\infty}$ 型 [[不定式]]。

## 法则 (1.28)

```
lim_{x→a} f(x)/g(x) = lim_{x→a} f'(x)/g'(x)                (1.28)
```

## 前提条件（四条须同时满足）

```
(i)   存在极限 lim_{x→a} f(x) = lim_{x→a} g(x) = b，
      其中 b = 0 或 b = ±∞，而 −∞ ⩽ a ⩽ ∞
(ii)  存在一个邻域 U(a)，使对所有 x ∈ U(a) 且 x ≠ a，导数 f'(x) 和 g'(x) 存在
(iii) 对所有 x ∈ U(a) 且 x ≠ a，有 g'(x) ≠ 0
(iv)  式 (1.28) 右边的极限存在
```

当 $x \to a+0$（相应地 $x \to a-0$）时也有类似论述，其中 $a \in \mathbb{R}$；这时假设 (ii) 和 (iii) 只需对满足 $x > a$（相应地 $x < a$）的点成立。手册注明导数 $f'(x)$ 的概念在 1.4.4 引入（见 [[queries/13节引用14节导数与微分尚未入库]]）。

## 变形：重复应用

有时必须重复应用洛必达法则，直到右端有极限：

```
lim_{x→a} f(x)/g(x) = lim_{x→a} f'(x)/g'(x) = … = lim_{x→a} f^{(n)}(x)/g^{(n)}(x)
```

## 其他不定式的转化

- $0 \cdot \infty$ 型可转化为 $\frac{\infty}{\infty}$ 型。例 4：$\lim_{x\to+0} x \ln x = \lim_{x\to+0} \frac{\ln x}{1/x} = \lim_{x\to+0} (-x) = 0$。
- $\infty - \infty$ 型可转化为 $\infty \cdot a$ 型（$a$ 为某个有限值）。例 5：$\lim_{x\to+\infty}(\mathrm{e}^x - x) = +\infty$。
- $0^0$、$\infty^0$、$0^\infty$ 型借助

```
a^x = e^{x · ln a}
```

处理。例 6（$\infty^0$）：由 $x^{1/x} = \mathrm{e}^{\ln x / x}$ 及例 2 得 $\lim_{x\to+\infty} x^{1/x} = \mathrm{e}^0 = 1$。

## 手册给出的例子

- 例 1（$\frac{0}{0}$）：$\lim_{x\to 0} \frac{\sin x}{x} = \lim_{x\to 0} \frac{\cos x}{1} = \cos 0 = 1$。
- 例 2（$\frac{\infty}{\infty}$）：$\lim_{x\to+\infty} \frac{\ln x}{x} = 0$；$\lim_{x\to+\infty} \frac{\mathrm{e}^x}{x} = +\infty$。
- 例 3：$\lim_{x\to+\infty} \frac{\mathrm{e}^x}{x^2} = \lim_{x\to+\infty} \frac{\mathrm{e}^x}{2x} = \lim_{x\to+\infty} \frac{\mathrm{e}^x}{2} = +\infty$。
