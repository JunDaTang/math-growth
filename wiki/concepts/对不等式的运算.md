# 对不等式的运算

1.1.5 节：对任意实数 a, b, c，下列法则成立：

```latex
\begin{array}{ll}
a \leqslant b \Rightarrow a + c \leqslant b + c & (\text{加法}), \\
a \leqslant b \Rightarrow a - c \leqslant b - c & (\text{减法}), \\
a \leqslant b,\ c \geqslant 0 \Rightarrow ac \leqslant bc & (\text{乘法}), \\
a \leqslant b,\ c < 0 \Rightarrow ac \geqslant bc & \\
a \leqslant b,\ c > 0 \Rightarrow \frac{a}{c} \leqslant \frac{b}{c} & (\text{除法}), \\
a \leqslant b,\ c < 0 \Rightarrow \frac{a}{c} \geqslant \frac{b}{c} & \\
0 < a \leqslant b \Rightarrow \frac{1}{b} \leqslant \frac{1}{a} & (\text{倒数}).
\end{array}
```

即：不等式两边可以同时加或减同一个数，或同时乘以或除以一个**正数**，而不改变不等号；两边都乘以或除以一个**负数**，不等号**改变方向**。

## 两个不等式的运算

对任意实数 a, b, c, d：

```latex
\begin{array}{ll}
a \leqslant b,\ c \leqslant d \Rightarrow a + c \leqslant b + d & (\text{加法}), \\
a \leqslant b,\ 0 \leqslant c \leqslant d \Rightarrow ac \leqslant bd & (\text{乘法}).
\end{array}
```

当不等号 ≤ 都用严格不等号 < 代替时，上述所有法则仍成立。

## 典型例子

- 例 1：对任意实数 a, b，`ab ≤ ½(a² + b²)`。证明由 `0 ≤ (a − b)²` 展开得 `0 ≤ a² − 2ab + b²`，两边加 2ab 后除以 2。
- 例 2：对所有实数 a，`a⁴/(1 + a²) ≤ a⁴`。证明由 `1 ≤ 1 + a²` 及倒数法则得 `1/(1 + a²) ≤ 1`，再两边乘 a⁴。
- 例 3：线性不等式 `ax − b ≥ 0`（(1.16)，a ≠ 0）：a > 0 时成立当且仅当 x ≥ b/a；a < 0 时成立当且仅当 x ≤ b/a。
- 例 4：二次不等式 `ax² + 2bx + c ≥ 0`（(1.17)，a > 0），判别式 `D := b² − ac`：D ≤ 0 时任一实数 x 都是解；D > 0 时解集为

```latex
x \leqslant \frac{-b - \sqrt{D}}{a} \quad \text{或} \quad x \geqslant \frac{-b + \sqrt{D}}{a}.
```
