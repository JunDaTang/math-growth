# 双曲函数倍角与半角公式

《数学指南——实用数学手册》在两个相邻小节中分别给出双曲函数的倍角与半角公式：0.2.10 节覆盖 $\sinh$、$\cosh$，0.2.11 节覆盖商型双曲函数 $\tanh$、$\coth$。两者合起来构成完整的双曲倍角/半角恒等式体系。

## 倍角公式

### $\sinh$、$\cosh$ 的倍角（0.2.10 节）

$$
\sinh 2x = 2 \sinh x \cosh x, \qquad \cosh 2x = \sinh^{2} x + \cosh^{2} x.
$$

两式均为 [[双曲函数加法定理]] 在 $y = x$ 时的特例；结合基本恒等式 $\cosh^{2}x - \sinh^{2}x = 1$，$\cosh 2x$ 亦可写成 $1 + 2\sinh^{2}x$ 或 $2\cosh^{2}x - 1$（本手册 0.2.10 节给出的形式是 $\sinh^{2}x + \cosh^{2}x$）。

### $\tanh$、$\coth$ 的倍角（0.2.11 节）

$$
\tanh 2x = \frac{2\tanh x}{1 + \tanh^{2} x}, \quad \coth 2x = \frac{1 + \coth^{2} x}{2\coth x}.
$$

两者都可以由 [[双曲函数加法定理]] 中取 $y = x$ 直接得到。注意分母 $1 + \tanh^{2} x$ 中的「加号」与三角倍角公式 $\tan 2x = \frac{2\tan x}{1 - \tan^{2} x}$ 的符号相反。

与 [[双曲函数的平方关系]] 联用，倍角公式还可写成 $\tanh 2x = \frac{2\sinh x \cosh x}{\cosh^{2} x + \sinh^{2} x}$ 等形式。

## 半角公式

### $\sinh$、$\cosh$ 的半角（0.2.10 节）

$$
\sinh \frac{x}{2} =
\begin{cases}
\sqrt{\frac{1}{2}(\cosh x - 1)}, & x \geqslant 0, \\
-\sqrt{\frac{1}{2}(\cosh x - 1)}, & x < 0,
\end{cases}
$$

$$
\cosh \frac{x}{2} = \sqrt{\frac{1}{2}(\cosh x + 1)}, \qquad x \in \mathbb{R}.
$$

### $\tanh$、$\coth$ 的半角（0.2.11 节）

$$
\tanh \frac{x}{2} = \frac{\cosh x - 1}{\sinh x} = \frac{\sinh x}{\cosh x + 1},
$$

$$
\coth \frac{x}{2} = \frac{\sinh x}{\cosh x - 1} = \frac{\cosh x + 1}{\sinh x}.
$$

$\tanh \frac{x}{2}$ 的两种写法互为倒数关系下的等价形式（分子分母同乘 $\cosh x + 1$ 即得第二式），这种「无平方根」的半角表达是双曲情形相对三角情形的一个便利之处。

## 公式一览

| 函数 | 倍角公式 | 半角公式 | 来源节 |
|---|---|---|---|
| $\sinh$ | $\sinh 2x = 2\sinh x \cosh x$ | 带 $\pm$ 分支的根式，分界点 $x = 0$ | 0.2.10 |
| $\cosh$ | $\cosh 2x = \sinh^{2}x + \cosh^{2}x$ | $\sqrt{\frac{1}{2}(\cosh x + 1)}$，取正根 | 0.2.10 |
| $\tanh$ | $\tanh 2x = \dfrac{2\tanh x}{1 + \tanh^{2}x}$ | $\dfrac{\cosh x - 1}{\sinh x} = \dfrac{\sinh x}{\cosh x + 1}$ | 0.2.11 |
| $\coth$ | $\coth 2x = \dfrac{1 + \coth^{2}x}{2\coth x}$ | $\dfrac{\sinh x}{\cosh x - 1} = \dfrac{\cosh x + 1}{\sinh x}$ | 0.2.11 |

## 定义域与适用范围（0.2.10 节相关说明）

- $\sinh \frac{x}{2}$ 的公式**限定实变量**，且带 $\pm$ 分支，分界点为 $x = 0$；这与 $\sinh$ 本身的奇函数性一致。
- $\cosh \frac{x}{2}$ 取正根，限定 $x \in \mathbb{R}$。半角公式不适用于一般复数 $x$，这与本节其余公式「对所有复数 $x$ 和 $y$ 成立」的声明形成范围差异。
- 源文档在排版上把 $\cosh \frac{x}{2}$ 一行印在「棣莫弗公式」小标题之下，属小标题错位，详见 [[0210节半角与棣莫弗公式小标题错位]]。

## 与 0.2.10 节内容的衔接

完整的双曲倍角/半角体系还包括 $\sinh 2x$、$\cosh 2x$ 与 $\sinh \frac{x}{2}$、$\cosh \frac{x}{2}$ 等形式（见 [[双曲正弦]]、[[双曲余弦]]）。0.2.11 节新增的 $\tanh$、$\coth$ 分支可视为这些基元公式之商。

一个结构性事实（0.2.11 节来源）：0.2.11 节的倍角（2.5 倍角）是「双曲正切」曲线上真正可用代数（而非三角）方式处理的部分，这也解释了为什么 [[双曲函数的平方关系]] 表全部由 $\sinh$、$\cosh$ 的平方构成。
