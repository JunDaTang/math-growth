# 最低项有理函数

## 定义

最低项有理函数是指表达式

```latex
f(x) := \frac{N(x)}{D(x)},
```

其中 $N$ 和 $D$（分别是分子和分母）是**复系数多项式**，且满足条件

```latex
0 \leqslant \deg(N) < \deg(D).
```

即：分子次数严格小于分母次数。这里的次数概念见 [[concepts/多项式的次数|多项式的次数]]。

## 作用

「最低项」条件是 [[concepts/部分分式分解|部分分式分解]] 定理成立的前提。定理的结论只对最低项有理函数成立：

```latex
f(x) = \sum_{j=1}^{r} \left( \sum_{\beta=1}^{\alpha_j} \frac{A_{j\beta}}{(x - x_j)^{\beta}} \right),
```

其中 $x_1, \dots, x_r$ 是分母 $D$ 的两两互异零点，$\alpha_1, \dots, \alpha_r$ 是其[[concepts/多项式的零点与重数|重数]]。

## 与一般有理函数的关系

若不满足 $\deg(N) < \deg(D)$（即 $\deg(N) \geqslant \deg(D)$），则先用 [[concepts/欧几里得算法-多项式|欧几里得算法（多项式）]] 作带余除法，把函数写成

```latex
\frac{N(x)}{D(x)} = Q(x) + \frac{R(x)}{D(x)},
```

其中 $Q$ 是多项式、$R/D$ 是最低项有理函数。由此任意[[concepts/有理函数|有理函数]]的部分分式分解都可归约到最低项情形。

## 说明

- 定义中系数域为复数域；实系数情形作为特例在定理中另行讨论（此时零点与系数均复共轭成对）。
- 原始来源把该定义紧接在示例之后给出，是用一般性陈述替换「先设形式再解系数」这一具体操作的关键一步。
