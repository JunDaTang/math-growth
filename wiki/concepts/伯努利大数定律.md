# 伯努利大数定律

## 陈述

《数学指南——实用数学手册》6.1.2 节以抛硬币为模型给出该定律。设 $\varepsilon > 0$ 为任意给定的实数，记 $A_n$ 为满足

```
| H(e…) − 1/2 | < ε
```

的所有基本事件 $e_{i_1 i_2 \dots i_n}$ 组成的集合，即下标中「1」（以及「2」）所占百分比与 1/2 的差小于 $\varepsilon$。则

```
lim_{n→∞} P(A_n) = 1
```

等价地写作

```
lim_{n→∞} P( | H_n − 1/2 | < ε ) = 1
```

## 解释

这是「随机试验重复多次后，事件频率趋近其概率」这一基本经验的数学证明。文中指出，该定律由雅各布·伯努利最早提出并证明，伯努利是利用古典概型公式 (6.1) 计算 $P(A_n)$ 而得出的（见 [[concepts/古典概型]]、[[concepts/频率]]）。

## 边界

本节只给出抛硬币（单个概率 $P(A) = 1/2$ 的二值试验）这一特例的陈述，未给出一般形式的证明细节，也未讨论该定律与后来的弱大数定律、强大数定律、中心极限定理之间的强弱关系；中心极限定理在本节中仅以「见 6.2.4」的方式前向引用。

## 出处

《数学指南——实用数学手册》6.1.2 节（见 [[sources/10-数学指南实用数学手册--9-61-基本的随机性--1r43h9a]]）。
