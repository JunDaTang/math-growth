# 曲率中心

## 定义

曲率中心 $M(\xi,\eta)$ 是与曲线在点 $P$ 有二阶切触（见 [[曲率半径]]）的曲率圆的圆心。它与点 $P$ 的距离即曲率半径 $R$。

## 参数式曲线的曲率中心公式

对曲线 $x = x(t), y = y(t)$，源文件给出

$$
\xi = x_0 - \frac{y_0'(x_0'^2 + y_0'^2)}{x_0' y_0'' - y_0' x_0''}, \quad
\eta = y_0 + \frac{x_0'(x_0'^2 + y_0'^2)}{x_0' y_0'' - y_0' x_0''},
$$

其中的分母 $x_0'y_0'' - y_0'x_0''$ 与 [[曲率]] 公式的分子相同；分母为零处即曲率为零的情形，对应 [[拐点与极值点]] 讨论的拐点，此时曲率中心退到无穷远。

## 显式与隐式情形的公式（表 3.7 与表 3.8）

| 表示 | 曲率中心 |
|---|---|
| 显形式 $y = y(x)$ | $\xi = x_0 - \dfrac{y_0'(1 + y_0'^2)}{y_0''}$，$\eta = y_0 + \dfrac{1 + y_0'^2}{y_0''}$ |
| 极坐标 $r = r(\varphi)$ | $\xi = x_0 - \dfrac{(r^2 + r'^2)(x_0 + r'\sin\varphi)}{r^2 + 2r'^2 - rr''}$，$\eta = y_0 - \dfrac{(r^2 + r'^2)(y_0 - r'\cos\varphi)}{r^2 + 2r'^2 - rr''}$ |
| 隐式 $F(x,y) = 0$ | $\xi = x_0 - \dfrac{F_x(F_x^2 + F_y^2)}{F_y^2F_{xx} - 2F_xF_yF_{xy} + F_x^2F_{yy}}$，$\eta = y_0 - \dfrac{F_y(F_x^2 + F_y^2)}{F_y^2F_{xx} - 2F_xF_yF_{xy} + F_x^2F_{yy}}$ |

以上均按源文件表 3.7、表 3.8 原文照录；极坐标一栏的分子中出现 $x_0, y_0$ 的方式存在可疑之处，记录于 [[361节表37与表38公式符号疑似讹误]]。

## 例：圆

对 $x = R\cos t, y = R\sin t$，曲率中心为原点 $(0,0)$（源文件例 2）。这也与隐式公式一致：以 $F(x,y) = x^2 + y^2 - R^2$ 代入上表第三行，得到 $\xi = 0$、$\eta = 0$。
