# 单位圆与直角三角形中的三角函数

《数学指南——实用数学手册》0.2.8 节在给出分析定义之后，补上两种几何解释：直角三角形中的**边比**（表 0.16）与单位圆中的**线段长**（图 0.31）。前者面向计算与测量，后者用来解释周期性与对称性。

## 直角三角形解释（表 0.16）

设角 $x$ 以弧度为单位（参看 [[角度制与弧度制]]），$0 < x < \pi/2$：

| | 正弦 | 余弦 |
|---|---|---|
| 边比 | $\sin x = \dfrac{a}{c}$（对边 $a$ 与斜边 $c$ 的比） | $\cos x = \dfrac{b}{c}$（邻边 $b$ 与斜边 $c$ 的比） |

## 单位圆解释

利用单位圆，$\sin x$ 与 $\cos x$ 变成图中所示的线段长，由此立即可得：

- **周期性**：旋转 $2\pi$ 后取值不变，即 $\sin(x + 2\pi) = \sin x$、$\cos(x + 2\pi) = \cos x$（公式 (0.38)），且对所有复变量 $x$ 成立。
- **对称性**：对 $0 \leqslant x \leqslant \pi/2$ 存在一组对称关系（手册编号 (0.39)；本来源的 OCR 未保留公式本体，见 [[queries/正弦余弦对称性公式039的具体形式]]）。
- **毕达哥拉斯关系**：由图 0.31(a) 与毕达哥拉斯定理得 $\cos^{2} x + \sin^{2} x = 1$（公式 (0.40)），对所有复变量 $x$ 成立，见 [[毕达哥拉斯三角恒等式]]、[[毕达哥拉斯定理]]。
- **函数图像与零点**：由图 0.31(e)、(f) 读出 $y = \sin x$ 与 $y = \cos x$ 的图像及零点分布，见 [[三角函数的零点]]。

## 负角的约定

正角为逆时针方向（数学上的正方向），负角为顺时针方向（数学上的负方向）；图 0.32 给出 $x = -\pi/4$ 与 $x = -\pi$ 的图示。
