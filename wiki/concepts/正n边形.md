# 正n边形

一个 n 边形称为正 n 边形，若它的所有边和角都相等。见 [[数学指南-实用数学手册]]（0.1.3 节，图 0.7 给出 n = 3, 4, 5, 6 的示例）。

## 几何关系

设正 n 边形的中心到各个角的距离为 $r$：

| 量 | 公式 |
|---|---|
| 中心角 | $\varphi = \frac{2\pi}{n}$ |
| 补角 | $\alpha = \pi - \varphi$ |
| 边长 | $a = 2r\sin\frac{\varphi}{2}$ |
| 周长 | $C = na$ |
| 面积 | $A = \frac{1}{2}nr^{2}\sin\varphi$ |

## 与相邻条目的区分

正 n 边形是**二维**对象；[[正多面体]]（0.1.5 节）是**三维**对象，两者不可交叉套用公式。与 [[多边形内角和]]（0.1.2 节）内容相邻。

正 n 边形能否用尺规作出由 [[正多边形尺规作图]]（高斯定理）给出判定。面积与周长的一般公式汇总另见 [[平面图形面积与周长公式]]。
