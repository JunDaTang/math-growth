# 二次收敛

《数学指南——实用数学手册》4.2.5 节对迭代 $a_{n+1} = a_n/2 + 1/a_n$（用于计算 $\sqrt{2}$）给出的收敛速度估计。记 $\Delta_n = a_n - \sqrt{2}$ 为全误差，则

```
Δ_{n+1} ≤ Δ_n²
```

来源称之为**二次收敛**，「即该过程收敛得非常快」。与此配合的是先验估计 $\Delta_{n+2} \leqslant 10^{-2^n}$，它把二次收敛在步数上表现为双指数衰减。

具体数值见来源的表 4.1：$a_1=2$、$a_2=1.5$、$a_3=1.4118$、$a_4=1.414215$、$a_5=1.414213562$，由之得到 $\sqrt{2} = 1.414213562 \pm 10^{-9}$，即五步之内达到 $10^{-9}$ 精度。

收敛速度的研究被列为解决数学问题八步流程的第 (vii) 步，见[[concepts/适定问题]]。
