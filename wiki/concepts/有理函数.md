# 有理函数

## 定义

两个来源对有理函数的界定方式不同，分别列出，不合并为单一表述：

| 来源 | 定义表述 | 系数范围 |
|---|---|---|
| 0.2.15 有理函数 | （实）有理函数是形如 $y = \dfrac{a_{n}x^{n} + \cdots + a_{1}x + a_{0}}{b_{m}x^{m} + \cdots + b_{1}x + b_{0}}$ 的函数 $y=f(x)$，分子与分母上都是多项式 | 实数（书中写作「（实）有理函数」） |
| 2.1.7 部分分式分解 | 有理函数是分子与分母均为[[多项式|多项式]]的分式函数，即形如 $\dfrac{N(x)}{D(x)}$，其中 $N,D$ 是多项式且 $D$ 不恒为零 | 复系数多项式 |

0.2.15 的表述：

```latex
y = \frac{a_{n}x^{n} + \cdots + a_{1}x + a_{0}}{b_{m}x^{m} + \cdots + b_{1}x + b_{0}}
```

其中分子和分母上都是多项式（参看 [[多项式]]，本书 0.2.14）。分母多项式的零点处函数无定义，是函数的极点或[[表观奇点|表观奇点]]。

2.1.7 的表述：

```latex
\frac{N(x)}{D(x)}
```

的函数，其中 $N, D$ 是多项式（$D$ 不恒为零）。在 2.1.7 节的处理中，$N, D$ 取复系数多项式。

> [!note] 来源说明
> 2.1.7 的原始来源未对有理函数给出独立的形式化定义，而是在「一般有理函数」标题下以其与[[最低项有理函数|最低项有理函数]]的对比来刻画；对应的整理页据此组织内容，以避免与来源的表述产生冲突。上述表格式定义出自 0.2.15。

## 在无穷远点的性状

（此节的结论出自 0.2.15。）令 $c := a_{n}/b_{m}$（首项系数之比），则

```latex
\lim_{x \to \pm\infty} f(x) = \lim_{x \to \pm\infty} c\,x^{n-m} .
```

当 $c>0$ 时，$x \to +\infty$ 的极限为：$n=m$ 时等于 $c$；$n>m$ 时为 $+\infty$；$n<m$ 时为 $0$。$x \to -\infty$ 的极限还依赖 $n-m$ 的奇偶：$n>m$ 且 $n-m$ 为偶数时为 $+\infty$，为奇数时为 $-\infty$。当 $c<0$ 时，须用 $\mp\infty$ 代替 $\pm\infty$。详见 [[有理函数在无穷远点的性状]]。

## 分解与结构

### 一般有理函数向最低项情形的归约（2.1.7）

2.1.7 节的主题是给出**任意**有理函数的分解：

- 当 $\deg(N) < \deg(D)$ 时，函数本身即 [[最低项有理函数|最低项有理函数]]，可直接应用 [[部分分式分解|部分分式分解]] 定理。
- 当 $\deg(N) \geqslant \deg(D)$ 时，先用 [[欧几里得算法-多项式|欧几里得算法（多项式）]] 分出多项式部分 $Q(x)$，余下的 $R(x)/D(x)$ 为最低项有理函数。

于是「一般有理函数」的分解被完整地归约为最低项情形；节末的算例

```latex
\frac{x^{2}}{x^{2} + 1} = 1 - \frac{1}{x^{2} + 1} = 1 - \frac{1}{2\mathrm{i}} \left( \frac{1}{x - \mathrm{i}} - \frac{1}{x + \mathrm{i}} \right)
```

正是 $\deg(N) = \deg(D) = 2$ 的非最低项例子：先分出多项式部分 $1$，再分解最低项部分。

### 结构说明（0.2.15）

由 [[部分分式分解]]（本书 2.1.7）可以把有理函数化为简单分式之和，从而得到有理函数的清晰结构。

## 分类图景

（此节按分母次数由低到高给出若干层级，出自 0.2.15。）

- 最简形式 $y=b/x$：[[等轴双曲线]]；
- 线性分子与分母：[[线性分式函数]]，可经坐标平移化为标准形；
- $n$ 次分母 $y=b/x^{n}$：[[倒数幂函数]]；
- 二次分母：[[二次分母有理函数的分类]]，由判别式 $D:=c^{2}-d$ 决定形态，其中 $D<0$ 时函数在 $\mathbb{R}$ 上光滑（[[有理函数的光滑性]]）。

## 与多项式的对照

（此节出自 0.2.15。）有理函数是多项式概念的自然延伸：分子分母均为多项式。与 [[多项式在无穷远点的性状]] 平行，本节给出了有理函数在无穷远点的性状；与 [[多项式的光滑性]] 平行，本节给出了二次分母情形下 $D<0$ 时的光滑性结论。
