# 比较系数法

## 定义

比较系数法是求 [[concepts/部分分式分解|部分分式分解]] 中待定系数 $A_{j\beta}$ 的一种方法：把去分母后的恒等式按幂次展开，比较两边同次幂的系数，得到一个以待定系数为未知量的[[concepts/线性方程组|线性方程组]]，解之即得系数。

## 在 2.1.7 节中的操作

以 $f(x) = \dfrac{x}{(x-1)(x-2)^2}$ 为例，去分母得式 (2.30)：

```latex
x = A(x-2)^{2} + B(x-1)(x-2) + C(x-1).
```

展开右端：

```latex
x = A(x^{2} - 4x + 4) + B(x^{2} - 3x + 2) + C(x - 1).
```

比较 $x^{2}$、$x$ 及常数项 1 的系数：

```latex
0 = A + B,      1 = -4A - 3B + C,      0 = 4A + 2B - C.
```

解得

```
A = 1,  B = -1,  C = 2.
```

## 与其他方法的关系

原始来源指出，比较系数法给出的是 $n$ 个未知量、$n$ 个方程的线性方程组，与 [[concepts/代入特殊值法|代入特殊值法]] 相比**通常较慢**；两种方法给出的系数相同，均唯一。
