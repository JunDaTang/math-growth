# 立体图形的体积与表面积公式

《数学指南——实用数学手册》0.1.4 节的表 0.5 系统给出了 18 类三维图形的体积 $V$、表面积 $O$ 与侧面积 $M$。本页汇总该表内容，并逐条注明原文所给的变量含义。表中各条**互不依赖**，引用时须逐条对应各自图形，不可把一个图形的公式或近似性推广到另一个图形。

## 体积公式汇总

| 立体图形 | 体积公式 | 变量含义 |
|---|---|---|
| 立方体 | $V = a^{3}$ | $a$ 为边长 |
| 长方体 | $V = abc$ | $a, b, c$ 为边长 |
| 球 | $V = \frac{4}{3}\pi r^{3}$ | $r$ 为半径 |
| 棱柱 | $V = Gh$ | $G$ 为底面积，$h$ 为高 |
| 圆柱 | $V = \pi r^{2}h$ | $r$ 为半径，$h$ 为高 |
| 立体圆环 | $V = \pi h(r^{2} - \rho^{2})$ | $r$ 为外半径，$\rho$ 为内半径，$h$ 为高 |
| 棱锥 | $V = \frac{1}{3}Gh$ | $G$ 为底面积，$h$ 为高 |
| 圆锥 | $V = \frac{1}{3}\pi r^{2}h$ | $r$ 为半径，$h$ 为高，$s$ 为母线长 |
| 棱台 | $V = \frac{h}{3}(G + \sqrt{Gg} + g)$ | $G$ 为下底面积，$g$ 为上底面积 |
| 圆台 | $V = \frac{\pi h}{3}(r^{2} + r\rho + \rho^{2})$ | $r, \rho$ 为半径，$h$ 为高，$s$ 为母线长 |
| 方尖形 | $V = \frac{1}{6}\left(ab + (a + c)(b + d) + cd\right)$ | $a, b, c, d$ 为边长 |
| 楔形（侧面为等边三角形） | $V = \frac{\pi}{6}bh(2a + c)$ | $a, b$ 为底边长，$c$ 为上边，$h$ 为高 |
| （由纬线所界定的）球冠 | $V = \frac{\pi}{3}h^{2}(3r - h)$ | $r$ 为球的半径，$h$ 为高 |
| （由两条纬线所界定的）球台 | $V = \frac{\pi h}{6}(3R^{2} + 3\rho^{2} + h^{2})$ | $r$ 为球的半径，$h$ 为高，$R$ 和 $\rho$ 为两条纬线圈的半径 |
| 圆环 | $V = 2\pi r^{2}\rho$ | $r$ 为圆环的半径，$\rho$ 为截面半径 |
| 桶形（圆形截面） | $V = 0.0873h(2D + 2r)^{2}$ | $D$ 为直径，$r$ 为顶的半径，$h$ 为高；**这是一个近似公式** |
| 椭球 | $V = \frac{4}{3}\pi abc$ | $a, b, c$ 为轴长，$c < b < a$ |

## 表面积与侧面积公式汇总

表 0.5 中只对部分图形给出了 $O$ 或 $M$（未给出者原文留空）：

| 立体图形 | 表面积 / 侧面积 |
|---|---|
| 立方体 | $O = 6a^{2}$ |
| 长方体 | $O = 2(ab + bc + ca)$ |
| 球 | $O = 4\pi r^{2}$ |
| 圆柱 | $O = M + 2\pi r^{2}$，其中 $M = 2\pi rh$ |
| 圆锥 | $O = M + \pi r^{2}$，其中 $M = \pi rs$ |
| 圆台 | $O = M + \pi(r^{2} + \rho^{2})$，其中 $M = \pi s(r + \rho)$ |
| （由纬线所界定的）球冠 | $O = 2\pi rh$（顶部） |
| （由两条纬线所界定的）球台 | $O = 2\pi rh$（中部） |
| 圆环 | $O = 4\pi^{2}r\rho$ |
| 椭球 | 见 [[勒让德椭球表面积公式]]（公式 (L)） |

棱柱、立体圆环、棱锥、棱台、方尖形、楔形、桶形在表 0.5 中未给出表面积或侧面积。

## 结构性观察

- **柱体与锥体的统一形式**：棱柱 $V = Gh$ 与棱锥 $V = \frac{1}{3}Gh$ 构成「柱—锥」系数 1 与 $1/3$ 的对照；圆柱与圆锥、棱台与圆台同理（圆台公式即棱台公式在圆形截面上 $G = \pi r^{2}$、$g = \pi\rho^{2}$ 的特例）。
- **球体的加框强调**：原文对球（$V = \frac{4}{3}\pi r^{3}$、$O = 4\pi r^{2}$）、棱柱、棱锥三组公式加框，提示其在手册中的基础地位。
- **球冠与球台的表面积**：二者均记为 $O = 2\pi rh$，但原文分别限定为「顶部」与「中部」，指由纬线分出的那一部分的曲面面积，不可误读为整体表面积；两式中 $r$ 的含义也不同（球冠条目的 $r$ 为球的半径；球台条目变量说明中同时出现 $r$ 与两条纬线圈半径 $R, \rho$）。
- **椭球是唯一的例外项**：椭球体积与球同型（$V = \frac{4}{3}\pi abc$），但表面积不能初等表示，须借助椭圆积分，见 [[椭球表面积需椭圆积分]]。
- **唯一的近似公式**：桶形（圆形截面）体积被原文明确标注为「这是一个近似公式」，引用时须保留该限定。
