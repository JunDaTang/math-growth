# 均值与方差

## 定义（一维）

《数学指南——实用数学手册》6.1.4 节对具有概率密度 $\varphi$ 的随机变量 $X$ 定义

```
X̄ := ∫_{−∞}^{∞} x φ(x) dx
```

称为 $X$ 的**均值**（或期望）；称

```
(ΔX)² := ∫_{−∞}^{∞} (x − X̄)² φ(x) dx
```

为 $X$ 的**方差**或平方离差，并称非负量 $\Delta X$ 为 $X$ 的**标准差**。文中给出直观解释：若把 $\varphi$ 理解为质量密度，则 $\overline{X}$ 就是质量中心。

## 随机变量函数的均值与方差

设 $Z = F(X)$，则

```
Z̄ = ∫_{−∞}^{∞} F(x) φ(x) dx
(ΔZ)² = ∫_{−∞}^{∞} (F(x) − Z̄)² φ(x) dx
```

例 2 给出 $(\Delta X)^2 = \overline{(X-\overline{X})^2} = \int_{-\infty}^{\infty}(x-\overline{X})^2\varphi(x)\,\mathrm{d}x$。

**均值加法公式**

```
F(X) + G(X) 的均值 = F(X) 的均值 + G(X) 的均值
```

二维情形的对应公式见 [[concepts/协方差与相关系数]]。

## 与置信区间的关系

均值与标准差共同刻画测量值的集中程度：由 [[concepts/切比雪夫不等式]] 可推出测量值落入 $[\overline{X} - \Delta X/\sqrt{\alpha}, \overline{X} + \Delta X/\sqrt{\alpha}]$ 的概率大于 $1 - \alpha$。故 $\Delta X$ 越小，$X$ 的测量值越密集在 $\overline{X}$ 附近。

## 样本估计

6.1.5 节给出由测量值 $x_1,\dots,x_n$ 估计真值的公式：

```
X̄ = (1/n) Σ_{j=1}^n x_j
(ΔX)² = (1/(n−1)) Σ_{j=1}^n (x_j − X̄)²
```

注意方差估计式的分母为 $n-1$。
