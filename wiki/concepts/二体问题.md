# 二体问题

二体问题是《数学指南——实用数学手册》1.12.5.2 节的主题。天体力学中的二体问题可以被归结为两个物体关于其中另一个物体的相对运动的一个一体问题，这导致了开普勒（Kepler, 1571—1630）的运动定律。

## 问题设定

对分别具有质量 $m_1$ 与 $m_2$、总质量 $m = m_1 + m_2$ 的两个天体，研究其运动 $\boldsymbol{x}_1 = \boldsymbol{x}_1(t)$ 与 $\boldsymbol{x}_2 = \boldsymbol{x}_2(t)$。例如 $m_1$ 可以是太阳的质量，$m_2$ 可以是其行星之一的质量（图 1.139）。运动定律为

```text
m₁ x₁'' = F,   m₂ x₂'' = -F,
x_j(0) = x_{j0},   x_j'(0) = v_j,   j = 1, 2            (1.290)
```

其中牛顿引力为

```text
F = G m₁ m₂ (x₂ - x₁) / |x₂ - x₁|³
```

力 F 与 −F 成对出现，相应于牛顿定律「作用力 = 反作用力」。原始理论体系见 [[牛顿]]。

## 求解结构

本源把二体问题分解为四步：

1. **质心运动的分离**：总动量守恒 $P' = 0$，故 $m y'' = 0$，质心 $\boldsymbol{y}(t) = \boldsymbol{y}(0) + t\boldsymbol{y}'(0)$ 以常速度沿一直线运动。细节见 [[质心分离]]。
2. **约化到一体问题**：取相对坐标 $x := x_2 - x_1$，得到 (1.291)——质量为 $m_2$ 的物体在质量为 m 的物体的引力场中的一体问题。细节见 [[一体问题]]。
3. **守恒律**：由 (1.291) 得能量守恒 (1.292) 与角动量守恒 (1.293)，其中势能 $U(\boldsymbol{x}) = -G m m_2 / |\boldsymbol{x}|$（参阅 1.9.6）。
4. **平面运动与极坐标化**：角动量守恒 ⇒ $\boldsymbol{x}(t)\cdot\boldsymbol{N} = 0$，运动被限制于垂直于 $\boldsymbol{N}$ 的平面；取 z 轴沿 $\boldsymbol{N}$ 后引入极坐标，得到方程组 (1.294)。见 [[极坐标单位向量]]。

## 主要结论

- 轨道方程为圆锥曲线：

```text
r = p / (1 + ε cos φ)                                   (1.295)
```

- 时间与极角的关系由 $t = \frac{m_2}{|N|}\int_0^\varphi r(\varphi)^2 \mathrm{d}\varphi$ 给出。
- 在 $0 \leqslant \varepsilon < 1$ 的情形下得到椭圆轨道，即开普勒第一定律；面积扫过率恒定为开普勒第二定律；周期与长半轴关系为开普勒第三定律。见 [[开普勒定律]] 与 [[圆锥曲线轨道]]。

## 与其他页面的关系

- 与 [[N体问题]] 的区别：本源只处理两个天体的特殊情况，并借助质心分离把它化为单体问题；一般的 N 体问题见 1.9.6 节（[[太阳系质心沿直线常速运动]]）。
