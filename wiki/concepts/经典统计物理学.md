# 经典统计物理学

## 模型

《数学指南——实用数学手册》6.1.6 节声称「利用上一段的结果，全部经典统计物理学可以描述得非常优美和简洁」。考虑由 $N$ 个质量为 $m$ 的粒子组成的系统。

系统能量

```
E = H(q, p)
```

$H$ 为系统的哈密顿函数。设每个粒子有 $f$ 个自由度（例如三个平移自由度，以及/或者其他来自旋转或震动的自由度），

```
q = (q_1, …, q_{fN}),   p = (p_1, …, p_{fN})
```

其中 $q_j$ 是粒子的坐标，$p_j$ 是与粒子速度有关的（广义）动量变量。

**经典力学**：运动方程由典范方程组给出

```
q_j′(t) = H_{p_j}(q(t), p(t)),  p_j′(t) = −H_{q_j}(q(t), p(t)),  j = 1,…,fN
```

假设 $(q,p)$ 在 $\mathbb{R}^{fN}$ 的区域 $\Pi$ 中运动，称 $\Pi$ 为系统的**相空间**（有关哈密顿力学的基本概念，见 5.1.3）。

**经典统计力学**：从概率密度出发

```
φ(q,p) := C e^{−H(q,p)/(kT)}
```

其中常数 $C$ 由 $\int_\Pi \varphi\,\mathrm{d}q\,\mathrm{d}p = 1$ 确定，$T$ 为绝对温度，$k$ 为 [[concepts/玻尔兹曼常量]]。

## 由 $\varphi$ 引入的量

1. 系统落入相空间子区域 $G$ 的概率

```
P(G) = ∫_G φ(q,p) dq dp        (6.7)
```

2. 函数 $F = F(q,p)$ 的均值和方差

```
F̄ = ∫_Π F(q,p) φ(q,p) dq dp
(ΔF)² = ∫_Π (F(q,p) − F̄)² φ(q,p) dq dp
```

3. 两个给定函数 $A$、$B$ 的相关系数

```
r = (1/(ΔA ΔB)) · (A − Ā)(B − B̄) 的均值
```

4. 系统在绝对温度 $T$ 时的熵

```
S = −k · (ln φ) 的均值
```

## 波动原理

关键问题是：为什么了解气体的统计性质必须具备非常灵敏的测量能力？答案在对理想气体成立的公式

```
ΔE / Ē = (1/√N) · (Δε / ε̄)        (6.9)
```

中，其中 $N$ 为粒子数，$E$ 为总能量，$\varepsilon$ 为单个粒子的能量。由于 $\Delta\varepsilon/\overline{\varepsilon}$ 近似等于 1，而 $N$ 的量级为 $10^{23}$，因此气体能量的相对方差 $\Delta E/\overline{E}$ 相当小，在日常生活中没有任何明显作用。推理基于 [[concepts/随机变量的独立性]]：粒子间无相互作用，各粒子能量独立，故

```
Ē = N ε̄,   (ΔE)² = N (Δε)²
```

由此得 (6.9)。

## 可变粒子数与化学势

在化学反应期间粒子数可以变化，相应的统计物理学需要考虑参数 $T$（绝对温度）与参数 $\mu$（化学势）。文中指出有关讨论见 [212]，那里考虑了一个也可应用于现代量子统计（原子、分子、光子和基本粒子的统计）的一般方案。
