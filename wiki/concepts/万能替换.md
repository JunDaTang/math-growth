# 万能替换

万能替换指三角有理积分中的换元

```latex
t = \tan\frac{\varphi}{2} \tag{3.58}
```

《数学指南——实用数学手册》3.8.3 节用它来解释该替换之所以「万能」的代数几何原因。

## 本节给出的解释

积分

```latex
J = \int R(x, \sqrt{1 - x^{2}})\,\mathrm{d}x \tag{3.57}
```

对应圆 $C: x^{2} + w^{2} = 1$，其亏格为零，故存在有理参数化

```latex
x = \frac{t^{2} - 1}{t^{2} + 1}, \quad w = \frac{2t}{t^{2} + 1}
```

令 (3.58) 后即得

```latex
x = \cos\varphi, \quad y = \sin\varphi \tag{3.59}
```

于是形如

```latex
\int R(\cos\varphi, \sin\varphi)\,\mathrm{d}\varphi
```

的积分总能化为参数 $t$ 的有理函数积分，这正是替换 (3.58) 被称为万能替换的原因：它是圆这一亏格为零曲线之有理参数化的三角面。

（源文式 (3.59) 将第二分量写作 $y$，见 [[383节式359的y与w记号疑似讹误]]。）
