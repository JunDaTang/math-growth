# 含指数函数的积分（e^{αx} 族）

## 概述

表 0.9.5 的 0.9.5.4 节以 416–433 号共 18 个条目处理含 e^{αx} 的积分：416–427 为纯指数与指数—有理复合型，428–433 为指数与三角函数的乘积型。本族中最特殊的两条是 420（引出 [[积分指数函数Ei]]）与 427/456（回指 420）。

## 基本型（416–421）

```latex
416. ∫ e^{αx} dx = (1/α) e^{αx}.
417. ∫ x e^{αx} dx = (e^{αx}/α²)(αx − 1).
418. ∫ x² e^{αx} dx = e^{αx} (x²/α − 2x/α² + 2/α³).
419. ∫ x^n e^{αx} dx = (1/α) x^n e^{αx} − (n/α) ∫ x^{n−1} e^{αx} dx.
421. ∫ e^{αx}/x^n dx = (1/(n−1)) ( −e^{αx}/x^{n−1} + α ∫ e^{αx}/x^{n−1} dx ),  n ∈ ℕ, n > 1.
```

416–419 是标准的[[分部积分公式|分部积分]]递推族；421 向 n 递减方向归约，直到 420。

## 指数—有理复合型（422–427）

```latex
422. ∫ dx/(1 + e^{αx}) = (1/α) ln( e^{αx}/(1 + e^{αx}) ).
423. ∫ dx/(β + γe^{αx}) = x/β − (1/(αβ)) ln(β + γe^{αx}).
424. ∫ e^{αx} dx/(β + γe^{αx}) = (1/(αγ)) ln(β + γe^{αx}).
425. ∫ dx/(βe^{αx} + γe^{−αx})
   = (1/(α√(βγ))) arctan( e^{αx} √(β/γ) ),  βγ > 0;
   = (1/(2α√(−βγ))) ln( (γ + e^{αx}√(−βγ)) / (γ − e^{αx}√(−βγ)) ),  βγ < 0.
426. ∫ x e^{αx} dx/(1 + αx)² = e^{αx}/(α²(1 + αx)).
427. ∫ e^{αx} ln x dx = (e^{αx} ln x)/α − (1/α) ∫ e^{αx}/x dx   （参看 420）.
```

425 的两个分支由 βγ 的符号决定，分别落到 arctan 与 ln 形式；426 说明含 (1+αx)² 的条目可化为初等函数。

## 指数 × 三角（428–433）

```latex
428. ∫ e^{αx} sin βx dx = e^{αx}(α sin βx − β cos βx)/(α² + β²).
429. ∫ e^{αx} cos βx dx = e^{αx}(α cos βx + β sin βx)/(α² + β²).
430. ∫ e^{αx} sin^n x dx = e^{αx} sin^{n−1}x (α sin x − n cos x)/(α² + n²)
     + n(n−1)/(α² + n²) ∫ e^{αx} sin^{n−2}x dx.
431. ∫ e^{αx} cos^n x dx = e^{αx} cos^{n−1}x (α cos x + n sin x)/(α² + n²)
     + n(n−1)/(α² + n²) ∫ e^{αx} cos^{n−2}x dx.
432/433. ∫ x e^{αx} sin βx dx、∫ x e^{αx} cos βx dx 由 428/429 乘 x 并补一项低阶修正得到。
```

430、431 是幂型递推与指数型的结合，其递推方向回指 416、428、429。

## 与 Ei 的联系

420 号把 ∫ e^{αx}/x dx 展开为级数，并由此定义[[积分指数函数Ei]]：

```latex
∫_{−∞}^{x} e^t/t dt = C + ln x + x/(1·1!) + x²/(2·2!) + … + x^n/(n·n!) + …
```

其中 C 为[[欧拉常数]]。427 与 456 都把 ∫ e^{αx} ln x dx 归结到 420，说明 Ei 是本族中不可回避的非初等对象。
