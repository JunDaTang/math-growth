# 经典迭代法（A = -L + D - U 分解）

## 定位

《数学指南——实用数学手册》7.2.2.1 节以**经典迭代法**为题，把雅可比方法、高斯-赛德尔方法及其松弛推广（JOR、SOR）统一在同一套矩阵分解框架下。它与 7.2.2.2 节的[[concepts/共轭梯度法]]并列，构成本节给出的两条迭代求解路线。

经典迭代法适于求解系数矩阵 $A$ 稀疏的大型方程组 $Ax + b = 0$，其迭代过程统一写成[[concepts/不动点形式]] $x = Tx + c$。

## 统一的矩阵分解

源文将矩阵 $A$ 分解为和 $A = -L + D - U$：

- $L$：**严格下三角矩阵**，元素为 $-a_{ij}\ (i>j)$；
- $U$：**严格上三角矩阵**，元素为 $-a_{ij}\ (i<j)$；
- $D := \operatorname{diag}(a_{11}, a_{22}, \dots, a_{nn})$，且对角线元素 $a_{kk}$ 非零。

结构（逐字保留源文矩阵形式）：

```
L := (  0      0      0    ...   0   )
     ( -a_21   0      0    ...   0   )
     ( -a_31  -a_32   0    ...   0   )
     (  ...    ...   ...          ... )
     ( -a_n1  -a_n2  -a_n3  ...   0   )

U := (  0    -a_12  -a_13  ...  -a_1n )
     (  0      0    -a_23  ...  -a_2n )
     (  0      0      0    ...  -a_3n )
     ( ...    ...    ...          ...  )
     (  0      0      0    ...    0    )

D := diag(a_11, a_22, ..., a_nn)
```

注意源文把 $A$ 写成 $A = -L + D - U$，因此 $L$ 与 $U$ 中存放的是 $A$ 的非对角元素的**相反数**。

## 四个方法在框架中的位置

| 方法 | 迭代格式 | 迭代矩阵 | 性质 |
|------|----------|----------|------|
| [[concepts/雅可比方法]]（组合步方法） | $Dx^{(k+1)} = (L+U)x^{(k)} - b$ | $T_{\mathrm{J}} = D^{-1}(L+U)$ | 收敛充分条件：$A$ 对角占优 |
| [[concepts/高斯-赛德尔方法]]（单步方法） | $(D-L)x^{(k+1)} = Ux^{(k)} - b$ | $T_E = (D-L)^{-1}U$ | 收敛充分条件：$A$ 对角占优或对称正定 |
| [[concepts/JOR方法]]（组合步 + 松弛因子） | $x^{(k+1)} = x^{(k)} + \omega[\cdots]$ | $T_{\mathrm{JOR}}(\omega) = (1-\omega)E + \omega D^{-1}(L+U)$ | $\omega$ 调节性能 |
| [[concepts/SOR逐次超松弛方法]]（单步 + 松弛因子） | 见方法页 | $T_{\mathrm{SOR}}(\omega) = (D-\omega L)^{-1}[(1-\omega)D + \omega U]$ | $\omega$ 调节性能 |

JOR 是雅可比方法的松弛推广，SOR 是高斯-赛德尔方法的松弛推广；两者均由对单个分量乘以[[concepts/松弛因子与最优松弛因子|松弛因子]] $\omega \neq 1$ 得到，$\omega > 1$ 称为超松弛，$\omega \leqslant 1$ 称为低松弛。

## 收敛性

所有四个方法最终都归结为[[concepts/谱半径收敛判据]]：$\rho(T) < 1$ 当且仅当迭代序列收敛。源文对各方法给出的对角占优／对称正定条件只是使得该判据成立的充分条件。
