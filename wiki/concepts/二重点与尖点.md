# 二重点与尖点

**二重点**与**尖点**是《数学指南》3.8.5 节 [[克莱布施公式]] 中出现的两类基本奇点类型，分别以 $d$ 与 $c$ 计数。

## 在克莱布施公式中的位置

若不可约 $n$ 次曲线只有二重点和尖点作为奇点，则

$$
p = \frac{(n-1)(n-2)}{2} - c - d, \tag{3.67}
$$

其中

- $d$ = 二重点的个数；
- $c$ = 尖点的个数。

二者均使亏格相对无奇点情形下降 1。

## 三次曲线情形

对不可约三次曲线，$p = 1 - c - d \geqslant 0$，故：

- $d = 1, c = 0$：恰一个二重点 ⟹ $p = 0$（有理）；
- $d = 0, c = 1$：恰一个尖点 ⟹ $p = 0$（有理）。

## 二重点可位于无穷远

源文例 5 指出：**阿涅西箕舌线**是有一个二重点的三次曲线，它位于**无穷远处**，对应于在图 3.79 中画出的那条实渐近线；因此 $d = 1$、$c = 0$、$p = 0$。这说明奇点计数须在射影（含无穷远点）意义下进行。
