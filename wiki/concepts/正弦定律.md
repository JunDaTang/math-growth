# 正弦定律

正弦定律是《数学指南——实用数学手册》3.2.1 节列出的三角形四个基本定律之一，编号 (3.3)，原文形式为两条边之比与对应角的正弦之比相等：

$$
\frac{a}{b} = \frac{\sin\alpha}{\sin\beta}.\tag{3.3}
$$

其中 a, b 为三角形的两条边，α, β 为它们的对角（记号约定见 [[concepts/平面三角学]]）。

## 在源中的用法

- 第一个基本问题（已知边 c 及其两个相邻角 α, β）用正弦定律求另外两边：$a = c\frac{\sin\alpha}{\sin\gamma}$，$b = c\frac{\sin\beta}{\sin\gamma}$。
- 第二个基本问题由 $c = \frac{\sin\gamma}{\sin\alpha}a$ 定出第三边；第四个问题（SSA）由 $\sin\beta = \frac{b}{a}\sin\alpha$ 定角 β，再由 $c = \frac{\sin\gamma}{\sin\alpha}a$ 定边 c。
- 在直角三角形中，因 $\sin\beta = \cos\alpha$，正弦定律退化为 $\tan\alpha = \frac{a}{b}$（见 [[concepts/毕达哥拉斯定理]] 相关段落）。
- 外接圆半径公式 $R = \frac{a}{2\sin\alpha}$ 与该定律同源（见 [[concepts/三角形的外接圆与内切圆]]）。

## 注意

本节只给出比值形式 $\frac{a}{b} = \frac{\sin\alpha}{\sin\beta}$；教科书中常见的连比形式 $\frac{a}{\sin\alpha} = \frac{b}{\sin\beta} = \frac{c}{\sin\gamma} = 2R$ 并非本节原文陈述，属由本节公式与 $R = \frac{a}{2\sin\alpha}$ 组合而成的推论。
