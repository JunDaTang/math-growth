# 本征值问题（特征值问题）

本节 1.12.1.5 末给出如下的边值问题：

```latex
\begin{array}{l}
-x''(t) = \lambda x(t), \\
x(0) = x(l) = 0 \quad (\text{边界条件}),
\end{array}
```

称其为本征值问题；数 $l>0$ 给定，非平凡解 $x\ne 0$ 称为本征解 $(x,\lambda)$，相应的数 $\lambda$ 称为本征值。

**定理**：所有本征解由
```latex
x(t) = C \sin(n\omega_0 t), \quad \lambda = n^2\omega_0^2, \quad
\omega_0 = \frac{\pi}{l}, \quad n=1,2,\dots
```
给出，$C$ 为任意非零常数。证明利用 (1.213) 在 $x_0=0,\ F\equiv 0$ 时的解 $x(t)=\frac{v}{\omega}\sin\omega t$，并确定频率 $\omega$ 使质点在 $t=l$ 时位于 $x=0$；由 $\sin(\omega l)=0$ 得 $\omega l=n\pi$，即 $\omega=n\frac{\pi}{l}=n\omega_0$。
