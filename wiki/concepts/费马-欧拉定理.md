# 费马-欧拉定理

## 陈述

源文以「**费马（1640）和欧拉（1760）定理**」署名给出：对于正自然数 $a$ 和 $m$，如果它们互素，那么

```
a^φ(m) ≡ 1 mod m,
```

其中 $\varphi(m)$ 表示整数 $1,\cdots,m$ 中与 $m$ 互素的数的个数，即 [[欧拉φ函数]]（源文注明「参看 2.7.2」）。

该定理亦称欧拉定理；本节中文标题中的「费马-欧拉定理」即指此式。

## 素数特例

源文例 2：对于不整除 $a$ 的素数 $p$ 有

```
a^(p−1) ≡ 1 mod p,
```

源文注明「定理的这种形式最初是费马提出的」，即通常所称的 [[费马小定理]]。

## 在编码理论中的应用

[[RSA公钥密码体制]] 的译码证明直接依赖于该定理：

```
n^φ(m) ≡ 1 mod m,
```

配合逆元方程 $ts = 1 + k\varphi(m)$，即得 $r^t \equiv n^{st} \equiv n^{1+k\varphi(m)} \equiv n \bmod m$。源文称此定理在 200 多年前仅被视为纯粹数学结果，1977 年后成为公钥密码的基础。
