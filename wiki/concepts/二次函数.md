# 二次函数

二次函数是形如 \(y = ax^{2}\)（\(a \neq 0\)）或 \(y = ax^{2} + 2bx + c\) 的实值函数，其图像是一条抛物线。按《数学指南——实用数学手册》0.2.3 节，二次函数是继 [[线性函数]] 之后最简单的多项式函数类型。

## 两种书写形式

来源区分了两种写法。

最简形式（式 0.30）：

```latex
y = a x^{2}
```

一般形式（式 0.31）：

```latex
y = a x^{2} + 2 b x + c
```

注意一般形式的一次项系数被写成 \(2b\) 而非通常的 \(B\)。这一写法使配方后的表达式与判别式定义保持形式简洁（见 [[二次配方与顶点形式]]、[[二次判别式]]），但也造成与通行教材的记法差异。

## 图像

二次函数的图像是一条抛物线。以最简形式 \(y = ax^{2}\) 为例，其顶点在原点 \((0,0)\)，开口方向由 \(a\) 的符号决定：\(a > 0\) 开口向上，\(a < 0\) 开口向下。一般形式的图像可由最简形式的图像平移得到，见 [[二次函数的抛物线图像]] 与 [[一般二次函数图像由最简抛物线平移得到]]。

在圆锥曲线分类中，抛物线也可由“到焦点与准线距离相等”的几何条件定义，见 [[圆锥曲线]] 与 [[抛物线的标准方程]]。本节的讨论属于“函数图像”视角，与“圆锥曲线”视角互补但不等同。

## 零点与方程

二次函数的零点由二次方程 \(ax^{2} + 2bx + c = 0\) 给出，其解由 [[二次方程求根公式]] 给出，零点个数由 [[二次判别式]] 决定；当判别式为负时出现 [[二次方程的复零点]]。

## 来源边界

来源仅给出上述定义、配方、求根公式与三种判别式情形，未讨论二次函数的导数、极值、韦达定理、二次不等式或圆锥曲线的焦点准线性质。
