# 似然函数 L

## 定义

在《数学指南——实用数学手册》6.3.5 节的脚注 1) 中，似然函数定义为样本的联合概率密度（或概率）之积：

```latex
L = \varphi(x_1, \beta)\,\varphi(x_2, \beta) \cdots \varphi(x_n, \beta).
```

它是「观测值 $x_1, \cdots, x_n$ 在参数 $\beta$ 下出现的可能性」的度量，作为参数 $\beta$ 的函数看待。

## 与最大似然方程组的关系

[[最大似然法]]要求似然函数取极大值：

```latex
L \stackrel{!}{=} \max,
```

由此导出极值条件

```latex
\frac{\partial L}{\partial \beta_r} = 0, \quad r = 1, \dots, k.
```

因为 $L$ 是乘积形式，将上述方程**除以 $L$** 后，每一项化为 $\frac{1}{\varphi}\frac{\partial \varphi}{\partial \beta_r}$ 的形式，即得到[[最大似然方程组]]中的 (6.37)。这正是「取对数再求导」之外、原书采用的等价写法。
