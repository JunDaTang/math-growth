# 中值定理（介值定理）

注意：此处的「中值定理」是**介值定理**（intermediate value theorem），与微分学中值定理（mean value theorem）不同名同事。

## 单变量形式（1.3.1.2）

如果函数 $f: [a, b] \to \mathbb{R}$ 连续，那么对所有满足

```
min_{a ⩽ x ⩽ b} f(x)  ⩽  γ  ⩽  max_{a ⩽ x ⩽ b} f(x)
```

的 $\gamma$，方程

```
f(x) = γ,   x ∈ [a, b]
```

有一个解。

## 推广形式（1.3.3.2）

如果 $f: M \to \mathbb{R}$ 连续，且 $M$ 是**弧连通集**，那么象 $f(M)$ 是一个区间。

在 $M$ 中有两个点 $a, b$ 使 $f(a) < f(b)$ 的特殊情形下，方程

```
f(x) = γ,   x ∈ M
```

对每个满足 $f(a) \leqslant \gamma \leqslant f(b)$ 的实数 $\gamma$ 都有一个解。
