# 余项多项式

在多项式带余除法

```
N(x) = D(x)Q(x) + R(x),    (2.19)
```

中，$R(x)$ 称为**余项多项式**，其次数严格小于分母 $D(x)$ 的次数。

## 相关术语（来源 2.1.5 节）

- $N(x)$：**分子**（被除式）
- $D(x)$：分母（除式），要求 $\deg D \ge 1$
- $Q(x)$：两个多项式的**商**
- $R(x)$：**余项多项式**

替代写法 (2.20) 把除法结果拆成整部与真分式之和：

```
N(x)/D(x) = Q(x) + R(x)/D(x).    (2.20)
```

## 算例中的取值

- 例 2（无余项）：$N(x) = x^2 - 1$，$D(x) = x - 1$，$Q(x) = x + 1$，$R(x) = 0$。
- 例 3（带余项）：$R(x) = -2x - 5$，其次数（1）严格小于 $D(x) = x^2 - 2x + 3$ 的次数（2）。

## 与其他概念的关系

余项为零是整除（$D$ 整除 $N$）的判别；而在欧几里得算法中，末项非零余项给出最大公因子，见 [[concepts/欧几里得算法-多项式]] 与 [[concepts/最大公因子-多项式]]。
