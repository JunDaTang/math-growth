# 伯努利模型中的频率与频数

## 频率 $H_n$

在 [[伯努利模型]] 的基本事件空间 $E$ 上，由

```
H_n(e_{i_1} ... e_{i_n}) = (1/n) · (e ... 的等于 1 的脚标个数)
```

定义函数 $H_n : E \to \mathbb{R}$。$H_n$ 是事件 $e_1$ 在试验序列中发生的频率（如抛硬币中「正面向上」发生的频率）。原文称「我们的任务是研究随机变量 $H_n$」。

## 频数 $A_n$

函数

```
A_n := n H_n
```

刻画事件 $e_1$ 在试验序列中出现的次数（如一系列抛硬币中得到「正面向上」的总次数）。

## 两者的理论性质（定理 1 与定理 2）

| 量 | 分布 | 期望 | 标准差 |
|----|------|------|--------|
| 频率 $H_n$ | $P(H_n = k/n) = \binom{n}{k} p^k (1-p)^{n-k}$ | $\overline{H}_n = p$ | $\Delta H_n = \sqrt{p(1-p)}/\sqrt{n}$ |
| 频数 $A_n$ | $P(A_n = k) = \binom{n}{k} p^k (1-p)^{n-k}$ | $\overline{A}_n = np$ | $\Delta A_n = \sqrt{np(1-p)}$ |

对频率还有切比雪夫型估计（定理 1(iv)）：

```
P(|H_n − p| ≤ ε) ≥ 1 − p(1−p)/(n ε²),   ε > 0 必须充分小。
```

原文由此指出：当 $n$ 增大时，频率与期望值的差越来越小；该期望值正是 $e_1$ 在比较试验中发生的概率 $p$。

## 与示性函数的关系（定理 3）

```
H_n = (1/n)(X_1 + ... + X_n),    A_n = X_1 + ... + X_n,
```

其中 $X_j$ 为 [[示性函数]]，且 $X_1, \ldots, X_n$ 相互独立、$\overline{X}_j = p$、$\Delta X_j = \sqrt{p(1-p)}$。

## 与既有条目 [[频率]] 的关系

6.1 节的 [[频率]] 概念（频率的稳定性、作为概率的直观来源）在本节被赋予了精确的随机变量身份：$H_n$ 是概率空间 $E$ 上的函数，具有已知的分布、期望与标准差。本节因此可视为对「频率」概念的测度论化与定量化。

## 三种极限行为

- $H_n \to p$：[[伯努利大数定律]] (6.19) 依概率收敛；[[无穷重伯努利试验]] 中几乎必然收敛。
- $A_n$ 的标准化趋于 $N(0,1)$：[[棣莫弗-拉普拉斯全面极限定理]]。
- 区间概率的实用算式：$P(p + a\Delta H_n \leqslant H_n \leqslant p + b\Delta H_n) = \Phi_0(b) - \Phi_0(a)$。
