# 加速度向量

由定义，二阶导数

```
r″(t) := lim_{Δt→0} [r′(t + Δt) − r′(t)] / Δt
```

为在时刻 t 粒子的**加速度向量**，并且 |r″(t)| 是在时刻 t 的**加速度**（即加速度的大小）。

加速度向量是 [[concepts/速度向量]] 这一向量值函数的导数，因此它的定义同样建立在 [[concepts/向量序列的极限]] 之上，只是被求导的对象从位置函数 r(t) 换成了速度函数 r′(t)。

在经典力学中，加速度向量是 [[concepts/牛顿基本运动定律]] 的核心量：

```
m r″(t) = F(r(t), t)                                    (1.160)
```

在 [[concepts/笛卡儿坐标系]] 下，r″ 的分量就是位置分量函数的二阶导数 x″(t), y″(t), z″(t)，见 [[concepts/向量函数的坐标表示]]。
