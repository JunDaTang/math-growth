# 勒让德符号

## 定义

源文 2.7.8.2 节先提出两个同余方程的可解性问题：

```
x^2 ≡ q mod p        (2.96)
x^2 ≡ p mod q        (2.97)
```

并令勒让德符号为

```
( q / p ) := 1,   如 (2.96) 有解;
( q / p ) := −1,  如 (2.96) 无解.
```

即 $(q/p)$ 取 $\pm 1$，指示 $x^2 \equiv q \bmod p$ 是否有解。

## 补充公式

源文同时给出两个取值公式：

```
( −1 / p ) = (−1)^((p−1)/2),   ( 2 / p ) = (−1)^((p^2−1)/8).
```

## 应用示例

源文例：设 $p = 4n + 1$ 是素数（$n$ 为正自然数），则方程

```
x^2 ≡ −1 mod p
```

有解，理由即 $\left(\frac{-1}{p}\right)=1$。这由补充公式 $\left(\frac{-1}{p}\right)=(-1)^{(p-1)/2}$ 在 $p \equiv 1 \pmod 4$ 时取 $+1$ 直接得到。
