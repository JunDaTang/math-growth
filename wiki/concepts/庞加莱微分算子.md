# 庞加莱微分算子

## 定义（源文逐字保留）

```latex
\partial z := \frac{1}{2}\left(\frac{\partial}{\partial x} - \mathrm{i}\frac{\partial}{\partial y}\right)
\quad \text{和} \quad
\partial \bar z := \frac{1}{2}\left(\frac{\partial}{\partial x} + \mathrm{i}\frac{\partial}{\partial y}\right)
```

源文将这两个算子称为「庞加莱微分算子 $\partial z$ 和 $\partial \bar z$」。

## 作用：把柯西-黎曼方程写成优美形式

在这两个算子下，[[柯西-黎曼微分方程]] (1.453) 可以写成

```latex
\partial \bar z\, f(z_0) = 0.
```

## 作用：一阶微分形式分解

令 $z = x + \mathrm{i}y$，$\bar z = x - \mathrm{i}y$ 及

```latex
\mathrm{d}z := \mathrm{d}x + \mathrm{i}\,\mathrm{d}y, \quad \mathrm{d}\bar z := \mathrm{d}x - \mathrm{i}\,\mathrm{d}y.
```

把 $f(z)$ 记为 $f(x,y)$，则 $\mathrm{d}f = u_x\,\mathrm{d}x + u_y\,\mathrm{d}y + \mathrm{i}(v_x\,\mathrm{d}x + v_y\,\mathrm{d}y)$，由此即得

```latex
\mathrm{d}f = \partial z f\; \mathrm{d}z + \partial \bar z f\; \mathrm{d}\bar z.
```

若 $f$ 在点 $z_0$ 处[[复可微与复导数|复可微]]，则分解式中 $\partial \bar z f$ 项消失，得到

```latex
\mathrm{d}f = \partial z f\; \mathrm{d}z.
```

源文未逐步展开上述代数推导，但各步都可由定义直接验证。

## 命名问题

源文所使用的名称「庞加莱微分算子」为其自身命名；这类算子在现代文献中通常与 Wirtinger 导数相关联。命名归属有待核实，见 [[庞加莱微分算子命名是否为Wirtinger导数]]。
