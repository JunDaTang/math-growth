# 线性方程组——直接法

## 界定

求解非齐次线性方程组

$$
Ax + b = 0, \quad \text{即} \quad \sum_{k=1}^{n} a_{ik}x_k + b_k = 0,\ i = 1,2,\dots,n,
$$

其中 $A$ 为 $n \times n$ 正则矩阵（$\det A \neq 0$）时，对每个常向量 $b$ 存在唯一解向量 $x$。《数学指南——实用数学手册》7.2.1 节处理的是**数值计算 $x$ 的直接消元法**：经有限步消元或分解给出（在舍入意义下的）解，与之相对的是 [[线性方程组迭代法]]（见 [[线性代数]]）。

## 共同的「三步」结构

节内三种分解型算法（高斯、楚列斯基等）具有统一形式：

1. 分解：$PA = LR$ 或 $A = LL^{\mathrm{T}}$；
2. 向前代换：$Lc - Pb = 0$（或 $Lc - b = 0$）求出 $c$；
3. 逆代换：$Rx + c = 0$（或 $L^{\mathrm{T}}x + c = 0$）求出 $x$。

对同一矩阵 $A$ 与不同右端 $b$ 求解时，分解只需进行一次，这是该结构的核心价值。

## 稳定性与误差

- 为保证稳定性须作**主元选取**：[[主元选取策略]]（最大排队策略、相对排队策略）；不选主元的对角线策略仅在 [[对角占优]] 时可靠。
- 输入数据与舍入误差使算法实际只能近似求解；误差放大由 [[线性方程组的条件数]] 控制，剩余（残差）大小一般不表示解的精度。
