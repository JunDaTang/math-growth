# 全纯变换原理

## 陈述

令在开集 $U$ 上给定一个全纯函数

```latex
f: U \subseteq \mathbb{C} \to \mathbb{C}.
```

此外，令 $b: U \to V$ 为[[双全纯映射]]。则可以自然地把 $f$ 变换到集合 $V$。对这个变换后得到的函数 $f_{*}$，有

(i) $f_{*}: V \subseteq C \to C$ 是全纯的。

(ii) 积分不变，即，对 $U$ 中所有 $C^{1}$ 曲线 $C$ 和 $C_{*} := b(C)$，都有

```latex
\int_{C} f(z)\,\mathrm{d} z = \int_{C^{*}} f_{*}(w)\,\mathrm{d} w,
```

来源：[[sources/10-数学指南实用数学手册--18-11410-双全纯映射和黎曼映射定理--1q6wyov|《数学指南》1.14.10]]。

## 变换的显式形式（原文脚注 1）

原文脚注 1) 给出：显然有

```latex
f_{*} := f \circ b^{-1}, \quad \text{即} \quad f_{*}(w) = f(b^{-1}(w)).
```

## 意义

- (i) 说明双全纯映射把全纯函数变换成全纯函数，这是[[双全纯映射]]「保持全纯性」的精确形式。
- (ii) 说明[[复积分]]在双全纯坐标变换下不变，因而积分是与局部坐标选择无关的构造。
- 二者合起来使[[复流形]]的引入成为可能：全纯函数与积分的概念可以在只有局部坐标、坐标变换为双全纯函数的对象上以不变方式定义（原文「注」的 (iv) 条）。

## 原文疑点

- 变换原理用 (i)(ii) 编号，随后「注」中的复流形构造又用 (i)–(v) 重新编号，见 [[queries/11410节复流形编号i-v与全纯变换原理i-ii编号冲突]]。
- 断言 (i) 中的「$V \subseteq C \to C$」其 $C$ 应为黑板体 $\mathbb{C}$（$\mathbb{C}$ 与曲线名 $C$ 同形混用），见 [[queries/11410节全纯变换原理中C应为黑板体C]]。
