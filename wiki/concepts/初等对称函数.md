# 初等对称函数

## 定义

函数

```
e₁ := x₁ + … + xₙ
e₂ := Σ_{j<k} x_j x_k = x₁x₂ + x₂x₃ + … + x_{n−1}x_n
e₃ := Σ_{j<k<m} x_j x_k x_m = x₁x₂x₃ + … + x_{n−2}x_{n−1}x_n
……
eₙ := x₁x₂…x_n
```

称为变量 $x_{1},\cdots,x_{n}$ 的初等对称函数。

## 性质与用途

- 每个 $e_{k}$ 都是对称的，即在变量的任意置换下不变。
- 通过 [[concepts/韦达定理]] 的一般形式，多项式 $p(x):=a_{0}+a_{1}x+\cdots+a_{n-1}x^{n-1}+x^{n}$ 的系数由零点的初等对称函数表出：
  $$a_{n-1}=-e_{1},\quad a_{n-2}=e_{2},\quad\dots,\quad a_{0}=(-1)^{n}e_{n}.$$
- 初等对称函数是 [[concepts/对称多项式主定理]] 中生成所有对称多项式的"基本构件"。
- [[concepts/判别式-代数方程]] $\varDelta=\prod_{j<k}(x_{j}-x_{k})^{2}$ 是对称多项式，因此也可用 $e_{1},\cdots,e_{n}$ 表出（如 $n=2$ 时 $\varDelta=e_{1}^{2}-4e_{2}$）。
