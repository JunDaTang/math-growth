# 广义积分的主值

## 在这一节中的角色

0.9.5 的第 3 部分在 420 与 438 两处把「主值」作为定义手段：两个被积函数 e^t/t 与 1/ln t 在内点处发散，源文以「取广义积分的主值」的方式赋予它们确定的值。

```latex
420：当 x > 0 时，该积分在 t = 0 处发散，此时 Ei(x) 是这个广义积分的主值
     （参看 0.5.5 和 0.7.2）。
438：当 x > 1 时，它在点 t = 1 处发散。此时，函数 li(x) 的值是这个广义积分的主值
     （参看 0.5.5 和 0.7.2）。
```

## 要点

- 主值（Cauchy principal value）指在极点两侧对称截断后取极限；它是把发散广义积分「正则化」为有限值的标准方式。
- 本表用主值把两个原本发散的对象 [[积分指数函数Ei]] 与 [[对数积分li]] 纳入[[原函数]]家族的语境：它们不是初等函数，但仍是良定义的函数。
- 源文两处都注明「参看 0.5.5 和 0.7.2」，说明主值的严格定义与级数表示分别属于手册 0.5.5（特殊函数）与 0.7.2（幂级数）两节，本 wiki 尚未入库这两处的相应正文。
