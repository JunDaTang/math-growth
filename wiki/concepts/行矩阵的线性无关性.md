# 行矩阵的线性无关性

源在 2.1.4.5 中的定义：设给定 $m$ 个行矩阵 $A_1,\cdots,A_m$（脚注 1)），它们的长度为 $n$，并有实元素。如果方程

$$
\alpha_1 A_1 + \dots + \alpha_m A_m = \mathbf{0} \quad (\alpha_i \text{ 为实数})
$$

仅当

$$
\alpha_1 = \alpha_2 = \cdots = \alpha_m = 0
$$

时才成立，则称 $A_1,\cdots,A_m$ **线性无关**；否则称它们**线性相关**。类似的定义对列矩阵（即 $n\times1$ 矩阵）也成立。

## 例 1（源中示例）

```
(i)  线性无关性。对于 A₁ := (1,0) 和 A₂ := (0,1)，α₁A₁ + α₂A₂ = 0 推出 (α₁,α₂) = (0,0)，
     因此 α₁ = α₂ = 0。这意味着 A₁ 和 A₂ 线性无关。
(ii) 线性相关性。对于 A₁ := (1,1) 和 A₂ := (2,2)，有 2A₁ − A₂ = (2,2) − (2,2) = 0，
     亦即 A₁ 和 A₂ 线性相关。
```

## 复系数的推广

在「复方程组」段落中，源指出：若线性方程组的系数为复数，则此前所有论述仍然成立，但线性无关性定义中的 $\alpha_1,\cdots,\alpha_k$ 也**必须是复数**。

## 用途

线性无关的行/列的最大个数定义了 [[concepts/矩阵的秩]]；行矩阵之间的线性相关关系（如例 2 中第二行等于第一行的两倍）直接决定了方程组的可解性与自由度数。
