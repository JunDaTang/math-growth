# 线性无关性

2.3.2 节定义：K 上的线性空间中的元素 $u_1,\dots,u_n$ 称为线性无关的，当且仅当关系式

```text
α₁u₁ + … + αₙuₙ = 0,   α₁, …, αₙ ∈ K
```

总蕴涵 $\alpha_1 = \dots = \alpha_n = 0$。否则称 $u_1,\dots,u_n$ 线性相关。

线性无关性直接决定 [[线性空间的维数]]（线性无关元素的最大个数）与 [[基-线性空间]]（每个元素可唯一线性表示的一组元素）。[[施泰尼茨基交换定理]] 刻画了基与线性无关元素之间的关系。
