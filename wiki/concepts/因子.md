# 因子

## 定义

在《数学指南——实用数学手册》6.3.6 节中，**因子**（Factor）被定义为多元分析中**最重要的影响量**。源文表述为：「在多元分析中，最重要的影响量也称为因子。」

因子是本节五个子方法中的核心区分变量：

- 在 [[方差分析]] 中，因子是**已知的**（例：各类肥料 $F_1, \cdots, F_n$ 是已知因子）。
- 在 [[因子分析]] 中，因子是**事先不知道的**，需要从 $k$ 个性质 $M_1, \cdots, M_k$ 的测量值中反推 $n$ 个因子 $F_1, \cdots, F_n$ 是否有本质影响。

## 记号

源文档以箱式标记给出因子集合：

```
F_1, …, F_n
```

在因子分析例中，与之相对的是性质集合

```
M_1, …, M_k
```

## 因子的可解释性限制

源文档明确指出：因子分析这种统计方法「本身对于可能很重要的因子类型并不作任何表述」。也就是说，**统计计算给出的是因子结构，而不是因子的物理/业务含义**；甄别因子的重要性是**研究者自己的工作**，需要一定的经验和技巧。因子的含义解释不能由方法自动完成。

一旦重要因子被确定，统计方法可提供额外帮助，即 [[因子权]]。
