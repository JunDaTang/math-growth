# 析取

**析取命题**（或命题）是把两个命题 A、B 以「或」连结所得的复合命题「A 或 B」。其真值语义为：若两个命题 A 或 B 之一为真，则复合命题为真；若 A 和 B 都是假的，则「A 或 B」为假。

## 源中例证

- **例 1**：命题「2 整除 4 或 3 整除 5」是真的，因为该命题的第一部分是真的。
- **例 1（续）**：命题「2 整除 5 或 3 整除 7」是假的，因为该命题的两部分都是假的。

## 与其他概念的关系

- 与[[严格析取]]对照：严格析取要求两者中恰有一个为真，析取只要求至少一个为真。
- [[德摩根律]] (v) 给出了析取的否定：「非 (A 或 B) ⇔ (非 A 且非 B)」。
- 重言式 (i) 包含析取与合取的分配律：「A 或 (B 且 C) ⇔ (A 或 B) 且 (A 或 C)」，并称其是集合论（4.3.2）中并、交分配律的根据。
