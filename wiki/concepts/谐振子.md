# 谐振子

在《数学指南——实用数学手册》中，谐振子出现在多个不同的位置，承担着不同的角色：

- **1.9.1 节**（速度与加速度）：谐振子是作为 [[牛顿基本运动定律]] 的**第一个示例**出现的，给出无外力项的齐次方程。
- **1.12.1.5 节**（引导性的例子）：谐振子是作为弹簧力加上外力驱动的一般模型出现的，给出带外力项的方程、初值条件及其解的积分表示。
- **5.1.4 节**（应用）：谐振子被从势能的泰勒展开出发建模，并进一步用于相空间描述与量子化。该处把谐振子称为「力学系统中最简单的非平凡的数学模型」，并强调从这个简单模型可以洞察深邃的物理含义：**谐振子的量子化导致爱因斯坦的光子理论，从而推出辐射的普朗克定律**。

各来源使用的是同一物理模型（质量 $m$、弹簧、恢复力正比于位移），但**方程形式、记号与讨论的问题不同**，下面按来源分别列出。

## 来源一：1.9.1 节中作为牛顿运动定律的示例

### 设定

质量为 m 的弹簧沿一条直线放置，其终点的运动由

```
r(t) = x(t) i
```

给出；作用在它上的力是

```
F := −k x i
```

这里 k > 0 是描述弹簧物理性质的一个常量（参见原文图 1.96，其中标出了中性点、位移 x 与方向 i）。

### 运动方程

代入牛顿运动定律得

```
m x″(t) i = −k x i
```

令 ω² = k/m，得到谐振子的微分方程

```
x″ + ω² x = 0
```

该方程为**齐次方程，不含外力项**；此处 1.9.1 节用记号 F 表示弹簧力本身。

### 后续求解指引

原文明确指明：这个微分方程将在 **1.11.1.2** 节求解。该节目前尚未入库，见 [[191节引用1112节与141节尚未入库]]。

### 与非谐振子的关系

谐振子是更一般的 [[非谐振子]] 在参数 l = 0 时的特例；非谐振子的力定律为 F(x) = −k x i − l x³ i。

相关结果：[[谐振子微分方程x二阶加omega平方x等于零]]。

## 来源二：1.12.1.5 节中的受外力驱动模型

### 设定

质量为 $m$ 的质点在一个弹簧（形成正比于离 $x=0$ 处距离的力 $\mathbf F_0 := -kx\mathbf i$）与附加外力 $\mathbf F_1 := \mathcal F(t)\mathbf i$ 下沿 $x$ 轴运动。注意此处 1.12.1 节用 $\mathbf F_0$ 表示弹簧力（对应 1.9.1 节中的 F），用 $\mathbf F_1$ 表示附加外力。

### 微分方程与初值条件

由 [[牛顿]] 的力定律 $mx''=F_0+F_1$ 得

```latex
\begin{array}{c}
x''(t) + \omega^2 x(t) = F(t), \\
x(0) = x_0, \\
x'(0) = v,
\end{array}                                       \tag{1.212}
```

其中 $\omega := \sqrt{k/m}$，$F := \mathcal F/m$，$F:[0,+\infty[\to\mathbb R$ 连续。

### 解与格林函数

唯一解为

```latex
x(t) = x_0 \cos \omega t + \frac{v}{\omega}\sin \omega t + \int_0^t G(t,\tau) F(\tau)\,\mathrm{d}\tau,  \tag{1.213}
```

$G(t,\tau)=\frac{1}{\omega}\sin\omega(t-\tau)$ 为 [[格林函数]]。

### 与其他章节的关系

本模型是 [[特征振荡]]、[[共振]] 与 [[阻尼振动]] 三小节的共同基础。

## 来源三：5.1.4 节中的建模假设、相空间与量子化

### 建模假设

所考虑的一维运动具有三条性质：

- (a) 系统关于平衡态仅有小偏离；
- (b) 在平衡点处没有作用力；
- (c) 势能是正的。

势能作泰勒展开

$$
U(q) = U(0) + U'(0)q + \frac{U''(0)}{2}q^2 + \dots
$$

假设 (b) 隐含 $0 = F(0) = -U'(0)$；由于 $U(0)$ 与力、与运动方程 $mq'' = F$ 均不相关，不失一般性可设 $U(0) = 0$。由此得到谐振子势能

$$
U(q) = \frac{k q^2}{2}, \qquad k := U''(0) > 0 .
$$

### 运动与相空间

令 $\omega = \sqrt{k/m}$，牛顿运动定律给出

$$
q'' + \omega^2 q = 0, \quad q(0) = q_0, \quad q'(0) = q_1,
$$

唯一解为 $q(t) = q_0 \cos\omega t + (q_1/\omega)\sin\omega t$。

哈密顿函数为

$$
H(q, p) = \frac{p^2}{2m} + \frac{kq^2}{2},
$$

典范方程给出 $p' = -kq$、$q' = p/m$，其轨线为相空间中的椭圆，大小随能量增加而增大。

### 量子化

- [[玻尔-索末菲量子化]]：两椭圆之间的相空间面积为 $h$，得 $\Delta E = \hbar\omega$；
- [[海森伯量子化准则]]：能级 $E = \hbar\omega(n + \tfrac{1}{2})$，$n = 0,1,2,\dots$，基态能量非零。
