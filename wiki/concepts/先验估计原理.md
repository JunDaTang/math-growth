# 先验估计原理

**先验估计原理**是《数学指南——实用数学手册》1.12.9.8 节的结论，表述为一句「数学中一般原理」：先验估计保证解的存在性。

## 陈述（源文）

假设：

- (A5) 如果初值问题 (1.321) 在一个开区间 $]t_0-T,t_0+T[$ 上有解存在，那么有式 (1.322)：

```text
|x(t)| ≤ C,
```

其中常数 $C$ 可能依赖于 $T$。

定理：在假设 (A1) 和 (A5) 之下，初值问题 (1.321) 有唯一一个对所有时刻 $t$ 都存在的解。

注：称像 (1.322) 那样的估计为**先验估计**；上述定理是「先验估计保证了解的存在性」这一数学中一般原理（原书脚注 1)）的一个特殊情形。

## 例（源文）

初值问题 $x'=\sin x$、$x(0)=x_0$ 对每个 $x_0\in\mathbb{R}$ 有唯一一个对所有时刻存在的解。证明思路是：设 $x=x(t)$ 是 $[-T,T]$ 上的一个解，由积分形式

```text
x(t) = x0 + ∫_{-T}^{T} sin x(t) dt
```

与 $|\sin x|\le 1$ 得到先验估计

```text
|x(t)| ≤ |x0| + ∫_{-T}^{T} dt = |x0| + 2T.
```

源文补充：为了得到这样的先验估计，可以利用**微分不等式**。

- 与 1.12.9.7 的 [[concepts/整体解的存在性]]（线性增长假设 A4）形成两条独立的整体存在性判据：一条约束右端的**增长阶**，另一条约束解的**先验界**。
- 与 1.12.9.4 的 [[concepts/格朗沃尔引理]]、1.12.9.5 的 [[concepts/微分不等式]] 互为工具：先验界的获得常依赖这两者。
