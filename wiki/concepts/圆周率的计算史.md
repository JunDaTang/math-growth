# 圆周率的计算史

《数学指南——实用数学手册》2.7.7 节以「圆周长的计算，亦即数 $\pi$ 的计算」为主线，称其「起始于远古时代，并且总是在耗费数学家的才智」。该节按方法类型给出了如下脉络：

| 阶段 | 代表 | 方法/结果 |
|---|---|---|
| 古代近似 | 《旧约·列王纪（上）》7:23 | 以 3 作为 $\pi$ 的近似值 |
| 古代近似 | 古埃及纸草书（约公元前 1650 年起） | $\pi=(16/9)^2=3.16,\dots$ |
| 多边形逼近 | [[阿基米德]]（前 287–前 212） | 正 96 边形给出 $223/71<\pi<22/7$ |
| 最佳逼近 | [[祖冲之]]（430—501） | 分数 $355/113$ 已作为 $\pi$ 的近似值 |
| 高精度估计 | 1766 年日本 | $\frac{5419351}{1725033}<\pi<\frac{428224593349304}{136308121570117}$ |
| 解析公式 | [[韦达]]（1579） | [[queries/韦达乘积公式]]，$\pi$ 的首个解析公式 |
| 解析公式 | [[沃利斯]]（1655） | [[concepts/沃利斯乘积]] (2.89) |
| 幂级数 | [[牛顿]]（1665，22 岁） | $\arcsin x$ 级数取 $x=1/2$，算得 $\pi$ 前 14 位 |
| 幂级数 | [[莱布尼茨]]（1674，28 岁） | [[莱布尼茨级数]] (2.90)，收敛慢 |
| 乘积公式 | [[欧拉]] | [[欧拉乘积公式]] (2.91) |
| 高精度计算 | [[鲁道夫-范柯伦]]（1540—1610） | 首次算到 35 位小数，$\pi$ 故称鲁道夫数 |
| arctan 公式 | [[梅钦]]（18 世纪起） | [[findings/现代π计算公式梅钦拉马努金丘德诺夫斯基与博温迭代]] + $\arctan$ 幂级数 |
| 现代公式 | [[拉马努金]]（1914） | [[findings/现代π计算公式梅钦拉马努金丘德诺夫斯基与博温迭代]]，与模形式理论相关 |
| 现代公式 | [[丘德诺夫斯基兄弟]] | 用类似的修饰公式算到 2260321336 位 |
| 迭代算法 | [[博温兄弟]] | [[博温迭代法]]，15 次迭代达 20 亿位 |

该节还以 [[莱布尼茨级数]] 与 [[arctan的一般连分式]] 的对比说明算法的实际效率差异：算到第 7 位，莱布尼茨级数约需 $10^6$ 项，而 arctan 连分式取 $x=1$ 只需 9 项。这一对比引出节末对「[[科学计算]]」的定点：高效能计算机提出了全新的方法和算法要求。

理论侧的两条结论由本节独立给出：$\pi$ 的无理性（[[兰伯特]] 1766，[[勒让德]] 1806 补全）与 $\pi$ 的超越性（[[林德曼]] 1882，否定化圆为方）。
