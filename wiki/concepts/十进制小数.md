# 十进制小数

1.1.1.3 节说明十进制系统的位值含义：符号 123 是 1·10² + 2·10¹ + 3·10⁰ 的缩写；符号 2.43 表示

```latex
2 \cdot 10^{0} + 4 \cdot 10^{-1} + 3 \cdot 10^{-2}.\tag{1.3}
```

## 无限小数由不等式组唯一确定

像 2.43567… 这样的符号表示（唯一）实数 x，它满足无穷不等式组

```latex
\begin{array}{c}
2.4 \leqslant x < 2.4 + 10^{-1}, \\
2.43 \leqslant x < 2.43 + 10^{-2}, \\
2.435 \leqslant x < 2.435 + 10^{-3}, \\
\dots\dots
\end{array}\tag{1.4}
```

## 一般展开

设所有 a_j 为整数，a_j = 0,1,…,9，且 a_n ≠ 0，n = 0,1,2,…：

(i) 有限符号表示的和

```latex
a_{n} \cdot 10^{n} + a_{n-1} \cdot 10^{n-1} + \dots + a_{0} \cdot 10^{0} + a_{-1} \cdot 10^{-1} + \dots + a_{-m} \cdot 10^{-m};
```

(ii) 无限符号 a_n a_{n−1} … a_0 . a_{−1} a_{−2} … 表示满足下列不等式链的唯一实数 x：

```latex
a_{n} \dots a_{0}.a_{-1}a_{-2} \dots a_{-m} \leqslant x < a_{n} \dots a_{0}.a_{-1}a_{-2} \dots a_{-m} + 10^{-m}, \quad m = 1, 2, \dots
```

每个实数都可以唯一展开成这样的十进制小数。

## 定理

**一个实数是有理数，当且仅当它的十进制小数展开式是有限的或周期的。**

例：1/4 = 0.25 与 1/3 = 0.333333… 是有理数；√2 的展开没有周期。
