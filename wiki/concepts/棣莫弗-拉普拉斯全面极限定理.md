# 棣莫弗-拉普拉斯全面极限定理

## 标准化量

在本节中，与 [[伯努利模型中的频率与频数]] 相关的标准化量定义为

```
𝓗_n := (H_n − H̅_n)/ΔH_n,   有 𝓗̅_n = 0, Δ𝓗_n = 1;
𝓐_n := (A_n − A̅_n)/ΔA_n。
```

$\Phi_n$ 表示 $\mathfrak{H}_n$ 的分布函数；$\Phi$ 表示标准高斯正态分布 $N(0,1)$ 的分布函数。原文指出 $\mathfrak{A}_n$ 等于标准化的频率 $H_n$，因此 $A_n$ 的分布函数也是 $\Phi_n$。

## 陈述（6.2.5.3 节，脚注 2）

对所有 $x \in \mathbb{R}$，

```
lim_{n→∞} Φ_n(x) = Φ(x)。
```

由此对一切区间 $[a,b]$：

```
lim_{n→∞} P(a ≤ 𝓗_n ≤ b) = (1/√(2π)) ∫_a^b e^{−z²/2} dz.        (6.22)
```

## 定量误差界

原文强调「事实上，还有一个非常精确的估计式」：

```
sup_{x∈ℝ} |Φ_n(x) − Φ(x)| ≤ (p² + (1−p)²) / √(np(1−p)),   n = 1, 2, ...。        (6.23)
```

**推论（本节的重点实用注释）**：若概率 $p$ 非常小，则 (6.23) 表明只有当 $n$ 非常大时用正态分布逼近 $\Phi_n$ 才有效——这直接引出 [[泊松逼近定理]]。

## 实用形式 (6.24)

当 $n$ 较大时，频率近似服从期望 $\overline{H}_n = p$、标准差 $\Delta H_n = \sqrt{p(1-p)/n}$ 的正态分布。因此对每个区间 $[a,b]$：

```
P(p + aΔH_n ≤ H_n ≤ p + bΔH_n) = Φ_0(b) − Φ_0(a)
  = (1/√(2π)) ∫_a^b e^{−z²/2} dz.        (6.24)
```

等价形式：

```
P(x ≤ H_n ≤ y) = Φ_0((y − p)/ΔH_n) − Φ_0((x − p)/ΔH_n);
P(u ≤ A_n ≤ v) = Φ_0((v − np)/√(np(1−p))) − Φ_0((u − np)/√(np(1−p)))。
```

其中 $\Phi_0$ 的值可在表 0.34 中查到；当 $z$ 取负值时有 $\Phi_0(z) = -\Phi_0(-z)$。原文称 (6.24)「给出了伯努利大数定律的一个精确表述」。

## 下游应用

(6.24) 是本节其余全部统计内容的技术基础：

- [[假设检验与残概率]]：置信区间 $[1/2 - z_\alpha \Delta H_n, 1/2 + z_\alpha \Delta H_n]$；
- [[概率p的置信区间]]：由 $|(h_n - p)/\Delta H_n| < z_\alpha$ 反解出 $p$ 的二次不等式 (6.28)；
- 质量控制中的区间概率计算，见 [[6254节质量控制中的泊松逼近与正态逼近例]]。

## 历史

[[棣莫弗]] 在 $p = 1/2$ 和对称边界 $b = -a$ 的情形发现了该公式；[[拉普拉斯]] 在 1812 年《分析概率论》中证明了这里给出的一般公式。
