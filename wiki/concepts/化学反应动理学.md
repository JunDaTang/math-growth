# 化学反应动理学

本节 1.12.1.8：给定 $m$ 种化学物质 $A_1,\dots,A_m$，反应写作

```latex
\sum_{j=1}^{m} \nu_j A_j = 0,
```

$\nu_j$ 称为**计量系数**。令 $N_j$ 为 $A_j$ 的分子数，**密度**

```latex
c_j := \frac{N_j}{V},
```

$V$ 为反应的累积体积。例：$2A_1+A_2\to 2A_3$ 对应 $\nu_1=-2,\nu_2=-1,\nu_3=2$；具体实例 $2\mathrm H_2+\mathrm O_2\to 2\mathrm H_2\mathrm O$。

基本方程

```latex
\begin{array}{l}
\frac{1}{\nu_j}\frac{\mathrm{d}c_j}{\mathrm{d}t} = k c_1^{n_1} c_2^{n_2}\dots c_m^{n_m}, \quad j=1,\dots,m, \\
c_j(0) = c_{j0} \quad (\text{初始条件}),
\end{array}                                       \tag{1.218}
```

$k$ 为正的反应速度常量（依赖压力 $p$ 与温度 $T$），$n_1,n_2,\dots$ 称为**反应的阶**；未知量是密度 $c_j(t)$ 对时间的依赖。源文指出 (1.218) 型方程及其变形也常用于生物学，此时 $N_j$ 为某种生物的数目（可与 [[增长方程]] (1.206) 和阻抗增长方程 (1.208) 比较）。
