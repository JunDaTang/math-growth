# 对等式的运算

1.1.4 节：设 a, b, c 为任意实（或复）数，对等式的运算符合下列规则：

```latex
a = b \Rightarrow a + c = b + c   \quad (\text{加法}),
a = b \Rightarrow a - c = b - c   \quad (\text{减法}),
a = b \Rightarrow ac = bc         \quad (\text{乘法}),
a = b,\ c \neq 0 \Rightarrow \frac{a}{c} = \frac{b}{c}   \quad (\text{除法}),
a = b,\ a \neq 0 \Rightarrow \frac{1}{a} = \frac{1}{b}   \quad (\text{倒数}).
```

用语言叙述：

1. 可以在一个等式两边加相同的数，其结果仍是一个等式。
2. 可以在等式两边乘以同一个数。
3. 可以在等式两边除以同一个（不为零的）数。
4. 可以得到等式的倒数。

在情况 (iii) 和 (iv) 中必须注意：**不允许 0 作除数！**

直观上，一个等式就像衡量平衡的尺度：对于其两端，在相同的时间作同样的事就不会打破平衡。

## 两个等式的运算

对所有实（或复）数 a, b, c, d：

```latex
\begin{array}{ll}
a = b, c = d \Rightarrow a + c = b + d & (\text{两个等式的加法}), \\
a = b, c = d \Rightarrow a - c = b - d & (\text{两个等式的减法}), \\
a = b, c = d \Rightarrow ac = bd & (\text{两个等式的乘法}), \\
a = b, c = d, c \neq 0 \Rightarrow \frac{a}{c} = \frac{b}{d} & (\text{两个等式的除法}).
\end{array}
```

其中最后一条右端写作 b/d，与前文的书写形式不一致，见 [[queries/两个等式除法法则右端写作bd的转写疑误]]。
