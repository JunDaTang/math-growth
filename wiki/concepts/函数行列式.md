# 函数行列式（雅可比行列式）

函数行列式是《数学指南》2.1.2 节末尾衔接微积分的概念：$\frac{\partial(f_1,\cdots,f_n)}{\partial(u_1,\cdots,u_n)}$ 表示**一阶偏导数** $\partial f_j / \partial u_k$ 的行列式（原文注明参看 1.5.3）。即

```latex
\frac{\partial(f_1, \cdots, f_n)}{\partial(u_1, \cdots, u_n)}
= \det\left( \frac{\partial f_j}{\partial u_k} \right)_{j,k}.
```

## 乘法法则（链式法则）

原文给出的核心公式：

```latex
\frac{\partial(f_1, \cdots, f_n)}{\partial(u_1, \cdots, u_n)}
= \frac{\partial(f_1, \cdots, f_n)}{\partial(v_1, \cdots, v_n)}
\cdot \frac{\partial(v_1, \cdots, v_n)}{\partial(u_1, \cdots, u_n)}.
```

该式本质上是 $\det A \det B = \det(AB)$ 在偏导数矩阵上的应用：把中间变量 $v_1,\cdots,v_n$ 的偏导数矩阵相乘，行列式相应地相乘。
