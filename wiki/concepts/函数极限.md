# 函数极限（序列式定义）

《数学指南——实用数学手册》1.3.1.1 节用**数列极限**来定义单实变量函数的极限，而不是直接采用 ε-δ 形式。

## 定义

设 $-\infty \leqslant a, b \leqslant \infty$。记

```
lim_{x→a} f(x) = b
```

如果对 $f$ 定义域里每个序列 $(x_n)$，其中每个 $x_n \neq a$，有

```
lim_{n→∞} x_n = a  蕴涵  lim_{n→∞} f(x_n) = b
```

原注指出：在这些情形函数 $f$ **不必在点 $a$ 有定义**；只要求 $f$ 的定义域至少包含一个具有上述极限性质的序列 $(x_n)$。

序列式定义的直接好处是：函数极限的运算自动继承数列极限的运算。

## 运算律

当 $-\infty \leqslant a \leqslant \infty$ 时，

```
lim_{x→a} (f(x) + g(x)) = lim_{x→a} f(x) + lim_{x→a} g(x)
lim_{x→a} f(x) g(x)    = lim_{x→a} f(x) · lim_{x→a} g(x)
lim_{x→a} f(x)/h(x)    = lim_{x→a} f(x) / lim_{x→a} h(x)
```

需**额外假设**等式右端的极限都存在且有限，且最后一个表达式中 $\lim_{x\to a} h(x) \neq 0$。当 $x \to a+0$ 或 $x \to a-0$（$a \in \mathbb{R}$）时这些运算依然成立。这是与数列极限运算律的一个重要差别：右端存在性必须单独假定。

## 例子

- 例 1：$f(x) := x$，则 $\lim_{x\to a} f(x) = a$。
- 例 2：$f(x) := x^2$，则 $\lim_{x\to a} x^2 = \lim_{x\to a} x \cdot \lim_{x\to a} x = a^2$。
- 例 3：分段函数（$x > a$ 取 1，$x = a$ 取 2，$x < a$ 取 −1）的右极限为 1、左极限为 −1（图 1.19）。
