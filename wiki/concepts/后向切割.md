# 后向切割（第二基本问题）

后向切割是《数学指南——实用数学手册》3.2.2.2 节给出的「第二基本问题」：已知具[[笛卡儿坐标]] $(x_A, y_A)$、$(x_B, y_B)$、$(x_C, y_C)$ 的三个点 $A$、$B$、$C$，测得图 3.13 中位于待定点 $P$ 处的角 $\alpha$ 与 $\beta$，要求 $P$ 的坐标 $(x, y)$。英文文献中通常称为后方交会（resection）。

## 可解性条件

源文件明确指出：**这个问题只能在这四点不共圆时才有解。** 共圆时观测角与点位失去一一对应性，$P$ 不能唯一确定。此条件与三点所决定的外接圆有关（参看 [[三角形的外接圆与内切圆]]）。

## 计算步骤（源文件原样）

先计算辅助量：

```
x₁ = x_A + (y_C − y_A) · cot α
y₁ = y_A + (x_C − x_A) · cot α

x₂ = x_B + (y_B − y_C) · cot β
y₂ = y_B + (x_B − x_C) · cot β
```

再计算 $\mu$ 与 $\eta$：

```
μ = (y₂ − y₁) / (x₂ − x₁)
η = 1 / μ
```

最终得到

```
y = y₁ + (x_C − x₁ + (y_C − y₁) · μ) / (μ + η)

x = { x_C − (y − y_C) · μ,   当 μ < η
    { x₁ + (y − y₁) · η,     当 η < μ
```

## 未决问题

源文件**未给出本公式的证明**，仅列出计算步骤；辅助量中 $x$ 与 $y$ 两式对 $\cot\alpha$（及 $\cot\beta$）的搭配并不对称，且 $\mu < \eta$ 与 $\eta < \mu$ 两支的取解自洽性需要核验。详见 [[queries/322节第二基本问题公式对称性与分支条件存疑]]。
