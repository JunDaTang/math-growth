# 毕达哥拉斯定理

毕达哥拉斯定理（即勾股定理）给出直角三角形三边的平方关系。两个源版本分别以不同编号和上下文给出这一定理。

## 定理表述

### 源 0.1.3：表 0.4 中的直角三角形条目

在 [[数学指南-实用数学手册]] 表 0.4 的直角三角形条目中给出为

$$a^{2} + b^{2} = c^{2},$$

其中 $c$ 为斜边（直角三角形中直角的对边），$a$ 为对边，$b$ 为邻边。

### 源 3.2.1：3.2.1.2 节的关系式 (3.6)

毕达哥拉斯定理是 3.2.1.2 节给出的直角三角形核心关系式，编号 (3.6)：

$$c^{2} = a^{2} + b^{2}.\tag{3.6}$$

原文以文字表述为：斜边长的平方等于两条直角边长的平方和。

## 与其他公式的关系

### 源 0.1.3 的同一行内容

表 0.4 的同一行还给出边角关系 $a = c\sin\alpha$、$b = c\cos\alpha$、$a = b\tan\alpha$，以及高的欧几里得关系 $h^{2} = pq$（见 [[欧几里得关系]]）。

### 源 3.2.1 中的定理地位

- 该定理被明确说明为 [[余弦定律]] (3.2) 的特殊情形：因为 $\gamma = \pi/2$ 且 $\cos\gamma = 0$。
- 与「高的欧几里得定律」$h^{2} = pq$ 和「直角边的欧几里得定律」$a^{2} = qc$、$b^{2} = pc$ 并列，构成本节直角三角形公式群（$p$、$q$ 为两条直角边在斜边上的投影线段）。

> 说明：$h^{2} = pq$ 在两个源中均出现。源 0.1.3 将其作为「高的欧几里得关系」并指向 [[欧几里得关系]]；源 3.2.1 将其称为「高的欧几里得定律」，并额外给出直角边的欧几里得定律 $a^{2} = qc$、$b^{2} = pc$。

## 应用示例（源 3.2.1）

定理在源 3.2.1 的两处例题证明中被直接使用：

- 例 1（等腰直角三角形）：由 $a^{2} = h^{2} + h^{2}$ 推出 $h = a\sqrt{2}/2$；
- 例 2（等边三角形）：由 $a^{2} = h^{2} + (a/2)^{2}$ 推出 $h = a\sqrt{3}/2$。

与其他基本公式一样，可经循环置换生成相应形式（源中「循环置换」段落）。

## 命名与历史归属

- 源 0.1.3 脚注明示：人们认为萨摩斯岛的毕达哥拉斯（[[毕达哥拉斯]]，Pythagoras，公元前 500 年）是古希腊最著名的学派（毕达哥拉斯学派）的创立者，该定理因而以其命名。然而早在距那时大约 1000 年之前，汉谟拉比（[[汉谟拉比]]，Hammurapi，公元前 1728—前 1686）国王统治下的巴比伦人就已知道这一定理。因此本 wiki 表述时保留这一历史限定，不将其归为某一方的独家贡献。
- 源 3.2.1 中，定理以 [[毕达哥拉斯]] 冠名；该源未给出年代或历史叙述。
