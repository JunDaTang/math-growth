# 区间

1.1.1.5 节：设 a、b 是实数且 a < b。**紧区间**（有端点 a 和 b）定义为

```latex
[a, b] := \{x \in \mathbb{R} \mid a \leqslant x \leqslant b\}.
```

## 有界区间

```latex
\begin{array}{ll}
]a, b[ := \{x \in \mathbb{R} \mid a < x < b\}; & (\text{开区间}) \\
[a, b[ := \{x \in \mathbb{R} \mid a \leqslant x < b\}; & (\text{右半开区间}) \\
]a, b] := \{x \in \mathbb{R} \mid a < x \leqslant b\}; & (\text{左半开区间})
\end{array}
```

## 无限区间

```latex
\begin{array}{l}
]-\infty, a] := \{x \in \mathbb{R} \mid x \leqslant a\}, \quad ]-\infty, a[ := \{x \in \mathbb{R} \mid x < a\}, \\
[b, \infty[ := \{x \in \mathbb{R} \mid b \leqslant x\}, \quad ]b, \infty[ := \{x \in \mathbb{R} \mid b < x\}.
\end{array}
```

实数集合 ℝ 也可记作 `]−∞, ∞[`。

本小节使用的开区间记号是欧洲惯例的 `]a, b[`，与英文文献常用的 `(a, b)` 不同；在引用 0.9 积分表的条目时需要留意记号体系的差异。图示见图 1.4。
