# 解方程的两步范式

1.1.4 节在三个例子中反复使用同一模式，构成手册对「解方程」的方法论表述：

- **第一步**：假设数 x（或 x, y）是方程的解，由此推出「若解存在，则解必为某形式」。
- **第二步（检验）**：把第一步得到的表达式代回原方程，验证它确实是解。

手册明确警告：**通常，数学错误的出现是因为混淆了第一步与一个完整的证明**（参看 4.2.6.2）。这是本小节的方法论要点，见 [[findings/解方程需两步范式第一步非完整证明]]。

## 例 1：线性方程

```latex
2x + 3 = 7\tag{1.11}
```

第一步：两边同时减去 3 得 2x = 4，再除以 2 得 x = 2；第二步：验证 2·2 + 3 = 7。方程有唯一解 x = 2。

## 例 2：线性方程组

设 a, b, c, d, α, β 为实（或复）数，且 ad − bc ≠ 0：

```latex
\left\{ \begin{array}{l} ax + by = \alpha, \\ cx + dy = \beta \end{array} \right.\tag{1.12}
```

有唯一解

```latex
x = \frac{\alpha d - \beta b}{ad - bc}, \quad y = \frac{a\beta - c\alpha}{ad - bc}.\tag{1.13}
```

第一步的推导是：用 d（或 −b）乘第一个（或第二个）方程后相加，得 (ad − bc)x = αd − βb；再用 (−c)（或 a）乘第一个（或第二个）方程后相加，得 (ad − bc)y = aβ − cα；分别除以 ad − bc 即得 (1.13)。

## 例 3：二次方程

设实数 b, c 满足 b² − c > 0，则

```latex
x^{2} + 2bx + c = 0\tag{1.14}
```

恰有两个解

```latex
x = -b \pm \sqrt{b^{2} - c}.\tag{1.15}
```

第一步：两边加 b² − c 并配方得 (x + b)² = b² − c，故 x + b = ±√(b² − c)，再两边加 (−b)。
