# 最大似然方程组 (6.37) 与 (6.38)

最大似然估计通过求解关于参数的方程组得到。《数学指南——实用数学手册》6.3.5 节按随机变量类型给出两组方程。

## 连续型情形 (6.37)

设概率密度 $\varphi = \varphi(x, \boldsymbol\beta)$ 依赖参数 $\boldsymbol\beta = (\beta_1, \cdots, \beta_k)$，$x_1, \cdots, x_n$ 为观测值，则最大似然估计值由下式解得：

```latex
\sum_{j=1}^{n} \frac{1}{\varphi(x_j, \boldsymbol\beta)}
  \frac{\partial \varphi(x_j, \boldsymbol\beta)}{\partial \beta_r} = 0,
\quad r - 1, \dots, k.   \tag{6.37}
```

其中指标书写 `r - 1, …, k` 疑为 `r = 1, …, k`，见 [[635节最大似然方程组中r减1疑为r等于1]]。

## 离散型情形 (6.38)

设 $X$ 以概率 $p_1(\boldsymbol\beta), \cdots, p_k(\boldsymbol\beta)$ 取有限多个值 $a_1, \cdots, a_k$，$h_j$ 为 $a_j$ 在变异序列 $x_1, \cdots, x_n$ 中出现的频率（$\sum_j h_j = 1$），则

```latex
\sum_{j=1}^{k} \frac{h_j}{p_j(\boldsymbol\beta)}
  \frac{\partial p_j(\boldsymbol\beta)}{\partial \beta_r} = 0,
\quad r = 1, \dots, k.   \tag{6.38}
```

它与 (6.37) 的结构一致：把连续情形中的「密度归一化」换成「概率归一化」，并把对样本的求和换成按取值加权的频率求和。

## 特化结果

- **正态分布**（$\beta_1 = \mu$，$\beta_2 = \sigma$）：利用 $\partial \varphi/\partial \mu = \frac{\mu - x}{\sigma^2}\varphi$ 与 $\partial \varphi/\partial \sigma = \left(-\frac{1}{\sigma} + \frac{(\mu - x)^2}{\sigma^3}\right)\varphi$，(6.37) 化为 $\sum_j (\mu - x_j) = 0$ 与 $-\frac{n}{\sigma} + \sum_j \frac{(x_j - \mu)^2}{\sigma^3} = 0$，解得 $\mu = \frac{1}{n}\sum x_j$、$\sigma^2 = \frac{1}{n}\sum (x_j - \mu)^2$。
- **伯努利型**：由 (6.38) 得 $\frac{h_1}{p} - \frac{h_2}{1-p} = 0$，故 $p = h_1$。
- **泊松型**：由 (6.38) 得 $\sum_j \left(\frac{j}{\beta} - 1\right) h_j = 0$，故 $\beta = \sum_j h_j j = \frac{1}{n}\sum_{j=1}^{n} x_j$，即 (6.39)。
