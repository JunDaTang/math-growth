# 被零除错误

《数学指南——实用数学手册》4.2.6.1 节剖析的第一类错误证明：「证明中的两个最主要的错误是在证明中做出了『被零除』的一步，以及『沿错误的方向』证明命题」。本节提醒，在解方程时必须时刻当心在处理某些变量的值时有实施被零除的可能。

**错误的断言**：方程 $(x-2)(x+1) + 2 = 0$（4.11）恰有一个实数解 $x = 1$。

**该断言的「证明」**：易验 $x=1$ 是解；为证唯一性，假定 $x_0$ 是另一解，则 $x_0^2 - 2x_0 + x_0 - 2 + 2 = 0$，即 $x_0^2 - x_0 = 0$，于是

```
x₀(x₀ − 1) = 0        (4.12)
```

除以 $x_0$ 得 $x_0 - 1 = 0$，即 $x_0 = 1$。

**错误所在**：断言本身是假的，因为 $x = 1$ 和 $x = 0$ 同是 (4.11) 的解。证明的错误在于 (4.12) 之后的除法：**只能在 $x_0 \neq 0$ 的假定下除以 $x_0$**。正确断言是方程 (4.11) 恰有两个解 $x=1$ 与 $x=0$，其证明只需由 (4.12) 得「要么 $x=0$ 要么 $x-1=0$」，再逐一检验两个值确实满足 (4.11)。

与「被零除」并列的另一类错误见[[concepts/沿错误方向的证明]]。
