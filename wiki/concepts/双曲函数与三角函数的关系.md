# 双曲函数与三角函数的关系

双曲函数与三角函数通过**虚宗量代换**相互转化。《数学指南——实用数学手册》在 0.2.10 节（$\sinh$、$\cosh$）与 0.2.11 节（$\tanh$、$\coth$）两个层面给出同一族对应关系。本页按「层面」而非「来源文档」组织，但每条公式均标注其出处小节。

## 对应关系总表

| 双曲函数 | 源文档给出的形式 | 出处 |
|---|---|---|
| $\sinh$ | $\sinh \mathrm{i} x = \mathrm{i} \sin x$ | 0.2.10 |
| $\sinh$ | $\sinh x = -\mathrm{i} \sin \mathrm{i} x$ | 0.2.11（用于与 $\tanh$ 之商对照） |
| $\cosh$ | $\cosh \mathrm{i} x = \cos x$ | 0.2.10 |
| $\cosh$ | $\cosh x = \cos \mathrm{i} x$ | 0.2.11（同上） |
| $\tanh$ | $\tanh x = -\mathrm{i} \tan \mathrm{i} x$ | 0.2.11 |
| $\coth$ | $\coth x = \mathrm{i} \cot \mathrm{i} x$ | 0.2.11 |

两小节使用的书写方向不同（0.2.10 把虚宗量放在双曲函数一侧，0.2.11 把它放在三角函数一侧），但均以「对所有复数 $x$」为前提成立；上表按各源文档原样保留，未合并成单一形式。

0.2.11 节在给出 $\tanh$、$\coth$ 关系时注明「**参见表 0.20**」（见 [[表020双曲函数与三角函数的零点与极点]]）。0.2.10 节则在 $\sinh$、$\cosh$ 层面给出同类关系（见 [[双曲正弦]]、[[双曲余弦]]）。

## 0.2.10：正弦、余弦层面的对应

对所有复数 $x$：

$$
\sinh \mathrm{i} x = \mathrm{i} \sin x, \qquad \cosh \mathrm{i} x = \cos x.
$$

### 方法论主张

《数学指南——实用数学手册》0.2.10 节据此断言：**关于双曲正弦和双曲余弦的每个公式都能由正弦和余弦函数得到**。

源文档给出的唯一示例是：由对任意复数 $x$ 有 $\cos^2 \mathrm{i}x + \sin^2 \mathrm{i}x = 1$，得到

$$
\cosh^{2} x - \sinh^{2} x = 1.
$$

### 证据强度

- 示例推导本身严格：$\cos \mathrm{i}x = \cosh x$、$\sin \mathrm{i}x = \mathrm{i}\sinh x$，直接代入即得，无需额外假设。
- 「每个公式都能得到」是**全称量词式断言**，0.2.10 节仅给出一个例证，未逐一验证。属推断而非穷尽证明。本 wiki 将本条记为推断，参见 [[双曲恒等式可由三角恒等式代换得到]]。

> 归属说明：上述「全称量词式断言 + 仅一个例证」的证据评估，来自以 0.2.10 节为唯一来源的页面版本；0.2.11 节来源版本未对此断言作证据强度评估。

## 0.2.11：正切、余切层面的商型分支

0.2.11 节在 $\tanh$、$\coth$ 层面给出：

$$
\tanh x = -\mathrm{i}\tan \mathrm{i}x, \quad \coth x = \mathrm{i}\cot \mathrm{i}x.
$$

- **正切分支**：$\tanh x = -\mathrm{i}\tan \mathrm{i}x$，与 $\sinh x = -\mathrm{i}\sin \mathrm{i}x$、$\cosh x = \cos \mathrm{i}x$ 之商一致：
  $$
  \frac{\sinh x}{\cosh x} = \frac{-\mathrm{i}\sin \mathrm{i}x}{\cos \mathrm{i}x} = -\mathrm{i}\tan \mathrm{i}x .
  $$
- **余切分支**：$\coth x = \mathrm{i}\cot \mathrm{i}x$，同样可由 $\cosh x / \sinh x$ 的对应关系推出。

注意两个分支的系数符号不同（$\tanh$ 带 $-\mathrm{i}$，$\coth$ 带 $+\mathrm{i}$），根源在于 $\coth$ 是 $\tanh$ 的倒数函数。

## 零点与极点：虚宗量代换的几何意义

虚宗量代换把三角函数的零点/极点整体旋转到虚轴上：

- $\sin x$ 的零点 $\pi k$ 变为 $\sinh x$ 的零点 $\pi k \mathrm{i}$；
- $\cos x$ 的零点 $\pi k + \frac{\pi}{2}$ 变为 $\cosh x$ 的零点 $\left(\pi k + \frac{\pi}{2}\right)\mathrm{i}$。

这为 [[表020双曲函数与三角函数的零点与极点]] 提供了推导路径，详见 [[双曲函数与三角函数的零点与极点]]。

## 与其它恒等式的关系

按 0.2.11 节来源的说法，虚宗量代换是整节公式表「三角恒等式 → 双曲恒等式」转写规则的来源：加法定理（[[双曲函数加法定理]]）、倍角半角公式（[[双曲函数倍角与半角公式]]）与平方关系（[[双曲函数的平方关系]]）都可按此规则逐条对应。

按 0.2.10 节来源的说法，该转写能力被表述为「关于双曲正弦和双曲余弦的每个公式都能由正弦和余弦函数得到」这一全称断言，而源文档仅提供一个例证（见上文「方法论主张」与「证据强度」）。两条表述覆盖的范围不同——一条针对整节公式表，一条针对 $\sinh$、$\cosh$；本页分别保留，不合并为同一结论。

## 边界说明

- 0.2.10 节**未提及**欧拉（Euler），因此不应把本页与 [[欧拉乘积公式]]、[[欧拉]] 等页面直接绑定——双曲—三角对应是同一族指数恒等式的近亲，但 0.2.10 节的论证链中不含欧拉其人。
