# 最大公因子（多项式）

## 定义与求法

来源 2.1.5 节以欧几里得算法求两个多项式 $N(x)$ 与 $D(x)$（次数至少为 $1$）的最大公因子 (gcd)。其结论为：写出一串带余除法

```
N(x)   = D(x)Q(x)    + R_1(x),
D(x)   = R_1(x)Q_1(x) + R_2(x),
R_1(x) = R_2(x)Q_2(x) + R_3(x),  等等。
```

由 $\deg(R_{j+1}) < \deg(R_j)$，经有限步后某一步余项多项式为零：

```
R_m(x) = R_{m+1}(x)Q_{m+1}(x).
```

于是 $R_{m+1}(x)$ 是 $N(x)$ 和 $D(x)$ 的最大公因子。

## 与带余除法唯一性的区别

本节包含两条独立断言：带余除法中 $Q,R$ 的**存在唯一性**，以及 **gcd 由末项非零余项给出**。前者属于 [[concepts/多项式带余除法]]，后者属于本页所属的欧几里得算法框架；来源并未把二者互相推导，也不应互相移用。

## 算例（例 5）

$N(x) := x^3 - 1$，$D(x) := x^2 - 1$：

```
x^3 - 1 = (x^2 - 1)x + x - 1,
x^2 - 1 = (x - 1)(x + 1).
```

因此 $x - 1$ 是 $x^3 - 1$ 和 $x^2 - 1$ 的最大公因子。

## 边界

来源未给出最大公因子的唯一性规范化约定（例如首一化），也未讨论 gcd 与因式分解、多项式零点之间的关系。
