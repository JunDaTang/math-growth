# 复数的绝对值与距离

1.1.2.1 节定义复数 z = x + iy 的**绝对值**

```latex
|z| := \sqrt{x^{2} + y^{2}}.
```

从几何上看，它是由 z 定义的向量的长度（图 1.6(a)）。

## 实数情形

对实数 x，

```latex
|x| := \begin{cases} x, & x \geqslant 0, \\ -x, & x < 0. \end{cases}
```

例：|i| = 1，|1 + i| = √(1² + 1²) = √2。

## 距离

两个复数 z 和 w 之间的**距离**是 `|z − w|`（图 1.6(b),(c)）。特别地，|z| 是原点到 z 的距离。

## 运算性质

```latex
|zw| = |z||w|, \quad \left|\frac{z}{w}\right| = \frac{|z|}{|w|}, \quad |z| = |\bar{z}|,
```

其中当 w 出现在分母时 w ≠ 0。

绝对值的大小比较性质见 [[concepts/三角不等式]]。
