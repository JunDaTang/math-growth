# 线性离心率

线性离心率 $e$ 是《数学指南——实用数学手册》0.1.7 节为圆锥曲线引入的长度量，其数值等于焦点到中心的距离。它与无量纲的 [[数值离心率]] $\varepsilon$ 通过 $\varepsilon = e/a$ 相联系（$a$ 为相应的半轴长）。

## 各圆锥曲线的定义

| 圆锥曲线 | 线性离心率 e | 数值离心率 ε |
|---|---|---|
| 椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$0<b<a$） | $e = \sqrt{a^{2} - b^{2}}$ | $\varepsilon = e/a$ |
| 双曲线 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$ | $e = \sqrt{a^{2} + b^{2}}$ | $\varepsilon = e/a$ |
| 抛物线 $y^{2}=2px$ | $e = \frac{p}{2}$ | $\varepsilon = 1$ |

椭圆的焦点为 $(\pm e,0)$，双曲线的焦点为 $(\pm e,0)$，抛物线的焦点为 $(e,0)$。

## 用 ε 与 p 表示的等价形式（表 0.8）

| 圆锥曲线 | 数值离心率 ε | 线性离心率 e |
|---|---|---|
| 双曲线 | ε > 1 | $e = \frac{\varepsilon p}{(1 - \varepsilon)^2}$ |
| 抛物线 | ε = 1 | $e = \frac{p}{2}$ |
| 椭圆 | 0 ≤ ε < 1 | $e = \frac{\varepsilon p}{1 - \varepsilon^2}$ |
| 圆 | ε = 0（极限情况 d = ∞） | e = 0 |

其中 $p$ 为 [[半参数p]]。圆的行是极限情形，其准线距离 $d$ 趋于无穷。
