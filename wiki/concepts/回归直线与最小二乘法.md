# 回归直线与最小二乘法

## 最小化问题

《数学指南——实用数学手册》6.1.5 节考虑最小化问题

```
(Y − a − bX) 的均值 = min,  a, b ∈ ℝ        (6.6)
```

即寻找一个最密切逼近 $Y$ 的线性函数 $a + bX$。文中指出，这个最小化问题相应于**高斯的最小二乘法**。

> 说明：来源文本中 (6.6) 的公式框内印作 $bX^{2}$，而同一小节 (b) 中的残差式印作 $(Y - a - bX)^2$，两处不一致；参见 [[queries/615节方程66中bX平方疑点]]。

## 解

(a) (6.6) 的解是所谓的**回归直线**

```
Ȳ + r (ΔY/ΔX) (X − X̄)
```

(b) 对于这个解，有

```
(Y − a − bX)² 的均值 = (ΔY)² (1 − r²)
```

对于 $r^2 = 1$（或 $r = 0$），得到的是最好（或最差）的逼近。

## 由测量值估计

在实际情形，给定测量值 $x_1,\dots,x_n$ 和 $y_1,\dots,y_n$，将 $(x_j,y_j)$ 描在 $(x,y)$ 平面上，回归直线

```
y = Ȳ + r (ΔY/ΔX) (x − X̄)
```

是最好地拟合所有这些点的直线（图 6.5）。$\Delta X, \Delta Y$ 和 $r$ 的真值未知，可用测量值估计：

```
X̄ = (1/n) Σ_{j=1}^n x_j
(ΔX)² = (1/(n−1)) Σ_{j=1}^n (x_j − X̄)²
r = (1/((n−1) ΔX ΔY)) Σ_{j=1}^n (x_j − X̄)(y_j − Ȳ)
```
