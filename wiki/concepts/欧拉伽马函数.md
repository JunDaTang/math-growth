# 欧拉伽马函数 Γ

欧拉伽马函数 Γ 是把阶乘从非负整数推广到复数的特殊函数。本源（《数学指南——实用数学手册》1.14.16 节）以如下方式引入：

$$\Gamma(n+1) := n!, \quad n = 0, 1, 2, \dots,$$

由此蕴含递推关系，即[[伽马函数方程]]

$$\Gamma(z+1) = z\Gamma(z). \tag{1.480}$$

欧拉的问题是能否对 $z$ 的其他值合理定义 $n!$；他给出的一个解是[[欧拉积分表示]]

$$\Gamma(x) := \int_{0}^{\infty} \mathrm{e}^{-t} t^{x-1}\,\mathrm{d}t, \quad x > 0. \tag{1.481}$$

## 解析延拓与亚纯性

由 (1.481) 定义的实值函数可以**唯一**扩展为 $\mathbb{C}$ 上的一个[[亚纯函数]]。该函数的极点恰为 $z = 0, -1, -2, \cdots$，并且全部为**一阶极点**（参见[[极点-复变函数]]）。在极点 $z = -n$ 邻域的[[洛朗展开定理|洛朗级数]]为

$$\Gamma(z) = \frac{(-1)^{n}}{n!\,(z+n)} + (z+n) \text{ 的幂级数}, \quad n = 0, 1, 2, \cdots.$$

由[[恒等原理]]（源文此处写作「恒等定理」），函数方程 (1.480) 对一切非 Γ 极点的复 $z$ 成立。这一延拓过程是[[解析延拓]]的典型例子。

## 主要性质一览

- [[高斯乘积公式]]：Γ 无零点，$1/\Gamma$ 是[[整函数]]，且
  $$1/\Gamma(z) = \lim_{n \to \infty} \frac{1}{n^{z} n!} z(z+1)\cdots(z+n), \quad z \in \mathbb{C}.$$
- [[高斯乘法公式]]：$\prod_{j=0}^{k-1}\Gamma\!\left(\frac{z+j}{k}\right) = \frac{(2\pi)^{(k-1)/2}}{k^{\,z-1/2}}\Gamma(z)$。
- [[拉格朗日加倍公式]]：$k=2$ 的特例。
- [[欧拉互补定理]]：$\Gamma(z)\Gamma(1-z) = \pi/\sin \pi z$（$z$ 非整数）。
- [[斯特林公式]]：$\Gamma(x+1) = \sqrt{2\pi}\,x^{\,x+1/2}\mathrm{e}^{-x}\mathrm{e}^{\,\theta(x)/12x}$（$0<\theta(x)<1$），并给出 $n!$ 的渐近估计。
- [[维兰特唯一性定理]]：递推 + 带域有界 + $f(1)=1$ 唯一刻画 Γ。

## 补充性质（源文「更多的性质」）

- (i) (1.481) 对满足 $\operatorname{Re} z > 0$ 的所有复数 $z$ 成立。
- (ii) $\Gamma(1) = 1$，$\Gamma(1/2) = \sqrt{\pi}$，$\Gamma(-1/2) = -2\sqrt{\pi}$。
- (iii) 对非整数 $z$：$\Gamma(z)\Gamma(-z) = -\pi/\bigl(z\sin(\pi z)\bigr)$。
- (iv) 对 $z + 1/2$ 非整数的 $z$：$\Gamma(1/2+z)\Gamma(1/2-z) = \pi/\cos(\pi z)$。
