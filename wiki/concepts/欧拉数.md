# 欧拉数

欧拉数 $E_k$ 是手册中与 [[伯努利数]] $B_k$ 并列的一族数列。手册 0.7.1.2 的脚注指出，二者分别介绍于 0.1.10.4 与 0.1.10.5（两节尚未入库，见 [[concepts/伯努利数]]）。

## 定义与符号方程

对所有复数 $x$（$|x| < \frac{\pi}{2}$），无穷级数

$$
\frac{1}{\cosh x} = 1 + \frac{E_1}{1!}x + \frac{E_2}{2!}x^2 + \dots = \sum_{k=0}^{\infty} \frac{E_k}{k!}x^k
$$

收敛。该级数中的系数 $E_k$ 称为欧拉数。原文约定 $E_0 = 1$，且对所有奇数 $n$，$E_n = 0$。

如果施行乘法运算之后用 $E_n$ 代替 $E^n$，则欧拉数满足符号方程

$$
(E+1)^n + (E-1)^n = 0, \quad n = 1, 2, \dots
$$

原文指出：这为 $E_n$ 提供了一个便利的递归公式。

## 与伯努利数的关系

欧拉数与 [[伯努利数]] 之间的关系再次以符号形式给出为

$$
E_{2n} = \frac{4^{2n+1}}{2n+1}\left(B_n - \frac{1}{4}\right)^{2n+1}, \quad n = 1, 2, \dots
$$

## 欧拉数在无穷级数中的出现

欧拉数出现在下列函数的幂级数展开中：$\dfrac{1}{\cosh x}$、$\dfrac{1}{\cos x}$（参看 0.7.2）。

在 ζ 函数的**交错奇次幂族**公式中，欧拉数作为系数出现：

$$
1 - \frac{1}{3^{2k+1}} + \frac{1}{5^{2k+1}} - \dots = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)^{2k+1}} = \frac{\pi^{2k+1}}{2^{2k+2}(2k)!}|E_{2k}|
$$

> [!note] 两种版本给出的下标范围不同
> - 0.1.10 版本（现有页面）陈述该公式**对 $k = 1, 2, \cdots$** 成立。
> - 0.7.1 版本（本次生成）把同一公式写作**对 $k = 0, 1, 2, \dots$** 成立，并给出 $k=0$ 的取值（见下）。
>
> 两者对公式形式本身没有分歧，仅下标起点不同；此处并列保留，不做合并。

### 具体取值（据 0.7.1 版本）

- $k = 0$：$|E_0| = 1$，得到 [[莱布尼茨级数]] $\pi/4$；
- $k = 1$：得到 $1 - 1/3^3 + 1/5^3 - \dots = \pi^3/32$。

由此可见，偶数下标欧拉数的绝对值控制的是 $\pi$ 的**奇次幂**级数，与伯努利数控制的 $\pi$ 的偶次幂族形成对偶。详见 [[ζ函数的特殊值]]、[[concepts/幂级数]]。

## 注意区分

本页的「欧拉数」$E_k$ 指数列，与手册 0.7.1.1 中把 $2 + 1/2! + 1/3! + \dots = \mathrm{e}$ 标注为「欧拉数」的用法含义不同：后者指的是常数 $\mathrm{e}$ 的名称来源，见 [[concepts/欧拉数]]。
