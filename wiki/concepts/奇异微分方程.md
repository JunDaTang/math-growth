# 奇异微分方程

**奇异微分方程**指二阶线性常微分方程

$$
w^{\prime\prime} + p(z) w^{\prime} + q(z) w = 0 \tag{1.494}
$$

中系数 $p(z)$ 与（或）$q(z)$ 在某点 $z = a$ 处不解析的情形，该点 $z = a$ 称为方程的**奇点**。

## 解的结构

在奇点的去心邻域 $0 < |z-a| < r$ 内，方程 (1.494) 仍有两个线性无关解 $w_1, w_2$，通解为

$$
w(z) = C_1 w_1(z) + C_2 w_2(z), \quad 0 < |z-a| < r,
$$

其中 $C_1, C_2$ 为复常数。解的局部行为由 (1.495) 的两类形式刻画：

- 情形 1：$w_j(z) = (z-a)^{\rho_j} \mathcal{L}_j(z-a)$，$j = 1, 2$；
- 情形 2：$w_2(z) = (z-a)^{\rho_1} \mathcal{L}_2(z-a) + w_1(z) \ln(z-a)$。

其中 $\mathcal{L}_j$ 表示点 $z = a$ 处的洛朗级数（见 [[洛朗级数]]）。

## 正则奇点

若上述 $\mathcal{L}_1, \mathcal{L}_2$ 都退化为幂级数，则 $z = a$ 称为**正则奇点**；其等价刻画见 [[正则奇点]]。正则奇点情形下，可通过 [[Frobenius幂级数解法]] 与 [[指数方程-奇异微分方程]] 构造解。

## 无穷远点

通过代换 $z = 1/\zeta$，可把 $z = \infty$ 邻域内的方程化为 $\zeta = 0$ 邻域内的同类方程，见 [[无穷远点奇性分析]]。
