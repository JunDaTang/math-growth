# 变形字问题

变形字问题是《数学指南——实用数学手册》2.1.1 节中「有重组合，不考虑顺序」这一类基本问题的名称。

## 问题陈述与公式

如果当两个字的差别仅在于字母的排列就称它们是等价的，那么等价字的频数等于

$$
\boxed {\binom {n + k - 1} {n}}
$$

来源把这一情形称为变形字问题，其中 $n$ 为字长、$k$ 为字母个数。

## 例 4 中的计算

- $n = k = 2$ 时，$A = \binom{3}{2} = \frac{3\cdot2}{1\cdot2} = 3$，代表可取 $0 0, 0 1, 1 1$；
- $n = 3, k = 2$ 时，$A = \binom{4}{3} = \frac{4\cdot3\cdot2}{1\cdot2\cdot3} = 4$，代表可取 $0 0 0, 0 0 1, 0 1 1, 1 1 1$。
