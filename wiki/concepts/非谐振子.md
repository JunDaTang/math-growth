# 非谐振子

非谐振子（anharmonic oscillator）在《数学指南——实用数学手册》1.9.1 节中以**脚注 1** 的形式给出推导，其力定律为

```
F(x) = −k x i − l x³ i
```

其中 k, l 为正的常数。与 [[concepts/谐振子]] 相比，多出一个三阶（非谐）修正项 −l x³ i；谐振子是 l = 0 的特例。

## 推导思路（原文脚注）

该运动定律由一般考虑导出：根据泰勒定理，对 x 的足够小的值（小振幅）有近似展开

```
F(x) = F(0) + x a + x² b + x³ c + …
```

- 如果没有运动，那么也就没有力，即 **F(0) = 0**；
- 期望有对称性 **F(−x) = −F(x)**，由此即得 **b = 0**；
- 因为力的方向与运动方向相反，所以它的作用方向一定是 −i，因此对正的常数 k, l 有 **a = −k i, c = −l i**。

于是得到 F(x) = −k x i − l x³ i。

## 转录疑点

在正文中，「这称为非谐（anharmonic）振子。当 l = 0 时的特殊情形就是谐振子」一句出现在推导谐振子微分方程之前的紧邻位置，与其内容（非谐振子）不符，疑为转写错位，见 [[queries/191节谐振子例中非谐振子一句归属是否讹误]]。
