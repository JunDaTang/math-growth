# 事件的逻辑演算（表 6.4）

《数学指南——实用数学手册》6.2.1 小节以「事件是集合」为出发点：集合论的每一种关系和运算都对应着一个概率论的解释和意义，事件的运算按集合论规则进行（参见 4.3.2 节）。表述这一对应关系的核心是表 6.4，逐字复述如下：

| 事件 | 解释 | 概率 |
|---|---|---|
| $E$ | 全体事件 | $P(E)=1$ |
| $\varnothing$ | 不可能事件 | $P(\varnothing)=0$ |
| $A$ | 任意事件 | $0 \le P(A) \le 1$ |
| $A \cup B$ | 事件 $A$ 或 $B$ 发生 | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ |
| $A \cap B$ | 事件 $A$ 和 $B$ 都发生 | $P(A\cap B)=P(A)+P(B)-P(A\cup B)$ |
| $A \cap B=\varnothing$ | 事件 $A$ 和 $B$ 不能同时发生 | $P(A\cup B)=P(A)+P(B)$ |
| $A-B$ | 事件 $A$ 发生而 $B$ 不发生 | $P(A-B)=P(A)-P(A\cap B)^{*}$ |
| $C_E A$ | 事件 $A$ 不发生（$C_E A := E-A$） | $P(C_E A)=1-P(A)$ |
| $A \subseteq B$ | 若事件 $A$ 发生，则 $B$ 发生 | $P(A)\le P(B)$ |
| | 事件 $A$ 与 $B$ 相互独立 | $P(A\cap B)=P(A)P(B)$ |

## 要点

- 加法公式 $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ 对任意两事件成立；互不相容（$A\cap B=\varnothing$）时退化为直接相加。
- 表中「事件 $A$ 与 $B$ 相互独立」一行只是定义式的罗列，完整的（含 $n$ 个事件的）定义见 [[事件的独立性]]。
- 补事件的记号是 $C_E A := E-A$，等价于集合论中的差集；与之对应的是 $P(C_E A)=1-P(A)$。
- 单调性 $A \subseteq B \Rightarrow P(A)\le P(B)$ 直接来自概率测度的非负性与可加性。

## 译者脚注（差事件公式）

源文本中 $A-B$ 一行的概率写作 $P(A-B)=P(A)-P(B)$，并带有译者脚注：

> 原文为 $P(A-B)=P(A)-P(B)$，但这个结果仅当 $B \subseteq A$ 时才成立。——译者

因此正文采用修正后的形式 $P(A-B)=P(A)-P(A\cap B)$，该式对任意 $A, B$ 均成立。
