# 向量积

本手册 1.8.3 节定义：两个向量 $a, b$ 的**向量积**，记作 $a \times b$，定义为长为

```latex
|a| |b| sin φ
```

的一个向量（这个量即为由向量 $a, b$ 生成的平行四边形的面积，参看图 1.92），它垂直于 $a$，也垂直于 $b$，并且三个向量 $a, b, a \times b$ 以这个次序形成一个**右手系**，如果 $a \neq 0, b \neq 0$。

法则：对任意向量 $a, b, c$ 及任意实数 $\alpha$，

- $a \times b = -(b \times a)$（反交换）；
- $\alpha(a \times b) = (\alpha a) \times b$；
- $a \times (b + c) = (a \times b) + (a \times c)$（对加法分配）；
- $a \times a = 0$。

性质：

(i) $a \times b = 0$，当且仅当 $a, b$ 有一个为零向量，或 $a, b$ 平行或反平行。

(ii) $a \times b = 0$，当且仅当 $a, b$ 线性相关。

(iii) 向量积不满足交换律，即当 $a \times b \neq 0$ 时，$a \times b \neq b \times a$。

在笛卡儿坐标下有行列式表示

```latex
a × b = | i    j    k   |
        | a_1  a_2  a_3 |
        | b_1  b_2  b_3 |
      = (a_2 b_3 − a_3 b_2) i + (a_3 b_1 − a_1 b_3) j + (a_1 b_2 − a_2 b_1) k.
```

两个向量积的复合由展开法则 $a \times (b \times c) = b(ac) - c(ab)$ 与 [[拉格朗日等式]] 给出；向量积又是 [[三重积]] 的构造元件。
