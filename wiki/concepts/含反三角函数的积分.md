# 含反三角函数的积分

## 概述

表 0.9.5 以 478–500 号共 23 个条目处理含 arcsin、arccos、arctan、arccot 的积分，四者各成一组，组内结构平行：一次幂、x 倍、x² 倍、x^n 倍递推，以及除以 x、x²、x^n 的形式。所有含 √(α²−x²) 的条目均限定 |x| < |α|。

## arcsin 组（478–482）

```latex
478. ∫ arcsin(x/α) dx = x arcsin(x/α) + √(α² − x²),  |x| < |α|.
479. ∫ x arcsin(x/α) dx = (x²/2 − α²/4) arcsin(x/α) + (x/4)√(α² − x²),  |x| < |α|.
480. ∫ x² arcsin(x/α) dx = (x³/3) arcsin(x/α) + (1/9)(x² + 2α²)√(α² − x²),  |x| < |α|.
481. ∫ arcsin(x/α)/x dx = x/α + (1/(2·3·3)) x³/α³ + (1·3/(2·4·5·5)) x⁵/α⁵ + … .
482. ∫ arcsin(x/α)/x² dx = −(1/x) arcsin(x/α) − (1/α) ln((α + √(α²−x²))/x),  |x| < |α|.
```

## arccos 组（483–487）

```latex
483. ∫ arccos(x/α) dx = x arccos(x/α) − √(α² − x²),  |x| < |α|.
484. ∫ x arccos(x/α) dx = (x²/2 − α²/4) arccos(x/α) − (x/4)√(α² − x²),  |x| < |α|.
485. ∫ x² arccos(x/α) dx = (x³/3) arccos(x/α) − (1/9)(x² + 2α²)√(α² − x²),  |x| < |α|.
486. ∫ arccos(x/α)/x dx = (π/2) ln x − x/α − (1/(2·3·3)) x³/α³ − … .   ← 源转写为 π/x ln x
487. ∫ arccos(x/α)/x² dx = −(1/x) arccos(x/α) + (1/α) ln((α + √(α²−x²))/x),  |x| < |α|.
```

483–487 与 478–482 逐条对应，差别仅在 √(α²−x²) 项与级数的符号。

## arctan 与 arccot 组（488–500）

```latex
488. ∫ arctan(x/α) dx = x arctan(x/α) − (α/2) ln(α² + x²).
489. ∫ x arctan(x/α) dx = (1/2)(x² + α²) arctan(x/α) − αx/2.
490. ∫ x² arctan(x/α) dx = (x³/3) arctan(x/α) − αx²/6 + (α³/6) ln(α² + x²).
491. ∫ x^n arctan(x/α) dx = x^{n+1}/(n+1) · arctan(x/α) − (α/(n+1)) ∫ x^{n+1} dx/(α² + x²),  n ∈ ℕ.
492. ∫ arctan(x/α)/x dx = x/α − x³/(3²α³) + x⁵/(5²α⁵) − x⁷/(7²α⁷) + …,  |x| < |α|.
493. ∫ arctan(x/α)/x² dx = −(1/x) arctan(x/α) − (1/(2α)) ln((α² + x²)/x²).
494. ∫ arctan(x/α)/x^n dx = −(1/((n−1)x^{n−1})) arctan(x/α) + (α/(n−1)) ∫ dx/(x^{n−1}(α² + x²)).

495. ∫ arccot(x/α) dx = x arccot(x/α) + (α/2) ln(α² + x²).
496. ∫ x arccot(x/α) dx = (1/2)(x² + α²) arccot(x/α) + αx/2.
497. ∫ x² arccot(x/α) dx = (x³/3) arccot(x/α) + αx²/6 − (α³/6) ln(α² + x²).   ← 源转写为 x³/α
498. ∫ x^n arccot(x/α) dx = x^{n+1}/(n+1) · arccot(x/α) + (α/(n+1)) ∫ x^{n+1} dx/(α² + x²),  n ∈ ℕ.
499. ∫ arccot(x/α)/x dx = (π/2) ln x − x/α + x³/(3²α³) − x⁵/(5²α⁵) + … .
500. ∫ arccot(x/α)/x² dx = −(1/x) arccot(x/α) + (1/(2α)) ln((α² + x²)/x²).
```

## 结构特征

- arctan 组与 arccot 组互为补充：符号在 αx 项与 ln 项上翻转，来自 arctan u + arccot u = π/2。
- 491 与 494 互为反方向的递推（一个升幂、一个降幂）；498 与 501 号的关系由源中「参看第 501 个积分」标出，而 501 不在本部分范围内。
- 492、499 的级数交替出现，与[[幂级数展开表]]中 arctan 的展开式一致。
- 481、486、499 的级数收敛域为 |x| < |α|，与含 √(α²−x²) 条目的定义域不同。

## 已知疑点

486 的 π/x、497 的 x³/α、498 对 501 的引用，以及 493、500 的对数形式核对，均见 [[095节公式转写疑误汇总]]。
