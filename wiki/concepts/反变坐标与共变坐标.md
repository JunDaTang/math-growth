# 反变坐标与共变坐标

在 1.8.3 节的一般坐标系框架下，一个向量 $a$ 相对于原基 $e_1, e_2, e_3$ 与 [[对偶基]] $e^1, e^2, e^3$ 有两套分解：

```latex
a = a^1 e_1 + a^2 e_2 + a^3 e_3   （a^1, a^2, a^3 为反变坐标）
a = a_1 e^1 + a_2 e^2 + a_3 e^3   （a_1, a_2, a_3 为共变坐标）
```

本手册给出的一般坐标系下的乘积公式为

```latex
a b = a_1 b^1 + a_2 b^2 + a_3 b^3,

a × b = (e_1 e_2 e_3) | e^1  e^2  e^3 |
                      | a^1  a^2  a^3 |
                      | b^1  b^2  b^3 |

(a b c) = (e_1 e_2 e_3) | a^1  a^2  a^3 |
                        | b^1  b^2  b^3 |
                        | c^1  c^2  c^3 |
```

即：标量积用「一方的共变坐标 × 另一方的反变坐标」求和；向量积与三重积则既用反变坐标，又乘以三重积 $(e_1 e_2 e_3)$。

在 [[笛卡儿坐标系]] 中 $a_j = a^j\ (j = 1, 2, 3)$，此情形反变坐标与共变坐标相等。
