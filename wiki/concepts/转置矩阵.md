# 转置矩阵

设给定实或复 `m × n` 矩阵 `A = (a_jk)`。A 的**转置矩阵** `A^T` 是将 A 的各行和各列互换所得的矩阵。若用 `a_jk^T` 表示 `A^T` 的元素，则

```
a_kj^T := a_jk,        k = 1,...,n,  j = 1,...,m
```

因此 `A^T` 是 `n × m` 矩阵。

来源例 8：

```
A := ( 1 2 3i )     A^T = ( 1  4 )
     ( 4 5  6 )            ( 2  5 )
                            ( 3i 6 )
```

## 性质

对于所有的实数或复数 `α` 和 `β`：

```
(A^T)^T = A
(αA + βB)^T = αA^T + βB^T
(CD)^T = D^T C^T
(Q^{-1})^T = (Q^T)^{-1}
```

前置假设：A 和 B 有相同的行数和列数；矩阵乘积 CD 存在（要求 C 和 D 相配）；Q 的逆矩阵 `Q^{-1}` 存在（要求 `det Q ≠ 0`），此时 `Q^T` 的逆矩阵也存在。

## 关联

- 取复共轭后再转置得到 [[伴随矩阵]]。
- `(Q^{-1})^T` 称为 Q 的 [[逆步矩阵]]。
- `tr A^T = tr A`，见 [[矩阵的迹]]。
