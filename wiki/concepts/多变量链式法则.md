# 多变量链式法则（表 0.38）

表 0.38 是《数学指南——实用数学手册》0.8.3 节的核心表格，标题为「链式法则」，结构上用两行分别给出全微分与链式法则：

$f = f(x,y)$，$f_x := \frac{\partial f}{\partial x}$，$f_y := \frac{\partial f}{\partial y}$

| 名称 | 公式 |
|---|---|
| 全微分 | $\mathrm{d}f = f_x\mathrm{d}x + f_y\mathrm{d}y$ |
| 链式法则 | $\frac{\partial f}{\partial w} = f_x\frac{\partial x}{\partial w} + f_y\frac{\partial y}{\partial w}$ |

## 手册的补充说明

表下脚注指出：在链式法则中把 $x = x(w, \cdots)$、$y = y(w, \cdots)$ 看成是 $w$ 以及（可能还有）其他变量的函数。随后手册把法则推广到 $n$ 元函数：

$$\frac{\partial f}{\partial w} = f_{x_1}\frac{\partial x_1}{\partial w} + \cdots + f_{x_n}\frac{\partial x_n}{\partial w}$$

并给出一个重要的特殊化步骤：**如果 $x_1, \cdots, x_n$ 只是 $w$ 的函数**，则用 $\frac{\mathrm{d}}{\mathrm{d}w}$ 代替 $\frac{\partial}{\partial w}$，得到

$$\frac{\mathrm{d}f}{\mathrm{d}w} = f_{x_1}\frac{\mathrm{d}x_1}{\mathrm{d}w} + \cdots + f_{x_n}\frac{\mathrm{d}x_n}{\mathrm{d}w}$$

这一「偏导退化为全导」的替换在例子中起到了关键作用，也是连接多变量与单变量微分法则的桥梁。

## 应用中还原出的一元法则

- **例 5**：$f(t) := x(t)y(t)$，由 $\mathrm{d}f = y\,\mathrm{d}x + x\,\mathrm{d}y$ 得 $f'(t) = y(t)x'(t) + x(t)y'(t)$——即乘积法则。
- **例 6**：$f(t) := \frac{x(t)}{y(t)}$，由 $\mathrm{d}f = y^{-1}\mathrm{d}x - xy^{-2}\mathrm{d}y$ 得 $\frac{x'(t)y(t) - x(t)y'(t)}{y(t)^{2}}$——即商法则。

手册由此明确指出：可以把乘积法则看成是多变量函数链式法则的特例。该结论记录为 [[乘积法则是多变量链式法则的特例]]。
