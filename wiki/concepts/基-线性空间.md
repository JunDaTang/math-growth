# 基（线性空间）

设 $\dim X < \infty$。2.3.2 节定义：K 上的线性空间 X 中的一组元素 $b_1,\dots,b_n$ 称为 X 的基，如果每个元素 $u \in X$ 可以唯一地写成

```text
u = α₁b₁ + … + αₙbₙ,   α₁, …, αₙ ∈ K
```

此时称 $\alpha_1,\dots,\alpha_n$ 为 u 关于这个基的坐标。

例：$\mathbb{R}^n$ 的基可取 $\boldsymbol{b}_1 := (1,0,\dots,0),\dots,\boldsymbol{b}_n := (0,\dots,0,1)$；次数小于 n 的多项式空间可取基 $1,x,x^2,\dots,x^{n-1}$。相关定理见 [[基定理]]、[[施泰尼茨基交换定理]]；基的选取与算子的关系见 [[相伴矩阵与基变换]]。
