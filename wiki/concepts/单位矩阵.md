# 单位矩阵

来源首先以 `3 × 3` 方阵为例给出单位矩阵：

```
E := ( 1 0 0 )
     ( 0 1 0 )
     ( 0 0 1 )
```

类似地，`n × n` **单位矩阵**定义为主对角线元素为 1、其余元素为 0 的 `n × n` 方阵。

## 在运算中的作用

对 `A ∈ Mat(n,n)`：`AE = EA = A`，即 E 是环 `Mat(n,n)` 的乘法单位元。见 [[矩阵乘法]] 与 [[矩阵环与矩阵代数]]。

## 与逆矩阵的关系

[[逆矩阵]] `A^{-1}` 正是满足 `A A^{-1} = A^{-1} A = E` 的唯一矩阵，其存在当且仅当 `det A ≠ 0`。
