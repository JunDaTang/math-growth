# 单变量微分法则（表 0.37）

表 0.37 是《数学指南——实用数学手册》0.8.2 节列出的六条单变量微分法则，全部以 [[莱布尼茨记号]] 书写。

## 六条法则

| 法则 | 公式 |
|---|---|
| 加法法则 | $\frac{\mathrm{d}(f+g)}{\mathrm{d}x} = \frac{\mathrm{d}f}{\mathrm{d}x} + \frac{\mathrm{d}g}{\mathrm{d}x}$ |
| 与常数的乘积法则 | $\frac{\mathrm{d}(Cf)}{\mathrm{d}x} = C\frac{\mathrm{d}f}{\mathrm{d}x}$（$C$ 为常数） |
| 乘积法则 | $\frac{\mathrm{d}(fg)}{\mathrm{d}x} = \frac{\mathrm{d}f}{\mathrm{d}x}g + f\frac{\mathrm{d}g}{\mathrm{d}x}$ |
| 商法则 | $\frac{\mathrm{d}\left(\frac{f}{g}\right)}{\mathrm{d}x} = \frac{\frac{\mathrm{d}f}{\mathrm{d}x}g - f\frac{\mathrm{d}g}{\mathrm{d}x}}{g^{2}}$ |
| 链式法则 | $\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}z}\frac{\mathrm{d}z}{\mathrm{d}x}$ |
| 反函数法则 | $\frac{\mathrm{d}x}{\mathrm{d}y} = \frac{1}{\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)}$ |

## 成立条件

手册脚注指出：1.4 节介绍了这些公式成立所需要的具体假设条件；这些法则对具有一个实变量或复变量的函数成立，且 0.8.2 节的例 1～例 6 对复变量 $x$ 也成立。这是一条重要的适用范围声明：微分法则本身不区分实分析与复分析。

## 例题体系

0.8.2 节用六个例题逐条演示法则的用法，所有例题都只是把表 0.35（[[一阶导数表]]）的条目与法则组合：

- **例 1**（加法法则）：$(\mathrm{e}^{x}+\sin x)'$、$(x^{2}+\sinh x)'$、$(\ln x+\cos x)'$。
- **例 2**（常数倍法则）：$(2\mathrm{e}^{x})'$、$(3\sin x)'$、$(3x^{4}+5)'$。
- **例 3**（乘积法则）：$(x\mathrm{e}^{x})' = (1+x)\mathrm{e}^{x}$、$(x^{2}\sin x)'$、$(x\ln x)' = \ln x + 1$。
- **例 4**（商法则）：$(\tan x)' = \frac{1}{\cos^{2} x}$，并由此确认 $\tan$ 的导数存在范围恰为分母 $\cos x$ 的非零点集 $x \neq k\pi + \frac{\pi}{2}$。
- **例 5、例 6**（链式法则）：$y = \sin 2x$ 与 $y = \cos(3x^{4}+5)$，后者结果 $-12x^{3}\sin(3x^{4}+5)$ 在 0.8.3 节被再次用作偏导数的对照例。
- **反函数法则的应用**：由 $y = \mathrm{e}^{x}$ 与 $x = \ln y$ 互为反函数，导出 $\frac{\mathrm{d}\ln y}{\mathrm{d}y} = \frac{1}{y}$，见 [[反函数法则导出对数函数的导数]]。

## 与其他页面的关系

- 与 [[多变量链式法则]] 的关系：0.8.3 节的例 5、例 6 表明乘积法则与商法则都是多变量链式法则的特例，见 [[乘积法则是多变量链式法则的特例]]。
