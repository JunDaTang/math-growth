# 概率密度与分布函数

## 定义

《数学指南——实用数学手册》6.1.4 节给出连续型模型。设 $\varphi : \mathbb{R} \to \mathbb{R}$ 为连续（或更一般地，几乎处处连续）函数，满足规范化条件

```
∫_{−∞}^{∞} φ dx = 1
```

并设 $X$ 为由某些实数值测量结果确定的随机测量变量（如人的身高）。规定

```
P(a ≤ X ≤ b) := ∫_a^b φ(x) dx
```

称 $\varphi$ 为 $X$ 的**概率密度**，称

```
Φ(x) := ∫_{−∞}^{x} φ(ξ) dξ,  x ∈ ℝ
```

为由 $\varphi$ 确定的**分布函数**。直观地说，$P(a \leqslant X \leqslant b)$ 相当于以曲线 $\varphi$ 为顶、以区间 $[a,b]$ 为底的图形面积（图 6.1(a)），而 $\Phi$ 是相应的累积面积（图 6.1(b)）。

## 二维情形

6.1.5 节把模型推广到随机向量 $(X,Y)$：设 $\varphi : \mathbb{R}^2 \to \mathbb{R}$ 几乎处处连续且非负，满足

```
∫∫_{ℝ²} φ(x,y) dx dy = 1
```

则

```
P((X,Y) ∈ G) := ∫∫_G φ(x,y) dx dy
```

称 $\varphi$ 为随机向量 $(X,Y)$ 的概率密度，边缘密度为

```
φ_X(x) := ∫_{−∞}^{∞} φ(x,y) dy,   φ_Y(y) := ∫_{−∞}^{∞} φ(x,y) dx
```
