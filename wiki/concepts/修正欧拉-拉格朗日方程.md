# 修正欧拉-拉格朗日方程

**修正欧拉-拉格朗日方程**指 5.1.6 节中把[[concepts/修正拉格朗日函数]] $\mathscr{L}$ 代入欧拉-拉格朗日方程所得到的方程 (5.41)：

```latex
\boxed{\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k} - \mathscr{L}_{q_k} = 0,\quad k = 1,\dots,K.}\tag{5.41}
```

原始定义中脚注 1) 给出其显式写法：

```latex
\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k}(q(t), q'(t), t)
- \mathscr{L}_{q_k}(q(t), q'(t), t) = 0.
```

## 与普通欧拉-拉格朗日方程的关系

从形式上看，(5.41) 与 [[concepts/欧拉-拉格朗日方程]] 相同，区别只在于被求偏导的函数由 $L$ 换为 $\mathscr{L}$。因此带约束问题在形式上被化归为无约束问题，代价是引入了额外的未知函数（或常数）$\lambda_k$。

原文相应表述为「并在欧拉-拉格朗日方程中用 L 代替 L」；由于句中两个符号在源文本中完全相同，此处应理解为「用 $\mathscr{L}$ 代替 $L$」，见 [[queries/516节用花体L代替L表述讹误]]。

## 指标范围

(5.41) 的指标写作 $k=1,\dots,K$，即与约束个数 $K$ 对应；但待求函数 $q=(q_1,\cdots,q_F)$ 有 $F$ 个分量，方程通常应对全部分量列出，即 $k=1,\dots,F$。这一差异见 [[queries/516节修正欧拉-拉格朗日方程索引k范围是否为F]]。
