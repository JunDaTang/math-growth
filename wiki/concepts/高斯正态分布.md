# 高斯正态分布 N(μ,σ)

## 定义

《数学指南——实用数学手册》6.1.4 节：高斯正态分布 $N(\mu,\sigma)$ 的概率密度为

```
φ(x) := (1/(σ√(2π))) e^{−(x−μ)²/(2σ²)},  x ∈ ℝ
```

其中参数 $\mu, \sigma$ 均为实数，且 $\sigma > 0$（图 6.2）。对于这种分布，

```
X̄ = μ,   ΔX = σ
```

即参数 $\mu$ 就是均值，参数 $\sigma$ 就是标准差。

## 本节中的出现位置

1. **6.1.3 节**：(6.5) 右边的函数即此密度，其参数为 $\mu = n/2$、$\sigma = \sqrt{n/4}$，由此给出 [[concepts/棣莫弗极限定理]]。
2. **6.1.4 节**：作为连续型分布的标准例，并列入表 6.3。
3. **6.1.5 节**：二维形式为两个一维正态密度的乘积

```
φ(x,y) := (1/(σ_x√(2π))) e^{−(x−μ_x)²/(2σ_x²)} · (1/(σ_y√(2π))) e^{−(y−μ_y)²/(2σ_y²)}
```

它相应于两个相互独立随机变量 $X$ 和 $Y$ 的联合分布，且 $(\Delta(X+Y))^2 = \sigma_x^2 + \sigma_y^2$。
4. **6.1.6 节**：[[concepts/麦克斯韦速度分布]] 中动量的一个分量 $mv$ 服从均值 0、标准差 $\sqrt{mkT}$ 的正态分布。

## 为何重要

文中指出：「正态分布是概率论中最重要的分布。这是因为根据中心极限定理，任何随机变量，只要它是由大量相互独立的随机变量叠加而成的，那么它就近似服从正态分布（见 6.2.4）。」该段为对 6.2.4 节的前向引用。
