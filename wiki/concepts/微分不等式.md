# 微分不等式

**微分不等式**是《数学指南——实用数学手册》1.12.9.5 节的工具：把满足不等式的一支解与满足等式的比较解作对比，从而得出解的上下界。

## 陈述（源文）

考虑方程组 (1.320)：

```text
x'(t) ≤ f(x(t)),   在 J 上,
y'(t) = f(y(t)),   在 J 上,
x(0) ≤ y(0),
```

其中 $J:=[0,T]$，并且 $f$ 是 $C^1$ 型的**严格单调增函数**。

定理：如果 $x$ 和 $y$ 是满足 (1.320) 的 $C^1$ 函数，且在 $J$ 上 $x(t)\ge 0$，那么

```text
x(t) ≤ y(t),   在 J 上.
```

推论：如果 $x$ 和 $y$ 满足 $x'(t)\ge f(x(t))$（在 $J$ 上）、$y'(t)=f(y(t))$（在 $J$ 上）、$0\le y(0)\le x(0)$，并且在 $J$ 上 $x(t)\ge 0$，那么 $0\le y(t)\le x(t)$ 在 $J$ 上成立。

## 例题（源文）

令 $x=x(t)$ 是 $x'(t)=F(x(t))$、$x(0)=0$ 的一个解，其中对所有 $x\in\mathbb{R}$ 有 $F(x)\ge 1+x^2$。那么

```text
x(t) ≥ tan t,   0 ≤ t ≤ π/2,
```

并且因而 $\lim_{t\to\pi/2-0}x(t)=+\infty$。证明取 $f(y):=1+y^2$、$y(t):=\tan t$，由 $y'(t)=1+y^2$ 及上述推论即得。

## 作用与关联

- 该定理是「比较原理」在一维、严格单调增右端下的形式。
- 源文末尾指出，先验估计也可以借助微分不等式获得（1.12.9.8），因此本概念与 [[concepts/先验估计原理]]、[[concepts/格朗沃尔引理]] 构成同一工具族。
- 上述例题给出的是**破裂下界**：解至少不慢于 $\tan t$ 地趋于无穷，可与 [[concepts/有限时间爆炸]] 对照。
