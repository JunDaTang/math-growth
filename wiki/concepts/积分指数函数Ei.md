# 积分指数函数 Ei(x)

## 定义（源文表述）

表 0.9.5 的 420 号条目在给出 ∫ e^{αx}/x dx 的级数展开后，定义：

```latex
广义积分 ∫_{−∞}^{x} e^t/t dt 称为积分指数函数，记为 Ei(x)。
当 x > 0 时，该积分在 t = 0 处发散，此时 Ei(x) 是这个广义积分的主值
（参看 0.5.5 和 0.7.2）。

∫_{−∞}^{x} e^t/t dt = C + ln x + x/(1·1!) + x²/(2·2!) + x³/(3·3!) + … + x^n/(n·n!) + …
（C 为欧拉常数，参看 0.1.1）
```

## 要点

- 定义域：t = 0 是被积函数 e^t/t 的极点，因而 x > 0 时须取[[广义积分的主值]]；x < 0 时积分路径不跨越 t = 0，可直接理解。
- 与[[欧拉常数]]的关系：展开式中的常数项 C 即欧拉常数，故 Ei 不是「不含自由常数」的初等对象。
- 与 ∫ e^{αx}/x dx 的关系：420 号给出的 α = 1 情形与 Ei 只差常数，故 ∫ e^{αx}/x dx 同样不能表为初等函数。
- 与其他条目的连接：427（∫ e^{αx} ln x dx）与 456 都把问题归约到 420，即归约到 Ei。
