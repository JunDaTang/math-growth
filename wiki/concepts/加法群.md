# 加法群

**加法群**是集合 $G$ 带一个运算，使每个有序对 $(g,h)$ 存在和 $g+h\in G$，满足：

```
(i)   g + (h + k) = (g + h) + k        (结合律)
(ii)  存在唯一 0，使 0 + g = g + 0 = g (中性元素)
(iii) 对每个 g 存在唯一 -g，使 (-g) + g = g + (-g) = 0  (逆元素)
(iv)  g + h = h + g                    (交换律)
```

因此，加法群与"群运算写作 $+$、中性元素写成 $0$ 的交换群"没有差别。

## 例

- 所有实数 $\mathbb{R}$ 关于通常加法是加法群，整数集 $\mathbb{Z}$ 是 $\mathbb{R}$ 的加法子群。
- 每个线性空间是一个加法群。
- 整数加法群 $\mathbb{Z}$ 是无限循环的 [[concepts/循环群]]，由 1 生成。

有限生成加法群的分类见 [[concepts/加法群的主定理]]；[[concepts/环]] 的加法部分即加法群。
