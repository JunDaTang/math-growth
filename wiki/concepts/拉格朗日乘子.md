# 拉格朗日乘子

**拉格朗日乘子**（Lagrange multiplier）是在带约束的极小化问题中引入的辅助未知量 $\lambda_{k}=\lambda_{k}(t)$，用来把约束并入目标泛函，从而把约束极值问题化成无约束的欧拉-拉格朗日型方程问题。

## 在变分问题中的形式

对 5.1.6 节的问题提法 (5.38)：

```latex
\boxed{\begin{array}{c}
  \int_{t_0}^{t_1} L(q(t), q'(t), t)\,\mathrm{d}t \stackrel{!}{=} \min, \\
  q(t_0) = a,\quad q(t_1) = b,
\end{array}}\tag{5.38}
```

满足约束 (5.39) 或 (5.40) 时，乘子 $\lambda_k$ 出现在[[concepts/修正拉格朗日函数]]

```latex
\mathscr{L} := L + \sum_{k=1}^{K} \lambda_k(t) N_k
```

以及[[concepts/修正欧拉-拉格朗日方程]]

```latex
\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k} - \mathscr{L}_{q_k} = 0,\quad k = 1,\dots,K.\tag{5.41}
```

之中。求解目标是联立 (5.41)、约束条件与边界条件，确定 $q_k=q_k(t)$ 与 $\lambda_k=\lambda_k(t)$。

## 乘子为函数还是实数

乘子的类型取决于约束的类型：

- 对**积分约束**（等周约束）(5.39)：$\int_{t_0}^{t_1} N_k\,\mathrm{d}t = \text{常数}$，乘子是**实数**，而非函数。
- 对**隐约束**（微分约束）(5.40)：$N_k\,\mathrm{d}t = 0$ 在 $[t_0,t_1]$ 上，乘子一般取为**函数** $\lambda_k(t)$（修正拉格朗日函数 $\mathscr{L}$ 中即以 $\lambda_k(t)$ 的形式出现）。

## 存在性

乘子的存在性由 5.1.6 节的**主定理**保证：设 $q=q(t)$ 是带约束 (5.39) 或 (5.40) 的极小化问题 (5.38) 的 $C^{2}$ 解，且不是线性情形，则存在充分光滑的拉格朗日乘子 $\lambda_k$ 使 (5.41) 成立。其中「不是线性情形」是防止约束退化的正则性条件，见 [[concepts/不是线性情形约束规范]]。
