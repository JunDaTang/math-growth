# 不定式

《数学指南——实用数学手册》1.3.1.3 节以洛必达法则为中心，列举了可由该法则及 $a^x = \mathrm{e}^{x\ln a}$ 处理的不定式类型：

```
0/0,   ∞/∞,   0·∞,   ∞−∞,   0^0,   ∞^0,   0^∞
```

处理思路：

- $\frac{0}{0}$、$\frac{\infty}{\infty}$：直接应用 [[洛必达法则]] 式 (1.28)。
- $0 \cdot \infty$：改写为 $\frac{\infty}{\infty}$ 型后应用洛必达法则（例 4：$\lim_{x\to+0} x\ln x = 0$）。
- $\infty - \infty$：转化为 $\infty \cdot a$ 型（$a$ 为有限值）（例 5：$\lim_{x\to+\infty}(\mathrm{e}^x - x) = +\infty$）。
- $0^0$、$\infty^0$、$0^\infty$：借助恒等式 $a^x = \mathrm{e}^{x\ln a}$，把幂型化为指数型后处理（例 6：$\lim_{x\to+\infty} x^{1/x} = 1$）。

这些结论与 [[函数的数量级]] 中「$\mathrm{e}^x$ 比任何幂函数增长得快」互为印证。
