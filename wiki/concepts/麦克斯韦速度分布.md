# 麦克斯韦速度分布

## 陈述

《数学指南——实用数学手册》6.1.6 节「对麦克斯韦速度分布的应用」：考虑由 $N$ 个质量为 $m$ 的粒子组成的、在 $\mathbb{R}^{3}$ 的有界区域 $\Omega$ 中运动的理想气体，$V$ 表示 $\Omega$ 的体积。第 $j$ 个粒子用坐标向量 $x_j = x_j(t)$ 和动量向量

```
p_j(t) = m x_j′(t)
```

描述，其中 $x_j'(t)$ 是粒子在时刻 $t$ 的速度。若 $v$ 表示在笛卡儿坐标系中第 $j$ 个粒子速度向量的任意一个分量，则

```
P(a ≤ mv ≤ b) = ∫_a^b (1/(σ√(2π))) e^{−x²/(2σ²)} dx        (6.8)
```

这是 $mv$ 落入区间 $[a,b]$ 的概率。相应的概率分布是均值

```
mv 的均值 = 0
```

标准差

```
Δ(mv) = σ = √(mkT)
```

的高斯正态分布。

## 历史定位

文中写道：「这条定律是麦克斯韦在 1860 年确立的。他利用这条定律为玻尔兹曼建立统计力学奠定了基础。」

## 推导思路

在笛卡儿坐标系中令 $p_1 = p_1 i + p_2 j + p_3 k$，$p_2 = p_4 i + p_5 j + p_6 k$，$\dots$，以及 $x_1 = q_1 i + q_2 j + q_3 k$，$\dots$。理想气体粒子之间没有相互作用，因此总能量为各粒子动能之和：

```
E = p_1²/(2m) + … + p_N²/(2m) = Σ_{j=1}^{3N} p_j²/(2m)
```

例如考虑 $p_1 = mv$，由 (6.7) 有

```
P(a ≤ p_1 ≤ b) = C ∫_a^b exp(−p_1²/(2mkT)) dp_1 · J
```

其中 $J$ 由对 $p_2 \cdots p_{3N}$ 从 $-\infty$ 到 $\infty$ 的积分以及关于坐标 $q_j$ 的积分得到；$CJ$ 的值由规范化条件 $P(-\infty < p < \infty) = 1$ 求出。这样就得到 (6.8)。
