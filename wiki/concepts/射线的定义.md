# 射线的定义

《数学指南——实用数学手册》3.2.5 节给出的射线定义（图 3.21(e), (f)）先引入「同一边 / 不同边」：

> 设 A, B, C 和 D 为在一条直线 $l$ 上的四个不同点，其中 C 在 A 和 D 之间但不在 A 与 B 之间，我们则说点 A 和 B 位于 C 的同一边，而 A 和 D 在 C 的不同边.

随后定义射线：

> 在 C 的一边的所有点的集合被称为一条射线.

该定义依赖 [[concepts/次序公理]]，并直接用于 [[concepts/角的定义]]；其后由公理推出的 [[findings/由一条直线对平面的分解定理]] 把它推广到直线对平面的划分。
