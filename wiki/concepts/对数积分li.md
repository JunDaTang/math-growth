# 对数积分 li(x)

## 定义（源文表述）

表 0.9.5 的 438 号条目在给出 ∫ dx/ln x 的级数展开后，定义：

```latex
438. ∫ dx/ln x = ln ln x + ln x + (ln x)²/(2·2!) + (ln x)³/(3·3!) + … .

积分 ∫ dt/ln t 称为对数积分，记为 li(x)。当 x > 1 时，它在点 t = 1 处发散。
此时，函数 li(x) 的值是这个广义积分的主值（参看 0.5.5 和 0.7.2）。
```

## 要点

- 奇点：t = 1 是 1/ln t 的极点，因此当上限超过 1 时须取[[广义积分的主值]]，与 0.5.5、0.7.2 的约定一致。
- 与 438 的级数：展开式正确表达了 li(x) 在小 x（0 < x < 1 一侧）附近的展开；积分常数在源中被省去。
- 转写疑点：源文把该广义积分写作 ∫_0^∞ dt/ln t，但 li(x) 应是上限为 x 的积分（标准写法为 PV ∫_0^x dt/ln t，或等价地以 t = 2 为起点的形式）。上限 ∞ 与「li(x) 依赖 x」矛盾，疑为转写脱漏，见 [[095节公式转写疑误汇总]]。
- 与 Ei 的关系：令 t = e^u 即可把 li 与 [[积分指数函数Ei]] 联系起来，二者在数论中的经典应用（素数分布）不属本手册本节的讨论范围。
