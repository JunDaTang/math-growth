# 对偶基

设 $e_1, e_2, e_3$ 是任意三个线性无关向量，本手册 1.8.3 节称下面三个向量构成的集合为基 $e_1, e_2, e_3$ 的**对偶基**：

```latex
e^1 := (e_2 × e_3) / (e_1 e_2 e_3),
e^2 := (e_3 × e_1) / (e_1 e_2 e_3),
e^3 := (e_1 × e_2) / (e_1 e_2 e_3).
```

构造中用到 [[向量积]] 与 [[三重积]] $(e_1 e_2 e_3)$，因此要求 $e_1, e_2, e_3$ 线性无关（即三重积非零）。

有了对偶基，每个向量 $a$ 有唯一分解式

```latex
a = a^1 e_1 + a^2 e_2 + a^3 e_3   及   a = a_1 e^1 + a_2 e^2 + a_3 e^3,
```

前者的系数称为**反变坐标**，后者的系数称为**共变坐标**，见 [[反变坐标与共变坐标]]。

在 [[笛卡儿坐标系]] 这一特例中 $i = e_1 = e^1$、$j = e_2 = e^2$、$k = e_3 = e^3$，即基与其对偶基重合。
