# 可解群

群 $G$ 称为**可解群**，当且仅当存在子群序列（$G_0=\{e\}$）

$$
G_0\subseteq G_1\subseteq\dots\subseteq G_{n-1}\subseteq G_n:=G
$$

且对每个 $j$：

```
G_j 是 G_{j+1} 的正规子群，且商群 G_{j+1}/G_j 是交换的
```

## 例

- 每个交换群可解。
- $\mathcal{S}_2$ 可解（交换）。
- $\mathcal{S}_3$ 可解，链为 $\{e\}\subseteq\mathcal{A}_3\subseteq\mathcal{S}_3$。
- $\mathcal{S}_4$ 可解，链为 $\{e\}\subseteq\mathcal{K}_4\subseteq\mathcal{A}_4\subseteq\mathcal{S}_4$。商群的阶为 $\operatorname{ord}\mathcal{A}_3=3$、$\operatorname{ord}(\mathcal{S}_3/\mathcal{A}_3)=2$、$\operatorname{ord}(\mathcal{A}_4/\mathcal{K}_4)=3$，皆为素数，故对应商群是循环群从而交换。
- 对 $n\ge5$，$\mathcal{S}_n$ 不可解，因 $\mathcal{A}_5$ 是 [[concepts/单群]]。

由 [[concepts/伽罗瓦理论]]，这些结论构成次数 $\ge5$ 的代数方程不可用根式解出的依据（见 2.6.5）。
