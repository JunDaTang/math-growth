# 斯特林公式

《数学指南——实用数学手册》在三个不同位置给出斯特林公式的写法与用法，它们在**误差项的处理**和**历史表述**上各不相同，下面按来源分别标明。

## 阶乘的渐近形式

### 0.1 节给出的形式

$$
n! = \left(\frac{n}{\mathrm{e}}\right)^{n} \sqrt{2\pi n}
$$

- 手册将其定位为对天文数字级阶乘"很好的近似"：统计物理学中需要 $n$ 为 $10^{23}$ 左右时的 $n!$。
- 这是大 $n$ 的渐近结果：手册正文明确称之为"近似"，虽以等号框出，但不应理解为精确等式，也不应外推到小 $n$。
- 公式同时涉及本节的多个常数：e 与 π（见 [[初等数学常数]]）。

### 6.2.5 节给出的形式（棣莫弗的近似与常数 $C$）

为证明 [[棣莫弗-拉普拉斯局部极限定理]]（即 (6.20) 两边商的极限为 1），居住在伦敦的 [[棣莫弗]]（de Moivre, 1667—1754）在 $n$ 的值很大时使用了近似公式

```
n! = C √n (n/e)^n,   n → ∞ ;        (6.21)
```

其中 $C$ 的值近似为 $C \approx 2.5047$。

当棣莫弗向 [[斯特林]]（Stirling, 1692—1770）寻求帮助时，**斯特林发现 $C$ 的精确值为**

```
C = √(2π)。
```

原文随即指出：相应公式 (6.21) 称为斯特林公式。

> 注意：0.1 节把 $\sqrt{2\pi n}(n/\mathrm{e})^n$ 直接作为"近似"给出；6.2.5 节则记录了它作为 (6.21) 的历史来路——先由棣莫弗以近似常数 $C \approx 2.5047$ 使用，后由斯特林定出 $C = \sqrt{2\pi}$ 的精确值。

### 1.14.16 节给出的形式（带误差项）

特别地，对 $n = 1, 2, \dots$，

$$\boxed{n! = \sqrt{2\pi n}\left(\frac{n}{\mathrm{e}}\right)^{n} \mathrm{e}^{\,\theta(n)/12n}.}$$

该形式给出了阶乘的经典渐近估计，公式以[[斯特林]]命名。注意其与 0.1 节形式的区别：这里显式保留了误差因子 $\mathrm{e}^{\theta(n)/12n}$（$0 < \theta(n) < 1$），因而对每个正整数 $n$ 成立，而非 0.1 节那种省略误差项的近似等式。

## 欧拉伽马函数形式

《数学指南——实用数学手册》1.14.16 节给出[[欧拉伽马函数]]的渐近估计：对每个正实数 $x$，存在满足 $0 < \theta(x) < 1$ 的数 $\theta(x)$，使

$$\Gamma(x+1) = \sqrt{2\pi}\, x^{\,x+1/2} \mathrm{e}^{-x} \mathrm{e}^{\,\theta(x)/12x}.$$

## 复变量模估计

同节（1.14.16）并给出复变量的模估计：对满足 $\operatorname{Re} z > 0$ 的每个复数 $z$，

$$|\Gamma(z)| \leqslant |\Gamma(\operatorname{Re} z)|.$$

## 应用

### 统计物理（0.1 节）

手册把 0.1 节的形式定位为对天文数字级阶乘"很好的近似"：统计物理学中需要 $n$ 为 $10^{23}$ 左右时的 $n!$。

### 概率论：棣莫弗-拉普拉斯局部极限定理（6.2.5 节）

该公式是二项分布系数 $\binom{n}{k}$ 渐近展开的关键工具：正是它把常数 $\sqrt{2\pi}$ 送入 [[棣莫弗-拉普拉斯局部极限定理]] 的表达式

```
P(A_n = k) ~ (1/(σ√(2π))) e^{−(k−μ)²/(2σ²)},
```

从而使 [[二项分布]] 的正态渐近取得标准正态密度的形式。
