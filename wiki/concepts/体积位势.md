# 体积位势

体积位势是 1.9.9 显式解构造中出现的积分算子，把一个源密度分布 $\rho$ 映为一个标量场 $V$。

## 定义

```
V(x) := ∫_{R^3} ρ(y) dy / (4π|x − y|)
```

其中 $x \in \mathbb{R}^3$，$\mathrm{d}y$ 表示对源点 $y$ 的体积元积分，$|x-y|$ 为场点与源点间的欧氏距离。核 $1/(4\pi|x-y|)$ 是三维 [[拉普拉斯算子]] 的基本解（相差符号），因此体积位势可看作泊松方程 $\Delta V = -\rho$ 的解。

## 使用前提

在 1.9.9 中，体积位势的定义与使用需满足：

- 域取 $D = \mathbb{R}^3$；
- $\rho$ 在 $\mathbb{R}^3$ 上为 $C^3$ 类，并在某一球外为零（保证积分收敛与可微性）。

## 用途

令 $D_{par} := -\operatorname{grad} V$，则

```
div D_par = ρ,  curl D_par = 0,  在 R^3 上.
```

这给出 [[源的规定]] 中的显式特解。

## 与 1.9.5「势」的区别

本节的「体积位势」是积分算子（把源密度变为场），而 1.9.5 中 [[势与势函数]] 指的是满足 $F = -\operatorname{grad} U$ 的反导数函数。二者名称相近、功能不同，参见 [[queries/199节体积位势与195节势函数同名异义]]。
