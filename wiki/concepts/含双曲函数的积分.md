# 含双曲函数的积分

## 概述

表 0.9.5 以 457–477 号共 21 个条目处理含双曲函数的积分。它是三角函数积分组的双曲镜像：457–462 对应 sin/cos 幂，463–469 对应乘积与混合，470–477 对应商型、倒数型与 tanh/coth 型。

## 幂与基本型（457–462）

```latex
457. ∫ sinh αx dx = (1/α) cosh αx.
458. ∫ cosh αx dx = (1/α) sinh αx.
459. ∫ sinh²αx dx = (1/(2α)) sinh αx cosh αx − x/2.
460. ∫ cosh²αx dx = (1/(2α)) sinh αx cosh αx + x/2.
462. ∫ cosh^n αx dx
   = (1/(αn)) sinh αx cosh^{n−1}αx + ((n−1)/n) ∫ cosh^{n−2}αx dx,  n ∈ ℕ, n > 0;
   = −(1/(α(n+1))) sinh αx cosh^{n+1}αx + ((n+2)/(n+1)) ∫ cosh^{n+2}αx dx,  n ∈ ℤ, n < −1.
```

462 的两个分支方向相反，是本表中参数条件影响归约方向的典型例子。461 号在源中只给出被积式 ∫ sinh²αx dx 而无结果，疑为 459 的重复，见 [[095节公式转写疑误汇总]]。

## 乘积与混合型（463–469）

```latex
463. ∫ sinh αx sinh βx dx = (α sinh βx cosh αx − β cosh βx sinh αx)/(α² − β²),  α² ≠ β².
464. ∫ cosh αx cosh βx dx = (α sinh αx cosh βx − β sinh βx cosh αx)/(α² − β²),  α² ≠ β².
465. ∫ cosh αx sinh βx dx = (α sinh βx sinh αx − β cosh βx cosh αx)/(α² − β²),  α² ≠ β².
466. ∫ sinh αx sin αx dx = (1/(2α))(cosh αx sin αx − sinh αx cos αx).
467. ∫ cosh αx cos αx dx = (1/(2α))(sinh αx cos αx + cosh αx sin αx).
468. ∫ sinh αx cos αx dx = (1/(2α))(cosh αx cos αx + sinh αx sin αx).
469. ∫ cosh αx sin αx dx = (1/(2α))(sinh αx sin αx − cosh αx cos αx).
```

466–469 是双曲函数与三角函数的混合积分，结果均由双曲—三角配对项组成。

## 商型与 tanh/coth（470–477）

```latex
470. ∫ dx/sinh αx = (1/α) ln tanh(αx/2).
471. ∫ dx/cosh αx = (2/α) arctan e^{αx}.   ← 源转写为 ∫ c x / cosh αx
472. ∫ x sinh αx dx = (1/α) x cosh αx − (1/α²) sinh αx.
473. ∫ x cosh αx dx = (1/α) x sinh αx − (1/α²) cosh αx.
474. ∫ tanh αx dx = (1/α) ln cosh αx.
475. ∫ coth αx dx = (1/α) ln sinh αx.
476. ∫ tanh²αx dx = x − tanh αx/α.
477. ∫ coth²αx dx = x − coth αx/α.
```

470、471 通过 e^{αx} 与对数把双曲倒数积分化为初等形式，与[[含指数函数的积分]]中的 422 号同源。
