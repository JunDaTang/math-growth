# 三角形的四个基本问题

《数学指南——实用数学手册》3.2.1.3 节按已知量的组合，把平面三角形的求解归结为四个基本问题（即解三角形的四种标准情形），并给出每一步所依据的定律。

## 唯一性前提

节首强调：由方程 $\sin\alpha = d$ 不能唯一确定角 α，因为 α 可以是锐角也可以是钝角，而 $\sin(\pi-\alpha)=\sin\alpha$。源中声称下面的方法对第一个和第三个问题给出唯一的角（第二、第四个问题则需附加判别或分情形处理）。

## 问题一：已知边 c 与其两个相邻角 α, β

1. $\gamma = \pi - \alpha - \beta$（[[concepts/和角定律]]）。
2. $a = c\frac{\sin\alpha}{\sin\gamma}$，$b = c\frac{\sin\beta}{\sin\gamma}$（[[concepts/正弦定律]]）。
3. $A = \frac{1}{2}ab\sin\gamma$。

## 问题二：已知边 a, b 与其夹角 γ

1. 由 [[concepts/正切定律]] 唯一算出 $\tan\frac{\alpha-\beta}{2} = \frac{a-b}{a+b}\cot\frac{\gamma}{2}$，其中 $-\frac{\pi}{4} < \frac{\alpha-\beta}{2} < \frac{\pi}{4}$。
2. 由和角公式得 $\alpha = \frac{\alpha-\beta}{2} + \frac{\pi-\gamma}{2}$，$\beta = \frac{\pi-\gamma}{2} - \frac{\alpha-\beta}{2}$。
3. $c = \frac{\sin\gamma}{\sin\alpha}a$。
4. $A = \frac{1}{2}ab\sin\gamma$。

## 问题三：已知三条边 a, b, c

1. 算半周长 $s=\frac{1}{2}(a+b+c)$ 与内切圆半径 $r = \sqrt{\frac{(s-a)(s-b)(s-c)}{s}}$。
2. 角由 $\tan\frac{\alpha}{2} = \frac{r}{s-a}$，$\tan\frac{\beta}{2} = \frac{r}{s-b}$ 唯一确定（$0 < \frac{\alpha}{2}, \frac{\beta}{2} < \frac{\pi}{2}$）。
3. $\gamma = \pi - \alpha - \beta$。
4. 面积 $A = rs$（[[concepts/海伦公式]]）。

## 问题四：已知两边 a, b 与一个对角 α（SSA）

分三种情形，均以 $\sin\beta = \frac{b}{a}\sin\alpha$ (3.8) 为基础：

| 情形 | 原文结论 |
|------|----------|
| $a > b$ | $\beta < 90^{\circ}$，β 由 (3.8) 唯一决定 |
| $a = b$ | 正好有 $\alpha = \beta$ |
| $a < b$ | 若 $b\sin\alpha < a$，(3.8) 给出两个角 β 的解（一锐角一钝角）；原文写作「当 $b\sin\alpha = b$ 时我们有 $\beta = 90^{\circ}$」；若 $b\sin\alpha > a$ 则无满足条件的三角形 |

随后由和角定律定 $\gamma = \pi - \alpha - \beta$，由正弦定律定 $c = \frac{\sin\gamma}{\sin\alpha}a$，面积 $A = \frac{1}{2}ab\sin\gamma$。

第三列中的「$b\sin\alpha = b$」与标准判别式 $b\sin\alpha = a$ 不符，疑为讹误，见 [[queries/321节第四问题SSA判别条件疑似讹误]]。
