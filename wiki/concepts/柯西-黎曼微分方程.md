# 柯西-黎曼微分方程

## 方程形式（源文逐字保留）

设 $f: U \subseteq \mathbb{C} \to \mathbb{C}$，写 $z = x + \mathrm{i}y$（$x, y \in \mathbb{R}$）与

```latex
f(z) = u(x, y) + \mathrm{i} v(x, y),
```

则柯西-黎曼微分方程为

```latex
u_x = v_y, \quad u_y = -v_x \tag{1.453}
```

## 与复可微性的关系（源文主定理）

《数学指南——实用数学手册》1.14.3 节以「柯西(1814) 和黎曼(1851) 的主定理」形式陈述：复值函数 $f: U \subseteq \mathbb{C} \to \mathbb{C}$ 在 $z_0 \in \mathbb{C}$ 处[[复可微与复导数|复可微]]，**当且仅当** $u$ 与 $v$ 在点 $(x_0, y_0)$ 处[[弗雷歇可微]]，并且 (1.453) 在点 $(x_0, y_0)$ 处成立。这时

```latex
f'(z_0) = u_x(x_0, y_0) + \mathrm{i} v_x(x_0, y_0).
```

源文未给出证明。本节指出，柯西-黎曼微分方程正是「复微分与偏微分方程理论之间的联系」的体现。

## 优美形式

引入[[庞加莱微分算子]] $\partial z = \frac{1}{2}(\partial_x - \mathrm{i}\partial_y)$ 与 $\partial \bar z = \frac{1}{2}(\partial_x + \mathrm{i}\partial_y)$ 后，方程 (1.453) 可写成

```latex
\partial \bar z\, f(z_0) = 0.
```

## 相关概念

- [[全纯函数]]：处处满足复可微性（从而处处满足柯西-黎曼方程）的函数。
- [[解析延拓]]：以全纯性为出发点的进一步理论。
- 注意：本条目讨论的是复分析的柯西-黎曼方程组，与常微分方程中的[[柯西定理解析解]]、偏微分方程的[[柯西-柯瓦列夫斯卡娅定理]]是不同的结果，勿混同。
