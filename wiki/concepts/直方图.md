# 直方图

为了得到**测量分布**的一般思想，特别是当测量组很大时，《数学指南——实用数学手册》0.4.1 节采用图示表示，称为直方图。其构造过程分为四步：

(i) 把测量值分成几类 $K_1, K_2, \cdots, K_s$，它们是邻区间。
(ii) 令 $m_r$ 表示类 $K_r$ 中测量值的数目。
(iii) 若记 $n$ 个测量值为 $x_1, \cdots, x_n$，则量 $\frac{m_r}{n}$ 称为类 $K_r$ 的相对测量频率。
(iv) 画出类 $K_j$，其中第 $K_r$ 类所在的矩形的高度 $\frac{m_r}{n}$。

## 要点

- 分箱为**互不重叠的邻区间**（记法上区间取左闭右开，如 $170 \le x < 175$）。
- 矩形高度取**相对测量频率** $\frac{m_r}{n}$（见 [[相对测量频率]]），而非绝对频数 $m_r$，因而各矩形高度之和为 1。
- 手册的例 4 用 100 个人的身高数据（表 0.27）作示范，得到图 0.42。

## 例 4 的分箱数据

| 类 $K_r$ | 测量值 | 频率 $m_r$ | 相对频率 $\frac{m_r}{100}$ |
|---|---|---|---|
| $K_1$ | 150 ≤ x < 165 | 2 | 0.02 |
| $K_2$ | 165 ≤ x < 170 | 18 | 0.18 |
| $K_3$ | 170 ≤ x < 175 | 30 | 0.30 |
| $K_4$ | 175 ≤ x < 180 | 32 | 0.32 |
| $K_5$ | 180 ≤ x < 185 | 16 | 0.16 |
| $K_6$ | 185 ≤ x < 200 | 2 | 0.02 |
