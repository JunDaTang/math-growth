# 单侧极限（左极限与右极限）

在 [[函数极限]] 的序列式定义中，若只考虑满足 $x_n > a$ 的序列 $(x_n)$，得到的极限记为

```
lim_{x→a+0} f(x) = b      （右极限）
```

若只考虑满足 $x_n < a$ 的序列，则得到

```
lim_{x→a-0} f(x) = b      （左极限）
```

其中 $a \in \mathbb{R}$。手册称前者为 $f$ 在点 $a$ 处的**右极限**，后者为**左极限**。

## 典型例子

1.3.1.1 例 3 的分段函数

```
f(x) := 1  (x > a),   2  (x = a),   −1  (x < a)
```

满足 $\lim_{x\to a+0} f(x) = 1$，$\lim_{x\to a-0} f(x) = -1$（图 1.19）。该例说明单侧极限可以不等，且函数在 $a$ 点的取值（2）与两侧极限都无关。

## 与洛必达法则的关系

洛必达法则在 $x \to a+0$（相应地 $x \to a-0$）时有类似表述，此时要求假设 (ii)(iii) 只对满足 $x > a$（相应地 $x < a$）的点 $x \in U$ 成立，见 [[洛必达法则]]。
