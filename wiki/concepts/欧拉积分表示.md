# 欧拉积分表示

《数学指南——实用数学手册》1.14.16 节给出伽马函数的积分表示，作为函数方程 $\Gamma(z+1) = z\Gamma(z)$ 的一个解：

$$\Gamma(x) := \int_{0}^{\infty} \mathrm{e}^{-t} t^{x-1}\,\mathrm{d}t, \quad \text{对满足 } x > 0 \text{ 的所有 } x \in \mathbb{R}. \tag{1.481}$$

由[[欧拉]]给出，故名。

## 定义域与其在复平面上的扩展

源文最初只对正实数 $x > 0$ 陈述该积分。同节「更多的性质」之 (i) 指出：积分表示 (1.481) 对满足 $\operatorname{Re} z > 0$ 的**所有复数 $z$** 都成立。再由[[解析延拓]]，该实值函数可唯一扩展为 $\mathbb{C}$ 上的亚纯函数，即[[欧拉伽马函数]] Γ，其极点为 $z = 0, -1, -2, \cdots$（均为一阶极点）。

## 相关数值

由积分表示可得[[欧拉伽马函数]]的取值：$\Gamma(1) = 1$、$\Gamma(1/2) = \sqrt{\pi}$、$\Gamma(-1/2) = -2\sqrt{\pi}$。
