# 零矩阵

所有元素均为 0 的 `m × n` 矩阵

```
O := ( 0 0 ... 0
       ⋮ ⋮     ⋮
       0 0 ... 0 )
```

称为**零矩阵**，记作 `O`。

## 在运算中的作用

- 对 `A, B, C ∈ Mat(m,n)`：`A + O = A`（加法单位元）。
- 对 `A ∈ Mat(n,n)`：`AO = OA = O`。

## 注意与其他零元的区别

在环 `Mat(n,n)` 中，`AB = O` 并不蕴涵 `A = O` 或 `B = O`，这与实数乘法有本质区别，见 [[零因子-矩阵环]]。
