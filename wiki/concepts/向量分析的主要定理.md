# 向量分析的主要定理

「向量分析的主要定理」（Der Hauptsatz der Vektoranalysis）是 1.9.9 节的最高结论，也是该节的标题所指：向量场由其源、涡以及边界上的法向分量唯一确定。

## 定理陈述

问题

```
div v = ρ  与  curl v = J,  在 D 上,
v n = g,  在 ∂D 上                             (1.173)
```

在 $\bar{D}$ 上有唯一 $C^2$ 类解 $v$，如果满足下列假设：

(i) $D$ 是 $\mathbb{R}^3$ 中有光滑边界的有界区域；$n$ 是边界上的外法线单位向量。

(ii) $\bar{D}$ 上给定的函数 $\rho$ 与 $J$ 足够光滑，并且 $g$ 在 $\partial D$ 上足够光滑。

(iii) 在 $D$ 上有

```
div J = 0
```

和

```
∫_D ρ ds = ∫_{∂D} g dF.
```

条件 (iii) 即 [[相容性条件]]。

## 结构解读

定理把三个数据放在一起：源 $\rho$（散度）、涡 $J$（旋度）、边界法向分量 $g$。前两个数据在区域内部刻画场，第三个数据在边界上「钉住」解。若无边界条件，[[源的规定]] 与 [[涡流的规定]] 中的通解都含任意函数（$\operatorname{curl} A$ 或 $\operatorname{grad} U$），解不唯一；正是边界条件消除了这些自由度。

## 物理解释

向量场 $v$（比如速度场）由它的源及涡及它在边界上的法向分量确定。在流体语境下，$\rho$ 代表源汇强度、$J$ 代表涡量（旋度）分布、$g$ 代表穿过边界的法向流量。
