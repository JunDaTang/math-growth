# 复数域的哈密顿构造

按照哈密顿（1805—1865）的方法，可用有序对给出复数理论的严格基础。取 $\mathbb{C}$ 为所有有序对 $(a,b)$（$a,b\in\mathbb{R}$）的集合，定义

```
(a, b) + (c, d) = (a + c, b + d)
(a, b)(c, d)  = (ac - bd, ad + bc)
```

则 $\mathbb{C}$ 上得到一个 [[concepts/域与体]] 结构。令

```
i := (0, 1)
```

则有 $\mathrm{i}^2=(-1,0)$，且每个元素有唯一分解

$$
(a,b) = (a,0) + (b,0)\mathrm{i}
$$

映射 $\varphi(a):=(a,0)$ 是 $\mathbb{R}$ 到 $\mathbb{C}$ 的同态，故可将 $a\in\mathbb{R}$ 看作 $(a,0)\in\mathbb{C}$，从而把每个元素唯一写成

$$
a + b\mathrm{i}, \qquad \mathrm{i}^2 = -1
$$

于是回到通常记号，并证明 $\mathbb{C}$ 含有 $\mathbb{R}$ 作为子域。

**四元数**：形如 $\alpha+\beta i+\gamma j+\delta k$（$\alpha,\beta,\gamma,\delta\in\mathbb{R}$）的集合 $\mathbb{H}$ 是一个体（非交换），含 $\mathbb{C}$ 为子域。当 $\alpha^2+\beta^2+\gamma^2+\delta^2\ne0$ 时

$$
(\alpha+\beta i+\gamma j+\delta k)^{-1} = \frac{\alpha-\beta i-\gamma j-\delta k}{\alpha^2+\beta^2+\gamma^2+\delta^2}
$$

参见 [[concepts/四元数]]、[[entities/哈密顿]]。
