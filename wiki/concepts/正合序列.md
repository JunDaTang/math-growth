# 正合序列

2.3.3.3 节。现代线性代数和代数拓扑常常通过正合序列的语言来表述。线性算子 A 和 B 的序列

```text
X --A--> Y --B--> Z
```

称为是正合的，如果 $\operatorname{Im}(A) = \operatorname{Ker}(B)$。更一般地，序列

```text
… → X_k --A_k--> X_{k+1} --A_{k+1}--> X_{k+2} → …
```

称为正合的，如果对所有 k 有 $\operatorname{Im}(A_k) = \operatorname{Ker}(A_{k+1})$。

定理：对于线性算子 A，

```text
(i) A 是满射 ⇔ X --A--> Y → 0 正合
(ii) A 是单射 ⇔ 0 → X --A--> Y 正合
(iii) A 是双射 ⇔ 0 → X --A--> Y → 0 正合
```

这里 0 表示仅由中性元组成的平凡线性空间 $\{0\}$，$0 \to X$ 与 $Y \to 0$ 表示零算子。核与象见 [[核与象]]，满射/单射见 [[满射判别法与单射判别法]]。
