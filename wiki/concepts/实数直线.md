# 实数直线

1.1.1 节对实数的直觉介绍：设直线 G 上有两点 0 与 1（图 1.2(a)），则 G 上每个点 a 对应一个实数，由此得到**实数直线**。为简单起见，手册用同一符号表示直线 G 上的点 a 及与它对应的实数。从 0 到 1 的线段称为 G 中的**单位线段 E**。

序关系定义为：对任意两个实数 a、b，当且仅当点 a 严格位于点 b 的左边，记作 `a < b`，称 a 小于 b（图 1.2(b)）；若 a < b 或 a = b，记作 `a ≤ b`。实数 a 是正的、负的、非负的，分别当且仅当 `0 < a`、`a < 0`、`0 ≤ a`。

手册脚注指出，实数的严格定义以及实数史上对无理数的争议可参看 1.2.2 节（该节尚未入库，见 [[queries/11节实数严格定义与122节依赖]]）。
