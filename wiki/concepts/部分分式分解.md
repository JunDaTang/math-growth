# 部分分式分解

## 定义

部分分式分解（部分分式方法）是把有理函数拆成若干结构更简单的分式之和的代数方法。分解后的每一项形如 $\dfrac{A}{x-x_{0}}$，其极点在 $x_{0}$，据此即可读出原函数的极点位置（见 [[有理函数的极点]]）。更一般地，分解式是用**多项式**及形如

```latex
\frac{A}{(x - a)^{k}}
```

的表达式给出有理函数的加法分解式；当只对最低项有理函数作分解时，分解式中不含多项式部分。

在本 wiki 收录的源文件中，该概念分别以三种身份出现：

- 源文件 **0.2.15（有理函数）** 中，它作为二次分母有理函数的结构性分解工具被引用（参看本书 2.1.7）：0.2.15.4 用它把二次分母有理函数写成两个一次分式之和，0.2.15.5 则指出由部分分式分解能得到有理函数的清晰结构。
- 源文件 **0.9.4（重要代换）** 中，它是被**反复引用**的后继步骤：该节在每一类积分的末尾都注明「参看 0.9.3」，即把代换得到的有理函数分解成部分分式之和再逐项积分。
- 源文件 **2.1.7（部分分式分解）** 中，它作为一般定理被完整给出：包括最低项有理函数的分解公式、系数唯一性、实系数情形、系数求法、非最低项的归约和示例。

> 源文件 0.2.15 指向的后续小节是 **2.1.7**，0.9.4 指向的后续小节是 **0.9.3**。二者属于不同章节的指涉，不应合并为一个结论。2.1.7 即本 wiki 另一源文件所对应的章节；0.9.3 在本 wiki 中对应 [[有理函数的积分]]。

## 一般定理（源文件 2.1.7）

设 $f$ 是一个 [[最低项有理函数|最低项有理函数]]，即

```latex
f(x) := \frac{N(x)}{D(x)}, \quad 0 \leqslant \deg(N) < \deg(D),
```

其中 $N, D$ 为复系数多项式。设分母 $D$ 的两两互异的零点是 $x_1, \cdots, x_r$，重数分别为 $\alpha_1, \cdots, \alpha_r$，则

```latex
D(x) = (x - x_1)^{\alpha_1} \cdots (x - x_r)^{\alpha_r},
```

且对所有复数 $x \neq x_1, \cdots, x_r$ 有

```latex
f(x) = \sum_{j=1}^{r} \left( \sum_{\beta=1}^{\alpha_j} \frac{A_{j\beta}}{(x - x_j)^{\beta}} \right),
```

其中复数 $A_{j\beta}$ **唯一确定**。

分解的结构规则很清晰：分母的每个零点 $x_j$ 贡献 $\alpha_j$ 项，幂次 $\beta$ 从 $1$ 取到重数 $\alpha_j$。

### 实系数情形

如果 $N$ 和 $D$ 有实系数，那么 $D$ 的零点以复数共轭的形式成对出现且重数相同；此时对应的系数 $A_{j\beta}$ 也是复数共轭的。要点在于：实系数输入会产生共轭配对的零点与共轭配对的系数，因此可以把共轭对合并为实二次因子上的分式项。这一结论依赖 [[实系数多项式共轭零点定理|实系数多项式共轭零点定理]]。

### 非最低项：归约到最低项

若 $\deg(N) \geqslant \deg(D)$，则用 [[欧几里得算法-多项式|欧几里得算法（多项式）]] 做带余除法得

```latex
\frac{N(x)}{D(x)} = Q(x) + \frac{R(x)}{D(x)},
```

其中 $Q$ 为多项式，$R/D$ 为最低项有理函数。于是任意有理函数的分解都可归约为：先分出多项式部分 $Q$，再对最低项部分作部分分式分解。

### 系数求法

系数 $A_{j\beta}$ **总是可以**用两种方法之一算出：

1. **[[比较系数法|比较系数法]]**：把去分母后的恒等式展开，比较各次幂的系数，得到以待定系数为未知量的线性方程组。
2. **[[代入特殊值法|代入特殊值法]]**：在去分母恒等式中取若干个方便的 $x$ 值（常取分母的零点）直接解出系数。教科书指出该方法通常更快。

### 示例

分解 $f(x) = \dfrac{x}{(x-1)(x-2)^2}$，设

```latex
f(x) = \frac{A}{x-1} + \frac{B}{x-2} + \frac{C}{(x-2)^{2}},
```

乘以分母得式 (2.30)：

```latex
x = A(x-2)^{2} + B(x-1)(x-2) + C(x-1).
```

两种方法均得

```
A = 1,  B = -1,  C = 2.
```

另一个演示复数情形的例子：

```latex
\frac{x^{2}}{x^{2} + 1} = 1 - \frac{1}{x^{2} + 1} = 1 - \frac{1}{2\mathrm{i}} \left( \frac{1}{x - \mathrm{i}} - \frac{1}{x + \mathrm{i}} \right).
```

## 在 0.2.15 中的具体形式

### 特例 2（两个不同实根）

由

```latex
y = \frac{1}{(x-x_{+})(x-x_{-})}, \quad x_{-} < x_{+} \tag{0.45}
```

可得

```latex
y = \frac{1}{x_{+}-x_{-}}\left(\frac{1}{x-x_{+}} - \frac{1}{x-x_{-}}\right).
```

### 一般二次分母（$D>0$）

对

```latex
f(x) = \frac{ax+b}{x^{2}+2cx+d}, \qquad x^{2}+2cx+d = (x-x_{+})(x-x_{-}),\quad x_{\pm}=-c\pm\sqrt{D},
```

有

```latex
f(x) = \frac{A}{x-x_{+}} + \frac{B}{x-x_{-}},
```

其中系数由极限或待定系数求得：

```latex
A = \lim_{x \to x_{+}} (x-x_{+})f(x) = \frac{ax_{+}+b}{x_{+}-x_{-}}, \qquad
B = \lim_{x \to x_{-}} (x-x_{-})f(x) = \frac{ax_{-}+b}{x_{-}-x_{+}} .
```

### 意义

分解后的极点读法与上述形式，正是 0.2.15.4 分类讨论（见 [[二次分母有理函数的分类]]）的代数基础。

## 在 0.9.4 中的作用

七类积分的归约流程统一为两步：

1. **代换**：把被积函数化为关于 $t$ 的 [[多变量有理函数]]；
2. **部分分式分解**（参看 0.9.3）：把有理函数拆成可逐项积分的简单分式。

### 出现位置（本源 0.9.4）

源文件在每一类积分的末尾都注明「它能分解成部分分式之和（参看 0.9.3）」；就源文件 0.9.4 所举的七类而言，分别在第一类、第二类（两条路径）、第三类、第七类之后出现该注记：

- **第一类**：$t=\mathrm{e}^{x}$ 化出的有理函数；
- **第二类**（两条路径）：$t=\mathrm{e}^{\mathrm{i}x}$ 或 $t=\tan(x/2)$ 化出的有理函数；
- **第三类**：分式根式代换化出的有理函数；
- **第七类**：表 0.46 代换化出的有理函数。

## 适用边界与说明

- 分解的存在性与系数的唯一性在原始来源中为**直接陈述，未给证明**；分母能完全分解成一次因子幂，以 [[代数学基本定理|代数学基本定理]] 为背景。
- 幂次结构 $\beta = 1, \dots, \alpha_j$ 依赖于分母零点的[[多项式的零点与重数|重数]]；重数概念见 2.1.6 节。
- 除本节讨论的两种手工求系数方法外，符号计算软件可直接给出分解（见 [[Mathematica|Mathematica]]）。
