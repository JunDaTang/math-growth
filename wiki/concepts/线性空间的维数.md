# 线性空间的维数

2.3.2 节定义：线性空间 X 的线性无关元素的最大个数称为它的维数，记作 $\dim X$。符号 $\dim X = \infty$ 表示 X 中存在任意多个线性无关的元素；如果 X 仅由中性元素组成，则 $\dim X = 0$。

维数与 [[基-线性空间]] 的关系由 [[基定理]] 给出：如果每 n 个线性无关的元素都形成 X 的基，则 $\dim X = n$。在 2.3.3 节中，维数是有限维线性空间唯一特征——两个有限维线性空间同构当且仅当有相同的维数（见 [[线性空间同构]]）。与维数相对的 [[余维数]] $\operatorname{codim} Y = \dim X - \dim Y$。
