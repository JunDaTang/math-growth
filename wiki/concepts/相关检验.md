# 相关检验

6.3.3.5 节的**相关检验**用于检验两个随机变量 $X$ 和 $Y$ 是否相关。

## 程序结构

- **假定**：随机变量 $X$ 和 $Y$ 均服从正态分布。
- **假设**：相关系数 $r = 0$，即 $X$ 与 $Y$ **不相关**。
- **变列**：由测量值（6.35）

```text
x_1, …, x_n  和  y_1, …, y_n                    (6.35)
```

计算经验相关系数

```text
ρ = m_{XY} / (Δx · Δy)

经验协方差  m_{XY} := (1/(n-1)) · Σ_{j=1}^{n} (x_j - x̄)(y_j - ȳ)
```

## 判定规则（6.36）

当

```text
ρ · sqrt(n - 2) / sqrt(1 - ρ^2) > t_{α, m}      (6.36)
```

成立时，拒绝 $X$ 与 $Y$ 不相关的假设，犯错误的概率为 $\alpha$。$t_{\alpha,m}$ 查附录 0.4.6.3，其中

```text
m = n - 2
```

## 推理依据

令

```text
R := Σ (X_j - X̄)(Y_j - Ȳ)
     / ( Σ (X_j - X̄)^2 · Σ (Y_j - Ȳ)^2 )^{1/2}
```

则随机变量 $R\sqrt{n-2}/\sqrt{1-R^2}$ 服从自由度为 $n-2$ 的 [[t分布]]。由观测值 (6.35) 可得 $R$ 的一个实现 $\rho$；由 $P(|R| \ge t_\alpha) = \alpha$，故 (6.36) 成立时拒绝所作假设，犯错误概率为 $\alpha$。

## 特征

- 待检验的参数是**相关系数**，而非位置或离散程度，因此与前两个检验（[[t检验]]、[[F检验]]）互为补充。
- 样本必须成对出现（$X$ 与 $Y$ 有相同个数 $n$ 的观测），与 (6.32) 中两个样本量可以不同的 t 检验不同。
- 统计量经 $R\sqrt{n-2}/\sqrt{1-R^2}$ 变换后落入 [[t分布]]，这是本节第三次使用 t 分位点。
- 与 6.1.5 节 [[协方差与相关系数]] 的相关系数定义、6.2.3.3 节 [[回归直线与最小二乘法]] 的回归讨论在概念上相接，但本节把它置于显著性检验的框架内。

## 遗留疑点

(6.36) 的统计说明以 $\rho$ 与 $t_{\alpha,m}$ 直接比较，推理却写 $P(|R| \ge t_\alpha)$，记号与检验方向可疑，见 [[633节相关检验推理中R与t记号及方向疑点]]。
