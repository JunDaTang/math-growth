# 高阶偏导数

## 定义方式

本节说明：**用同样的方式可得高阶偏导数**——对已经求出的偏导数再施行一次「固定其余变量、只对一个变量求导」的操作。以 $f(u,v) := u^2v^3$ 为例：

```text
∂²f/∂v∂u = ∂/∂v(∂f/∂u) = 6uv^2
∂²f/∂u∂v = ∂/∂u(∂f/∂v) = 6uv^2
```

即先对 $u$ 再对 $v$，或先对 $v$ 再对 $u$，在本例中结果相同。

## 记号

```text
f_uv := (f_u)_v = ∂²f/∂v∂u
f_vu := (f_v)_u = ∂²f/∂u∂v
```

注意下标书写顺序与求导顺序的对应：$f_{uv} = (f_u)_v$ 表示先对 $u$ 求导、再对 $v$ 求导。

## 对称性

对于足够光滑的函数有 $f_{uv} = f_{vu}$。这一「方便」的性质由 [[施瓦茨定理]] 给出严格条件，并推广为：$C^k$ 类函数（$k \geqslant 2$）求直到 $k$ 阶的偏导数与其先后次序无关。

## 示例（例 1）

对 $f(u,v) = u^4v^2$：

```text
f_u  = 4u^3 v^2
f_v  = 2u^4 v
f_uv = f_vu = 8u^3 v
f_uu = 12u^2 v^2
f_uuv = f_uvu = 24u^2 v
```

## 与单变量高阶导数的关系

单变量情形下的 [[高阶导数]] 是本概念的特例（$N = 1$ 时偏导数即普通导数）。多元情形新增的问题是**求导次序**是否影响结果，这正是本节引入施瓦茨定理的动机。
