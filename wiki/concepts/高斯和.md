# 高斯和

## 定义与高斯定理（1808）

源文以「**高斯定理（1808）**」给出：设 $\varepsilon := e^{2\pi i/p}$，其中 $p$ 是素数。那么有

```
Σ_{k=1}^{p−1} ( k / p ) ε^k = √p,   当 p ≡ 1 mod 4;
Σ_{k=1}^{p−1} ( k / p ) ε^k = i√p,  当 p ≡ 3 mod 4.
```

源文说明：「**这种类型的和称为高斯和**。高斯甚至花费很长时间去证明这个结果。」

## 结构说明

- 求和项由 [[勒让德符号]] $(k/p)$ 加权的 $p$ 次单位根 $\varepsilon^k$ 组成，取值只可能是 $\pm\sqrt{p}$ 或 $\pm i\sqrt{p}$。
- 该结果是 [[高斯]] 在给出 [[二次互反律]] 第一个完全证明之后的又一项贡献（源文标注 1808，互反律标注 1796）。
- 该和属于代数数论中的指数和/循环域计算范畴。
