# 轨道方程（圆锥曲线）

轨道方程是《数学指南——实用数学手册》1.12.5.2 节的中心公式 (1.295)：二体问题相对运动的解在极坐标下是一条以原点（焦点）为极点的圆锥曲线。

## 定理与公式

(1.294) 的解是

```text
r = p / (1 + ε cos φ)                                   (1.295)
```

此时时间 $t$ 的运动由

```text
t = ( m₂ / |N| ) ∫₀^φ r(φ)² dφ                          (1.296)
```

给出，其中的诸常数为

```text
p := N² / (α m₂),   ε := √(1 + 2 E N² / (m₂ α²)),   α := G m m₂   (1.297)
```

本源只讨论 $0 \leqslant \varepsilon < 1$ 的情形，此时轨道是椭圆。

## 几何参数

在 $0 \leqslant \varepsilon < 1$ 时，记

```text
a := p / (1 - ε²),        b := p / √(1 - ε²),
```

其中 a 为长半轴、b 为半短轴、ε 为偏心率。椭圆所围面积为 $\pi a b$，太阳（引力中心）位于椭圆的焦点 $(0,0)$。图 1.141(a) 标注了 a、b、εa、r、φ 等量。

## 证明思路（据脚注 1)）

利用 $\mathrm{d}\varphi/\mathrm{d}r = \varphi'(t)/r'(t) = F(t)$，通过分离变量法积分此方程即导致公式 (1.295)；函数 $F(t)$ 从 (1.294) 中第一个方程推导而得。此外从 (1.294) 中第二个方程即得 (1.296)。本源指出，在 1.13.1.5 中将利用雅可比（C. G. J. Jacobi, 1804—1850）漂亮的方法来计算这个解。
