# 复流形的局部坐标

## 定义与作用

构造复流形的典型手法是为每个点指定一个**局部坐标**（坐标卡），并用局部坐标定义映射的全纯性。源文档以 $\overline{\mathbb{C}} := \mathbb{C} \cup \{\infty\}$ 为例说明这一构造：

- 对每个 $a \in \mathbb{C}$：取邻域 $U := \mathbb{C}$，坐标 $\zeta := z$；
- 对点 $\infty$：取邻域 $V := \overline{\mathbb{C}} - \{0\}$，坐标
  $$
  \zeta' := \begin{cases} 1/z, & \text{对满足 } z \neq 0 \text{ 的 } z \in \mathbb{C}, \\ 0, & \text{对 } z = \infty. \end{cases}
  $$

在重叠区域 $\overline{\mathbb{C}} - \{0\}$ 上有两个坐标 $\zeta = z$ 与 $\zeta' = 1/z$，满足过渡关系 $\zeta = 1/\zeta'$。点 $0$ 只有 $\zeta = 0$，点 $\infty$ 只有 $\zeta' = 0$。

## 全纯性的局部坐标刻画

完备复平面上的映射 $f: U \subseteq \overline{\mathbb{C}} \to \overline{\mathbb{C}}$ 称为全纯的，当且仅当过渡到局部坐标后 $f$ 是 [[全纯函数]]。例：对 $f(z) = z^n$（$f(\infty) = \infty$），取 $\zeta = 1/z$、$\mu = 1/w$ 得 $\mu = \zeta^n$，在 $\zeta = 0$ 有 $n$ 阶零点，故 $f$ 在 $\infty$ 处有 $n$ 阶极点，见式 (1.470) 与 [[findings/完备复平面上全纯映射例1至例4]]。

## 结果

- 局部坐标使 $\overline{\mathbb{C}}$ 成为一维 [[复流形]]，按其定义即 [[黎曼面]]，并且是紧黎曼面。
- 黎曼球面 $S^2$ 通过 [[球极平面投影]] 的局部坐标也成为一维复流形，且 $\varphi: S^2 \to \overline{\mathbb{C}}$ 双全纯。向量丛意义下的复流形概念另见 [[复流形]]。
