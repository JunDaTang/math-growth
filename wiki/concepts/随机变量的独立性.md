# 随机变量的独立性

## 定义

《数学指南——实用数学手册》6.1.5 节：若随机变量 $X$ 和 $Y$ 的（联合）概率密度 $\varphi$ 具有因式分解形式

```
φ(x,y) = a(x) b(y),  (x,y) ∈ ℝ²
```

则称 $X$ 与 $Y$ 是**相互独立**的。

## 独立性的推论

此时有：

1. $\varphi_X(x) = a(x)$，$\varphi_Y(y) = b(y)$；
2. **概率乘法公式**：$P(a \leqslant X \leqslant b,\ c \leqslant Y \leqslant d) = P(a \leqslant X \leqslant b)\, P(c \leqslant Y \leqslant d)$；
3. **均值乘法公式**：$\overline{F(X)G(Y)} = \overline{F(X)} \cdot \overline{G(Y)}$；
4. **相关系数 $r$ 为 0**。脚注给出推导：由 $\overline{X - \overline{X}} = 0$ 以及

```
(X − X̄)(Y − Ȳ) 的均值 = (X − X̄) 的均值 · (Y − Ȳ) 的均值 = 0
```

得到 $r = 0$；
5. **方差加法公式**：

```
(Δ(X+Y))² := (ΔX)² + (ΔY)²
```

## 应用

- **二维高斯分布**：两个一维正态密度之积即两个相互独立随机变量的联合分布（见 [[concepts/高斯正态分布]]）。
- **6.1.6 节波动原理**：理想气体粒子间无相互作用，各粒子能量是相互独立的随机变量，因而可应用均值与方差加法公式，得到 $\overline{E} = N\overline{\varepsilon}$、$(\Delta E)^2 = N(\Delta\varepsilon)^2$，由此推出 (6.9)（见 [[concepts/经典统计物理学]]）。

## 注意

由独立性可推出 $r = 0$，但本节并未断言 $r = 0$ 蕴含独立；该反向命题不成立。
