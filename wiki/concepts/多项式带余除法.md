# 多项式带余除法

## 陈述 (2.19)(2.20)

设 $N(x)$ 和 $D(x)$ 是两个多项式，并设 $D(x)$ 的次数至少是 $1$。那么**存在唯一确定**的多项式 $Q(x)$ 和 $R(x)$ 使得

```
N(x) = D(x)Q(x) + R(x),    (2.19)
```

其中余项多项式 $R(x)$ 的次数严格小于分母 $D(x)$ 的次数。代替 (2.19) 也可写成

```
N(x)/D(x) = Q(x) + R(x)/D(x).    (2.20)
```

术语：$N(x)$ 是分子，$Q(x)$ 是两个多项式的商；$R(x)$ 是余项多项式。

## 长除法算法

来源以例 3 的竖式给出实际做法，并将其概括为：

> 除以最高项，与除式相乘，作减法，除以所得到的最高项，等等。当所得最高项不能再相除时，计算结束。

即循环执行「除法 → 乘法 → 减法 → 再除法」四步，直至当前被除式的次数低于除式的次数。

## 两个必须分清的断言

1. **存在唯一性**：满足 (2.19) 且 $\deg R < \deg D$ 的 $Q,R$ 存在且唯一。这是本节的定理性内容。
2. **gcd 的给出方式**：反复应用 (2.19) 所得的末项非零余项是 gcd。这是另一条独立断言，见 [[concepts/欧几里得算法-多项式]]。

二者不可互相移用：前者是除法本身的性质，后者是算法链的终止结果。
