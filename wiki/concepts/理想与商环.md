# 理想与商环

## 理想

环 $R$ 的子集 $J$ 称为**理想**，如果 $J$ 是子环，并且

```
由 r ∈ R 及 a ∈ J 可推出 ra ∈ J 及 ar ∈ J
```

## 子环

环 $R$ 的子集 $U$ 称为**子环**，如果 $U$ 自身关于诱导运算是一个环，即要求 $a-b\in U$ 与 $ab\in U$ 对所有 $a,b\in U$。

## 商环

设 $J$ 是环 $R$ 的 [[concepts/理想与商环]] 意义上的理想。对 $a,c\in R$ 定义 $a\sim c\iff a-c\in J$，这是等价关系；等价类记作 $[a]$，全体等价类关于

```
[a][b] := [ab],   [a] + [b] := [a+b]
```

构成环，称为**商环** $R/J$。商环元素 $[a]$ 也称**剩余类**，商环本身在某些情形也称为**剩余类环**。

## 例

- $\mathbb{Z}$ 的所有理想为 $m\mathbb{Z}:=\{mz\ |\ z\in\mathbb{Z}\}$（$m$ 为任意自然数）。
- 由商环构造 [[concepts/高斯剩余类环]] $\mathbb{Z}/m\mathbb{Z}$。

与同态的关系见 [[concepts/环同态]]。
