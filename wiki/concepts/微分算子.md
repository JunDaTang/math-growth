# 微分算子

微分算子指把求偏导这一操作本身当作对象来记号的记法，例如 $\partial_x = \partial/\partial x$、$\partial_y$、$\partial_r$、$\partial_\varphi$ 及其组合。《数学指南——实用数学手册》1.5.4 节的标题即为「对微分算子的变换的应用」。

## 算子表达式

在该节第二个方法中，由链式法则解得 $f_x = A f_r + B f_\varphi$、$f_y = C f_r + D f_\varphi$，等价于如下被称为「重要公式」的算子等式：

```
∂_x = A ∂_r + B ∂_φ,   ∂_y = C ∂_r + D ∂_φ
A = cos φ,  B = -sin φ / r,  C = sin φ,  D = cos φ / r
```

## 算子的乘法与平方

算子可以相乘并展开。该节以

```
∂_x² = (A ∂_r + B ∂_φ)(A ∂_r + B ∂_φ)
     = A ∂_r(A ∂_r) + B ∂_φ(A ∂_r) + A ∂_r(B ∂_φ) + B ∂_φ(B ∂_φ)
```

为例，指出必须用乘法法则处理形如 $\partial_r(A\partial_r)$ 的项，即 $\partial_r(A\partial_r) = (\partial_r A)\partial_r + A\partial_r^2$（见 [[concepts/莱布尼茨积法则]]）。这里算子写在系数之后时作用于系数，这一非交换性由乘法法则一并处理。

由此得到

```
∂_x² = A A_r ∂_r + A² ∂_r² + B A_φ ∂_r + 2 A B ∂_φ ∂_r + A B_r ∂_φ + B B_φ ∂_φ + B² ∂_φ²
```

交换 $A \leftrightarrow C$、$B \leftrightarrow D$ 得到 $\partial_y^2$ 的相应表达式；把两者相加即得极坐标下的 [[concepts/拉普拉斯算子]] 公式 (1.64)。

## 源文档的转写疑误

原文最后一行写作 $\Delta = \partial_x^2 + \partial_y^2 = \partial_r^2 + \frac{1}{r^2}\partial_\varphi^2 + \frac{1}{r}\partial r$，右端最后一项为 $\frac{1}{r}\partial r$，缺少作用于函数的下标或微分算子记号。按上下文应为 $\frac{1}{r}\partial_r$。详见 [[queries/154节末算子公式右端缺少微分算子符号]]。
