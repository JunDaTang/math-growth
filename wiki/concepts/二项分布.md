# 二项分布

## 本节给出的形式

在 [[伯努利模型]] 中，频率 $H_n$ 与频数 $A_n$ 的分布都由同一个公式给出（6.2.5.2 定理 1(i) 与定理 2(i)）：

```
P(A_n = k) = P(H_n = k/n) = C(n, k) p^k (1 − p)^{n−k},  k = 0, ..., n。
```

原文用 $\binom{n}{k}$ 记组合数。该分布即二项分布。

## 前两个矩

对频数 $A_n$（定理 2）：

```
A̅_n = n H̅_n = np          (期望)
ΔA_n = √(np(1−p))         (标准差)
```

对频率 $H_n$（定理 1）：

```
H̅_n = p
ΔH_n = √(p(1−p)) / √n
```

即频率的期望恒为 $p$，而标准差以 $1/\sqrt{n}$ 的速率趋于零——这正是伯努利大数定律 (6.19) 的定量内容。

## 使用上的不便与三套逼近

原文明确指出：(i) 中给出的概率计算公式**使用起来不方便**。为此 [[棣莫弗]]、[[拉普拉斯]] 和 [[泊松]] 都曾尝试寻找适当的逼近公式，最终形成：

- [[棣莫弗-拉普拉斯局部极限定理]]（(6.20)，逐点逼近）；
- [[棣莫弗-拉普拉斯全面极限定理]]（分布函数一致逼近，含误差界 (6.23)）；
- [[泊松逼近定理]]（1837，$p$ 很小时更优）。

当 $n$ 充分大时也可直接用 [[高斯正态分布]] 计算区间概率，见 (6.24)。

## 质量控制中的用法

6.2.5.4 给出工业场景：集装箱中恰好 $r$ 件次品的概率为 $\binom{n}{r} p^r (1-p)^{n-r}$；次品数介于 $k$ 与 $m$ 之间的概率为 $\sum_{r=k}^{m} P(A_n = r)$。见 [[6254节质量控制中的泊松逼近与正态逼近例]]。
