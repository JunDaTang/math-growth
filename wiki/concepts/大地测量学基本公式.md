# 大地测量学基本公式

《数学指南——实用数学手册》3.2.2 节标题为「大地测量学的基本公式」的一组公式，解决的是由两个已知点的[[笛卡儿坐标]]确定它们之间的距离与方向角的问题，是后续三个基本问题的公共基础。

## 公式

设已知由笛卡儿坐标 $(x_A, y_A)$ 和 $(x_B, y_B)$ 给出的两点 $A$、$B$，并假定 $x_A < x_B$：

```
d = √((x_A − x_B)² + (y_A − y_B)²)
α = arctan((y_B − y_A) / (x_B − x_A))
```

其中 $d = AB$ 为两点间距离，$\alpha$ 为方向角（连线相对 $x$ 轴的倾角）。

## 符号约定

图 3.11 给出了两种情形：当 $y_B > y_A$ 时 $\alpha > 0$；当 $y_B < y_A$ 时 $\alpha < 0$。即方向角的符号由纵坐标差决定。

## 后续使用

在第一基本问题（[[前向切割]]）中，同一表达式被拆开使用：$c$ 为 $A$、$B$ 间距离，$\delta$ 为方向角，二者都是该基本公式的直接产物。
