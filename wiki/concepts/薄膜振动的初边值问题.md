# 薄膜振动的初边值问题 (1.501)

来源《数学指南——实用数学手册》1.14.22 的第二个应用是圆形薄膜的振动。令 $u(x, y, t)$ 为时刻 $t$ 薄膜在点 $(x, y)$ 处的位移，振动问题为

```
(1/c^2) u_tt − u_xx − u_yy = 0 ,   (x, y) ∈ D, t > 0
u = 0 ,                           在 ∂D 上（边界值）
u(x, y, 0) = u_0(x, y) ,  u_t(x, y, 0) = u_1(x, y)  （初始值）          (1.501)
```

正文取 $c = 1$。

## 定理（唯一解与级数形式）

**如果指定的连续函数 $u_0, u_1: \bar{D} \to \mathbb{R}$ 是光滑的，则边界-初值问题 (1.501) 有唯一解**

$$u(x, y) = \sum_{k, m} \left(a_{km} \cos(\lambda_{km} t) + b_{km} \sin(\lambda_{km} t)\right) v_{km}(x, y),$$

其中

$$a_{km} = (u_0, v_{km}), \qquad \lambda_{km} b_{km} = (u_1, v_{km}).$$

这里 $v_{km}$ 是 [[单位圆盘上的狄利克雷特征值问题]] (1.500) 的特征解，$\{v_{km}\}$ 是 [[完备规范正交系]]，括号 $(u, v) = \int_D u v \,\mathrm{d}x\,\mathrm{d}y$。

## 求解途径

正文明确指出：**这个解是通过考虑 (1.500)、利用傅里叶方法得到的**（见 [[傅里叶方法]]）。即先解圆盘上的 Dirichlet 特征值问题得到 $\lambda_{km}$ 与 $v_{km}$，再把 $u$ 按这组特征函数展开，时间方向化为常微分方程。

## 待澄清

定理中的求和写作 $\sum_{k,m=0}^{\infty}$，而 $v_{km}$ 的下标范围是 $k = 0,1,\cdots$、$m = 1,2,\cdots$（$\lambda_{km}$ 是 $J_k$ 的第 $m$ 个零点，故 $m$ 不应从 0 开始）。见 [[11422节振动解求和下标起点矛盾]]。
