# 主轴定理（旋转标准化）

**主轴定理**指：任何实对称矩阵都可以通过正交变换对角化，等价地，任何二次型都可通过一个旋转化为不含交叉项的法式。本节以 [[concepts/欧几里得运动]] 中的旋转为工具给出该定理并给出证明。

## 定理陈述（三维）

对笛卡儿坐标系 $(x_{1}, x_{2}, x_{3})$ 应用一个旋转可将 $x^{T}Ax = b$ 化为

$$
\lambda x^{2} + \mu y^{2} + \zeta z^{2} = b,
$$

其中 $\lambda, \mu, \zeta$ 是 $A$ 的特征值，$\det A = \lambda\mu\zeta$，$\operatorname{tr}A = \lambda + \mu + \zeta$。二维情形同构，即化为 $\lambda x^{2} + \mu y^{2} = b$。

## 证明思路

1. 取 $A$ 的三个特征向量 $u, v, w$：$Au = \lambda u$，$Av = \mu v$，$Aw = \zeta w$。
2. 选取它们使 $u^{T}v = u^{T}w = v^{T}w = 0$，$u^{T}u = v^{T}v = w^{T}w = 1$（即标准正交）。
3. 令 $D := (u, v, w)$，则 $\boldsymbol{x} = D\boldsymbol{x}'$ 是一个旋转。
4. 代入得 $b = \boldsymbol{x}'^{\mathrm{T}}(D^{\mathrm{T}}AD)\boldsymbol{x}'$，而 $D^{\mathrm{T}}AD = \operatorname{diag}(\lambda, \mu, \zeta)$。

二维证明完全平行，只需两个特征向量 $u, v$。

## 在分类中的作用

主轴定理把二次型分类问题归约为特征值符号的组合问题：对一般圆锥截线还要先用平移消去一次项（有中心情形），对无中心情形则化为 $\lambda x^{2} + 2qx + py + c = 0$ 并配完全平方。由此得到 [[concepts/圆锥截线]] 的表 3.3、表 3.4 与 [[concepts/二次曲面]] 的表 3.5、表 3.6。
