# 二次方程求根公式

本页整合同一公式在两处来源中的不同规范形式：0.2.3 节采用 \(a x^{2}+2bx+c=0\)（\(a,b,c\) 实、\(a>0\)），2.1.6 节采用首一形式 \(x^{2}+2px+q=0\)（\(p,q\) 复）。两者当 \(a=1\)、\(p=b\)、\(q=c\) 时重合；更一般地，把 \(a x^{2}+2bx+c=0\) 除以 \(a\) 即得首一形式，对应 \(p=b/a\)、\(q=c/a\)。

## 形式 \(a x^{2}+2bx+c=0\)（来源：0.2.3 二次函数）

《数学指南——实用数学手册》0.2.3 节给出二次方程

\[
a x^{2} + 2 b x + c = 0
\]

的解。其中系数 \(a, b, c\) 为实数，且 \(a > 0\)。解为

\[
x_{\pm} = \frac{-b \pm \sqrt{D}}{a} = \frac{-b \pm \sqrt{b^{2} - a c}}{a}
\]

此处判别式 \(D = b^{2} - ac\)。

### 与通行记法的比较

与通行的写法 \(x = \frac{-B \pm \sqrt{B^{2} - 4AC}}{2A}\)（对应方程 \(Ax^{2} + Bx + C = 0\)）相比，本式：

- 一次项系数被写作 \(2b\)；
- 分母为 \(a\) 而非 \(2a\)；
- 根式内为 \(D = b^{2} - ac\)，而非 \(b^{2} - 4ac\)。

两套记法在代数上等价：若把 \(Ax^{2} + Bx + C = 0\) 改写为 \(a = A\)、\(b = B/2\)、\(c = C\)，则 \(b^{2} - ac = B^{2}/4 - AC\)，而 \(\sqrt{b^{2}-ac}/a = \sqrt{B^{2}/4 - AC}/A = \sqrt{B^{2} - 4AC}/(2A)\)，与通行公式一致。详见 [[二次判别式]] 与 [[二次函数判别式记法差异]]。

### 零点个数

由 [[二次判别式]] \(D = b^{2} - ac\) 的符号决定：\(D > 0\) 两个不同实根，\(D = 0\) 一个二重实根，\(D < 0\) 两个复根（见 [[二次方程的复零点]]）。

### 来源给出的数值例子

例 1：方程 \(x^{2}-6x+8=0\) 有两个零点

\[
x_{\pm} = 3 \pm \sqrt{3^{2} - 8} = 3 \pm 1,
\]

即 \(x_{+}=4\)，\(x_{-}=2\)。

例 2：方程 \(x^{2}-2x+1=0\) 的零点为

\[
x_{\pm} = 1 \pm \sqrt{1 - 1} = 1.
\]

例 3：方程 \(x^{2} + 2x + 2 = 0\) 的零点为

\[
x_{\pm} = - 1 \pm \sqrt {1 - 2} = - 1 \pm \mathrm{i}.
\]

三个例子均取 \(a = 1\)，因此一次项系数 \(B = 2b\) 在数值上等于例子中的 \(-6\)、\(-2\)、\(2\)，而 \(b\) 取 \(B/2\)。

## 形式 \(x^{2}+2px+q=0\)（来源：2.1.6 代数学基本定理）

2.1.6 节给出公式（2.1.6.1）：具有复系数 \(p\) 和 \(q\) 的方程

\[
x^{2}+2px+q=0 \tag{2.22}
\]

有两个解

\[
x_{1,2}=-p\pm\sqrt{D},
\]

其中 \(D:=p^{2}-q\) 是所谓 [[判别式-代数方程]]；\(\sqrt{D}\) 表示一个固定的方根，亦即方程 \(y^{2}=D\) 的一个固定的解。

### 韦达关系

\[
-2p=x_{1}+x_{2},\quad q=x_{1}x_{2},\quad 4D=(x_{1}-x_{2})^{2}\qquad(\text{韦达定理}).
\]

### 实系数情形的根的性质（表 2.1）

| 条件 | 根的性质 |
|---|---|
| \(D>0\) | 两个实零点 |
| \(D=0\) | 一个二重实零点 |
| \(D<0\) | 两个共轭复零点 |

### 来源给出的数值例子

方程 \(x^{2}-2x-3=0\) 对应 \(p=-1,\ q=-3\)，判别式 \(D=p^{2}-q=4\)，两个解 \(x_{1,2}=1\pm2\)，即 \(x_{1}=3\) 及 \(x_{2}=-1\)。

## 两种形式的对应与判别式的关系

- 0.2.3 节的 \(a x^{2}+2bx+c=0\) 与 2.1.6 节的首一形式 \(x^{2}+2px+q=0\) 在 \(a=1\)、\(p=b\)、\(q=c\) 时完全一致。
- 当 \(a\neq1\) 时，两边除以 \(a\) 得 \(x^{2}+2(b/a)x+c/a=0\)，故 \(p=b/a\)、\(q=c/a\)；两个判别式满足 \(D_{2.1.6}=p^{2}-q=(b^{2}-ac)/a^{2}=D_{0.2.3}/a^{2}\)。因 0.2.3 节限定 \(a>0\)，二者符号相同，因此对实系数情形的零点个数判定一致。
- 注意两处来源对 \(D<0\) 的描述：0.2.3 节只写“两个复根”，2.1.6 节在实系数表 2.1 中进一步明确为“两个共轭复零点”。保留两条陈述，后者是前者的细化。

## 来源边界

0.2.3 节来源未讨论韦达定理（根与系数的关系）、判别式为零时根的重数在代数上的进一步性质，也未涉及高次方程求根。

2.1.6 节来源给出了韦达关系，并在相关页面中列出韦达定理、判别式-代数方程以及二次方程求根公式与表21的关联；对于更高次的方程，2.1.6 节还关联 [[卡尔达诺公式]] 与 [[代数学基本定理]]，但本节正文只给出二次方程的结果。
