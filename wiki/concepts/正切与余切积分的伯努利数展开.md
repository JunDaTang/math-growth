# 正切与余切积分、对数三角积分的伯努利数展开

## 现象

表 0.9.5 中有一组条目的原函数不是初等闭式，而是以[[伯努利数]] B_{2n} 为系数的幂级数。它们集中在两处：403、404、412、413（∫x tan αx dx、∫ tan αx/x dx、∫x cot αx dx、∫ cot αx/x dx），以及 451、452、453（∫ln sin x dx、∫ln cos x dx、∫ln tan x dx）。

## 原文条目

```latex
403. ∫ x tan αx dx
   = αx³/3 + α³x⁵/15 + 2α⁵x⁷/105 + 17α⁷x⁹/2835 + …
   + 2^{2n}(2^{2n}−1) B_{2n} α^{2n−1} x^{2n+1}/(2n+1)! + …

404. ∫ tan αx/x dx
   = αx + (αx)³/9 + 2(αx)⁵/75 + 17(αx)⁷/2205 + …
   + 2^{2n}(2^{2n}−1) B_{2n} (αx)^{2n−1}/((2n−1)(2n)!) + …
   （B_{2n} 为伯努利数，参看 0.1.10.4）

412. ∫ x cot αx dx = x/α − αx³/9 − α³x⁵/225 − … − 2^{2n} B_{2n} α^{2n−1} x^{2n+1}/(2n+1)! − …

413. ∫ cot αx/x dx = −1/(αx) − αx/3 − (αx)³/135 − 2(αx)⁵/4725 − …
   − 2^{2n} B_{2n} (αx)^{2n−1}/((2n−1)(2n)!) − …

451. ∫ ln sin x dx = x ln x − x − x³/18 − x⁵/900 − … − 2^{2n−1} B_{2n} x^{2n+1}/(n(2n+1)!) − …
452. ∫ ln cos x dx = −x³/6 − x⁵/60 − x⁷/315 − … − 2^{2n−1}(…) B_{2n} x^{2n+1}/(n(2n+1)!) − …
453. ∫ ln tan x dx = x ln x − x + x³/9 + 7x⁵/450 + … + 2^{2n}(2^{2n−1}−1) B_{2n} x^{2n+1}/(n(2n+1)!) + …
```

## 系数结构

- 403/404 的系数因子为 2^{2n}(2^{2n}−1)，与 tan z = Σ 2^{2n}(2^{2n}−1)|B_{2n}| z^{2n−1}/(2n)! 的展开式一致。
- 412/413 的系数因子只有 2^{2n}，对应 cot z 的展开式（比 tan 少一个 (2^{2n}−1) 因子）。
- 451–453 的系数因子为 2^{2n−1} 或 2^{2n}(2^{2n−1}−1) 型，分母为 n(2n+1)!，来自对 ln sin x、ln cos x、ln tan x 的幂级数逐项积分。

上列前四项的系数与手册 0.7.2 的幂级数展开表同源，逐项验算见 [[095节正切余切积分级数系数由伯努利数给出]]。

## 注意

- 404、412、413 的收敛半径与 tan、cot 的奇点位置一致，级数只在 |αx| < π/2（对 tan）或 |αx| < π（对 cot）内有效；源中未给出收敛区间说明。
- 452 的系数因子在源中转写为 2^{2n−1}(2^{2n−1})，逐项验算（n = 1 时应得 −x³/6）与之不符，疑应为 2^{2n−1}(2^{2n}−1)，见 [[095节公式转写疑误汇总]]。
- 453 的伯努利数出处写作「参看 1.1.10.4」，与 404、412、413 的「0.1.10.4」不一致，疑为转写错误。
