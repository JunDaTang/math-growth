# 前向切割（第一基本问题）

前向切割是《数学指南——实用数学手册》3.2.2.1 节给出的「第一基本问题」：已知两点 $A$、$B$ 及其坐标 $(x_A, y_A)$、$(x_B, y_B)$，并在图 3.12 中测得角 $\alpha$ 与 $\beta$，要求第三点 $P$ 的[[笛卡儿坐标]] $(x, y)$。英文文献中通常称为前方交会（forward intersection）。

## 计算步骤

先由[[大地测量学基本公式]]得到基线与方向角，再由[[正弦定律]]定出 $b$：

```
c = √((x_B − x_A)² + (y_B − y_A)²)
b = c · sin β / sin(α + β)
δ = arctan((y_B − y_A) / (x_B − x_A))
```

并得到

```
x = x_A + b · cos(α + δ)
y = y_A + b · sin(α + δ)
```

## 源文件给出的证明

利用图 3.12 中的直角三角形 $APQ$：

```
x = x_A + Δx = x_A + b · sin ε
y = y_A + Δy = y_A + b · cos ε
```

由 $\varepsilon = \pi/2 - \alpha - \delta$ 得 $\sin\varepsilon = \cos(\alpha+\delta)$、$\cos\varepsilon = \sin(\alpha+\delta)$；由正弦定律得 $b = c\,\sin\beta/\sin\gamma$；再由三角形的和角关系 $\gamma = \pi - \alpha - \beta$（见[[和角定律]]）得 $\sin\gamma = \sin(\alpha+\beta)$。证明自洽完整。
