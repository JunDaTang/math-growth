# 勒贝格测度

1.9.7 节在定义 [[concepts/体积的导数]] (1.165) 时使用记号 $\mathrm{meas}\,D_n$，并明确说明它表示勒贝格测度。对三维区域而言，勒贝格测度即体积，因此 (1.165) 的分母就是 [[concepts/容许区域]] $D_n$ 的体积。

```
g(P) = lim_{n→∞} ( ∫_{D_n} g(x) dx ) / ( meas D_n )        (1.165)
```

本节未对该测度概念作进一步展开，仅作为体积导数的记号前提出现。
