# 单位圆盘上的狄利克雷特征值问题 (1.500)

来源《数学指南——实用数学手册》1.14.22 的第一个应用是把 [[贝塞尔函数]] 用于求解开单位圆盘

$$D := \{(x, y) \in \mathbb{R}^2 \mid x^2 + y^2 < 1\}$$

上拉普拉斯算子的 Dirichlet 特征值问题：

```
−v_xx − v_yy = λ v ,   在 D 上
v = 0 ,               在 ∂D 上                                        (1.500)
```

边界条件 $v|_{\partial D} = 0$ 属于 [[第一边值问题]] 的齐次形式。

## 特征解

正文给出的特征解为

$$v_{km}(x, y) := \frac{1}{\sqrt{\pi}\,|J_k'(\lambda_{km})|} J_k(\lambda_{km} r)\, \mathrm{e}^{\mathrm{i} k \varphi}, \qquad \lambda = \lambda_{km},$$

其中 $k = 0, 1, \cdots$，$m = 1, 2, \cdots$，$x = r\cos\varphi$、$y = r\sin\varphi$，而 $0 < \lambda_{k1} < \lambda_{k2} < \cdots$ 是 $J_k$ 的零点。归一化因子 $1/(\sqrt{\pi}|J_k'(\lambda_{km})|)$ 使这族函数成为规范（正交归一的）函数系。

## 与完备规范正交系的关系

正文断言 $\{v_{km}\}$ 在希尔伯特空间（[[希尔伯特]]）$L_2(D)$ 中形成 **完备规范正交系**，标量积取

$$(u, v) := \int_D u(x, y) v(x, y)\, \mathrm{d}x\, \mathrm{d}y,$$

并注明「参看 1.13.2.13」。详见 [[完备规范正交系]]、[[vkm在L2D构成完备规范正交系]] 与 [[11422节引用072与113213未入库]]。

## 待澄清

正文把特征参数写成 $\lambda = \lambda_{km}$（即 $J_k$ 的零点本身），而 $v_{km}$ 中自变量组合为 $J_k(\lambda_{km} r)$。这两处的记号关系需要核对，见 [[11422节特征值疑应为lambda-km平方]]。
