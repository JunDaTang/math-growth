# 示性函数

## 定义（6.2.5.2 节）

利用规则

```
X_j(e_{i_1 ... i_n}) = { 1, 若 i_j = 1;
                       { 0, 其他
```

定义随机变量 $X_j : E \to \mathbb{R}$。于是 $X_j$ 等于 1 当且仅当 $e_1$ 在第 $j$ 次试验中发生。这里的 $E$ 是 [[伯努利模型]] 的基本事件空间。

## 性质（定理 3）

```
(i)   P(X_j = 1) = p;
(ii)  X̅_j = p,  ΔX_j = √(p(1−p));
(iii) X_1, ..., X_n 相互独立;
(iv)  H_n = (1/n)(X_1 + ... + X_n);
(v)   A_n = X_1 + ... + X_n.
```

即：频率是示性函数的算术平均，频数是示性函数之和。

## 为什么它重要

这是本节把伯努利模型接入一般概率论机器的**接口**：

1. $A_n$ 被写成 $n$ 个同分布独立随机变量之和，于是 [[中心极限定理]] 可直接适用，给出棣莫弗-拉普拉斯定理；
2. $H_n$ 作为样本均值，可直接套用切比雪夫弱大数定律（见 [[弱大数定律]]），得到伯努利大数定律 (6.19) 作为其特例；
3. 期望与方差的相加性使 $\overline{A}_n = np$、$\Delta A_n = \sqrt{np(1-p)}$ 的推导变得直接。

原文对此的表述是：「频数 $A_n$ 是一些可以同样处理的独立随机变量的叠加。因此，考虑到中心极限定理，我们预期当 $n$ 很大时，$A_n$ 近似服从正态分布。」
