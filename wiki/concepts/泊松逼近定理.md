# 泊松逼近定理（1837）

## 动机

原文（6.2.5.3 节「比较试验中的小概率 $p$」）指出：若概率 $p$ 非常小，则误差界 (6.23)

```
sup_{x∈ℝ} |Φ_n(x) − Φ(x)| ≤ (p² + (1−p)²)/√(np(1−p))
```

表明**只有当 $n$ 非常大时**，用正态分布逼近 $\Phi_n$ 才有效。[[泊松]] 发现，当 $p$ 的值较小时，有一个更好的逼近公式。

## 陈述（1837）

如果比较试验的概率 $p$ 非常小，则对于频数 $A_n$（见 [[伯努利模型中的频率与频数]]），近似有

```
(i) P(A_n = r) = (λ^r / r!) e^{−λ},  其中 λ = np, r = 0, 1, ..., n。
(ii) A_n 的分布函数 Φ_n 近似等于参数 λ = np 的泊松分布的分布函数；更精确地，
     sup_{x∈ℝ} |Φ_n(x) − Φ(x)| ≤ 3√(λ/n)。
```

注意误差界以 $\sqrt{\lambda/n} = \sqrt{p}$ 的阶趋于零，与 (6.23) 中 $1/\sqrt{np(1-p)}$ 的阶不同——这正是 $p$ 小时泊松逼近优于正态逼近的定量表述。

## 应用：质量控制

6.2.5.4 节把该定理作为**实用近似公式**用于次品数：

```
P(A_n = r) ≈ (λ^r / r!) e^{−λ},   λ = np,
```

并直接查泊松分布数值表 **0.4.6.9**。例 1（1000 只灯泡，$p = 0.001$，$\lambda = 1$）得

```
P(A_1000 = 0) = 0.37,  P(A_1000 = 1) = 0.37,  P(A_1000 = 2) = 0.18,
P(A_1000 ≤ 2) = 0.92。
```

详见 [[6254节质量控制中的泊松逼近与正态逼近例]]。

## 与正态逼近的分工

| 情形 | 推荐逼近 | 依据 |
|------|----------|------|
| $p$ 不很小、$n$ 大 | 正态分布 | (6.23)/(6.24)，[[棣莫弗-拉普拉斯全面极限定理]] |
| $p$ 很小 | 泊松分布 | 本节泊松逼近定理 |
