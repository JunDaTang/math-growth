# 第三基本问题（不可直接测量的距离）

《数学指南——实用数学手册》3.2.2.3 节给出「第三基本问题」：求图 3.14 中两点 $P$、$Q$ 之间的距离 $\overline{PQ}$，例如它们被一个湖分隔，因而该距离不能直接测量。

## 观测量

- 基线长度 $c = \overline{AB}$，即另外两点 $A$、$B$ 之间的距离；
- 四个角 $\alpha$、$\beta$、$\gamma$、$\delta$：$\alpha$、$\beta$ 在 $A$ 处，$\gamma$、$\delta$ 在 $B$ 处。

## 计算步骤（源文件原样）

由辅助量

```
ρ = 1 / (cot α + cot δ)
σ = 1 / (cot β + cot γ)
```

以及

```
x = σ · cot β − ρ · cot α
y = σ − ρ
```

得到所求距离

```
d = √(x² + y²)
```

## 未决问题

源文件未给出该公式的证明，仅列出结果。公式以余切 $\cot$（即 $1/\tan$）为核心运算，与[[前向切割]]、[[后向切割]]中同样使用余切的做法一致。
