# 代数曲线

代数曲线在《数学指南——实用数学手册》3.8.3 节中以平面形式引入：平面上由多项式方程

```latex
C: p(x, w) = 0
```

定义的曲线。它是代数几何学（[[代数几何学]]）中最基本的研究对象之一。

## 在本源中的作用

3.8.3 节研究的积分

```latex
J = \int R(x, w)\,\mathrm{d}x \tag{3.54}
```

中，被积函数含变量 $w$，而 $w$ 是 $x$ 的代数函数，即点偶 $(x, w)$ 恰落在某条平面代数曲线 $C$ 上。于是「积分 (3.54) 能否用有理替换求解」这一分析问题被转化为「曲线 $C$ 是否存在有理参数表示」这一几何问题，判据由曲线的亏格给出（[[亏格]]）。

## 本节出现的两条具体代数曲线

- 圆 $C: x^{2} + w^{2} = 1$，亏格为零，存在有理参数化，对应例 1。
- 无奇点三次曲线 $w^{2} = (x - e_{1})(x - e_{2})(x - e_{3})$，亏格为 1，不存在有理参数化，对应例 2 与 [[椭圆积分]]。
