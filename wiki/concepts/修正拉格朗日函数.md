# 修正拉格朗日函数

**修正拉格朗日函数**（本节记作 $\mathscr{L}$，花体字母 L）是《数学指南——实用数学手册》5.1.6 节为处理带约束变分问题而构造的辅助泛函核。它把约束项以拉格朗日乘子为权重并入原来的[[concepts/拉格朗日函数]] $L$：

```latex
\boxed{\mathscr{L} := L + \sum_{k=1}^{K} \lambda_k(t) N_k}
```

其中 $N_k$ 是约束 (5.39) 或 (5.40) 中的约束函数，$\lambda_k(t)$ 是[[concepts/拉格朗日乘子]]，$K$ 为约束个数。

## 用法

构造 $\mathscr{L}$ 的目的，是在欧拉-拉格朗日方程中用它替换 $L$，得到[[concepts/修正欧拉-拉格朗日方程]]

```latex
\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k} - \mathscr{L}_{q_k} = 0,\quad k = 1,\dots,K.\tag{5.41}
```

原文以「隐藏在拉格朗日乘子背后的思想」为标题陈述这一构造：用修正的拉格朗日函数代替拉格朗日函数 $L$，并把乘子作为待定未知量连同 $q(t)$ 一起解出。

## 记号说明

源文本中该定义写作 $\mathscr{L} := L + \sum_{k=1}^{K}\lambda - k(t) N_k$，其中 $\lambda_k(t)$ 被排为 `\lambda - k(t)`，应理解为 $\lambda_k(t)$，见 [[queries/516节修正拉格朗日函数中lambda-k记号讹误]]。
