# 间隙定理

## 陈述

《数学指南——实用数学手册》2.7.3 节以「间隙定理」之名给出：数

```text
n! + 2, n! + 3, …, n! + n      (n = 2, 3, 4, …)
```

都不是素数，并且当 n 增长时非素数集合（即素数集合中的间隙）越来越长。

## 证明思路（初等）

对 $k = 2, 3, \dots, n$，有 $k \mid n!$，因而 $k \mid n! + k$，且 $n! + k > k$，故 $n! + k$ 为合数。于是从 $n!+2$ 到 $n!+n$ 之间连续出现 $n-1$ 个合数，任何长度的素数间隙都可在此区间内找到。

## 意义

该定理是素数「稀疏性」的初等体现，与 [[素数定理]]、[[素数分布函数]] 给出的平均密度结论互为补充：素数整体上越来越稀，但间隙长度不受限制。关于素数本身的性质见 [[素数]]。
