# 大圆弧积分估计（式 1.466）

## 陈述

在 [[有理函数实积分的留数公式]] (1.464) 的证明概述中，令 $f := g/h$，$B_R$ 为上半平面中半径为 $R$ 的半圆弧。则

```text
lim_{R→∞} ∫_{B_R} f dz = 0.        (1.466)
```

## 估计的由来

当 $f$ 满足

```text
|f(z)| ≤ 常数 / |z²| = 常数 / R²,   对所有满足 |z| = R 的 z
```

该估计由次数关系式 $\deg h \geqslant \deg g + 2$ 直接得到。再由（周线积分的）三角不等式得到

```text
|∫_{B_R} f dz| ≤ (半圆周 B_R 的长度) · sup_{z ∈ B_R} |f(z)|
              ≤ (πR · 常数) / R² → 0,  当 R → ∞ 时。
```

其中所述常数与 $R$ 无关（源文档脚注 ¹⁾ 明确指出）。

## 作用

(1.466) 是 (1.464) 证明中的关键一环：它使半圆围道在大半径极限下只剩实轴上的积分，从而把复围道积分等式转化为实积分公式。
