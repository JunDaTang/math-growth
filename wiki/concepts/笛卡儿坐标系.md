# 笛卡儿坐标系

本手册 1.8.2 节定义：**笛卡儿坐标系**由三个单位长度的向量 $i, j, k$ 给出，它们相互垂直，并且符合**右手法则**，即它们就像右手的拇指、食指与中指的关系一样定向。那么 $V(O)$ 中的每个向量 $r$ 有唯一表示

```latex
r = x i + y j + z k,
```

其中 $x, y, z$ 称为 $r$ 的终点 $P$ 的**笛卡儿坐标**（图 1.85）。平面中相应的情况见图 1.86：(a) 斜坐标系，(b) 笛卡儿坐标系。

在 1.8.3 节的一般坐标系框架下，笛卡儿坐标系是自对偶的特例：

```latex
i = e_1 = e^1,  j = e_2 = e^2,  k = e_3 = e^3,  a_j = a^j,  j = 1, 2, 3.
```

特别地，在这个情形反变坐标与共变坐标相等。笛卡儿坐标下三个乘积化为行列式形式，见 [[笛卡儿坐标下乘积的分量表示]]。

参见 [[基与分量]]、[[对偶基]]、[[反变坐标与共变坐标]]。
