# 逆矩阵

## 定义

设 `A ∈ Mat(n,n)`。给定矩阵 A 的逆矩阵定义为矩阵 `B ∈ Mat(n,n)`，它满足

```
AB = BA = E
```

其中 `E` 是 `n × n` [[单位矩阵]]。

## 存在性与唯一性

> 这种矩阵 B 存在，当且仅当 `det A ≠ 0`，亦即 A 的 [[行列式]] 非零。此时 B 唯一确定并记作 `A^{-1}`。

因此当 `det A ≠ 0` 时，

```
A A^{-1} = A^{-1} A = E
```

## 二阶情形（来源例 7）

矩阵 `A := (a b; c d)` 的逆矩阵存在当且仅当 `det A ≠ 0`，即 `ad − bc ≠ 0`，此时

```
A^{-1} = 1/(ad − bc) · ( d  −b )
                       ( −c  a )
```

来源验证：计算表明 `A A^{-1} = A^{-1} A = (1 0; 0 1)`。

## 元素公式（依赖 2.1.2 节）

对于任意 `det A ≠ 0` 的 `n × n` 矩阵 A：

```
(A^{-1})_jk = (det A)^{-1} A_kj
```

其中 `(A^{-1})_jk` 表示 `A^{-1}` 的第 j 行及第 k 列上的元素，`A_kj` 是 A 的行列式中 `a_kj` 的**伴随行列式**（来源指向其 2.1.2 节）。注意此处「伴随行列式」是 [[伴随行列式]]（代数余子式），与本节另一处定义的 [[伴随矩阵]]（共轭转置）是不同概念。

## 与正则矩阵、GL(n,ℂ) 的关系

`det A ≠ 0` 的矩阵称为 [[正则矩阵]]，其全体构成 [[一般线性群]] `GL(n,ℂ)`。
