# 泊松分布

## 定义（6.2.5.3 节）

假设在实数轴上的点 $x = 0, 1, 2, \cdots$ 处分别赋予质量 $m_0, m_1, \cdots$，其中

```
m_r := (λ^r / r!) · e^{−λ},   r = 0, 1, ...,
```

这里 $\lambda > 0$ 是参数。则相应的质量分布函数

```
Φ(x) := 区间 ]−∞, x[ 所包含的质量
```

称为泊松分布函数（原文图 6.15）。

![图 6.15 泊松分布函数](media/10-数学指南实用数学手册--19-625-应用于独立重复试验的伯努利模型--89e2y0/001-a741172f399eb0a89ef201dee96b1fa461ba50cda9dcaa1f289cd645388c748d.jpg)

这是 [[离散型与连续型随机变量]] 中离散型分布的一个具体例子，其质量集中在非负整数点 $0, 1, 2, \cdots$ 上。

## 两个矩（本节定理）

若随机变量 $X$ 服从上述泊松分布（即 $X$ 的分布函数是上述泊松分布函数），则

```
X̅ = λ      (均值)
ΔX = √λ    (标准差)
```

原文未在本节给出推导，仅列出结论。

## 数值表

原文指出：$\frac{\lambda^r}{r!}\mathrm{e}^{-\lambda}$ 的值可以在 **0.4.6.9** 中查到。质量控制一节的两个算例都直接引用该表。

## 用途

泊松分布在本节中作为 **$p$ 很小、$n$ 很大时二项分布的替代逼近** 出现，见 [[泊松逼近定理]]；它也被用于描述产品质量控制中的次品数（[[6254节质量控制中的泊松逼近与正态逼近例]]）。
