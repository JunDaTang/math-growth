# 沿错误方向的证明

《数学指南——实用数学手册》4.2.6.2 节剖析的第二类错误证明：常犯的错误包括**试图通过证明逆蕴涵 $\mathcal{B} \Rightarrow \mathcal{A}$ 来证明命题 $\mathcal{A} \Rightarrow \mathcal{B}$**，所谓「0 = 0」证明就属于这类错误。

**错误的断言**：每个实数 $x$ 都是方程

```
x² − 4x + 3x + 1 = (x−1)² + 3x        (4.13)
```

的一个解。

**该断言的「证明」**：设 $x \in \mathbb{R}$，由 (4.13) 有

```
x² − x + 1 = x² − 2x + 1 + 3x = x² + x + 1      (4.14)
```

两边加 $-x^2-1$ 得

```
−x = x        (4.15)
```

平方得

```
x² = x²       (4.16)
```

这意味着

```
0 = 0         (4.17)
```

这条正确的蕴涵链表明 $(4.13) \Rightarrow (4.14) \Rightarrow (4.15) \Rightarrow (4.16) \Rightarrow (4.17)$，但它**不是**上述断言的证明：需要的是相反方向的链条 $(4.17) \Rightarrow (4.16) \Rightarrow (4.15) \Rightarrow (4.14) \Rightarrow (4.13)$，而这是不可能的，因为蕴涵 $(4.15) \Rightarrow (4.16)$ 不能逆过来——$(4.16) \Rightarrow (4.15)$ 仅对 $x = 0$ 为真。

**正确的断言**：方程 (4.13) 有唯一的解 $x=0$。步骤 1 由正向链条 $(4.13) \Rightarrow (4.14) \Rightarrow (4.15) \Rightarrow x = 0$ 得至多一个解；步骤 2 验证 $x = 0 \Rightarrow (4.15) \Rightarrow (4.14) \Rightarrow (4.13)$。来源指出，更复杂的情形下人们常试图只作「逻辑等值」的处理，使两个方向立刻得证，即证明

```
(4.13) ⇔ (4.14) ⇔ (4.15) ⇔ x = 0
```

这一错误的根源与[[concepts/蕴涵]]、[[concepts/逻辑等值]]、[[concepts/充分条件与必要条件]]直接相关；另一类错误见[[concepts/被零除错误]]。
