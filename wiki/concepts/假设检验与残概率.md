# 假设检验与残概率（伯努利模型）

## 目标（6.2.5.5 节）

只通过对一个实验的试验观测，**揭露使用不均匀硬币行骗的骗子**。原文称这是数理统计中一个典型的数学论证方法。

## 残概率的概念

原文强调数理统计的主要特性之一：它认为「揭露一个骗子」只能在一定的**残概率**（记为 $\alpha$）下才能进行；这里所说的残概率是指**所作结论不正确的概率**。

对 $\alpha = 0.05$，这意味着：如果我们试图揭露一个骗子 100 次，那么平均来说大约会有 5 次作出错误的结论，此时会把一个无辜的人当成骗子。

## 检验程序

**试验** 将一枚硬币抛 $n$ 次，观察「正面向上出现 $k$ 次」。称 $h_n = k/n$ 为随机变量 $H_n$（[[伯努利模型中的频率与频数]]）的实现；$p$ 表示一次试验中正面向上出现的概率。

**假设**

```
(H) 硬币是公平的，即 p = 1/2。
```

**数理统计基本原理** 如果

```
h_n 不在置信区间 [1/2 − z_α ΔH_n, 1/2 + z_α ΔH_n] 内,        (6.25)
```

便以残概率 $\alpha$ 放弃假设 (H)。

其中

```
ΔH_n := 1/(2√n),
z_α 由等式 2Φ_0(z_α) = 1 − α 并查表 0.34 确定。
```

原文给出：对 $\alpha = 0.01$（或者 0.05 和 0.1），有 $z_\alpha = 1.6$（相应地 2.0 和 2.6）——该对应关系的可靠性见 [[queries/625节z-alpha取值与残概率对应疑点]]。

**推理** 由 (6.24)（见 [[棣莫弗-拉普拉斯全面极限定理]]），当 $n$ 很大时，理论量 $H_n$ 的实测值 $h_n$ 落入 (6.25) 置信区间的概率是

```
Φ_0(z_α) − Φ_0(−z_α) = 1 − α。
```

若实测值未落入该区间，就放弃假设 (H)，此时作出错误结论的概率是 $\alpha$。

## 例

$n = 10\,000$ 时 $\Delta H_n = 1/200 = 0.05$，相应于残概率 $\alpha = 0.05$ 的置信区间是

```
[0.49, 0.51]。        (6.26)
```

- 若 10 000 次抛掷中有 5200 次「正面向上」，则 $h_n = 0.52$ 落在 (6.26) 之外，故以 0.05 的出错概率下结论：这枚硬币不公平。
- 若「正面向上」出现 5050 次，则 $h_n = 0.505$ 落在 (6.26) 中，故相信硬币其实是公平的；该结论正确的概率为 95%，错误的概率为 $\alpha = 0.05$。

## 术语说明

本节把检验的显著性水平称为「残概率」，与 6.1 节的 [[置信区间]] 概念互补：置信区间是「以 $1-\alpha$ 的概率覆盖真值」的区间，残概率则是同一 $\alpha$ 的补视角。本节的两类应用分别固定 $p$ 检验 $H_n$（6.2.5.5）与固定 $H_n$ 反求 $p$（见 [[概率p的置信区间]]）。
