# 素数定理

## 陈述

《数学指南——实用数学手册》2.7.3.1 节以「素数基本定理」之名给出：对于大数 x，有渐近等式

```text
π(x) ~ x/ln x ~ li x,  x → +∞
```

文中称这是「数学中最著名的渐近公式」，其中 π 为 [[素数分布函数]]，li 为 [[对数积分]]。等价地可写成极限形式

```text
lim_{x→∞} π(x)/(x/ln x) = lim_{x→∞} π(x)/li x = 1
```

## 等价形式

若 $p_n$ 表示第 n 个素数，则定理等价于

```text
p_n ~ n ln n,  n → +∞
```

## 发现史与证明史

- 欧拉（1707—1783）仍相信素数是完全不规则地分布的。
- π(x) 的渐近分布由 33 岁的 [[勒让德]] 于 1785 年、14 岁的 [[高斯]] 于 1792 年通过对对数表的深入研究**独立**发现。
- 严格证明由 30 岁的 [[阿达马]] 与 30 岁的 [[德拉瓦莱普桑]] 于 **1896 年独立**给出。

详见 [[concepts/素数定理]]。

## 误差与更精细的估计

文中给出误差项的双边界与黎曼陈述下的误差界，见 [[concepts/素数定理]]；其条件涉及 [[黎曼猜想]] 与 [[黎曼ζ函数]]。

## 注意事项

本小节把该定理称为「素数基本定理」，这与通行名称「素数定理」指同一命题；「基本定理」在算术语境中通常指 [[算术基本定理]]，两者不可混淆。
