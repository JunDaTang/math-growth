# 结式

## 定义（式 2.29）

设给定两个复系数多项式

$$p(x):=a_{0}+a_{1}x+\dots+a_{n}x^{n},\qquad q(x):=b_{0}+b_{1}x+\dots+b_{m}x^{m},$$

其中 $n,m\geqslant1$ 且 $a_{n}\neq0,\ b_{m}\neq0$。$p$ 和 $q$ 的**结式** $R(p,q)$ 定义为下列行列式：

```
R(p,q) := | a_n  a_{n-1} … a_0                          |
           |     a_n  a_{n-1} … a_0                    |
           |         …   …   …                        |
           |              a_n  a_{n-1} … a_0           |
           | b_m  b_{m-1} … b_0                        |
           |     b_m  b_{m-1} … b_0                    |
           |         …   …   …                        |
           |              b_m  b_{m-1} … b_0           |
```

行列式中空白处全为零。该行列式由 $m$ 行 $p$ 的系数与 $n$ 行 $q$ 的系数组成（西尔维斯特型行列式）。

## 结式的用途

- **公共零点**：$p$ 和 $q$ 有公共复零点当且仅当 $R(p,q)=0$，见 [[concepts/公共零点主定理]]。
- **多重零点**：$p$ 有多重零点当且仅当 $R(p,p')=0$；除去非零常数因子，$R(p,p')$ 与 [[concepts/判别式-代数方程]] $\varDelta$ 相同，见 [[concepts/多重零点主定理]]。
- 两个多项式的最大公因子容易借助 [[concepts/欧几里得算法-多项式]] 确定，这给出了公共零点判定的另一条途径。
