# 向量函数的坐标表示

在《数学指南——实用数学手册》1.9.1 节中，选取笛卡儿坐标系 (x, y, z)、点 O 为其原点，则对任意向量有

```
r(t) = x(t) i + y(t) j + z(t) k
```

以及

```
r⁽ⁿ⁾(t) = x⁽ⁿ⁾(t) i + y⁽ⁿ⁾(t) j + z⁽ⁿ⁾(t) k
|r⁽ⁿ⁾(t)| = √( x⁽ⁿ⁾(t)² + y⁽ⁿ⁾(t)² + z⁽ⁿ⁾(t)² )
```

特别地有 r′(t) = r⁽¹⁾(t)，r″(t) = r⁽²⁾(t) 等。

## 意义

这一表示说明：**当 n 阶导数 x⁽ⁿ⁾(t), y⁽ⁿ⁾(t), z⁽ⁿ⁾(t) 存在时，n 阶导数 r⁽ⁿ⁾(t) 确实存在**。也就是说，向量函数的微分运算可以完全**逐分量**进行，停留在实值微积分的范围内。

由此还得到极限的坐标刻画：令 aₙ = αₙ i + βₙ j + γₙ k，a = α i + β j + γ k，则 lim aₙ = a 当且仅当 n → ∞ 时 αₙ → α, βₙ → β, γₙ → γ（坐标的收敛性，或称按坐标收敛）。

基底 i, j, k 及相关记号见 [[concepts/笛卡儿坐标系]] 与 [[concepts/基与分量]]。
