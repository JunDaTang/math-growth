# 阻尼振动

本节 1.12.1.7：若存在正比于质点速度的附加阻抗力 $\mathbf F_2=-\gamma\mathbf x'$（$\gamma>0$），由 $m\mathbf x''=\mathbf F_0+\mathbf F_2=-k\mathbf x-\gamma\mathbf x'$ 得

```latex
\begin{array}{l}
x''(t) + \omega^2 x(t) + 2\beta x'(t) = 0, \\
x(0) = x_0, \quad x'(0) = v,
\end{array}                                       \tag{1.216}
```

其中 $\beta := \gamma/2m$。作假设 $x=\mathrm e^{\lambda t}$ 得特征方程 $\lambda^2+\omega^2+2\beta\lambda=0$，其解 $\lambda_\pm=-\beta\pm\mathrm i\sqrt{\omega^2-\beta^2}$；解的一般形式 $x=C\mathrm e^{\lambda_+ t}+D\mathrm e^{\lambda_- t}$，也可用欧拉公式 $\mathrm e^{(a+\mathrm ib)t}=\mathrm e^{at}(\cos bt+\mathrm i\sin bt)$。

当 $0<\beta<\omega$ 时唯一解为阻尼振动

```latex
x = x_0 \mathrm{e}^{-\beta t}\cos \omega_* t
+ \frac{v+\beta x_0}{\omega_*} \mathrm{e}^{-\beta t}\sin \omega_* t,  \tag{1.217}
```

其中 $\omega_* := \sqrt{\omega^2-\beta^2}$。源文以 $x_0\ne 0,\ v=0$ 为例（图 1.123(b)）。
