# 二次分母有理函数的分类

## 一般形式

已知实数 $a,b,c,d$ 且 $a^{2}+b^{2}\neq 0$，由

```latex
y = \frac{ax+b}{x^{2}+2cx+d} \tag{0.47}
```

定义的函数 $y=f(x)$ 的形态取决于判别式

```latex
D := c^{2} - d
```

的符号。并且恒有

```latex
\lim_{x \to \pm\infty} f(x) = 0 .
```

（本书 0.2.15.4 一般情况。）

## 情形 1：$D>0$

分母有两个不同实零点：

```latex
x^{2}+2cx+d = (x-x_{+})(x-x_{-}), \qquad x_{\pm} = -c \pm \sqrt{D}.
```

由[[concepts/部分分式分解]]得

```latex
f(x) = \frac{A}{x-x_{+}} + \frac{B}{x-x_{-}},
```

```latex
A = \frac{ax_{+}+b}{x_{+}-x_{-}}, \qquad B = \frac{ax_{-}+b}{x_{-}-x_{+}} .
```

函数的极点在 $x_{\pm}$。

## 情形 2：$D=0$

此时 $x_{+}=x_{-}$，故

```latex
f(x) = \frac{ax+b}{(x-x_{+})^{2}},
```

```latex
\lim_{x \to x_{+}\pm 0} f(x) =
\begin{cases}
+\infty, & ax_{+}+b > 0, \\
-\infty, & ax_{+}+b < 0.
\end{cases}
```

即点 $x_{+}$ 是极点。

## 情形 3：$D<0$

此时对一切 $x \in \mathbb{R}$ 有 $x^{2}+2cx+d > 0$，因此对任意 $x \in \mathbb{R}$，函数 (0.47) 都连续且无穷可微，即 $f$ 光滑，见 [[concepts/有理函数的光滑性]]。

## 特例

- $y = \dfrac{1}{x^{2}+d^{2}}$ 与 $y = \dfrac{x}{x^{2}+d^{2}}$（$d>0$），见图 0.40。
- $y = \dfrac{1}{(x-x_{+})(x-x_{-})}$（$x_{-}<x_{+}$），见式 (0.45)。
- $y = \dfrac{x-1}{x^{2}-1}$，在 $x=1$ 处有[[concepts/表观奇点]]。

## 判别式记号辨析

本节的判别式 $D := c^{2}-d$ 是**有理函数分母** $x^{2}+2cx+d$ 的判别式形式，与 [[concepts/二次判别式]] 及 [[concepts/二次方程求根公式]] 中的判别式在语义上相关，但作用对象不同（后者针对二次方程 $ax^{2}+bx+c=0$），记法与系数命名亦不一致，引用时须区分。
