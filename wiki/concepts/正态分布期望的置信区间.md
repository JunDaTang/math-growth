# 正态分布期望的置信区间

6.3.3.1 节给出在正态假定下期望 $\mu$ 的置信区间，是 6.3.1 节 [[置信区间]] 一般定义在正态测量值上的具体实现。

## 前提与变列

假设 $X$ 服从正态分布 $N(\mu, \sigma)$。由测量值 $x_1, \cdots, x_n$ 算出

```text
x̄  = (1/n) · Σ_{j=1}^{n} x_j
Δx = sqrt( (1/(n-1)) · Σ_{j=1}^{n} (x_j - x̄)^2 )
```

## 统计说明（6.30）

关于期望 $\mu$ 的不等式

```text
| x̄ - μ | ≤ (Δx / sqrt(n)) · t_{α, n-1}          (6.30)
```

成立的概率为 $1 - \alpha$，其中 $t_{\alpha, n-1}$ 的值可在 0.4.6.3 中查到。

## 推理

随机变量 $\sqrt{n}(M - \mu)/S$ 服从自由度为 $n-1$ 的 [[t分布]]。由于

```text
P(|T| ≤ t_{α, n-1}) = 1 - α
```

故不等式

```text
( | x̄ - μ | / Δx ) · sqrt(n) ≤ t_{α, n-1}
```

成立的概率为 $1-\alpha$，由此得 (6.30)。

## 要点

- 区间半宽为 $(\Delta x/\sqrt n)\cdot t_{\alpha,n-1}$：既随测量次数 $n$ 增大而按 $1/\sqrt n$ 收缩，也随样本离散程度 $\Delta x$ 增大而变宽。
- 使用 f 分布族的 t 分位点而非 6.1.4 节 [[正态分布置信区间的z-alpha分位点]] 中的 $z_\alpha$，因为总体标准差 $\sigma$ 未知、以样本标准差代替。两处的对照见 [[631节z-alpha取值与残概率对应疑点]] 所讨论的相关疑点。
- 自由度 $m = n - 1$，参见 [[自由度]]。
