# 沿一条曲线的解析延拓

**沿一条曲线的解析延拓**是 1.14.15 节给出的解析延拓构造性方法：通过幂级数在收敛圆盘内另一点处重排，把收敛域逐步「搬」出去，从而沿一条曲线推进延拓。

## 构造步骤

1. 给定幂级数

$$
f(z) = a_0 + a_1 (z-a) + a_2 (z-a)^2 + \dots, \tag{1.479}
$$

其收敛域为 $D = \{z \in \mathbb{C} : |z-a| < r\}$。

2. 选一个点 $b \in D$，令 $z - a = (z-b) + b - a$，对级数 (1.479) 重新排序，得到新的幂级数

$$
g(z) = b_0 + b_1 (z-b) + b_2 (z-b)^2 + \dots,
$$

其收敛域为 $D' = \{z \in \mathbb{C} : |z-b| < R\}$（图 1.191(a)）。

3. 在交集 $D \cap D'$ 上有 $f = g$。如果 $D'$ 包含不在 $D$ 里的点，令

$$
\text{在 } D \text{ 上 } F := f, \quad \text{在 } D' \text{ 上 } F := g,
$$

就得到并集 $D \cup D'$ 上 $f$ 的一个解析延拓 $F$。

4. 可以尝试继续这个过程（图 1.191(b)）：在新圆盘内再取一点重排，得到下一个圆盘，逐段沿曲线推进。

## 关键性质

- 每一步的合法性都由 [[恒等原理]] 保证：$f$ 与 $g$ 在交集 $D \cap D'$（非空开集）上相等，故 $F$ 定义良好且全纯。
- 若沿不同路径延拓到同一终点得到不同结果，则延拓结果依赖于路径——这正是多值函数出现的机制（见 [[例5平方根主值绕圈延拓得负主值]] 与 [[例6对数主值绕m圈得加2πmi]]）。
- 当区域单连通且延拓可行时，结果与路径无关，即 [[单值性定理]]。

## 与其他延拓手段的对比

| 手段 | 机制 | 适用条件 |
|---|---|---|
| 沿曲线的解析延拓 | 幂级数重排、圆盘覆盖 | 一般区域，但可能得到多值函数 |
| [[单值性定理]] | 路径无关性 | 单连通区域 |
| [[施瓦茨反射原理]] | 关于线段的对称反射 | 区域关于线段对称 |

## 相关概念

- [[柯西展开式]]：把全纯函数在某点展开为幂级数的基本工具，是级数重排的前提。
- [[解析延拓]]：本方法是其标准构造。
- [[最大解析延拓]]：无限继续此过程所趋向的终点。
