# 单位圆紧化的实数集 ℝ̄

《数学指南——实用数学手册》1.3.2.1 例 4 构造了一个把有限极限与无限极限统一起来的度量空间。

## 构造

考虑单位圆：实数直线 ℝ 上的每个点 $x$ 对应于单位圆上唯一的点 $x_*$；北极点 N 不对应 ℝ 的任何点，通常把北极点替换成 $+\infty$ 与 $-\infty$。定义

```
ℝ̄ := ℝ ∪ {+∞, −∞}
```

令

```
d(x, y) := 单位圆 Z 上 x_* 与 y_* 之间的弧长
```

则集合 $\overline{\mathbb{R}}$ 成为[[度量空间]]。约定

```
d(−∞, ∞) := 2π
```

例如 $d(\pm\infty, 0) = \pi$。

## 意义

设 $(x_n)$ 是一个实数序列。在 $\overline{\mathbb{R}}$ 中度量 $d$ 的意义下，收敛

```
lim_{n→∞} x_n = x,   −∞ ⩽ x ⩽ +∞
```

意味着单位圆上的对应点序列 $(x_n)_*$ 收敛到点 $x_*$；这等价于收敛的经典概念。于是单位圆度量空间 $Z$ 中收敛的度量概念，给出了收敛到有限值和无限值的统一刻画。

## 动机（1.3.2.5 例 3）

ℝ 相对于经典距离函数是无界集，因此不是紧的；而 ℝ ∪ {±∞} 是有界紧的。手册明言：「这就是能统一处理有限极限和无限极限的更深层次的原因。」此即 [[findings/单位圆紧化统一有限与无限极限]]。

## 延伸

手册指出，上述概念可以推广到一般度量空间和拓扑空间（见 [212]，参见 [[queries/13节参考文献212尚未识别]]）。它与 wiki 中已有的 [[实数直线]] 概念直接相关。
