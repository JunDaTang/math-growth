# 经验协方差与经验相关系数

本节（6.3.3.5）在 [[相关检验]] 中给出的两个样本量：**经验协方差** $m_{XY}$ 与**经验相关系数** $\rho$。

## 定义（出处：6.3.3.5）

由成对测量值 $x_1,\dots,x_n$ 与 $y_1,\dots,y_n$ 计算：

```text
经验协方差   m_{XY} := (1/(n-1)) · Σ_{j=1}^{n} (x_j - x̄)(y_j - ȳ)

经验相关系数 ρ := m_{XY} / (Δx · Δy)
```

其中 $\bar x, \bar y$ 为经验期望，$\Delta x, \Delta y$ 为经验标准差。

## 要点

- 分母为 $n-1$ 而非 $n$，与 6.3.3.1 中经验标准差

```text
Δx = sqrt( (1/(n-1)) · Σ (x_j - x̄)^2 )
```

的归一化方式一致，二者同源于 6.3.2 节的无偏估计量思路（参见 [[方差的估计量S2]]、[[估计量的无偏性]]）。
- $\rho$ 是 [[相关检验]] 中待检验假设 $r = 0$ 的直接样本对应物：由观测值得到 $\rho$ 后，经 $\rho\sqrt{n-2}/\sqrt{1-\rho^2}$ 变换以构造 t 统计量。
- 与 6.1.5 节 [[协方差与相关系数]]（总体层面的协方差与相关系数）以及 6.2.3.3 节的回归讨论对应，本节给出的是样本（经验）版本的表达形式与其在显著性检验中的用途。
- 记号说明：源文使用 $m_{XY}$ 表示经验协方差、$\rho$ 表示经验相关系数，与总体量 $r$ 相区别；同一符号 $\rho$ 在检验推理中被记为随机量 $R$ 的一个实现。
