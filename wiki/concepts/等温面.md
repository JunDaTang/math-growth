# 等温面

等温面是温度场 $T(x,t)$ 的等值面。1.9.7 节在解释 [[concepts/傅里叶热传导定律]] 时用到该概念：热通量密度向量

```
J = −κ grad T
```

正交于等温面。这一性质直接来自 [[concepts/梯度]] 垂直于标量场等值面的结论，参见 [[findings/梯度垂直于等值面并指向标量场递增方向]]。

图 1.103 中以区域内部的两条短平行线段示意等温面（或一般等值面），并以带箭头的线段标注外法线 $\boldsymbol{n}$。
