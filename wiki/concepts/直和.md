# 直和

2.3.4.3 节。设 Y 和 Z 是线性空间 X 的两个子空间。记 $X = Y \oplus Z$，当且仅当每个 $u \in X$ 可以唯一地写成

```text
u = y + z,   y ∈ Y, z ∈ Z
```

空间 X 称为 Y 和 Z 的直和，并说 Z 是 Y 在 X 中的代数补集。有

```text
dim(Y ⊕ Z) = dim Y + dim Z
```

定理：(i) 由 $X = Y \oplus Z$ 可推出 $Z \cong X/Y$；(ii) $\dim Z = \operatorname{codim} Y$（见 [[余维数]]）。

存在定理：对于 X 的每个子空间 Y 存在一个代数补集 Z，即有 $X = Y \oplus Z$。补空间的构造：设 Y 是 n 维空间 X 的 m 维子空间，$0 < m < n < \infty$，取 X 的基 $u_1,\dots,u_n$，则 $X = Y \oplus \operatorname{span}\{u_{m+1},\dots,u_n\}$。

任意多个子空间的直和：$X = \bigoplus_{\alpha \in A} X_\alpha$ 当且仅当每个 $x \in X$ 可唯一地写成 $x = \sum_{\alpha \in A} x_\alpha$（只允许有限多个加项）；下标集有限时有 $\dim X = \sum_{\alpha \in A} \dim X_\alpha$。例 2（图 2.3）画出 $\mathbb{R}^2 = Y \oplus Z$。
