# 欧几里得范数

在《数学指南——实用数学手册》1.3.2.1 例 2 中，$\mathbb{R}^N$ 的元素写作 $x = (\xi_1, \cdots, \xi_N)$，并定义距离

```
d(x, y) := sqrt( Σ_{j=1..N} (ξ_j − η_j)^2 )
```

进一步定义

```
|x − y| := d(x, y),        |x| := sqrt( Σ_{j=1..N} ξ_j^2 )
```

并称 $|x|$ 为 $x$ 的**欧几里得范数**；直观上 $|x|$ 是 $x$ 到原点的距离。手册插图图 1.23 分别画出 $N = 1, 2, 3$ 时的距离概念，与通常（朴素）的距离概念一致。

借助该范数，$\mathbb{R}^N$ 成为一个 [[度量空间]]，其收敛性等价于各分量收敛：

```
lim_{n→∞} x_n = x   ⟺   lim_{n→∞} ξ_{jn} = ξ_j,  j = 1, …, N
```
