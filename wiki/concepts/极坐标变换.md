# 极坐标变换

极坐标变换是用新的坐标 $r, \varphi$ 替代笛卡儿坐标 $x, y$ 的坐标变换，定义见《数学指南——实用数学手册》1.5.4 节：

```
x = r cos φ,  y = r sin φ,  -π < φ ≤ π          (1.60)
```

其中 $r, \varphi$ 称为极坐标。该节用极坐标为例说明：通过转变坐标，可以简化微分方程；并且同样的想法可以用到任意坐标变换。

## 逆变换

令 $\alpha := \arctan(y/x)$（$x \neq 0$），逆变换为

```
r = √(x² + y²)                                    (1.61)

        ⎧ α,              x > 0, y ∈ ℝ
        ⎪ ±π + α,         x < 0, y ≷ 0
φ =     ⎨ ±π/2,           x = 0, y ≷ 0
        ⎪ π,              x < 0, y = 0
```

注意编号 (1.61) 只标注在 $r$ 的表达式上，$\varphi$ 的分段表达式紧随其后，共用同一编号。

## 函数的坐标变换

把函数 $F = F(x, y)$ 从笛卡儿坐标变换到极坐标，设

```
f(r, φ) := F(x(r, φ), y(r, φ))                    (1.62)
```

本节中坐标变换对拉普拉斯算子的作用，见 [[concepts/拉普拉斯算子]] 与 [[concepts/拉普拉斯方程]]。
