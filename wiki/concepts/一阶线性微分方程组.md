# 一阶线性微分方程组

《数学指南——实用数学手册》1.12.6.1 的基础模型为

```latex
\boxed { \begin{array}{l} {\pmb {x} ^ {\prime} = \pmb {A} (t) \pmb {x} + \pmb {B} (t), \quad t \in J,} \\ {\pmb {x} (t _ {0}) = \pmb {a} \quad (\text {初始值}).} \end{array} }\tag{1.300}
```

其中 $\boldsymbol{x}=(x_1,\cdots,x_n)^{\mathrm{T}}$ 为复列向量，$\boldsymbol{A}(t)$ 为复 $n\times n$ 矩阵，$\boldsymbol{B}(t)$ 为复列向量，$J$ 为包含 $t_0$ 的开区间。分量形式为

```latex
x _ {j} ^ {\prime} = \sum_ {k = 1} ^ {n} a _ {j k} (t) x _ {k} + b _ {j} (t), \quad j = 1, \dots , n.
```

## 基本性质

- **存在性和唯一性定理**：若 $\boldsymbol{A}$、$\boldsymbol{B}$ 的分量在 $J$ 上连续，则对每个 $\boldsymbol{a}\in\mathbb{C}^n$，初值问题 (1.300) 在 $J$ 上恰好有一个解；若 $\boldsymbol{A}$、$\boldsymbol{B}$、$\boldsymbol{a}$ 为实，则解也为实。详见 [[findings/一阶线性组存在唯一性定理]]。
- **解的结构**：$\boldsymbol{x}(t) = \boldsymbol{P}(t,t_0)\boldsymbol{a} + \int_{t_0}^{t}\boldsymbol{P}(t,\tau)\boldsymbol{B}(\tau)\,\mathrm{d}t$，由[[传播子]]给出。
- **齐次通解**：$\boldsymbol{x}(t) = \sum_{j=1}^{n} C_j \boldsymbol{X}_j(t)$，由[[基本解]]给出。

## 与其他模型的关系

- **常系数**情形可由拉普拉斯变换（参阅 1.11.1.2）求解，此时 $\boldsymbol{P}(t,\tau)=\mathrm{e}^{(t-\tau)\boldsymbol{A}}$。
- **任意阶线性微分方程** $y^{(n)} + a_{n-1}(t)y^{(n-1)} + \dots + a_0(t)y = f(t)$ 可通过引进 $x_1 = y, x_2 = y', \dots, x_n = y^{(n-1)}$ 化归为本形式；同理，任意阶线性方程组也可如此处理。详见 [[findings/任意阶线性微分方程化为一阶方程组]]。
- 例题 (1.303) 对应[[谐振子]]运动，是 (1.300) 的一个二维实例。
