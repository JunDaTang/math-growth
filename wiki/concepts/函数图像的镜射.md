# 函数图像的镜射

**函数图像的镜射**（镜像反射）是 [[函数的变换]] 的一类，包含两种轴向反射：

```latex
y = f(-x) \quad \text{（由 } y = f(x) \text{ 经 } y \text{ 轴镜射）}
y = -f(x) \quad \text{（由 } y = f(x) \text{ 经 } x \text{ 轴镜射）}
```

## 原文示例（例 4）

$y = e^{-x}$ 的图像由 $y = e^{x}$ 的图像经 y 轴镜射得到（手册图 0.26，含 (a) $y = e^{x}$ 与 (b) $y = e^{-x}$）。该示例与 [[指数函数与自然对数]] 中的指数函数性质相关。

## 与对称性的联系

镜射下的不变性正是奇偶性的图像刻画：

- $y = f(-x)$ 与 $y = f(x)$ 的图像重合 $\iff$ $f(-x) = f(x)$，即 $f$ 为**偶函数**，图像关于 y 轴对称；
- $y = -f(x)$ 与 $y = f(x)$ 的图像关于 x 轴互为镜射；奇函数 $f(-x) = -f(x)$ 的图像关于**原点**对称。

手册例 5 给出：$y = x^2$ 是偶函数，$y = x^3$ 是奇函数。定义原文与更完整的整理见 [[函数的奇偶性与周期性]]。
