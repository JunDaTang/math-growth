# 相关性秩条件（定理）

## 定理陈述

《数学指南——实用数学手册》1.5.5 节的定理：假设两个矩阵 $^{1)}$

```
(f_1'(x), ..., f_{K+1}'(x)) 与 (f_1'(x), ..., f_K'(x))
```

的秩是常数，等于某个 $r$，$1 \leqslant r \leqslant K$，则满足上述相关性关系式（即 $f_{K+1}$ 依赖于 $f_1, \dots, f_K$，见 [[concepts/函数相关性]]）。

其中 $f_j'(x)$ 是 $f_j$ 的偏导排成的列矩阵（脚注 1) 的约定），故 $(f_1'(x), \dots, f_K'(x))$ 是 $N \times K$ 矩阵，$(f_1'(x), \dots, f_{K+1}'(x))$ 是 $N \times (K+1)$ 矩阵。详见 [[concepts/梯度矩阵]]。

## 判据的意义

该条件把「存在 $C^1$ 关系式 $f_{K+1} = F(f_1, \dots, f_K)$」这一函数存在性问题，转化为对梯度矩阵秩的计算问题：秩条件成立时，$f_{K+1}'$ 不会给出 $f_1', \dots, f_K'$ 之外的新方向，故可由 $f_1, \dots, f_K$ 决定。这与 [[concepts/雅可比矩阵]]、[[concepts/雅可比行列式]] 提供的手段直接衔接。

## 表述上的不确定处

原文只写「两个矩阵……的秩是常数，等于某个 $r$」，字面上未明确：

1. 两个矩阵的秩是否必须相等（通常的完整陈述要求二者秩相等且等于常数 $r$）；
2. 该条件是充分、必要还是充要条件；
3. 两个矩阵是否共用同一个 $r$。

因此本条目的证据强度有限（见 [[findings/梯度矩阵秩为常数则函数相关]]，confidence: low），需回查原书排版确认。相关追踪见 [[queries/155节定理表述是否缺少秩相等条件]]。
