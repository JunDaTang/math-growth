# 诺伊曼函数（$N_p$ / $N_n$）

诺伊曼函数是 [[贝塞尔微分方程]] 的第二解。本页合并两处来源的说法：来源 1.14.22 给出**整数阶** $\alpha = n$ 下的定义式与显式公式；来源 0.7.3.3 给出**实参数** $p$ 下的渐近表示。

> [!note] 两处来源的参数与适用范围不同
> - 1.14.22 使用整数阶符号 $N_n$（$n = 0,1,2,\cdots$），自变量记为 $z$，并断言幂级数对**所有复数 $z \in \mathbb{C}$** 收敛。
> - 0.7.3.3 使用实参数符号 $N_p$（$p$ 为实数），自变量记为 $x \to +\infty$。
>
> 两处来源各自只陈述自己的参数范围，未互相推广；以下分节并列保留，不做合并推断。

## 定义式：整数阶情形（来源 1.14.22）

诺伊曼函数 $N_n$ 是 [[贝塞尔微分方程]] (1.499) 在整数阶 $\alpha = n$（$n = 0,1,2,\cdots$）情形下的第二解，用以替代与 $J_n$ 线性相关的 $J_{-n}$（见 [[情形2整数阶Jn与J负n线性相关]]）。

来源《数学指南——实用数学手册》1.14.22 给出的定义为

$$N_n(z) := \frac{1}{\pi}\left.\left(\frac{\partial J_\alpha(z)}{\partial \alpha} - (-1)^n \frac{\partial J_{-\alpha}(z)}{\partial \alpha}\right)\right|_{\alpha = n},$$

即把阶数 $\alpha$ 视为参数，对 $\alpha$ 求偏导后在 $\alpha = n$ 处取值，并以 $(-1)^n$ 组合 $J_\alpha$ 与 $J_{-\alpha}$ 的导数。

## 显式公式（来源 1.14.22）

正文进一步给出「由它可推出」的显式公式：

```
N_n(z) = (2/π)(C + ln z − ln 2) J_n(z)
         − (1/π) Σ_{k=0..n−1} [(n−k−1)! / k!] · (2/z)^{n−2k}
         − (1/π) Σ_{k=0..∞} [(−1)^k / (k!(n+k)!)] · (z/2)^{n+2k} · (H_{n+k} + H_k)
```

其中：

- $C = 0.5772\cdots$ 为 **欧拉常数**（[[欧拉]]）；
- $H_k := \sum_{r=1}^{k} 1/r$，且 $H_0 := 0$，即 [[调和数]]；
- 正文说明：**对所有复数 $z \in \mathbb{C}$，幂级数收敛**。

公式中含 $\ln z$ 项与 $(2/z)$ 的有限负幂项，这与 1.14.20 中「情形 2：第二解含对数项」的理论预测一致，是 [[奇异微分方程]] 一般理论在贝塞尔方程上的直接印证。

## 渐近表示：实参数情形（来源 0.7.3.3）

手册 0.7.3.3 给出诺伊曼函数的渐近表示：

$$
N_{p}(x)=\sqrt{\frac{2}{\pi x}}\left(\sin\left(x-\frac{p\pi}{2}-\frac{\pi}{4}\right)\right)+o\left(\frac{1}{\sqrt{x}}\right),\quad x\to+\infty,
$$

其中参数 $p$ 为实数。

### 与贝塞尔函数渐近式的比较（来源 0.7.3.3）

- 与 [[贝塞尔函数]] 的渐近式相比，振幅 $\sqrt{2/(\pi x)}$、相位 $-p\pi/2-\pi/4$ 与余项阶 $o(1/\sqrt{x})$ 完全相同，唯一的差别是 $\cos$ 被换成 $\sin$，即相差相位 $\pi/2$。
- 这一配对关系提炼为 [[贝塞尔与诺伊曼函数渐近主项仅差相位]]。

## 命名说明

来源 0.7.3.3 仅把 $N_{p}$ 作为**函数**引入，未把「诺伊曼」作为人物实体页处理；相应的函数族背景见 [[特殊函数]]。整数阶情形的定义与显式公式另见 [[诺伊曼函数定义与显式公式]]。
