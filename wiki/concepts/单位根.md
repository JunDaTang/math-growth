# 单位根

在 1.1.2.4 节中，当 a = 1 时，方程 xⁿ = a 的 n 个根被称为**单位根**。手册给出 n = 2, 3, 4 的图示（图 1.10）：

- n = 2：1 与 −1；
- n = 3：圆周三等分点；
- n = 4：1、i、−1、−i。

一般公式由 [[concepts/复数的n次根]] 给出，此时 |a| = 1、φ = 0，故 n 个根是 e^{2πik/n}，k = 0, …, n − 1，即把单位圆 n 等分。
