# 平面的一般方程

## 公式

三维空间中的平面方程为：

```latex
\boxed {A x + B y + C z = D.}
```

其中实常数 $A, B, C$ 应满足条件：

$$A^{2} + B^{2} + C^{2} \neq 0$$

（图 0.20(b)）。

## 非零条件的意义

条件 $A^2 + B^2 + C^2 \neq 0$ 排除退化情形：若 $A = B = C = 0$，方程退化为 $0 = D$，不再表示任何平面（$D \neq 0$ 时空集，$D = 0$ 时全空间）。手册特意显式给出这一条件，是常见疏漏点。

**注意适用范围**：该非零条件仅约束平面方程的系数，不应外推到直线方程——[[空间直线的参数方程]] 自身无需此类约束。

## 与向量代数的衔接

系数三元组 $(A, B, C)$ 的几何意义（平面的法向量）以及点法式等工具属于向量代数内容，手册将其安排在 3.3 节（"向量代数在三维空间中的直线和平面上的应用"）。本节仅给出方程形式与系数约束，对平面的刻画因此是不完整的，待 3.3 节录入后补充链接。
