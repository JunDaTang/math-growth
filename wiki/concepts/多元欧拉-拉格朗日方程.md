# 多元欧拉-拉格朗日方程

多元欧拉-拉格朗日方程是 5.2.1 主定理给出的 (5.44)/(5.45) 类多变量变分问题的必要条件的偏微分方程组，是单变量情形[[欧拉-拉格朗日方程]]（本书称[[欧拉-伯努利方程]]）在区域 $D\subset R^{N}$ 上的推广。

## 主定理的陈述

**主定理**：如果 $\boldsymbol{q}=\boldsymbol{q}(t)$ 是 (5.44) 或 (5.45) 的解，那么 $\boldsymbol{q}$ 在 $D$ 上满足

```latex
\sum_{j=1}^{N}\partial_{j}L_{\partial_{j}q_{k}}-L_{q_{k}}=0,\quad k=1,\dots,K. \tag{5.46}
```

原文脚注以更详细的方式表达为

```latex
\sum_{j=1}^{N}\frac{\partial}{\partial x_{j}}\frac{\partial L(Q)}{\partial(\partial_{j}q_{k})}
-\frac{\partial L(Q)}{\partial q_{k}}=0,\quad k=1,\dots,K,
```

其中 $Q=(\boldsymbol{x},\boldsymbol{q}(\boldsymbol{x}),\partial\boldsymbol{q}(\boldsymbol{x}))$。

**推论**：对于充分光滑的函数 $\boldsymbol{q}$，问题 (5.45) 等价于 (5.46)。

## 归属与意义

原文指出这些著名方程是拉格朗日在 1762 年推导出来的；物理中各领域的理论都可借助 (5.46) 用公式表达，其中问题 (5.45)（稳态提法）对应稳态作用原理。

## 与单变量形式的区别

- 对 $q'$ 的常导数被对 $\partial_{j}q_{k}$ 的偏导数与对 $x_{j}$ 的散度型求和取代：$\sum_{j}\partial_{j}L_{\partial_{j}q_{k}}$。
- 结果是 $K$ 个耦合的偏微分方程，而非 $K$ 个常微分方程。
- 边界条件在 $\partial D$ 上整体给定（Dirichlet 型 $\boldsymbol{q}=\boldsymbol{\psi}$），自然边界条件在带边界积分的泛函（如 (5.52)）中才会出现。
