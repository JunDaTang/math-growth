# 线性化与线性近似

## 含义

在本源 1.5.2 节中，「线性化」指用线性映射 $h \mapsto f'(p)h$ 作为增量 $f(p+h)-f(p)$ 的**主部**，余项 $r(h)$ 相对 $|h|$ 为高阶无穷小：

```latex
f(p + h) - f(p) = f'(p)h + r(h), \quad \lim_{h \to 0} \frac{r(h)}{|h|} = 0.
```

它与一维情形下的切线与切线方程（见 [[切线与切线方程]]）是同一思想的多元版本：以一阶（线性）信息逼近函数在一点附近的局部行为。

## 本源中的例证

对 $f(\boldsymbol{x}) = x_1 \cos x_2$、$\boldsymbol{p} = (0,0)^{\mathrm{T}}$，利用泰勒展开式

```latex
\cos h_2 = 1 - \frac{(h_2)^2}{2} + \dots
```

得到

```latex
f(\boldsymbol{p} + \boldsymbol{h}) - f(\boldsymbol{p}) = f'(\boldsymbol{p})\boldsymbol{h} + r(\boldsymbol{h}) = (1, 0) \binom{h_1}{h_2} + r(\boldsymbol{h}),
```

并指出可以把 $f'(p)h = h_1$ 看成 $f(h) = h_1 \cos h_2$ 的线性近似（当 $h_1, h_2$ 足够小）。详见 [[例1x1cosx2的弗雷歇导数]]。

对线性映射，线性化退化为映射本身，见 [[线性映射的线性化是映射本身]]。
