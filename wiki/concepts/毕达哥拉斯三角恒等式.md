# 毕达哥拉斯三角恒等式

手册公式 (0.40) 是正弦与余弦之间最基本的代数约束：

$$
\cos^{2} x + \sin^{2} x = 1.
\tag{0.40}
$$

## 来源与适用范围

- **几何来源**：由单位圆图 0.31(a) 与 [[毕达哥拉斯定理]] 直接得出（见 [[单位圆与直角三角形中的三角函数]]）。
- **适用范围**：手册两次强调，该关系不仅对实变量 $x$ 成立，**对所有复变量 $x$ 也成立**；其复变量版本也可由加法定理 (0.37) 配合 $\sin 0 = \sin 2\pi = 0$、$\cos 0 = \cos 2\pi = 1$ 推出。

## 作用

- 提供计算特殊角值（手册表 0.17）的几何依据。
- 与和差化积公式配合，可在三角恒等式之间相互转换，见 [[三角函数的和差化积与积化和差公式]]。
- 与 [[三角函数的指数表示]] 联立，可得到 $\mathrm{e}^{\mathrm{i}x}\mathrm{e}^{-\mathrm{i}x} = 1$ 这一指数形式的等价表述。
