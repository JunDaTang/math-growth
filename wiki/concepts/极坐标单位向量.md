# 极坐标与单位向量 e_r、e_φ

本源在 1.12.5.2 节中把二维平面运动化为极坐标形式，并引入随动单位向量 $e_r$、$e_\varphi$，从而把守恒律写成一阶常微分方程组 (1.294)。

## 平面运动的来源

由角动量守恒 (1.293) 得，对所有时刻 $t$ 有 $\boldsymbol{x}(t) \cdot \boldsymbol{N} = 0$，因此运动被限制于垂直于向量 $\boldsymbol{N}$ 的平面内。选取 z 轴沿向量 $\boldsymbol{N}$ 方向，则 $\boldsymbol{x}(t)$ 位于 $(x,y)$ 平面中：

```text
x(t) = x(t) i + y(t) j.
```

## 极坐标与单位向量

```text
x = r cos φ,   y = r sin φ,
e_r  :=  cos φ i + sin φ j,
e_φ  := -sin φ i + cos φ j.
```

运动由 $\varphi = \varphi(t)$、$r = r(t)$ 给出；选取 x 轴使 $\varphi(0) = 0$。对时间求导得

```text
e_r' = (-sin φ i + cos φ j) φ' = φ' e_φ.
```

由轨道方程 $x(t) = r(t)e_r(t)$ 得

```text
x' = r' e_r + r φ' e_φ,
```

且由于 $e_r \cdot e_\varphi = 0$，

```text
x'² = (r')² + r² (φ')².
```

## 由此得到的方程组

结合能量守恒 (1.292) 与角动量守恒 (1.293)，得到

```text
m₂ ( r'² + r² φ'² - 2 G m / r ) = 2 E,
m₂ r² φ' = |N|.                                         (1.294)
```
