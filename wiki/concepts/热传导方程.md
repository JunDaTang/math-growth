# 热传导方程

1.9.7 节给出的热流基本方程：

```
s μ T_t − κ ΔT = F                                               (1.170)
```

其中 $T(x,t)$ 表示在时刻 $t$ 时在点 $x$ 处的温度，$F(x,t)$ 表示时刻 $t$ 在点 $x$ 放热的功率密度（单位时间内单位体积产生的热量）；常量 $\mu, s, \kappa$ 分别表示质量密度、比热容与热传导系数。

## 推导链

本节给出的动机推导可整理为：

```
Q(t) = ρ(x,t) ΔV                  （一级近似，ρ 为热密度）
ΔQ = s μ ΔV ΔT                    （比热容 s 的定义方程）
ρ_t = s μ T_t                     （取 Δt → 0）
J = −κ grad T                     （傅里叶热传导定律的一级近似）
```

把 $\rho_t$ 与 $\boldsymbol{J}$ 的表示代入 [[concepts/质量平衡方程]] (1.166)，即得 (1.170)。
