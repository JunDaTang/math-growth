# 连续性方程

当没有物质产生（源项 $F = 0$）时，[[concepts/质量平衡方程]] (1.166) 与 [[concepts/通量密度向量]] 关系 $\boldsymbol{J} = \rho\boldsymbol{v}$ 给出所谓的连续性方程：

```
ρ_t + div(ρ v) = 0                                               (1.169)
```

对 [[concepts/不可压缩液体]]，即 $\rho=$ 常量，上式化为

```
div v ≡ 0
```

这说明不可压缩液体的体积不变。

## 推广

1.9.7 节指出：如果把质量换成电荷，且没有电荷生成，则得到关于电荷密度 $\rho$ 的同形方程 (1.169)。因此 (1.169) 是一个形式上的普适守恒表达式，其物理含义由 $\rho$ 与 $\boldsymbol{J}$ 的具体解释决定。
