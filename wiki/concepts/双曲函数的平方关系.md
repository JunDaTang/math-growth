# 双曲函数的平方关系

手册 0.2.11 节以一张 4×4 表给出 $\sinh^{2} x$、$\cosh^{2} x$、$\tanh^{2} x$、$\coth^{2} x$ 四个平方量之间的全部互化表达式（对角线元素为自身，表中以破折号占位）。原始表格逐格数据见 [[10-数学指南实用数学手册--27-0211-双曲函数-tanh-x-和-coth-x--1tmwzib]]。

## 生成规则

整张表只需两个基本恒等式：

1. **基本关系**：$\cosh^{2} x - \sinh^{2} x = 1$，即 $\cosh^{2} x = \sinh^{2} x + 1$、$\sinh^{2} x = \cosh^{2} x - 1$；
2. **商型定义**：$\tanh^{2} x = \frac{\sinh^{2} x}{\cosh^{2} x}$，$\coth^{2} x = \frac{\cosh^{2} x}{\sinh^{2} x} = \frac{1}{\tanh^{2} x}$。

例如 $\tanh^{2} x = \frac{\sinh^{2} x}{\sinh^{2} x + 1} = \frac{\cosh^{2} x - 1}{\cosh^{2} x}$ 与 $\coth^{2} x = \frac{\sinh^{2} x + 1}{\sinh^{2} x} = \frac{\cosh^{2} x}{\cosh^{2} x - 1}$ 都是把定义 (2) 代入关系 (1) 的直接结果。

## 可读出的几条推论

- $\tanh^{2} x < 1 < \coth^{2} x$（实数 $x \neq 0$ 时），因为 $\cosh^{2} x > \sinh^{2} x$；
- $\tanh^{2} x \cdot \coth^{2} x = 1$，表中右下角与左下角互为倒数正体现了这一点；
- 表的对称性并不完全：例如 $\frac{\tanh^{2} x}{1 - \tanh^{2} x} = \sinh^{2} x$ 与 $\frac{1}{\coth^{2} x - 1} = \sinh^{2} x$ 是同一恒等式的两种写法。

平方关系与 [[双曲函数倍角与半角公式]] 中的 $\tanh 2x = \frac{2\tanh x}{1 + \tanh^{2} x}$ 形式相呼应：分母 $1 + \tanh^{2} x$ 正是本表所用商型结构的线性组合。
