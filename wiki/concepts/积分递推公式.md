# 积分递推公式（降次归约）

## 定义

积分递推公式（reduction formula）指把形如 ∫ f_n(x) dx 的积分用同族但阶数更低的积分 ∫ f_{n−k}(x) dx 表出的恒等式，通常由[[分部积分公式|分部积分]]或三角/双曲恒等式得到。它不直接给出闭式，而是把问题逐步降到表内基元积分。

## 在 0.9.5 中的形态

表 0.9.5 的第 3 部分（342–500）中，递推公式以两种形式出现：

**两分支型**（同一式子给出两个方向的归约）：

```latex
348. ∫ sin^n αx cos^m αx dx
   = − sin^{n−1} αx cos^{m−1} αx/(α(n+m)) + ((n−1)/(n+m)) ∫ sin^{n−2} αx cos^m αx dx
   =   sin^{n+1} αx cos^{m−1} αx/(α(n+m)) + ((m−1)/(n+m)) ∫ sin^n αx cos^{m−2} αx dx.
```

**单向型**（每次降一阶或两阶）：

```latex
357. ∫ dx/(sin αx cos^n αx) = 1/(α(n−1)cos^{n−1}αx) + ∫ dx/(sin αx cos^{n−2} αx),  n ≠ 1.
419. ∫ x^n e^{αx} dx = (1/α) x^n e^{αx} − (n/α) ∫ x^{n−1} e^{αx} dx.
437. ∫ (ln x)^n dx = x(ln x)^n − n ∫ (ln x)^{n−1} dx,  n ≠ −1, n ∈ ℤ.
```

## 本部分涉及的递推族

315/316/318、346/350/352 ↔ 358、347/351/353 ↔ 357、348、359、365、369、370、376、380、381、402、411、419、421、430、431、437、439、441、444、446、450、462、491、494、498。它们共同把 342–500 号与前两部分（1–341 号）以及 [[表039基本积分]] 连接起来。

## 使用要点

- 归约方向由参数范围决定：如 462 号对 n > 0 与 n < −1 给出两个相反的递推方向。
- 递推链的终点是基元积分；源文档用「参看第 N 个积分」显式标出终点，本 wiki 将其整理为[[095节递推公式网络形成交叉引用体系]]。
- 递推式成立通常带参数条件（n ≠ 1、m > 1、n > 3 等），使用前须核对。
