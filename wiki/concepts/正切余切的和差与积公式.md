# 正切与余切的和差、积与平方公式

## 约定

下列公式对所有复变量 $x$、$y$ 都成立，除非它们使函数有一个极点。

## 和

$$
\tan x \pm \tan y=\frac{\sin(x\pm y)}{\cos x \cos y},\qquad
\cot x \pm \cot y=\pm\frac{\sin(x+y)}{\sin x \sin y},
$$

$$
\tan x + \cot y=\frac{\cos(x-y)}{\cos x \sin y},\qquad
\cot x - \tan y=\frac{\cos(x+y)}{\sin x \cos y}.
$$

后两式是**混合**形式（正切与余切相加、相减），分母中同时出现 $\cos$ 与 $\sin$。

## 积

$$
\tan x \tan y=\frac{\tan x + \tan y}{\cot x + \cot y}=-\frac{\tan x - \tan y}{\cot x - \cot y},
$$

$$
\cot x \cot y=\frac{\cot x + \cot y}{\tan x + \tan y}=-\frac{\cot x - \cot y}{\tan x - \tan y},
$$

$$
\tan x \cot y=\frac{\tan x + \cot y}{\cot x + \tan y}=-\frac{\tan x - \cot y}{\cot x - \tan y}.
$$

三条公式结构统一：乘积等于"和之比"或"差之比的相反数"，体现了正切与余切之间的互换关系。这些公式是 [[三角函数的和差化积与积化和差公式]] 在正切、余切上的对应形式。
