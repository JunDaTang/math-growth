# 含对数函数的积分（ln x 族）

## 概述

表 0.9.5 以 434–456 号共 23 个条目处理含 ln x 的积分，可分为三组：纯对数幂（434–439）、对数与幂函数复合（440–450）、对数与三角函数的复合（451–456）。本族的两处「非初等」出口分别是 438（[[对数积分li]]）与 445（归结到 420，即 [[积分指数函数Ei]]）。

## 纯对数幂（434–439）

```latex
434. ∫ ln x dx = x(ln x − 1).
435. ∫ (ln x)² dx = x[(ln x)² − 2 ln x + 2].
436. ∫ (ln x)³ dx = x[(ln x)³ − 3(ln x)² + 6 ln x − 6].
437. ∫ (ln x)^n dx = x(ln x)^n − n ∫ (ln x)^{n−1} dx,  n ≠ −1, n ∈ ℤ.
438. ∫ dx/ln x = ln ln x + ln x + (ln x)²/(2·2!) + (ln x)³/(3·3!) + …   → 引出 li(x)
439. ∫ dx/(ln x)^n = −x/((n−1)(ln x)^{n−1}) + (1/(n−1)) ∫ dx/(ln x)^{n−1},  n ∈ ℕ, n > 1.
```

## 对数与幂函数复合（440–450）

```latex
440. ∫ x^m ln x dx = x^{m+1}[ ln x/(m+1) − 1/(m+1)² ],  m ∈ ℕ.
441. ∫ x^m (ln x)^n dx = x^{m+1}(ln x)^n/(m+1) − (n/(m+1)) ∫ x^m (ln x)^{n−1} dx.
442. ∫ (ln x)^n/x dx = (ln x)^{n+1}/(n+1).
443. ∫ ln x / x^m dx = −ln x/((m−1)x^{m−1}) − 1/((m−1)²x^{m−1}),  m ∈ ℕ, m > 1.
444. ∫ (ln x)^n/x^m dx = −(ln x)^n/((m−1)x^{m−1}) + (n/(m−1)) ∫ (ln x)^{n−1}/x^m dx.
445. ∫ x^m dx/ln x = ∫ e^{−y}/y dy，且 y = −(m+1) ln x   （参看 420）.
446. ∫ x^m dx/(ln x)^n = −x^{m+1}/((n−1)(ln x)^{n−1}) + ((m+1)/(n−1)) ∫ x^m dx/(ln x)^{n−1}.
447. ∫ dx/(x ln x) = ln ln x.
448. ∫ dx/(x^n ln x) = ln ln x − (n−1) ln x + (n−1)²(ln x)²/(2·2!) − (n−1)³(ln x)³/(3·3!) + ….
449. ∫ dx/(x(ln x)^n) = −1/((n−1)(ln x)^{n−1}),  n ∈ ℕ, n > 1.
450. ∫ dx/(x^m (ln x)^n) = −1/(x^{m−1}(n−1)(ln x)^{n−1}) − ((m−1)/(n−1)) ∫ dx/(x^m (ln x)^{n−1}).
```

441、444、446、450 互为兄弟递推式，覆盖 x^m、x^{−m} 与 (ln x)^{±n} 的各种组合。

## 对数与三角复合（451–456）

```latex
451. ∫ ln sin x dx = x ln x − x − x³/18 − x⁵/900 − … − 2^{2n−1} B_{2n} x^{2n+1}/(n(2n+1)!) − …
452. ∫ ln cos x dx = −x³/6 − x⁵/60 − x⁷/315 − … − 2^{2n−1}(2^{2n−1}) B_{2n} x^{2n+1}/(n(2n+1)!) − …
453. ∫ ln tan x dx = x ln x − x + x³/9 + 7x⁵/450 + … + 2^{2n}(2^{2n−1}−1) B_{2n} x^{2n+1}/(n(2n+1)!) + …
454. ∫ sin ln x dx = (x/2)(sin ln x − cos ln x).
455. ∫ cos ln x dx = (x/2)(sin ln x + cos ln x).
456. ∫ e^{αx} ln x dx = (1/α) e^{αx} ln x − (1/α) ∫ e^{αx}/x dx   （参看 420）.
```

451–453 的系数由[[伯努利数]] B_{2n} 给出，与本表 403、404、412、413 同源，详见[[正切与余切积分的伯努利数展开]]。452 的系数因子在源中转写为 2^{2n−1}(2^{2n−1})，与逐项验算不符，见 [[095节公式转写疑误汇总]]。
