# 比热容

1.9.7 节以定义方程的形式引入比热容 $s$：

```
ΔQ = s μ ΔV ΔT
```

即一小片体积为 $\Delta V$ 的物质，其热量改变 $\Delta Q$ 与温度改变 $\Delta T$ 之间的关系，式中 $\mu$ 为质量密度。该式在节中被称为「比热容 $s$ 的定义方程」。

## 在推导中的作用

令 $\Delta Q = Q(t+\Delta t) - Q(t)$ 及 $\Delta T = T(x,t+\Delta t) - T(x,t)$，配合一级近似 $Q(t) = \rho(x,t)\Delta V$（$\rho$ 为热密度），取极限 $\Delta t \to 0$ 即得

```
ρ_t = s μ T_t
```

该式再与 [[concepts/傅里叶热传导定律]] 一并代入 (1.166)，导出 [[concepts/热传导方程]]。
