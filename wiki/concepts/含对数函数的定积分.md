# 含对数函数的定积分（0.9.6.2 节）

0.9.6.2 是定积分表的第二个子节，收录条目 33–49，被积函数含 ln x 或 ln(α ± β cos x) 一类的对数因子，积分区间集中在 [0,1]、[0,π/2]、[0,π] 与 [0,∞)。

## 内部结构

**（一）以对数本身为被积函数的「对数对数」积分（条目 33）**

∫₀¹ ln ln x dx = −C ≈ −0.5772，其中 C 为 [[欧拉常数]]（参看 0.1.1）。

**（二）ln x 与有理函数之积（条目 34–37、40）**

- 34：∫₀¹ ln x/(x−1) dx = π²/6；
- 35：∫₀¹ ln x/(x+1) dx = −π²/12；
- 36：∫₀¹ ln x/(x²−1) dx = π²/8；
- 37：∫₀¹ ln(1+x)/(x²+1) dx = (π/8)ln 2；
- 40：∫₀¹ (x^{α−1}−x^{−α})/((1+x)ln x) dx = ln tan(απ/2)（0 < α < 1），此处 ln x 出现在分母。

三条以 π² 的有理倍数表示的结果（34–36）彼此成比例，是同一族积分在分母 (x−1)、(x+1)、(x²−1) 上的分工。

**（三）含 Γ 函数的条目（条目 38、39）**

- 38：∫₀¹ (1−x^α)(1−x^β)/((1−x)ln x) dx = ln[Γ(α+1)Γ(β+1)/Γ(α+β+1)]（α > −1，β > −1，α+β > −1），此条的解释恰为条目 50 的 B 函数取对数；
- 39：∫₀¹ ln(1/x)^α dx = Γ(α+1)（−1 < α < ∞）。

**（四）三角区间上的对数积分（条目 41–43、46–49）**

- 41：∫₀^{π/2} ln sin x dx = ∫₀^{π/2} ln cos x dx = −(π/2)ln 2；
- 42：∫₀^π x ln sin x dx = −π²ln 2/2；
- 43：∫₀^{π/2} sin x ln sin x dx = ln 2 − 1；
- 46：∫₀^π ln(α ± β cos x) dx = π ln[(α+√(α²−β²))/2]（α ⩾ β）；
- 47：∫₀^π ln(α²−2αβcos x+β²) dx = 2π ln α（α ⩾ β > 0）或 2π ln β（β ⩾ α > 0）；
- 48：∫₀^{π/2} ln tan x dx = 0；
- 49：∫₀^{π/4} ln(1+tan x) dx = (π/8)ln 2。

**（五）含振荡因子的对数积分（条目 44、45）**

∫₀^∞ (sin x/x) ln x dx = −(π/2)C，∫₀^∞ (sin x/x) ln²x dx = (π/2)C² + π³/24，两者与 0.9.6.1 中条目 9–11 的 C 模式一致，见 [[096节以欧拉常数C给出若干定积分值]]。

## 与 0.9.5 节的关系

本子节与不定积分表 0.9.5 中的 [[含对数函数的积分]] 同名但内容不同；定积分形式使 ln sin x、ln tan x 这类无初等原函数的积分获得确定值。

## 疑点

条目 38、47 在入库文本中未印出序号，见 [[096节条目编号在多个公式处缺失]]；条目 46 的「α ⩾ β」与条目 47 的「α ⩾ β > 0 或 β ⩾ α > 0」未给出 α、β 的符号前提，见 [[096节公式转写疑误汇总]]。
