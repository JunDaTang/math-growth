# 不动点形式 x = Tx + c

## 定义

《数学指南——实用数学手册》7.2.2 节指出，迭代过程基于将给定线性方程组

$$
Ax + b = 0
$$

化为**不动点形式**

$$
\boxed{x = Tx + c,}
$$

其中 $T$ 称为**迭代矩阵**，$c$ 为常数向量。给定初始向量 $x^{(0)}$ 后，由

$$
x^{(k+1)} = Tx^{(k)} + c, \qquad k = 0, 1, 2, \dots
$$

生成迭代序列。

## 在 7.2.2 节各方法中的具体形式

| 方法 | 迭代方程 | 迭代矩阵 $T$ | 常数向量 $c$ |
|------|----------|--------------|--------------|
| 雅可比（组合步） | $Dx^{(k+1)} = (L+U)x^{(k)} - b$ | $T_{\mathrm{J}} = D^{-1}(L+U)$ | $-D^{-1}b$（由原式推得） |
| 高斯-赛德尔（单步） | $(D-L)x^{(k+1)} = Ux^{(k)} - b$ | $T_E = (D-L)^{-1}U$ | $c_E = (D-L)^{-1}b$ |
| JOR | —— | $T_{\mathrm{JOR}}(\omega) = (1-\omega)E + \omega D^{-1}(L+U)$ | $c_{\mathrm{JOR}} = -\omega D^{-1}b$ |
| SOR | —— | $T_{\mathrm{SOR}}(\omega) = (D-\omega L)^{-1}[(1-\omega)D + \omega U]$ | $c_{\mathrm{SOR}} = -\omega(D-\omega L)^{-1}b$ |

注：上表中雅可比方法的常数向量在源文中未单独以 $c$ 记号写出；表中按 $x^{(k+1)} = D^{-1}(L+U)x^{(k)} - D^{-1}b$ 的对应关系列出，属于由源文方程的直接推得，而非源文原句。

## 收敛条件

不动点序列收敛到解 $x$ 的**当且仅当**条件是迭代矩阵的谱半径满足 $\rho(T) < 1$，见[[concepts/谱半径收敛判据]]。

源文同时指出，除化为不动点形式之外，还可以「通过对逼近泛函求极小」来组织迭代——这正是[[concepts/共轭梯度法]]所走的路线，其基础是[[concepts/二次泛函]]的极小化。
