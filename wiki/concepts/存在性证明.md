# 存在性证明

《数学指南——实用数学手册》4.2.4 节给出的证明类型，与 [[concepts/唯一性证明]]严格区分。来源指出：**一般而言，存在性的证明要比唯一性的证明困难得多**。存在性证明分两种类型：

1. **存在性的抽象证明**（不构造解，仅由公理或一般定理断言解存在）；
2. **存在性的构造证明**（给出可逼近或可计算解的过程）。

来源以方程 $x^2 = 2$ 为例说明两者。

**抽象证明**：定义 $A := \{a \in \mathbb{R} : a < 0 \text{ 或 } (a \geqslant 0 \text{ 且 } a^2 \leqslant 2)\}$、$B := \{a \in \mathbb{R} : a \geqslant 0 \text{ 且 } a^2 > 2\}$；由 $0 \in A$、$2 \in B$ 知两集合非空，据 1.2.2.1 完备性公理得到实数 $\alpha$ 使对所有 $a \in A$、$b \in B$ 有 $a \leqslant \alpha \leqslant b$；再用反证法与 $\varepsilon$ 扰动排除 $\alpha^2 < 2$ 与 $\alpha^2 > 2$ 两种情形（情形 1 中取 $\varepsilon = \min\left(\frac{2-\alpha^2}{2\alpha+1}, 1\right)$ 使 $\alpha+\varepsilon \in A$，与 $\alpha+\varepsilon \leqslant \alpha$ 矛盾）。

**构造证明**：证明迭代 $a_{n+1} = \frac{a_n}{2} + \frac{1}{a_n}$（$a_1 := 2$）收敛于 $\sqrt{2}$。步骤 1 用归纳法证 $a_n > 0$；步骤 2 用[[concepts/伯努利不等式]]证 $a_n^2 \geqslant 2$；步骤 3 证 $a_n - a_{n+1} = \frac{1}{2a_n}(a_n^2-2) \geqslant 0$，故 $(a_n)$ 递减有下界，据 1.2.4.1 收敛性判据得极限 $x$，在迭代式中取极限得 $x^2 = 2$，再由 $a_n \geqslant 0$ 得 $x = \sqrt{2}$。

在 4.2.5 节的算法流程中，存在性的抽象证明被列为解决数学问题的第一步，因为不知道唯一解存在时，计算机给出的可能只是虚幻解。
