# 有理数

1.1.1.2 节的**定义**：所有形式为 a/b 的实数（其中 a、b 是整数）称为有理数；不是有理数的实数称为无理数（见 [[concepts/无理数]]）。

## 分数的构造与运算

把单位线段 E 分成 n 等份，得到点 1/n, 2/n, …, n/n = 1。在分数 m/n 中，m 称为分子，n 称为分母。

- **约分与扩分**：分子、分母乘以（除以）相同的自然数 n，分数值不变。例：2/3 用 4 扩分得 8/12；8/12 除以 4 约分得 2/3。
- **乘法**：分子乘以分子，分母乘以分母。例：2/3 · 3/4 = 6/12。
- **除法**：第 1 个分数乘以第 2 个分数的倒数。例：2/7 ÷ 3/5 = 10/21。
- **加法**：先通分，再分子相加，即「十字相乘法」

```latex
\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}.
```

例：1/2 + 3/4 = (1·4 + 2·3)/(2·4) = 10/8 = 5/4。

- **负分数**：把点 m/n 过原点反射可得点 −m/n，符号由除法规则 (1.2) 决定。例：(−3)/(−4) = 3/4，(−3)/4 = −3/4，3/(−4) = −3/4。

## 符号法则并非任意

手册强调，(1.1)、(1.2) 中符号的选择看似任意，实际上需要保证实数的「简单」计算法则成立。例如要求分配律 a(b + c) = ab + ac 成立，取 a = 4, b = 3, c = −3：

```latex
4(3 + (-3)) = 4 \cdot 0 = 0,
4(3 + (-3)) = 4 \cdot 3 + 4 \cdot (-3) = 12 + 4 \cdot (-3) = 0,
```

由此必须 `4(−3) = −12`，与法则 (1.1) 相符。详见 [[findings/符号法则非任意由分配律确定]]。

## 常用数集符号

现代著作中通用 ℕ（自然数集）、ℤ（整数集）、ℚ（有理数集）、ℝ（实数集）、ℂ（复数集）。

## 幂

对实数 a ≠ 0：

```latex
a^{0} := 1, \quad a^{1} := a, \quad a^{2} := a \cdot a, \quad \dots, \quad
a^{-1} := \frac{1}{a}, \quad a^{-2} := \frac{1}{a^{2}}, \quad \dots
```

例：2⁰ = 1，2² = 4，2³ = 8，2⁻¹ = 1/2，2⁻² = 1/4。
