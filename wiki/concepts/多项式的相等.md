# 多项式的相等

来源 2.1.5 节按定义规定两个多项式相等：

```
a_0 + a_1 x + ... + a_n x^n = b_0 + b_1 x + ... + b_m x^m
```

当且仅当 $n = m$，并且 $a_j = b_j$（对所有 $j$）——亦即两个多项式有**相同的次数和相同的系数**。

## 要点

- 相等是逐系数的、形式的（formal）等同，不依赖把 $x$ 代入具体数值后的取值。
- 该规定是后续带余除法「唯一性」陈述的前提：唯一性指的是满足 (2.19) 且 $\deg R < \deg D$ 的 $Q,R$ 在「相等」这个意义下唯一。
