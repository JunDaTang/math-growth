# 平面直线的一般方程与截距式

## 一般方程

《数学指南——实用数学手册》0.1.7.1 节指出：所有直线都可以定义成满足如下方程的点的集合：

$$
A x + B y + C = 0
$$

其中 A, B, C 为常数，满足条件 $A^{2} + B^{2} \neq 0$。原文示例：当 A = 1，B = C = 0 时，得到 y 轴方程 $x = 0$。

## 截距式（原文式 0.8）

若用 $b$ 除斜截式方程 $y = mx + b$，并令 $\frac{1}{a} := -\frac{m}{b}$，就得到

$$
\frac {x}{a} + \frac {y}{b} = 1 \tag{0.8}
$$

当 $y = 0$（$x = 0$）时，可以口算得出直线在点 $(a,0)$ 处与 x 轴相交（在点 $(0,b)$ 处与 y 轴相交）。即 $a$、$b$ 分别是 x 截距与 y 截距。

原文示例：若用 4 除直线方程 $y = -8x + 4$，就得到 $\frac{y}{4} = -2x + 1$，因此 $2x + \frac{y}{4} = 1$；令 $y = 0$ 得 $x = \frac{1}{2}$，故直线与 x 轴在 $x = \frac{1}{2}$ 处相交。

> 记法提示：原文把式 (0.8) 的标题写作「直线的 x 轴方程」，但公式实际描述的是直线在两条轴上的截距，学界通常称为**截距式**。此处保留原文措辞并标注疑问，公式内容本身无疑义。

## 与斜截式的关系

- 斜截式 $y = mx + b$ 见 [[直线的斜截式方程]]。
- 一般方程是二者的统一形式；特别地，$x = 0$（y 轴）不是斜截式的特例。
- 注意区分：三维空间中平面的一般方程另见 [[平面的一般方程]]（手册 0.1.8），两者对象不同。
