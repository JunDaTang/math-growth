# 有理参数化

有理参数化（亦称有理替换、有理表示）指用有理函数把曲线上的点表示为一个参数 $t$ 的函数。在《数学指南——实用数学手册》3.8.3 节中，它是把代数型积分化为有理被积函数积分的核心手段。

## 在本节中的形式

若代数曲线 $C$ 给出参数表示

```latex
x = x(t), \quad w = w(t) \tag{3.55}
```

则积分

```latex
J = \int R(x, w)\,\mathrm{d}x \tag{3.54}
```

通过替换化为

```latex
J = \int R(x(t), w(t))\, x'(t)\,\mathrm{d}t \tag{3.56}
```

(3.56) 的被积函数彼此间只含有理运算，因此可借助部分分式分解计算。

## 存在问题

源文以经验法则给出：这样的有理表示存在**当且仅当**曲线 $C$ 的亏格为零。历史叙述方面，源文提到大约在 1700 年，早在牛顿和莱布尼茨的时代就已在寻找新的有理替换；此后「对哪些积分确实存在有理替换」成为关键论点。详见 [[亏格]] 与 [[亏格判据有理表示等价]]。

## 本节的两个实例

- 圆 $C: x^{2} + w^{2} = 1$ 的有理参数化为

```latex
x = \frac{t^{2} - 1}{t^{2} + 1}, \quad w = \frac{2t}{t^{2} + 1}
```

它把 (3.57) 化为有理积分，并解释了 [[万能替换]] $t = \tan\frac{\varphi}{2}$ 为何万能。

- 无奇点三次曲线 $w^{2} = (x - e_{1})(x - e_{2})(x - e_{3})$ 亏格为 1，不存在有理参数化，因此 [[椭圆积分]] 不能由有理替换解决。
