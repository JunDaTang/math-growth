# 无穷重伯努利试验

## 构造（6.2.5.7 节）

前面已经考虑了 $n$ 重伯努利试验（见 [[伯努利模型]]）；为了系统阐述 [[强大数定律]]，需要将试验重数增加到**无穷大**。

考虑由基本事件

```
e_{i_1 i_2} ...
```

组成的全体事件 $E$，其中每个 $i_j$ 的值都等于 1 或 2。符号 $e_{12}$ 表示在第一次试验中 $e_1$ 发生、在第二次试验中 $e_2$ 发生……

用 $A_{i_1 \ldots i_n}$ 表示由所有形如 $e_{i_1 \ldots i_n}$ 的基本事件组成的集合，并规定

```
P(A_{i_1 i_2 ... i_n}) = p_{i_1 i_2 ... i_n},        (6.29)
```

其中 $p_1 := p$，$p_2 := 1 - p$（见 (6.18)）。

用 $\mathcal{S}$ 表示对所有的 $n$ 包含一切集合 $A_{i_1 \ldots i_n}$ 的 $E$ 的最小 $\sigma$ 域。

## 存在唯一性定理

**定理** 在 $\mathcal{S}$ 的子集上存在满足性质 (6.29) 的唯一确定的概率测度 $P$。于是 $(E, \mathcal{S}, P)$ 是一个 [[概率空间]]。

这一定理是 [[科尔莫戈罗夫公理化概率论]] 框架下把有限重试验「取极限」为无穷重试验的合法性依据：先给出柱集上的概率规定，再取最小 $\sigma$ 域并断言测度唯一延拓。

## 其上的频率

通过

```
H_n(e_{i_1 ... i_n} ...) = (1/n) × (e 的满足 i_j = 1 且 1 ≤ j ≤ n 的脚标 i_j 的个数)
```

定义随机变量 $H_n : E \to \mathbb{R}$。

## 直接后果

在该空间上，博雷尔（1909）-坎泰利（1917）强大数定律成立：

```
lim_{n→∞} H_n = p  在 E 上几乎必然成立。
```

即频率这一随机变量序列在 [[几乎必然收敛]] 意义下收敛到 $p$。这与 6.2.5.3 中依概率收敛的伯努利大数定律 (6.19) 形成强弱对照，参阅 [[弱大数定律]]、[[强大数定律]]。
