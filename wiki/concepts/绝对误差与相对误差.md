# 绝对误差与相对误差

## 定义

对函数 $y = f(x)$，设自变量误差为 $\Delta x$，则：

- **绝对误差**：$\Delta f = f(x + \Delta x) - f(x)$，即函数值的直接偏差；
- **相对误差**：$\dfrac{\Delta f}{f(x)}$，即绝对误差相对于函数值本身的比值。

多变量情形下，绝对误差定义为

```text
Δf := f(x₁ + Δx₁, …, x_N + Δx_N) − f(x₁, …, x_N)
```

## 为什么需要两种误差

两种误差在组合运算下表现出不同的可加性：

- **加法**（例 2）：$H = \sum_k f_k$ 时绝对误差直接相加，$\Delta H = \sum_k \Delta f_k$；
- **乘法**（例 3）：$H = \prod_k f_k$ 时相对误差（对数误差）相加，$\Delta H / H = \sum_k \Delta f_k / f_k$；
- **除法**（例 4）：$H = f/g$ 时相对误差相减，$\Delta H / H = \Delta f / f - \Delta g / g$。

也就是说，绝对误差适合描述加减法，相对误差适合描述乘除法。原书把乘除法的相对误差相加、相减分别表述为「相对对数误差相加」「相对对数误差相减」，因为 $\mathrm{d}\ln f = \mathrm{d}f/f$。
