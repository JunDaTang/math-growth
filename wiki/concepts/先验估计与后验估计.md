# 先验估计与后验估计

《数学指南——实用数学手册》4.2.5 节对近似值估计所作的两分：

- (a) **先验估计**：在（计算机）作计算之前得到的关于近似值误差的信息；
- (b) **后验估计**：使用从（计算机）已经作过的计算所获得的信息。

来源把这两个概念类比于[[entities/康德]]（1724—1804）的哲学，并给出实际经验：**后验估计比先验估计更精确**。

以 $\sqrt{2}$ 的迭代计算（$a_{n+1} = a_n/2 + 1/a_n$，$\Delta_n = a_n - \sqrt{2}$）为例，来源给出的估计为

```
Δ_{n+2} ≤ 10^{−2^n}          （先验估计）
2/a_n ≤ √2 ≤ a_n             （后验估计）
```

后验估计给出的是一对上下界，可直接用于误差界；先验估计则给出随步数 $n$ 呈双指数衰减的误差上界，与[[concepts/二次收敛]]性质相配合。
