# 矩阵环与矩阵代数

来源《数学指南》2.1.3 节用抽象代数语言对两类矩阵集合作了定位。其原文表述是：「从代数角度看，我们在此所看到的事实是矩阵的集合形成一个（非交换）环，而不是域。」

## Mat(m,n)：复数域上的线性空间

对于 `A, B, C ∈ Mat(m,n)` 及标量 `α`，满足

```
A + B = B + A
(A + B) + C = A + (B + C)
A + O = A
α(A + B) = αA + αB
```

来源结论：集合 `Mat(m,n)` 形成**复数域上的线性空间**（来源指向 2.3.2 节）。

## Mat(n,n)：复数域上的（非交换）环与代数

设 `A, B, C ∈ Mat(n,n)`，`E` 为 `n × n` [[单位矩阵]]，`O` 为 `n × n` [[零矩阵]]，则

```
A(BC) = (AB)C
A(B + C) = AB + AC
AE = EA = A
AO = OA = O
A + O = A
```

来源结论：集合 `Mat(n,n)` 形成**复数域上的（非交换）环**，并且是**复数域上的代数**（来源指向 2.4.1 和 2.5.2 两节）。

## 之所以不是域：两条证据

1. [[矩阵乘法的非交换性]]：`n ≥ 2` 时一般 `AB ≠ BA`。
2. [[零因子-矩阵环]]：存在 `A ≠ O`、`B ≠ O` 而 `AB = O`。

## 与群结构的对照

去掉不可逆矩阵后，`det A ≠ 0` 的方阵全体 `GL(n,ℂ)` 形成**群**而不是环（因为并非任意两个正则矩阵之和仍正则），见 [[一般线性群]]。
