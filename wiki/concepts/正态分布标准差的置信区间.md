# 正态分布标准差的置信区间

6.3.3.2 节给出在正态假定下标准差 $\sigma$（等价地方差 $\sigma^2$）的置信区间。

## 前提

假设 $X$ 服从正态分布 $N(\mu, \sigma)$。

## 统计说明（6.31）

关于标准差的不等式

```text
(n-1)(Δx)^2 / b ≤ σ^2 ≤ (n-1)(Δx)^2 / a     (6.31)

其中  a := χ²_{1-α/2} ，b := χ²_{α/2}
分布自由度 m = n - 1
```

成立的概率为 $1 - \alpha$。$a$ 与 $b$ 的值可在 0.4.6.4 中查到。

## 推理

$A := (n-1)S^2/\sigma^2$ 服从自由度为 $n - 1$ 的 [[卡方分布]]。由图 0.50，

```text
P(a ≤ A ≤ b) = P(A ≥ a) - P(A ≥ b) = 1 - α/2 - α/2 = 1 - α
```

因此

```text
a ≤ (n-1)(Δx)^2 / σ² ≤ b
```

成立的概率为 $1-\alpha$，(6.31) 由此导出。

## 要点

- 两个分位点的对应方向容易误读：下界分母是 $b := \chi^2_{\alpha/2}$，上界分母是 $a := \chi^2_{1-\alpha/2}$。因为 $\chi^2_{\alpha/2} < \chi^2_{1-\alpha/2}$，分母小者给出较大的商，故 $b$ 出现在下界、$a$ 出现在上界。这与 (6.30) 中单一分位点的用法不同。
- 区间是关于 $\sigma^2$ 的，源文标题写「标准差的置信区间」，实际给出的是方差 $\sigma^2$ 的区间（开方即得 $\sigma$ 的区间）。
- 自由度 $m = n - 1$，参见 [[自由度]]。
- 依据的抽样分布是 [[卡方分布]]，来自 6.3.2 节关于方差估计量抽样分布的结论（见 [[方差的估计量S2]]）。
