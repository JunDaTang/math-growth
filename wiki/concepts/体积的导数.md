# 体积的导数

1.9.7 节用「体积的导数」把积分形式的守恒关系化为点态方程。设 $g$ 是在点 $P$ 的某个邻域内连续的一实值函数，$(D_n)$ 为 [[concepts/容许区域]] 序列（例如球），均包含 $P$ 且直径趋于零，则

```
g(P) = lim_{n→∞} ( ∫_{D_n} g(x) dx ) / ( meas D_n )        (1.165)
```

右端表达式称为体积的导数；$\mathrm{meas}\,D_n$ 表示 [[concepts/勒贝格测度]]。

## 用途

若两个体积积分在任意子区域上相等，则被积函数在连续点处相等——这正是由

```
∫_D ρ_t dx = −∫_D div J dx + ∫_D F(x,t) dx
```

得到 [[concepts/质量平衡方程]] (1.166) 的桥梁。该结论的前提是函数在点 $P$ 的邻域内连续。
