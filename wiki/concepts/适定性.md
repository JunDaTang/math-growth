# 适定性（well-posedness）

本节用于刻画「初始条件的小变动是否只导致解的小变动」。源文表述为：「初始量 $N_0$ 的小变动导致解的小变动」，并给出定量不等式。

本节三次出现适定性讨论：

- **1.12.1.1（衰减）**：适定。对两个解 $N,N_*$ 有
```latex
\|N-N_*\| \le |N(0)-N_*(0)|,
```
其中范数 $\|N\| := \max_{0\le t\le \mathcal T}|N(t)|$。

- **1.12.1.2（增长）**：**不适定**。$\|N-N_*\| = \mathrm{e}^{\alpha \mathcal T}|N(0)-N_*(0)|$，初值差随时间指数放大。

- **1.12.1.5（谐振子）**：适定。不等式
```latex
\|x-x_*\| \le |x(0)-x_*(0)| + \frac{1}{\omega}|x'(0)-x_*'(0)|
+ \frac{\mathcal F}{\omega}\max_{0\le t\le \mathcal T}|F(t)-F_*(t)|.
```
