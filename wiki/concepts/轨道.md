# 轨道（Orbit）

在《数学指南——实用数学手册》1.9.1 节中，轨道是这样引入的：选取一个固定点 O，令

```
r(t) := 向量 OP(t)
```

则方程

```
r = r(t),  α ≤ t ≤ β
```

描述了在时刻 t 时坐标为 P(t) 的粒子的运动。

换言之，**轨道**就是向量值函数 r(t) 在空间中的像（点的集合），而参数 t 通常解释为时间。固定点 O 的选取给出了一个参照原点，使每个位置都被表示为 [[concepts/标量与向量]] 意义下的位置向量。

由此，粒子运动的全部信息被编码为一个 [[concepts/向量值函数]]；其一阶导数给出 [[concepts/速度向量]]（方向即轨道的切线方向），二阶导数给出 [[concepts/加速度向量]]。在 [[concepts/笛卡儿坐标系]] 中，轨道由三个分量函数 x(t), y(t), z(t) 描述，见 [[concepts/向量函数的坐标表示]]。
