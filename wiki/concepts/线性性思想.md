# 线性性思想

2.3.1 节指出，函数的微分和积分是线性运算：

```text
(αf + βg)′(x) = αf′(x) + βg′(x)
∫_G (αf + βg) dx = α ∫_G f dx + β ∫_G g dx
```

一般地，线性算子 L 满足

```text
L(αf + βg) = αLf + βLg
```

其中 f、g 可以是函数、向量、矩阵等。线性性的思想在许多数学和物理问题中都很重要。它是 [[线性代数]] 的出发点，并衍生出 [[叠加原理-线性算子]] 与 [[线性化原理]]。与拓扑学的联系体现在用德拉姆上同调群或向量丛等线性结构研究拓扑空间的定性性质。
