# 双曲余弦 $\cosh x$

## 定义

对全体复数 $x$：

$$
\cosh x := \frac{\mathrm{e}^{x}+\mathrm{e}^{-x}}{2}.
$$

读音为 “cosh”。对实变量 $x$，其图像见图 0.34(b)（在 [[图0-34-双曲函数图像]] 中记录该图在本 wiki 加载失败）。

## 基本性质（据《数学指南——实用数学手册》0.2.10）

- 偶性：$\cosh(-x) = \cosh x$
- 复域周期性：$\cosh(x + 2\pi \mathrm{i}) = \cosh x$
- 幂级数（只含偶次项）：$\cosh x = 1 + \dfrac{x^{2}}{2!} + \dfrac{x^{4}}{4!} + \dfrac{x^{6}}{6!} + \dots$
- 导数：$\dfrac{\mathrm{d}\cosh x}{\mathrm{d}x} = \sinh x$
- 加法定理：$\cosh(x \pm y) = \cosh x \cosh y \pm \sinh x \sinh y$
- 倍角：$\cosh 2x = \sinh^{2} x + \cosh^{2} x$
- 半角：$\cosh \frac{x}{2} = \sqrt{\frac{1}{2}(\cosh x + 1)},\ x \in \mathbb{R}$
- 和差化积：$\cosh x + \cosh y = 2 \cosh \frac{1}{2}(x+y)\cosh \frac{1}{2}(x-y)$；$\cosh x - \cosh y = 2 \sinh \frac{1}{2}(x+y)\sinh \frac{1}{2}(x-y)$

## 与其他页面的关系

- 与 [[双曲正弦]] 由基本恒等式 $\cosh^{2} x - \sinh^{2} x = 1$ 相联系。
- 与三角函数的关系：$\cosh \mathrm{i} x = \cos x$，见 [[双曲函数与三角函数的关系]]。
- 命名理据：$x = a \cosh t$ 是双曲线参数方程的横坐标分量。
- 与 [[等轴双曲线]]（$y = b/x$ 型）**不是同一对象**，不可互链为同一概念。
