# 商域与分式域

设 $P$ 是一个 [[concepts/整环]]，且不是仅由零元素组成。则存在一个 [[concepts/域与体]] $Q(P)$ 具有性质：

```
(i)  P 含在 Q(P) 中；
(ii) 若 P 含在域 K 中，则 K 的包含 P 的最小子域是 Q(P)。
```

域 $Q(P)$ 称为 $P$ 的**商域**（分式域）。

## 显式构造

考虑所有有序对 $(a,b)$（$a,b\in P$，$b\ne0$）的集合，定义

$$
(a,b)\sim(c,d) \iff ad=bc
$$

这是等价关系；等价类 $[(a,b)]$ 关于下列运算构成域：

```
[(a,b)][(c,d)] := [(ac, bd)]
[(a,b)] + [(c,d)] := [(ad + bc, bd)]
```

将 $[(a,b)]$ 写作 $\frac{a}{b}$，则 $Q(P)$ 由全体 $\frac{a}{b}$ 组成，计算按通常分式规则：

```
a/b = c/d  ⇔  ad = bc
(a/b)(c/d) = ac/bd,   a/b + c/d = (ad + bc)/bd
```

令 $\varphi(a):=\frac{ar}{r}$（$r\ne0$）得到同态 $\varphi:P\to Q(P)$，与 $r$ 无关；于是可把 $a$ 与 $\frac{ar}{r}$ 等同，$\frac{r}{r}$ 是单位元，且 $\frac{a}{b}=ab^{-1}$。

这种看似复杂的剩余类构造只是保证分式的形式运算不导致矛盾。

## 例

- $\mathbb{Z}$ 的商域是有理数域 $\mathbb{Q}$。
- 整环 $P\ne\{0\}$ 上的 [[concepts/多项式环]] $P[x]$ 的商域记作 $P(x)$，即 [[concepts/有理函数域]]。
