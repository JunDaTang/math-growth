# 矩阵乘法

## 基本思想（公式 2.7）

矩阵乘法的基本思想包含在行向量与列向量的配对积中：

```
(a, b) · (α; β) := aα + bβ                                  (2.7)
```

来源例 3：`(1,3) · (2; 4) = 1·2 + 3·4 = 2 + 12 = 14`。

公式 (2.7) 的自然推广为内积形式：

```
(a_1, a_2, ..., a_n) · (α_1; α_2; ...; α_n) = a_1α_1 + a_2α_2 + ... + a_nα_n
```

## 乘积定义（公式 2.8）

矩阵 `A ∈ Mat(m,n)` 与矩阵 `B ∈ Mat(n,l)` 的乘积是一个矩阵 `C = AB ∈ Mat(m,l)`，它的元素 `c_jk` 由下列法则定义：

```
c_jk = A 的第 j 行乘以 B 的第 k 列                            (2.8)
```

若将 A（及 B）的元素记作 `a_..`（及 `b_..`），则公式为

```
c_jk = Σ_{s=1}^{n} a_js b_sk
```

## 相配（可乘条件）

> 矩阵乘积 `AB` 存在，当且仅当 A 与 B **相配**，亦即 A 的列数等于 B 的行数。

## 来源例题

例 4：设 `A := (1 2; 3 4)`、`B := (2 1; 4 1)`，则

```
c_11 = (1,2)·(2;4) = 10
c_12 = (1,2)·(1;1) = 3
c_21 = (3,4)·(2;4) = 22
c_22 = (3,4)·(1;1) = 7

AB = C = ( 10  3 )
         ( 22  7 )
```

来源另给：

```
( 1 2 ) ( 1 0 2 )   ( 1 2 4 )
( 0 1 ) ( 0 1 1 ) = ( 0 1 1 )
```

## 方阵乘法的代数性质

设 `A, B, C ∈ Mat(n,n)`，`E` 为 [[单位矩阵]]，`O` 为 [[零矩阵]]：

```
A(BC) = (AB)C            （结合律）
A(B + C) = AB + AC       （分配律）
AE = EA = A
AO = OA = O
```

来源结论：`Mat(n,n)` 形成复数域上的（非交换）环，并且是复数域上的代数。见 [[矩阵环与矩阵代数]]。

## 与实数乘法的差异

- 一般不满足交换律，见 [[矩阵乘法的非交换性]]。
- 存在 [[零因子-矩阵环]]，即 `A ≠ O`、`B ≠ O` 而 `AB = O` 可能成立。
