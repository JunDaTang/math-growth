# 双曲正弦 $\sinh x$

## 定义

对全体复数 $x$：

$$
\sinh x := \frac{\mathrm{e}^{x}-\mathrm{e}^{-x}}{2}.
$$

读音为 “sinch”。对实变量 $x$，其图像见图 0.34(a)（在 [[图0-34-双曲函数图像]] 中记录该图在本 wiki 加载失败）。

## 基本性质（据《数学指南——实用数学手册》0.2.10）

- 奇性：$\sinh(-x) = -\sinh x$
- 复域周期性：$\sinh(x + 2\pi \mathrm{i}) = \sinh x$
- 幂级数（只含奇次项）：$\sinh x = x + \dfrac{x^{3}}{3!} + \dfrac{x^{5}}{5!} + \dfrac{x^{7}}{7!} + \dots$
- 导数：$\dfrac{\mathrm{d}\sinh x}{\mathrm{d}x} = \cosh x$
- 加法定理：$\sinh(x \pm y) = \sinh x \cosh y \pm \cosh x \sinh y$
- 倍角：$\sinh 2x = 2 \sinh x \cosh x$
- 半角：$x \geqslant 0$ 时 $\sinh \frac{x}{2} = \sqrt{\frac{1}{2}(\cosh x - 1)}$；$x < 0$ 时取负号
- 和差化积：$\sinh x \pm \sinh y = 2 \sinh \frac{1}{2}(x \pm y) \cosh \frac{1}{2}(x \mp y)$

## 与其他页面的关系

- 与 [[双曲余弦]] 由基本恒等式 $\cosh^{2} x - \sinh^{2} x = 1$ 相联系。
- 与三角函数的关系：$\sinh \mathrm{i} x = \mathrm{i} \sin x$，见 [[双曲函数与三角函数的关系]]。
- 命名理据：$y = b \sinh t$ 是双曲线参数方程的纵坐标分量。
- 与 [[等轴双曲线]]（$y = b/x$ 型）**不是同一对象**，不可互链为同一概念。
