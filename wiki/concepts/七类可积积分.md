# 七类可积积分（0.9.4 的分类体系）

《数学指南——实用数学手册》0.9.4 节把可由「通用代换」机械归约为有理函数积分的积分划分为**七类**。这一分类是本节的骨架，也是 [[重要代换]] 概念在手册中的具体展开。

## 分类总表

| 类别 | 积分形式 | 归约手段 |
|------|----------|----------|
| 第一类 | $\int R(\sinh x,\cosh x,\tanh x,\coth x,e^{x})\,\mathrm{d}x$ | $t=\mathrm{e}^{x}$ |
| 第二类 | $\int R(\sin x,\cos x,\tan x,\cot x)\,\mathrm{d}x$ | $t=\mathrm{e}^{\mathrm{i}x}$ 或 $t=\tan(x/2)$ |
| 第三类 | $\int R\!\left(x,\sqrt[n]{(\alpha x+\beta)/(\gamma x+\delta)}\right)\mathrm{d}x$ | 分式根式代换，$\alpha\delta-\beta\gamma\neq0$ |
| 第四类 | $\int R\!\left(x,\sqrt{\alpha x^{2}+2\beta x+\gamma}\right)\mathrm{d}x$ | 配方 → 表 0.44；或表 0.45 欧拉代换 |
| 第五类 | $\int R\!\left(x,\sqrt{\alpha x^{4}+\beta x^{3}+\gamma x^{2}+\delta x+\mu}\right)\mathrm{d}x$ | 椭圆函数代换（椭圆积分） |
| 第六类 | $\int R(x,w(x))\,\mathrm{d}x,\ P(x,w)=0$ | 阿贝尔积分理论 |
| 第七类 | $\int x^{m}(\alpha+\beta x^{n})^{k}\,\mathrm{d}x$ | 表 0.46 三种情形 |

## 共同模式

七类的归约目标一致：**得到一个关于新变量 $t$ 的有理函数**，随后用 [[部分分式分解]]（本节参看 0.9.3）。这也是手册把本节安排在「积分表」之下的原因——它提供的是把积分「送进」有理函数这个可机械处理类别的通道。

## 类别之间的判别

- 前三类按**被积函数的构造方式**区分（指数式、三角式、分式根式）。
- 第四类与第五类按**根式的多项式次数**区分：二次 → 表 0.44／表 0.45；四次（或退化情形 $\alpha=0,\beta\neq0$）→ 椭圆积分。
- 第六类是被积函数中出现**任意代数函数**的一般情形，前五类都可视为其特例。
- 第七类是具有特定形状 $\int x^{m}(\alpha+\beta x^{n})^{k}\mathrm{d}x$ 的积分，可积性有**充要条件**（表 0.46），是七类中唯一带「当且仅当」判定的。

## 方法论限定

源文件强调：几乎没有积分可以仅凭初等函数解决；在特殊情况下，用特殊代换也许更能简化必要的计算，而今天的计算机代数系统能够实现这一目标。因此本分类应视为**可执行的归约清单**，而不是积分可达性的完整刻画。
