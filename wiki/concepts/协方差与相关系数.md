# 协方差与相关系数

## 定义

《数学指南——实用数学手册》6.1.5 节：称数

```
Cov(X,Y) := (X − X̄)(Y − Ȳ) 的均值
```

为 $X$ 和 $Y$ 的**协方差**。显然有

```
Cov(X,Y) = ∫∫_{ℝ²} (x − X̄)(y − Ȳ) φ(x,y) dx dy
```

其中 $\varphi$ 为随机向量 $(X,Y)$ 的联合概率密度。关于两个随机变量的一个基本问题是：$X$ 和 $Y$ 是强相关还是弱相关？答案由**相关系数**

```
r = Cov(X,Y) / (ΔX ΔY)
```

给出。文中强调，相关系数 $r$ 恒满足

```
−1 ≤ r ≤ 1,  即 r² ≤ 1
```

并定义 $r^2$ 越大，$X$ 与 $Y$ 的相关性越强；等价地，$|r|$ 越大，所测量的两个量的相关性（相互依赖性）越强。

## 在统计物理学中的推广

6.1.6 节把同一构造用于相空间上的函数 $A = A(q,p)$、$B = B(q,p)$：

```
r = (1/(ΔA ΔB)) · (A − Ā)(B − B̄) 的均值
```

## 与其他量的关系

- 与 [[concepts/回归直线与最小二乘法]]：回归直线的斜率包含因子 $r\,\Delta Y/\Delta X$，并且最小残差满足 $\overline{(Y - a - bX)^2} = (\Delta Y)^2(1 - r^2)$。
- 与 [[concepts/随机变量的独立性]]：若 $X$ 与 $Y$ 相互独立，则 $r = 0$（见该页脚注的推导）。
