# 幂级数逐项求导

## 源文陈述

设

```latex
f(z) = a_0 + a_1(z - a) + a_2(z - a)^2 + a_3(z - a)^3 + \dots
```

源文指出：该函数在[[收敛圆|收敛域]]内部的每个点处都可微（参看 1.10.3），并可以通过对幂级数逐项求导得到函数的导数，即

```latex
f'(z) = a_1 + 2a_2(z - a) + 3a_3(z - a)^2 + \dots .
```

即逐项求导把系数 $a_n$ 变为 $n a_n$。

## 例 2（源文）

令 $f(z) := \mathrm{e}^{z}$。由

```latex
f(z) = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \dots
```

即得

```latex
f'(z) = 1 + z + \frac{z^2}{2!} + \dots = \mathrm{e}^{z}, \quad \text{对所有} z \in \mathbb{C}.
```

## 相关陈述与张力

源文紧接着给出断言：「对所有可以展成幂级数的函数，实导数与复导数一致」，并指向 0.8.1 的初等函数导数表。该断言未界定「可以展成幂级数」的确切适用范围，见 [[1143节实导数与复导数一致断言的适用范围未界定]]。

此外，源文引用的 1.10.3 与 0.8.1 两处小节尚未入库，见 [[1143节引用的082与1103与11410未入库]]。
