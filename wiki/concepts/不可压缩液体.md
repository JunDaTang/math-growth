# 不可压缩液体

1.9.7 节把「$\rho=$ 常量」的情形称作不可压缩液体的一个特例。代入 [[concepts/连续性方程]]

```
ρ_t + div(ρ v) = 0
```

可得

```
div v ≡ 0
```

即速度场的散度处处为零。

## 解释

本节给出的物理解释是：这说明不可压缩液体的体积不变。数学上，$\mathrm{div}\,\boldsymbol{v} \equiv 0$ 意味着速度场是「无源」的，流体在任何一点既不产生也不消失。这一点与 1.9.3 节关于散度描述体积相对变化的讨论一致，参见 [[findings/形变定理旋度描述旋转散度描述体积相对变化]]。
