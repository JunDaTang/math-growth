# 通量密度向量

在 1.9.7 节中，$\boldsymbol{J}(x,t)$ 表示在时刻 $t$ 时在点 $x$ 处的「质量流的通量密度向量」，单位为「单位面积与时间的质量」。它在边界上的法向分量积分

```
B′(t) = ∫_{∂D} J_n dF
```

给出单位时间流出区域 $D$ 的物质质量，并通过 [[concepts/高斯定理]] 等于 $\int_D \mathrm{div}\,\boldsymbol{J}\,\mathrm{d}x$。

## 与速度场的关系

若 $\boldsymbol{v}=\boldsymbol{v}(x,t)$ 是物质 $S$ 在液体中流动形成的速度场，则

```
J = ρ v                                                          (1.168)
```

在热流情形中，$\boldsymbol{J}$ 由 [[concepts/傅里叶热传导定律]] 给出：$\boldsymbol{J} = -\kappa\,\mathrm{grad}\,T$。因此「通量密度向量」是一个随物理情境换装的形式概念：物质流、电流与热流共用同一数学位置。
