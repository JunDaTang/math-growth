# 度量空间

《数学指南——实用数学手册》1.3.2 节以「动机」段落说明引入度量空间的目的：把单变量函数极限的概念推广到多变量函数，并最终通向泛函分析（原文引参考文献 [212]）。手册把这一抽象化描述为「把更多不同的概念替换成几个极其基本概念的推导」。

## 定义（三条公理）

一个非空集合 $X$ 称为**度量空间**，如果对 $X$ 里每个有序点对 $(x, y)$ 存在一个实数 $d(x, y) \geqslant 0$，使得对所有 $x, y, z \in X$：

```
(i)   d(x, y) = 0 当且仅当 x = y
(ii)  d(x, y) = d(y, x)（对称性）
(iii) d(x, z) ⩽ d(x, y) + d(y, z)（三角不等式）
```

数 $d(x, y)$ 称为 $x$ 与 $y$ 之间的距离。由定义，空集也是度量空间。公理 (iii) 即 wiki 中已有的 [[三角不等式]]。

## 两条基本事实

- **子集仍是度量空间**：度量空间的每个子集仍是具有相同距离函数的一个度量空间。
- **极限唯一性**：若 $\lim_{n\to\infty} x_n = x$（即 $\lim_{n\to\infty} d(x_n, x) = 0$）存在，则它被唯一确定。

## 标准例子

- **例 1（X = ℝ）**：$d(x, y) := |x - y|$，诱导出通常（朴素）的距离概念（见 1.2.3.1）。
- **例 2（X = ℝ^N）**：$d(x, y) := \sqrt{\sum_{j=1}^N (\xi_j - \eta_j)^2}$，见 [[欧几里得范数]]；$N = 1, 2, 3$ 时与朴素距离一致（图 1.23）。此时

```
lim_{n→∞} x_n = x   ⟺   lim_{n→∞} ξ_{jn} = ξ_j,  j = 1, …, N
```

即 ℝ^N 中的收敛等价于各分量的收敛。
- **例 4（单位圆）**：实数直线 ℝ 上的每个点 $x$ 对应单位圆上唯一的点 $x_*$，北极点 N 不对应 ℝ 的任何点，通常把 N 替换成 $+\infty$ 与 $-\infty$，从而构造出 [[单位圆紧化实数集]] $\overline{\mathbb{R}}$。
