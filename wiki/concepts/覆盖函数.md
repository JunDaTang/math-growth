# 覆盖函数

4.4.1 节用于把真值推及全部表达式的映射：

$$
b: \{q _ {1}, q _ {2}, \dots \} \rightarrow \{\mathrm{T}, \mathrm{F} \}.
$$

它为每个命题变元 $q_j$ 联系一个值 T（真）或 F（假）。给定 $b$ 后，任何表达式按下列规则递归取值：

```
(i)   value(q_j) := b(q_j)
      value(¬A) := non(value(A))          ← 源文此处缺编号 (ii)
(iii) value(A ∧ B) := et(value(A), value(B))
(iv)  value(A ∨ B) := vel(value(A), value(B))
(v)   value(A → B) := seq(value(A), value(B))
(vi)  value(A ↔ B) := eq(value(A), value(B))
```

节内例 1：对 $b(q) = \mathrm{T}$、$b(p) = \mathrm{F}$，得 $\operatorname{value}(\neg p) = \operatorname{non}(\mathrm{F}) = \mathrm{T}$，以及 $\operatorname{value}(q \to \neg p) = \operatorname{seq}(\mathrm{T}, \mathrm{T}) = \mathrm{T}$。

覆盖函数是[[concepts/重言式]]与[[concepts/等价表达式]]的定义量化对象：「对任何覆盖函数取值 T」/「对任何覆盖函数取相同值」。源文中第二行规则缺编号 (ii)，见 [[queries/44节记法编号讹误与未落地引用]]。
