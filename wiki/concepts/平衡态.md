# 平衡态（时间无关解）

本节 1.12.1.3 将「时间无关解」定义为平衡态。对归一化逻辑斯谛方程 (1.209)，平衡态由

```latex
\mathcal N \equiv 0 \quad \text{和} \quad \mathcal N \equiv 1
```

给出。证明：由 $\mathcal N=$ 常数 与 (1.209) 得 $\mathcal N^2-\mathcal N=0$，故 $\mathcal N=0$ 或 $\mathcal N=1$。

在衰减方程 (1.202) 中，平衡解是 $N\equiv 0$，解渐近趋于它。
