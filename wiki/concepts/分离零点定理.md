# 分离零点定理

《数学指南——实用数学手册》1.12.8.1 节以「关于分离零点的施图姆定理」给出：

> 如果 $y$ 是 (1.307) 的一个解，并且 $z$ 是
> $$- (p(x) z')' + q^{*}(x) z = 0, \quad \text{在 } J \text{ 上}\tag{1.308}$$
> 的一个解，并且在 $J$ 上 $q^{*}(x) \leqslant q(x)$，那么在 $z$ 的任意两个零点之间有 $y$ 的一个零点。

这是「零点交错」型的比较结果：系数 $q$ 较大的方程，解的零点更密。注意本节中 (1.307) 与 (1.308) 共用同一个 $p(x)$，只有 $q$ 与 $q^{*}$ 不同。

该定理与 [[concepts/施图姆零点定理]] 共同支撑 [[concepts/振荡]] 判据；与 [[concepts/比较定理]]（本征值不等式 $\lambda_n \leqslant \lambda_n^{*}$）属于同一比较思想在不同层级上的体现，但两者的前提与结论并不相同，不应互换。
