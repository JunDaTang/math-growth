# 二次配方与顶点形式

二次配方是把一般二次函数化为“完全平方 + 常数”形式（顶点形式）的代数操作。《数学指南——实用数学手册》0.2.3 节用它把式 (0.31) 化为式 (0.32)。

## 来源给出的结果

由二次配方，一般二次函数

```latex
y = a x^{2} + 2 b x + c \tag{0.31}
```

可写成

```latex
y = a \left(x + \frac{b}{a}\right)^{2} - \frac{D}{a} \tag{0.32}
```

其中判别式

```latex
D := b^{2} - a c
```

来源随即断言：(0.31) 的图像可以通过把 (0.30) 的图像的顶点 \((0,0)\) 平移到 \(\left(-\frac{b}{a}, -\frac{D}{a}\right)\) 得到。

## 恒等式的验证

式 (0.32) 可以直接展开验证（这是代数恒等式，不依赖任何几何假设）：

```latex
a \left(x + \frac{b}{a}\right)^{2} - \frac{D}{a}
= a \left(x^{2} + \frac{2b}{a} x + \frac{b^{2}}{a^{2}}\right) - \frac{b^{2} - ac}{a}
= a x^{2} + 2 b x + \frac{b^{2}}{a} - \frac{b^{2}}{a} + c
= a x^{2} + 2 b x + c
```

因此来源关于“顶点平移到 \(\left(-\frac{b}{a}, -\frac{D}{a}\right)\)”的说法，其代数部分证据强度高。

## 记法上的便利

一般形式把一次项写成 \(2bx\)（而非 \(Bx\)），使配方时括号内出现 \(\frac{b}{a}\) 这一对称形式，并使常数项余项恰好写成 \(-\frac{D}{a}\)，其中 \(D = b^{2} - ac\)。这是本节记法选择的动机之一，代价是与通行教材的 \(-4ac\) 形式不同（见 [[二次判别式]] 与 [[二次函数判别式记法差异]]）。

## 几何含义

顶点形式把二次函数图像的位置信息（顶点）与形状信息（系数 \(a\)）分离：\(a\) 控制开口方向与开口宽窄，\(\left(-\frac{b}{a}, -\frac{D}{a}\right)\) 控制位置。这正是 [[函数图像的平移]] 所描述的操作在二次函数上的具体用法，见 [[二次函数的抛物线图像]] 与 [[一般二次函数图像由最简抛物线平移得到]]。
