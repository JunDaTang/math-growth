# 棣莫弗公式

手册公式 (0.41) 给出倍角的复数形式表示。

## 公式 (0.41)

令 $n = 2, 3, \cdots$，则对所有复数 $x$：

$$
\cos n x + \mathrm{i}\sin n x = \sum_{k=0}^{n} \mathrm{i}^{k} \binom{n}{k} \cos^{n-k} x \, \sin^{k} x.
\tag{0.41}
$$

分离实部与虚部得到 (0.42)：

$$
\cos n x = \cos^{n} x - \binom{n}{2} \cos^{n-2} x \sin^{2} x + \binom{n}{4} \cos^{n-4} x \sin^{4} x - \dots,
$$

$$
\sin n x = \binom{n}{1} \cos^{n-1} x \sin x - \binom{n}{3} \cos^{n-3} x \sin^{3} x + \binom{n}{5} \cos^{n-5} x \sin^{5} x - \dots .
\tag{0.42}
$$

## 历史与逻辑顺序的倒转

手册脚注指出：该公式由 A. 棣莫弗（de Moivre, 1667—1754）得到，欧拉受此启发发现 $\mathrm{e}^{\mathrm{i}x} = \cos x + \mathrm{i}\sin x$。但在现代处理中「反过来更方便」：

$$
\cos n x + \mathrm{i}\sin n x = \mathrm{e}^{\mathrm{i}nx} = (\mathrm{e}^{\mathrm{i}x})^{n} = (\cos x + \mathrm{i}\sin x)^{n},
$$

配合二项式公式（参看 0.1.10.3，即 [[二项式定理]] 与 [[二项式系数]]），**棣莫弗公式 (0.41) 便是 [[欧拉公式]] 的推论**。参见 [[concepts/棣莫弗公式]]。

## 应用

- 低阶展开：$n = 2, 3, 4$ 的显式公式见 [[三角函数的倍角与半角公式]]。
- 方幂公式（将 $\sin^{n} x$、$\cos^{n} x$ 化为倍角的线性组合）也由 (0.42) 得到。
