# 平面图形面积与周长公式

平面图形面积与周长公式汇总了最重要平面图形的面积 $A$ 与周长 $C$ 的解析表达式，来源为 [[数学指南-实用数学手册]] 表 0.4。本页是其细化子页；更广义的初等几何公式集合见 [[初等几何公式]]。

## 多边形与直边图形

| 图形 | 面积 | 周长 |
|---|---|---|
| 正方形 | $A = a^{2}$ | $C = 4a$ |
| 矩形 | $A = ab$ | $C = 2a + 2b$ |
| 平行四边形 | $A = ah = ab\sin\gamma$ | $C = 2a + 2b$ |
| 菱形（等边平行四边形） | $A = a^{2}\sin\gamma$ | $C = 4a$ |
| 梯形 | $A = \frac{1}{2}(a + b)h$ | $C = a + b + c + d$ |
| 三角形 | $A = \frac{1}{2}ah = \frac{1}{2}ab\sin\gamma$；亦见 [[海伦公式]] | $C = a + b + c$ |
| 直角三角形 | $A = \frac{1}{2}ab$；见 [[毕达哥拉斯定理]]、[[欧几里得关系]] | $C = a + b + c$ |
| 等边三角形 | $A = \frac{\sqrt{3}}{4}a^{2}$ | $C = 3a$ |

三角形面积公式中 $s := C/2$，海伦公式为 $A = \sqrt{s(s-a)(s-b)(s-c)}$。直角三角形的边角关系为 $a = c\sin\alpha$、$b = c\cos\alpha$、$a = b\tan\alpha$（c 为斜边，a 为对边，b 为邻边）。

## 圆与曲边图形

| 图形 | 面积 | 周长 |
|---|---|---|
| 圆 | $A = \pi r^{2}$ | $C = 2\pi r$ |
| 扇形 | $A = \frac{1}{2}\alpha r^{2}$ | $C = L + 2r,\ L = \alpha r$ |
| 圆环 | $A = \pi(r^{2} - \rho^{2})$ | $C = 2\pi(r + \rho)$ |
| 抛物扇形 | $A = \frac{1}{3}xy$ | 原表未给出 |
| 双曲扇形 | $A = \frac{1}{2}\left(xy - ab\cdot\operatorname{arcosh}\frac{x}{a}\right)$，$b = a\tan\alpha$ | 原表未给出 |
| 椭圆扇形 | $A = \frac{1}{2}ab\cdot\operatorname{arcosh}\frac{x}{a}$（**待核验**，见下） | 原表未给出 |
| 椭圆 | $A = \pi ab$（$b < a$） | $C = 4aE(\varepsilon)$，见 [[椭圆周长的椭圆积分]] |

扇形面积与弧长公式均以弧度制角 $\alpha$ 表达，与 [[角度制与弧度制]] 的约定相关。抛物扇形、双曲扇形、椭圆扇形分别指向 0.1.7 中讨论的抛物线、双曲线与椭圆；$\operatorname{arcosh}$ 函数在 0.2.12 中介绍。

## 注释与待核验

- **椭圆扇形公式存疑**：原表将椭圆扇形面积与双曲扇形同样写作含 $\operatorname{arcosh}$ 的形式 $A = \frac{1}{2}ab\cdot\operatorname{arcosh}\frac{x}{a}$。椭圆（闭曲线）扇形面积通常涉及 $\arcsin/\arccos$ 或参数角，此式可疑，可能为排版/OCR 问题或特定参数化约定。本 wiki 不将其作为确证结论。
- **毕达哥拉斯定理的归属限定**：源文脚注指出，萨摩斯岛的毕达哥拉斯（约公元前 500 年）被视为毕达哥拉斯学派创立者，但汉谟拉比（公元前 1728—前 1686）统治下的巴比伦人早约 1000 年已知该定理。命名归属须保留此历史限定。
