# RSA公钥密码体制

## 来源

源文 2.7.8.1「费马-欧拉定理在编码理论中的应用」称：**1977 年** [[里夫斯特]]（Rivest）、[[沙米尔]]（Shamir）及 [[阿德莱曼]]（Adlemann）公布了这一「简单得令人难以置信但却非常安全的码」，其基础是 [[费马-欧拉定理]]。

## 操作器的准备

```
(i)  取两个素数 p 和 q，它们的大小大约为 10^100，并且要予以保密.
(ii) 作乘积  m = p q
     并计算  φ(m) = (p−1)(q−1).
(iii) 取另一个自然数 s，使适合  1 < s < φ(m).
(iv) 发送信息的人（公开地）给出两个数 m 和 s.
```

其中 $(m, s)$ 是公开密钥，$p$、$q$（进而 $\varphi(m)$）是保密的。

## 信息编码

将信息简单地编码为单个自然数：将每个字母对应于（例如）一个两位数 $10, 11, 12, \cdots$，并将信息中的每个字母换为所对应的两位数；于是将它们连接起来就得到一个大数 $n$。然后用 $m$ 去除数 $n^s$，将余数 $r$ 输送到操作器中，亦即只将满足

```
n^s ≡ r mod m
```

的数 $r$ 作为发出的信息。

## 译码

要从余数 $r$ 构造出原来的数 $n$。因为 $\varphi(m)$ 与 $s$ 互素，所以存在自然数 $t \geqslant 1$ 使

```
t s ≡ 1 mod φ(m).        (2.95)
```

定理：$r^t \equiv n \bmod m$。操作器恰是用 $m$ 去除 $r^t$，所得余数就是 $n$。注意从 $m$ 的大小可知总有 $n < m$。

证明：由 [[费马-欧拉定理]] 有 $n^{\varphi(m)} \equiv 1 \bmod m$；由 (2.95) 知存在整数 $k$ 适合 $ts = 1 + k\varphi(m)$，于是

```
r^t ≡ n^(st) ≡ n^(1 + kφ(m)) ≡ n mod m.
```

## 方法的安全性

- 入侵者若要破译，必须知道数 $t$，亦即必须知道 $\varphi(m) = (p-1)(q-1)$；
- 为得到 $\varphi(m)$，他必须确定公开数 $m$ 的素数分解式；
- 方法的诀窍在于 $p$ 与 $q$ 的大小，使得还没有任何计算机能在合理时间内确定 $p$ 与 $q$ 的因数，即 [[整数分解困难性]]；
- 由于计算机功能不断增强，只有不断选取新的更大的 $p$ 和 $q$ 才能保证安全性；
- 源文断言：若找到将大整数快速分解为素数之积的算法，则上述方法将变得不安全。

源文另有一句非数学性评论：由于上述原因，所有在该领域从事研究的数学家都被 [[国家安全委员会]] 严密地监控。
