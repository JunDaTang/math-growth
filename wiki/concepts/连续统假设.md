# 连续统假设

4.4.4.3 节。习惯上用 $N_0$ 表示自然数集 $\omega$ 的基数 $\operatorname{card} \omega$（记法应为 $\aleph_0$，见 [[queries/44节记法编号讹误与未落地引用]]）；还存在着确实比 $N_0$ 大的最小基数 $N_1$。可以想象两种情况：

```
(i)  N_0 < N_1 = card R
(ii) N_0 < N_1 < card R
```

实数集的基数 $\operatorname{card} \mathbb{R}$ 称为连续统的基数。**康托尔曾试图证明连续统假设 (i)，但没有成功。** 直观上，(i) 说明在自然数集的基数和连续统的基数之间不存在别的基数。

独立性结果：

- 1940 年，[[entities/哥德尔]] 证明了 (i) 与集合论的其余公理相容；
- 1963 年，[[entities/科恩]] 证明了 (ii) 也是如此。

合并即 [[concepts/哥德尔-科恩定理]]。本节由此得出方法论结论：不止有一种集合论，而是有好几种可能的集合论；4.4.3 中非常自然的公理并没有完全确定无穷的结构。
