# 二次判别式

在《数学指南——实用数学手册》0.2.3 节中，判别式定义为

```latex
D := b^{2} - a c
```

其中 \(a, b, c\) 是在一般二次函数 \(y = ax^{2} + 2bx + c\)（式 0.31）中出现的系数。

## 作用

判别式 \(D\) 决定二次方程 \(ax^{2} + 2bx + c = 0\) 的零点个数，也决定抛物线 \(y = ax^{2} + 2bx + c\) 与 \(x\) 轴的相交情况：

| 判别式 | 方程零点 | 抛物线与 \(x\) 轴 |
|---|---|---|
| \(D > 0\) | 两个不同实零点 \(x_{+}, x_{-}\) | 两个不同交点（图 0.28(a)） |
| \(D = 0\) | 一个实零点 \(x_{+} = x_{-}\) | 相切（图 0.28(b)） |
| \(D < 0\) | 两个复零点 | 不相交（图 0.28(c)） |

同时，\(D\) 出现在顶点形式 \(y = a\left(x + \frac{b}{a}\right)^{2} - \frac{D}{a}\)（式 0.32）中，因此也决定顶点的纵坐标 \(-D/a\)。见 [[二次配方与顶点形式]]。

## 与通行记法的关系

通行教材在方程 \(Ax^{2} + Bx + C = 0\) 下使用的判别式是 \(B^{2} - 4AC\)，其求根公式分母为 \(2A\)。本节采用的 \(D = b^{2} - ac\) 配合一次项系数 \(2b\) 与分母 \(a\)，同样自洽：取 \(a = A\)、\(b = B/2\)、\(c = C\)，则

```latex
D = b^{2} - a c = \frac{B^{2}}{4} - A C = \frac{B^{2} - 4 A C}{4}
```

即本节的 \(D\) 恰为通行判别式的四分之一。因此“\(D > 0\) / \(D = 0\) / \(D < 0\)”的符号判据与通行判据给出的三种情形完全一致，只是数值相差因子 4。记法差异及其潜在混淆见 [[二次函数判别式记法差异]]。

## 来源边界

来源只给出判别式的定义及其三种符号情形，未讨论判别式在三次及更高次方程中的推广，也未讨论判别式作为多项式结式/不变量的代数意义。
