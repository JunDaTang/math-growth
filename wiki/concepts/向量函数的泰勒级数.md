# 向量函数的泰勒级数

《数学指南——实用数学手册》1.9.1 节给出：如果区间 [a, b] 上的 r = r(t) 是 **C^{n+1} 类**的，那么对所有的 t, t + h ∈ [a, b] 有

```
r(t + h) = r(t) + h r′(t) + (h²/2) r″(t) + … + (hⁿ/n!) r⁽ⁿ⁾(t) + R_{n+1}
```

其中误差（余项）估计为

```
|R_{n+1}| ≤ h^{n+1}/(n+1)! · sup_{s ∈ [a, b]} |r⁽ⁿ⁺¹⁾(s)|
```

## 说明

- 展开式中各项的系数 h^k/k! 与实值泰勒公式完全一致，只是每一项由向量 r⁽ᵏ⁾(t) 替代了标量 f⁽ᵏ⁾(t)。
- 余项估计中的上确界取在整段区间 [a, b] 上，是实值泰勒余项估计在 [[concepts/向量函数的Ck光滑性]] 条件下的逐分量推广。
- 形式上，向量级数在 R³ 中可以按分量理解，见 [[concepts/向量函数的坐标表示]]。
