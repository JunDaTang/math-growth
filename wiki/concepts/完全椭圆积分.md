# 完全椭圆积分 E 与 K

完全椭圆积分 $K$ 与 $\mathrm{E}$ 是第一类、第二类椭圆积分在振幅 $\varphi = \pi/2$ 处的取值（源 0.5.4 节）。同一对函数在手册定积分表中出现于 0.9.6.1 节条目 30、31，源 0.9.6 在此给出定义并指向 0.5.4 节（该节在 0.9.6 的引用体系中记为尚未入库）。

## 定义（源 0.5.4）

完全椭圆积分 $K$ 与 $\mathrm{E}$ 的定义为：

$$
K = F\left(k, \frac{\pi}{2}\right) = \int_0^{\pi/2} \frac{\mathrm{d}\psi}{\sqrt{1 - k^2 \sin^2 \psi}} = \int_0^{1} \frac{\mathrm{d}x}{\sqrt{1 - x^2}\sqrt{1 - k^2 x^2}},
$$

$$
\mathrm{E} = E\left(k, \frac{\pi}{2}\right) = \int_0^{\pi/2} \sqrt{1 - k^2 \sin^2 \psi}\,\mathrm{d}\psi = \int_0^{1} \sqrt{\frac{1 - k^2 x^2}{1 - x^2}}\,\mathrm{d}x,
$$

其中 [[模数与模角]] 给出 $k = \sin\alpha$。

## 定义与引用（源 0.9.6）

0.9.6.1 节条目 30、31 给出 E、K 的定义式并指向 0.5.4 节：

```latex
\mathrm{E}=E\left(a,\frac{\pi}{2}\right),\qquad
\mathrm{K}=F\left(a,\frac{\pi}{2}\right)\quad(\text{参看 } 0.5.4)
```

即 E、K 分别是第二类与第一类椭圆积分的完全形式（第二参数取 $\pi/2$），二者在手册其它节中以 $E(a, \varphi)$、$F(a, \varphi)$ 的形式出现。

> **约定归属说明**
> - 源 0.5.4 明确给出模数约定 $k = \sin\alpha$。
> - 源 0.9.6 在此处使用参数 $a$ 书写 $E(a, \pi/2)$、$F(a, \pi/2)$，但该节未说明 $a$ 是模数 $k$ 还是参数 $m = k^2$，需依赖 0.5.4 节确认。相关未入库问题见 [[096节引用节号011-051-054尚未入库]]。

## 在定积分条目中的使用（源 0.9.6）

```latex
30. \int_{0}^{\pi/2}\frac{\sin^{2}x\,\mathrm{d}x}{\sqrt{1-a^{2}\sin^{2}x}}
    =\frac{1}{a^{2}}(\mathrm{K}-\mathrm{E}),\quad|a|<1.
31. \int_{0}^{\pi/2}\frac{\cos^{2}x\,\mathrm{d}x}{\sqrt{1-a^{2}\sin^{2}x}}
    =\frac{1}{a^{2}}\left[\mathrm{E}-(1-a^{2})\mathrm{K}\right],\quad|a|<1.
```

两条结果的分母同为 $\sqrt{1-a^{2}\sin^{2}x}$，区别仅在分子为 $\sin^{2}x$ 与 $\cos^{2}x$；两者相差 $K/a^{2}$，与 $\sin^{2}x + \cos^{2}x = 1$ 的归一化一致。

它们与相邻的同分母条目 28、29 构成一族：

- 条目 28：$\displaystyle \int_{0}^{\pi/2}\frac{\sin x\,\mathrm{d}x}{\sqrt{1-a^{2}\sin^{2}x}} = \frac{1}{2a}\ln\frac{1+a}{1-a}$；
- 条目 29：$\displaystyle \int_{0}^{\pi/2}\frac{\cos x\,\mathrm{d}x}{\sqrt{1-a^{2}\sin^{2}x}} = \frac{1}{a}\arcsin a$；
- 条目 30、31 引入 E、K。

因此该族中只有分子为 $\sin^{2}x$、$\cos^{2}x$ 的两条无法用初等函数表示。

## 数值表（源 0.5.4，表 c）

[[表c完全椭圆积分]] 以 $\alpha = 0^\circ,\ldots,89^\circ$（步长 1°）为行，分别列出 $K$ 与 $\mathrm{E}$。

- $K$：在 $\alpha = 0^\circ$ 处 $K = 1.5708$（即 $\pi/2$ 的数值），随 $\alpha$ 增大单调递增，$\alpha = 89^\circ$ 时已达 $5.4349$；
- $\mathrm{E}$：在 $\alpha = 0^\circ$ 处 $\mathrm{E} = 1.5708$，随 $\alpha$ 增大单调递减，$\alpha = 89^\circ$ 时为 $1.0008$。

## 边界约定（源 0.5.4）

源 0.5.4 明确规定：当 $\alpha = 90^\circ$ 时，令 $K = \infty$，$\mathrm{E} = 1$。此处 $k = \sin 90^\circ = 1$，被积函数在 $\psi = \pi/2$ 处出现平方根零点，$K$ 发散。
