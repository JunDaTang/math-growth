# 线性空间同构

2.3.3 节定义：两个线性空间 X 和 Y 称为同构的，如果存在一个线性一一映射 $A: X \to Y$，这种映射称为同构。

在同构的线性空间中可以用相同的方式完成计算，从抽象观点来看，同构的线性空间之间没有差别。定理：两个 K 上的有限维线性空间同构，当且仅当它们有相同的维数。因此 [[线性空间的维数]] 是有限维线性空间仅有的特征。

设 $b_1,\dots,b_n$ 是 X 的基，则 $A(\alpha_1 b_1 + \dots + \alpha_n b_n) := (\alpha_1,\dots,\alpha_n)$ 定义 X 到 $K^n$ 的线性同构。与同构相关的构造见 [[商空间]]、[[直和]]。
