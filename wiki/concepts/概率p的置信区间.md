# 概率 p 的置信区间

## 问题（6.2.5.6 节）

考虑一枚硬币，$p$ 是一次比较试验中出现「正面向上」的概率。将硬币抛 $n$ 次，观测「正面向上」的频率 $h_n$。此时 $p$ 未知，希望以一定的置信度确定它的值——这是与 [[假设检验与残概率]] 方向相反的推断问题。

## 结果

在错误概率 $\alpha$ 下，假定未知的 $p$ 值落在区间

```
[p_−, p_+] 内，
```

其中

```
(1 + z_α²/n) p_± = h_n + z_α²/(2n) ± √( h_n z_α²/n + z_α²/(4n²) )。
```

原文指出：一般来说，对于 6.2.5.2 中 [[伯努利模型]] 的概率 $p$ 的估计，这个结论是正确的。

## 推导

由 (6.24)（见 [[棣莫弗-拉普拉斯全面极限定理]]）可知，当 $n$ 较大时不等式

```
|(h_n − p)/ΔH_n| < z_α        (6.27)
```

成立的概率为 $\Phi_0(z_\alpha) - \Phi_0(-z_\alpha) = 1 - \alpha$。由于 $(\Delta H_n)^2 = p(1-p)/n$，(6.27) 等价于

```
(h_n − p)² < z_α² · p(1−p)/n,
```

即

```
p²(1 + z_α²/n) − (2h_n + z_α²/n) p + h_n² < 0。        (6.28)
```

当且仅当 $p$ 的值介于相应二次方程

```
p²(1 + z_α²/n) − (2h_n + z_α²/n) p + h_n² = 0
```

的两个根 $p_-$ 与 $p_+$ 之间时，不等式 (6.28) 成立。这一推导之所以可行，关键正是 $\Delta H_n$ 本身依赖于待估参数 $p$，故必须解二次不等式而不能直接正态区间套用。

## 例

将一枚硬币抛 10 000 次：

- 若「正面向上」出现 5010 次，则 $h_n = 0.501$，原文称 $p$ 落在区间 $[0.36, 0.64]$ 中（残概率 $\alpha = 0.05$）；
- 原文随即指出这个估计「还是十分粗糙的」，并在相同的残概率 $\alpha = 0.05$ 下断定 $p$ 的值落在区间 $[0.500, 0.503]$ 内。

两处数值的取舍见 [[queries/6256节置信区间例数值与公式不符]]。

## 与 6.1 节 [[置信区间]] 的关系

6.1.4 节的置信区间是围绕高斯正态分布给出的通用概念；本节把它具体化为伯努利模型中单一参数 $p$ 的区间估计，并给出了更精确的二次不等式解法，把 [[假设检验与残概率]] 中使用的同一套 $\alpha$、$z_\alpha$、$\Delta H_n$ 记号贯穿起来。
