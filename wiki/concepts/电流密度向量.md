# 电流密度向量 j

《数学指南——实用数学手册》1.9.10 节中，$\boldsymbol{j}$ 表示电流密度向量。它在 [[麦克斯韦方程]] 表 1.6 第四式中作为磁场的源项出现：$\text{curl}H = j + D_{t}$；在积分形式中出现于 $\int_{\partial M}\boldsymbol{H}\mathrm{d}r = \int_{M}j\boldsymbol{n}\mathrm{d}F + \frac{\mathrm{d}}{\mathrm{d}t}\int_{M}\boldsymbol{D}\boldsymbol{n}\mathrm{d}F$；并出现在电荷守恒式 $\rho_{t} + \text{div}j = 0$ 及其积分形式 $\frac{\mathrm{d}}{\mathrm{d}t}\int_{D}\rho\mathrm{d}x = -\int_{\partial D}j\boldsymbol{n}\mathrm{d}F$ 中。

$j$ 与 [[电荷密度]] $\rho$ 通过该无源形式连续性方程相联系，与《数学指南》1.9.7 节中电流满足无源连续性方程的结论一致（见 [[连续性方程]]）。
