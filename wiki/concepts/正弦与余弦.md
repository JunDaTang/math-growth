# 正弦与余弦

正弦函数 $y = \sin x$ 与余弦函数 $y = \cos x$ 是三角学的两个基本函数。《数学指南——实用数学手册》0.2.8 节从**分析的定义**（幂级数）出发建立它们，再由 [[欧拉公式]] 导出全部恒等式，从而把几何对象完全代数化。

## 手册给出的定义顺序

1. **分析的定义**：用无穷级数定义 $\sin x$ 与 $\cos x$，对所有复数 $x$ 收敛（[[三角函数的幂级数定义]]）。
2. **欧拉公式 (0.35)**：$\mathrm{e}^{\pm\mathrm{i}x} = \cos x \pm \mathrm{i}\sin x$，手册称其「支配着三角函数的整个理论」。
3. **指数表示 (0.36)**：$\sin x = \dfrac{\mathrm{e}^{\mathrm{i}x} - \mathrm{e}^{-\mathrm{i}x}}{2\mathrm{i}}$，$\cos x = \dfrac{\mathrm{e}^{\mathrm{i}x} + \mathrm{e}^{-\mathrm{i}x}}{2}$，是推导一切三角恒等式的通用工具（[[三角函数的指数表示]]）。
4. **几何解释**：直角三角形中的边比（表 0.16）与单位圆上的线段长（图 0.31），后者给出周期 $2\pi$ 的几何解释（[[单位圆与直角三角形中的三角函数]]）。

## 基本性质一览

| 性质 | 内容 | 适用范围 |
|---|---|---|
| 奇偶性 | $\sin(-x) = -\sin x$，$\cos(-x) = \cos x$ | 所有复数 $x$ |
| 周期 | $\sin(x + 2\pi) = \sin x$，$\cos(x + 2\pi) = \cos x$ | 所有复数 $x$ |
| 毕达哥拉斯关系 | $\cos^{2} x + \sin^{2} x = 1$ | 所有复数 $x$ |
| 零点 | $\sin$：$x = k\pi$；$\cos$：$x = k\pi + \frac{\pi}{2}$ | 复平面上仅有实零点 |
| 加法 | 见 [[正弦余弦加法定理]] | 所有复数 $x, y$ |
| 导数 | $\frac{\mathrm{d}\sin x}{\mathrm{d}x} = \cos x$，$\frac{\mathrm{d}\cos x}{\mathrm{d}x} = -\sin x$ | 所有复数 $x$ |

## 记号

符号「$\sin x$」读作「$x$ 的正弦」，「$\cos x$」读作「$x$ 的余弦」；拉丁语 *sinus* 表示「凸出」。旧文献中还使用正割 $\sec x := 1/\cos x$ 与余割 $\csc x := 1/\sin x$。
