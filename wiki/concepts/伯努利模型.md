# 伯努利模型（独立重复试验）

## 定义

[[雅各布-伯努利]] 提出并研究的模型，是概率论中最重要的模型之一。其构造分三步：

1. **比较试验（基本试验）**：一个有两个可能结果的试验，记结果为 $e_1, e_2$；结果 $e_j$ 出现的概率为 $p_j$。规定 $p := p_1$，于是 $p_2 = 1-p$。称 $p$ 为该基本试验的概率。
2. **重复**：将该试验进行 $n$ 次。
3. **独立性**：所有这些试验相互独立，即它们的结果彼此互不影响。

原文以抛硬币为例：$e_1$ 表示「正面向上」，$e_2$ 表示「反面向上」；$p = 1/2$ 时硬币是公平的，$p \neq 1/2$ 时显然不公平。

## 概率空间

全部事件 $E$ 由基本事件 $e_{i_1 i_2 \ldots i_n}$（$i_j = 1, 2$，$j = 1, \ldots, n$）组成，概率规定为

```
P(e_{i_1 i_2 ... i_n}) := p_{i_1} p_{i_2} ... p_{i_n}.        (6.18)
```

解释：$e_{121}$ 表示试验序列的结果依次为 $e_1, e_2, e_1, \cdots$；例如 $P(e_{121}) = p(1-p)p = p^2(1-p)$。

## 试验的独立性（本节给出的证明）

定义事件 $A_i^{(k)}$ 为「事件 $e_i$ 在第 $k$ 次试验中发生」。则对所有可能的下标，事件 $A_{i_1}^{(1)}, A_{i_2}^{(2)}, \ldots, A_{i_n}^{(n)}$ 相互独立。

原文证明 $n=2$ 的特例：

```
P(A_i^{(1)}) = P(e_{i1}) + P(e_{i2}) = p_i p_1 + p_i p_2 = p_i,
A_i^{(1)} ∩ A_j^{(2)} = {e_{ij}},  P(e_{ij}) = p_i p_j,
```

于是 $P(A_i^{(1)} \cap A_j^{(2)}) = P(A_i^{(1)}) P(A_j^{(2)})$，即满足独立事件的概率乘法性质。$\square$

注意这里的独立性不是假设，而是由 (6.18) 的概率规定**推导**出来的结论——这正是该模型构造上的关键。

## 模型的两个基本随机变量

- **频率** $H_n$：事件 $e_1$ 在试验序列中发生的频率，$H_n = \frac{1}{n}(X_1 + \cdots + X_n)$；
- **频数** $A_n := n H_n$：事件 $e_1$ 在试验序列中出现的次数，$A_n = X_1 + \cdots + X_n$。

详见 [[伯努利模型中的频率与频数]] 与 [[示性函数]]。

## 分析上的意义

原文强调：频数 $A_n$ 是一些可以同样处理的独立随机变量的叠加，因此结合中心极限定理，预期 $n$ 很大时 $A_n$ 近似服从正态分布——这正是棣莫弗-拉普拉斯定理的内容。由此该模型成为连接 [[伯努利大数定律]]、[[棣莫弗-拉普拉斯局部极限定理]]、[[棣莫弗-拉普拉斯全面极限定理]] 与 [[泊松逼近定理]] 的统一舞台，并直接支撑 [[假设检验与残概率]] 与 [[概率p的置信区间]] 两类统计应用。

## 无穷化推广

为阐述强大数定律，原文把试验重数增加到无穷大，构造 [[无穷重伯努利试验]]，得到博雷尔（1909）-坎泰利（1917）强大数定律。
