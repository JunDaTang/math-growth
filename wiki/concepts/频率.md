# 频率

## 定义

《数学指南——实用数学手册》6.1.2 节在抛硬币模型中定义频率。将硬币抛 $n$ 次后，对基本事件 $e_{i_1 i_2 \dots i_n}$ 赋予

```
H(e_{i_1 i_2 … i_n}) := (正面向上发生的次数) / (试验次数 n)
```

其中分子等于该基本事件下标中「1」出现的次数。当恰好有 $k$ 个下标为「1」时，频率

```
H_n = k/n
```

## 与概率的关系

频率是经验可观测的量，概率是模型内赋予的量。本节的核心论断是：将随机试验重复许多次，事件的频率会越来越接近其概率——这正是 [[concepts/伯努利大数定律]] 所证明的事实，也是概率论大量应用的基础。在 6.1.3 节中，$H_n = k/n$ 的频率取值被赋予了精确概率

```
P(H_n = k/n) = C(n,k) · 1/2^n
```

并进一步得到 [[concepts/棣莫弗极限定理]] 的渐近分布。
