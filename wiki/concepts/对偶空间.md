# 对偶空间

2.3.5 节。用 $X^*$ 表示所有 X 上的 [[线性泛函]] 的集合，定义线性组合

```text
(αu* + βv*)(u) := αu*(u) + βv*(u),   对所有 u ∈ X
```

于是 $X^*$ 具备 K 上的线性空间结构，称为 X 的对偶空间。令 $X^{**} := (X^*)^*$。

例 2：设 X 为 K 上的 n 维线性空间，则 $X^* \cong X$，但它不是典范的，甚至与基 $b_1,\dots,b_n$ 的选取有关。定义 $b_j^*(u_1 b_1 + \dots + u_n b_n) := u_j$，则 $b_1^*,\dots,b_n^*$ 形成 $X^*$ 的基，称为对偶基。每个 X 上的线性型可写成 $u^* = \alpha_1 b_1^* + \dots + \alpha_n b_n^*$；令 $A(u^*) := \alpha_1 b_1 + \dots + \alpha_n b_n$，则 $A: X^* \to X$ 是线性双射，给出 $X^* \cong X$。

另一方面，令 $u^{**}(u^*) := u^*(u)$，则同构 $X^{**} \cong X$ 是典范的（与基的选取无关）。对于无穷维线性空间，X 与 $X^*$、$X^{**}$ 的关系不再像有限维情形那样清晰（例如巴拿赫空间，参看 [212]）。
