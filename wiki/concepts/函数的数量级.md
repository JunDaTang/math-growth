# 函数的数量级（Landau 符号）

《数学指南——实用数学手册》1.3.1.4 节引入两个「归功于 [[兰道]]（Landau）」的符号 $O(g(x))$、$o(g(x))$ 以及渐近等式 $\cong$，用于在不求极限精确值的情况下理解函数量的变化。设 $-\infty \leqslant a \leqslant \infty$。

## 渐近等式

```
f(x) ≅ g(x),  x→a     当且仅当     lim_{x→a} f(x)/g(x) = 1
```

例 1：由 $\lim_{x\to 0} \frac{\sin x}{x} = 1$ 得，当 $x \to 0$ 时 $\sin x \cong x$。

## 大 O 记号 (1.29)

```
f(x) = O(g(x)),  x→a                    (1.29)
```

如果存在 $a$ 的一个邻域 $U(a)$ 及一个实数 $K$，使得

```
|f(x)/g(x)| ⩽ K   对所有 x ∈ U(a) 且 x ≠ a                 (1.29*)
```

定理：如果**有限**极限 $\lim_{x\to a} f(x)/g(x)$ 存在，则关系式 (1.29) 成立。

例 2：$\lim_{x\to+\infty} \frac{3x^2+1}{x^2} = 3$ 蕴涵当 $x \to +\infty$ 时 $3x^2 + 1 = O(x^2)$。

## 小 o 记号

```
f(x) = o(g(x)),  x→a     当且仅当     lim_{x→a} f(x)/g(x) = 0
```

例 3：当 $x \to 0$ 时 $x^n = o(x)$（$n = 2, 3, \cdots$）。

## 例 4（四个具体比较）

```
(i)   x²/(x²+2) ≅ 1,           x→∞
(ii)  1/(x²+2) ≅ 1/x²,         x→+∞
(iii) sin x = O(1),            x→a（−∞ ⩽ a ⩽ ∞）
(iv)  ln x = o(1/x) (x→+0)；ln x = o(x) (x→+∞)
(v)   x^n = o(e^x),            x→+∞（n = 1, 2, …）
```

最后的陈述 (v) 表示：当 $x \to +\infty$ 时，函数 $y = \mathrm{e}^x$ 比任何幂函数 $x^n$ 增长得快，见 [[findings/指数函数增长快于任意幂函数]]。

## 单侧版本

设 $a \in \mathbb{R}$。当 $x \to a+0$（相应地 $x \to a-0$）时，同样可以引进符号 $f(x) \cong g(x)$、$f(x) = O(g(x))$、$f(x) = o(g(x))$；一般地，此时不等式 (1.29\*) 只需在 $x \in U(a)$ 且 $x > a$（相应地 $x < a$）时成立。
