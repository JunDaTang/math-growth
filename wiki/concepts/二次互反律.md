# 二次互反律

## 陈述（高斯，1796）

源文以「**高斯二次互反律（1796）**」给出：如果 $p$ 和 $q$ 是大于 2 的素数，那么有

```
( q / p ) = (−1)^((p−1)(q−1)/4) ( p / q ).
```

其中 $(q/p)$、$(p/q)$ 为 [[勒让德符号]]，分别刻画同余方程 $x^2 \equiv q \bmod p$（源文式 (2.96)）与 $x^2 \equiv p \bmod q$（源文式 (2.97)）的可解性。

该式的作用在于把符号 $(q/p)$ 的求值问题转化为 $(p/q)$ 的求值问题，并使符号因子 $(-1)^{(p-1)(q-1)/4}$ 完全由 $p, q \bmod 4$ 的余数决定。

## 补充公式

源文一并给出

```
( −1 / p ) = (−1)^((p−1)/2),   ( 2 / p ) = (−1)^((p^2−1)/8).
```

## 历史评注

源文称：这个定理是 [[欧拉]]（1722）、[[勒让德]]（1785）及 [[高斯]] 独立地**凭借经验发现**的；**高斯给出第一个完全的证明**。源文并评论：「这个定律及其许多推广表述了我们熟知的数论中最深刻的基本性质。」

## 示例

设 $p = 4n + 1$ 是素数，$n$ 为某正自然数，则 $x^2 \equiv -1 \bmod p$ 有解，因为 $\left(\frac{-1}{p}\right)=1$。
