# 多项式加法与乘法

来源 2.1.5 节规定：多项式的加法与乘法**通过合并次数相同的项、应用自然法则 (1.1.4)** 进行。

## 算例（例 1）

```
(x^2 + 1) + (2x^3 + 4x^2 + 3x + 2) = 2x^3 + 5x^2 + 3x + 3,

(x + 1)(x^2 - 2x + 2) = x^3 - 2x^2 + 2x + x^2 - 2x + 2 = x^3 - x^2 + 2.
```

乘法算例中 $x^3 - 2x^2 + 2x + x^2 - 2x + 2$ 是逐项展开的中间步骤，合并同次项后得到 $x^3 - x^2 + 2$。

## 依赖与边界

- 运算所依据的「自然法则 (1.1.4)」指 1.1.4 小节；该小节在本 wiki 中**尚无页面**，见 [[queries/215节引用114自然法则未入库]]。
- 来源未讨论多项式环的公理性质（结合律、交换律、分配律的独立验证），只以「应用自然法则 (1.1.4)」一笔带过。
