# 二次函数的抛物线图像

按《数学指南——实用数学手册》0.2.3 节，最简单的二次函数 \(y = ax^{2}\)（\(a \neq 0\)）的图像是一条抛物线（来源图 0.27）。本节从“函数图像”而非“圆锥曲线”的角度讨论抛物线的形状与位置。

## 开口方向

开口方向由二次项系数 \(a\) 的符号决定。来源图 0.27 按两类给出示意：

- \(a > 0\)：开口向上（图 0.27 的 (a)(c)）
- \(a < 0\)：开口向下（图 0.27 的 (b)(d)）

## 顶点

最简形式 \(y = ax^{2}\) 的顶点为 \((0,0)\)。

一般形式 \(y = ax^{2} + 2bx + c\) 经配方（见 [[二次配方与顶点形式]]）化为

```latex
y = a \left(x + \frac{b}{a}\right)^{2} - \frac{D}{a}
```

后，来源断言其图像可由最简形式图像的顶点 \((0,0)\) 平移到

```latex
\left(-\frac{b}{a}, -\frac{D}{a}\right)
```

得到，其中 \(D := b^{2} - ac\)。因此一般二次函数图像的顶点坐标直接由 \(a, b, D\) 读出。

这一主张把配方与 [[函数图像的平移]] 联系起来，是 [[标准形式经三类变换生成全部函数图像]] 在二次函数这一特例上的具体体现，另见 [[一般二次函数图像由最简抛物线平移得到]]。

## 与 \(x\) 轴的交点

抛物线与 \(x\) 轴的交点个数由判别式 \(D\) 决定：\(D > 0\) 时有两个不同交点，\(D = 0\) 时相切（一个二重交点），\(D < 0\) 时（实）抛物线与 \(x\) 轴不相交。详见 [[二次判别式]] 与 [[二次方程的复零点]]。

## 与圆锥曲线视角的关系

本节讨论的抛物线与 [[抛物线的标准方程]]、[[圆锥曲线]] 中所讨论的抛物线是同一几何对象的不同刻画方式：前者以函数 \(y = f(x)\) 的形式出现，后者以到焦点与准线等距的几何条件出现。两处对焦点、准线、离心率等性质的处理不同，引用时应注意区分视角与记法（见 [[二次函数判别式记法差异]]）。
