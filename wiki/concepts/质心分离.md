# 质心运动的分离

质心运动的分离是《数学指南——实用数学手册》1.12.5.2 节求解二体问题的第一步：把整体运动拆成「质心的匀速直线运动」与「关于质心的相对运动」两部分。

## 定义与推导

对系统的质心

```text
y := (1/m)( m₁ x₁ + m₂ x₂ )
```

以及总动量 $P = m y'$，从运动定律 (1.290) 得到总动量守恒

```text
P' = 0,
```

即 $m y'' = 0$，其解为

```text
y(t) = y(0) + t y'(0).
```

因而质心以常速度沿一直线运动。显式地：

```text
y(0)  = (1/m)( m₁ x₁₀ + m₂ x₂₀ ),
y'(0) = (1/m)( m₁ v₁ + m₂ v₂ ).
```

## 关于质心的相对运动

对相对坐标

```text
y_j := x_j - y
```

可以得到运动方程

```text
m₁ y₁'' = F,   m₂ y₂'' = -F,   m₁ y₁ + m₂ y₂ = 0.
```
