# 次序公理

**次序公理**（图 3.21(b)）是 [[concepts/希尔伯特公理体系]] 中关于「介于」（之间）关系的一组公理，共三条。源文原文如下：

(i) 若一点 B 位于点 A 和点 C 之间, 则 A, B 和 C 是在同一条直线上的三个不同的点, 并且点 B 也在 C 和 A 之间.

(ii) 对每两个不同的点 A 和 C, 存在一点 B 位于 C 和 A 之间.

(iii) 若三个不同的点在一条直线上, 则正好只有它们中的一个点位于其他两点之间.

「之间」是平面几何的基本概念之一，在构建几何的基础中不能被描述。以此公理组为基础，才可能给出 [[concepts/线段的定义]]、[[concepts/射线的定义]] 等概念，并证明 [[findings/由一条直线对平面的分解定理]]，以及陈述 [[concepts/帕施公理]]。
