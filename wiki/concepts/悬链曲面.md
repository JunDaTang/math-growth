# 悬链曲面

悬链曲面（catenoid）在《数学指南——实用数学手册》5.2.2 中作为旋转曲面形式的等周/面积最小问题出现。

## 变分提法

让一条曲线 $y=y(x)$ 围绕 x 轴旋转，目的是按这一方式产生一个面积最小的曲面：

```latex
\int_{x_{0}}^{x_{1}} L(y(x),y'(x),x)\,\mathrm{d}x \stackrel{!}{=} \min,\quad
y(x_{0})=y_{0},\quad y(x_{1})=y_{1},
```

这里

```latex
L=y\sqrt{1+y'^{2}}.
```

## 求解

根据 (5.8)（守恒律——被积函数不含 $x$ 时 $y'L_{y'}-L=$ 常数），从欧拉-拉格朗日方程得到 $y'L_{y'}-L=$ 常数，即有

```latex
\frac{y(x)}{\sqrt{1+y'(x)^{2}}}=\text{常数}.
```

其解为悬链面

```latex
y=c\cosh\left(\frac{x}{c}+b\right),
```

原文称此悬链曲面是通过旋转曲线得到的唯一的极小曲面。
