# 伴随矩阵

## 定义

设给定实或复 `m × n` 矩阵 `A = (a_jk)`。先求 [[转置矩阵]]，再取各元素的复数共轭，就得到 A 的**伴随矩阵** `A*`。若用 `a_jk^*` 表示 `A*` 的元素，则

```
a_kj^* := conj(a_jk),        k = 1,...,n,  j = 1,...,m
```

因此 `A*` 是 `n × m` 矩阵。

来源例 8：

```
A := ( 1 2 3i )     A* = ( 1  4 )
     ( 4 5  6 )           ( 2  5 )
                           ( −3i 6 )
```

## 性质

对于所有的实数或复数 `α` 和 `β`：

```
(A*)* = A
(αA + βB)* = ᾱA* + β̄B*        （注意标量取共轭）
(CD)* = D* C*
(Q^{-1})* = (Q*)^{-1}
```

前置假设同 [[转置矩阵]]。

## ⚠️ 与「伴随行列式」的区分

本节来源中的「伴随矩阵」指**共轭转置**（adjoint / conjugate transpose）；而 2.1.2 节所定义的 [[伴随行列式]] 是行列式展开中的代数余子式型概念。二者名称相近但完全不同：来源在本节逆矩阵元素定理处引用的 `A_kj` 属于后者（[[伴随行列式]]），而不是本节定义的 `A*`。参见既有问题 [[212节Ajk称伴随行列式是否宜称代数余子式]]。
