# 狄利克雷算术级数定理

## 陈述（1837）

如果 a 和 d 是两个互素的自然数，那么算术级数（原文公式 (2.70)）

```text
a, a + d, a + 2d, a + 3d, …
```

含有无穷多个素数。此处 a、d 互素的条件是必要的：若 a、d 不互素，则该级数中始终不出现素数，除非 a 本身是素数。

**例 1**：取 $a = 3$ 与 $d = 5$，得到序列 $3, 8, 13, 18, 23, \dots$，其中含有无穷多个素数。

## 推论：以 $\ln p / p$ 加权的等分布

对任意实数 $x \geqslant 2$，令 $P_{a,d}(x)$ 为 (2.70) 中所有满足 $p \leqslant x$ 的素数 p 的集合，则（原文公式 (P)）

```text
∑_{p ∈ P_{a,d}(x)} (ln p)/p = (1/φ(d))·ln x + O(1),  x → +∞
```

其中 φ 为 [[欧拉φ函数]]（参看 2.7.2），余项 O(1) 与 a 无关；例 1 中有 $\varphi(d) = 4$。该公式的含义是：所有具有常数公差 d 的数列含有「渐近」相等个数的素数，且与 a 的取值无关。特别地，当 $a = 2$、$d = 1$ 时数列含有所有素数，此时 $\varphi(d) = 1$。详见 [[concepts/狄利克雷算术级数定理]]。

## 方法意义

在证明中，[[狄利克雷]] 把傅里叶级数、狄利克雷级数及 L 级数引入数论，开创了 [[解析数论]]，这些方法在代数数论中同样是基本的。其技术核心是把欧拉乘积写成带 [[狄利克雷特征]] 的形式，得到 [[狄利克雷L级数]]，见 [[素数模m的狄利克雷局部化原理]]。
