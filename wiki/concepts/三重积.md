# 三重积

本手册 1.8.3 节定义**三重积**为

```latex
(abc) := (a × b)c.
```

$a, b, c$ 置换后，三重积 $(abc)$ 要乘以置换的符号，即

```latex
(abc) = (bca) = (cab) = −(acb) = −(bac) = −(acb).
```

原书此处末项记为 $-(acb)$，与前面重复，疑为 $-(cba)$，见 [[queries/18节三重积置换公式末项是否重复讹误]]。

几何意义：三重积 $(abc)$ 是由 $a, b, c$ 张成的**平行六面体的体积**（图 1.93），详见 [[三重积的几何意义为平行六面体体积]]。

两个三重积之积可用行列式表示：

```latex
(abc)(efg) =
| a e  a f  a g |
| b e  b f  b g |
| c e  c f  c g |
```

**线性无关判据**：三个向量 $a, b, c$ 是线性无关的，当且仅当满足下面两个条件之一：

(a) $(abc) \neq 0$；

(b) [[格拉姆行列式]]非零。

在笛卡儿坐标下 $(abc)$ 等于以三向量坐标为行的三阶行列式；在一般坐标系下等于 $(e_1 e_2 e_3)$ 乘以以反变坐标为行的三阶行列式。
