# 质量平衡方程

1.9.7 节的核心方程，描述连续介质中物质密度的时间变化、通量散度与源项之间的平衡：

```
ρ_t + div J = F,  在 Ω 上                                       (1.166)
```

其中

```
ρ(x,t)  在时刻 t 时在点 x 处的质量密度（单位体积的质量）
J(x,t)  在时刻 t 时在点 x 处的质量流的通量密度向量（单位面积与时间的质量）
F(x,t)  在时刻 t 时在点 x 处产生物质的力密度（单位体积单位时间生成的质量）
```

## 推导要点

以区域 $D \subset \Omega$ 内的物质 $S$ 为对象，定义 $A(t)$（$D$ 中物质 $S$ 的质量）、$B(t)$（$[0,t]$ 内流出 $D$ 外的质量）、$C(t)$（$[0,t]$ 内由化学反应生成的质量），质量守恒给出

```
A′(t) = −B′(t) + C′(t)                                          (1.167)
```

将三个量用密度表示，并借助 [[concepts/高斯定理]] 把边界积分改写为体积积分，得到同一区域上的积分恒等式，再由 [[concepts/体积的导数]] 即得 (1.166)。

## 适用范围

该推导明确限定于「能相互起化学反应的物质 $S$」，即理想的均质连续介质模型假设。取 $F=0$ 并令 $\boldsymbol{J}=\rho\boldsymbol{v}$，即退化为 [[concepts/连续性方程]]；把质量换成电荷、热量则分别得到电流守恒与 [[concepts/热传导方程]]。
