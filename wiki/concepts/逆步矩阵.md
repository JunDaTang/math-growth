# 逆步矩阵

矩阵 `(Q^{-1})^T` 称为 Q 的**逆步矩阵**，其中 Q 为可逆方阵（`det Q ≠ 0`）。

## 相关性质

由来源给出的性质表：

```
(Q^{-1})^T = (Q^T)^{-1}
(Q^{-1})* = (Q*)^{-1}
```

即取逆与取转置（或取伴随）两种运算可以交换次序。来源说明：假设 Q 的逆矩阵 `Q^{-1}` 存在（即 `det Q ≠ 0`），此时 `Q*` 和 `Q^T` 的逆矩阵也存在。
