# 古典概型

## 定义

《数学指南——实用数学手册》6.1.1 节的基本模型：考虑一个随机试验，其全部可能结果记为

```
e_1, e_2, …, e_n
```

称为**基本事件**。用 $E$ 表示由所有 $e_j$ 组成的**全体事件**集合，**事件** $A$ 是 $E$ 的一个子集。对给定事件 $A$ 按如下法则赋予概率

```
P(A) := A 所包含元素的个数 / n        (6.1)
```

古典文献中的等价表述为

```
P(A) := 有利结果数 / 可能结果数        (6.2)
```

其中 $A$ 中的基本事件称为「有利结果」，全部基本事件组成的集合称为「可能结果」组成的集合。文中指出，概率概念的这个定义式是雅各布·伯努利在 17 世纪末引入的。

## 适用范围与前提

该定义以「有限个等可能基本事件」为前提：$P(A)$ 只依赖 $A$ 所含基本事件的**个数**，因此必须先把试验结果划分成彼此等可能的原子事件。本节所有例子（掷骰子、掷两粒骰子、抽彩、生日问题）都遵循这一划分方式。一旦样本空间无限或各结果不等可能，就需要 [[concepts/概率密度与分布函数]] 所描述的连续型模型。

## 本节中的应用

- **掷一粒骰子**：$e_1,\dots,e_6$；$P(\{e_1\}) = 1/6$，$P(\{e_2,e_4,e_6\}) = 1/2$。
- **掷两粒骰子**：$e_{ij}$（$i,j = 1,\dots,6$），共 36 个基本事件；点数相同的概率为 $6/36 = 1/6$。
- **抽彩问题（45 取 6）**：基本事件为 $e_{i_1 i_2 \dots i_6}$，共 $\binom{45}{6}$ 个。
- **生日问题**：基本事件为 $e_{i_1\dots i_n}$，$i_j = 1,\dots,365$，共 $365^n$ 个。
