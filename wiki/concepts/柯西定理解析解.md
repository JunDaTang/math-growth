# 柯西定理（解析解）

**柯西定理**是《数学指南——实用数学手册》1.12.9.3 节陈述的结论：解析右端给出解析解。

## 陈述（源文）

如果 (1.316) 的右端 $f$ 是**解析的**（原书脚注 2) 对解析性的界定未转录），那么初值问题的最大解 $x=x(t)$ 也是解析的。$x=x(t)$ 的局部幂级数展开由**比较系数法**得到。

源文附加的注是：对于复变量 $t,x_1,\cdots,x_n$ 和复值函数 $f_1,\cdots,f_n$，柯西定理仍然成立——即该结论不限于实变量情形。

## 例（源文）

对初值问题 $x'=x$、$x(0)=1$：由方程本身可得 $x'(0)=x(0)=1$，逐次求导并对所有 $n$ 得到 $x^{(n)}(0)=1$，于是

```text
x(t) = x(0) + x'(0) t + x''(0) t²/2! + ...
     = 1 + t + t²/2! + ... = e^t.
```

该例演示了「先由方程递推初值处的各阶导数，再写出幂级数」的比较系数法。

## 与相邻结论的关系

- 与 1.12.9.2 的 [[concepts/解对初值与参数的光滑依赖]] 互补：后者给出 $C^k$ 右端对应 $C^k$ 解，前者把结论推到解析（$C^\infty$ 且幂级数收敛）层级。
- 与 1.12.9.1 的 [[concepts/最大解]] 相连：解析性是最大解在整个存在域上的性质，而非仅局部。
