# 含指数函数的定积分（0.9.6.1 节）

0.9.6.1 是 0.9.6 定积分表的第一个子节，收录条目 1–32，开篇说明其考察对象为「含指数函数、代数函数、三角函数和对数函数的积分」，即被积函数不必只含指数函数。

## 内部结构

**（一）纯指数型（条目 1–7）**

- 条目 1、2 给出 ∫₀^∞ xⁿe^{−αx}dx 与 ∫₀^∞ xⁿe^{−αx²}dx 的一般式，二者都以 [[伽马函数]] Γ 表达；
- 条目 3、4 是条目 2 中 n 取 0、2 的特例：∫₀^∞ e^{−α²x²}dx = √π/(2α)，∫₀^∞ x²e^{−α²x²}dx = √π/(4α³)；
- 条目 5 是带余弦因子的高斯型积分：∫₀^∞ e^{−α²x²}cos βx dx = (√π/2α)e^{−β²/4α²}；
- 条目 6、7 是以 e^x 为分母的经典结果 ∫₀^∞ x dx/(e^x−1) = π²/6、∫₀^∞ x dx/(e^x+1) = π²/12。

**（二）含对数因子的指数积分（条目 8–11）**

条目 8 为 ∫₀^∞ e^{−αx} sin x /x dx = arccot α；条目 9–11 的三条结果以 [[欧拉常数]] C 表达，见 [[096节以欧拉常数C给出若干定积分值]]。

**（三）三角型定积分与其正交关系（条目 12–26）**

- 条目 12 是 ∫₀^{π/2} sin^{2a+1}x cos^{2b+1}x dx，以 [[贝塔函数]] 与 Γ 表达；
- 条目 13–15 是周期 2π 上正弦/余弦系的正交关系，用 [[克罗内克符号]] 书写；
- 条目 16–22 是形如 ∫₀^∞ sin(αx)/x、∫₀^∞ (cos αx − cos βx)/x 的振荡积分，结果多为 π/2 的分段常数或对数；
- 条目 23 给出 ∫₀^∞ sin x /√x dx = ∫₀^∞ cos x /√x dx = √(π/2)；
- 条目 24、25 为含 1/(α²+x²)、1/(1+x²) 的有理权重振荡积分，结果含指数衰减 e^{−|αβ|}、e^{−|α|}；
- 条目 26 为 ∫₀^∞ sin²αx /x² dx = (π/2)|α|。

**（四）椭圆型与其它（条目 27–32）**

条目 27 为菲涅耳型积分 ∫_{−∞}^{+∞} sin(x²)dx = ∫_{−∞}^{+∞} cos(x²)dx = √(π/2)；条目 28–31 分母同为 √(1−a²sin²x)，其中条目 30、31 需要 [[完全椭圆积分]] E、K；条目 32 为泊松核型积分 ∫₀^π cos αx dx /(1−2βcos x+β²) = πβ^α/(1−β²)（α ∈ ℕ，|β| < 1）。

## 与 0.9.5 节的关系

本子节与不定积分表 0.9.5 中的 [[含指数函数的积分]] 同名但内容不同：0.9.5 给出原函数族，0.9.6.1 给出在固定上下限上的定值，故出现了不定积分表中不存在的 Γ、C、E、K 等特殊常数。

## 疑点

条目 2、5、10 在入库文本中未印出序号，见 [[096节条目编号在多个公式处缺失]]；条目 18 的 ∫₀^a cos αx dx /x = ∞ 需理解为 a ≠ 0 时长发散；全部转写疑点见 [[096节公式转写疑误汇总]]。
