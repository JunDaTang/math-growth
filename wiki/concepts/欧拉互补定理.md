# 欧拉互补定理（反射公式）

《数学指南——实用数学手册》1.14.16 节给出的反射型恒等式：

$$\Gamma(z)\Gamma(1-z) = \frac{\pi}{\sin \pi z}, \quad \text{对所有不是整数的复数 } z.$$

它把关于 $z$ 与 $1-z$ 的[[欧拉伽马函数]]值联系起来，也称**反射公式**，以[[欧拉]]命名。

## 相邻形式

同节「伽马函数更多的性质」给出两个相关的反射型恒等式：

- (iii) 对不是整数的所有复数 $z$：$\Gamma(z)\Gamma(-z) = -\dfrac{\pi}{z\sin(\pi z)}$；
- (iv) 对 $z + \frac{1}{2}$ 不是整数的所有复数 $z$：$\Gamma\!\left(\frac{1}{2}+z\right)\Gamma\!\left(\frac{1}{2}-z\right) = \dfrac{\pi}{\cos(\pi z)}$。

这些恒等式与[[斯特林公式]]、[[高斯乘积公式]]一起构成源文所列 Γ 的核心性质。
