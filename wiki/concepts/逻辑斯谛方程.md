# 逻辑斯谛（logistic）方程

本节 1.12.1.3「阻抗增长」给出的方程：

```latex
\begin{array}{l}
N'(t) = \alpha N(t) - \beta N(t)^2, \\
N(0) = N_0 \quad (\text{初值}).
\end{array}                                       \tag{1.208}
```

它「是从增长方程 (1.206) 添加阻抗项而得，阻抗项描述了种群寻找食物的困难性」。方程 (1.208) 是 [[里卡蒂微分方程]] 的特殊情形（见 1.12.4.7）。

经 [[重标度]] $N=\gamma\mathcal N,\ t=\delta\tau$ 并取 $\delta=1/\alpha,\ \gamma=\alpha/\beta$，归一化为 (1.209)：

```latex
\begin{array}{l}
\mathcal N'(\tau) = \mathcal N(\tau) - \mathcal N(\tau)^2, \\
\mathcal N(0) = \mathcal N_0 \quad (\text{初始条件}).
\end{array}                                       \tag{1.209}
```

解为 $\mathcal N(\tau)=\dfrac{1}{1+C\mathrm{e}^{-\tau}},\ C=(1-\mathcal N_0)/\mathcal N_0$（$0<\mathcal N_0\le 1$）。平衡态为 $\mathcal N\equiv 0$ 与 $\mathcal N\equiv 1$。
