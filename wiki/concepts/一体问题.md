# 一体问题（二体问题的约化）

「一体问题」是《数学指南——实用数学手册》1.12.5.2 节中二体问题化简后的目标形式：一个质量为 $m_2$ 的物体在质量为 m 的物体的引力场中的运动。

## 定义

对相对坐标

```text
x := x₂ - x₁,
```

从 $x = y_2 - y_1$ 得到运动定律

```text
m₂ x'' = - G m m₂ x / |x|³,
x(0) = x₂₀ - x₁₀,   x'(0) = v₂ - v₁                    (1.291)
```

## 与原问题的关系

若已知 (1.291) 的解，则通过

```text
x₁(t) = y(t) - (m₂/m) x(t),   x₂(t) = y(t) - (m₁/m) x(t)
```

可得到原来的运动方程 (1.290) 的一个解，其中 $\boldsymbol{y}(t)$ 是匀速直线运动的质心。原书中 $x_2(t)$ 一项的符号存疑，见 [[1125节反解公式x2符号疑义]]。

## 要点

- 约化后的方程中出现的质量参数是总质量 $m = m_1 + m_2$（作为引力源的质量），而运动物体的质量是 $m_2$。
- 约化方程 (1.291) 本身就是一个中心力场中的单体问题，其解由 [[二体问题]] 一节继续展开为极坐标方程组 (1.294) 与轨道方程 (1.295)。
