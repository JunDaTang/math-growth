# 正弦式波与周期函数

## 周期函数与振动

1.1.3 节：给定周期为 T > 0 的函数 f，即

```latex
f(t + T) = f(t), \quad \text{对所有 } t \in \mathbb{R},
```

可定义

```latex
\nu := \frac{1}{T} \quad (\text{频率}), \quad \omega := 2\pi\nu \quad (\text{角频率}).
```

**例 1（正弦振动）**：函数

```latex
y := A \cdot \sin(\omega t + \alpha)
```

描述了角频率为 ω、振幅为 A 的一个振动（图 1.12(a)）；数 α 叫做**相移**。

## 正弦式波

**例 2（正弦式波）**：设 A > 0, ω > 0，函数

```latex
y(x, t) = A \cdot \sin(\omega t + \alpha - kx)\tag{1.10}
```

描述了振幅为 A、波长为 `λ := 2π/k` 的一个波，它以**波相速度**

```latex
c := \frac{\omega}{k}
```

从左向右传播（图 1.12(b)）。数 k 叫做**波数**。根据规则 `kx = ωt + α − π/2` 随时间移动的点 (x, y(x, t))，对应着以速度 c 从左向右移动的高度为 A 的波峰。

## 复函数表示

在物理学和应用科学中，通常用复函数表示这样的波：

```latex
Y(x, t) := C \cdot \mathrm{e}^{\mathrm{i}(\omega t - kx)},
```

其中**复振幅** `C = A e^{iα}`；Y(x, t) 的虚部对应着 (1.10) 中的 y(x, t)。该表示依赖欧拉公式，见 [[concepts/欧拉公式]]。
