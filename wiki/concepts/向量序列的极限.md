# 向量序列的极限

若 (aₙ) 是向量序列，a 是某一固定向量，且所有 aₙ 和 a 的基点都是同一点 O，则定义

```
a = lim_{n→∞} a_n
当且仅当  lim_{n→∞} |a_n − a| = 0
```

其几何含义是：当 n → ∞ 时，aₙ 的终点与 a 的终点之间的距离趋向于 0（见原文图 1.94）。

这一概念是 1.9.1 节把实值函数的性质推广到 [[concepts/向量值函数]] 的**起点**：一旦有了向量序列的极限，就可以逐字照搬实值情形来定义向量函数的极限、[[concepts/向量函数的连续性]]与导数。

关键在于，该定义把代数对象（向量）的收敛归结为一个**标量距离**的收敛，因此所有的距离、范数语言都可以直接沿用。与之等价的「按坐标收敛」形式见 [[findings/向量极限的坐标收敛性判据]] 与 [[concepts/向量函数的坐标表示]]。
