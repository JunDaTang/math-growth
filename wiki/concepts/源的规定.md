# 源的规定

「源的规定」（Vorgabe der Quellen）是 [[向量分析的主要定理]] 的两大支柱之一，回答的问题为：给定一个标量函数 $\rho$，能否在指定区域上找到向量场，使 $\rho$ 恰为其散度？

## 命题

假设在 $\mathbb{R}^3$ 中[[可缩区域]] $D$ 上给定 $C^1$ 类函数 $\rho : D \to \mathbb{R}$，则在 $D$ 上总存在 $C^2$ 类向量场 $D$，满足方程

```
div D = ρ,  在 D 上.
```

即：可缩区域上任意 $C^1$ 的标量函数都能实现为某个 $C^2$ 向量场的散度。此处区域 $D$ 的可缩性是本质前提（拓扑条件），它排除了诸如「围绕空洞的场无法取为单一势的梯度」这类障碍。

## 通解结构

散度方程的通解形为

```
D = D_par + curl A,
```

其中 $D_{par}$ 是任一特解，$A$ 是 $D$ 上任意 $C^3$ 类向量场。解的齐次部分为旋度场，即 $\operatorname{curl} A$——这与 1.9.5 中「势相差常数」的非唯一性属于不同机制：散度方程的非唯一性来源于旋度自由度（三参数函数自由度），而非常数。

## 在 $\mathbb{R}^3$ 上的显式实现

当 $D = \mathbb{R}^3$，$\rho$ 为 $C^3$ 类且在某一球外为零时，取 [[体积位势]] $V$，令

```
D_par := −grad V,
```

则 $\operatorname{div} D_{par} = \rho$ 且 $\operatorname{curl} D_{par} = 0$。
