# 涡流的规定

「涡流的规定」（Vorgabe der Wirbel）是 [[向量分析的主要定理]] 的另一支柱，回答的问题为：给定一个向量场 $J$，能否在指定区域上找到向量场 $H$，使其旋度恰为 $J$？其背景是 1.9.8 由 [[斯托克斯积分定理]] 建立的「旋度—环量」图像，$J$ 亦被解释为涡密度（在电磁学语境下即电流密度）。

## 命题

假设给定 $\mathbb{R}^3$ 中 [[可缩区域]] $D$ 上的 $C^1$ 类向量场 $J$，则在 $D$ 上存在唯一一个 $C^2$ 类向量场 $H$，使得如果在 $D$ 上 $\operatorname{div} J = 0$ 时 $H$ 满足

```
curl H = J,  在 D 上.
```

前提 $\operatorname{div} J = 0$ 是必需的：由恒等式 $\operatorname{div}\operatorname{curl} H \equiv 0$，若 $J$ 是某场的旋度，则 $J$ 必须无源。这属于 [[相容性条件]]。

## 通解结构

```
H = H_par + grad U,
```

其中 $H_{par}$ 是特解，$U : D \to \mathbb{R}$ 是任意 $C^3$ 类函数。

原文在同一段落中先断言 $H$「存在唯一」，随后又给出含任意 $U$ 的通解，两者在字面上不相容。可能的读法是：唯一性应理解为在附加规范化条件（例如固定散度或边界条件）之下的唯一性，或者「唯一」一词属原文/转录措辞问题。此张力记录于 [[queries/199节涡流规定唯一性与通解矛盾]]。

## 在 $\mathbb{R}^3$ 上的显式实现

当 $D = \mathbb{R}^3$、$J$ 为 $C^3$ 类且在某一球外为零、且 $\operatorname{div} J \equiv 0$ 时，取 [[向量位势]] $C$，令

```
H_par := curl C,
```

则 $\operatorname{div} H_{par} = 0$ 且 $\operatorname{curl} H_{par} = J$。
