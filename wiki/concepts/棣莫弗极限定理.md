# 棣莫弗极限定理

## 陈述

《数学指南——实用数学手册》6.1.3 节以「棣莫弗定理（1730）」为标题给出：当试验次数 $n$ 很大时，有渐近等式

```
P(H_n = k/n) ~ (1/(σ√(2π))) e^{−(k−μ)²/(2σ²)},  k = 1,2,…,n        (6.5)
```

其中

```
μ = n/2,   σ = √(n/4)
```

右边的函数就是 [[concepts/高斯正态分布]] 的概率密度。

## 前置结果

设 $A_{n,k}$ 表示由恰好有 $k$ 个下标为「1」的所有基本事件 $e_{i_1 i_2 \cdots i_n}$ 组成的集合，即 $n$ 次试验中正面向上次数为 $k$ 的所有试验，则在 $A_{n,k}$ 的每个基本事件中频率 $H_n = k/n$，且

```
P(H_n = k/n) = C(n,k) · 1/2^n
```

## 解释与边界

文中强调这是「概率论中最重要、最深刻的研究之一」，即得到 $n \to \infty$ 极限情形的易于理解的结果。正如预料，当 $k = n/2$ 时 (6.5) 中的概率 $P$ 取得最大值。本节只讨论抛硬币（$p = 1/2$）的二项特例，未给出一般的中心极限定理表述；后者以「见 6.2.4」的方式前向引用。
