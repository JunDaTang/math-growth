# 施泰尼茨基交换定理

2.3.2 节（指 [[施泰尼茨]] 交换定理）：如果 $b_1,\dots,b_n$ 形成线性空间 X 的基，并且 $u_1,\dots,u_r$ 是 X 中的线性无关的元素，那么

```text
u₁, …, u_r, b_{r+1}, …, b_n
```

形成 X 的新基（必要时重新编号）。

该定理说明可在保持基的前提下用线性无关元素替换原基中的元素，是 [[基-线性空间]] 与 [[线性空间的维数]] 理论的基本工具。
