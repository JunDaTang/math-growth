# 含反双曲函数的积分

## 定义

「含反双曲函数的积分」指被积函数为反双曲函数 $\operatorname{arsinh}$、$\operatorname{arcosh}$、$\operatorname{artanh}$、$\operatorname{arcoth}$ 的不定积分族，对应《数学指南——实用数学手册》**0.9.5.5** 子节。本族首次出现在 0.9.5 节第 502–505 号条目中（见 [[entities/表095不定积分表-4]]）。

需要与 [[concepts/含双曲函数的积分]] 区分：

- [[concepts/含双曲函数的积分]] 的被积函数**是**双曲函数本身（被积式为 $\sinh x$、$\cosh x$ 等的表达式）。
- 本概念的被积函数**是反双曲函数**（被积式为 $\operatorname{arsinh}(x/\alpha)$ 等），函数方向相反。

同样地，本族与 [[concepts/含反三角函数的积分]] 构成「反函数型」与「三角型」的对照关系。

## 基本公式

本族在 0.9.5.5 中给出的全部条目（单位系数形式，均可由分部积分令 $v = x$ 得到）：

```latex
\int \operatorname{arsinh}\frac{x}{\alpha}\,\mathrm{d}x
  = x \operatorname{arsinh}\frac{x}{\alpha} - \sqrt{x^{2}+\alpha^{2}}

\int \operatorname{arcosh}\frac{x}{\alpha}\,\mathrm{d}x
  = x \operatorname{arcosh}\frac{x}{\alpha} - \sqrt{x^{2}-\alpha^{2}}
  \quad (|\alpha| < |x|)

\int \operatorname{artanh}\frac{x}{\alpha}\,\mathrm{d}x
  = x \operatorname{artanh}\frac{x}{\alpha} + \frac{\alpha}{2}\ln(\alpha^{2}-x^{2})
  \quad (|x| < |\alpha|)

\int \operatorname{arcoth}\frac{x}{\alpha}\,\mathrm{d}x
  = x \operatorname{arcoth}\frac{x}{\alpha} + \frac{\alpha}{2}\ln(x^{2}-\alpha^{2})
  \quad (|\alpha| < |x|)
```

## 统一推导模式

四条公式共享同一结构：$\int u\,\mathrm{d}x = xu - \int x\,\mathrm{d}u$，其中

- 当 $u = \operatorname{arsinh}(x/\alpha)$ 时，$x\,\mathrm{d}u = x\,\mathrm{d}x/\sqrt{x^{2}+\alpha^{2}}$，其积分恰为 $\sqrt{x^{2}+\alpha^{2}}$，与结果中的负根式项对应；
- 当 $u = \operatorname{arcosh}(x/\alpha)$ 时，对应 $\sqrt{x^{2}-\alpha^{2}}$；
- 当 $u = \operatorname{artanh}(x/\alpha)$ 或 $\operatorname{arcoth}(x/\alpha)$ 时，$x\,\mathrm{d}u = \pm \alpha x\,\mathrm{d}x/(\alpha^{2}-x^{2})$，其积分给出对数项。

因此本族可视为 [[concepts/分部积分公式]] 的直接应用，推导细节与验算见 [[findings/反双曲函数积分可由分部积分令v等于x得到]] 与 [[findings/095节501至505条目逐条求导验算正确]]。

## 定义域

- $\operatorname{arsinh}$ 在全实轴有定义，因之 502 无附加条件。
- $\operatorname{arcosh}(x/\alpha)$ 要求 $|x/\alpha| \ge 1$，故给出 $|\alpha| < |x|$，排除根式为零的端点。
- $\operatorname{artanh}(x/\alpha)$ 要求 $|x/\alpha| < 1$，故给出 $|x| < |\alpha|$，排除对数发散的端点。
- $\operatorname{arcoth}(x/\alpha)$ 要求 $|x/\alpha| > 1$，故给出 $|\alpha| < |x|$。

端点是否应取到，见 [[queries/095节反双曲函数积分定义域的端点条件]]。
