# 第二类椭圆积分

第二类椭圆积分 $E(k,\varphi)$ 的两种等价积分表示为（源文 0.5.4 节）：

$$
E(k, \varphi) = \int_0^{\varphi} \sqrt{1 - k^2 \sin^2 \psi}\,\mathrm{d}\psi = \int_0^{\sin \varphi} \sqrt{\frac{1 - k^2 x^2}{1 - x^2}}\,\mathrm{d}x,
$$

其中 [[模数与模角]] 给出 $k = \sin\alpha$，[[振幅]] $\varphi$ 为积分上限。

## 数值表

[[表b第二类椭圆积分]] 以 $\alpha$ 为列（0°–90°，步长 10°）、$\varphi$ 为行（0°–90°，步长 10°）列出数值。可观察到：

- 当 $\varphi = 0^\circ$ 时 $E = 0$；
- 与 [[第一类椭圆积分]] 相反，在同一 $\varphi$ 行上，$E$ 随 $\alpha$（即随 $k$）增大而减小；
- 在 $\varphi = 90^\circ$ 行，数值即[[完全椭圆积分]]的 $\mathrm{E}$：例如 $\alpha = 0^\circ$ 对应 $1.5708$，$\alpha = 30^\circ$ 对应 $1.467\,5$，$\alpha = 90^\circ$ 对应 $1.000\,0$，与 [[表c完全椭圆积分]] 中同 $\alpha$ 的 $E$ 值一致。

## 与完全椭圆积分的关系

$\mathrm{E} = E(k, \pi/2)$，即表 b 最后一行（$\varphi = 90^\circ$）与表 c 的 $E$ 列逐项对应，可作交叉校核，见 [[表b与表c在φ等于90度处的交叉一致]]。

## 数据校勘

表 b 中有两处数值与相邻数据及表 c 的交叉校核不符（$\alpha = 10^\circ,\varphi = 40^\circ$ 与 $\alpha = 80^\circ,\varphi = 10^\circ$），疑为排版讹误，详见 [[queries/表b中两处数值的排版讹误]]。
