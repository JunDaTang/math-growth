# 系统宏观量

《数学指南——实用数学手册》1.9.6 节在讨论 N 体系统时，先引入一组描述整个系统的「宏观量」。原文定义（逐条照录）如下：

- 总质量 $M := \sum_{j=1}^{N} m_{j}$
- 重心 $r_{cm} := \frac{1}{M} \sum_{j=1}^{N} m_{j} r_{j}$
- 总动量 $P := \sum_{j=1}^{N} m_{j} r_{j}'$
- 总角动量 $A := \sum_{j=1}^{N} r_{j} \times m_{j} r_{j}'$
- 合力 $F := \sum_{j=1}^{N} F_{j}$
- 总力矩 $T := \sum_{j=1}^{N} r_{j} \times F_{j}$
- 总动能 $T := \sum_{j=1}^{N} \frac{1}{2} m_j r'_2$
- 总势能 $U$

## 说明

- 这些量是 [[concepts/平衡方程]] 与 [[concepts/守恒律]] 所使用的因变量：平衡方程给出它们的（或它们的和的）时间导数，守恒律则给出导数为零时的结论。
- 总质量 $M$ 与重心 $r_{cm}$ 只在质心运动方程 $M r_{cm}'' = F$ 中出现；$r_{cm}$ 是各 $r_j$ 以质量为权的平均。
- 总角动量 $A$ 与总力矩 $T$（力矩）中出现的「$\times$」是 1.8 节的[[concepts/向量积]]。
- 总动能 $T$（动能）与总力矩 $T$（力矩）在转写文本中使用了同一个符号 $T$，且总动能公式右端写作 $r'_2$，两处均存在疑义，见 [[queries/196节总动能公式r2转写与符号T冲突]]。
- 总势能 $U$ 与 [[concepts/势能]] 及 [[concepts/势与势函数]] 中讨论的势函数是同一对象在 N 体情形下的推广；对[[concepts/保守力]]，$U$ 的存在性正是力可写成 $F_j = -\operatorname{grad}_{r_j}U(r)$ 的条件。
