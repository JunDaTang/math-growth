# 命题逻辑公理系统

4.4.1.1 节给出的 15 条公理（源文编号 A1–A15），是用纯粹形式方法刻画全部[[concepts/重言式]]的出发点：

```
(A1)  p → ¬¬p
(A2)  ¬¬p → p
(A3)  p → (q → p)
(A4)  ((p → q) → p) → p
(A5)  (p → q) → ((q → r) → (p → r))
(A6)  p ∧ q → p
(A7)  p ∧ q → q
(A8)  (p → q) → ((p → r) → (p → q ∧ r))
(A9)  p → p ∨ q
(A10) q → p ∨ q
(A11) (p → r) → ((q → r) → (p ∨ q → r))
(A12) (p ↔ q) → (p → q)
(A13) (p ↔ q) → (q → p)
(A14) (p → q) → ((q → p) → (p ↔ q))
(A15) (p → q) → (¬q → ¬p)
```

结构上可分四组：否定（A1–A2）、蕴涵（A3–A5）、合取（A6–A8）、析取与等值（A9–A14），以及逆否形式的 A15。A15 即 4.1 节 [[concepts/换位]] 所讨论的换位律。

公理本身全部是重言式，且由 [[concepts/命题逻辑主要定理]] 保证：表达式是重言式当且仅当它可从这些公理推演出；各公理相互独立。推演机制见 [[concepts/推演规则]]。
