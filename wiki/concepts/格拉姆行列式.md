# 格拉姆行列式

本手册 1.8.3 节在讨论三个向量 $a, b, c$ 的线性无关性时，给出除三重积之外的第二条判据，即**格拉姆行列式**非零：

```latex
| a a  a b  a c |
| b a  b b  b c |  ≠ 0
| c a  c b  c c |
```

其中每个元素都是相应两个向量的标量积。故三个向量 $a, b, c$ 线性无关，当且仅当 $(abc) \neq 0$，或等价地，格拉姆行列式不等于零。

原书称此行列式为「格拉姆行列式」，未给出处与证明。它与 [[三重积]] 并列构成 1.8 节对线性无关的两条判据。

参见 [[标量积]]、[[三重积]]、[[线性无关的三重积与格拉姆行列式判据]]。
