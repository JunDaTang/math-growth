# 二次方程的复零点

《数学指南——实用数学手册》0.2.3 节在判别式 \(D < 0\) 的情形下（情形 3），给出二次方程 \(ax^{2} + 2bx + c = 0\) 的两个复零点

```latex
x_{\pm} = \frac{-b \pm \mathrm{i} \sqrt{-D}}{a} = \frac{-b \pm \mathrm{i} \sqrt{a c - b^{2}}}{a},
```

其中 \(\mathrm{i}\) 是虚数单位，满足 \(\mathrm{i}^{2} = -1\)（来源提示参看《数学指南》1.1.2 节）。

## 几何含义

来源明确说明：在这种情况下，（实）抛物线 \(y = ax^{2} + 2bx + c\) 与 \(x\) 轴不相交（图 0.28(c)）。也就是说，复零点是方程在复数域中的解，但不表现为实函数图像与 \(x\) 轴的交点。

## 数值例子

来源给出的第三个例子即属此情形：方程 \(x^{2} + 2x + 2 = 0\) 的零点为

```latex
x_{\pm} = - 1 \pm \sqrt {1 - 2} = - 1 \pm \mathrm{i}.
```

此处 \(a = 1\)、\(b = 1\)、\(c = 2\)，判别式 \(D = 1 - 2 = -1 < 0\)，\(\sqrt{-D} = 1\)。

## 与其他情形的对照

三种情形由 [[二次判别式]] 的符号统一刻画：\(D > 0\) 两个不同实零点、\(D = 0\) 一个实（二重）零点、\(D < 0\) 两个共轭复零点。求根公式的统一形式见 [[二次方程求根公式]]。

## 来源边界

来源仅引用虚数单位的定义并给出复零点公式，未讨论复数域的构造、复数的极坐标表示、代数基本定理，也未讨论复零点在因式分解中的意义。
