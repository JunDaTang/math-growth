# 线性算子的迹与行列式

2.3.3.4 节。设 $\dim X < \infty$，用下列关系式定义线性算子 $A: X \to X$ 的迹和行列式：

```text
tr A := tr(a_{jk}),   det A := det(a_{jk})
```

这些定义都与为形成矩阵所使用的基的选取无关。定理：对两个线性算子 $A, B: X \to X$ 有

```text
(i)   det(AB) = (det A)(det B)
(ii)  A 是双射 ⇔ det A ≠ 0
(iii) tr(αA + βB) = α tr A + β tr B
(iv)  tr(AB) = tr(BA)
(v)   tr I_X = dim X
```

矩阵情形见 [[矩阵的迹]]、[[行列式]]；相伴矩阵见 [[相伴矩阵与基变换]]。
