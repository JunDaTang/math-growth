# 0.9.6 节公式转写疑误汇总

本页汇总 0.9.6 节（条目 1–56）在入库文本中发现的转写与排版疑点，供后续与纸质原书核对。

## 一、编号类

1. 条目 **2、5、10、38、47** 未印出序号（可由上下文锁定，见 [[096节条目编号在多个公式处缺失]]）。
2. 条目 **12**、**29** 的序号在文本中呈现为「1 2.」「2 9.」，两位数字间有间隙。
3. 脚注序号 1)、2) 分挂于条目 13、15 之后，但脚注正文被合并为一条写在条目 26 之后，位置与标记分离。

## 二、公式内容类

| 条目 | 疑点 | 处理 |
|------|------|------|
| 2 | 条件写作「n, α, ∈ ℝ」，逗号多余 | 应为「n, α ∈ ℝ」 |
| 2 | 三种情形的条件「n = 2k, k ∈ ℕ」与首行「n > −1」并列，k 是否含 0 未说明 | 待核 |
| 18 | ∫₀^a cos αx dx/x = ∞（a ∈ ℝ），未排除 a = 0 | 应补充 a ≠ 0 |
| 19 | 与条目 17 对照，条件 0 < s < 1 使分母 cos(sπ/2) 不为零，正确 | 通过 |
| 46 | 条件仅写 α ⩾ β，未限定 α > 0；α² − β² 需非负 | 应补充 α ⩾ |β| 或 α > 0 |
| 47 | 分支条件 α ⩾ β > 0 与 β ⩾ α > 0 在 α = β 时重叠，两式取值相同（2π ln α = 2π ln β） | 逻辑自洽，仅书写冗余 |
| 51、52 | 条件仅写 α < 1，未给下界 | 结合收敛性应补 0 < α < 1 |
| 54 | 结果分子含因子 **√x**，应为 **√π** | 见 [[096节条目54结果中的根号x疑为根号pi]] |

## 三、已核对通过的条目

- 条目 3、4 与条目 2 在 n = 0、2 的特殊化一致（√π/(2α)，√π/(4α³)，其中 α 以 α² 代入）；
- 条目 6、7 与已知 ζ(2) = π²/6 及 (1−2^{1−2})ζ(2) = π²/12 一致；
- 条目 13–15 的正交关系与傅里叶系数的标准结果一致，见 [[096节三角函数正交性由克罗内克符号表达]]；
- 条目 41、48 的 ∫₀^{π/2} ln sin x dx = −(π/2)ln 2 与 ∫₀^{π/2} ln tan x dx = 0 与标准结果一致；
- 条目 55、56 相差 2 倍，与 [0,1] 与 [0,∞) 上被积函数对称性相符；
- 条目 9 与条目 33 同取 −C，自洽。

## 开放问题

- 条目 17、19 的分母 sin(sπ/2)、cos(sπ/2) 与条件 0 < s < 2、0 < s < 1 是否应再作 s ≠ 1、s ≠ 2 的显式排除？
- 条目 30、31 中 E、K 的模数/参数约定依赖 0.5.4 节，该节尚未入库，无法核对，见 [[096节引用节号011-051-054尚未入库]]。
