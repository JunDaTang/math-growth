# 7.2.2.2 节 CG 算法中剩余向量更新式 r^(k) = x^(k-1) + q_k z 是否为 r^(k-1) − q_k z 之误？

## 问题

《数学指南——实用数学手册》7.2.2.2 节的 CG 算法块中，同一行给出

```
x^{(k)} = x^{(k-1)} + q_k p^{(k)},   r^{(k)} = x^{(k-1)} + q_k z,
```

其中 $z = Ap^{(k)}$。

## 疑点

1. 等号右边出现了 $x^{(k-1)}$，而按 CG 的算子结构，剩余向量应由**前一步剩余**递推，即形如 $r^{(k)} = r^{(k-1)} - q_k z$（或按符号约定为 $r^{(k-1)} + q_k z$）：
   - 由 $r^{(k)} = Ax^{(k)} + b$ 与 $x^{(k)} = x^{(k-1)} + q_k p^{(k)}$ 可得
     $$r^{(k)} = (Ax^{(k-1)} + b) + q_k Ap^{(k)} = r^{(k-1)} + q_k z.$$
   这与源文写出的 $x^{(k-1)}$ 不符。
2. 若把 $x^{(k-1)}$ 视为 $r^{(k-1)}$ 的排印讹误，则该式自洽；若视为符号约定不同（例如定义 $r = -Ax - b$），则同页论文中 $r^{(0)} = Ax^{(0)} + b$ 的初值又与之矛盾。

## 影响

该式是算法块中唯一用于更新剩余向量的语句，若按其字面实现，CG 迭代将不产生正确的剩余序列，进而使 $e_{k-1}$、$q_k$ 两个标量与终止判据失效。

## 待核实

- 原书德文版／英文版对应位置的算式；
- 是否为 OCR 将 $r^{(k-1)}$ 误识为 $x^{(k-1)}$。
