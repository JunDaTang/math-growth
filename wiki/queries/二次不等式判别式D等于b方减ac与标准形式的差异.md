# 二次不等式判别式 D = b² − ac 与标准判别式的差异

## 问题

1.1.5 节例 4 讨论二次不等式

```latex
ax^{2} + 2bx + c \geqslant 0, \quad a > 0,\tag{1.17}
```

并定义 **所谓判别式** `D := b² − ac`，给出：

- D ≤ 0 时，任一实数 x 是解；
- D > 0 时，解集为 x ≤ (−b − √D)/a 或 x ≥ (−b + √D)/a。

而在 1.1.4 节例 3 中，二次方程写作 `x² + 2bx + c = 0`，其两根为 `x = −b ± √(b² − c)`（条件 b² − c > 0）。两处都采用「2b」这一线性项写法，因此判别式为 b² − ac 与 b² − c 是彼此一致的自洽约定，与常见的「b² − 4ac」只差写法上的规范化。

## 拟解决方式

确认手册是否在 0.1.11 或第 1 章其他位置统一采用「2b」系数约定；本 wiki 引用这两个公式时应同时给出原式 (1.15)、(1.17)，避免与标准写法混用。
