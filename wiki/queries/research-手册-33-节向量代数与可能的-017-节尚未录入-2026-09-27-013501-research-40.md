# Research: 手册 3.3 节（向量代数）与可能的 0.1.7 节尚未录入

# 手册 3.3 节「向量代数在解析几何学中的应用」概览与收录缺口

## 一、主题界定与收录现状

本次研究主题指向《[[数学指南-实用数学手册|数学指南——实用数学手册]]》中编号为 **3.3** 的一节，以及可能涉及的 **0.1.7** 节。根据手册目录 [13]，3.3 节的完整标题并非笼统的「向量代数」，而是 **「3.3 向量代数在解析几何学中的应用」**（第 770 页起），其下含三个子节：3.3.1 平面中的直线（771）、3.3.2 空间中的直线和平面（773）、3.3.3 体积（774）。因此，主题中「3.3 节（向量代数）」的括注需要精确化为「向量代数在解析几何学中的应用」。

关于 0.1.7 节的收录状态需要修正：wiki 中已经存在 [[10-数学指南实用数学手册--17-017-平面解析几何学中的基本公式--9kgone]]，即「0.1.7 平面解析几何学中的基本公式」；同时 0.1.8「空间解析几何学中的基本公式」也已录入为 [[10-数学指南实用数学手册--17-018-空间解析几何学中的基本公式--985n6a]]。因此真实的缺口是 **3.3 节的正文尚未录入**，而 0.1.7/0.1.8 是既有条目，二者构成「公式表」与「向量推导框架」的互补关系。

本文以 [1]–[15] 等来源为证据，重构 3.3 节的可能内容结构，并说明它与 0.1.7 的关系。

## 二、3.3 节在全书中的坐标

依据目录 [13]，3.3 节位于「几何学」大板块的末尾偏前位置，前后邻接关系如下：

- 3.2 大地测量学与几何基础（3.2.2 对大地测量学的应用 754；3.2.3 球面几何学 757；3.2.5 几何的希尔伯特公理 763；3.2.6 欧几里得平行公理 767；3.2.7 非欧椭圆几何学 767；3.2.8 非欧双曲几何学 768）
- **3.3 向量代数在解析几何学中的应用 770**
- 3.4 欧氏几何学（运动的几何学）775（3.4.2 圆锥截线 776；3.4.3 二次曲面 778）
- 3.5 射影几何学 782；3.6 微分几何学 790；3.7 平面曲线的例子 810；3.8 代数几何学 822

这一编排说明 3.3 节承担的是「用向量工具统一处理直线与平面解析几何」的桥梁功能：它上承几何公理与非欧几何的讨论，下启运动群、圆锥截线与二次曲面的分类。

向量代数的**基础理论**并不在 3.3 节，而在 **1.8 向量代数（372）**，其子节为 1.8.1 向量的线性组合、1.8.2 坐标系、1.8.3 向量的乘法 [13]；其后紧接 1.9 向量分析与物理学领域（377），含速度与加速度、梯度散度旋度、哈密顿算子、守恒律、高斯与斯托克斯积分定理、麦克斯韦方程等 [13]。另有一部同名的《实用数学手册》把「15.1 向量代数」列于第 565 页，属于「向量分析、张量分析」章 [12]。三处「向量代数」条目（1.8、3.3、15.1）定位各异，检索时应注意区分。

## 三、3.3.1 平面中的直线

坐标系下的平面直线部分，可用「点 + 方向向量」与「点 + 法向量」两种对偶描述组织 [5][2]。来源 [6][8] 给出了完整的公式序列：

- 两点间距离与中点坐标；
- 斜率、点斜式、斜截式 y = kx + b、两点式、截距式与一般式 Ax + By + C = 0（A、B 不同时为 0）；
- 平行与垂直的判定（斜率相等 / 斜率互为负倒数）；
- 两直线夹角与「到角」的区分，以及角平分线方程 [8]；
- 点到直线的距离公式 d = |Ax₀ + By₀ + C| / √(A² + B²)，以及由它导出的两平行线距离公式 [6][8]。

该公式的推导在历史教科书中至少有四条路径：交点法、原点距离法（坐标平移法）、法线式方程法以及等面积法 [7][10]。来源 [7] 系统比较了 20 世纪中叶前西方解析几何教科书中的这些处理方式，并指出「坐标平移法与直线法线式密不可分」——法线式中系数满足 cos²α + sin²α = 1，这正是把一般式 Ax + By + C = 0 乘以因子 R = ±1/√(A²+B²) 即可互化的原因 [7]。

这些结果与 wiki 已录入的 [[平面两点间距离公式]]、[[直线的斜截式方程]]、[[直线的一般方程]] 以及 [[平面笛卡儿坐标系]] 直接对应。

## 四、3.3.2 空间中的直线与平面

这是 3.3 节篇幅最大、也最可能被引用的一节。综合 [1][2][3][4][5]，其内容可重构为以下条目。

**（1）平面的方程。** 设平面过点 P₀(x₀, y₀, z₀)、法向量 n = (A, B, C)，则对平面上任意点 P 有 n · $\overrightarrow{P_0P}$ = 0，展开即点法式 A(x−x₀) + B(y−y₀) + C(z−z₀) = 0；令 D = −(Ax₀ + By₀ + Cz₀) 得一般式 Ax + By + Cz + D = 0 [1][3][5]。法向量可用平面内两不共线向量的叉积求得 [4]。

**（2）空间直线的三种方程。** 两个不平行平面的交线给出一一般方程（联立 a₁x + b₁y + c₁z + d₁ = 0 与 a₂x + b₂y + c₂z + d₂ = 0，要求两法向量不共线）；引入方向向量 r = (m, n, p) 与参数 λ 后得到参数方程 (x, y, z) = (x₀, y₀, z₀) + λ(m, n, p)；消去 λ 即得点向式（对称式、标准方程）(x − x₀)/m = (y − y₀)/n = (z − z₀)/p [1]。来源 [1] 特别指出分母含 0 的约定：当 m = 0 而 n、p 不为 0 时，该式应理解为 x = x₀ 与 (y − y₀)/n = (z − z₀)/p 的组合。

**（3）夹角公式。** 两直线夹角取其方向向量夹角或其补角，故 cos⟨l₁, l₂⟩ = |r₁ · r₂| / (|r₁||r₂|) [1][5]；直线与平面夹角 φ ∈ [0, π/2]，满足 sin⟨l, Π⟩ = |r · n| / (|r||n|) [1][5]。来源 [5] 同时给出垂直与平行的充要条件：直线与平面平行 ⟺ am + bn + cp = 0；垂直 ⟺ a/m = b/n = c/p [5]。

**（4）点到平面的距离。** d = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²) [1]，其形式是平面情形在三维的自然推广。

**（5）投影与平面束。** 来源 [1] 以例 11 演示「求直线在平面上的投影」：先构造过直线 l 且垂直于投影面 Π 的投影平面 Π₁，再与 Π 联立。为避免解两个方程组，可用**平面束方程** λ₁(a₁x + b₁y + c₁z + d₁) + λ₂(a₂x + b₂y + c₂z + d₂) = 0 表示一切过 l 的平面；[1] 提醒该束方程不包含第二个平面本身，须验证其不是所求平面。

**（6）立体几何定理。** 来源 [5] 还收录了三正弦定理 sin γ = sin α · sin β（二面角 α、线棱角 β、线面角 γ）与三余弦定理，可作为 3.3 节在处理二面角问题时的补充工具。

## 五、3.3.3 体积

按目录 [13]，3.3 节以「体积」收尾。其数学核心应是**混合积**（标量三重积）：|(a × b) · c| 给出以三向量为棱的平行六面体体积，等价于 3×3 行列式的绝对值。来源 [4] 完整给出叉积的行列式展开

a × b = (a₂b₃ − a₃b₂, a₃b₁ − a₁b₃, a₁b₂ − a₂b₁)

并给出右手定则的方向约定 [4]，这是体积公式的直接前置工具。需要指出：本次检索到的一手来源 [1]–[11] 均未直接给出 3.3.3 节「体积」的原文，该子节内容目前属于**推断重构**，与已录入的 [[立体图形的体积与表面积公式]]（对应手册 0.1.4 节）应属不同层次——后者是具体几何体的公式表，前者应是向量/行列式形式的一般理论。

## 六、前置理论：向量代数基础与叉积工具

3.3 节需要 1.8 节作为前置 [13]。教学化材料 [11] 按「什么是向量 → 坐标系 → 加减法 → 标量乘法 → 单位向量 → 内积 → 投影 → 范数」的顺序展开，并强调行向量与列向量是矩阵的特殊情形、转置即行列互换 [11]。工具书层面的定义 [14] 把「向量代数」概括为三块：向量空间的数学结构（线性独立与相依、基底与子空间）、向量运算（加法、纯量倍法、线性组合、纯量积、向量积）、以及矩阵代数（线性方程组、逆矩阵、特征向量、行列式）。这一三分法与 [13] 中 1.8.1–1.8.3 的编排高度吻合。

来源 [4] 从行列式的余子式与代数余子式出发，经拉普拉斯定理导出叉积坐标公式，再说明「平面内两不共线向量的叉积即平面法向量」，并给出中学—大学衔接的教学启示：构建「几何对象代数化—矩阵运算系统化—结果几何解释」的思维链 [4]。

## 七、与已录入 0.1.7 / 0.1.8 节的关系

0.1.7（[[10-数学指南实用数学手册--17-017-平面解析几何学中的基本公式--9kgone]]）与 0.1.8（[[10-数学指南实用数学手册--17-018-空间解析几何学中的基本公式--985n6a]]）在手册中属于第 0 章「初等数学中的基本公式」[13]，其形态是**结论式的公式清单**，已录入的对应概念页包括 [[平面笛卡儿坐标系]]、[[平面两点间距离公式]]、[[直线的斜截式方程]]、[[直线的一般方程]]、[[空间笛卡儿坐标系]]、[[三维两点间距离公式]]、[[空间直线的参数方程]]、[[平面的一般方程]]。

据此可以判断：**0.1.7/0.1.8 与 3.3 节不是重复，而是同一批几何对象在两种语言下的表述**——前者用坐标与公式罗列，后者用向量（方向向量、法向量、内积、叉积）统一推导。3.3 节的价值恰在于回答「0.1.7 中的公式从何而来」。类似的互补模式在手册其他处也能观察到，例如 [[平面图形面积与周长公式]] 与 [[海伦公式]] 的组合，以及 [[圆锥曲线]] 与 3.4.2「圆锥截线」[13] 的对应。

## 八、来源之间的差异、约定与潜在矛盾

1. **直线与平面夹角的两种表述。** [1] 写作 sin⟨l, Π⟩ = |π/2 − ⟨r, n⟩| 之后化简为 |cos⟨r, n⟩|；[5] 直接定义为直线与投影直线的夹角 φ ∈ [0, π/2]。两者等价，但 [1] 的中间写法依赖角度符号约定，容易误读。
2. **平行条件的除法陷阱。** [5] 用 m₁/m₂ = n₁/n₂ = p₁/p₂ 表示两直线平行，用 a/m = b/n = c/p 表示线面垂直；当分母为 0 时该写法失效，而 [1] 改用「不成比例」「共线」的向量语言回避了此问题。这是录入时需要标注的记法风险。
3. **平面束的完整性。** [1] 明确指出参数化的平面束方程 λ₁(·) + λ₂(·) = 0 漏掉其中一个平面，须单独检验。若后续条目只抄公式而未记此注，会导致投影求解的反例。
4. **直线夹角的方向性。** [8] 区分「到角」（有向、可叠加）与「夹角」（取较小角）；[1][5] 的 cos 公式均加了绝对值，只适用于夹角。涉及旋转与对称问题时须回到 [8] 的到角公式。
5. **法向量求法的层次差异。** [4] 用矩阵/行列式/拉普拉斯定理系统求解，属高等视角；[2] 的博客材料则以「直线与法向量叉乘求点到空间直线的法向量」等工程化描述出现，术语不够统一。二者指向同一运算，但严格性不同。

## 九、尚存缺口与建议补充的来源

- **手册 3.3 节原文**：目录 [13] 仅给出标题与页码（770–774），三个子节的正文、例题与记法尚未获得，是本次最关键的缺口。建议直接查找《数学指南——实用数学手册》中译本第 770–774 页。
- **手册 1.8 节原文**（372–377）：向量的线性组合、坐标系、向量的乘法三小节的确切记法，尤其是叉积与混合积的符号约定，需要原文核对。
- **《实用数学手册》15.1 向量代数**（565 页起）[12]：另一部工具书的平行条目，可用于交叉验证符号与公式编号。
- **3.3.3 体积的向量表述**：目前只能由 [4] 的叉积行列式间接推断，缺少混合积的直接引用。
- **3.4.3 二次曲面**[13]：与 3.3 的空间平面/直线理论属同一工具箱的延续，可能含 3.3 未展开的内容。
- **平面解析几何中「到角」与夹角公式的严格来源**：[8] 属 Wikibooks 教材类材料，权威性有限，宜以手册原文或传统教科书替换。

## 十、小结

综合现有证据，手册 3.3 节的定位可以概括为：**以 1.8 节的向量代数为基础，用方向向量、法向量、内积、叉积与混合积统一处理平面直线（3.3.1）、空间直线与平面（3.3.2）以及体积（3.3.3），从而为 0.1.7/0.1.8 的公式清单提供推导依据**。它既不是 0.1.7 的重复，也不是纯代数的向量公理体系；在 wiki 结构上，它应当作为连接 [[平面笛卡儿坐标系]] / [[空间笛卡儿坐标系]] 与 [[平面的一般方程]] / [[空间直线的参数方程]] 等条目的一层「统一理论」。当前的首要任务仍是补齐 3.3 节原文，以校正本节中属于推断的部分。
