# 更新既有页面以纳入 0.1.8 节

## 概述

本页记录将《数学指南——实用数学手册》0.1.8 节「空间解析几何学中的基本公式」的内容并入既有 wiki 页面的方案、依据与待办事项。0.1.8 属于第 0 章「公式、图和表」下 0.1「初等数学中的基本公式」的第三个几何类小节，紧接 0.1.7「平面解析几何学中的基本公式」之后，把视角从平面推向三维空间 [4][16]。

按中文版目录的页码标注，0.1.7 起于第 37 页，0.1.8 起于第 46 页，而 0.1.9「幂、根与对数」起于第 47 页 [4]。繁体版目录给出的边界一致 [16]。据此可以推断 0.1.8 在正文中篇幅很短（约一页），这一体量判断对"本节应当新增哪些页面"有直接影响，但属于目录推断，尚无原文佐证。

## 0.1.8 在手册中的位置与主题范围

- **层级归属**：第 0 章 → 0.1 初等数学中的基本公式 → 0.1.8 空间解析几何学中的基本公式 [4][16]。
- **前后承接**：上游是 0.1.7 平面解析几何，下游是 0.1.9 幂、根与对数，因此 0.1.8 是手册中"解析几何"这一小簇的收尾小节 [4][16]。
- **结构外部参照**：1987 年科学出版社《数学公式手册》把「空间解析几何」进一步细分为"各种坐标系／空间中的点和线段／空间中的平面／空间中的直线／二次曲面／x、y 和 z 的一般二次方程"六个子目 [17]。若 0.1.8 沿用相近的组织方式，其内部结构可据此预期。
- **概念背景**：解析几何在三维空间中，一个方程通常表示一个曲面，而空间曲线往往表示成两个曲面的交线或一条参数方程 [18]。这正是 0.1.8 必须同时给出"曲面／平面方程"与"直线方程"两条线索的原因。
- **方法来源**：维基百科条目指出，费马从代数公式出发去描述几何曲线，笛卡儿则从几何曲线出发以方程收尾，后者能处理更复杂的方程并发展到高次多项式 [18]。这一对比可作为 0.1.8 页面结语性质的背景说明。

### [[空间笛卡儿坐标系]]

现有页面仅以笛卡儿坐标为核心。0.1.8 若覆盖坐标系，应补充：

- 平面极坐标在三维中的两种推广——圆柱坐标系与球坐标系，这是三维空间最常见的另类坐标系 [18]；
- 坐标变换关系与适用场景（旋转对称问题用柱坐标、球对称问题用球坐标）；
- 与 [[三维两点间距离公式]] 的耦合：距离公式的坐标表达依赖坐标系选择。

### [[三维两点间距离公式]]

- 保持标准形式 d = √((x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²)，该式在中文公式集中以平面两点距离公式的形式给出，是其在三维的自然推广 [12]；维基百科亦将距离、角度等几何概念统一用公式表达，其中两点距离即勾股定理的坐标化 [18]。
- 补充向量表述 |**AB**| 及与数量积的关系 [19]。
- 明确与 0.1.7 平面两点距离公式的维数边界，避免跨节重复。

### [[空间直线的参数方程]]

这是 0.1.8 中信息量最大的概念页，建议扩写为"空间直线的三种等价表示"：

1. **参数式**：过点 M₀(x₀,y₀,z₀)、方向向量 **u**(X,Y,Z) 的直线可写作 x = x₀ + λX, y = y₀ + λY, z = z₀ + λZ [10][7]。
2. **点向式／对称式**：(x−x₀)/X = (y−y₀)/Y = (z−z₀)/Z [10]。
3. **一般式（两平面交线）**：由两个平面方程联立给出，且其方向向量等于两平面法向量的向量积 [10]。

另需补充：由两个平面方程取叉积求方向向量的具体算法 [10]；一个带数值的算例（方向向量 (−2,−12,8)、过点 (0,0,0.5) 后写出参数式）[7]；以及"空间一次方程表示平面而非直线"这一常见误解的澄清 [6]。

### [[平面的一般方程]]

- **点法式**：平面由过点 M₀ 且与法向量 **n** 垂直唯一确定，展开即得 A(x−x₀)+B(y−y₀)+C(z−z₀)=0 [10]。
- **一般式**：Ax+By+Cz+D=0，系数 (A,B,C) 即法方向 [10][7]。
- **截距式与参数式**：参数的展开形式可给出平面上的双参数表示 [10]。
- **平面束**：以直线 l 为轴的共轴平面系形如 λ(A₁x+B₁y+C₁z+D₁) + μ(A₂x+B₂y+C₂z+D₂) = 0，其中 λ²+μ²≠0 [7]。注意此处 λ、μ 与直线参数方程的 λ 符号冲突，需在页面上显式标注。

### [[初等几何公式]] 与 [[初等代数公式]]

这两个 0.1 节的合并参考页目前偏重平面与立体图形公式。建议：

- 在导航区加入指向 [[空间笛卡儿坐标系]]、[[平面的一般方程]]、[[空间直线的参数方程]]、[[三维两点间距离公式]] 的入口；

## 0.1.8 中尚无独立页面、建议新建的事项

依 [17][19][18] 对空间解析几何的通行切分，下列条目在现有 wiki 中缺失，且大概率属于 0.1.8 内容：

1. **向量代数**：数量积（内积，结果为数）、向量积（外积，结果为向量且交换变号）、混合积（几何意义与行列式性质，用于求异面直线距离）；两向量垂直 ⟺ 数量积为零，平行 ⟺ 向量积为零向量 [19]。
2. **点到平面的距离**：d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²) [12][19]。
3. **异面直线间的距离与公垂线**：需以混合积与投影表述 [10][19]。
4. **直线与直线的位置关系判定**：共面（平行、相交、重合）或异面，共面判据可用混合积为零 [7][10]。
5. **直线与平面的位置关系判定**：l ∥ Π ⟺ AX+BY+CZ=0；l ⊂ Π ⟺ 该式与 Ax₀+By₀+Cz₀+D=0 同时成立；相交 ⟺ 三阶行列式非零 [7][10]；另有以线性方程组解数表述的等价判据 [7]。
6. **线线、线面、面面夹角公式** [19]。
7. **二次曲面**：椭球面、双曲面、抛物面等的标准方程，以及 x、y、z 的一般二次方程 [17][19]。
8. **曲面方程与空间曲线方程**：交线、投影曲线与旋转曲面 [18][19]。

## 交叉校验与矛盾点

- **维数混淆是本组页面的最大风险**。0.1.7 与 0.1.8 共用"两点距离""直线方程"等标题，但语义不同：形如 ax+by+c=0 的二元一次方程在三维空间中表示一个平面，例如 x−y=0 即为一平面 [6]。所有从 0.1.7 复用到 0.1.8 的条目都须显式标注维数。
- **符号冲突**：[[空间直线的参数方程]] 采用 λ 作参数（与来源 [7] 一致），而共轴平面束同样使用 λ、μ [7]。建议在跨页面的记法约定中统一或加注，可参考既有疑问页 [[立体图形公式表中的记法疑问]] 的处理方式。
- **篇幅与内容的矛盾**：目录显示 0.1.8 仅占约一页 [4][16]，而 [17][19] 所列举的空间解析几何条目（向量代数、二次曲面、一般二次方程、夹角与距离）足以写满数十页。这意味着 0.1.8 很可能只是高度浓缩的公式表，新增页面数量应保守估计，"二次曲面是否入选"须以原文为准。
- **替代来源不足以覆盖**：通用公式集 [12][13] 基本只覆盖平面解析几何与少量立体几何，无法替代 0.1.8 原文；[14] 虽提及解析几何章节，但无具体条目可供核对。
