# 1.14.12 节例 2 中「Ω = C − {0}」的 C 是否应为黑板体 ℂ？

## 问题

1.14.12 节例 2 写作

> 令 $\Omega = C - \{0\}$

其中 $C$ 未使用黑板体 $\mathbb{C}$。而本节开头明确写的是"$\mathbb{R}^2$ 等同于复平面 $\mathbb{C}$"，且例 3 中亦有

> 令 $\Omega := \{z \in C : |z| < 1\}$

同样使用普通 $C$。

## 判断

从上下文看，这里的 $C$ 显然指复平面 $\mathbb{C}$，属于排版/转写层面的不一致（本 wiki 的其他节中同类情形见 [[11410节全纯变换原理中C应为黑板体C]]）。
