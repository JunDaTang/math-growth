# 0.4 节统计软件推荐的时效性

## 问题

《数学指南——实用数学手册》0.4 节导言给出的软件推荐，在当代是否仍然成立？

原文该句为：

> 计算机上的数理统计 许多初等的标准过程都可以通过 Mathematica 实现。今天普遍使用的更专业的统计包是 SPSS 和 SAS。

## 争议点

1. **「今天普遍使用」的时效断层**：把 [[spss]] 与 [[sas]] 并列为「今天普遍使用的更专业的统计包」，是典型的 1990s—2000s 表述。在 R 与 Python 生态（pandas、scipy、statsmodels 等）成为主流的当代语境下，该判断已明显过时。
2. **[[mathematica]] 的定位**：来源只称其可实现「许多初等的标准过程」，既未给出能力上限，也未与现代统计环境作对比。
3. **推荐依据缺失**：全句无版本号、无具体函数、无对比数据，属未加论证的分类。

## 与已有 query 的关系

本问题与 [[03节软件推荐的时代适用性]] **同构**：手册在 0.3 节与 0.4 节都把软件生态固化在成书年代。二者可合并为「手册软件观的时代错位」这一主题，亦可各自独立追踪。
