## 420 与 438 两处引用的性质

研究主题只给出两个数字，未说明它们是**书页页码**还是**参考文献编号**。两种读法都需保留：

2. **若为文献编号：** 则须比照 [[113节文献212未核实]] 的处理方式，登记为「编号 420、438 的条目出处未核实」。

无论取哪一种读法，结论相同：**这两节在手册内部是被实际使用的交叉引用目标，缺少它们的正文会使当下的 wiki 无法追溯引用链。**

## 0.5.5 的内容重建：积分指数函数

0.5.5 标题把「积分三角函数」与「积分指数函数」并列。外部来源只覆盖了后者，以下逐项重建。

### 指数积分 Ei(x)

标准定义为取主值的积分 [2][3]：

Ei(x) = −∫_{−x}^{∞} e^{−t}/t dt = ∫_{−∞}^{x} e^{t}/t dt，x > 0

对 x > 0，该积分按 **柯西主值（Cauchy principal value）** 解释 [1][2][3]。注意 Ei(−x) 可由解析延拓与 −E₁(x) 相联系 [2]。

- 与对数积分的关系：li(e^x) = Ei(x)，对非零实数 x 成立 [3][7]。
- 与广义超几何函数的关系：Ei(x) = x·₂F₂(1,1; 2,2; x) + ln x + γ [3]。
- 借助整函数 Ein 的更简洁写法：Ei(x) = γ + ln x − Ein(−x)，x ≠ 0 [3]。

### 广义指数积分 Eₙ(x)

Eₙ(x) = ∫₁^{∞} e^{−xt}/tⁿ dt，x > 0，n = 0, 1, … [2][3]

它是**上不完全 Γ 函数**的特例：

Eₙ(x) = x^{n−1} Γ(1 − n, x) [2][3]

数值软件（如 PTC Mathcad 的符号函数）采用另一种记法 Ei(n, x)，对任意整数 n 用递推关系定义，n = 1 时退化为与欧拉常数 γ 相关的表达式，且对实数 x 有 Ei(x) 与 Ei(n, x) 的换算关系 [1]。**记法冲突值得注意：** 手册式记法 Eₙ(x) 与软件记法 Ei(n, x) 不可混用 [1][2]。

### 整函数 Ein

Ein(z) = ∫₀^{z} (1 − e^{−t}) dt/t = Σ_{k=1}^{∞} (−1)^{k+1} z^{k}/(k·k!) [3]

由此得到 E₁ 与 Ei 的统一表达 [3]：

- E₁(z) = −γ − ln z + Ein(z)，|Arg z| < π
- Ei(x) = +γ + ln x − Ein(−x)，x ≠ 0

### 对数积分 li(x) 与偏移对数积分 Li(x)

li(x) = ∫₀^{x} dt/ln t，x > 1 时按下述柯西主值理解 [7][9][10]：

li(x) = lim_{ε→0+} ( ∫₀^{1−ε} dt/ln t + ∫_{1+ε}^{x} dt/ln t )

被积函数 1/ln t 在 t = 1 处有奇点 [7][9]。实用的无奇点变体是偏移形式 Li(x) = ∫₂^{x} dt/ln t = li(x) − li(2) [8][10]。

数论意义：**素数定理**给出 π(x) ∼ Li(x)（x → ∞），即对数积分是素数计数函数的最佳简单近似 [7][10]。存在唯一正数（Soldner 常数，OEIS A070769）使 li(x) = 0，因此 li 也可写成以该常数为下限的积分 [9]。

### 级数展开、渐近展开与数值计算

小 x 用幂级数（收敛），大 x 用渐近级数（发散但高精度）[2][4]：

- Ei(x) = γ + ln x + x/(1·1!) + x²/(2·2!) + … [2]
- li(e^u) = Ei(u) = γ + ln|u| + Σ_{n≥1} uⁿ/(n·n!)，u ≠ 0 [7]
- Ei(x) ∼ (e^x/x)·(1 + 1!/x + 2!/x² + …) [2]
- li(x) ∼ (x/ln x)·Σ_{k≥0} k!/(ln x)^k，并且 li(x) − x/ln x = O(x/(ln x)²) [7]

数值实现要点（来自 [2] 的算法描述）：幂级数与渐近级数的切换阈值约为 |ln EPS|，其中 EPS 为要求的相对误差；在 Ei 的零点 x ≈ 0.3725 附近改用绝对误差判据；欧拉常数取 γ ≈ 0.57721566 [2]。渐近展开只在截断有限项且 x 较大时才是有意义的近似 [7]。

### 仍未获得来源的部分：积分三角函数

0.5.5 标题中的**积分正弦 Si(x)、积分余弦 Ci(x)**（以及双曲变体 Shi、Chi）在本次检索到的全部来源中没有出现。这三者的定义式、级数展开、渐近行为与在手册表中的列表值，仍属于**来源空缺**。同样，0.5.5 位于 0.5.4 椭圆积分、0.5.6 菲涅耳积分与 0.5.7 ∫e^(−t²)dt 之间，菲涅耳积分与误差函数在结构上同属「振荡型特殊函数」，三者共享渐近展开技术，但本次来源未覆盖 [11]。

## 0.7.2 的内容重建：幂级数

**完全空缺。** 本次提供的来源全部围绕特殊函数（指数积分、对数积分），没有任何一条涉及幂级数的收敛半径、逐项运算、代入与反演、部分分式展开、或与 0.7.3 渐近级数的分界 [1]–[10]。

从目录只能确认两点 [11]：
1. 0.7.2 位于 **0.7.1 特殊级数**（p. 133）与 **0.7.3 渐近级数**（p. 146）之间，跨约 10 页，体量不小；
2. 0.7 系列以 0.7.4 傅里叶级数（p. 149）、0.7.5 无穷乘积（p. 154）收尾，整体是一套「展开工具箱」。

也就是说，0.7.2 很可能包含常用初等函数的幂级数表（这是「手册」体裁的典型内容），但**这一猜测没有来源支持**，不应写入任何条目正文。

## 矛盾、缺口与待核实清单

1. **「420、438」的性质未定**——页码还是文献编号，直接决定核查路径。
2. **0.5.5 页码不一致**——[11] 为 128，[15] 未列出；两份目录整体相差约 23 页 [11][15]。
3. **0.5.5 的一半内容无来源**——积分三角函数 Si(x)、Ci(x)（及 Shi、Chi）的定义与表值完全空缺。
4. **0.7.2 全节无来源**——幂级数小节共约 10 页，现有来源未触及。
5. **记法冲突未消解**——手册式 Eₙ(x) 与软件式 Ei(n, x) 的对应关系只得到部分说明 [1][2][3]。
6. **中译本与德文/英译本差异**——译者序明确指出英译本纠正了德文原版的错误，同时又引入新的错误，中译以两版参校完成 [13]；因此 0.5.5、0.7.2 的公式若入库，应注明取自哪一版本。
7. **书籍元数据小分歧**——全书页数 1303 [12] 与 1332 [15] 不一致。
