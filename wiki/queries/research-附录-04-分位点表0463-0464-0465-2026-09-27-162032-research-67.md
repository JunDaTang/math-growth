# 附录 0.4 分位点表（0.4.6.3 / 0.4.6.4 / 0.4.6.5）

## 概述与在手册中的位置

本页讨论《[[数学指南-实用数学手册]]》附录 0.4 中三张连续分布分位点表的结构、读法与相互关系：

- **0.4.6.3** —— [[t分布|Student *t* 分布]]分位点表（又称 t 表、临界值表）；
- **0.4.6.4** —— [[卡方分布|χ² 分布]]分位点表；
- **0.4.6.5** —— [[F分布|*F* 分布]]分位点表。

三者属于同一"尾部概率—临界值"族谱：给定[[自由度]] ν 与显著性水平 α，查表得到使 `P(T > t) = α` 的临界值 t。这组表是第 6.3 节[[数理统计]]各程序（[[正态分布期望的置信区间]]、[[正态分布标准差的置信区间]]、[[t检验]]、[[F检验]]、[[相关检验]]）在无法直接计算时的查表依据，在功能上与附录中正态分布的 [[正态分布置信区间的z-alpha分位点]] 表（对应 0.4.6.1 或 0.4.6.2 档位）互补。

> **证据边界说明**：现有研究来源[[1]–[15]](均为公开的高校讲义、NIST 数字表格与 Wikipedia 条目)**并未包含手册附录 0.4 的实际扫描内容**。因此本页给出的是"该三张表在标准文献中的通行结构与取值"，而非对原书页面的转录。凡涉及具体数字，均以公开表为准并标注来源。

## 0.4.6.3 Student *t* 分布分位点表

### 表结构

*t* 表为一个二维网格：行为[[自由度]] ν（表头常写作 `df`），列为累积概率或尾部概率。列头有两种常见的等价写法：

| 写法 | 示例列头 | 含义 |
|---|---|---|
| 单尾 / 双尾并列 | `0.05 / 0.10`、`0.025 / 0.05`、`0.005 / 0.01` | 同一临界值可同时服务于单侧与双侧检验 |
| 上尾概率 Pr(T > t) | `0.1`、`0.05`、`0.025`、`0.01`、`0.005` | 直接给出右尾面积 |

来源 [1] 采用第一种写法，列出累积概率 `0.50 / 0.25 / 0.20 / 0.15 / 0.10 / 0.05 / 0.025 / 0.01 / 0.005 / 0.001 / 0.0005`（单尾）与 `1.00 / 0.50 / 0.40 / 0.30 / 0.20 / 0.10 / 0.05 / 0.02 / 0.01 / 0.002 / 0.001`（双尾）；来源 [3] 采用第二种写法，列为 `0.2 / 0.1 / 0.05 / 0.04 / 0.03 / 0.025 / 0.02 / 0.01 / 0.005 / 0.0005`，标题明示为 **Upper Tail Probability: Pr(T > t)**。

### 代表值（用于校核与直觉）

以常见的 95% 双侧分位点 `t_{0.975}`、90% 单侧分位点 `t_{0.95}` 为例（来源 [1][3]）：

| ν (df) | t₀.₉₅ | t₀.₉₇₅ | t₀.₉₉₅ |
|---|---|---|---|
| 1 | 6.314 | 12.706 | 63.657 |
| 5 | 2.015 | 2.571 | 4.032 |
| 10 | 1.812 | 2.228 | 3.169 |
| 11 | 1.796 | 2.201 | 3.106 |
| 14 | 1.761 | 2.145 | 2.977 |
| 16 | 1.746 | 2.120 | 2.921 |
| ∞（近似） | 1.645 | 1.960 | 2.576 |

要点：

1. **ν = 1 时 t 分布即柯西分布**，方差不存在（来源 [2] 给出方差为 `ν/(ν−2)`，仅当 ν > 2 时有限；超峰度为 `6/(ν−4)`，仅当 ν > 4 时有限）。
2. ν 增大时各列单调下降并趋向正态分位点；ν ≈ 30 以上时与 [[正态分布置信区间的z-alpha分位点]] 的差别已在第二位小数。
3. 表通常按 ν = 1…30 逐行列出，再补 40、60、120、∞ 等大自由度行（来源 [3] 给出 1、5–17 等采样行，其余档位在完整表中连续）。

### 读表约定

- **单侧检验**（如 "X > μ"）：α 直接取单尾列。
- **双侧检验**：α 取双尾列（等价于单尾 α/2 列）。这正是 [[t检验]] 中对两均值比较时常用的形态。
- 分布关于 0 对称，故只列右半轴，左尾临界值取负号即可。

## 0.4.6.4 χ² 分布分位点表

### 表结构

χ² 表同样以[[自由度]] ν 为行，列为右尾概率。由于 χ² 分布非对称，**必须同时给出上、下两侧**才能在置信区间构造中使用，故该表往往把低概率列（0.995、0.975、0.95、0.90 等）与高概率列（0.10、0.05、0.025、0.01、0.005）并排摆放。

来源 [6] 的列可解读为：

```
0.999  0.995  0.975  0.95  0.90 | 0.10  0.05  0.025  0.01  0.005
```

来源 [10] 采用更细的列集：`0.995, 0.975, 0.2, 0.1, 0.05, 0.025, 0.02, 0.01, 0.005, 0.002, 0.001`。来源 [9] 明确标注其表为分位点表 `Q(.005) Q(.01) Q(.025) …`。

### 代表值

| ν | χ²₀.₉₇₅ | χ²₀.₀₅ | χ²₀.₀₂₅ | χ²₀.₀₅ 对照 |
|---|---|---|---|---|
| 1 | 0.001 | 3.841 | 5.024 | 6.635 (0.01) |
| 10 | 3.247 | 18.307 | 20.483 | — |
| 14 | 5.629 | 23.685 | 26.119 | 29.141 (0.01) |
| 20 | 9.591 | 31.410 | 34.170 | — |
| 30 | 16.791 | 43.773 | 46.979 | 50.892 (0.01) |
| 100 | 74.222 | 124.342 | 129.561 | 135.807 (0.01) |

（数据来源 [6][10]；两来源在 ν = 14、15、16、20、30、100 等行逐值一致。）

### 理论背景（可与表对照）

来源 [8] 指出 χ² 分布是伽马分布的特例：

`X ∼ χ²_k` ⟺ `X ∼ Gamma(α = k/2, θ = 2)`，

并给出尺度化形式 `X ∼ s²χ²_k` ⟺ `X ∼ Gamma(α = k/2, θ = 2s²)`，以及与 Wishart 分布 `W₁(s², k)` 的联系。这解释了为何 χ² 分位点与 [[伽马函数]] 密切相关，也解释了自由度 k 在表中作为形状参数的唯一索引作用。

来源 [7]（NIST）说明该表的典型用法：以 α = 0.05 为例，在给定 ν 下查得右尾面积 0.05 对应的临界值，即可用于假设检验与区间估计。χ² 表在手册中服务于 [[正态分布标准差的置信区间]] 与 [[卡方分布]] 相关检验。

## 0.4.6.5 *F* 分布分位点表

### 表结构

*F* 分布由**分子自由度**（d.f.N.）与**分母自由度**（d.f.D.）两个参数决定（来源 [11][14] 均强调这一点，并常以 F(3,2) 记法表示）。因此该表不能像 t、χ² 那样只用一张二维表覆盖全部信息，标准做法是：

- **每个显著性水平 α 一张表**（如 α = 0.005、0.01、0.025、0.05、0.10，来源 [11]；或 α = 0.95/0.99，来源 [13]）；
- 表内行 = 分母自由度 d.f.D.，列 = 分子自由度 d.f.N.（通常取 1, 2, 3, …, 10, 12, 15, 20, 24, 30, 40, 60, 120, ∞）。

来源 [11] 在一份 PDF 中顺序给出 α = 0.005 / 0.01 / 0.025 / 0.05 / 0.10 五张单侧上尾表；来源 [12] 单独给出 α = 0.05 表；来源 [13] 给出 α = 0.05 与 α = 0.01 两张表，并附计算器。

### 代表值（α = 0.05，上尾）

| d.f.D. \ d.f.N. | 1 | 2 | 5 | 10 |
|---|---|---|---|---|
| 1 | 161.4 | 199.5 | 230.2 | 241.9 |
| 5 | 6.608 | 5.786 | 5.050 | 4.735 |
| 10 | 4.965 | 4.103 | 3.326 | 2.978 |
| 15 | 4.543 | 3.682 | 2.901 | 2.544 |

（来源 [11][12][13] 三处数值一致。）

α = 0.01 时例如 F₀.₀₁(1,1) = 4052、F₀.₀₁(3,5) = 12.06、F₀.₀₁(10,10) ≈ 4.85（来源 [11][13]）。

### 使用要点

- **两侧性**：*F* 表通常只列上尾（即较大方差比一侧）。下尾临界值通过倒数恒等式获得：
  `F_{1−α}(ν₁, ν₂) = 1 / F_α(ν₂, ν₁)`
  例如 `F_{0.95}(1,1) = 1/161.4 ≈ 0.0062`。
- 与 [[F检验]]（方差比检验）的关系：F = (s₁²/s₂²)，分子自由度对应较大方差组的样本量减一。
- 与 χ² 的关系：若 U ∼ χ²_{ν₁}、V ∼ χ²_{ν₂} 独立，则 `(U/ν₁)/(V/ν₂) ∼ F(ν₁, ν₂)`。
- 与 t 的关系（ν₁ = 1 的退化情形）：`F(1, ν) = t_ν²`。校核：`t_{0.975,10} = 2.228`，平方为 4.964，与表中 `F_{0.05}(1,10) = 4.965` 一致（来源 [12][13] 对 [1][3]）。

## 三张表之间的谱系关系

```
正态 z（附录 0.4.6.1/0.4.6.2）
   │  ν → ∞
   ▼
Student t（0.4.6.3）  ── 平方 ──►  F(1, ν)（0.4.6.5）
   │                                   ▲
   │  高斯化                            │ 两独立 χ² 之比
   ▼                                   │
χ²（0.4.6.4）──────────────────────────┘
   │  χ²_k = Gamma(k/2, 2)
   ▼
伽马分布 / 正态方差估计
```

这条谱系解释了手册为何把三张表相邻编排：**6.3 节的所有检验与区间估计，本质上只需在这四类分位点（z、t、χ²、F）之间切换**。[[费希尔]] 的工作把 *F* 分布引入方差分析，使 0.4.6.5 成为 [[F检验]] 与方差分析（参见 [[方差分析]]、[[因子]]）的必备附表。

## 常见陷阱与勘误

### 表格层面的矛盾与疑似 OCR 错误

1. **来源 [6] 的 χ² 表行标签重复且错乱**：同一数字（如 "2"、"4"、"6"、"8"、"12"、"14"）在行首出现两次，而实际代表的是连续的 df = 2, 3 / 4, 5 / 6, 7 …。行首标签不可直接信任，应结合数值判断。例如行首标 "2" 的第三行数值 `0.072, 0.115, 0.216, 0.352, 0.584, 6.251, 7.815, …` 实为 **df = 3**（因 χ²₀.₀₅,₃ = 7.815）。

2. **来源 [6] df = 16 行存在明显笔误**：该行写出 `6.098`（应为 `6.908`）与 `33.542`（应为 `23.542`）。可对照来源 [10] 的 df = 16 行 `5.142, 6.908, …, 23.542, …, 26.296, …` 予以纠正。

3. **来源 [11] α = 0.005 表 df = 8 行疑有错位**：该行 `6.43 | 7.42 | 6.18 | 6.06 | 5.95` 中，6.43 对应 d.f.N. = 30，其后 7.42 应落在 d.f.N. = 40 的位置，但明显大于前一值，破坏了 *F* 值随分母自由度增大而单调递减的规律（40 处应为 ≈ 6.29 量级）。此处需以其他权威表复核。

### 记号与约定差异

- **单尾 vs 双尾**：t 表若只看列头易混淆。来源 [1] 用 "one-tail / two-tails" 并列，来源 [3] 仅给上尾。**同一检验在两种表下的查表列号可能相差一倍**。
- **累积分位点 vs 上尾概率**：χ² 表在来源 [6] 中间接地隐含了 0.999、0.995 等低尾列，但列头在转录中丢失，需依据数值反推（见上文解读）。
- **α 的语义在 F 表中易反转**：来源 [13] 的表标题写作 "F-distribution 0.95 (a=0.05)"，即以 0.95 累积概率命名，对应上尾 α = 0.05。阅读时必须确认所指是累积概率还是上尾面积。

## 空白与建议补充的资料

1. **原书附录的实际排版**：目前所有来源均为外部通用表，**缺少 0.4.6.3 / 0.4.6.4 / 0.4.6.5 的原始扫描或转录**，因此本页无法确认手册采用的列集合（例如 χ² 是否含 0.001 列、F 表是否含 α = 0.005）与精确的有效位数。
2. **0.4.6.1 / 0.4.6.2 的确认**：附录 0.4 的分位点表族应含正态与可能的二项/泊松表，需查明其编号，方能与 [[正态分布置信区间的z-alpha分位点]] 完整对应。
3. **数值精度与舍入规则**：不同来源在大自由度行的末位上有差异（如 F 表 α = 0.05 中 d.f.N.=2、d.f.D.=2 处出现 19.000 与 19.000 的写法差异，参见 [11] 与 [13]），需要手册原文以确定统一舍入位数。
4. **计算器与算法**：来源 [5] 提供在线 *t* 分位点计算器，来源 [14] 提供 F 表配套计算器。若要替代静态表，应补充分位点函数的数值算法说明（例如 β 函数反演、Newton 迭代）。
5. **与 6.3 节具体程序的勾连**：建议为 [[t检验]]、[[F检验]]、[[相关检验]]、[[正态分布标准差的置信区间]] 各自补一份"该程序用到哪张附表、查哪一列"的交叉索引。
