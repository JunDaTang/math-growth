# 1.14.10 节全纯变换原理中「V ⊆ C → C」的 C 应为黑板体 C？

## 问题

全纯变换原理的断言 (i) 在原文中写作「$f_{*}: V \subseteq C \to C$ 是全纯的」。按上下文，此处 $C$ 应为复平面 $\mathbb{C}$（黑板体），而非曲线名 $C$。

## 背景

同一节内 $C$ 同时被用作：复平面（应为 $\mathbb{C}$）、$U$ 中的 $C^{1}$ 曲线 $C$、以及变换后的曲线 $C_{*} := b(C)$。字面符号完全同形，仅在字体（黑板体/斜体）上有区别，转录时易丢失。

## 待解决

- 原文此处是否确为黑板体 $\mathbb{C}$？
- 是否需要在 wiki 页面中统一采用 $\mathbb{C}$（复平面）与 $C$（曲线）的记号约定，以避免下游引用出错？
