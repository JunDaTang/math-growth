# 3.2.5 节次序公理与射线的定义表述是否可疑？

## 问题一：次序公理 (ii)

源文次序公理第 (ii) 条为：

> 对每两个不同的点 A 和 C, 存在一点 B 位于 C 和 A 之间.

按希尔伯特原始公理（II, 2），该条应断言「直线 AC 上至少存在一点 B 位于 A 与 C 之间」，即点 B 必须落在 A 与 C 的**线段内部**。源文的「存在一点 B 位于 C 和 A 之间」在字面上与通行表述一致（「B 在 C 和 A 之间」即 B 在 C 与 A 之间），故此处可能并不构成讹误，但**「位于 C 和 A 之间」的措辞在源文中与 (i) 条的「位于 A 和 C 之间」顺序相反**，需核对原文是否为刻意的次序对称表述。

## 问题二：线段定义中的端点归属

源文线段定义：「线段 $AB$ 是 $l$ 上所有位于 A 和 B 之间的点的集合. 点 A 和 B 在此情形也被计算在内.」此句明确线段**含端点**，与某些教科书把线段定义成开集的习惯不同。此非讹误，但值得记录。

## 问题三：射线的定义依赖未定义的前置关系

源文射线定义之前在一条直线上取四个点 A, B, C, D，其中「C 在 A 和 D 之间但不在 A 与 B 之间」。该表述要求读者已经理解「同一边 / 不同边」，但同一边的概念本身正是在此定义中才被引入，存在**循环叙述**的观感（实际由次序公理保证一致性）。

## 问题四：分解定理中的记号

分解定理正文写作「所有点或是在直线 $l$ 上或是在两个集合 **A 和 B** 之一」，但随后用小写花体的 $\mathcal{A}$ 与 $\mathcal{B}$。源文（含图像 OCR）在此处大小写／字体不统一。

## 待确认

上述各处是否为源书原貌、OCR 讹误，抑或中文译本的用语选择。
