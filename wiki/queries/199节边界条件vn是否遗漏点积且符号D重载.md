# 1.9.9 节边界条件 `v n = g` 是否遗漏点积，以及符号 D 的重载

## 疑点一：边界条件缺漏点积号

问题 (1.173) 的第二式在已转录文本中写作 `v n = g`；按上下文（$g$ 为标量、$n$ 为外法线单位向量）应为 $v\cdot n = g$。同类缺漏在本手册 1.9.2 与 1.9.8 节亦曾出现（方向导数、斯托克斯公式的转录中同样缺少点积号），可能是 OCR 或排版问题。

## 疑点二：符号 $D$ 的两重身份

本节的 $D$ 至少承担两种含义：

1. 函数 $\rho : D \to \mathbb{R}$ 的定义域，即区域 $D$；
2. 「源的规定」中满足 $\operatorname{div} D = \rho$ 的向量场 $D$。

同一节内区域与向量场共用大写 $D$，易致混淆（例如「$\operatorname{div} D = \rho$，在 $D$ 上」一句中两个 $D$ 指代不同对象）。需核对原文是否使用不同字体（粗体 vs 斜体）区分。
