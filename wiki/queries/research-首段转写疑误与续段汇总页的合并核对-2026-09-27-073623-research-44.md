# Research: 首段转写疑误与续段汇总页的合并核对

# 积分表（不定积分公式汇总）

本页汇总并核对多份「积分表」类资料，内容涵盖不定积分基本公式、常用变形公式、使用积分表时的常见错误，以及不同来源之间的转写差异。此页同时回应研究主题「首段转写疑误与续段汇总页的合并核对」，即对若干来源（尤其是自动抓取与 OCR 转写文本）中的疑似错字、漏项与排版残缺进行比对。

## 定义与用途

积分表（integral table）是数学与微积分学科中用于辅助积分计算的工具型数学用表，其用途在于汇总常用积分公式并按被积函数类型进行排列 [6]。维基百科条目同样以「按被积函数类型（有理式、根式、三角、指数、对数等）分类」的方式组织公式 [7]。

从实用角度看，积分表本质上是**模式识别工具**：当被积函数本身已是标准形式（如 $x^n$、$\frac{1}{x}$、$e^x$、基本三角函数）时可直接查表；若不符标准形式，积分表也能提示该题可能需改用 $u$-代换或分部积分法 [2]。任何有限的积分表都不可能涵盖所有积分，「完整积分表」通常指学生最常用的标准公式，加上判断某题是否适合直接查表的能力 [2]。

《数学指南——实用数学手册》将积分表作为独立工具章节列出，包含**不定积分表**、**定积分表**与**积分变换表**（其中含傅里叶变换等）[4]；这说明积分表在综合性数学手册中是与 [[傅里叶通用方法]] 等工具并列的查阅型内容。

## 基本积分表

多份来源给出的核心条目高度一致，可归纳如下（$C$ 为积分常数）[2][3][9]：

- 幂函数公式：$\displaystyle \int x^n\,dx = \frac{x^{n+1}}{n+1} + C$，条件 $n \neq -1$ [2][3]。
- 对数型：$\displaystyle \int \frac{1}{x}\,dx = \ln|x| + C$ [2][3][9]。
- 自然指数：$\displaystyle \int e^x\,dx = e^x + C$ [3][9]。
- 一般指数：$\displaystyle \int a^x\,dx = \frac{a^x}{\ln a} + C$（$a>0,\ a\neq 1$）[2][3]。
- 正弦：$\displaystyle \int \sin x\,dx = -\cos x + C$ [3][9]。
- 余弦：$\displaystyle \int \cos x\,dx = \sin x + C$ [3][9]。
- 正割平方：$\displaystyle \int \sec^2 x\,dx = \tan x + C$ [9]。
- 余割平方：$\displaystyle \int \csc^2 x\,dx = -\cot x + C$ [9]。
- 反正切型：$\displaystyle \int \frac{dx}{1+x^2} = \arctan x + C$ [9]。
- 反正弦型：$\displaystyle \int \frac{dx}{\sqrt{1-x^2}} = \arcsin x + C$ [9]。

线性性质与单个公式同等重要：

$$\int \big(af(x)+bg(x)\big)\,dx = a\int f(x)\,dx + b\int g(x)\,dx$$

即可以把和拆开、把常数提到积分号外，但一般情况下**不允许把乘积拆开** [2]。

## 幂函数公式的例外：$\frac{1}{x}$

来源普遍强调 $x^{-1}$ 是对数型而非普通幂函数：不能对 $\frac{1}{x}$ 套用幂函数公式，因为那会使分母 $n+1$ 变为 $0$ [2][3]。来源 [2] 把「对 $\frac{1}{x}$ 使用幂函数公式」列为使用积分表时的典型错误之一。

## 含 $ax+b$ 与二次式的公式

基本公式常以内部含 $ax$ 或 $ax+b$ 的形式再次出现；当 $a\neq 0$ 时可作为直接结果 [2]。对于含 $R=\sqrt{ax^2+bx+c}$ 的积分，维基百科给出递推与对数/反三角形式，例如 [7]：

- $\displaystyle \int \frac{dx}{R} = \frac{1}{\sqrt{a}}\ln\big(2\sqrt{a}\,R + 2ax + b\big)$（$a>0$）；
- $\displaystyle \int \frac{dx}{R} = -\frac{1}{\sqrt{-a}}\arcsin\frac{2ax+b}{\sqrt{b^2-4ac}}$（$a<0$ 等条件下）；
- $\displaystyle \int \frac{dx}{\sqrt{a^2+x^2}} = \ln\big(x+\sqrt{a^2+x^2}\big) + C$。

来源 [5]（「新不定积分表」）进一步给出高阶递推式，如 $\int \sin^n x\,dx$、$\int \csc^n x\,dx$、$\int \sec^n x\,dx$、$\int \frac{\sin^m x}{\cos^n x}\,dx$ 等按 $m,n$ 奇偶性分情形展开的公式，以及形如 $\int \frac{dx}{a+b\sin x}$、$\int \frac{dx}{a+b\cos x}$ 的结果 [5]。

## 使用积分表的常见错误与检验方法

来源 [2] 明确列出四类常见错误：

1. **对错了模式**——如 $xe^x$ 这类乘积或 $\cos(x^2)$ 这类复合函数通常不能只靠直接查表。
2. **忘记缩放因子**——例如 $\int \cos(2x)\,dx = \frac{1}{2}\sin(2x)+C$，而非 $\sin(2x)+C$。
3. **对 $\frac{1}{x}$ 使用幂函数公式**——此类为对数型。
4. **漏掉 $+C$**——不定积分表示的是一族原函数。

最快的检验方法是**求导回代**：把结果求导应回到原被积函数 [2]。例如
$$\frac{d}{dx}\Big(x^3 - 4\ln|x+1| + \frac{5}{2}\sin(2x)\Big) = 3x^2 - \frac{4}{x+1} + 5\cos(2x)$$
求导后回到被积函数，故原函数正确；该结论在 $x\neq -1$ 的区间上成立，因为原被积函数在 $x=-1$ 处无定义 [2]。来源 [9] 亦以 $\int \sec x\,dx$ 为例，通过 $\int \frac{d(\sec x+\tan x)}{\sec x+\tan x}$ 的写法给出 $\ln|\sec x+\tan x|+C$ 的推导。

## 转写疑误与汇总页合并核对

本节专门处理各来源中疑似转写/OCR 造成的差异，供后续合并与勘误参考。

**（1）来源 [9] 疑似漏写 $\ln$。** 博客园「常见不定积分表」在推导 $\int \frac{dx}{x^2-a^2}$ 时步骤中出现 $\ln$，但最终结果写作
$$\frac{1}{2a}\left\lvert\frac{x-a}{x+a}\right\rvert + C,$$
按同样步骤其正确形式应为 $\dfrac{1}{2a}\ln\left\lvert\dfrac{x-a}{x+a}\right\rvert + C$。此处疑为**转录时漏掉 $\ln$**。

**（2）来源 [1] 存在 OCR 切分混乱。** CSDN 博客文本把公式拆成碎片，例如把 $\int x^a\,dx=\frac{x^{a+1}}{a+1}+C\ (a\neq -1)$ 转写成「∫xadx=a+11xa+1+C(a∈R,a=−1)」，并出现「x=_−_ 1 的幂函数」这类断裂片段 [1]。这些属于排版/转写噪声，不应作为公式的正确书写形式引用。

**（3）来源 [2] 表格排版残缺。** GPAI 表格中一般指数公式被转写成「∫axdx=a{​x}{lna}+C」，应为 $\int a^x\,dx=\frac{a^x}{\ln a}+C$ [2]；此外条件列「| 对数型 | $\int \frac{1}{x},dx = \ln | x |$」的截断也丢失了绝对值闭符号与 $+C$。

**（4）表示形式差异而非矛盾。** 来源 [1] 给出 $\int \tan x\,dx = -\ln|\cos x|+C$，而来源 [3] 给出 $\int \tan x\,dx = \ln|\sec x|+c$。由于 $\ln|\sec x| = -\ln|\cos x|$，二者等价，属于**同一原函数族的不同写法**，并非矛盾 [1][3]。类似的绝对值与常数写法差异在合并汇总页时需统一约定。

**（5）关于「续段汇总页的合并核对」。** 现有来源各自成篇（CSDN、GPAI、analyzemath、博客园、维基百科、手册目录、考研资料等），彼此以「基本公式集合」高度重叠 [1][2][3][9]，因此在做续段汇总时，建议以 [3]（表列最完整的初等函数积分）与 [9]（含推导）为骨架，用 [5] 补充高阶递推，用 [7] 补充含根式 $R$ 的条目，并逐条标注各来源的表示形式差异与上述转写疑点。

## 矛盾、空白与建议补充来源

**已识别的空白：**

- 多个来源仅给出结果，未系统给出**成立区间**；只有 [2] 在例题中强调「在满足 $x\neq -1$ 的区间上成立」，其余条目多缺此限定 [2]。
- 来源 [5] 的公式虽最丰富，但文本本身为扫描/转写产物，符号残缺严重（如「烅 烄 烆」等乱码），需人工校订后才可引用 [5]。
- 各来源对积分常数、绝对值、反双曲函数写法（如 $\operatorname{arsinh}$ 与 $\ln$ 形式）不统一 [7]。

**建议补充来源：**

1. 权威积分表专著（如 Gradshteyn–Ryzhik 型手册）以校核 [5] 中高阶递推公式。
2. 《数学指南——实用数学手册》的**不定积分表与定积分表**原页（第 143–187 页区段），以核对 [4] 目录所列条目的完整公式 [4]。
3. 针对考研场景的公式推导资料（如 [8]）可作为练习与检验题的补充，但其公式需以上述权威来源复核 [8]。
