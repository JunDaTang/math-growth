# 3.8.3 节式 (3.60) 括号不配对与例 2 前提次序表述是否存疑？

## 问题一：括号不配对

源文式 (3.60) 写作

```latex
\int R\left(x, \sqrt{(x - e_{1})(x - e_{2})(x - e_{3}))}\right)\,\mathrm{d}x
```

在三根乘积之后多出一个右括号，属疑似排印缺陷或抽取过程中的字符重复。按上下文，正确形式应为

```latex
\sqrt{(x - e_{1})(x - e_{2})(x - e_{3})}
```

## 问题二：例 2 前提的次序约束

源文前提写作

```latex
-\infty < e_{1} < e_{2}, \ e_{3} < \infty
```

该表述只约束了 $e_{1} < e_{2}$，未给出 $e_{2}$ 与 $e_{3}$ 的次序关系；常规表述应为 $e_{1} < e_{2} < e_{3}$。逗号处疑有讹误或抽取遗漏。

## 影响范围

两处疑点均不影响例 2 的实质结论（三次曲线无奇点、亏格为 1、不能有理化），见 [[三次曲线亏格1与椭圆积分不可有理化]]。
