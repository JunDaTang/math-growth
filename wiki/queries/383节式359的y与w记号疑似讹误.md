# 3.8.3 节式 (3.59) 中的 y 与 w 记号是否疑似讹误？

## 问题

《数学指南——实用数学手册》3.8.3 节例 1 中，源文给出的替换为

```latex
t = \tan\frac{\varphi}{2} \tag{3.58}
```

随后写出

```latex
x = \cos\varphi, \quad y = \sin\varphi \tag{3.59}
```

但本小节的积分与参数化一律使用变量 $w$（如 $C: x^{2} + w^{2} = 1$ 与 $w = \frac{2t}{t^{2} + 1}$），语境中并未出现 $y$。

## 疑点

(3.59) 的第二分量极可能是 $w = \sin\varphi$ 的书写或抽取错误。若成立，则该式与前述 $w = 2t/(t^{2}+1)$ 在 $t = \tan\frac{\varphi}{2}$ 下恰好一致。

## 影响范围

仅涉及记号一致性，不影响 [[圆的有理参数化与万能替换]] 的结论。
