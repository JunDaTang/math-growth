# 二次函数判别式记法差异

## 问题

《数学指南——实用数学手册》0.2.3 节把一般二次函数写作 \(y = ax^{2} + 2bx + c\)，并把判别式定义为 \(D := b^{2} - ac\)，求根公式为 \(x_{\pm} = (-b \pm \sqrt{D})/a\)。而通行教材通常把二次函数写作 \(y = Ax^{2} + Bx + C\)，判别式为 \(B^{2} - 4AC\)，求根公式为 \(x = (-B \pm \sqrt{B^{2} - 4AC})/(2A)\)。

两者是否只是同一事实的两套等价记法？换算后是否有任何命题（符号判据、顶点坐标、根的表达）会因此改变？在跨文献引用时应当如何避免混淆？

## 目前证据

来源内部的自洽性可以核对：

- 取 \(a = A\)、\(b = B/2\)、\(c = C\)，则 \(D = b^{2} - ac = B^{2}/4 - AC\)，即本节的 \(D\) 恰为通行判别式 \(B^{2} - 4AC\) 的四分之一；
- 求根公式分母为 \(a\)（而非 \(2a\)），与上式配套：\(\sqrt{D}/a = \sqrt{B^{2}/4 - AC}/A = \sqrt{B^{2} - 4AC}/(2A)\)；
- 顶点形式 \(y = a(x + b/a)^{2} - D/a\) 换算后给出顶点 \(\left(-\frac{B}{2A}, -\frac{B^{2} - 4AC}{4A}\right)\)，与通行结论一致。

因此，就来源给出的全部命题（三种符号情形、顶点坐标、根的表达式）而言，本节记法与通行记法在换算后等价；差别只在于判别式的数值相差因子 4，以及一次项系数与分母的书写方式。

来源中的三个数值例子（\(x^{2}-6x+8=0\)、\(x^{2}-2x+1=0\)、\(x^{2}+2x+2=0\)）均取 \(a = 1\)，数值上与通行记法不产生冲突。

## 待确认

- 手册其他章节（例如 0.1 或 1.1 节）是否统一采用 \(b^{2} - ac\) 记法？若统一，则这是全书约定，而非本节笔误；
- 是否存在必须区分两种判别式的场景（例如引用具体数值 \(D\) 的场合，如二次曲线分类中的判别式）；
- 与 [[立体图形公式表中的记法疑问]] 是否属于同一类“手册内部非通行记法”问题。
