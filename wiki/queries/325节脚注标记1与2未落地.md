# 3.2.5 节脚注标记 1) 与 2) 是否未落地？

## 问题

《数学指南——实用数学手册》3.2.5 节正文中共出现以下脚注标记，但均未看到对应的脚注正文：

| 位置 | 标记 |
|------|------|
| 康德题记 *Kritik der reinen Vernunft, Elementarlehre* 之后 | 1) |
| 基本概念列表中「关联」之后 | 2) |
| 角的定义中「也可用记号 $\angle(c, b)$ 代替 $\angle(b, c)$」之后 | 1) |
| [[concepts/阿基米德公理]] 末尾 | 1) |

其中「1)」在同一节内出现三次，指向不同位置，这在数学手册的编号体例中通常是**逐页脚注**（每页重新编号）的做法；源文件提取时脚注正文未被保留，或原书脚注位于页面底部而被截断。

## 待确认

1. 原书该页脚注的实际内容是什么（尤其是「关联」处的 2) 是否给出「关联」一词的德语原文 *Inzidenz* 或同类说明）？
2. 角记号 $\angle(c, b) = \angle(b, c)$ 处的脚注是否说明该记号的无序性约定？
3. 阿基米德公理末尾的 1) 是否给出该公理的另述形式或出处（如与阿基米德本人的关系）？
