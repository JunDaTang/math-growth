# 1.8 节三重积置换公式末项是否重复讹误

本节给出的三重积置换公式转写为

```latex
(abc) = (bca) = (cab) = −(acb) = −(bac) = −(acb).
```

末项 $-(acb)$ 与前面第四项 $-(acb)$ 完全相同，而三个逆序项本应为 $-(acb), -(bac), -(cba)$。因此末项疑为 $-(cba)$ 的转写讹误。

需人工核对原书该行公式以确认，并据此修正 [[三重积]] 页中的记录。
