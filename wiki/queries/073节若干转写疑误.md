# 0.7.3 节若干转写疑误

## 问题

在 0.7.3 节的入库文本中，发现若干可能与原始排版或转写有关的疑点，需要人工核对原书：

1. **人名转写**：0.7.3.3 小标题写作「庞加菜意义下的渐近展开式」，正文却写「庞加莱 (Poincaré, 1854—1912)」。「庞加菜」应为「庞加莱」的误植。页面对应 [[庞加莱]]。
2. **定常相方法的函数记号**：公式给出 $A_{k}$ 时使用的是 $(P^{m}f)(a)$，而定理的其余部分描述的是振幅函数 $A$（以及相因子 $p$）。$f$ 与 $A$ 是否为同一对象、是否应写作 $(P^{m}A)(a)$，需核。
3. **条件的编号与顺序**：条件 (i)、(ii) 出现在公式块之后，而 (iii) 被脚注与后续文本隔开单独出现，源文排版顺序是否为原书如此，需核。
4. **脚注锚点位置**：脚注 1) 的标记出现在庞加莱展开式定义式之后，但脚注内容同时涉及 $o(\cdots)$ 的定义与一条极限等式，其归属范围（是否覆盖 0.7.3.3 全节）需核。
5. **$\operatorname{arcosh}$ 与 $\operatorname{arcoth}$ 的记号**：0.7.3.1 表中分别写作 $\ln 2x-\operatorname{arcosh}x$ 与 $\operatorname{arcoth}x$，与手册他处（如 0.2.10、0.2.11 节）的 $\operatorname{arcosh}$/$\operatorname{arcoth}$ 写法是否一致，需核。
6. **收敛域与变量域**：0.7.3.1 表中前三行与 $\ln2x-\operatorname{arcosh}x$ 行注明「$x$ 为实数」，$\operatorname{arcoth}x$ 行注明「$x$ 为复数」，这一层次差异是否为原书原文，需核。
