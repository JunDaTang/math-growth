# 两个等式除法法则右端写作 b/d 的转写疑误

## 问题

1.1.4 节「两个等式的运算」中，除法条目的入库文本为

```latex
a = b,\ c = d,\ c \neq 0 \Rightarrow \frac{a}{c} = \frac{b}{d}.
```

若 a = b 且 c = d，则左端 a/c 与右端 b/d 表示的是同一个数（因为 a = b, c = d），结论平凡成立，逻辑上无碍；但按同一小节的书写习惯（对比单等式除法写作 a/c = b/c），右端更可能应为 b/c，条件也应为 c ≠ 0。

## 推断

这可能是转写时把 c 误写为 d。需要核对原书排版，以确定该法则的原始形式与条件（例如是否本意是「a = b, c = d ⇒ a/c = b/d」，即两个等式分别作除）。

## 拟解决方式

核对原书 1.1.4 节「两个等式的运算」表格中的除法一行。
