# Research: 0.9.5 不定积分表（续2，条目 181–341）尚未入库

# 0.9.5 不定积分表（续 2，条目 181–341）

## 一、概述

「0.9.5 不定积分表」是《数学指南——实用数学手册》第 0 章「公式、图和表」中 0.9 节「积分表」的第五个子节。该书德文原书为 E. Zeidler 等主编的 *Teubner-Taschenbuch der Mathematik*，中文版由李文林等译、科学出版社于 2012 年出版 [15]。所谓「不定积分」（unbestimmtes Integral）即一给定函数的全体原函数之集合 $\int f(x)\,dx = F(x) + C$，是把求导运算「倒过来」并保留一个任意积分常数的运算 [19][20]。

据目录 [2][5]，0.9 节的分节与起始页码如下：

| 子节 | 标题 | 起始页 |
| --- | --- | --- |
| 0.9.1 | 初等函数的积分 | 161 |
| 0.9.2 | 积分法则 | 163 |
| 0.9.3 | 有理函数的积分 | 166 |
| 0.9.4 | 重要代换 | 167 |
| **0.9.5** | **不定积分表** | **171** |
| 0.9.6 | 定积分表 | 205 |

由此可知 0.9.5 覆盖原书约 pp.171–204，条目按连续编号编排（同类德文积分表中条目常排到数百条以上，见 [4] 中出现的第 466–477 号条目）。本页收纳的是其中 **条目 181–341 这一段（即「续 2」）**；据标题命名推断，条目 1–180 属「续 1」、342 及以后属「续 3」，二者均尚未入库。

## 二、本段承接的前文：$\sqrt{x^2+a^2}$ 类根式积分

收集到的原书片段 [4] 显示，条目 179–182 属于含 $\sqrt{x^2+a^2}$（记 $Q = x^2+a^2$）的根式积分组，其中 181、182 正落在本段起点，可用作定位锚点：

| 条目 | 积分 | 结果 | 来源 |
| --- | --- | --- | --- |
| 179 | （片段残缺，疑为 $\int \dfrac{dx}{x\sqrt{Q}}$ 一类） | 涉及 $\ln$ 形式 | [4] |
| 180 | $\displaystyle\int \dfrac{\sqrt{Q}}{x}\,dx$ | $\sqrt{Q} - a\,\ln\dfrac{a+\sqrt{Q}}{x}$ | [4] |
| **181** | $\displaystyle\int \dfrac{\sqrt{Q}}{x^{3}}\,dx$ | $-\dfrac{\sqrt{Q}}{2x^{2}} - \dfrac{1}{2a}\ln\dfrac{a+\sqrt{Q}}{x}$ | [4] |
| **182** | $\displaystyle\int \dfrac{dx}{\sqrt{Q}}$ | $\operatorname{arsinh}\dfrac{x}{a} = \ln\!\bigl(x+\sqrt{Q}\bigr) - \ln a$ | [4] |

条目 182 同时给出反双曲正弦与对数两种等价表达，体现了该表「同一结果多写法并列」的编排风格 [4]。

## 三、条目 181–341 的内容构成

原书这一区间的完整正文尚未获得，以下分组主要依据片段 [4]、同类不定积分表 [1][3][7][8][16] 的元素类型对照推断，**条目号与分组的精确对应关系仍需以原书为准**。

### 3.1 代数函数与无理函数的积分

承接第二节的根式组，应继续覆盖 $\sqrt{x^2-a^2}$、$\sqrt{a^2-x^2}$ 及一般 $\sqrt{ax^2+bx+c}$ 型积分。可对照的等价公式包括：

- $\displaystyle\int \dfrac{dx}{\sqrt{x^{2}-a^{2}}} = \ln\bigl|x+\sqrt{x^{2}-a^{2}}\bigr| + C$ [8]；
- $\displaystyle\int \sqrt{a^{2}-x^{2}}\,dx = \tfrac12 x\sqrt{a^{2}-x^{2}} + \tfrac{a^{2}}{2}\arcsin\dfrac{x}{a} + C$，$\displaystyle\int \dfrac{dx}{\sqrt{a^{2}-x^{2}}} = \arcsin\dfrac{x}{a} + C$ [8]；
- 含 $\sqrt{x^{2}-a^{2}}$ 的成组公式（$\int\frac{dx}{\sqrt{(x^2-a^2)^3}}$、$\int x\sqrt{x^2-a^2}\,dx$ 等）[7]；
- 有理分式递推式 $\displaystyle\int \dfrac{dx}{(ax^{2}+bx+c)^{n}}$、$\displaystyle\int \dfrac{x\,dx}{ax^{2}+bx+c}$ 等，按判别式 $\Delta$ 或 $4ac-b^{2}$ 的符号分支 [1][16]。

### 3.2 三角函数有理式（Weierstrass 代换型）

同类表 [1] 给出的典型形式与本段应处理的类型一致：

- $\displaystyle\int \dfrac{dx}{a+b\sin x}$（$|a|>|b|$ 用 $\arctan$、$|a|<|b|$ 用 $\ln$ 表达）[1]（31）；
- $\displaystyle\int \dfrac{dx}{a+b\cos x}$ [1]（32）；
- $\displaystyle\int \dfrac{dx}{a\sin\alpha x + b\cos\alpha x} = \dfrac{1}{\alpha\sqrt{a^{2}+b^{2}}}\ln\dfrac{a\sin x+b\cos x}{a\sin x-b\cos x}$ [1]（33）；
- $\displaystyle\int \dfrac{dx}{a\cos^{2}x + b\sin^{2}x}$，按 $ab>0$ 与 $ab<0$ 分支 [1]（34）。

### 3.3 三角函数的乘积

- $\displaystyle\int \sin ax\sin bx\,dx = \dfrac{\sin(b-a)x}{2(b-a)} - \dfrac{\sin(b+a)x}{2(b+a)}$，$\ |a|\neq|b|$ [1]（29）[3] 3.3；
- $\displaystyle\int \sin ax\cos bx\,dx$、$\displaystyle\int \cos ax\cos bx\,dx$ [1]（30）[3] 3.5；
- $\displaystyle\int \sec x\tan x\,dx = \sec x + C$、$\displaystyle\int \csc x\cot x\,dx = -\csc x + C$ [3] 3.1–3.2。

### 3.4 幂函数与三角、反三角函数之积

- $\displaystyle\int x^{n}\sin ax\,dx$、$\displaystyle\int x^{n}\cos ax\,dx$ 的有限求和公式 [1]（35）（36）；
- $\displaystyle\int x^{n}\arccos\dfrac{x}{a}\,dx$、$\displaystyle\int x^{n}\arcsin\dfrac{x}{a}\,dx$（二者由 $\int x^{n}\arcsin\frac{x}{a} = \frac{\pi x^{n+1}}{2^{n+2}} - \int x^{n}\arccos\frac{x}{a}$ 相联系）、$\displaystyle\int x^{n}\arctan\dfrac{x}{a}\,dx$、$\displaystyle\int x^{n}\operatorname{arccot}\dfrac{x}{a}\,dx$ [1]（37）（38）。

### 3.5 指数函数与幂×指数

- $\displaystyle\int x^{n}e^{ax}\,dx$、$\displaystyle\int x^{n}a^{x}\,dx$ [1]（39）（40）；
- 基础项 $\int e^{x}dx$、$\int a^{x}dx = \frac{a^{x}}{\ln a}+C$、$\int \ln x\,dx = x\ln x - x + C$ [3] 4.1–4.3；
- $\displaystyle\int e^{ax}\sin bx\,dx$、$\displaystyle\int e^{ax}\cos bx\,dx$ [3] 6.1–6.2。

### 3.6 本段末端：有理三角积分（条目约 337–343）

片段 [4] 显示本段收尾于形如 $\dfrac{1}{(\beta+\gamma\cos\alpha x)^{2}}$、$\dfrac{1}{\beta^{2}\pm\gamma^{2}\cos^{2}\alpha x}$ 的有理三角积分，并出现交叉引用「参看第 337 个积分」：

- 约条目 340：$\displaystyle\int \dfrac{\cos\alpha x\,dx}{(\beta+\gamma\cos\alpha x)^{2}}$；
- 约条目 341–342：$\displaystyle\int \dfrac{dx}{\beta^{2}+\gamma^{2}\cos^{2}\alpha x} = \dfrac{1}{\alpha\beta\sqrt{\beta^{2}+\gamma^{2}}}\arctan\dfrac{\beta\tan\alpha x}{\sqrt{\beta^{2}+\gamma^{2}}}$（$\beta>0$）；
- 约条目 343：$\displaystyle\int \dfrac{dx}{\beta^{2}-\gamma^{2}\cos^{2}\alpha x}$，按 $\beta^{2}>\gamma^{2}$（$\arctan$）与 $\gamma^{2}>\beta^{2}$（$\ln$）分两支 [4]。

（原书数字与公式的 OCR 顺序有错位，上列条目号与公式的对应为暂定。）

### 3.7 超出本段的后继内容

片段 [4] 还显示表中更靠后（约条目 344 起）为 $\sin\alpha x\cos\alpha x$、$\sin^{2}\alpha x\cos^{2}\alpha x$、$\sin^{n}\alpha x\cos\alpha x$ 等三角积分，而条目 466–477 已属双曲函数组（$\int\sinh\alpha x\sin\alpha x\,dx$、$\int\frac{dx}{\sinh\alpha x}$、$\int\tanh^{2}\alpha x\,dx$ 等）[4]。这些均在本段（181–341）之外，仅用于说明该表条目连绵贯通的编排体例。

## 四、与 wiki 其他内容的关联

- 0.9.5 所属手册在 0.5 节设有「特殊函数值表」，其中 0.5.2 柱函数（贝塞尔函数）、0.5.3 球函数（勒让德多项式）、0.5.4 椭圆积分、0.5.5 积分三角函数与积分指数函数、0.5.6 菲涅耳积分 [2][5]。这些特殊函数的积分与恒等式和 0.9.5 的条目互为补充，可与 [[贝塞尔微分方程]]、[[勒让德多项式]]、[[球面函数]]、[[拉盖尔多项式]] 等页面相互印证。
- 同一手册的分析学部分已部分入库，例如 1.13 偏微分方程见 [[10-数学指南实用数学手册--9-113-偏微分方程--i6obpr]]；其 1.12、1.13 各子节亦已建档。0.9.5 属同一「工具书式」条目体系，可与这些既有来源页交叉定位。
- 与本页同类的「子节尚未入库」问题，可参见 [[113节各子节尚未入库]]，二者属同一手册录入进度的不同侧面。

## 五、缺口、矛盾与待核实

1. **正文缺失**：条目 181–341 的主体内容未获得完整文本，目前仅有 175–182 与约 337–343 两处片段 [4]，中段（如 $\sqrt{x^2-a^2}$、$\sqrt{a^2-x^2}$、$\sqrt{ax^2+bx+c}$、三角与指数函数各组）的条目号—公式对应关系属推断。
2. **OCR 乱码**：来源 [1][4] 的数学符号大量错乱（如以「犿∈瓔」表示 $m\in\mathbb{N}$、「槡」表示根号），数字与公式错位，难以逐字还原。
3. **编号体系冲突**：来源 [1]（一份独立的中文「新不定积分表」）同时出现 (11)–(17) 与 (28)–(40) 两套编号，与 [4] 的连续编号（175–182、340–347、466–477）并不一致，需与原书逐条核对。
4. **分段依据未确认**：标题称「续 2 = 181–341」，但该切分是否与原书分页 / 条目分组一致，尚无来源直接证实。
5. **引用书目未核实**：0.9.5 是否在正文或书末列出 Gröbner–Hofreiter 的 *Integraltafel* [10]–[14] 或 Bronstein 等标准积分表，未核实。
