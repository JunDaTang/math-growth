# 1.12.5.2 节反解公式中 x₂(t) 一项的符号疑义

## 问题

1.12.5.2 节在给出由约化方程 (1.291) 的解反推原方程 (1.290) 的解时，写作

```text
x₁(t) = y(t) - (m₂/m) x(t),   x₂(t) = y(t) - (m₁/m) x(t)
```

按质心定义 $y = (m_1x_1 + m_2x_2)/m$ 与 $x = x_2 - x_1$ 直接验算：

```text
y + (m₁/m) x = (m₁x₁ + m₂x₂)/m + (m₁x₂ - m₁x₁)/m = x₂,
```

即第二式应为加号。因此本源所印的减号疑似转写（或排版）讹误。

## 已知信息

- 第一式 $x_1 = y - (m_2/m)x$ 与验算一致。
- 本源未对这两个公式给出推导，只称「可以得到」。

## 待办

- 核对原始排版（或德文/英文原书）确认 $x_2(t)$ 一项的符号。若确认为加号，则在 [[约化一体问题1291]] 与 [[一体问题]] 中修正并注明。
