# 表 0.5 中若干立体图形公式的记法疑问

**问题**：《数学指南——实用数学手册》0.1.4 节表 0.5 中，若干条目的字面记法与通行的立体几何标准形式存在差异，其中部分疑为 OCR 或排版问题。它们是同一图形内部的记法问题，不涉及不同实体之间的混淆，但在与 wiki 其他页（如 [[初等几何公式]]）的标准形式对照时会产生字面冲突，故登记待核对。

**待核对条目**

1. **圆环体积**：原文 $V = 2\pi r^{2}\rho$（$r$ 为圆环的半径，$\rho$ 为截面半径），而同表给出的表面积 $O = 4\pi^{2}r\rho$。两式中 $\pi$ 的幂次不一致；按标准环面（torus）$V = 2\pi^{2}Rr^{2}$、$O = 4\pi^{2}Rr$ 对照，$V$ 疑应为 $2\pi^{2}r^{2}\rho$。相反方向的可能（表面积多了一个 $\pi$）亦需核对原书。
2. **桶形（圆形截面）体积**：$V = 0.0873h(2D + 2r)^{2}$，系数 $0.0873$ 约等于 $\pi/36$。原文已明确标注「这是一个近似公式」，引用时应无条件保留该近似限定。
3. **方尖形体积**：$V = \frac{1}{6}\left(ab + (a + c)(b + d) + cd\right)$ 中未出现高 $h$，与棱柱、棱台等体积公式的维度习惯不符，疑为漏项（常见形式为 $\frac{h}{6}\left(ab + (a+c)(b+d) + cd\right)$）。
4. **楔形（侧面为等边三角形）体积**：$V = \frac{\pi}{6}bh(2a + c)$ 中出现 $\pi$，对由边长与高确定的刚体楔形不寻常，疑为 $\frac{1}{6}$ 的排版讹误。
5. **球冠与球台的表面积**：两条均记为 $O = 2\pi rh$，但分别限定为「顶部」与「中部」，且两条中 $r$ 的含义不同（球冠条目说明 $r$ 为球的半径；球台条目同时出现球半径与两条纬线圈半径 $R, \rho$）。易被误读为整个立体图形的表面积，引用时须保留「顶部／中部」的限定语。

**当前处理**：[[立体图形的体积与表面积公式]] 与源页面均照录原文字面值，不擅自改订；本 query 用于跟踪后续与纸质原书或其他来源的核对。

**需要的证据**

- 纸质版或官方电子版《数学指南——实用数学手册》0.1.4 节的原样排版。
- 其他权威手册中环面、方尖形、楔形、桶形体积的标准形式。
- wiki 中 [[初等几何公式]] 是否已采用与本节不同的形式（若已采用，需按 Contradiction Handling 记录）。
