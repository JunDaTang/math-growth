# 1.9.1 节谐振子例中「非谐振子」一句归属是否讹误

## 问题

1.9.1 节正文的例（谐振子）中，在由 m x″(t) i = −k x i 过渡到 x″ + ω² x = 0 的**之前**，出现了这样一句：

> 这称为非谐（anharmonic）振子。当 l = 0 时的特殊情形就是谐振子。

## 疑点

- 该句讨论的是**非谐振子**（含 l x³ 修正项），而正文此处尚未引入参数 l；参数 l 与 F(x) = −k x i − l x³ i 均只出现在**脚注 1** 中。
- 紧随其后的一句才是「如果令 ω² = k/m，那么我们得到谐振子的微分方程 x″ + ω² x = 0」，即此处讨论的对象是**谐振子**。
- 脚注 1 末尾重复出现了完全相同的两句：「这称作非谐振子。谐振子是 l = 0 时的特例。」

因此正文中的这两句疑为从脚注 1 末尾**错位／重复插入**的转写讹误，其正确位置应在非谐振子力定律 F(x) = −k x i − l x³ i 之后。

## 影响范围

影响 [[concepts/谐振子]]、[[concepts/非谐振子]] 与 [[findings/非谐振子力定律由泰勒展开与对称性导出]] 的叙述次序，不影响数学内容。
