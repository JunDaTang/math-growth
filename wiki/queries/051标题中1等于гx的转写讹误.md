# 0.5.1 标题中 1=г(x) 的转写讹误

## 问题

source 文件《数学指南——实用数学手册》0.5.1 的标题原文为：

```
0.5.1 г函数г（x）和1=г（x）
```

其中存在两处可疑字符，需确认是否为 OCR / 字符映射讹误：

1. **`г` → `Γ`**：标题使用西里尔小写字母 ge（U+0433）`г`，而数学文献惯例为希腊大写字母 Gamma（U+0393）`Γ`。正文中两次出现该字符，且写法不一致（`г函数`、`г（x）`）。
2. **`=` → `/`**：`1=г（x）` 按字面读作「1 等于 Γ(x)」。但该小节标题的结构（「Γ(x) 和 …」并列）暗示后一项应是 Γ 的**倒数函数**，即 `1/Γ(x)`；「／」在 OCR 中被识别为「=」是最合理的解释。

## 为何值得追踪

- 若按字面读作「1 = Γ(x)」，会引入一个与 Γ 函数基本性质相冲突的表述；但本源**没有正文**可供核对，无法从内容侧面消解歧义。
- 同书其他 source 页已出现同类字符 / 编号讹误（例如章节号残缺、符号错位），因此该问题与手册的转录质量整体相关，而非孤例。
- 该判定直接影响 [[倒数伽马函数]] 页面标题与 slug 的最终写法。

## 当前倾向（未确证）

倾向判定为 `1/Γ(x)`。理由为标题并列结构与数学语境，而非源文档的直接证据。在获得原始 PDF 或后续小节正文之前，此判定标为**未确证**。

## 待澄清

- 原始 PDF 中该处确为「/」还是其他符号？
- `г` 与 `Γ` 的混用是全文系统性问题，还是仅标题行的问题？
- 是否存在同一 OCR 批次中其他小节的同类讹误，可一并规整？
