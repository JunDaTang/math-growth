# 5.1.4 节「玻尔佐末菲」「F(1)」等记号讹误

## 问题

源文档中存在若干疑似排版或 OCR 讹误：

1. (vii) 标题写作「玻尔佐末菲量子化（1913）」，通行写法应为「玻尔-索末菲量子化」（Bohr–Sommerfeld）。
2. 谐振子段落中「由于常数 $U(0)$ 与力不相关（因为 $F(1) = -U'(q)$）」，其中 $F(1)$ 应为 $F(q)$；否则无法与「与力不相关」的论证衔接。
3. 一维运动段落中「导出欧拉-拉格朗日微分方程 $(L_{q'})' - L_q = -U'(q)$，即 (5.31) $mq''=-U'(q)$」——欧拉-拉格朗日方程的标准形式为 $(L_{q'})' - L_q = 0$，此处右端代入了 $-U'(q)$，属省略「$=0$」后的简写还是讹误，需要确认。
4. (vi) 中「因此哈密顿函由 $H = \dots$ 给出」缺「数」字。

## 待确认

- 以上各项应作为勘误标注，还是保留原样并加注？
- 第 3 项是否影响与 [[欧拉-拉格朗日方程]] 条的表述一致性？
