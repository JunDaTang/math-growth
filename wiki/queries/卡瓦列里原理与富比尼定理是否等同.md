# 卡瓦列里原理与富比尼定理是否等同

## 问题

《数学指南》1.7 节把积分理论的第 (i) 个关键词写作：

```
(i) 卡瓦列里(Cavalieri) 原理(富比尼(Fubini) 定理),
```

即以括注形式把「卡瓦列里原理」与「富比尼定理」**等同**。这一等同是否成立？

## 张力

- 通行用法中，卡瓦列里原理通常指几何的截面原理：立体体积等于其截面面积沿某方向的积分。
- 富比尼定理通常指累次积分定理：在适当条件下，重积分可化为累次积分且积分次序可交换。

两者的陈述对象（几何直观 vs 分析陈述）与前提条件并不相同，简单等同可能掩盖条件差异。
