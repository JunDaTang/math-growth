# 6.3.5 节离散型估计自变量下标 (x₁,…,x_k) 与泊松例求和上限 n 是否为笔误？

本 query 汇合两处相邻的记号疑点，均出现在同一离散型段落的正文与算例中。

## 疑点一：估计值的自变量下标

原文称「最大似然估计值 $\beta_r = \beta_r(x_1, \cdots, x_k),\; r = 1, \cdots, k$」。此处同时使用 $k$ 表示**参数个数**与**取值个数**（$a_1, \cdots, a_k$），而观测值序列长度为 $n$。由于估计值应是**全部观测值**的函数，其自变量下标疑应为 $x_1, \cdots, x_n$。

## 疑点二：泊松例推理中的求和上限

泊松例的推理给出方程

```latex
\sum_{j=0}^{n} \left(\frac{j}{\beta} - 1\right) h_j = 0,
```

而上文明确 $X$ 的取值是 $j = 0, 1, \dots$（无限多个）。因此求和上限按 $j$ 的取值范围应为 $\infty$，写作 $n$ 疑与样本容量 $n$ 混淆。该求和结果 $\beta = \sum_{j=1}^{n} h_j j$ 若按无限求和理解，则与 (6.39) 的等价性推导自洽。

## 建议处理

两处均按「$n$ 为样本容量」的约定理解：估计值自变量记作 $x_1, \cdots, x_n$，离散求和对 $j$ 的全部取值（上限 $\infty$）进行。
