# Research: 高斯误差传播定律中的协方差项未出现

# 高斯误差传播定律中的协方差项未出现

## 核心结论

[[高斯]]误差传播定律（error propagation / propagation of uncertainty）用于由若干直接测量量 $x, y, \dots$ 求间接量 $f = f(x, y, \dots)$ 的不确定度。教科书、实验手册与在线计算器中最常见的写法是"各项平方和开方"形式：

$$\sigma_f^2 = \left(\frac{\partial f}{\partial x}\right)^2 \sigma_x^2 + \left(\frac{\partial f}{\partial y}\right)^2 \sigma_y^2 + \cdots$$

该式中不出现协方差项。这一"缺席"并非定律本身缺少内容，而是**隐含假设了各输入量相互独立**：当协方差 $\sigma_{xy} = 0$ 时，完整的一阶传播公式恰好退化为上式 [1][5][15]。因此，问题的关键不在于"协方差项是否存在"，而在于"何时可以把它省略、何时必须把它写出"。

## 完整形式：协方差项所在的位置

一般（一阶）传播公式在平方和之外还包含交叉项 [1][2][3]：

$$\sigma_f^2 = \left(\frac{\partial f}{\partial x}\right)^2 \sigma_x^2 + \left(\frac{\partial f}{\partial y}\right)^2 \sigma_y^2 + \cdots + 2\left(\frac{\partial f}{\partial x}\right)\left(\frac{\partial f}{\partial y}\right)\sigma_{xy} + \cdots$$

其中 $\sigma_{xy}$ 即 $x$ 与 $y$ 之间的协方差 [1][2]。若引入相关系数 $\rho$，则协方差可写成 [1]：

$$\sigma_{xy} = \rho\,\sigma_x\,\sigma_y$$

于是加法（或任意二元函数）的完整方差公式变为：

$$\sigma_z^2 = \sigma_x^2 + \sigma_y^2 + 2\rho\,\sigma_x\,\sigma_y$$

[1]

值得注意，[3] 明确指出该公式是"到一阶"（to first order）的近似，即来自对 $f$ 作线性化展开。

## 协方差与相关系数

协方差度量两个随机变量"共同变化"的程度，其定义为 [8]：

$$\mathrm{cov}_{XY} = \sigma_{XY} = E[(X-\mu_X)(Y-\mu_Y)]$$

相关系数则是协方差的归一化版本 [8][10]：

$$\rho_{XY} = \frac{\sigma_{XY}}{\sigma_X \sigma_Y}$$

由此可得前述 $\sigma_{xy} = \rho \sigma_x \sigma_y$ 的关系 [1][8]。两者的关键区别 [8][9][10]：

- **协方差带量纲**，其数值受单位影响（如把米换成毫米会使协方差按比例改变），因此不便单独用于比较关联强弱；
- **相关系数无量纲**，取值限定在 $-1$ 与 $1$ 之间，更适合判断关系强弱：$0$ 表示无线性关系，$\pm 1$ 表示完全（正/负）线性关系；
- 变量与自身的协方差即其方差，变量与自身的相关系数恒为 $1$（两方差均为零的退化情形除外）[8]。

[3] 用人群体重与身高的例子说明这种相关性，并指出也存在"反相关"（anti-correlation），即一个变量取大值时另一个更可能取小值。

## 矩阵（雅可比—协方差矩阵）形式

在多输出、多输入情形，传播公式可写成矩阵形式 [11][13][15]：

$$\Sigma^{f} = J\,\Sigma^{x}\,J^{\top}$$

其中 $J$ 为函数 $f$ 对输入量的雅可比矩阵（各一阶偏导数），$\Sigma^x$ 为输入量的方差-协方差矩阵 [15]。Keysight 的技术文档同样给出 [13]：

$$[V_f] = [J]\,[V_x]\,[J]^{\top}$$

并说明相乘结果的**对角元给出各输出量的方差，非对角元给出协方差** [13]。NIST 的工作进一步指出，可先用按各误差机制标准差缩放的雅可比矩阵完成传播，最后一步再评估派生量的完整协方差矩阵 [11]。

这类框架之所以重要，是因为在许多真实测量（例如 S 参数测量）中，不同频率、不同量之间的统计相关性是必须纳入的 [11]。

## 为什么常见公式中不含协方差项

综合各来源，省略协方差项的情形主要有以下几种：

1. **输入量独立**。当 $x$ 与 $y$ 的误差相互独立时 $\sigma_{xy} = 0$，完整公式自动退化为简化形式 [1][5]。
2. **教材与计算的简化惯例**。多数入门公式"假设不确定度相互独立"，只处理独立情形，从而形成所谓"标准"传播公式 [2][14]。
3. **无共同误差源**。若两个量不共享同一误差来源（如用不同、随机误差互不相关的尺子分别测量高度与宽度），则可以忽略协方差 [3]。

反之，当两个量"共享一个共同误差来源"时，它们的误差就是相关的，必须引入协方差项 [4]。

## 定量例子

**矩形板周长**（[1]）：测得长 $L = 10.0 \pm 0.1\ \mathrm{cm}$、宽 $W = 5.0 \pm 0.05\ \mathrm{cm}$，周长 $P = 2L + 2W$。先用不考虑相关的公式计算；若 $L$ 与 $W$ 存在相关（例如同一次测量中的系统偏差），则须改用含 $2(\partial f/\partial L)(\partial f/\partial W)\sigma_{LW}$ 的完整公式 [1]。

**乘法法则校验**（[1]）：对 $z = xy$，在假设独立的条件下代入通用公式得 $\sigma_z^2 = y^2\sigma_x^2 + x^2\sigma_y^2$，两边除以 $z^2=(xy)^2$ 并开方，得到相对不确定度"平方和开方"的乘法法则 $(\sigma_z/z)^2 = (\sigma_x/x)^2 + (\sigma_y/y)^2$。这说明常见的相乘法则其实是含协方差项的通用公式在独立假设下的特例 [1]。

**除法法则**（[15]）：对 $f = A/B$，完整公式为

$$\sigma_f^2 \approx f^2\left[\left(\frac{\sigma_A}{A}\right)^2 + \left(\frac{\sigma_B}{B}\right)^2 - 2\frac{\sigma_{AB}}{AB}\right]$$

可见当 $A$、$B$ 相关时，交叉项带负号进入 [15]。

**数值传播**（[2]）：对不便于求导的函数，可用差分近似：先算 $du_x = f(x+\sigma_x, y) - f(x, y)$、$du_y = f(x, y+\sigma_y) - f(x, y)$；忽略协方差时 $\sigma_u = \sqrt{du_x^2 + du_y^2}$，计入协方差时

$$\sigma_u = \sqrt{du_x^2 + du_y^2 + 2\,\frac{du_x}{\sigma_x}\,\frac{du_y}{\sigma_y}\,\sigma_{xy}^2}$$

[2]

## 矛盾与空白

- **表述一致性**：各来源对"独立时协方差项为零、公式退化为简化形式"这一点表述一致 [1][5][15]，无明显矛盾。
- **公式完整度不一**：[15] 的摘录部分对一般公式仅给出矩阵形式，未在同一处显式列出标量形式的完整交叉项；而 [1]、[2]、[3] 则给出显式标量交叉项。三者互为补充而非冲突。
- **一阶近似的适用性**：仅有 [3] 明确强调公式为"一阶"近似；在函数强非线性或输入不确定度较大时该近似的精度问题，各来源均未展开。
- **来源 [4] 文本残缺**：该在线计算器页面的摘录只提到"当两个变量共享共同误差来源时其误差相关"，但完整公式被截断，无法据此核实其具体实现。
- **数值传播中的协方差估计**：[2] 给出含 $\sigma_{xy}$ 的数值公式，但未说明在仅有少量样本时如何稳定估计协方差（应使用 $n-1$ 分母还是其他约定，[9] 与 [8] 的期望值写法并不完全统一）。

## 小结

"协方差项未出现"并不是定律的缺陷，而是其最常被引用的形式所携带的隐含前提——**输入量独立**。一旦输入量之间共享误差来源或本身 statistical correlated，就必须回到含 $2(\partial f/\partial x)(\partial f/\partial y)\sigma_{xy}$ 的完整公式，或采用 $\Sigma^{f} = J\Sigma^{x}J^{\top}$ 的矩阵表述 [1][2][11][15]。
