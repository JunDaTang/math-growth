# 6.3.6 节线性回归求和上限 m 是否为 n 之误？

## 问题

《数学指南——实用数学手册》6.3.6.5 节给出多元线性回归方程组：

```
Y_j = ∑_{k=1}^{m} a_{jk} X_k + b_j + ε_j,   j = 1, …, m.
```

但在紧邻的正文中，自变量（解释变量）被明确写为 $X_1, \dots, X_n$，共 **$n$ 个**；因变量为 $Y_1, \dots, Y_m$，共 **$m$ 个**。

系数矩阵 $a_{jk}$ 的行索引 $j$ 对应因变量（$j = 1, \dots, m$），列索引 $k$ 应对应**自变量**。因此求和上限在逻辑上应为 **$n$** 而非 $m$。

## 可能的解释

1. **排版/翻译讹误**：求和上限 $m$ 应为 $n$。这与其他小节反复出现的下标记号疑点（如 [[635节正态分布第二方程中x_j减sigma疑为x_j减mu]]、[[6243节林德伯格条件中下标记号疑点]]）属同类问题。
2. **原文即如此**：若原书确有通例或上下文约定（例如某些章节约定 $n = m$，或先令两部分变量数相同），则应补充说明。
3. **记号体系不一致**：本节的 $n$ 指因子数/自变量数，$m$ 指因变量数，与 6.2.3 节中 $n$ 表示样本量的用法也不统一。

## 影响评估

对方法本身无实质影响（线性模型的形式不变），但会影响读者对系数矩阵维度的理解：读者可能误以为自变量只有 $m$ 个、或误以为 $a_{jk}$ 是方阵。

- 原著（德文原版或最新中文版）此处求和上限究竟为何？
