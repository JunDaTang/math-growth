# 振动理论（欧拉公式的应用领域）

## 概述

振动理论是 [[欧拉公式]] 最早、也最稳固的应用领域之一。其核心链条可概括为：简谐振子的运动方程是一个二阶线性常微分方程，把待解函数设为复指数形式，方程的特征根自然落在虚轴上；再借助欧拉公式，复数指数解与正弦、余弦解相互转换，从而得到既便于代数运算（振幅、相位、叠加）又与物理量直接对应的表达式 [2][3][6]。当振动由单个简谐分量推广到多个分量时，同一套复指数语言又自然生长为 Fourier 级数与 Fourier 分析 [11][12][15]。因此，"欧拉公式在振动理论中的应用"构成了从简谐振动到频谱分解的一条完整路径。

本页面为新建页面，用于补全 wiki 中"欧拉公式的应用领域"这一缺失环节；现有页面主要覆盖欧拉公式本身及其在三角函数、复指数中的性质，尚未覆盖振动与波动方向的展开。

## 简谐振子的复数指数解

考虑最简单的一维简谐振子方程

$$\ddot{x} + \omega_0^2 x = 0,$$

其中 $\omega_0$ 为实数角频率。由于指数函数的任意阶导数仍是指数函数，可尝试 $x = x_0 e^{\lambda t}$ 形式的解 [2]。代入后得

$$\lambda^2 x_0 e^{\lambda t} = -\omega_0^2 x_0 e^{\lambda t} \;\Longrightarrow\; \lambda = \pm i\omega_0,$$

这里 $i = \sqrt{-1}$，满足 $i^2=-1,\; i^3=-i,\; i^4=+1$ [2]。于是最一般的解可写为

$$x(t) = c_+ e^{i\omega_0 t} + c_- e^{-i\omega_0 t},$$

其中 $c_+, c_-$ 原则上可以是复数 [2]。文献 [1] 采用等价写法 $q(t) = \alpha e^{i\omega t} + \alpha^{*} e^{-i\omega t}$，星号表示复共轭（如 $(2+3i)^* = 2-3i$）[1][2]。文献 [3] 同样直接指出，形如 $x = \exp(\pm i\omega t)$ 的复指数函数构成自由谐振子的解。文献 [4] 则把三角形式 $x(t) = A\sin(\omega t) + B\cos(\omega t)$ 与指数形式 $x(t) = Ce^{i\omega t} + De^{-i\omega t}$ 并置比较，正是通过欧拉公式完成两者的对接。

值得注意的是一个表面上"自由度过多"的疑问：每个复数 $z = a+ib$ 含实部与虚部，似乎一般解含有 4 个实参数 [2]。但由于原方程是实系数方程、物理量取实部（或虚部）后才有意义，实际独立实常数只有 2 个，即振幅与相位 [2][6]。

## 由复数指数回到三角函数：欧拉公式的桥梁作用

把 $e^{i\omega_0 t}$ 展开为幂级数并按实部、虚部归并，

$$e^{i\omega_0 t} = 1 + i\omega_0 t + \frac{(i\omega_0 t)^2}{2!} + \frac{(i\omega_0 t)^3}{3!} + \cdots = \cos(\omega_0 t) + i\sin(\omega_0 t),$$

其中实部恰好是余弦的幂级数、虚部恰好是正弦的幂级数——这就是著名的欧拉公式 [2]。该推导所用的幂级数定义与 wiki 中 [[三角函数的幂级数定义]] 一致，可互为佐证。

由 $e^{\pm i\omega_0 t} = \cos(\omega_0 t) \pm i\sin(\omega_0 t)$ 可反解出 [2]

$$\cos(\omega_0 t) = \frac{e^{i\omega_0 t} + e^{-i\omega_0 t}}{2}, \qquad \sin(\omega_0 t) = \frac{e^{i\omega_0 t} - e^{-i\omega_0 t}}{2i}.$$

这正是 [[三角函数的指数表示]]。该互化关系使"三角解"与"复指数解"成为同一物理对象的两套书写，也正是振动计算中大量使用复指数的原因：求导、叠加、乘除振幅相位时，复指数形式远比三角函数形式简洁 [2][7]。

## 简谐振动的三种等价表示

中文教学文献通常把简谐振动归纳为三种表示法：三角函数表示、旋转矢量表示与复数表示 [8][9][10]。

- **三角函数表示**：$x = A\sin(\omega t + \varphi)$，由此求导可得速度 $\dot{x} = A\omega\cos(\omega t+\varphi)$ 与加速度 [8]。
- **旋转矢量（旋矢量）表示**：匀速旋转矢量的投影即简谐振动，其与横坐标投影所给出的简谐振动在幅值、频率上完全一致 [9][10]。
- **复数表示**：简谐振动 $s(t) = A\cos(\omega t + \varphi_0)$ 可用复数 $s(t) = A e^{i(\omega t + \varphi_0)}$ 的实部或虚部来表示 [6]；其数学基础即欧拉公式 [9]。

复数表示的优势在于：振幅 $A$ 与初相位 $\varphi_0$ 分别对应复数的模与辐角，因而"复平面上的旋转向量"可以在同一次运算中同时给出振幅与相位 [7]。此外，矢量图解与复数表示在合成两个同方向、同频率简谐振动时等价，是两个相互垂直、同频率简谐振动合成等问题的标准工具 [10]。

## 从单个简谐振动到 Fourier 分解

真实振动信号通常不是单一频率的简谐振动。若 $f(t)$ 是周期为 $T$ 的振动信号，按 Fourier 级数理论可展开为不同频率、振幅、相位的正弦项之和 [11]：

$$f(t) = a_0 + \sum_{n=1}^{\infty}\left[ a_n \cos\left(\frac{2\pi n t}{T}\right) + b_n \sin\left(\frac{2\pi n t}{T}\right)\right],$$

其中 $a_0$ 为常数项（直流分量），$a_n, b_n$ 为第 $n$ 次谐波频率 $n/T$ 处的 Fourier 系数 [11]。这些系数可由实验数据经积分求得 [11][14]：

$$a_0 = \frac{1}{T}\int_0^T f(t)\,dt,\quad a_n = \frac{2}{T}\int_0^T f(t)\cos\frac{2\pi n t}{T}\,dt,\quad b_n = \frac{2}{T}\int_0^T f(t)\sin\frac{2\pi n t}{T}\,dt \;(n\ge 1).$$

另一种广泛使用的写法是在 $[0, 2\pi]$ 上取 $a_n = \frac{1}{\pi}\int_0^{2\pi} f(x)\cos nx\,dx$、$b_n = \frac{1}{\pi}\int_0^{2\pi} f(x)\sin nx\,dx$ [14]。**注意：这两组归一化常数并不相同**，属于典型的记法约定差异（见下文"矛盾与缺口"）。

Fourier 级数有两种等价形式：三角形式与指数形式 [15]

$$x(t) = a_0 + \sum_{n=1}^{\infty}\left[a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t)\right] = \sum_{n=-\infty}^{\infty} c_n e^{jn\omega_0 t}.$$

指数形式与三角形式的等价性正是通过欧拉公式建立的 [15]，并可借助函数的奇偶分解（偶部对应余弦项、奇部对应正弦项）导出 [15]；奇偶性概念见 [[函数的奇偶性与周期性]]。这一步说明：欧拉公式不只是"把简谐振动写成复数"的书写技巧，而是 Fourier 分析得以以复指数为自然语言的底层原因 [13]。

## 历史脉络：从振动弦到频谱分析

Fourier 分析的成长与振动问题密不可分 [13]：

- 1754 年，Alexis Clairaut 用离散 Fourier 变换的雏形计算轨道，被描述为"DFT 的第一个公式"；1759 年 Joseph Louis Lagrange 在计算振动弦的三角级数系数时使用了类似方法。技术上，Clairaut 的工作是纯余弦级数（离散余弦变换的一种形式），Lagrange 的工作是纯正弦级数（离散正弦变换的一种形式）[13]。
- 1805 年，Gauss 在一次真正的余弦＋正弦 DFT 中将其用于小行星轨道的三角插值 [13]。
- 欧拉与 Lagrange 都曾对振动弦问题做离散化处理，用的是今天所谓的"采样" [13]。
- Daniel Bernoulli 与 Leonhard Euler 已引入函数的三角表示，Lagrange 已给出波动方程的 Fourier 级数解；Fourier 本人的贡献主要在于大胆断言"任意函数都可用 Fourier 级数表示"[13]。

换言之，"振动弦"问题同时是振动理论与 Fourier 分析的共同起点，而欧拉公式正是连接两者的技术枢纽。Fourier 分析后发展为调和分析（harmonic analysis），并且是表示论（representation theory）的早期实例 [13]。

## 应用案例

- **机械振动分析**：用复平面上的旋转向量表示简谐振动，可方便地计算振幅、相位等参数；有资料给出"简谐振动模拟器"式的实现 [7]。
- **车辆悬架振动分析**：对车轮悬架系统的周期振动信号拟合 Fourier 模型，识别贡献于整体振动模式的主导频率及其振幅和相位；实际计算用 Matlab 的 `fft()` / `ifft()` 对离散采样做积分近似 [11]。
- **物理教学中的振动合成**：相位差、简谐振动的能量与判别、两个同方向同频率简谐振动的合成、复数表示（欧拉公式）与矢量图解等 [10]。

## 矛盾与缺口

1. **虚数单位的记法冲突**：文献 [2] 明确指出，部分教材用 $j$ 而非 $i$ 表示 $\sqrt{-1}$，容易造成混淆；工程与信号处理文献中的 $e^{jn\omega_0 t}$ 记法即属此类 [2][15]。
2. **Fourier 系数的归一化约定不一致**：文献 [11] 使用 $\frac{2}{T}\int_0^T$（周期 $T$ 上），文献 [14] 使用 $\frac{1}{\pi}\int_0^{2\pi}$（周期 $2\pi$ 上）；文献 [14] 还自承"有些作者把常数项写成 $a_0$"[14]，不同教材对常数项与系数的取法存在分歧。这在比对不同来源的公式时必须校验。
3. **"应用领域"的边界模糊**：本主题究竟应界定为"欧拉公式与简谐振动复数表示"（狭义），还是应涵盖 Fourier 级数、Fourier 变换直至频谱分析的整条链路（广义），现有来源并未给出统一定义。本页面采取广义口径，但这一选择值得确认。
4. **阻尼振动、受迫振动与共振缺失**：现有来源全部集中于无阻尼自由振动与周期信号分解，未覆盖阻尼项、受驱动项与共振现象 [1]–[15]。
5. **来源层级偏低**：除 Wikipedia 与 LibreTexts 外，多数来源为课程讲义、科普视频与博客 [4][5][7][8][9][10]，缺少振动理论权威教材的系统表述，尚未形成可交叉验证的严格推导链。
