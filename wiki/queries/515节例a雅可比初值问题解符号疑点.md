# 5.1.5 节例 (a) 中 h(t) = −t − t₀ 是否应与初值条件一致？

## 问题

例 (a) 中，雅可比初值问题为

$$-h'' = 0 \text{ 在 } [t_0, t_1] \text{ 上}, \quad h(t_0) = 0, \quad h'(t_0) = 1.$$

源文给出的解为

$$h(t) = -t - t_0.$$

该式在 $t = t_0$ 处取值 $-2t_0$，导数恒为 $-1$，与初值 $h(t_0)=0$、$h'(t_0)=1$ 均不符。

## 推断

$\sqrt{1+q'^2}$ 型被积函数下该初值问题的正确解应为 $h(t) = t - t_0$（或含正号的线性函数）。源文的

$$h(t) = -t - t_0$$

疑为 $h(t) = t - t_0$ 的排版／转录讹误。

## 待确认

- 原文所印符号究竟为何？
- 若确为负号，则后文「仅有单个零点在 $t_0$」的结论是否仍然成立？（对 $h(t)=-t-t_0$，零点是 $t=-t_0$，一般不在 $t_0$。）
