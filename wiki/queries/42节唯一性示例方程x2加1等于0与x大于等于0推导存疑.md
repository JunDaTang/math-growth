# 4.2 节唯一性示例方程 x²+1=0 与「由 x ≥ 0」的推导是否讹误？

**问题一：示例方程的选择。** 4.2.3 节以「至多有一个正实数 $x$ 使得 $x^2 + 1 = 0$」（4.7）作为唯一性证明的范例。该命题为真但平凡（实际上没有正实数解），随后 4.2.4 节又用同一个方程 (4.7) 说明「唯一性不等于存在性」。需确认原书是否确实以这个无解方程作为唯一性证明的示例，还是排版/OCR 使得本应为 $x^2 = 2$ 一类的方程被写成了 $x^2 + 1 = 0$。

**问题二：「由 $x \geqslant 0$」的推导。** 4.2.4 节论证 (4.7) 无实数解时写道「假如 $x$ 是 (4.7) 的一个实数解，则由 $x \geqslant 0$ 我们立刻得到关系 $x^2 + 1 > 0$」。若 $x$ 是解则 $x^2 = -1$，此时并不能得到 $x \geqslant 0$；合理的依据应为「由 $x^2 \geqslant 0$ 得 $x^2 + 1 > 0$」。该处是否为 OCR 或译文讹误，需核对原文。

**尚待核实**：示例方程的原始形式；「$x \geqslant 0$」是否应为「$x^2 \geqslant 0$」。
