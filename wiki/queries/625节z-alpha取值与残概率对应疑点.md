# 6.2.5.5 节 z_α 取值与残概率 α 的对应关系疑点

## 原文表述

> 对于 $\alpha = 0.01$（或者 0.05 和 0.1），我们有 $z_{\alpha} = 1.6$（相应地 2.0 和 2.6）。

## 疑点

$z_\alpha$ 由等式 $2\Phi_0(z_\alpha) = 1 - \alpha$ 确定，即标准正态分布的双侧 $1-\alpha$ 分位数。按此定义，

| $\alpha$ | 应有 $z_\alpha$ |
|----------|------------------|
| 0.10 | ≈ 1.64 |
| 0.05 | ≈ 1.96 |
| 0.01 | ≈ 2.58 |

而原文给出的配对是 0.01 → 1.6、0.05 → 2.0、0.1 → 2.6，即 $\alpha$ 与 $z_\alpha$ **同向变化**，与分位数的反单调关系相反。

## 可能的解释

1. **数值次序颠倒**：原文想表达的可能是「$\alpha = 0.1$（或者 0.05 和 0.01），$z_\alpha = 1.6$（相应地 2.0 和 2.6）」，即三组配对整体反序书写；
2. **不同约定**：$\alpha$ 在原文某处被用作单侧概率或「置信水平」而非残概率——但本节已明确把 $\alpha$ 定义为残概率（结论不正确的概率）；
3. **取整与口径差异**：1.6/2.0/2.6 与 1.64/1.96/2.58 的差异恰好像是对后者的粗略取整，支持解释 1。

## 影响范围

- 6.2.5.5 的判决规则 (6.25) 与算例 (6.26)：算例用 $\alpha = 0.05$、$z_\alpha = 2$，若按标准分位数则 $z_{0.05} \approx 1.96$，区间半宽 $0.05 \times 1.96 = 0.098$ 与原文 $0.05 \times 2 = 0.1$ 相差很小，结论不变；
- 6.2.5.6 的 $p_\pm$ 公式与二次不等式 (6.28) 同样依赖 $z_\alpha$ 的取值。

请对照《数学指南》原书（表 0.34 与 6.2.5.5 节的排版）确认三组配对的原始顺序，并决定是否需在 wiki 中改为「$\alpha = 0.1 / 0.05 / 0.01$ 对应 $z_\alpha = 1.6 / 2.0 / 2.6$」的表述。
