# 1.9.1 节坐标收敛性中 rₙ → ν 是否应为 γₙ → γ

## 问题

在 1.9.1 节「坐标表示」部分，原文给出坐标收敛性时写作：

```
lim_{n→∞} a_n = a
当且仅当 n → ∞ 时  α_n → α,  β_n → β,  r_n → ν
```

前两个分量使用 αₙ → α、βₙ → β，第三个分量却写作 `r_n → ν`。

## 疑点

- 按前文约定 aₙ = αₙ i + βₙ j + γₙ k，第三个分量应为 **γₙ**（希腊字母 γ 的转写），而非拉丁字母 r（r 在本节已被占用为位置向量 r(t)）。
- 右端的极限值按体例应为 **γ** 而非 ν。

因此 `r_n → ν` 疑为 `γ_n → γ` 的 OCR／转写讹误。

## 影响范围

若确认，涉及 [[findings/向量极限的坐标收敛性判据]] 与 [[concepts/向量函数的坐标表示]] 的表述；不影响数学结论本身。
