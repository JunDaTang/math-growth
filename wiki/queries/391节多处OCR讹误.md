# 3.9.1 节多处 OCR 讹误，应如何恢复？

对《数学指南——实用数学手册》3.9.1 节抽取文本的通读显示，存在一批几乎可确定的 OCR/转录讹误，需要对照纸质原书核对。已识别的候选包括：

| 原文（抽取结果） | 疑似应作 | 依据 |
|------|------|------|
| 侠义相对论 | 狭义相对论 | 上下文多次出现 |
| 伪黎明曼时空流形 | 伪黎曼时空流形 | 「黎曼」的常见误识 |
| 四维伪黎明曼时空 | 四维伪黎曼时空 | 同上 |
| 现代量子力量 | 现代量子力学 | 主题为量子力学 |
| 希尔伯特定空间 | 希尔伯特空间 | 同段反复使用 |
| 自然算子 | 自伴算子 | 量子力学标准术语 |
| 自旋脉冲 | 自旋（角动量） | 自旋假设语境 |
| 辛力学 | 辛几何 | 该段开篇即「辛几何建立在…」 |
| 低维索群 | 低维李群 | 例外同构语境 |
| $SL(z,\mathbb{C})$ | $SL(2,\mathbb{C})$ | 与共形几何段一致 |
| $SO^{+}(3)$（万有覆叠群例 iii） | $SO^{+}(3,1)$？ | 与共形几何段不一致 |
| 「李群 $\mathcal{L}(G)$ 包含了李群 $G$…」 | 「李代数 $\mathcal{L}(G)$…」 | 记号 $\mathcal{L}(G)$ 为李代数 |

此外，流形段落处的脚注标记 $^{1)}$ 未落地，其脚注内容缺失（参看 [[389节脚注与星号标记未落地]] 等同类问题）。

**待决问题**：这些讹误哪些是纯 OCR 层面的（可据上下文直接恢复），哪些可能涉及原书排版或抽取流程的系统性缺陷（如脚注、图像、公式下标丢失）？是否需要为 3.9 节建立统一的勘误清单？
