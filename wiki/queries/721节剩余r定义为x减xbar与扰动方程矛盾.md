# 7.2.1.7 节剩余 r 定义为 x − x̄ 与扰动方程是否矛盾？

## 疑点

7.2.1.7 节先写道：

> 若在计算近似解 $\bar{x}$ 的同时，也计算亏量或剩余 $r := x - \bar{x}$，则 $\bar{x}$ 可看作扰动方程组 $A\bar{x} + (b - r) = 0$ 的准确解。

随后又写「误差向量 $z := x - \bar{x}$ 满足方程组 $Az + r = 0$」。

若 $r := x - \bar{x}$，则 $r$ 与 $z$ 是同一个量，无法同时满足上述两处用法；且由 $A\bar{x} + (b - r) = 0$ 可直接解出 $r = A\bar{x} + b$，即**剩余**才是 $A\bar{x} + b$（或其相反数），而非解的误差。

## 判断依据

- 由 $Ax + b = 0$ 与 $r = A\bar{x} + b$，有 $A(x - \bar{x}) + r = 0$，即 $Az + r = 0$，与源文档后一式一致。
- 由此推得后排的相对误差界 $\|z\|/\|x\| \leqslant \kappa(A)\cdot\|r\|/\|b\|$ 方成立。
- 因此「$r := x - \bar{x}$」应为「$r := A\bar{x} + b$」（或等价地减去 $b$ 的常数项形式）。

## 相关的第二个问题

同节的输入扰动方程写作 $(A + \Delta A)(x + \Delta x) = 0$，但随后的误差估计中却出现 $\|\Delta b\|/\|b\|$ 项；按非齐次方程组的扰动语义，扰动方程应为 $(A + \Delta A)(x + \Delta x) + (b + \Delta b) = 0$。

## 待确认

两处是否均为排印或 OCR 讹误；若是，应分别订正剩余的定义与扰动方程的形式。
