# Research: 核对表 0.6 未导入的脚注 1) 与 2) 的内容

# 表 0.6 未导入脚注 1) 与 2) 的内容核对

## 研究问题与现状

《数学指南——实用数学手册》（[[数学指南-实用数学手册]]）第 0 章 0.1.5 节“正多面体的体积与表面积”所附的表格，在中文版中编号为**表 0.6**。该表在导入 wiki 时（[[10-数学指南实用数学手册--15-015-正多面体的体积与表面积--111x62u]]），表体公式已录入，但表下以 **1)** 与 **2)** 标出的两条脚注正文未被一并导入。

本页的任务是：在无法直接读取原书 p.35 的情况下，依据现有资料核对这两条脚注**可能的内容**，给出每一条候选假设的支撑证据、可否证伪的判据，以及可用于验证的数值关系。这一核对与表 0.5 的同类问题（[[立体图形公式表中的记法疑问]]）互为姊妹条目。

## 一、表 0.6 的定位

目录与版权信息确认了编号归属：

- 中文版目录列出 0.1.4 立体图形的体积与表面积（p.33）、**0.1.5 正多面体的体积与表面积（p.35）**、0.1.6 n 维球的体积与表面积（p.36）[6][7]。
- 德文原书对应章节依次为 0.1.4 „Volumen und Oberflächen von Körpern“、0.1.5 „Volumen und Oberfläche der regulären Polyeder“，随后是 n 维球 [1]。

因此**表 0.5 → 0.1.4 立体图形，表 0.6 → 0.1.5 正多面体**。表 0.6 的脚注必然讨论正多面体（即柏拉图立体），而不会涉及椭球、球扇形等 0.1.4 的对象。

## 二、表 0.6 主体可核验的内容

### 2.1 五个正多面体与四个量

表中对象为五个正多面体（[[正多面体]]）：正四面体、正六面体（立方体）、正八面体、正十二面体、正二十面体 [2][4]。以棱长 a 为唯一参数，表体给出体积 V、表面积 O、外接球半径 R（德文 Umkugelradius）与内切球半径 r（Inkugelradius）[1][2][3]。

数值可用精确式逐项复核（下表“精确值”列由 [3][5] 的公式计算）：

| 立体 | Schläfli 记号 | V | O | R | r |
|---|---|---|---|---|---|
| 正四面体 | {3,3} | √2/12·a³ ≈ 0.1179a³ | √3·a² ≈ 1.732a² | √6/4·a ≈ 0.6124a | √6/12·a ≈ 0.2041a |
| 正六面体 | {4,3} | a³ | 6a² | √3/2·a ≈ 0.8660a | a/2 = 0.5a |
| 正八面体 | {3,4} | √2/3·a³ ≈ 0.4714a³ | 2√3·a² ≈ 3.464a² | √2/2·a ≈ 0.7071a | √6/6·a ≈ 0.4082a |
| 正十二面体 | {5,3} | (15+7√5)/4·a³ ≈ 7.6631a³ | 3√(25+10√5)·a² ≈ 20.6457a² | (√3/2)·φ·a ≈ 1.4013a | √(250+110√5)/20·a ≈ 1.1135a |
| 正二十面体 | {3,5} | (5/12)(3+√5)·a³ ≈ 2.1817a³ | 5√3·a² ≈ 8.6603a² | √(10+2√5)/4·a ≈ 0.9511a | √3(3+√5)/12·a ≈ 0.7558a |

表中 φ = (1+√5)/2。来源 [2] 给出的三位有效数字（V = 0.118 / 1 / 0.471 / 7.66 / 2.18；O = 1.73 / 6 / 3.46 / 20.6 / 8.66；R = 0.612 / 0.866 / 0.707 / 1.40 / 0.951；r = 0.204 / 0.5 / 0.408 / 1.11 / 0.756）与精确值完全一致，可作为脚注内容的自洽性标尺。来源 [5] 独立给出正四面体 O = a²√3、V = (1/12)a³√2 与正六面体 O = 6a²、V = a³，同样吻合。

### 2.2 通用公式与 Schläfli 记号

一般情形的封闭公式以 Schläfli 记号 {p, q} 表出 [3]：

- 体积：V = [p·q·a³ / (24 − 6(p−2)(q−2))] · cot²(π/p) · tan(β/2)
- 表面积：A_O = [p·q·a² / (4 − (p−2)(q−2))] · cot(π/p)
- 外接球半径：r_u = (a/2) · tan(π/q) · tan(β/2)

其中 β 为相邻面之间的二面角（Diederwinkel）[3]。正交的多面体计数公式 [15] 给出面数 N₂ = 4n/(2m+2n−mn)，并指出 m ≥ 3、n ≥ 3 的**整数解只有柏拉图五体**。

### 2.3 与球的体积/表面积之比

来源 [2] 另外给出各正多面体占其外接球的份额：体积份额为 12.3%、36.8%、31.8%、66.5%、60.5%，表面积份额为 36.7%、63.7%、55.1%、83.7%、76.2%（顺序均为正四面体、立方体、正八面体、正十二面体、正二十面体），并据此评论正十二面体“最接近球”。用 2.1 的数值复核：正四面体 0.1179/(4π/3·0.6124³) = 12.25%，表面积 √3/(4π·0.6124²) = 36.76%，与 [2] 相符。

### 2.4 二面角

来源 [2] 列出相邻面夹角（内二面角）：正四面体 70.5°、立方体 90°、正八面体 109.5°、正十二面体 116.6°、正二十面体 138.2°。精确值为 arccos(1/3)、90°、arccos(−1/3)、arccos(−1/√5)≈116.565°、arccos(−√5/3)≈138.190°。来源 [12] 则从“沿公共棱拼装面片”的应用角度编制了同类二面角表，其角度为**定向夹角**约定，与 [2] 的内角约定在数值上互为补角，引用时须注意。

## 三、脚注 1) 与 2) 的候选内容

现有来源均未给出脚注原文（[6][7] 仅为目录页与版权页），故只能给出候选假设并排序。

### 候选 A：黄金比 φ（最可能）

若脚注 1)、2) 分别挂在正十二面体、正二十面体两行（或两条公式）下，内容极可能是“式中出现黄金比 φ = (1+√5)/2”；若脚注统一挂在表下，则可能是对 φ 的一次性说明。证据链相当完整：

- 这两个体的 V、O、R、r 公式必须包含 √5 才能给出正确数值（见 2.1）。
- 由 [3] 的通用公式反解可得 tan(β/2) 的精确值：{3,3}→1/√2，{4,3}→1，{3,4}→√2，{5,3}→**φ**，{3,5}→**φ²**。即正十二面体与正二十面体恰以 φ 的幂与其余三体区分开。
- 正二十面体的顶点坐标条件导出方程 t² + t − 1 = 0，其正根 t = (−1+√5)/2，并等同于正五边形边长与对角线之比 [14]。

### 候选 B：正多面体只有五种（欧拉多面体公式）

脚注若用于说明“为什么只有五种”，其依据在来源中反复出现：

- 欧拉多面体公式 e + f = k + 2（[[欧拉多面体公式]]，[[欧拉]]），[2][4] 均列出 e、f、k 表（正四面体 4/4/6、立方体 8/6/12、正八面体 6/8/12、正十二面体 20/12/30、正二十面体 12/20/30）。
- 顶点处面角和判据：Σ(V) = 180°（正四面体）、240°（正八面体）、300°（正二十面体）、270°（立方体）、324°（正十二面体），均小于 360° [4]。
- 棱数计数：1/q − 1/6 = 1/E 只允许 q = 3, 4, 5，对应 E = 6, 12, 30 [11]；[15] 的 N₂ 公式给出同一结论。

值得注意的是，0.1.5 节紧接 0.1.6 “n 维球的体积与表面积”（[[n维球的体积与表面积]]），因此脚注也可能承担**向高维推广的交叉引用**；四维正多胞体的高维类比满足“超体积 = 表体积 × 胞心距 / 4”，与三维的“V = 表面积 × 面心距 / 3”同构 [9]。

### 候选 C：记号与命名约定

脚注亦可能只是表格约定的说明，例如：a 为棱长；R 为外接球半径、r 为内切球半径 [1][2][3]；正六面体即立方体（Hexaeder / Würfel 两种德文名并存 [2][4]）。若如此，脚注 1) 与 2) 应对应“参数定义”与“同一体的异名”两件事。

### 候选 D：二面角约定的限定

若表内或表下给出相邻面夹角，脚注可能声明该角是**内二面角**（面与面的夹角）而非法向量夹角或拼装用的定向角（见 2.4 的约定差异 [2][12]）。

## 五、矛盾、歧义与空白

1. **脚注原文缺位**：没有任何一份资料直接转录表 0.6 下方的 1)、2) 两条脚注；[6][7] 是目录级文本，不覆盖正文。
2. **脚注挂靠位置不明**：无法判断两条脚注是统一置于表下，还是分别挂在正十二面体与正二十面体行。这直接决定候选 A 是否成立（若是两行分挂，则“φ”与“φ²”分别对应两条脚注的可能性极大）。
3. **二面角约定歧义**：[2] 用内角（116.6°、138.2°），[12] 用定向拼装角，两者互补；若脚注引用后者数值会在 116.6°/63.4° 之间产生矛盾。
4. **符号体系差异**：德文原书以 R、r 表外接/内切球半径 [1]，而 [3] 用 r_u 与 β 等另一种记号；中文版采用哪一套需以原书 p.35 为准。
5. **版本差异**：0.1.4/0.1.5/0.1.6 的分节在 Teubner 历代版本中有调整 [1][7]，表号与脚注号可能随版次变动。
6. **数值舍入**：[2] 只给三位有效数字，与精确值存在 ±0.05 量级的舍入差，不宜用来反推脚注的确切公式形式。

## 七、结论

在现有资料范围内可以确认的是：**表 0.6 即 0.1.5 节的正多面体表**，其主体为五体 × 四量（V、O、R、r），并可与 Schläfli 记号下的通用公式、二面角数值、以及占外接球份额的百分比互相验证 [1][2][3][5]。

对未导入的脚注 1) 与 2)，资料支持度最高的两项候选为：

- **黄金比 φ**——由 tan(β/2) 在正十二面体、正二十面体上恰取 φ 与 φ²，以及 [14] 的 t² + t − 1 = 0 佐证，若脚注分挂两行则几乎可以确认；
- **正多面体只有五种及其欧拉公式依据**——由 [[欧拉多面体公式]]、Σ(V) < 360° 与棱数方程 1/q − 1/6 = 1/E 佐证 [2][4][11][15]。

记号约定（R、r、a 的含义，正六面体＝立方体）与二面角约定（内角/定向角）为次一级候选，通常也确实以脚注形式出现在同类表中 [1][12]。上述均为假设而非定论：**在获得原书 p.35 或德文母本 0.1.5 节正文之前，脚注 1)、2) 的内容应标记为待核实**，其结论应回填至 [[10-数学指南实用数学手册--15-015-正多面体的体积与表面积--111x62u]]，并与 [[立体图形公式表中的记法疑问]] 一并归档。
