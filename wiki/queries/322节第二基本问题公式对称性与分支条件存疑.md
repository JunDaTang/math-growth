# 3.2.2 节第二基本问题公式的对称性与分支条件是否可疑？

## 问题

《数学指南——实用数学手册》3.2.2.2 节（[[后向切割]]）给出的辅助量公式为

```
x₁ = x_A + (y_C − y_A) · cot α
y₁ = y_A + (x_C − x_A) · cot α
```

$x$ 方向使用纵坐标差 $(y_C - y_A)$，$y$ 方向使用横坐标差 $(x_C - x_A)$，两者都乘以同一个 $\cot\alpha$。这种「交叉搭配」在几何上对应绕点旋转 $90°$ 的方向，可能是正确的旋转公式，也可能在 OCR 或排印中发生了变量互换。同理，$x_2$、$y_2$ 使用 $(y_B - y_C)$ 与 $(x_B - x_C)$ 搭配 $\cot\beta$。

## 待核验点

1. 辅助量的交叉搭配是否为转动公式的正确形式，还是应有符号或变量的互换？
2. 最终解式中 $\mu < \eta$ 时取 $x = x_C - (y - y_C)\mu$，$\eta < \mu$ 时取 $x = x_1 + (y - y_1)\eta$，该分支判据与两支取解式是否自洽？当 $\mu = \eta$ 时公式无定义，这与「四点不共圆才有解」的条件是何关系？
3. $y$ 的主式分母为 $\mu + \eta$，其中 $\eta = 1/\mu$，该式是否只是把两条直线交点写成对称形式？

## 现状

源文件未给证明，无法在本源内部自洽验证。需要对照《数学指南》原书或另找测量学教材后方可判定是公式本身的形式还是录入讹误。
