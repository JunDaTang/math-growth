# 2.1.3 节运算法则中的「α ∈ C」是否应为黑板体 ℂ？

## 问题

2.1.3 节「运算法则」一段写作：

> 对于 `A, B, C ∈ Mat(m,n)` 及 `α ∈ C`，有……

同段的结论却写作「集合 `Mat(m,n)` 形成一个**复数域**上的线性空间」，且 `GL(n,ℂ)` 在本文其它位置使用黑板体 ℂ。故此处 `α ∈ C` 中的 `C` 很可能应为复数域的黑板体记法 `ℂ`，而非某个矩阵 `C`（且该式中的 `C` 已用于表示矩阵，存在记号冲突）。

## 影响

- 若 `C` 确为复数域，则与本节 `GL(n,ℂ)` 的记法不一致。
- 若 `C` 确为矩阵，则该式在语法上说不通（标量不可能是矩阵）。
