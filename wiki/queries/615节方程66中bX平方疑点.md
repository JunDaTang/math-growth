# 6.1.5 节 (6.6) 中的 bX² 是否应为 bX？

## 疑点

《数学指南——实用数学手册》6.1.5 节把最小二乘问题写作

```
(Y − a − bX²) 的均值 = min,  a, b ∈ ℝ        (6.6)
```

## 冲突证据

- 正文紧接 (6.6) 的说明是：「也就是说，我们要寻找一个**最密切逼近 $Y$ 的线性函数** $a + bX$」——明确写的是 $a + bX$，不是 $a + bX^2$。
- 同一小节 (b) 项中的残差公式印作 $\overline{(Y - a - bX)^2} = (\Delta Y)^2(1-r^2)$，用的是 $bX$。
- 回归直线的解 $\overline{Y} + r\frac{\Delta Y}{\Delta X}(X - \overline{X})$ 与 $r = \operatorname{Cov}(X,Y)/(\Delta X\Delta Y)$ 都只在线性模型下成立；若目标是拟合 $a + bX^2$，解不会是这条直线。
