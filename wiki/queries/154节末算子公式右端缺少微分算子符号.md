# 1.5.4 节末算子公式右端写作 (1/r)∂r 是否转写讹误

## 问题

1.5.4 节第二个方法末尾给出

```
Δ = ∂_x² + ∂_y² = ∂_r² + (1/r²) ∂_φ² + (1/r) ∂r
```

其中右端最后一项写作 $\frac{1}{r}\partial r$，缺少作用于函数的下标，也没有明确的微分算子记号。

## 分析

按本节上下文，该式声明「这就是变换后的公式 (1.64)」，而 (1.64) 为

```
Δf := f_rr + (1/r²) f_φφ + (1/r) f_r,  r > 0
```

两式对照可知，末项应对应 $\frac{1}{r} f_r$，即该处的「$\partial r$」应当是 $\partial_r = \partial/\partial r$（可能与后面被省略的作用对象发生了排版上的合并或丢失）。

## 状态

未决。需要核对纸质原书版式以确认原文写法，以及是否只是电子转写过程中下标 $r$ 丢失所致。相关算子记号讨论见 [[concepts/微分算子]]。
