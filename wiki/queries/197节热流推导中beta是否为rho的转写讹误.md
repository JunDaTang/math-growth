# 1.9.7 节热流推导中 β 是否为 ρ 的转写讹误

**问题**：1.9.7 节热流动机中，取极限前的差分式在源文档里写作

```
( ρ(x,t+Δt) − β(x,t) ) / Δt = s μ ( T(x,t+Δt) − T(x,t) ) / Δt
```

左端第二项的下标写作 $\beta(x,t)$，而按上下文该处应为热密度 $\rho(x,t)$，否则与随后取极限得到的 $\rho_t = s\mu T_t$ 不一致。

**判断倾向**：极可能为 OCR/转写讹误（$\rho$ 误作 $\beta$），但需核对原书排版（可能为 $\rho$ 的某种花体或印刷体形近字符）。

**影响**：不影响最终结论 $\rho_t = s\mu T_t$，但影响转录准确性，见 [[findings/热密度时间导数公式]]。

**状态**：待核对原书。
