# 1.12.8.1 节格林函数构造中 y₂′(b) 初始条件的规范化系数疑义

## 问题

1.12.8.1 节在构造格林函数时给出的初始条件为：

$$
y_1(a) = 0, \quad y_1'(a) = 1, \quad y_2(b) = 0, \quad y_2'(b) = 1 / p(b) y_1(b).
$$

- 末一项在源中排作 `1 / p(b) y_1(b)`，按线性书写顺序既可读作 $\dfrac{1}{p(b)\,y_1(b)}$，也可读作 $\dfrac{1}{p(b)}\cdot y_1(b)$。
- 另一方面，拼接公式 $G(x,\xi) = y_1(x) y_2(\xi)$（$x \leqslant \xi$ 段）要使 $G$ 对称并满足 $-(pG_x)_x + qG = \delta$，通常要求 $y_1$ 与 $y_2$ 的朗斯基式取特定规范值。
- 源中 $y_1'(a) = 1$ 已固定 $y_1$ 的规范化，则 $y_2$ 的规范化常数应由 $p(b)$ 与 $y_1(b)$ 共同确定。

## 待查

- 原书中该初始条件的确切表达式与括号位置。
- 与 [[concepts/朗斯基行列式]] 的关系：该条件是否等价于规定 $p(b) W(y_1, y_2)(b) = 1$ 一类条件。
