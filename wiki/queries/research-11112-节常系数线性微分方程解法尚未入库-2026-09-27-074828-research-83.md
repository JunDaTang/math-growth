# Research: 1.11.1.2 节常系数线性微分方程解法尚未入库

# 常系数线性微分方程解法

## 概述

常系数线性微分方程指系数均为常数（实数或复数）的线性微分方程，其一般形式可写作

$$a_0 y + a_1 y' + a_2 y'' + \cdots + a_n y^{(n)} = 0$$

其中 $a_0,\dots,a_n$ 为常数，或写成 $n$ 阶非齐次形式

$$y^{(n)}(x) + a_1 y^{(n-1)}(x) + \cdots + a_{n-1} y'(x) + a_n y(x) = f(x),$$

这里的 $a_1,\dots,a_n$ 为实数或复数，$f$ 为已知函数，$y$ 为待求函数 [11]。这类方程有相对完备的代数化解法（特征方程法），是常微分方程理论中最基本、最成熟的部分之一。

本页综合现有来源整理其解法，并标注与手册章节的对应情况。需要指出，本节主题（「1.11.1.2 节常系数线性微分方程解法」）在现有 wiki 中尚无独立页面，本页即为对此缺口的补充；同时，该主题的章节归属存在疑点，详见下文「章节归属的疑点」一节。

## 历史背景：欧拉与指数函数

对常系数线性微分方程的研究可追溯到 [[欧拉]]（Leonhard Euler）。他引入指数函数 $e^x$，把它定义为方程 $f' = f$ 且 $f(0)=1$ 的唯一解。由此可知 $e^{cx}$ 的 $n$ 阶导数为 $c^n e^{cx}$，这一性质使得齐次常系数线性微分方程可以相当容易地求解 [11]。魏尔斯特拉斯意义下的[[幂级数逐项求导]]性质（见 [[复变函数]] 相关页面）也为指数函数解的形式提供了分析基础。

## 齐次方程与特征方程法

### 试解与特征方程

一种解线性微分方程的方法是[[欧拉]]发现的，他意识到这类方程的解都具有 $e^{zx}$ 的形式，其中 $z$ 是某个[[复数]] [1]。对一般齐次方程

$$\frac{d^n y}{dx^n} + A_1 \frac{d^{n-1} y}{dx^{n-1}} + \cdots + A_n y = 0,$$

设 $y = e^{zx}$，代入得

$$z^n e^{zx} + A_1 z^{n-1} e^{zx} + \cdots + A_n e^{zx} = 0.$$

两边除以 $e^{zx}$，便得到 $n$ 次方程

$$F(z) = z^n + A_1 z^{n-1} + \cdots + A_n = 0,$$

称为**特征方程** [1][11]。求出特征方程的根 $z_1,\dots,z_n$，即可组装出齐次方程的通解。

### 实系数情形的复根与实解

若系数 $A_i$ 都是实数，则[[复数]]根必成对出现：如果 $a + bi$ 是特征方程的根，那么 $a - bi$ 也是根。于是 $y = e^{(a+bi)x}$ 与 $y = e^{(a-bi)x}$ 都是解 [1]。由于解的任意线性组合仍是解，可取两者的平均与差商，借助 [[欧拉公式]] 把复解化为实解：

- $y_1 = e^{ax} \cos bx$
- $y_2 = e^{ax} \sin bx$

由此得到通解 $y = C_1 e^{ax}\cos bx + C_2 e^{ax}\sin bx$ [1]。

### 例：二重共轭复根

求 $y'' - 4y' + 5y = 0$ 的通解。其特征方程为

$$z^2 - 4z + 5 = 0,$$

它的根是 $2 + i$ 和 $2 - i$。于是通解为

$$y = C_1 e^{2x}\cos x + C_2 e^{2x}\sin x. \quad \text{[1]}$$

### 例：两相异实根

对 $y'' - 4y = 0$，可写为标准形式，其中 $a = 1$（$y''$ 的系数）、$b = 0$（无 $y'$ 项）、$c = -4$（$y$ 的系数）。特征方程

$$r^2 - 4 = 0$$

可用平方差分解，得 $r = \pm 2$，即两个相异实根 [12]。这一例子说明，二阶常系数齐次方程

$$a y'' + b y' + c y = 0$$

的特征根类型（两相异实根、重实根、共轭复根）分别对应不同的通解形式 [12][14]。

### 重根情形的处理

当特征方程出现重根时，需要在解中引入幂因子（典型地乘以 $x, x^2, \dots$），以保证得到 $n$ 个线性无关的解。这一步骤在来源 [1]-[14] 中常被概述而未逐项展开，属于需要在正式教材中补足的技术细节（参见「缺口与待补来源」）。

## 解空间的结构

### 线性算子与叠加原理

记微分算子

$$\mathcal{L}(y) = a_0 y + a_1 y' + \cdots + a_n y^{(n)}.$$

$\mathcal{L}$ 是线性算子，满足

$$\mathcal{L}(\lambda_1 y_1 + \lambda_2 y_2) = \lambda_1 \mathcal{L}(y_1) + \lambda_2 \mathcal{L}(y_2).$$

当 $f$ 为零函数时，若 $y_1, y_2, \dots, y_m$ 均为方程的解，则任意线性组合 $\lambda_1 y_1 + \cdots + \lambda_m y_m$ 仍是解。这说明齐次方程的所有解构成一个线性空间 $V$，称为方程的**解空间** [1]。这正是[[傅里叶通用方法]]中叠加原理（用于 [[波方程]]、[[热方程]] 等）的线性代数本质。

### 非齐次解构成仿射空间

设 $y^s$ 是非齐次方程 $\mathcal{L}(y) = f$ 的一个解函数，$y$ 是相应齐次方程 $\mathcal{L}(y)=0$ 的任意解。则和 $y^s + y$ 仍是非齐次方程的解。另一方面，若非齐次方程的两个解为 $y_1^s$ 与 $y_2^s$，则它们的差 $y_1^s - y_2^s$ 是齐次方程的解。这说明非齐次方程的所有解都可以写成

$$y^s + y, \quad y \in V$$

的形式。因此非齐次方程的所有解构成一个仿射空间 $V' = y^s + V$ [1]。

### 朗斯基行列式

在手冊体系中，判断一组解是否线性无关所用的是朗斯基行列式（Wronskian），《实用数学手册》将其列为「高阶线性微分方程」一节的第 1 个子目（8.4.1）[2]。它与上述解空间结构共同刻画了「通解 = 齐次通解 + 特解」这一基本结论。

## 非齐次方程的解法

欲得到非齐次线性微分方程的通解，通常先求出对应齐次方程的通解，再用**待定系数法**或**常数变易法**求出非齐次方程本身的一个特解，把它们相加即为非齐次方程的通解 [1]。

### 待定系数法

考虑方程

$$\frac{dy}{dx} = y + e^{2x}.$$

对应的齐次方程是 $\frac{dy}{dx} = y$，其通解为 $y = c e^{x}$ [1]。对于右端为指数函数、三角函数等特定形式的 $f$，可假定特解具有与 $f$ 相似的形式，代入原方程求出待定常数 [1][8]。更一般地，可利用叠加原理，把驱动力分解为若干基元驱动，分别求出特解再叠加 [8]。

### 常数变易法

当 $f$ 不具有待定系数法适用的形式时，可用常数变易法（日语：定数変化法）把齐次通解中的常数视为函数，从而构造特解 [1]。

### 一般性结论

综合上述，$n$ 阶常系数线性非齐次方程的通解结构为

$$y = y_{\text{齐次通解}} + y_{\text{一个特解}},$$

这与前面用仿射空间语言表述的结论一致 [1][14]。

## 相关解法与推广

### 拉普拉斯变换法

对于关联齐次方程为常系数的线性微分方程，其解可能通过积分形式表示出来；一阶变系数线性微分方程的解也可以表示为积分形式 [3]。在实际操作中，常系数线性微分方程（及方程组）常借助积分变换求解，这正是《数学指南》第 1.11 节「积分变换」中 [[queries/拉普拉斯变换]]（1.11.1）等方法的应用场景 [4]，也是该主题章节编号「1.11.1」的由来（详见下文）。

### 傅里叶方法与线性系统

把信号/驱动力分解为正弦波或复指数波的叠加，再对每个基元求特解并叠加，是求解线性微分方程的通用策略。以简谐振动方程为例，对方程两边做傅里叶变换即得代数方程 [8]。之所以能这样展开，是因为所分析的是线性系统；对非线性系统则不能这样操作 [8]。

### 谐振子方程

无阻尼简谐振子的运动微分方程为

$$\frac{d^2x}{dt^2} + \omega^2 x = 0, \quad \omega = \sqrt{k/m},$$

其通解为简谐函数

$$x(t) = C_1 \cos(\omega t) + C_2 \sin(\omega t) = A_0 \sin(\omega t + \psi_0),$$

描述物体位移随时间的变化 [9][10]。无激励时系统只有本征频率（谐振频率）有意义，通解可写作 $y = \bar{y} e^{\pm i\omega x}$ [6]。这是特征方程法在物理中最直观的应用实例。

### 常系数线性微分方程组与 Jordan 标准形

在常系数线性微分方程组中，可使用代数方法求解：借助线性代数中的 Jordan 标准形以及矩阵相似理论，给出一般解法 [5]。这一路径与单方程的取指数解是同一思想的矩阵推广。

## 章节归属的疑点

本页主题标为「1.11.1.2 节常系数线性微分方程解法」，但依据《数学指南——实用数学手册》的目录 [4]，第 1.11 节为「积分变换」，其子节依次为 1.11.1 拉普拉斯变换、1.11.2 傅里叶变换、1.11.3 Z 变换，而常微分方程位于第 1.12 节（含 1.12.4 初等解法、1.12.6 线性微分方程组和传播子等）。另一方面，《实用数学手册》把「常系数线性微分方程」列为 §8.4.3（属 §8.4 高阶线性微分方程）[2]。

因此，「1.11.1.2」这一编号与「常系数线性微分方程解法」的具体对应关系需核实，存在两种可能：

1. 该内容实为 1.11.1（拉普拉斯变换）中「用变换法解常系数线性微分方程」的解法小节；
2. 编号之误，实际指向 1.12 节（常微分方程）或《实用数学手册》§8.4.3。

建议以原始手册页面核对后再确定页面归属与交叉链接。
