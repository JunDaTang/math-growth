# 表 b 中两处数值的排版讹误

源文 0.5.4 节 [[表b第二类椭圆积分]] 中至少有两处数值与邻域数据、以及表 c 的交叉校核不符，疑为排版讹误。

## 疑点一

$\alpha = 10^\circ$、$\varphi = 40^\circ$ 处记为 `0.396 6`。

- 同一行（$\varphi = 40^\circ$）的值为 `0.698 1`（$\alpha = 0^\circ$）、`0.692 1`（$\alpha = 20^\circ$）、`0.685 1`（$\alpha = 30^\circ$）、`0.676 3`（$\alpha = 40^\circ$），均在 `0.67–0.70` 区间；
- 同列（$\alpha = 10^\circ$）的相邻值在 $\varphi = 30^\circ$ 处为 `0.522 9`、$\varphi = 50^\circ$ 处为 `0.869 8`，故 $\varphi = 40^\circ$ 处应在二者之间；
- $0.3966$ 既不符合行趋势也不符合列趋势，而 `0.696 6` 同时满足两者。

## 疑点二

$\alpha = 80^\circ$、$\varphi = 10^\circ$ 处记为 `1.173 7`。

- 同一行（$\varphi = 10^\circ$）的值为 `0.174 0`（$\alpha = 50^\circ$）、`0.173 9`（$\alpha = 60^\circ$）、`0.173 8`（$\alpha = 70^\circ$）、`0.173 6`（$\alpha = 90^\circ$）；
- 同列（$\alpha = 80^\circ$）在 $\varphi = 0^\circ$ 处为 `0.000 0`、$\varphi = 20^\circ$ 处为 `0.342 2`；
- 显然应为 `0.173 7`，首位数字 `1` 为衍字。
