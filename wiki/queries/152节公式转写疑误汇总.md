# 1.5.2 节公式与文字转写疑误汇总

## 待确认的疑点

1. **分解式中的自变量误写**：例 1 的中间结果转写为

   ```latex
   \boxed{f(\boldsymbol{p} + \boldsymbol{h}) - f(\boldsymbol{h}) = h_1 + r(\boldsymbol{h}),}
   ```

   按上下文（对 $f(\boldsymbol{x}) = x_1\cos x_2$ 在 $\boldsymbol{p}=(0,0)^{\mathrm{T}}$ 处作线性化）应为 $f(\boldsymbol{p} + \boldsymbol{h}) - f(\boldsymbol{p})$，即右端减号后应为 $\boldsymbol{p}$ 而非 $\boldsymbol{h}$。见 [[例1x1cosx2的弗雷歇导数]]。

2. **矩阵框内的多余逗号**：定义 (1.49) 之后，「存在一个」后面转写为

   ```latex
   \left| K \times N \text{ 阶矩阵 } \boldsymbol{f}'(p), \right|
   ```

   逗号似误置于框内（应位于框外，或本无逗号）。

3. **例 2 中漏写撇号**：线性映射情形转写为

   ```latex
   \boldsymbol{f}(\boldsymbol{p}) = \begin{pmatrix} a & b \\ c & d \end{pmatrix},
   ```

   按上下文应为 $\boldsymbol{f}'(\boldsymbol{p})$（雅可比矩阵），与紧随其后的 $\det \boldsymbol{f}'(\boldsymbol{p})$ 一致。见 [[线性映射的线性化是映射本身]]。

4. **一维反向证明的省略**：「反之……那么即得 (1.48)」未展开推导，属省略而非讹误，但若需完整复现证明，应补出由 $r(h) = o(|h|)$ 推差商的过程。

## 状态

以上各项均为**待人工核对原书**的转写疑点，不改变本节数学内容的结论。
