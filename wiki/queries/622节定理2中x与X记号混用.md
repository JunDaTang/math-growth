# 6.2.2 节定理 2 中 x 与 X 的记号是否混用？

## 现象

源文档 6.2.2.2 节的定理 2 写作：

(i) $P(a \leqslant x < b) = \Phi(b) - \Phi(a).$

(ii) $P(a \leqslant x \leqslant b) = \Phi(b + 0) - \Phi(a).$

(iii) $P(X = a) = \Phi(a + 0) - \Phi(a - 0).$

同一小节的分布函数定义使用大写 $X$ 表示随机变量（$\Phi(x) := P(X < x)$），而定理 2 的 (i)(ii) 却改用小写 $x$。按定义，$x$ 是实数轴上的自变量、$a, b$ 是实数，$P(a \leqslant x < b)$ 因此没有明确的含义；从上下文看应为 $P(a \leqslant X < b)$ 与 $P(a \leqslant X \leqslant b)$。定理 2 的 (iii) 使用大写 $X$，进一步显示 (i)(ii) 的记号为笔误。

## 关联的记号观察

- 6.2.2.2 的随机变量定义式在原文中写作 $X := E \to R$（应为 $X: E \to \mathbb{R}$）。
- 图 6.9 的图注写作"具有单位质量的点 $p$"，而正文例 1 使用点 $x_1$ 与质量 $p = 1$，图注中的点记号也可能不一致。

## 待处理

确认定理 2 (i)(ii) 中的 $x$ 是否统一应为 $X$；若确认，应在 [[分布函数]] 与 [[6222节分布函数定义与两个定理]] 中按修正后的记号记录，并核对是否需要一并修正 (i) 的左闭/右闭区间写法。
