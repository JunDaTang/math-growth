# Research: 手册表 0.14 汇总表内容缺失

# 手册表 0.14 汇总表内容缺失

## 概述

「表 0.14」是《[[数学指南-实用数学手册|数学指南——实用数学手册]]》第 0 章第 0.2 节「[[10-数学指南实用数学手册--11-02-初等函数及其图示--1o4awf0|初等函数及其图示]]」中用于汇总函数性质的一张表（Tab. 0.14）。从目前可获得的数字文本来看，该表的**正文内容大面积缺失**：检索到的片段 [1] 中仅保留了表题「函数的性质」以及若干行/列的标签词，表格本体（即每种性质对应的定义式、等价判据或几何解释）并未随文出现，原文以省略号「[...]」形式截断。因此本页的目标是：整理可辨认的线索、推断表内应有的内容，并标注仍无法确证的部分。

需要说明的是，表 0.14 本身属于手册中的辅助性速查表，其缺失并不影响相邻正文的论证链条；但由于该表被正文明确引用（「参看表 0.14」），它承担着把「[[函数的单调性|单调性]]」「[[函数的奇偶性与周期性|奇偶性与周期性]]」等多个概念并置对照的功能，缺失后读者只能从散落的正文段落重建其结构。

## 表 0.14 出现的语境

据 [1] 的片段，表 0.14 紧接在函数单调性的定义之后。原文先给出（严格）增函数的定义：

> 函数 f 称为（严格）增函数，若 x < u ⇒ f(x) < f(u)。（式 0.27）

随后说明：把上式中的「f(x) < f(u)」依次替换为其他不等号，即可得到非减、减、非增等概念，并提示读者「参看表 0.14」。紧接着手册转入「反函数的基本思想」，以 y = x²（x > 0）为例讨论平方根函数的引入 [1]。由此可见，表 0.14 位于**单调性定义与反函数讨论之间的过渡位置**，其作用是把单调性、奇偶性、周期性这几类「函数性质」集中罗列，供读者对照。

## 可辨认的表格标签

从 [1] 中可直接提取出以下词条（OCR 存在明显粘连与错位，标签顺序无法完全确定）：

- 增函数
- 非减函数
- 减函数
- 非增函数
- 偶函数
- 奇函数
- 周期函数

片段中还有一处明显的 OCR 讹误：正文把「≤」渲染成「6」，把「≥」渲染成「>」，即「f(x) 6 f(u)」应为 f(x) ≤ f(u)，而重复出现的「f(x) > f(u), f(x) > f(u)」实为 f(x) ≥ f(u) 一类符号被识别失真的结果 [1]。这提示表 0.14 的正文很可能同样由「不等号 + 定义式」构成，从而在扫描/OCR 过程中最容易发生字形混淆。

## 推断的表格内容

尽管表格本体缺失，结合手册正文的定义方式 [1] 与通用的函数性质定义（可参见 [11][12][13][14] 等对奇偶性、周期性的标准化表述），表 0.14 中每种性质大致应包含如下判据：

| 性质 | 推断的判据（基于 [1] 与通用定义） |
|---|---|
| 增函数 | x < u ⇒ f(x) < f(u) |
| 非减函数 | x < u ⇒ f(x) ≤ f(u) |
| 减函数 | x < u ⇒ f(x) > f(u) |
| 非增函数 | x < u ⇒ f(x) ≥ f(u) |
| 偶函数 | 定义域关于原点对称，且 f(−x) = f(x)（图像关于 y 轴对称） |
| 奇函数 | 定义域关于原点对称，且 f(−x) = −f(x)（图像关于原点中心对称） |
| 周期函数 | 存在 p ≠ 0，使 f(x + p) = f(x) 对一切 x 成立 |

其中奇偶性、周期性的判据来自通用教材式表述 [11][12][14]，而非手册原文的直接转录，故只能视为**合理推断**，不可当作手册原文引用。需要特别留意 [[周期定义是否需最小正周期|周期定义是否需最小正周期]] 这一悬而未决的问题：手册表 0.14 是否要求 p > 0 或限定「最小正周期」，目前无法从残缺文本判断。

## 缺失与不确定之处

1. **表格正文整体缺失**：现有数字文本只保留了标签，各行对应的定义式、图示或补充说明均未出现 [1]。
2. **标签的版式归属不明**：OCR 把「增函数/非减函数/偶函数/奇函数」与「减函数/非增函数/周期函数」交错排布，无法据此确定表 0.14 是单列还是多列、是否按「单调类 / 对称类 / 周期类」分组。
3. **术语细微差别待考**：手册区分「增（严格）」与「非减（弱）」，但表内是否同时给出「严格」「非严格」两套记号，以及是否附有「单调」作为总称，均无从确证。
4. **与后续表格的关系**：手册第 0 章还有表 0.5（立体图形公式）等被单独记录并讨论记法疑问（参见 [[立体图形公式表中的记法疑问]]）；表 0.14 是否也存在类似的中译本记号统一问题，缺少对照材料。
