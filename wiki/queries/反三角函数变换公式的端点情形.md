# 反三角函数变换公式的端点情形

## 问题

《数学指南——实用数学手册》0.2.12 的变换公式中，两个公式族的适用范围写法不同：

- $\arcsin x = -\arcsin(-x) = \dfrac{\pi}{2} - \arccos x = \arctan\dfrac{x}{\sqrt{1-x^2}}$：限定为“对所有实数 $x$，$-1 < x < 1$”；
- $\arctan x = -\arctan(-x) = \dfrac{\pi}{2} - \operatorname{arccot} x = \arcsin\dfrac{x}{\sqrt{1+x^2}}$：限定为“对所有实数 $x$”。

导数公式也采用相同的开区间约定：$\arcsin$ 与 $\arccos$ 的导数仅在 $-1 < x < 1$ 上给出。

## 待澄清

1. 端点 $x = \pm 1$ 处，$\arctan\dfrac{x}{\sqrt{1-x^2}}$ 因分母为零而失效。此时 $\arcsin(\pm 1) = \pm\pi/2$、$\arccos(\pm 1) = 0$，两种表示是否可以通过极限或约定延拓统一？
2. 手册为何把 $\arcsin$ 一族的适用范围写成“对所有实数 $x$，$-1 < x < 1$”这种自相矛盾的措辞（“对所有实数”与开区间限定并列）？是排版便利还是强调 $x$ 本身为实数？
3. 这与 [[开区间记号的两种约定]] 中记录的 $]a,b[$ 与 $(a,b)$ 记法差异属同类端点约定问题，是否应合并讨论？
