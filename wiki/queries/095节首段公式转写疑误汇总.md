# 0.9.5 节首段（条目 1–180）公式转写疑误汇总

本页汇集 0.9.5 节首段（条目 1–180）中疑似转写错误的位置，供人工核对原书。判断依据是同族条目之间的形式一致性与量纲一致性。

## 待核对清单

| 条目 | 原文写法 | 疑点 |
|---|---|---|
| 22 | $\int \frac{\mathrm{d}x}{x^3L} = -\frac{1}{b^3}\left[a^2\ln\frac{L}{z} - \frac{2aL}{x} + \frac{L^2}{2x^2}\right]$ | 对数中写作 $L/z$，同族条目 19、23、24 均作 $L/x$，疑为 $L/x$ |
| 26 | $\int \frac{\mathrm{d}x}{L_1L_2} = \frac{1}{D} + \ln\frac{L_2}{L_1}$ | 右侧缺少乘在 $\ln$ 上的因子 $\frac{1}{D}$，与条目 28、31 的形式不一致 |
| 30 | 定义域写作 $x \neq -\frac{b}{c}$ | 同组条目 25–29、31–33 均作 $x \neq -\frac{b}{a}$，疑为 $-\frac{b}{a}$ |
| 42 | $\int \frac{\mathrm{d}x}{xQ} = \frac{1}{2c}\ln\frac{x^2}{Q} - \frac{b}{2^m}\int\frac{\mathrm{d}x}{Q}$ | 系数写作 $b/2^m$，条目 36、44 对应位置作 $\frac{b}{2c}$、$\frac{b}{2c^2}$，疑为 $\frac{b}{2c}$ |
| 83 | $\int \frac{\mathrm{d}x}{x^2K} = -\frac{1}{a^3x} \mp \frac{1}{a^3}\frac{x\,\mathrm{d}x}{K}$ | 第二项缺少积分号，条目 84 对应位置写作 $\mp\frac{4}{3a^6}\int\frac{x\,\mathrm{d}x}{K}$ |
| 123 | 标签 $\int x^2\sqrt{L^3}\,\mathrm{d}x$，结果 $\frac{2}{35a^2}(5\sqrt{L^7} - 7b\sqrt{L^5})$ | 结果与 $\int x\sqrt{L^3}\,\mathrm{d}x$ 相符，与 $x^2$ 标签不符；条目 124 才是 $x^2$ 的式子 |
| 132 | 首项写作 $L^{(4\pm n)}/2$ | 同式第二、三项作 $L^{(4\pm n)/2}$、$L^{(2\pm n)/2}$，首项疑漏括号 |
| 167 | $\int\frac{\sqrt{Q^3}}{x^3}\mathrm{d}x = -\frac{\sqrt{Q^3}}{2x^2} - \frac{\sqrt{3\sqrt{Q}}}{2} + \frac{3a}{2}\ln\frac{a+\sqrt{Q}}{x}$ | 中间项 $\frac{\sqrt{3\sqrt{Q}}}{2}$ 与同族条目 165、166 的 $\sqrt{Q}$ 幂次形式不协调，疑为 $\frac{3}{2}\sqrt{Q}$ 一类的表达式 |
| 171 | $\int\frac{x^3\mathrm{d}x}{\sqrt{Q^3}} = \sqrt{Q} + \frac{a^2}{Q}$ | 第二项 $\frac{a^2}{Q}$ 与同族条目 169（$1/\sqrt{Q}$）、170（$x/\sqrt{Q} - \arcsin\frac{x}{a}$）的量纲形式不协调 |
| 133 | $\int\frac{L^{n/2}\mathrm{d}x}{x} = \frac{2L^{n/2}}{n} + b\int\frac{L^{(n-2)/2}}{x}\mathrm{d}x$ | 与 134、135 互为递推链，形式自洽，但首项的因子 $2/n$ 在 $n \to 0$ 时退化，原文未注 $n \neq 0$ 的条件 |

## 处理方式

- 这些位置均未在原文中附注说明，且与本段其余同族条目（19、28、36、44、124、165、169 等）存在形式冲突，因此按转写疑误记录，不直接改写公式原文。
- 同一小节后续片段（条目 342–500）已有汇总页 [[queries/095节公式转写疑误汇总]]，两者可合并核对。
- 编号层面的问题（缺号、错位、未标号）单独记录于 [[findings/095节首段条目编号缺号与重号]]。
