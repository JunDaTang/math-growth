# 补充：图 0.29(b) 与脚注 2) 的缺失内容

## 一、问题背景

本页汇总对《数学指南——实用数学手册》0.2.6 节"对数"中两处缺失内容的补全。在可得文本里，正文出现了对**图 0.29(b)** 的引用，并附有依附于"对数的基本性质"的**脚注 2)**，但图形本体、图注以及脚注与正文标记的对应关系均不完整 [1]。

- 图书信息：《数学指南——实用数学手册》，(德) 埃伯哈德·蔡德勒等编，李文林等译，科学出版社 2012 年 1 月第 1 版，ISBN 9787030325402，中图分类号 O1-62，属精装工具书 [3][4]。
- 章节位置：0.2.6 节"对数"位于中译本第 73 页，紧随其后的 0.2.7 节"一般指数函数"位于第 74 页；图 0.29 与图 0.30 正落在这一跨页区间内 [2]。
- 相关既有页面：[[10-数学指南实用数学手册--6-026-对数--2uga02]]、[[对数]]、[[欧拉e函数]]。

## 二、图 0.29(b)：ln x 作为 e^x 的对角线镜像

### 2.1 正文相关文字

可得文本在"自然对数"一段中写道（原文存在 OCR 断字）：函数 $y = \ln x$ "它是函数 $y = e^x$ 的反函数。$y = \ln x$ 的图像可通过 $y = e^x$ 的图像沿对角线反射得到（图 0.29(b)）" [1]。

### 2.2 图形应当呈现的内容

结合上下文可以确定图 0.29(b) 的内容要点：

1. 主体曲线为 $y = \ln x$，定义域 $x > 0$，经过点 $(1, 0)$ 与 $(e, 1)$；
2. 参照曲线为 $y = e^x$，经过点 $(0, 1)$ 与 $(1, e)$；
3. 反射轴为对角线 $y = x$；两条曲线关于该直线互为镜像，即 $y = e^x$ 图像上的点 $(a, b)$ 对应 $y = \ln x$ 图像上的点 $(b, a)$；
4. 曲线自左向右单调上升、向左"极其缓慢"地下降的趋势，与同节给出的极限关系一致 [1]。

### 2.3 为什么"沿对角线反射"成立

反函数图像的对角线反射是本书 0.2 节已经建立的一般方法：在讨论 $y = x^2$（$x > 0$）时，正文指出把原函数图像沿对角线反射即得反函数 $y = \sqrt{x}$ 的图像（图 0.23），并称"对任意连续的增函数，都可以这样作出它们的反函数（参看 1.4.4）" [1]。1.4.4 节"反函数"确实见于目录 [2]。$\ln x$ 只是这一一般构造在指数函数上的特例，正文还预告了 $y = \arcsin x$、$y = \arccos x$ 等同类例子 [1]。

相关页面：[[反函数]]、[[函数图像的镜射]]、[[函数的变换]]、[[反函数存在性所需条件]]（"连续的增函数"是否已隐含严格单调）、[[自然对数与换底公式]]。

### 2.4 与脚注 1) 的分工

同一页的脚注 1) 指出："更确切地说，映射 $x \mapsto e^x$ 是从复平面 $\mathbb{C}$ 到 $\mathbb{C} \setminus \{0\}$ 的满射。" [1] 这恰好界定了图 0.29(b) 所依赖的"反函数"关系的适用范围：在实数域上 $e^x : \mathbb{R} \to (0, \infty)$ 是双射，故 $\ln$ 可作其反函数；在复数域上 $e^x$ 满射但不单射，反函数需要另行处理。参见 [[复指数函数的周期性]]、[[e函数具有复周期2πi]] 与相关来源 [[10-数学指南实用数学手册--11-025-欧拉-e-函数--qttyq2]]。

## 三、脚注 2)：$\ln(xy) = \ln x + \ln y$ 的推导

### 3.1 脚注原文

正文在"由加法定理 $e^{u+v} = e^u e^v$，对所有正实数 $x$ 和 $y$，有对数的基本性质：$\ln(xy) = \ln x + \ln y$"处标注脚注 2)，脚注内容为："若令 $x := e^u$，$y := e^v$，则 $xy = e^{u+v}$。由此得到 $u = \ln x$，$v = \ln y$，$u + v = \ln(xy)$。" [1]

### 3.2 逐步展开

该脚注给出的是一行式证明，可展开如下：

1. 设 $u = \ln x$、$v = \ln y$，等价地 $x = e^u$、$y = e^v$；
2. 由 $e$ 函数的加法定理 $e^{u+v} = e^u e^v$，得 $xy = e^u e^v = e^{u+v}$；
3. 对 $xy = e^{u+v}$ 两端取自然对数，即得 $u + v = \ln(xy)$；
4. 代回 $u = \ln x$、$v = \ln y$，得到 $\ln(xy) = \ln x + \ln y$。

整个推导的唯一前提是 $e$ 函数的加法定理以及 $\ln$ 与 $e^x$ 互为反函数，这正是图 0.29(b) 所刻画的关系 [1]。

### 3.3 该推导的地位

- 它表明对数的乘法法则并非独立公理，而是 $e$ 函数加法定理的直接推论 [1]，参见 [[欧拉e函数]]。
- 正文随后标注"对数法则 参看 0.1.9"，即完整性法则表见第 0.1.9 节"幂、根与对数" [1][2]，对应 [[10-数学指南实用数学手册--9-019-幂根与对数--1hc2cso]]、[[对数]]、[[幂法则]]。
- 该结论与函数方程视角下的刻画相呼应：参见 [[指数函数与对数的函数方程]]、[[指数函数与对数由函数方程唯一刻画]]。

## 四、同节其余断言的外部佐证

0.2.6 节还列出以下极限与导数关系 [1]。它们并非图 0.29(b) 或脚注 2) 的缺失部分，但可用外部来源核验，故一并整理：

| 正文断言 | 外部佐证 | 说明 |
|---|---|---|
| $\lim\limits_{x \to +0} \ln x = -\infty$ | [7][10] | 可由 $\ln$ 在 $(0,\infty)$ 上单调递增且在下方无界证明；[7] 用 $\delta$ 语言给出证明，[10] 用积分中值定理从反方向处理 |
| $\lim\limits_{x \to +\infty} \ln x = +\infty$ | [10] | 同上来源 |
| 对任意 $\alpha > 0$，$\lim\limits_{x \to +0} x^\alpha \ln x = 0$ | [6][8] | [6] 先证数列版本 $\ln n / n^a \to 0$，再推广到连续变量；[8] 给出 $\lim_{x\to 0^+} x^m (\ln x)^n = 0$ |
| $\dfrac{d \ln x}{d x} = \dfrac{1}{x}$（$x > 0$） | [11][12][13][14][15] | [12] 由 $d e^x/dx = e^x$ 经隐式求导得出，[13] 给出首原理推导并推广到一般底数，[14][15] 用反函数求导法则导出 |
| "$\ln x$ 在 $x = 0$ 附近极其缓慢地趋近于负无穷" | [6][8] | 即 $x^\alpha \ln x \to 0$ 的直观表述 |

正文关于 $\ln e = 1$ 以及 $y = \ln x$ 与 $y = e^x$ 互为反函数的表述，与 [11] 中的标准处理一致 [1][11]。极限 $x^\alpha \ln x \to 0$ 与 [[指数增长快于幂函数]]、[[一般幂的极限关系]] 属于同一类"增长率比较"命题，可相互参照。

来源 [9] 的摘要只提到 $x \to \infty$ 时某指数—阶乘型极限为 $0$，与本节内容关联较弱，暂不作为直接佐证。

## 五、矛盾与缺口

1. **图 0.29 的分图结构不明**：正文只引用 (b) 分图，(a) 分图绘为何物在可得文本中没有交代。只能由编号推断它属于 0.2.6 节、与图 0.30"一般指数函数"相邻 [1][2]，具体内容仍属缺口。
2. **脚注标记的归属需按语义还原**：转录文本把脚注 1)、2) 集中排在页末，正文中的上标位置已丢失。按内容可判断 1) 服务于 $e^x$ 的满射性陈述、2) 服务于对数乘法法则 [1]，但这一对应关系是重建而非原文直证。
3. **图号与式号同名易混**：同一章中既存在式 (0.29)（平方根函数的定义式），又存在图 0.29（对数相关），二者分属公式编号与插图编号两个序列，转录时容易混淆 [1]。
4. **外部来源未覆盖目标内容**：[6]–[15] 均为英文微积分教程或问答，能核验极限与导数断言，但没有一条涉及图 0.29(b) 的图像本身或脚注 2) 的排版原貌，属于佐证范围与实际缺口之间的错位。
5. **"参看 0.1.9"的具体范围不明**：正文只说"对数法则参看 0.1.9"，未列出该节中被引用的具体条目 [1]。

- 《数学指南》德文原版（Teubner 出版社）及英文版对应的 0.2.6 节，用于获取图 0.29 的完整图注与 (a)(b) 分图结构。

## 七、要点小结

- 图 0.29(b) 描绘的是 $y = \ln x$ 与 $y = e^x$ 关于直线 $y = x$ 的对角线镜像关系，是本书"反函数图像由原函数图像沿对角线反射得到"这一一般方法在指数函数上的实例 [1]。
- 脚注 2) 用 $x := e^u$、$y := e^v$ 的代换，把对数乘法法则 $\ln(xy) = \ln x + \ln y$ 化归为 $e$ 函数的加法定理 $e^{u+v} = e^u e^v$ [1]。
- 两处内容彼此关联：图给出几何图景，脚注给出代数证明，共同支撑"$\ln$ 是 $e^x$ 的反函数"这一核心事实 [1]。
