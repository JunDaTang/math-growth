# 4.1 节重言式 (iv) 公式与 (iii) 同形是否讹误？

## 问题

在 4.1.3 节重言式清单中，(iii)「蕴涵的换位」与 (iv)「逻辑等值的换位」两条给出的公式完全相同：

$$
(\mathcal {A} \Rightarrow \mathcal {B}) \Leftrightarrow (\text { 非 } \mathcal {B} \Rightarrow \text { 非 } \mathcal {A}).
$$

按标题，(iv) 应处理的是**逻辑等值** $A \Leftrightarrow B$ 的换位，即应为

$$
(\mathcal {A} \Leftrightarrow \mathcal {B}) \Leftrightarrow (\text { 非 } \mathcal {B} \Leftrightarrow \text { 非 } \mathcal {A})
$$

之类的形式；而正文 4.1.2 节「逻辑等值的换位」处给出的正是「非 A ⇔ 非 B」。

## 待确认

- (iv) 的公式是否应与 (iii) 区别，改为以 $\Leftrightarrow$ 联结的形式？
- 是否为源书排印或 OCR 层面的重出讹误？
