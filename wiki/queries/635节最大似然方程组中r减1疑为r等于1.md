# 6.3.5 节 (6.37) 中「r − 1, …, k」是否为「r = 1, …, k」之误？

## 问题

连续型最大似然方程组 (6.37) 的下标说明在原文中写作：

```latex
\sum_{j=1}^{n} \frac{1}{\varphi(x_j, \boldsymbol\beta)}
  \frac{\partial \varphi(x_j, \boldsymbol\beta)}{\partial \beta_r} = 0,
\quad r - 1, \dots, k.
```

其中 `r - 1, …, k` 若按字面理解，将意味着下标从 $r-1$ 起递增到 $k$，与参数编号 $1, \cdots, k$ 不符。

## 证据

同一脚注 1) 中由似然函数导出的极值条件写作 $\frac{\partial L}{\partial \beta_r} = 0,\; r = 1, \dots, k$；紧随其后的正态分布特例也按 $\beta_1 = \mu$、$\beta_2 = \sigma$ 逐一处理。因此 (6.37) 的指标几乎可以确定应为 `r = 1, …, k`，原文的 `-` 为 `=` 的排版讹误。

## 建议处理

按 `r = 1, \dots, k` 理解并使用 (6.37)；建议在勘误或注释中记录该印刷问题。
