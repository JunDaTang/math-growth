# 原书例 1 疑似排印问题需对照纸质原书核实

## 概述

本条记录的是在梳理《数学指南——实用数学手册》[[数学指南-实用数学手册]] 第 0.1.9 节「幂、根与对数」[[10-数学指南实用数学手册--9-019-幂根与对数--1hc2cso]] 时，对其中的**「例 1」**产生的一处疑似排印（或数字化转录 / OCR）问题的存疑。现有检索到的数字文本中，该例题的数值或记号前后不自洽，怀疑属于排版错误而非概念性错误；由于手头缺少纸质原书，暂无法直接判定，故立此条以便日后对照核实。

需要特别说明：本次收集到的研究来源[1]–[18] **均不含「例 1」本身的原文**。它们大体分为两类：

- 关于**对数定义与运算法则**的教学与参考材料（[1][2][3][4][5][16][17][18]），可用于反推一个正确的对数例题应满足何种数值与形式；
- 关于**M. 施蒂费尔与《整数的算术》**的历史材料（[6][7][8][9][10]），以及《数学指南》一书本身的版本信息（[11][12][13][14][15]）。

因此本页先以这些材料建立起"正确形式"的判据，再指出需要与纸质原书核对的要点。

## 判据一：对数的定义与基本值

对数的最简定义是：$\log_b n = x$ 当且仅当 $b^x = n$，即"以 $b$ 为底、得到 $n$ 所需的指数为 $x$"[17]。例如 $2^3 = 8$ 等价于 $\log_2 8 = 3$[3][17]。这一定义关系是判断任何对数例题数值是否正确的第一依据。

据此可整理出一组**参照数值**，供核对例题时使用：

| 对数式 | 正确值 | 依据 |
|---|---|---|
| $\log_2 8$ | $3$ | [1][3][17] |
| $\log_2 512$ | $9$（因 $512 = 2^9$） | [3] |
| $\log_8 64$ | $2$（因 $64 = 8^2$） | [3] |
| $\log_5 25$ | $2$ | [3] |
| $\log_{25} 5$ | $1/2$ | [3] |
| $\log_{125} 5$ | $1/3$ | [2] |
| $\log_{5} 125$ | $3$ | [2] |
| $\log_8 \tfrac{1}{64}$ | $-2$ | [3] |
| $\log_8 0.125$ | $-1$ | [1] |
| $\log_5 0.008$ | $-3$ | [1] |
| $\ln 7.389$ | $\approx 2$（因 $e^2 \approx 7.389$） | [1] |

如果「例 1」给出的底数、真数与结果三元组落在上表同类结构内，却与正确值不符，则基本可判为排印错误。

## 判据二：对数的运算法则

对数运算依赖以下法则，可用于检验例题中变形步骤是否成立[16][18]：

- **积法则**：$\log(xy) = \log x + \log y\ (x,y>0)$
- **商法则**：$\log(x/y) = \log x - \log y$
- **倒数法则**：$\log(1/x) = -\log x$
- **幂法则**：$\log(x^n) = n\log x$
- **根法则**：$\log(\sqrt[n]{x}) = \dfrac{\log x}{n}$
- **一般幂法则**：$\log(x^p) = p\log x\ (x>0,\ p\in\mathbb{R})$

幂法则的典型示例是 $\ln(2^6) = 6\ln 2$[2][4]。换底公式方面，$\log_b a = 1/(\log_a b)$，例如 $\log_{10} e = 1/(\ln 10)$、$\log_{125} 5 = 1/(\log_5 125)$[2]。

**使用幂法则时须注意前提条件**：虽然 $\ln(x^8)$ 对所有非零 $x$ 有定义，但等式 $\ln(x^8) = 8\ln x$ 仅在 $x>0$ 时成立；若允许 $x<0$，须改写为 $\ln(|x|^8) = 8\ln|x|$[16]。这一"定义域陷阱"是例题排印中最易出错、也最值得核查的地方——即例题是否遗漏了 $x>0$ 这类前提。

此外，$\log_a 1 = 0$ 对任何合法底数成立（因 $a^0 = 1$），且底数不能取 $1$[3][17]。

## 判据三：历史叙述可能涉及的施蒂费尔内容

如果「例 1」或其配套的史料旁注涉及对数的历史起源，则需核对以下事实性主张：

- 德国数学家 **M. 施蒂费尔**（Michael Stifel，1487—1567）于 1544 年在纽伦堡出版 **《整数的算术》**（*Arithmetica integra*）[8][9][10]。
- 该书被广泛认为是**首次使用"exponent"（指数）一词**，并给出幂的运算规则 $q^m q^n = q^{m+n}$ 与 $q^m/q^n = q^{m-n}$[8]。
- 书中含有一张整数与 2 的幂的对照表，被部分学者视为**对数表的早期雏形**；施蒂费尔明确指出，几何级数（下行）中的乘除可对应算术级数（上行）中的加减[8]。
- 施蒂费尔还给出了**负指数**的例子（见该书第 250 页附近）[8][9]；据载他"发现了对数"，但因其工作繁重而自认无力完成[6][7][8]。

这些主张中，"施蒂费尔发现对数"一语（[7]）带有夸张成分，需谨慎对待：文献更多将其描述为*对数的先驱*而非发明者，真正的对数发明通常归于 [[纳皮尔]]，并由 [[布里格斯]] 改进为常用对数[12][14]。若原书例题旁的历史注释采用了[7]式的表述，可能也需要与纸质原书核对。

## 争议与待核实要点

1. **例题原文缺失**：本次收集的来源中没有任何一条给出「例 1」的逐字原文，因此其"疑似排印问题"的性质（是数值错误、符号错误、单位错误还是 OCR 误识）**无法在现有材料范围内确认**。这是本条目最大的证据缺口。
2. **错误归属不确定**：需区分"纸质原书印刷错误"与"电子版 OCR / 转录错误"。若数字化文本来自 PDF 扫描，则上标、下标、负号（如 $8^{-2}$ 被识别为 $8^2$）极易出错[3][16]，这本身可能就是"疑似排印"的来源。
3. **版本差异**：中译本依据德文《托伊布纳数学手册》（*Teubner-Taschenbuch der Mathematik*）翻译，德文原版历经多次修订[12]，不同版次间例题数值可能变动，需指明所核对的版次。
4. **历史表述的严谨性**：如例题附带"施蒂费尔发现对数"一类说法，其措辞与史实存在张力[7][8]，核对时宜一并确认。

## 建议进一步查证的来源

- **纸质原书**：《数学指南——实用数学手册》，科学出版社 2012 年第 1 版，ISBN 978-7-03-032540-2，重点核对 0.1.9 节（目录页码见[14]）中「例 1」的完整原文与页码。
- **德文原版**：*Teubner-Taschenbuch der Mathematik*（相应版次），用于判断中译/排版环节是否引入了偏差[12]。
- **历史一手文献**：Michael Stifel, *Arithmetica integra*, Nürnberg: Petreius, 1544（影印本），特别是第 249r–250 页关于几何级数与算术级数对应、以及负指数的段落[8][9][10]。
- **二次研究**：J. Giesing, *Stifels arithmetica integra: ein Beitrag zur Geschichte der Arithmetik des 16.*（1879）[10]，可用于核实施蒂费尔相关史实。
