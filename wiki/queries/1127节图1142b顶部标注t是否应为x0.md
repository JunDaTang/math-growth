# 图 1.142(b) 顶部标注「$|t| < \delta$」是否应为 $|\boldsymbol{x}(0)| < \delta$？

**问题**：图 1.142(b)（渐近稳定性的示意图）顶部的标注被读取为「$|t| < \delta$」，下方为 $x$–$t$ 坐标系中振幅逐渐衰减的曲线。

**疑点**：渐近稳定性的定义涉及初值大小 $|\boldsymbol{x}(0)| < \delta_*$，而不是时间范围 $|t| < \delta$；「$|t| < \delta$」很可能是 $|\boldsymbol{x}(0)| < \delta$ 的 OCR 误读。也可能是原图对初值区域 $|t| < \delta$ 的另一种示意。

**待办**：核对原图标注文字，并据此回填 [[findings/稳定性三个定义]] 中的初值条件表述。
