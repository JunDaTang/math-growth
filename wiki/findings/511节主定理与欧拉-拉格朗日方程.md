# 5.1.1 节：主定理与欧拉-拉格朗日方程 (5.3)

**直接证据（本书陈述）**：

- 变分问题 (5.1) 为极小化问题，被积函数为 [[拉格朗日函数]] $L(q(t), q'(t), t)$，端点条件 $q(t_0) = a$、$q(t_1) = b$；(5.2) 把「$\min$」替换为「稳态」。
- **主定理**：若 $q = q(t)$ 是 (5.1) 或 (5.2) 的 $C^2$ 解，则 $\dfrac{\mathrm{d}}{\mathrm{d}t} L_{q'} - L_q = 0$（(5.3)）。
- 该方程**等价于 (5.2)**；但对 (5.1) 只是**必要条件**，(5.1) 的解满足 (5.3)，反之未必；充分条件留待 5.1.5 节。
- 向量情形下 (5.3) 由 (5.4) 的**方程组**代替：$\dfrac{\mathrm{d}}{\mathrm{d}t} L_{q_j'} - L_{q_j} = 0$，$j = 1, \dots, F$。

**归属与出处**：定理由 [[欧拉]] 于 1744 年在其论文 *Methodus inveniendi lineas curvas maximi minimive proprietate gaudentes, sive solutio problematis isoperimetrici latissimo sensu accepti* 中证明，据此奠定变分法学科基础；1762 年 [[拉格朗日]] 简化了欧拉的推导并推广到多变量函数（见 (5.46)）。[[queries/卡拉泰奥多里]] 评之为「现有的最漂亮的数学成果之一」。

**推断/待核**：本节标题作「欧拉－伯努利方程」，与正文的「欧拉-拉格朗日方程」不一致，见 [[欧拉-伯努利方程]]。
