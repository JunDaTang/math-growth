# 例 2：指数函数 e^z 的复导数为自身

## 陈述（源文逐字保留）

令 $f(z) := \mathrm{e}^{z}$。由关系式

```latex
f(z) = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \dots
```

即得

```latex
f'(z) = 1 + z + \frac{z^2}{2!} + \dots = \mathrm{e}^{z}, \quad \text{对所有} z \in \mathbb{C}.
```

## 依据

结论通过对幂级数逐项求导得到（见 [[幂级数逐项求导]]），并用到 $n/n! = 1/(n-1)!$ 使逐项求导后的级数与 $\mathrm{e}^z$ 的展开一致。源文给出结论，未展开系数计算细节。

## 属主限定

该结论针对函数 $\mathrm{e}^z$；不要把「导数等于自身」推广到其它初等函数。
