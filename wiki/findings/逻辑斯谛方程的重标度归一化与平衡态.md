# 逻辑斯谛方程的重标度归一化 (1.209) 与平衡态

源文对 (1.208) 作 [[重标度]] $N(t)=\gamma\mathcal N,\ t=\delta\tau$，并取 $\delta := 1/\alpha$、$\gamma := \alpha/\beta$，得到归一化方程

```latex
\begin{array}{l}
\mathcal N'(\tau) = \mathcal N(\tau) - \mathcal N(\tau)^2, \\
\mathcal N(0) = \mathcal N_0 \quad (\text{初始条件}).
\end{array}                                       \tag{1.209}
```

**平衡态**：时间无关解由 $\mathcal N\equiv 0$ 与 $\mathcal N\equiv 1$ 给出。源文证明从略记录为：由 $\mathcal N=$ 常数 与 (1.209) 得 $\mathcal N^2-\mathcal N=0$，蕴涵 $\mathcal N=0$ 或 $\mathcal N=1$。

**解**：$0<\mathcal N_0\le 1$ 时对所有 $\tau$
```latex
\mathcal N(\tau) = \frac{1}{1 + C\mathrm{e}^{-\tau}}, \quad C := (1-\mathcal N_0)/\mathcal N_0 ;
```
$\mathcal N_0=0$ 时对所有 $\tau$ 唯一解 $\mathcal N(\tau)\equiv 0$。

**稳定性**：$\lim_{\tau\to+\infty}\mathcal N(\tau)=1$。
