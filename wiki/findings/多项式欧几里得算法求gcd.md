# 欧几里得算法求多项式 gcd

## 陈述

设 $N(x)$ 和 $D(x)$ 是两个次数至少为 $1$ 的多项式。类似于 (2.19) 得到带余项的除法链：

```
N(x)   = D(x)Q(x)    + R_1(x),
D(x)   = R_1(x)Q_1(x) + R_2(x),
R_1(x) = R_2(x)Q_2(x) + R_3(x),  等等。
```

由关系式 $\deg(R_{j+1}) < \deg(R_j)$，经有限步后将在某一步余项多项式为零，亦即

```
R_m(x) = R_{m+1}(x)Q_{m+1}(x).
```

于是 $R_{m+1}(x)$ 是 $N(x)$ 和 $D(x)$ 的最大公因子。

## 证据与推理结构

- 结论由**次数严格递减 + 次数为非负整数**推出终止性，属于直接推理（非经验观察）。
- 算法的输入输出关系明确：输入两个次数 ≥ 1 的多项式，输出其 gcd。
- 来源未讨论系数域、gcd 的首一化约定或复杂度。
