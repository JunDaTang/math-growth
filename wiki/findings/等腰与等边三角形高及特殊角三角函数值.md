# 等腰与等边三角形的高及 30°、45°、60° 的三角函数值

## 例 1：等腰直角三角形（源图 3.5(b)）

结论：

$$
h_c = \frac{a\sqrt{2}}{2},\qquad \sin 45^{\circ} = \frac{h}{a} = \frac{\sqrt{2}}{2},\qquad \cos 45^{\circ} = \sin 45^{\circ}.
$$

源中证明（直接证据）：图 3.5(b) 中的三角形 APC 是直角三角形；由三角形内角和为 $180^{\circ}$ 得 $\alpha = \beta = 45^{\circ}$；因 $\frac{\gamma}{2} = 45^{\circ}$，三角形 APC 有相等边，于是由毕达哥拉斯定理知 $a^{2} = h^{2} + h^{2}$，从而 $h^{2} = a^{2}/2$，$h = a/\sqrt{2} = a\sqrt{2}/2$。

## 例 2：等边三角形（源图 3.4(b)）

结论：

$$
h_c = \frac{a\sqrt{3}}{2},\qquad \sin 60^{\circ} = \frac{h}{a} = \frac{\sqrt{3}}{2},\qquad \cos 30^{\circ} = \sin 60^{\circ}.
$$

源中证明（直接证据）：毕达哥拉斯定理给出 $a^{2} = h^{2} + \left(\frac{a}{2}\right)^{2}$，由此得到 $4a^{2} = 4h^{2} + a^{2}$，从而 $4h^{2} = 3a^{2}$，即 $2h = \sqrt{3}a$。

## 评估

两个证明都以 [[concepts/毕达哥拉斯定理]] 为唯一工具，步骤完整、结论与标准值一致。源中未给出 $30^{\circ}$ 的正弦值或 $60^{\circ}$ 的余弦值，仅以互补关系 $\cos 30^{\circ} = \sin 60^{\circ}$ 间接给出。
