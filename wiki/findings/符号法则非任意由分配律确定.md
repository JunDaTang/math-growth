# 符号法则非任意，由分配律确定

## 观察

手册 1.1.1.2 节主张：整数乘除法则 (1.1)、(1.2) 中符号的选择**似乎是任意**的，实际上需要保证实数的「简单」计算法则成立。

## 证据（直接来自原文）

要求分配律 `a(b + c) = ab + ac` 成立，取 a = 4, b = 3, c = −3：

```latex
4(3 + (-3)) = 4 \cdot 0 = 0,
4(3 + (-3)) = 4 \cdot 3 + 4 \cdot (-3) = 12 + 4 \cdot (-3) = 0,
```

由第二个等式必须 `4(−3) = −12`，与法则 (1.1) 给出的值相符。

## 评估

这是手册内部的**论证性说明**（非独立实验），用于说明符号法则的必然性。它把「负数乘正数为负」追溯到分配律这一更基本的运算律，属于推论而非经验结果。
