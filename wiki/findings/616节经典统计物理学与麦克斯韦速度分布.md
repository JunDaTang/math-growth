# 6.1.6 节：经典统计物理学、麦克斯韦速度分布与波动原理

## 直接证据（来源陈述）

**力学基础**：$N$ 个质量为 $m$ 的粒子组成系统，能量 $E = H(q,p)$；每个粒子有 $f$ 个自由度，$q = (q_1,\dots,q_{fN})$、$p = (p_1,\dots,p_{fN})$。运动方程

```
q_j′(t) = H_{p_j}(q(t), p(t)),  p_j′(t) = −H_{q_j}(q(t), p(t))
```

$(q,p)$ 所在区域 $\Pi$ 称为相空间（基本概念见 5.1.3）。

**统计力学**：从密度 $\varphi(q,p) := C\mathrm{e}^{-H(q,p)/\mathrm{k}T}$ 出发，$C$ 由 $\int_\Pi \varphi\,\mathrm{d}q\,\mathrm{d}p = 1$ 确定；系统落入子区域 $G$ 的概率 $P(G) = \int_G \varphi\,\mathrm{d}q\,\mathrm{d}p$ (6.7)；函数均值、方差、相关系数、熵 $S = -\mathrm{k}\overline{\ln\varphi}$ 均由该密度定义。

**麦克斯韦速度分布**：理想气体粒子速度向量的任一分量 $v$ 满足

```
P(a ≤ mv ≤ b) = ∫_a^b (1/(σ√(2π))) e^{−x²/(2σ²)} dx        (6.8)
```

即 $mv$ 服从均值 0、标准差 $\sigma = \sqrt{mkT}$ 的正态分布。来源注明该定律由麦克斯韦于 1860 年确立，并为玻尔兹曼建立统计力学奠定基础。

**波动原理**：对理想气体成立的公式

```
ΔE / Ē = (1/√N) · (Δε / ε̄)        (6.9)
```

因 $\Delta\varepsilon/\overline{\varepsilon} \approx 1$ 而 $N \sim 10^{23}$，故 $\Delta E/\overline{E}$ 极小，在日常生活中没有明显作用。

**可变粒子数与化学势**：化学反应期间粒子数可变，需引入 $T$（绝对温度）与 $\mu$（化学势）；来源前向引用 [212] 中也可应用于现代量子统计（原子、分子、光子和基本粒子）的一般方案。

## 推断（非来源直述）

- (6.9) 的推导依赖粒子能量的相互独立性：$\overline{E} = N\overline{\varepsilon}$、$(\Delta E)^2 = N(\Delta\varepsilon)^2$，两者相除即得该式。
- 由 $\sigma = \sqrt{mkT}$ 可知，温度越高，动量分量分布的宽度越大。
