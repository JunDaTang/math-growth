# 0.9.6 节条目 54 结果中的 √x 疑为 √π

## 源文档原文

```latex
54. \int_{0}^{1}\frac{\mathrm{d}x}{\sqrt{1-x^{\alpha}}}
    =\frac{\sqrt{x}\,\Gamma\left(\frac{1}{\alpha}\right)}{\alpha\,\Gamma\left(\frac{2+\alpha}{2\alpha}\right)}
```

## 问题

左端是定积分，其值只依赖参数 α，不可能含自变量 x。但右端分子含因子 √x。

## 核验

取换元 t = x^α，则 x = t^{1/α}，dx = (1/α)t^{1/α−1}dt，于是

- ∫₀¹ dx/√(1−x^α) = (1/α)∫₀¹ t^{1/α−1}(1−t)^{−1/2}dt = (1/α)B(1/α, 1/2)；
- B(1/α, 1/2) = Γ(1/α)Γ(1/2)/Γ(1/α + 1/2) = √π·Γ(1/α)/Γ((2+α)/(2α))。

注意 (2+α)/(2α) = 1/α + 1/2，与源文档分母的 Γ 自变量**完全一致**，因此源文档的 Γ 部分正确，唯分子中的 √x 应为 **√π**（π 被误识为 x）。

## 结论

判定为转写期字形混淆（π → x），数学上应为：

```latex
\int_{0}^{1}\frac{\mathrm{d}x}{\sqrt{1-x^{\alpha}}}
=\frac{\sqrt{\pi}\,\Gamma\left(\frac{1}{\alpha}\right)}
       {\alpha\,\Gamma\left(\frac{2+\alpha}{2\alpha}\right)}
```
