# 均值相同而标准差不同可区分两个测量组

## 陈述

在《数学指南——实用数学手册》0.4.1 节的例 3 中，两批各 8 个人的身高数据（表 0.25 与表 0.26）具有**相同的[[经验均值]]** $\bar x = 175$ cm，但[[经验标准差]]分别为 $\Delta x = 4.8$ 与 $\Delta x = 1.07$。因此仅凭均值无法区分这两组测量，必须用标准差刻画其离散程度。

## 证据

- 表 0.25：$(\Delta x)^2 = \frac{1}{7}[49+25+9+1+4+25+49] = 23$，$\Delta x = 4.8$。
- 表 0.26：$(\Delta x)^2 = \frac{1}{7}[1+1+1+1+1+1+1+1] = \frac{8}{7}$，$\Delta x = 1.07$。
- 均值计算：$\bar x = \frac{1}{8}(168+170+172+175+176+177+180+182) = 175$。

## 性质与限度

- 这是**演示性算例**而非独立实证结果；数据由手册自行构造以突出「均值同、尺度异」的对比。
- 结论限于 0.4.1 节的描述性统计框架，不涉及任何推断统计意义上的检验或区分准则。
- 表 0.25 那一行的偏差平方在原文中只印出 7 项（序列长度为 8），数值结果与完整计算一致，属印刷残缺，见 [[表025偏差平方列项残缺]]。
