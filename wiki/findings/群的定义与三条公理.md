# 群的定义与三条公理

群 $G$ 是一个集合，对任意有序对 $(g,h)$ 存在乘积 $gh$，满足：

```
(i)   g(hk) = (gh)k                        (结合律)
(ii)  存在唯一 e，eg = ge = g               (中性元素)
(iii) 对每个 g 存在唯一 g^{-1}，gg^{-1}=g^{-1}g=e  (逆元素)
```

若对所有 $g,h$ 有 $gh=hg$，称为**交换群**（阿贝尔群）。

> 直接结论。信心高；为标准定义，未涉及可复现性评估。
