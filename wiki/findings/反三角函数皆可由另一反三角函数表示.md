# 反三角函数皆可由另一反三角函数表示

## 陈述

《数学指南——实用数学手册》0.2.12 的变换公式表明，四个反三角函数之间存在显式的互相表示：

- 对所有实数 $x$，$-1 < x < 1$：$\arcsin x = -\arcsin(-x) = \dfrac{\pi}{2} - \arccos x = \arctan\dfrac{x}{\sqrt{1-x^2}}$；
- 对所有实数 $x$：$\arctan x = -\arctan(-x) = \dfrac{\pi}{2} - \operatorname{arccot} x = \arcsin\dfrac{x}{\sqrt{1+x^2}}$。

## 证据与来源

来源为《数学指南——实用数学手册》0.2.12。这些恒等式是标准三角学结果，由直角三角形边角关系或反函数求导均可验证。

`source:` 字段指向 [[10-数学指南实用数学手册--10-0212-反三角函数--1g1n0g5]]。

## 限定条件

两条链的适用范围不同：$\arcsin$ 一族要求 $-1 < x < 1$，端点处分式退化；$\arctan$ 一族对全体实数成立。这一差异记录于 [[反三角函数变换公式的端点情形]]。
