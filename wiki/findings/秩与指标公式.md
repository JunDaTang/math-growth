# 秩与指标公式

2.3.3.2 节：

```text
rank(A) := dim Im(A)
ind(A) := dim Ker(A) − codim Im(A)
```

仅当 $\dim \mathrm{Ker}(A)$ 与 $\operatorname{codim} \mathrm{Im}(A)$ 中有一个有限时才能定义 ind(A)。对有限维空间间的线性算子 $A: X \to Y$：

```text
ind(A) = dim X − dim Y
dim Ker(A) = dim X − rank(A)
```

推论：(a) (2.50) 的解空间 $u_0 + \mathrm{Ker}(A)$ 的维数等于 $\dim X - \operatorname{rank}(A)$；(b) 如果 $\operatorname{ind}(A) = 0$，则由 $\dim \mathrm{Ker}(A) = 0$ 推出 $\operatorname{Im}(A) = Y$，故 A 是双射，对每个 $v \in Y$ 有唯一解 $u = A^{-1}v$。
