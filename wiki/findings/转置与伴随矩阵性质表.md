# 转置与伴随矩阵的定义及性质表

## 定义

设给定实或复 `m × n` 矩阵 `A = (a_jk)`。A 的**转置矩阵** `A^T` 是将 A 的各行和各列互换所得的矩阵；如果再取各元素的复数共轭，就得到 A 的**伴随矩阵** `A*`。元素层面：

```
a_kj^T := a_jk,        a_kj^* := conj(a_jk),        k = 1,...,n,  j = 1,...,m
```

因此 `A^T` 和 `A*` 是 `n × m` 矩阵。

来源例 8：

```
A := ( 1 2 3i )     A^T = ( 1  4 )     A* = ( 1  4 )
     ( 4 5  6 )            ( 2  5 )          ( 2  5 )
                            ( 3i 6 )          ( −3i 6 )
```

## 性质表

对于所有的实数或复数 `α` 和 `β`，有

```
(A^T)^T = A                              (A*)* = A
(αA + βB)^T = αA^T + βB^T                (αA + βB)* = ᾱA* + β̄B*
(CD)^T = D^T C^T                         (CD)* = D* C*
(Q^{-1})^T = (Q^T)^{-1}                  (Q^{-1})* = (Q*)^{-1}
```

前置假设：A 和 B 有相同的行数和列数；矩阵乘积 CD 存在（要求 C 和 D 相配）；Q 的逆矩阵存在（要求 `det Q ≠ 0`），此时 `Q*` 和 `Q^T` 的逆矩阵也存在。

## 命名

矩阵 `(Q^{-1})^T` 称为 Q 的**逆步矩阵**，见 [[逆步矩阵]]。

## 证据类型

定义 + 性质表 + 算例（例 8）。注意伴随的标量线性性带有共轭：`(αA + βB)* = ᾱA* + β̄B*`。见 [[转置矩阵]]、[[伴随矩阵]]。
