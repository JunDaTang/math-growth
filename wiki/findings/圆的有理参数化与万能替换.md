# 圆的有理参数化与万能替换 $t=\tan\frac{\varphi}{2}$ 的由来

## 陈述（源文例 1）

积分

```latex
J = \int R(x, \sqrt{1 - x^{2}})\,\mathrm{d}x \tag{3.57}
```

可写为 $\int R(x, w)\,\mathrm{d}x$ 的形式，其中曲线为圆

```latex
C: x^{2} + w^{2} = 1.
```

圆的亏格为零，其一个有理参数化为

```latex
x = \frac{t^{2} - 1}{t^{2} + 1}, \quad w = \frac{2t}{t^{2} + 1}.
```

令

```latex
t = \tan\frac{\varphi}{2} \tag{3.58}
```

则得

```latex
x = \cos\varphi, \quad y = \sin\varphi \tag{3.59}
```

这便解释了替换 (3.58) 对形如 $\int R(\cos\varphi, \sin\varphi)\,\mathrm{d}\varphi$ 的积分是万能的原因。

## 证据评估

- 这是构造性例证：给出显式参数化与显式替换，可直接验证，故置信度为 high。
- 该例证同时也是 [[亏格判据有理表示等价]] 中「亏格为零 ⇒ 存在有理表示」方向的一个具体支持。
- 记号问题：式 (3.59) 第二分量在源文中写作 $y$，而前文一律使用 $w$ 且语境中无 $y$，疑似讹误，见 [[383节式359的y与w记号疑似讹误]]。此问题不影响结论本身。
