# 矩阵乘法公式 (2.7) 与 (2.8)

## 陈述

**公式 (2.7)** 给出矩阵乘法的基本思想：

```
(a, b) · (α; β) := aα + bβ                                  (2.7)
```

来源例 3：`(1,3) · (2; 4) = 1·2 + 3·4 = 2 + 12 = 14`。其自然推广为内积：

```
(a_1, ..., a_n) · (α_1; ...; α_n) = a_1α_1 + ... + a_nα_n
```

**公式 (2.8)** 给出乘积的元素：`A ∈ Mat(m,n)` 与 `B ∈ Mat(n,l)` 的乘积是 `C = AB ∈ Mat(m,l)`，满足

```
c_jk = A 的第 j 行乘以 B 的第 k 列                            (2.8)
c_jk = Σ_{s=1}^{n} a_js b_sk
```
