# 例 3：带余项除法

## 内容

来源给出

```
(3x^4 - 10x^3 + 22x^2 - 24x + 10)/(x^2 - 2x + 3)
  = 3x^2 - 4x + 5 + (-2x - 5)/(x^2 - 2x + 3)
```

相应的分解式为

```
3x^4 - 10x^3 + 22x^2 - 24x + 10
  = (x^2 - 2x + 3)(3x^2 - 4x + 5) + (-2x - 5)
```

余项多项式为 $R(x) = -2x - 5$。

## 长除法竖式（原文）

```
 3x^4 - 10x^3 + 22x^2 - 24x + 10        (除法: 3x^4 ÷ x^2 = 3x^2)
 3x^4 -  6x^3 +  9x^2                    (乘法: (x^2 - 2x + 3)·3x^2)
----------------------------------------
       -4x^3 + 13x^2 - 24x + 10          (减法+除法: -4x^3 ÷ x^2 = -4x)
       -4x^3 +  8x^2 - 12x                (乘法: (x^2 - 2x + 3)·(-4x))
----------------------------------------
                5x^2 - 12x + 10          (减法+除法: 5x^2 ÷ x^2 = 5)
                5x^2 - 10x + 15          (乘法: (x^2 - 2x + 3)·5)
----------------------------------------
                      -2x - 5             (减法)
```

来源将方法概括为：除以最高项，与除式相乘，作减法，除以所得到的最高项，等等；当所得最高项不能再相除时，计算结束。

## 说明

- 竖式中「减法+除法」一行 $-4x^3 + 13x^2 - 24x + 10$ 系上一行相减后的结果，与最终分解式一致。
- 余项次数为 1，严格小于除式次数 2，满足 (2.19) 的条件。
