# 6.1.5 节：相关系数、回归直线与随机变量独立性

## 直接证据（来源陈述）

**二维模型**：给定几乎处处连续的非负函数 $\varphi: \mathbb{R}^2 \to \mathbb{R}$，$\iint_{\mathbb{R}^2}\varphi = 1$；$(X,Y)$ 为随机向量，$P((X,Y) \in G) := \iint_G \varphi$；边缘密度 $\varphi_X(x) := \int \varphi(x,y)\,\mathrm{d}y$、$\varphi_Y(y) := \int \varphi(x,y)\,\mathrm{d}x$；$Z = F(X,Y)$ 的均值与方差由二重积分给出。

**协方差与相关系数**：

```
Cov(X,Y) := (X − X̄)(Y − Ȳ) 的均值
r = Cov(X,Y) / (ΔX ΔY),  −1 ≤ r ≤ 1
```

来源明确断言：$|r|$ 越大，两个被测量的相关性（相互依赖性）越强。

**回归直线与最小二乘法**：考虑最小化问题 (6.6)，其解为回归直线

```
Ȳ + r (ΔY/ΔX) (X − X̄)
```

且 $\overline{(Y - a - bX)^2} = (\Delta Y)^2(1 - r^2)$；$r^2 = 1$ 与 $r = 0$ 分别对应最好与最差的线性逼近。来源指出该最小化问题「相应于高斯的最小二乘法」。用测量值估计 $\overline{X}$、$(\Delta X)^2$、$r$ 的公式中，方差分母取 $n-1$。

**独立性**：若 $\varphi(x,y) = a(x)b(y)$ 则 $X$ 与 $Y$ 相互独立，此时有概率乘法公式、均值乘法公式、$r = 0$、以及方差加法公式 $(\Delta(X+Y))^2 = (\Delta X)^2 + (\Delta Y)^2$。二维高斯密度为两个一维正态密度之积，$(\Delta(X+Y))^2 = \sigma_x^2 + \sigma_y^2$。

## 推断（非来源直述）

- 残差公式 $(\Delta Y)^2(1-r^2)$ 表明 $r^2$ 可解释为线性回归可解释的方差比例；但由于 $r^2 \leqslant 1$，残差非负。
- 来源只给出「独立 $\Rightarrow r = 0$」方向，未断言其逆，故不应把 $r = 0$ 当作独立性的判据。
- 来源文本在 (6.6) 中印作 $bX^2$（详见 [[queries/615节方程66中bX平方疑点]]），若按字面理解则该最小化问题不是线性回归，与上下文不符。
