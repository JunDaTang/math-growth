# 向量函数 C^k 类判据按分量函数

**陈述.** 区间 [a, b] 上的函数 r = r(t) 是 C^k 类的，**当且仅当**在某一笛卡儿坐标系中，所有分量函数 x = x(t), y = y(t), z = z(t) 在 [a, b] 上都属于 C^k 类（r = r(t) 的 C^k 类性质定义与实函数相同，参看 1.4.1）。

**来源.** [[sources/10-数学指南实用数学手册--10-191-速度和加速度--1kt6qq]]（1.9.1 节「光滑性」）。

**说明.** 判据只要求在**某一个**笛卡儿系中成立，这与 [[concepts/特征不变性]] 的思想一致；它也是 [[concepts/向量函数的泰勒级数]] 的适用前提。

**性质.** 定理性陈述，非经验发现；置信度 high，复制状态不适用（null）。
