# 行矩阵线性无关的定义与例 1

**定义（源 2.1.4.5）** 设给定 $m$ 个行矩阵（脚注 1)）$A_1,\cdots,A_m$，长度为 $n$，并有实元素。如果

$$
\alpha_1 A_1 + \dots + \alpha_m A_m = \mathbf{0}
$$

仅当 $\alpha_1 = \cdots = \alpha_m = 0$ 时才成立，则称 $A_1,\cdots,A_m$ 线性无关；否则线性相关。类似定义对列矩阵（$n\times1$ 矩阵）成立。在「复方程组」段落中，源补充：若系数为复数，则 $\alpha_1,\cdots,\alpha_k$ 也必须是复数。

## 例 1

```
(i)  线性无关性。对于 A₁ := (1,0) 和 A₂ := (0,1)，α₁A₁ + α₂A₂ = 0 推出 (α₁,α₂) = (0,0)，
     因此 α₁ = α₂ = 0。这意味着 A₁ 和 A₂ 线性无关。
(ii) 线性相关性。对于 A₁ := (1,1) 和 A₂ := (2,2)，有 2A₁ − A₂ = (2,2) − (2,2) = 0，
     亦即 A₁ 和 A₂ 线性相关。
```

## 意义

该定义是 [[concepts/矩阵的秩]] 的基础（秩＝线性无关的列的最大个数）；例 1(ii) 中的线性相关关系与 [[findings/秩定理与例2]] 中「第二行为第一行两倍」的情形同型，正是无解/多解判别的代数根源。
