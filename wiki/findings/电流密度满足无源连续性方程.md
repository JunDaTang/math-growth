# 电流满足无源连续性方程 (1.169)

1.9.7 节「电流」段以一句话给出类比：

> 如果把质量换成电荷，且没有电荷生成，则得到关于电荷密度 $\rho$ 的 (1.169)。

即电荷密度与电流密度满足

```
ρ_t + div(ρ v) = 0
```

**性质**：这是原文给出的一处直接类比陈述，用于说明 (1.169) 的形式普适性；本节未对电流情形作独立推导。
