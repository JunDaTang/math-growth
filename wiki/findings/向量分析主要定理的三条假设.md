# 向量分析主要定理的三条假设与唯一性结论

## 问题与结论

问题为

```
div v = ρ  与  curl v = J,  在 D 上,
v n = g,  在 ∂D 上                             (1.173)
```

在 $\bar{D}$ 上有唯一 $C^2$ 类解 $v$，如果满足下列假设：

(i) $D$ 是 $\mathbb{R}^3$ 中有光滑边界的有界区域；$n$ 是边界上的外法线单位向量。

(ii) $\bar{D}$ 上给定的函数 $\rho$ 与 $J$ 足够光滑，并且 $g$ 在 $\partial D$ 上足够光滑。

(iii) 在 $D$ 上有 $\operatorname{div} J = 0$ 与

```
∫_D ρ ds = ∫_{∂D} g dF.
```

## 证据与保留意见

- 直接证据：来源「向量分析的主要定理」一段的三条假设与唯一性断言。
- 保留意见：假设 (ii) 中「足够光滑」为定性表述，未给出精确的 $C^k$ 阶数；边界条件在转录文本中写作 `v n = g`，按上下文应为 $v\cdot n = g$。
