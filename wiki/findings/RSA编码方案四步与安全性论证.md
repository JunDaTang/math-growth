# RSA 编码方案的四步流程及其安全性论证

## 直接证据（源文 2.7.8.1 节）

源文称 1977 年 [[里夫斯特]]（Rivest）、[[沙米尔]]（Shamir）及 [[阿德莱曼]]（Adlemann）公布此方案，并分四部分描述。

**操作器的准备**：

```
(i)  取两个素数 p 和 q，它们的大小大约为 10^100，并且要予以保密.
(ii) 作乘积  m = p q
     并计算  φ(m) = (p−1)(q−1).
(iii) 取另一个自然数 s，使适合  1 < s < φ(m).
(iv) 发送信息的人（公开地）给出两个数 m 和 s.
```

**信息编码**：把每个字母对应一个两位数 $10, 11, 12, \cdots$，连接得到大数 $n$，用 $m$ 除 $n^s$，将余数 $r$ 作为发出的信息：

```
n^s ≡ r mod m
```

**译码**：由 $\varphi(m)$ 与 $s$ 互素，存在自然数 $t \geqslant 1$ 使

```
t s ≡ 1 mod φ(m).        (2.95)
```

定理 $r^t \equiv n \bmod m$，故用 $m$ 除 $r^t$ 的余数即 $n$；且由 $m$ 的大小可知总有 $n < m$。

**证明**：由 [[费马-欧拉定理]] $n^{\varphi(m)} \equiv 1 \bmod m$；由 (2.95) 存在整数 $k$ 使 $ts = 1 + k\varphi(m)$，于是

```
r^t ≡ n^(st) ≡ n^(1 + kφ(m)) ≡ n mod m.
```

**安全性**：入侵者须知道 $t$，即须知道 $\varphi(m) = (p-1)(q-1)$，因而须分解公开数 $m$；诀窍在于 $p, q$ 的规模使现有计算机无法在合理时间内完成分解（[[整数分解困难性]]）。计算机能力增强意味着必须不断选用更大的 $p, q$；若出现快速整数分解算法，方法即不安全。源文并称，正因为此，「所有在这个领域从事研究的数学家都被 [[国家安全委员会]] 严密地监控」。

## 评注

- 四步流程即公钥 $(m, s)$ 与私钥 $t$ 的标准 RSA 构造，源文未使用「公钥/私钥」术语，而以「操作器」代指解密端。
- 最后一句关于国家安全委员会监控数学家的表述属非数学性评述，无法从数学内容推出，本页仅作如实转录。
