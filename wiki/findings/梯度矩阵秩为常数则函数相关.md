# 两个梯度矩阵的秩为常数 r（1≤r≤K）则函数相关

## 陈述

假设矩阵

```
(f_1'(x), ..., f_{K+1}'(x)) 与 (f_1'(x), ..., f_K'(x))
```

的秩是常数，等于某个 $r$，$1 \leqslant r \leqslant K$，则满足相关性关系式 $f_{K+1} = F(f_1, \dots, f_K)$（[[concepts/函数相关性]]）。

## 证据类型

来源陈述（原文定理），但存在转写风险，故 confidence 标为 low：

1. 原文未明确写出「两个矩阵的秩相等」这一通常必需的连接；
2. 未标明条件是充分、必要还是充要；
3. 未区分两个矩阵是否共用同一个 $r$。

因此不宜直接当作完整定理引用，需核对原书。追踪见 [[queries/155节定理表述是否缺少秩相等条件]]。

## 说明

$f_j'(x)$ 是偏导列矩阵（脚注 1) 的约定），见 [[concepts/梯度矩阵]]；秩不变意味着 $f_{K+1}'$ 不产生新方向。
