# 热密度时间导数公式 ρ_t = s μ T_t

1.9.7 节热流动机推导中的中间结果。由 $Q(t)=\rho(x,t)\Delta V$ 与 $\Delta Q = s\mu\Delta V\Delta T$，令 $\Delta Q = Q(t+\Delta t)-Q(t)$、$\Delta T = T(x,t+\Delta t)-T(x,t)$，得

```
( ρ(x,t+Δt) − ρ(x,t) ) / Δt = s μ ( T(x,t+Δt) − T(x,t) ) / Δt
```

取极限 $\Delta t \to 0$，得

```
ρ_t = s μ T_t
```

**符号注意**：此处的 $\rho(x,t)$ 在原文中被定义为「热密度」，与 (1.166) 中的质量密度 $\rho$ 含义不同；而在热流方程 (1.170) 中质量密度改记作 $\mu$，见 [[queries/197节符号rho在质量密度与热密度间漂移]]。

**转写提示**：源文档文本中该式左端的 $\rho(x,t)$ 在转录中有一处写作 $\beta(x,t)$（"$\rho(x,t+\Delta t) - \beta(x,t)$"），疑为 OCR/转写讹误，见 [[queries/197节热流推导中beta是否为rho的转写讹误]]。
