# 证明概述：(1.464) 由 (1.465) 与 (1.466) 推出

## 证明结构

令 $f := g/h$。把半圆围道的边界记作 $A_R + B_R$（图 1.177），半径 $R$ 选得足够大，使得上半平面中 $h$ 的所有零点都包含在半圆内部。由 [[柯西留数定理]] (1.462) 得

```text
∫_{A_R} f dz + ∫_{B_R} f dz = ∫_{A_R + B_R} f dz = 2πi Σ_{k=1}^{n} Res_{z_k} f.    (1.465)
```

此外，

```text
lim_{R→∞} ∫_{A_R} f dz = ∫_{−∞}^{∞} f(x) dx
lim_{R→∞} ∫_{B_R} f dz = 0                                                        (1.466)
```

当 $R \to \infty$ 时，由 (1.465) 即得断言 (1.464)。

## 大圆弧段的估计

(1.466) 由估计

```text
|f(z)| ≤ 常数 / |z²| = 常数 / R²,   对所有满足 |z| = R 的 z
```

得到，而该估计又由次数关系式 $\deg h \geqslant \deg g + 2$ 得出。再由周线积分的三角不等式：

```text
|∫_{B_R} f dz| ≤ (半圆周 B_R 的长度) · sup_{z ∈ B_R} |f(z)|
              ≤ (πR · 常数) / R² → 0,  当 R → ∞ 时。
```

## 证据类型与说明

- 源文档明确标示为「**证明概述**」，即非逐步完整证明。
- 脚注 ¹⁾ 强调所用常数与 $R$ 无关，这是估计能一致趋于零的前提。
- 该证明路线只适用于 (1.464) 这一特例（有理函数、$\deg h \geqslant \deg g + 2$）；源文档未给出 (1.462) 的一般证明。
