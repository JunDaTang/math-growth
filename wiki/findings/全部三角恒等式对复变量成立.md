# 三角函数的全部基本恒等式对复变量成立

## 观察内容

《数学指南——实用数学手册》0.2.8 节在多处**明确重复**同一个主张：所列的三角函数关系对**所有复数**成立，而不限于实数。被点名的至少包括：

- 幂级数定义 (0.34)："对所有复数 $x$，这两个级数都收敛。"
- [[欧拉公式]] (0.35) 与指数表示 (0.36)："对所有复数 $x$"。
- 加法定理 (0.37)："对所有复数 $x$ 和 $y$"。
- 周期关系 (0.38)："对所有复变量 $x$，这些关系都成立。"
- 对称性 (0.39)："事实上，对所有复数 $x$，这些关系都成立。"
- 毕达哥拉斯恒等式 (0.40)："不仅对实变量 $x$ 成立，对所有复变量 $x$ 也成立。"
- 平移法则、倍角与半角、求和与积化和差、方幂、三被加数加法定理、欧拉乘积公式、部分分式分解、导数公式，均标注"对所有复数"。

## 证据与推理

原文给出的统一证明路线是：由加法定理 (0.37)、$\sin 0 = \sin 2\pi = 0$ 与 $\cos 0 = \cos 2\pi = 1$，"很容易得到" (0.38)、(0.39)、(0.40) 对所有复数都成立；而加法定理本身由指数表示 (0.36) 加 $\mathrm{e}^{u+v} = \mathrm{e}^{u}\mathrm{e}^{v}$ 推出，后者对复数成立。另有一处更一般的说明：把 $\cos x$、$\sin x$ 写成 $\mathrm{e}^{\pm \mathrm{i}x}$ 的线性组合，便能证明"上述所有公式"，剩下的只是初等代数恒等式。

因此这一断言不是逐条独立验证的结果，而是**从一个复变量的定义出发、通过代数恒等式统一导出**的。

## 证据类型

直接证据：原文的显式陈述与所展示的推导路径。属于标准数学结论，本页记录的是手册选择反复强调这一点这一**表述特征**。

## 相关的边界情形

一个易被误解的对照点是零点：尽管所有恒等式对复数成立，$\sin x$ 与 $\cos x$ 在复平面上**仅有实零点**（见 [[三角函数的零点]]），其零点集合与实情形完全相同。这说明"解析延拓后恒等式保持"并不蕴含"零点集合扩张"。
