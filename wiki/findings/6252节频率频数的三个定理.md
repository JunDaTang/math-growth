# 6.2.5.2 节：频率与频数的三个定理（定理 1、2、3）

## 定理 1（频率 $H_n$）

```
(i)   P(H_n = k/n) = C(n, k) p^k (1−p)^{n−k},  k = 0, ..., n;
(ii)  H̅_n = p;
(iii) ΔH_n = √(p(1−p)) / √n;
(iv)  P(|H_n − p| ≤ ε) ≥ 1 − p(1−p)/(n ε²)   (切比雪夫不等式)。
```

原文附注：(iv) 中数 $\varepsilon > 0$ 必须充分小；当 $n$ 增大时，频率与期望值的差越来越小；该期望值就是 $e_1$ 在比较试验中发生的概率 $p$。

## 定理 2（频数 $A_n := n H_n$）

```
(i)   P(A_n = k) = P(H_n = k/n) = C(n, k) p^k (1−p)^{n−k};
(ii)  A̅_n = n H̅_n = np;
(iii) ΔA_n = √(np(1−p))。
```

## 定理 3（示性函数 $X_j$）

```
(i)   P(X_j = 1) = p;
(ii)  X̅_j = p,  ΔX_j = √(p(1−p));
(iii) X_1, ..., X_n 相互独立;
(iv)  H_n = (1/n)(X_1 + ... + X_n);
(v)   A_n = X_1 + ... + X_n。
```

## 解读

定理 3 是三项中结构意义最大的：它把频率与频数写成 [[示性函数]] 的平均与和，从而把伯努利模型接入一般随机变量理论。原文由此给出本节的核心论证：

> 于是，频数 $A_n$ 是一些可以同样处理的独立随机变量的叠加。因此，考虑到中心极限定理，我们预期当 $n$ 很大时，$A_n$ 近似服从正态分布。这就是棣莫弗-拉普拉斯定理的内容。

## 人物与方法评注

原文在此处插入两条方法论评注：

1. (i) 中给出的概率计算公式**使用起来不方便**，为此 [[棣莫弗]]、[[拉普拉斯]] 和 [[泊松]] 都曾尝试寻找适当的逼近公式（见 6.2.5.3）；
2. [[切比雪夫]] 不等式**对任意的随机变量都成立**——这解释了为何定理 1(iv) 无需二项分布的特殊结构即可使用。
