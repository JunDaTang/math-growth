# 对偶空间同构与对偶基

2.3.5 节。设 X 为 K 上的 n 维线性空间，则 $X^* \cong X$，但该同构不是典范的，与基 $b_1,\dots,b_n$ 的选取有关。定义

```text
b_j*(u₁b₁ + … + uₙbₙ) := u_j,   j = 1, …, n
```

则 $b_1^*,\dots,b_n^*$ 形成 $X^*$ 的基，称为对偶基。每个线性型可写成 $u^* = \alpha_1 b_1^* + \dots + \alpha_n b_n^*$；令 $A(u^*) := \alpha_1 b_1 + \dots + \alpha_n b_n$ 得双射 $A: X^* \to X$。

另一方面，$u^{**}(u^*) := u^*(u)$ 给出的同构 $X^{**} \cong X$ 是典范的（与基无关）。对无穷维空间，X 与 $X^*$、$X^{**}$ 的关系不再清晰（如巴拿赫空间，参看 [212]）。
