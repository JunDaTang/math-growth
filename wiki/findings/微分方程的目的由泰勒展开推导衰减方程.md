# 「微分方程的目的」：由泰勒展开推导衰减方程 (1.204)–(1.205)

源文的建模论证：不需知道放射性衰减的确切过程，也能推导出微分方程 (1.202)。为此考虑 [[泰勒]] 级数

```latex
N(t+\Delta t) - N(t) = A \Delta t + B(\Delta t)^2 + \dots   \tag{1.204}
```

假设 $A$ 正比于 $N(t)$；由于衰减，对 $\Delta t>0$ 有 $N(t+\Delta t)-N(t)<0$，所以 $A$ 必为负，因而令

```latex
A = -\alpha N(t).                                            \tag{1.205}
```

从 (1.204) 得 $N'(t)=\lim_{\Delta t\to 0}\frac{N(t+\Delta t)-N(t)}{\Delta t}=A=-\alpha N(t)$。

**评估**：这是**启发式建模论证**而非严格证明——「$A$ 正比于 $N(t)$」是外加假设，源文未给出其物理依据，也未讨论高阶项 $B(\Delta t)^2$ 的极限行为。同一展开式取 $A=+\alpha N(t)$ 即得增长方程 (1.206)，说明正负号的选取属建模选择而非数学结论。
