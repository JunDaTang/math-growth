# 欧几里得运动的定义与四类分类

## 陈述

以两个笛卡儿坐标系 $(x_{1}, x_{2}, x_{3})$ 与 $(x_{1}', x_{2}', x_{3}')$ 表示，一个欧几里得运动是

$$
\boldsymbol{x}' = \boldsymbol{D}\boldsymbol{x} + \boldsymbol{a},
$$

$\boldsymbol{a}=(a_{1},a_{2},a_{3})^{\mathrm{T}}$ 为常值列向量，$D$ 为正交矩阵（$DD^{T}=D^{T}D=E$）。显式形式为 $x_{j}' = d_{j1}x_{1} + d_{j2}x_{2} + d_{j3}x_{3} + a_{j}$，$j = 1, 2, 3$。

## 四类

| 类别 | 条件 |
|------|------|
| (i) 平移 | $D = E$ |
| (ii) 旋转 | $\det D = 1,\ \boldsymbol{a} = 0$ |
| (iii) 旋转反射 | $\det D = -1,\ \boldsymbol{a} = 0$ |
| (iv) 正常运动 | $\det D = 1$ |

所有运动的集合在复合下成群，即欧几里得运动群；所有旋转构成旋转群子群；所有平移（分别地，所有正常运动）构成平移群（分别地，正常欧氏运动群）子群。

## 证据性质

这是定义性陈述，源文件未给证明。分类的两个维度是：$D$ 是否为恒等（是否含平移分量）、$\det D$ 的符号（是否保定向）。
