# 相伴矩阵与基变换公式

2.3.3.4 节。与线性算子 A 关于基 $b_1,\dots,b_n$、$c_1,\dots,c_m$ 相伴的矩阵 $\mathscr{A} = (a_{jk})$ 由

```text
Ab_k = Σ_{j=1}^m a_{jk} c_j,   k = 1, …, n
```

定义，算子方程 $Au = v$ 对应于矩阵方程 $\mathcal{A}\mathcal{U} = \mathcal{V}$。定理：线性算子的和（或积）对应矩阵的和（或积）；线性算子的秩与相应矩阵的秩相同（与基无关）。

基变换：$b_k = \sum_r t_{rk} b_k'$、$c_j = \sum_i s_{ij} c_i'$，$\mathcal{T}$、$\mathcal{S}$ 可逆，则

```text
𝒰 = 𝒯𝒰′,   𝒱 = 𝒮𝒱′
𝒜′ = 𝒮⁻¹𝒜𝒯
```

特殊情形 $X = Y$ 且 $b_j = c_j$（所有 j），$\mathcal{S} = \mathcal{T}$，得相似变换 $\mathcal{A}' = \mathcal{T}^{-1}\mathcal{A}\mathcal{T}$。
