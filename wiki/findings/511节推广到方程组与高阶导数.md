# 5.1.1 节：推广——方程组 (5.4) 与带高阶导数的方程

**直接证据（本书陈述）**：

1. **方程组推广**：若 $q$ 为向量 $\boldsymbol{q} = (q_1, \cdots, q_F)$，则 (5.3) 由方程组 $\dfrac{\mathrm{d}}{\mathrm{d}t} L_{q_j'} - L_{q_j} = 0$，$j = 1, \dots, F$（(5.4)）代替。本节称此推广的工作属于 [[拉格朗日]]（1762）。
2. **力学实例**：取 $L = \text{动能} - \text{势能}$ 时 (5.4) 即 [[拉格朗日运动方程]]；此类变分问题 (5.2) 称为 [[queries/哈密顿稳态作用原理]]。
3. **高阶导数推广**：若 $L$ 依赖于直到 $n$ 阶导数，则 (5.4) 由逐项交替变号的方程 $L_{q_j} - \dfrac{\mathrm{d}}{\mathrm{d}t} L_{q_j'} + \dfrac{\mathrm{d}^2}{\mathrm{d}t^2} L_{q_j''} - \dots + (-1)^n \dfrac{\mathrm{d}^n}{\mathrm{d}t^n} L_{q_j^{(n)}}$ 代替；按稳态作用原理还须给定 $q_j^{(k)}$，$k = 0, 1, \cdots, n-1$ 在 $t_0$ 与 $t_1$ 的值。

**排版存疑**：高阶导数方程在原文中被竖线包围且未写出「$= 0$」，见 [[511节高阶导数方程缺少等于零记号与竖线符号]]。
