# 大地测量学基本公式：由笛卡儿坐标求距离与方位角

## 观察

《数学指南——实用数学手册》3.2.2 节在「大地测量学的基本公式」标题下给出：设已知由[[笛卡儿坐标]] $(x_A, y_A)$ 和 $(x_B, y_B)$ 给出的两个点 $A$ 和 $B$，其中假定 $x_A < x_B$（图 3.11），则距离 $d = AB$ 和角 $\alpha$ 满足

```
d = √((x_A − x_B)² + (y_A − y_B)²)
α = arctan((y_B − y_A) / (x_B − x_A))
```

## 符号行为

图 3.11 分为两种情形并给出方向角的符号约定：

- (a) $y_B > y_A$，故 $\alpha > 0$；
- (b) $y_B < y_A$，故 $\alpha < 0$。

## 证据强度

公式属解析几何中两点距离公式与斜率反正切的直接应用，证据充分。它是 [[前向切割]] 中 $c$ 与 $\delta$ 的来源，也是后续所有计算的公共基础。
