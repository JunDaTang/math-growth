# 表 0.5.3 在 x = 0 处与显式公式吻合

## 内容

把表 0.5.3 中 $x = 0.00$ 一行的数值与 0.5.3 节给出的显式表达式逐项对照：

| 函数 | 表值 | 由显式表达式所得 |
|---|---|---|
| $P_2(0)$ | -0.500 0 | $\frac{1}{2}(0-1) = -0.5$ |
| $P_3(0)$ | 0.000 0 | $\frac{1}{2}(0-0) = 0$ |
| $P_4(0)$ | 0.375 0 | $\frac{1}{8}(0-0+3) = 0.375$ |
| $P_5(0)$ | 0.000 0 | $\frac{1}{8}(0-0+0) = 0$ |
| $P_6(0)$ | -0.312 5 | $\frac{1}{16}(0-0+0-5) = -0.3125$ |
| $P_7(0)$ | 0.000 0 | $\frac{1}{16}(0-0+0-0) = 0$ |

六项全部一致。

## 证据与作用

- 该吻合同时验证了两件事：显式表达式的转写无误，以及 [[表053首列兼作x与P1x]] 中关于列对应的判读正确（若列对应错位，$x=0$ 处的常数项不会全部对上）。
- $x=0$ 处的取值同时体现奇偶性：奇数阶 $P_3, P_5, P_7$ 为 0，偶数阶 $P_2, P_4, P_6$ 为非零常数。
