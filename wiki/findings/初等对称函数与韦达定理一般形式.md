# 初等对称函数与韦达定理的一般形式

## 定义

```
e₁ := x₁ + … + xₙ
e₂ := Σ_{j<k} x_j x_k = x₁x₂ + x₂x₃ + … + x_{n−1}x_n
e₃ := Σ_{j<k<m} x_j x_k x_m = x₁x₂x₃ + … + x_{n−2}x_{n−1}x_n
……
eₙ := x₁x₂…x_n
```

称为变量 $x_{1},\cdots,x_{n}$ 的初等对称函数。

## 韦达定理

如果 $x_{1},\cdots,x_{n}$ 是复系数多项式 $p(x):=a_{0}+a_{1}x+\cdots+a_{n-1}x^{n-1}+x^{n}$ 的复根，那么

$$a_{n-1}=-e_{1},\quad a_{n-2}=e_{2},\quad\dots,\quad a_{0}=(-1)^{n}e_{n}.$$

这可由 $p(x)=(x-x_{1})\cdots(x-x_{n})$ 推出。因此多项式的系数可以通过它的零点表示出来。

## 评注

一个多项式称为对称的，如果它在其变量的任何置换下不变；例如 $e_{1},\cdots,e_{n}$ 是对称的。这直接导向 [[concepts/对称多项式主定理]]。
