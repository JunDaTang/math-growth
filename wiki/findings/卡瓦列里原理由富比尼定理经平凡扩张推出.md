# 卡瓦列里原理由富比尼定理经平凡扩张推出

## 结论

设 $f: D \subseteq R^{N} \to C$ 是 [[concepts/容许函数]]。则

```latex
\int_{D} f(\boldsymbol{y}, \boldsymbol{z}) \mathrm{d}\boldsymbol{y} \mathrm{d}\boldsymbol{z}
= \int_{\mathbb{R}^{M}} \left(\int_{D} f_{*}(\boldsymbol{y}, \boldsymbol{z}) \mathrm{d}\boldsymbol{y}\right) \mathrm{d}\boldsymbol{z}
\tag{1.141}
```

其中

```latex
D_{z} := \{\boldsymbol{y} \in \mathbb{R}^{K} : (\boldsymbol{y}, \boldsymbol{z}) \in D\}
```

是 $D$ 的 $z$ 截面（见 [[concepts/z截面]]），而

```latex
f_{*}(\boldsymbol{y}, \boldsymbol{z}) :=
\left\{ \begin{array}{ll}
f(\boldsymbol{y}, \boldsymbol{z}), & \text{在} D \text{上}, \\
0, & \text{其他}
\end{array} \right.
```

是 $f$ 的**平凡扩张**（在 $D$ 外补零）。

## 推导关系（本条目的核心）

源文明确说明：**把 (1.140) 中的函数 $f$ 替换成它的平凡扩张 $f_*$，即从 (1.140) 推出卡瓦列里原理。**

因此在该手册的体系中：

- **富比尼定理**处理的是全空间 $\mathbb{R}^N$ 上的容许函数（见 [[findings/富比尼定理两种积分次序相等]]）；
- **卡瓦列里原理**处理的是任意区域 $D \subseteq \mathbb{R}^N$，其手段是把 $f$ 补零扩张到全空间，再套用富比尼定理。

两者共享「化为累次积分」的骨架，但**适用对象不同**：后者是前者经补零扩张（即 [[concepts/归约原理]] 的做法）得到的推论，而非与之并列的独立原理。这一区分对既有问题 [[queries/卡瓦列里原理与富比尼定理是否等同]] 构成直接证据。

## 前提与限制

- 前提是 $f$ 为容许函数，与 1.7.2 节的存在性定理体系一致。
- 内层积分写作 $\int_{D} f_*(\boldsymbol{y}, \boldsymbol{z})\,\mathrm{d}\boldsymbol{y}$，其中被积对象是扩张后的 $f_*$，积分域为 $\mathbb{R}^K$；源文的写法省略了 $D_z$ 在外层积分中的显式出现。
