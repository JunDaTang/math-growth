# 欧拉积分表示 (1.481) 对正实数成立

源文陈述：函数方程 $\Gamma(z+1) = z\Gamma(z)$ 的一个解是收敛积分

$$\Gamma(x) := \int_{0}^{\infty} \mathrm{e}^{-t} t^{x-1}\,\mathrm{d}t, \quad \text{对满足 } x > 0 \text{ 的所有 } x \in \mathbb{R}. \tag{1.481}$$

**证据类型**：教科书级陈述。源文此处把积分表示定义在正实数 $x > 0$ 上；随后在「更多的性质」之 (i) 中把成立范围扩展到满足 $\operatorname{Re} z > 0$ 的所有复数 $z$（见[[伽马函数解析延拓与一阶极点结构]]）。详见[[欧拉积分表示]]。
