# 施图姆定理与例 3

## 定理

设 $p(a)\neq0$，$p(b)\neq0$ 且 $a<b$，把欧几里得算法略加变形应用于 $p(x)$ 与 $p'(x)$：

```
p   = p' q − R₁
p'  = R₁ q₁ − R₂
R₁  = R₂ q₂ − R₃
……
R_m = R_{m+1} q_{m+1}
```

用 $W(a)$ 表示序列 $p(a),p'(a),R_{1}(a),\cdots,R_{m+1}(a)$ 中的变号数，则 $W(a)-W(b)$ 等于 $p(x)$ 在区间 $[a,b]$ 中的不同零点个数（重零点按 1 个计数）。如果 $R_{m+1}$ 是实数，那么 $p$ 没有重零点。

## 例 3

对 $p(x):=x^{4}-5x^{2}+8x-8$ 取 $a=-3,\ b=2$，得

$$p^{\prime}(x)=4x^{3}-10x+8,\quad R_{1}(x)=5x^{2}-12x+16,\quad R_{2}(x)=-3x+284,\quad R_{3}(x)=-1.$$

因 $R_{3}$ 为实数，故 $p(x)$ 没有重零点。$x=-3$ 时施图姆序列为 $4,-70,97,293,-1$，3 次变号，$W(-3)=3$；$x=2$ 时序列为 $4,20,12,278,-1$，$W(2)=1$。因 $W(-3)-W(2)=2$，故 $p(x)$ 在 $[-3,2]$ 中有两个实零点，且由例 2 知全部实零点都在此区间内。类似地得 $W(0)=2$，由 $W(-3)-W(0)=1$ 及 $W(0)-W(2)=1$ 得知 $p(x)$ 在 $[-3,0]$ 与 $[0,2]$ 中各有一个零点；其余的零点成共轭复数对。
