# 热流基本方程 (1.170)

1.9.7 节以方框形式给出热流的基本方程：

```
s μ T_t − κ ΔT = F                                               (1.170)
```

**符号（原文照录）**：

```
T(x,t)    在时刻 t 时在点 x 处的温度
F(x,t)    时刻 t 在点 x 放热的功率密度（单位时间内单位体积产生的热量）
μ, s, κ   分别表示质量密度、比热容与热传导系数
```

**推导链（原文动机）**：$Q(t)=\rho\Delta V$ → $\Delta Q = s\mu\Delta V\Delta T$ → $\rho_t = s\mu T_t$ → $\boldsymbol{J}=-\kappa\,\mathrm{grad}\,T$ → 代入 (1.166) 得 (1.170)。

**证据强度**：教材级结论；本节给出了推导动机，但未给严格的证明出处。
