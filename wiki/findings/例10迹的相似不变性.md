# 例 10：tr(C⁻¹AC) = tr A 的相似不变性

## 陈述

如果 `n × n` 矩阵 C 可逆，那么有关系式

```
tr(C^{-1} A C) = tr(A C C^{-1}) = tr A
```

## 推导依据

来源使用的正是迹的性质 `tr(AB) = tr(BA)`（见 [[矩阵的迹]]），先令 `B = C^{-1}A` 或 `A C` 完成循环移位，再用 `C C^{-1} = E` 化简。

## 证据类型

来源中的算例式结论，属直接陈述。见 [[矩阵的迹]]、[[逆矩阵]]。
