# 无奇点三次曲线亏格为 1 与椭圆积分不可有理化

## 陈述（源文例 2）

设 $-\infty < e_{1} < e_{2},\, e_{3} < \infty$。积分

```latex
\int R\left(x, \sqrt{(x - e_{1})(x - e_{2})(x - e_{3})}\right)\,\mathrm{d}x \tag{3.60}
```

可写为 $\int R(x, w)\,\mathrm{d}x$ 的形式，其中

```latex
w^{2} = (x - e_{1})(x - e_{2})(x - e_{3}).
```

这是个没有奇点的三次曲线，因此它的亏格为 1。这就是椭圆积分不能由有理替换解决的深层次原因。

## 替代求解工具

计算 (3.60) 需要替换

```latex
x = \mathcal{G}(t), \quad w = \mathcal{G}'(t)
```

以双周期（椭圆）魏尔斯特拉斯 G 函数解决（参看 1.14.17.3）。

## 历史叙述

源文指出，该事实在 18 世纪的过程中被逐步意识到，从而导致了在 19 世纪中椭圆函数理论的发展。

## 证据评估

- 结论「亏格 1 ⇒ 不存在有理替换」依赖 [[亏格判据有理表示等价]]，而后者在本节中仅作为被标注为经验法则的断言给出，未加证明，故本条置信度标为 medium。
- 「无奇点 ⇒ 亏格为 1」这一推理在本节中直接陈述，未给出计算过程。
- 源文式 (3.60) 括号不配对，且前提表述 $-\infty < e_{1} < e_{2},\, e_{3} < \infty$ 未给出 $e_{1}<e_{2}<e_{3}$ 的完整次序约束，见 [[383节式360括号不配对与例2前提次序存疑]]。

## 对照

与 [[圆的有理参数化与万能替换]] 相对照：亏格 0 的圆可由单周期三角函数替换解决，亏格 1 的三次曲线则需双周期椭圆函数解决；统一的解释框架是[[亏格]]。
