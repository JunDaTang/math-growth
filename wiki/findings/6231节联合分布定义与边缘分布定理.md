# 6.2.3.1 节：联合分布函数的定义与边缘分布定理

## 观察

源自《数学指南——实用数学手册》6.2.3.1 节（直接陈述，非推断）。

1. **定义**：随机向量 $(X,Y)$ 是使 $A_{x,y} := \{e \in E: X(e) < x, Y(e) < y\}$ 对任意实数对 $(x,y)$ 均为事件的函数对；其联合分布函数为 $\Phi(x,y) := P(X < x, Y < y)$。
2. **策略**：把随机向量的研究简化为对分布函数的研究。
3. **直观解释**：把平面看成一个总质量为 1 的质量分布，$\Phi(x_0,y_0)$ 为该开区域 $]-\infty,x_0[\times]-\infty,y_0[$ 内的质量（图 6.13）。
4. **定理**：分量 $X$ 与 $Y$ 是随机变量，$\varPhi_X(x) = \lim_{y\to+\infty}\varPhi(x,y)$，$\varPhi_Y(y) = \lim_{x\to+\infty}\varPhi(x,y)$。
5. **概率密度**：非负连续 $\varphi$ 满足 $\int_{\mathbb{R}^2}\varphi = 1$ 且 $\Phi(x,y) = \int_{-\infty}^{x}\int_{-\infty}^{y}\varphi(\xi,\eta)\,\mathrm{d}\xi\mathrm{d}\eta$；边缘密度为 $\varphi_X(x)=\int\varphi(x,y)\mathrm{d}y$、$\varphi_Y(y)=\int\varphi(x,y)\mathrm{d}x$。
6. 以上讨论可推广到 $n$ 维随机向量 $(X_1,\cdots,X_n)$。
