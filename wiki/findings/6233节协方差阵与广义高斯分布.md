# 6.2.3.3 节：协方差阵与广义高斯分布

## 观察

源自《数学指南——实用数学手册》6.2.3.3 节（直接陈述）。

**协方差阵**：对随机向量 $(X_1,\cdots,X_n)$，$c_{jk} := \operatorname{Cov}(X_j,X_k)$，$j,k = 1,\dots,n$，矩阵 $C = (c_{jk})$ 称为协方差阵。任何随机向量的协方差阵都是**对称矩阵且所有特征值非负**。

解释：
- (i) $c_{jj} = (\Delta X_j)^2$；
- (ii) $r_{jk}^2 := c_{jk}^2/(c_{jj}c_{kk})$ 是 $X_j$ 与 $X_k$ 的相关系数的平方；
- (iii) 若 $X_1,\cdots,X_n$ 相互独立，则所有 $j\neq k$ 有 $c_{jk} = 0$，协方差阵为对角矩阵，主对角线为各分量方差。

**广义高斯分布**：设 $A$ 为 $n\times n$ 实对称正定矩阵，若随机向量 $(X_1,\cdots,X_n)$ 的密度为

$$
\varphi(\boldsymbol{x}) := K \mathrm{e}^{-Q(\boldsymbol{x},\boldsymbol{x})},\quad Q(\boldsymbol{x},\boldsymbol{x}) := \tfrac{1}{2}\boldsymbol{x}^{\mathrm{T}}\boldsymbol{A}\boldsymbol{x},\quad K^{2} := \frac{\det \boldsymbol{A}}{(2\pi)^{n}},
$$

则其协方差阵为 $(\operatorname{Cov}(X_j,X_k)) = \boldsymbol{A}^{-1}$，且对所有 $j$ 有 $\overline{X_j} = 0$。

若 $A = \mathrm{diag}(\lambda_1,\cdots,\lambda_n)$，则 $X_1,\cdots,X_n$ 相互独立，且 $(\Delta X_j)^2 = \lambda_j^{-1}$，$j\neq k$ 时协方差为 0。
