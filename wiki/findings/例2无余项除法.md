# 例 2：无余项除法

## 内容

对于 $N(x) := x^2 - 1$ 及 $D(x) := x - 1$，取 $Q(x) = x + 1$ 及 $R(x) = 0$，则 (2.19) 被满足。实际上

```
x^2 - 1 = (x - 1)(x + 1)
```

这意味着

```
(x^2 - 1)/(x - 1) = x + 1.
```

## 说明

余项为零，即 $D(x) = x - 1$ 整除 $N(x) = x^2 - 1$。本算例演示带余除法中 $\deg R < \deg D$ 条件的退化情形（$R = 0$）。
