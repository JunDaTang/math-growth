# 例：e^{x_1}、e^{x_2}、e^{x_1+x_2} 的秩为 2 且 f_3 = f_1 f_2

## 陈述

设 $f_1(x) := \mathrm{e}^{x_1}$，$f_2(x) := \mathrm{e}^{x_2}$，$f_3(x) := \mathrm{e}^{x_1+x_2}$，则

```
f_1'(x) = (∂_1 f_1(x), ∂_2 f_1(x))^T = (e^{x_1}, 0)^T,   f_2'(x) = (0, e^{x_2})^T
det(f_1'(x), f_2'(x)) := e^{x_1} e^{x_2} ≠ 0
rank(f_1'(x), f_2'(x)) = rank(f_1'(x), f_2'(x), f_3'(x)) = 2   对所有 x = (x_1, x_2) ∈ ℝ²
```

因此 $f_3$ 在 $\mathbb{R}^2$ 中依赖于 $f_1, f_2$，并可得明确关系式

```
f_3(x) = f_1(x) f_2(x).
```

## 证据类型

直接证据：本节唯一的经验性验证，计算完整、行列式恒不为零，结论明确；故 confidence 为 high。

## 推算链条与局限

推算链条为：$\det(f_1', f_2') \neq 0$ ⇒ 秩恒为 $2 = K$（满秩） ⇒ 满足 [[concepts/相关性秩条件]] ⇒ 存在关系式，且显式关系式为 $F(u, v) = uv$。本例中的 $\det(f_1', f_2')$ 即映射 $(f_1, f_2)$ 在点 $x$ 处的 [[concepts/雅可比行列式]]。

局限：仅验证了「依赖成立」的正向情形，未给出秩非常数或两矩阵秩不等导致不依赖的反例，因此不能据此判断定理是充分还是充要条件。
