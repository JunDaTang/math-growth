# 连续性方程 (1.169) 与不可压缩条件

1.9.7 节给出：如果没有物质产生，则由 (1.166) 与 $\boldsymbol{J}=\rho\boldsymbol{v}$ 得到所谓的连续性方程

```
ρ_t + div(ρ v) = 0                                               (1.169)
```

不可压缩液体的一个特例由「$\rho=$ 常量」给出，由此可得

```
div v ≡ 0
```

原文对此的解释是：这说明不可压缩液体的体积不变。

**证据强度**：教材级结论，未给证明与出处。$\mathrm{div}\,\boldsymbol{v} \equiv 0$ 与 1.9.3 节「散度描述体积相对变化」的结论相互印证，参见 [[findings/形变定理旋度描述旋转散度描述体积相对变化]]。
