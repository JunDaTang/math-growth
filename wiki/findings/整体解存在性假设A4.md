# 整体解存在性：假设 (A4) 与线性增长定理

## 命题

源文 1.12.9.7 节指出，解的破裂归因于 (A3) 中 $f$ 快于线性增长；如果增长至多是线性的，那么情形就完全不同。相应假设为：

- (A4) 存在正常数 $c$ 和 $d$，使得

```text
|f(x, t)| ≤ c |x| + d,   对所有 (x, t) ∈ R^{n+1}.
```

定理：如果假设 (A1) 和 (A4) 被满足，那么初值问题 (1.321) 有唯一一个对所有时刻 $t$ 都存在的解。

## 证据与强度

- 证据类型：定理陈述，无证明、无出处。
- 关键点：结论同时包含**存在性**（对一切 $t$）与**唯一性**（「唯一一个」）。
- 与 (A3) 的分野：`(A4)` 是全局的线性上界，`(A3)` 是径向下界且指数 $\beta>2$；两者不可同时成立，因而不冲突。
- 置信度：转录置信度高。

## 关联

- 与 [[concepts/先验估计原理]] 形成两条独立的整体存在性判据：一条限制右端增长，一条限制解的先验界。
- 该结论与 [[concepts/有限时间爆炸]] 描述的破裂现象构成对照。
