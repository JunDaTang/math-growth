# 链式法则定理的两条前提均以邻域表述定义域

## 观察

《数学指南——实用数学手册》1.4.2 节给出的链式法则定理，其两条前提假设都不是单纯断言「导数存在」，而是先把定义域规定为相应点的**邻域**，再断言导数存在：

```text
(i)   函数 f: M → ℝ 的定义域是 p 的邻域 U(p)，并且导数 f'(p) 存在。
(ii)  函数 g: N → ℝ 的定义域是 f(p) 的邻域 U(f(p))，并且导数 g'(f(p)) 存在。
```

对应的结论为

```latex
F^{\prime}(p) = g^{\prime}(f(p)) f^{\prime}(p)
```

## 说明

- 「定义域是某点的邻域」这一措辞确保该点是定义域的**内点**，从而单侧差商之外的普通导数可以在该点有意义地被讨论。参见 [[邻域]]、[[可导性与连续性]]。
- 第一条前提作用在点 $p$（内函数自变量）；第二条前提作用在点 $f(p)$（外函数自变量，即内函数的像）。
- 原书未解释这两条邻域条件的必要性，也未给出定理证明；此点已记为开放问题 [[链式法则定理为何需要邻域前提]]。
