# 6.2.5.4 节：质量控制中的二项、泊松与正态三种算法（含两个数值算例）

## 问题设定

某工厂生产产品 $\mathcal{P}$（如灯泡），$\mathcal{P}$ 是次品的概率非常小，记为 $p$（例如 $p = 0.001$）；一个运输集装箱中装有 $n$ 件产品。

## 精确公式

```
(i)  P(A_n = r) = C(n, r) p^r (1 − p)^{n−r};
(ii) P(k ≤ A_n ≤ m) = Σ_{r=k}^{m} P(A_n = r)。
```

## 两种近似

**泊松近似**（$p$ 很小）：

```
P(A_n = r) = (λ^r / r!) e^{−λ},  λ = np；   数值表见 0.4.6.9。
```

**正态近似**（$n$ 充分大）：

```
P(k ≤ A_n ≤ m) = Φ_0((m − np)/√(np(1−p))) − Φ_0((k − np)/√(np(1−p)))；  Φ_0 查表 0.34。
```

## 例 1（泊松算例）

1000 只灯泡，$p = 0.001$，$\lambda = np = 1$；由 0.4.6.9：

```
P(A_1000 = 0) = 0.37
P(A_1000 = 1) = 0.37
P(A_1000 = 2) = 0.18
P(A_1000 ≤ 2) = 0.37 + 0.37 + 0.18 = 0.92
```

原文结论：集装箱中无残次灯泡的概率为 0.37（37%）；集装箱中至多有两只残次灯泡的概率为 0.92。

## 例 2（正态算例）

次品概率改为 $0.005$，则 10 000 只灯泡中至多有 100 只次品的概率为

```
P(A_10000 ≤ 100) = Φ_0(7) − Φ_0(−7) = 2Φ_0(7) = 1
```

原文结论：几乎可以肯定在这 10 000 只灯泡中至多有 100 只残次灯泡。

## 观察

两个算例分别演示了 $p$ 很小（用泊松）与 $n$ 很大（用正态）两种途径，正好对应 6.2.5.3 中 (6.23) 与泊松误差界给出的适用性判据。例 2 中标准化值取到 7，落在正态分布尾部极远处，故得概率实质为 1。
