# 6.1.4 节：高斯正态分布、切比雪夫不等式与置信区间

## 直接证据（来源陈述）

**连续型模型**：给定连续（或几乎处处连续）函数 $\varphi$，满足 $\int_{-\infty}^{\infty}\varphi\,\mathrm{d}x = 1$；由

```
P(a ≤ X ≤ b) := ∫_a^b φ(x) dx
```

定义概率，$\varphi$ 为概率密度，$\Phi(x) := \int_{-\infty}^{x}\varphi(\xi)\,\mathrm{d}\xi$ 为分布函数。均值 $\overline{X} := \int x\varphi\,\mathrm{d}x$，方差 $(\Delta X)^2 := \int (x-\overline{X})^2\varphi\,\mathrm{d}x$，$\Delta X$ 为标准差。

**切比雪夫不等式**：对任意 $\beta > 0$，

```
P( |X − X̄| > β ΔX ) ≤ 1/β²
```

特别地 $\Delta X = 0$ 时 $P(X = \overline{X}) = 1$。

**置信区间**：设 $0 < \alpha < 1$，测量值落入 $[\overline{X} - \Delta X/\sqrt{\alpha},\ \overline{X} + \Delta X/\sqrt{\alpha}]$ 的概率大于 $1-\alpha$；例 1 取 $\alpha = 1/16$，得到落入 $[\overline{X} - 4\Delta X, \overline{X} + 4\Delta X]$ 的概率大于 $15/16$。

**高斯正态分布 $N(\mu,\sigma)$**：密度为 $\varphi(x) := \frac{1}{\sigma\sqrt{2\pi}}\mathrm{e}^{-(x-\mu)^2/2\sigma^2}$，$\sigma > 0$，且 $\overline{X} = \mu$、$\Delta X = \sigma$。文中称正态分布是概率论中最重要的分布，依据是中心极限定理（见 6.2.4）。

**指数分布**：密度见表 6.3，用于描述产品使用寿命；$\int_a^b \frac{1}{\mu}\mathrm{e}^{-x/\mu}\,\mathrm{d}x$ 是寿命落入 $[a,b]$ 的概率，平均寿命为 $\mu$。

**分布的均值与标准差汇总**（表 6.3）：正态分布 $(\mu,\sigma)$；指数分布 $(\mu,\mu)$；均匀分布 $((b+a)/2,\ (b-a)/\sqrt{12})$。

**随机变量函数的均值与方差**：$Z = F(X)$ 时 $\overline{Z} = \int F(x)\varphi(x)\,\mathrm{d}x$，$(\Delta Z)^2 = \int (F(x)-\overline{Z})^2\varphi(x)\,\mathrm{d}x$；**均值加法公式**成立。

## 推断（非来源直述）

- 置信区间的半宽 $\Delta X/\sqrt{\alpha}$ 与 $1/\sqrt{\alpha}$ 成正比：置信水平越高（$\alpha$ 越小），区间越宽。
- 表 6.3 中指数分布的均值与标准差相等（同为 $\mu$），均匀分布的标准差只依赖区间长度 $b-a$，这与来源给出的公式一致。
