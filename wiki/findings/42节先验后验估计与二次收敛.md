# 4.2 节：先验估计、后验估计与二次收敛

**来源**：《数学指南——实用数学手册》4.2.5 节例。

**直接证据（来源明述）**：对 (4.10) 产生的序列 $(a_n)$，记全误差 $\Delta_n = a_n - \sqrt{2}$，则对 $n = 1, 2, \dots$ 有

```
Δ_{n+1} ≤ Δ_n²               （收敛速度：通常所说的二次收敛）
Δ_{n+2} ≤ 10^{−2^n}          （先验估计）
2/a_n ≤ √2 ≤ a_n            （后验估计）
```

来源称二次收敛表示「该过程收敛得非常快」。表 4.1 给出 $a_1 = 2$、$a_2 = 1.5$、$a_3 = 1.4118$、$a_4 = 1.414215$、$a_5 = 1.414213562$，并据此声称 $\sqrt{2} = 1.414213562 \pm 10^{-9}$。先验估计是在计算之前得到误差信息，后验估计使用已完成计算的信息，二者被类比于[[entities/康德]]的哲学；来源给出的实际经验是「后验估计比先验估计更精确」。
