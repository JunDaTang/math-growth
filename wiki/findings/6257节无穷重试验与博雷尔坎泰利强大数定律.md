# 6.2.5.7 节：无穷重伯努利试验与博雷尔-坎泰利强大数定律

## 构造

为系统阐述强大数定律，把试验重数增加到无穷大：全体事件 $E$ 由基本事件 $e_{i_1 i_2} \ldots$ 组成，每个 $i_j$ 取值 1 或 2；$A_{i_1 \ldots i_n}$ 表示由所有形如 $e_{i_1 \ldots i_n}$ 的基本事件组成的集合，并规定

```
P(A_{i_1 i_2 ... i_n}) = p_{i_1 i_2 ... i_n},        (6.29)
```

其中 $p_1 := p$，$p_2 := 1-p$（见 (6.18)）。$\mathcal{S}$ 表示对所有的 $n$ 包含一切 $A_{i_1 \ldots i_n}$ 的 $E$ 的最小 $\sigma$ 域。

## 存在唯一性定理

**定理** 在 $\mathcal{S}$ 的子集上存在满足性质 (6.29) 的**唯一确定的概率测度** $P$；于是 $(E, \mathcal{S}, P)$ 是一个概率空间。

这是把有限重模型提升为无穷重模型的合法性依据，属于 [[科尔莫戈罗夫公理化概率论]] 的标准手法。

## 强大数定律

频率由

```
H_n(e_{i_1 ... i_n} ...) = (1/n) × (e 的满足 i_j = 1 且 1 ≤ j ≤ n 的脚标 i_j 的个数)
```

定义。则**博雷尔（1909）-坎泰利（1917）强大数定律**在 $E$ 上**几乎必然成立**：

```
lim_{n→∞} H_n = p。
```
