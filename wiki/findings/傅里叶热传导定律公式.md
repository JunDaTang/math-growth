# 傅里叶热传导定律与几何含义

1.9.7 节给出热通量密度向量的一级近似，并归功于 [[entities/傅里叶]]（Fourier, 1768—1830）：

```
J = −κ grad T
```

原文对该式的解释（直接引用要点）：

- $\boldsymbol{J}$ 正交于 [[concepts/等温面]]；
- $\boldsymbol{J}$ 与温度的差成正比；
- $\boldsymbol{J}$ 指向温度下降的方向。

**证据强度**：原文明确称之为「傅里叶的结论」与「一级近似」，未给进一步出处。
