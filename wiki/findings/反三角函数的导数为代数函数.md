# 反三角函数的导数为代数函数

## 陈述

反三角函数的导函数是纯代数函数：

- $\dfrac{\mathrm{d}\arcsin x}{\mathrm{d}x} = \dfrac{1}{\sqrt{1-x^2}}$，$\dfrac{\mathrm{d}\arccos x}{\mathrm{d}x} = -\dfrac{1}{\sqrt{1-x^2}}$（$-1 < x < 1$）；
- $\dfrac{\mathrm{d}\arctan x}{\mathrm{d}x} = \dfrac{1}{1+x^2}$，$\dfrac{\mathrm{d}\operatorname{arccot} x}{\mathrm{d}x} = -\dfrac{1}{1+x^2}$（所有实数 $x$）。

## 证据与来源

来源为《数学指南——实用数学手册》0.2.12，以 boxed 形式列出，属标准微积分结果。

`source:` 字段指向 [[10-数学指南实用数学手册--10-0212-反三角函数--1g1n0g5]]。

## 意义

“超越函数的导数仍是代数函数”这一现象，使反三角函数在积分理论中充当把有理/根式积分归结为封闭形式的桥梁。与 [[正弦余弦的导数]] 相比，三角函数求导仍留在三角体系内（$\sin' = \cos$），而反三角函数求导则离开了三角体系，进入代数函数范畴——这是两者在结构上的不对称之处。
