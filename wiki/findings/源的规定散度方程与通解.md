# 源的规定：散度方程及其通解

## 陈述

在 $\mathbb{R}^3$ 中 [[可缩区域]] $D$ 上给定 $C^1$ 类函数 $\rho : D \to \mathbb{R}$，则在 $D$ 上总存在 $C^2$ 类向量场 $D$，满足

```
div D = ρ,  在 D 上.
```

## 通解

```
D = D_par + curl A,
```

其中 $D_{par}$ 是特解，$A$ 是 $D$ 上任意 $C^3$ 类向量场。

## 证据与推断

- 直接证据：来源正文的「源的规定」一段。
- 推断：非唯一性来源于旋度自由度；若再用边界法向分量加以约束，自由度被消除（见 [[向量分析的主要定理]]）。
