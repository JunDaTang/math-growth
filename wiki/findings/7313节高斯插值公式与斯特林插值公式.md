# 7.3.1.3 节：高斯插值公式与斯特林插值公式

## 观察

1. 动机：某些情况下取区间中点为初值展开插值多项式是有意义的。等距插值点 $x_{j} = x_{0} + jh,\ j = 0, \pm 1, \cdots, \pm m$，插值点个数 $n = 2m+1$ 为奇数。
2. [[中心差分]] 的递归定义分为奇阶（下标 $j + 1/2$）与偶阶（下标 $j$）两条。
3. 由两个直观拟设多项式（$I^{(\mathrm{I})}$ 与 $I^{(\mathrm{II})}$，分别按 $\cdots(x - x_{1})(x - x_{-1})$ 与 $\cdots(x - x_{-1})(x - x_{1})$ 交替取因子）得到 [[高斯插值公式]] (I) 与 (II)；两者差别在于奇阶中心差分取自 $y_{0.5}$ 还是 $y_{-0.5}$，末项二项式系数为 $\binom{t+m-1}{n}$ 与 $\binom{t+m}{n}$。
4. [[斯特林插值公式]] 为两高斯公式的算术平均，用到平均差分 $\bar{\delta}^{k} y_{0} = \frac{1}{2}(\delta^{k} y_{0.5} + \delta^{k} y_{-0.5})$（$k$ 为奇数）；奇阶项用 $\bar{\delta}$，偶阶项用 $\delta$，偶阶项系数是 $t$ 的偶次多项式。

## 直接证据与推断

- 直接证据：中心差分递归定义、两个高斯公式与斯特林公式均显式给出。
- 推断：源文档未说明 $n$ 为偶数时中心差分展开应如何处理，仅假定插值点个数为奇数 $n = 2m+1$。
