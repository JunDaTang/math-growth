# 6.2.3.3 节：协方差、相关系数与回归直线

## 观察

源自《数学指南——实用数学手册》6.2.3.3 节（直接陈述）。

- **定义 1**：$\operatorname{Cov}(X,Y) := \overline{(X-\overline{X})(Y-\overline{Y})}$；相关系数 $r := \dfrac{\operatorname{Cov}(X,Y)}{\Delta X \Delta Y}$，且恒有 $-1 \leqslant r \leqslant 1$。
- **定义 2**：$r^2$ 越大，$X$ 与 $Y$ 的相关性越强。
- **回归直线**：最小化问题 $\overline{(Y-a-bX)^2} \stackrel{!}{=} \min.$ 的解为
  $$\overline{Y} + r \frac{\Delta Y}{\Delta X}(X - \overline{X}),$$
  其最小值为 $(\Delta Y)^2(1-r^2)$（回引 6.1.5 的讨论）。
- **协方差的测度论形式**（用 [[斯蒂尔切斯积分]] 表示）：
  $$\operatorname{Cov}(X,Y) = \int_E (X(e)-\overline{X})(Y(e)-\overline{Y})\,\mathrm{d}P = \int_{\mathbb{R}^2}(x-\overline{X})(y-\overline{Y})\,\mathrm{d}\Phi,$$
  其中 $\Phi$ 为联合分布函数。
- **例 1（离散型）**：若 $(X,Y)$ 只取 $(x_j,y_k)$ 且 $p_{jk} := P(X=x_j, Y=y_k)$，则
  $$\operatorname{Cov}(X,Y) = \sum_{j=1}^{n}\sum_{k=1}^{m}(x_j-\overline{X})(y_k-\overline{Y})p_{jk},$$
  其中 $\overline{X} = \sum_j x_j p_j$、$(\Delta X)^2 = \sum_j (x_j-\overline{X})^2 p_j$、$p_j := \sum_k p_{jk}$；$\overline{Y} = \sum_k y_k q_k$、$(\Delta Y)^2 = \sum_k (y_k-\overline{Y})^2 q_k$、$q_k := \sum_j p_{jk}$。
- **例 2（连续型）**：若 $(X,Y)$ 有连续密度 $\varphi$，协方差与 $r$ 可按 6.1.5 所述方法计算。
