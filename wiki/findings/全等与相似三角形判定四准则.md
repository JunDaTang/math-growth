# 全等与相似三角形的四准则（3.2.1.5 与 3.2.1.6）

## 观察（直接证据）

**全等（3.2.1.5）**：两个三角形全等（即它们由 3.1 中所描述的一个变换相关联），当且仅当满足下列四种情形之一：

1. 两条边和它们的夹角都相等；
2. 一条边和它的两个相邻角都相等；
3. 三条边都相等；
4. 两条边和它们的对角中最大的一个都相等。

**相似（3.2.1.6）**：两个三角形相似（即它们可由 3.1 的相似变换相互进行变换），当且仅当下列四个情形之一成立：

1. 两个角相等；
2. 边长的两对比率相等；
3. 边长的一对比率相等并且它们所夹的角也相等；
4. 边长的一对比率相等并且两条边中较长的一条的对角也相等。

**泰勒斯定理（射线定理）**：两条交于点 C 的直线被两条平行直线所截，则三角形 ABC 与 A′B′C 相似（理由：两个三角形的角和对应边的比率都相等），例如 $\frac{CA}{CA'} = \frac{CB}{CB'}$。

## 评估

全等的第 (iv) 条与相似的对应条 (iv) 都把「两条边与对角」的判别限定在**较大边（最大角）**一侧，正是为了排除 SSA/AAA 型的反例，这与 3.2.1.3 问题四的分情形讨论相呼应（见 [[queries/321节第四问题SSA判别条件疑似讹误]]）。两条判定定理均以 3.1 节的变换群语言（运动、相似变换）表述，属埃尔兰根纲领框架下的直接应用（见 [[concepts/埃尔兰根纲领]]）。
