# 轨道方程 (1.295) 与常数 (1.297)

## 结论（定理）

(1.294) 的解是

```text
r = p / (1 + ε cos φ)                                   (1.295)
```

此时时间 $t$ 的运动由

```text
t = ( m₂ / |N| ) ∫₀^φ r(φ)² dφ                          (1.296)
```

给出，其中的诸常数为

```text
p := N² / (α m₂),   ε := √(1 + 2 E N² / (m₂ α²)),   α := G m m₂   (1.297)
```

本源只讨论 $0 \leqslant \varepsilon < 1$ 的情形。

## 证明（据脚注 1)）

证明由直接求微商容易得到验证。脚注进一步说明：利用

```text
dφ/dr = φ'(t) / r'(t) = F(t),
```

并通过分离变量法积分此方程，就导致公式 (1.295)；函数 $F(t)$ 从 (1.294) 中第一个方程推导而得；此外从 (1.294) 中第二个方程即得 (1.296)。本源预告在 1.13.1.5 中将利用雅可比（C. G. J. Jacobi, 1804—1850）漂亮的方法来计算这个解。

## 证据与推理

- 直接证据：本源以「定理」形式给出 (1.295)–(1.297)。
- 推理归属：证明本身在本源中被压缩为「直接求微商容易得到验证」，细节由脚注 1) 补充；完整的分离变量计算未在本源中展开。
