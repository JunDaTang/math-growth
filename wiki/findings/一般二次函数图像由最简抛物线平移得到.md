# 一般二次函数图像由最简抛物线平移得到

## 主张

《数学指南——实用数学手册》0.2.3 节断言：(0.31) 式 \(y = ax^{2} + 2bx + c\) 的图像，可以通过把 (0.30) 式 \(y = ax^{2}\) 的图像的顶点 \((0,0)\) 平移到 \(\left(-\frac{b}{a}, -\frac{D}{a}\right)\) 得到，其中 \(D := b^{2} - ac\)。

## 依据

该主张的代数部分由配方恒等式

```latex
a x^{2} + 2 b x + c
= a \left(x + \frac{b}{a}\right)^{2} - \frac{b^{2} - a c}{a}
```

直接支撑（展开即可验证）。几何部分依赖于“\(y = f(x + p) + q\) 的图像是 \(y = f(x)\) 的图像平移 \((-p, q)\)”这一 [[函数图像的平移]] 规则。

## 证据强度与限定

- 证据类型：来源中的断言 + 可由展开验证的代数恒等式（直接证据）。
- 置信度：高（代数恒等式，无需经验验证）。
- 复现状态：未涉及实验，故记为 null。
- 限定：该结论适用于 \(a \neq 0\) 的一般二次函数；来源未讨论 \(a = 0\) 的退化情形（此时函数退化为 [[线性函数]]）。

## 与既有内容的关系

该发现是 [[标准形式经三类变换生成全部函数图像]] 在二次函数上的一个具体实例：二次函数图像族可由单一标准形式 \(y = ax^{2}\) 经平移生成，无需引入伸缩或镜射之外的额外变换类型（\(a\) 的符号与大小已包含在式 0.30 中）。它也把 [[二次配方与顶点形式]] 的代数结论与 [[二次函数的抛物线图像]] 的几何描述连接起来。

注意：来源采用的记法 \(D = b^{2} - ac\) 与通行教材的判别式不同，但该平移结论的形式（顶点坐标）在换算记法后与通行结论一致，见 [[二次判别式]]。
