# 诺伊曼函数 N_n 的定义与显式公式

## 结论

[[诺伊曼函数]] 由以下极限式定义（来源《数学指南——实用数学手册》1.14.22）：

$$N_n(z) := \frac{1}{\pi}\left.\left(\frac{\partial J_\alpha(z)}{\partial \alpha} - (-1)^n \frac{\partial J_{-\alpha}(z)}{\partial \alpha}\right)\right|_{\alpha = n}.$$

「更确切地说，由它可推出公式」：

```
N_n(z) = (2/π)(C + ln z − ln 2) J_n(z)
         − (1/π) Σ_{k=0..n−1} [(n−k−1)! / k!] · (2/z)^{n−2k}
         − (1/π) Σ_{k=0..∞} [(−1)^k / (k!(n+k)!)] · (z/2)^{n+2k} · (H_{n+k} + H_k)
```

其中 $C = 0.5772\cdots$（[[欧拉]]常数，[[欧拉]]），$H_k := \sum_{r=1}^{k} 1/r$ 且 $H_0 := 0$（[[调和数]]）。正文并称对所有复数 $z \in \mathbb{C}$ 幂级数收敛。

## 证据状况与结构观察

- 定义式与显式公式均由来源直接给出，未附推导。
- 显式公式含 $\ln z$ 项，与 1.14.20 中「情形 2：第二解含对数项」的预测一致，可视为 [[奇异微分方程]] 一般理论在整数阶贝塞尔方程上的应用与印证。
- 第二项为 $k = 0$ 到 $n-1$ 的**有限和**，贡献 $(2/z)$ 的负幂项（$z \to 0$ 时发散）；第三项为无穷级数，贡献 $(z/2)$ 的正幂项。这一「负幂 + $\ln z$ + 正幂」的结构是正则奇点处第二解的标准形态。
- 与 1.14.20 的对应关系属于跨节推理，来源本身只给出公式，未显式引用 1.14.20。
