# 伽马函数的解析延拓与一阶极点结构

源文关于伽马函数的解析延拓给出三条陈述：

1. 由 (1.481) 定义的实值函数 Γ 可以**唯一**扩展成复平面 $\mathbb{C}$ 上的一个亚纯函数（见[[解析延拓]]）。
2. 该函数的极点恰是 $z = 0, -1, -2, \cdots$，并且所有这些极点都是**一阶的**。
3. 对 $n = 0, 1, 2, \cdots$，在极点 $z = -n$ 邻域内的洛朗级数为

$$\Gamma(z) = \frac{(-1)^{n}}{n!\,(z+n)} + (z+n) \text{ 的幂级数}.$$

由此可直接读出极点 $z = -n$ 处的留数为 $(-1)^n / n!$。

此外，源文指出由[[恒等原理]]，[[伽马函数方程]] (1.480) 对不是 Γ 极点的所有复自变量 $z$ 都成立。

**证据类型**：标准复分析结论，教科书级陈述，证据强度高；源文未给出证明过程。相关条目见[[欧拉伽马函数]]。
