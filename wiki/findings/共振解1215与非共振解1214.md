# 共振解 (1.215) 与非共振解 (1.214)

在周期外力 $F(t):=\sin\alpha t$ 下考虑谐振子 (1.212)。

**非共振情形** $\alpha\ne\omega$，对所有时刻的唯一解为

```latex
x(t) = x_0 \cos \omega t + \frac{v}{\omega}\sin \omega t
+ \frac{\sin \alpha t + \sin \omega t}{2(\alpha+\omega)\omega}
- \frac{\sin \alpha t - \sin \omega t}{2(\alpha-\omega)\omega}.  \tag{1.214}
```

对所有制有界。

**共振情形** $\alpha=\omega$（即 $F(t):=\sin\omega t$），对所有时刻的唯一解为

```latex
x(t) = x_0 \cos \omega t + \frac{v}{\omega}\sin \omega t
+ \frac{\sin \omega t}{2\omega^2} - \frac{t}{2\omega}\cos \omega t .  \tag{1.215}
```

**关键观察**：末项 $t\cos\omega t$ 随 $t$ 增大无界，源文称其「是危险的」，「在日常生活中它可以导致一个结构的毁坏」。源文指出，该危险项可通过取极限 $\alpha\to\omega$ 从非共振解 (1.214) 得到，因而「就是可理解的」。
