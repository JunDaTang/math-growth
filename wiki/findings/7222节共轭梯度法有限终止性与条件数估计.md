# 7.2.2.2 节：共轭梯度法的有限终止性、条件数误差界与预条件

## 结论

《数学指南——实用数学手册》7.2.2.2 节给出 [[concepts/共轭梯度法]] 的适用前提（$A$ 对称正定、稀疏、大型）、变分基础（[[concepts/二次泛函]] 的极小化）、算法流程、$n$ 步有限终止性、以条件数平方根表示的误差界，以及通过[[concepts/预条件]]加速的完整框架。

## 直接证据（源文明确陈述）

1. **适用前提**：$A$ 对称正定，且为椭圆边值问题离散化产生的矩阵类型。
2. **变分基础**：解 $x$ 是 $F(v) := \frac{1}{2}v^{\mathrm{T}}Av + b^{\mathrm{T}}v$ 的极小点；极小按负梯度方向、逐次以共轭下降方向 $p^{(k)}$ 使 $F$ 在该方向极小化而得到。
3. **算法**（源文算法块逐字保留于 [[concepts/共轭梯度法]]）：初值 $r^{(0)} = Ax^{(0)} + b$、$p^{(1)} = -r^{(0)}$；$k>1$ 时由 $e_{k-1} = r^{(k-1)\mathrm{T}}r^{(k-1)}/r^{(k-2)\mathrm{T}}r^{(k-2)}$ 得 $p^{(k)} = -r^{(k-1)} + e_{k-1}p^{(k-1)}$；$z = Ap^{(k)}$，$q_k = r^{(k-1)\mathrm{T}}r^{(k-1)}/p^{(k)\mathrm{T}}z$；$x^{(k)} = x^{(k-1)} + q_k p^{(k)}$。
4. **正交/共轭性**：$r^{(k)}$ 两两正交，$p^{(k)}$ 两两共轭，$(p^{(k)})^{\mathrm{T}}Ap^{(j)} = 0\ (j<k)$。
5. **有限终止**：$n$ 个未知量最多 $n$ 次迭代得到解 $x$。
6. **子空间极小**：$F(x^{(k)}) = \min_{c_i} F\left(x^{(0)} + \sum_{i=1}^{k} c_i p^{(i)}\right)$，其中 $S_k := \operatorname{span}(\{p^{(1)}, \dots, p^{(k)}\})$。
7. **能量范数**：误差按 $\|z\|_A^2 = z^{\mathrm{T}}Az$ 关于 $S_k$ 极小。
8. **误差界**：$\dfrac{\|e^{(k)}\|_A}{\|e^{(0)}\|_A} \leqslant 2\left(\dfrac{\sqrt{\kappa(A)}-1}{\sqrt{\kappa(A)}+1}\right)^{k}$。
9. **步数估计**：$k \leqslant \frac{1}{2}\sqrt{\kappa(A)} \cdot \ln\left(\frac{2}{\varepsilon}\right) + 1$。
10. **预条件**：用 $C$ 作变换 $\tilde{A} = C^{-1}AC^{-\mathrm{T}}$、$\tilde{b} = C^{-1}b$、$\tilde{x} = C^{\mathrm{T}}x$；$K = C^{-\mathrm{T}}\tilde{A}C^{\mathrm{T}} = (CC^{\mathrm{T}})^{-1}A = M^{-1}A$；要求 $\kappa_2(M^{-1}A) \ll \kappa_2(A)$，且 $M = CC^{\mathrm{T}}$ 必须是 $A$ 的逼近；多种选取 $M$ 的方法参见 [425]。

## 推断部分

- 「误差界随 $\sqrt{\kappa(A)}$ 而非 $\kappa(A)$ 增长」是对源文误差界与步数估计的**概括性表述**，源文原文只说该上界「由容许值 $\varepsilon$ 和条件数 $\kappa(A)$ 的平方根决定」。
- $S_k$ 的两个生成向量组在源文中写作 $\{p^{(1)}, \dots, p^{(k)}\}$ 与 $\{p^{(0)}, \dots, p^{(k-1)}\}$，其一致性存疑，见[[queries/7222节子空间S_k的两个生成向量组不一致]]。

## 已记录的疑点

源文算法块中的剩余向量更新式 $r^{(k)} = x^{(k-1)} + q_k z$ 与常见递推形式不符，见[[queries/7222节共轭梯度算法中剩余向量r-k更新式疑为r-k-1减q_k z]]。该式若按字面理解，会与 $x^{(k)} = x^{(k-1)} + q_k p^{(k)}$ 的先验更新混杂，值得核校原文排版。
