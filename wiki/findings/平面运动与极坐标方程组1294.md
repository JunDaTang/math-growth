# 平面运动与极坐标方程组 (1.294)

## 结论

由角动量守恒 (1.293) 得，对所有时刻 $t$ 有 $\boldsymbol{x}(t)\cdot\boldsymbol{N} = 0$，因此运动被限制于垂直于向量 $\boldsymbol{N}$ 的平面内。选取 z 轴沿 $\boldsymbol{N}$ 方向，则

```text
x(t) = x(t) i + y(t) j.
```

引入极坐标 $x = r\cos\varphi,\ y = r\sin\varphi$ 与单位向量

```text
e_r  =  cos φ i + sin φ j,
e_φ  = -sin φ i + cos φ j,
```

得 $e_r' = \varphi' e_\varphi$、$x' = r' e_r + r\varphi' e_\varphi$，并由 $e_r\cdot e_\varphi = 0$ 得 $x'^2 = (r')^2 + r^2(\varphi')^2$。于是从 (1.292) 得到方程组

```text
m₂ ( r'² + r² φ'² - 2 G m / r ) = 2 E,
m₂ r² φ' = |N|.                                         (1.294)
```

## 证据与推理

- 直接证据：本源完整给出平面运动论证与 (1.294)。
