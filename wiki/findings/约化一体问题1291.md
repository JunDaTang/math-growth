# 约化一体问题 (1.291) 及其反解公式

## 结论

取相对坐标 $x := x_2 - x_1$，从 $x = y_2 - y_1$ 得到运动定律

```text
m₂ x'' = - G m m₂ x / |x|³,
x(0) = x₂₀ - x₁₀,   x'(0) = v₂ - v₁                    (1.291)
```

这是质量为 $m_2$ 的物体在质量为 m 的物体的引力场中的一体问题。

若已知 (1.291) 的解，则通过

```text
x₁(t) = y(t) - (m₂/m) x(t),   x₂(t) = y(t) - (m₁/m) x(t)
```

可得到原运动方程 (1.290) 的一个解。

## 证据与推理

- 直接证据：本源给出 (1.291) 与反解公式。
- 疑点（推断，非本源明言）：本源所印的反解式第二式用减号。按质心定义 $y = (m_1x_1 + m_2x_2)/m$ 与 $x = x_2 - x_1$ 直接验算，应为 $x_2(t) = y(t) + (m_1/m)x(t)$。故本源该处符号疑似转写讹误，详见 [[1125节反解公式x2符号疑义]]。
