# 6.2.5.3 节：伯努利大数定律与棣莫弗-拉普拉斯极限定理

## 伯努利大数定律

对任意 $\varepsilon > 0$，

```
lim_{n→∞} P(|H_n − p| < ε) = 1。        (6.19)
```

原文给出两条归属与化简说明：

1. [[雅各布-伯努利]] 通过**大量计算**发现了这条定律；
2. (6.19) 可由切比雪夫不等式（6.2.5.2 定理 1）得到；若利用定理 3 的结论 (iv)，则 (6.19) 是切比雪夫弱大数定律（见 6.2.4.1）的**一种特殊情况**。

## 棣莫弗-拉普拉斯局部极限定理

```
P(A_n = k) ~ (1/(σ√(2π))) e^{−(k−μ)²/(2σ²)},  μ = np, σ = √(np(1−p))。        (6.20)
```

含义：对每个 $k = 0, 1, \cdots$，当 $n \to \infty$ 时两边表达式**商的极限是 1**。

脚注 1 给出证明工具：[[棣莫弗]] 在 $n$ 很大时使用

```
n! = C √n (n/e)^n,  n → ∞ ,        (6.21)
```

其中 $C \approx 2.5047$；棣莫弗向 [[斯特林]]（1692—1770）求助，斯特林发现精确值 $C = \sqrt{2\pi}$，故 (6.21) 称为 [[斯特林公式]]。

## 棣莫弗-拉普拉斯全面极限定理

标准化量：$\mathfrak{H}_n := (H_n - \overline{H}_n)/\Delta H_n$（$\overline{\mathfrak{H}}_n = 0$，$\Delta \mathfrak{H}_n = 1$），$\mathfrak{A}_n := (A_n - \overline{A}_n)/\Delta A_n$；$\Phi_n$ 为 $\mathfrak{H}_n$ 的分布函数，$\Phi$ 为 $N(0,1)$ 的分布函数。原文指出 $\mathfrak{A}_n$ 等于标准化的频率 $H_n$，故 $A_n$ 的分布函数也是 $\Phi_n$。

```
lim_{n→∞} Φ_n(x) = Φ(x),  ∀x ∈ ℝ;
lim_{n→∞} P(a ≤ 𝓗_n ≤ b) = (1/√(2π)) ∫_a^b e^{−z²/2} dz。        (6.22)
```

定量误差界：

```
sup_{x∈ℝ} |Φ_n(x) − Φ(x)| ≤ (p² + (1−p)²)/√(np(1−p)),  n = 1, 2, ...。        (6.23)
```

原文据此指出：$p$ 非常小时必须 $n$ 非常大，正态逼近才有效——这引出泊松逼近（见 [[6253节泊松分布与泊松逼近定理]]）。

## 实用关系式 (6.24)

当 $n$ 较大时频率近似服从期望 $p$、标准差 $\sqrt{p(1-p)/n}$ 的正态分布，故

```
P(p + aΔH_n ≤ H_n ≤ p + bΔH_n) = Φ_0(b) − Φ_0(a)
  = (1/√(2π)) ∫_a^b e^{−z²/2} dz。        (6.24)
```

原文称该式「给出了伯努利大数定律的一个精确表述」，并给出等价形式

```
P(x ≤ H_n ≤ y) = Φ_0((y − p)/ΔH_n) − Φ_0((x − p)/ΔH_n);
P(u ≤ A_n ≤ v) = Φ_0((v − np)/√(np(1−p))) − Φ_0((u − np)/√(np(1−p)))。
```

$\Phi_0$ 的值可在表 0.34 中查到；当 $z$ 取负值时有 $\Phi_0(z) = -\Phi_0(-z)$。

## 历史归属

- [[棣莫弗]] 在 $p = 1/2$ 和对称边界 $b = -a$ 的情形发现了该公式（脚注 2）；
- [[拉普拉斯]] 在 1812 年出版的《分析概率论》（Théorie analytique des probabilités）中证明了这里给出的一般公式。
