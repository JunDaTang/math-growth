# 本征值问题 −x''=λx 的全本征解定理

本征值问题

```latex
\begin{array}{l}
-x''(t) = \lambda x(t), \\
x(0) = x(l) = 0 \quad (\text{边界条件}),
\end{array}
```

（$l>0$ 给定，非平凡解 $x\ne 0$ 称为本征解 $(x,\lambda)$，$\lambda$ 为本征值）。

**定理**：所有本征解由

```latex
x(t) = C \sin(n\omega_0 t), \quad \lambda = n^2\omega_0^2, \quad
\omega_0 = \frac{\pi}{l}, \quad n = 1,2,\dots
```

给出，$C$ 为任意非零常数。

**源文给出的证明**：利用 (1.213) 在 $x_0=0,\ F\equiv 0$ 时的解 $x(t)=\frac{v}{\omega}\sin\omega t$，并确定频率 $\omega$ 使质点在 $t=l$ 位于 $x=0$；由 $\sin(\omega l)=0$ 得 $\omega l = n\pi$，故 $\omega = n\frac{\pi}{l}=n\omega_0$。对 $x(t)=C\sin(n\omega_0 t)$ 求导即得 $x''(t)=-\lambda x(t)$，其中 $\lambda=n^2\omega_0^2$。

**注意**：源文称「所有本征解由…给出」，但给出的证明只展示了一族解满足方程，并未排除 $n$ 不是正整数或 $\lambda$ 为其他值的可能性（完整论证通常需讨论 $\lambda<0,\lambda=0,\lambda>0$ 三类情形）。
