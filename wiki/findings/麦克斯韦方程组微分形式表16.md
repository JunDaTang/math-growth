# 麦克斯韦方程组微分形式（表 1.6）

《数学指南——实用数学手册》1.9.10 节表 1.6 给出国际度量单位下的麦克斯韦方程组（前提 $D = \varepsilon_{0}E$、$B = \mu_{0}H$，$\varepsilon_{0}$ 为 [[介电常量]]，$\mu_{0}$ 为 [[真空透过性常量]]；$\rho$ 为 [[电荷密度]]，$\boldsymbol{j}$ 为 [[电流密度向量]]）：

| 方程 | 物理解释 |
|---|---|
| $\text{div}D = \rho$ | 电荷是电磁场 $E$ 的源 |
| $\text{curl }E = -B_{t}$ | 随时间而变的磁场产生电场的偶（感应律） |
| $\text{div}B = 0$ | 不存在磁感极小 |
| $\text{curl }H = j + D_{t}$ | 由电流或随时间而变的电场可产生磁场的偶 |
| $\rho_{t} + \text{div}j = 0$ | 电荷守恒（从其他方程即得） |

证据性质：教科书式直接陈述。表 1.6 中第一、第二、第五行所配的三张图片本次无法加载，图示内容未记录。表中“不存在磁感极小”与两处“偶”字为待核实措辞，详见 [[sources/10-数学指南实用数学手册--19-1910-对电磁学中麦克斯韦方程的应用--12vtrg6]]。
