# 例：x(t) ≥ tan t 与破裂下界

## 命题

源文 1.12.9.5 节的例题：令 $x=x(t)$ 是微分方程

```text
x'(t) = F(x(t)),   x(0) = 0
```

的一个解，其中对所有 $x\in\mathbb{R}$ 有 $F(x)\ge 1+x^2$。那么

```text
x(t) ≥ tan t,   0 ≤ t ≤ π/2,
```

并且因而 $\lim_{t\to\pi/2-0}x(t)=+\infty$。

## 证明（源文给出）

令 $f(y):=1+y^2$。对于 $y(t):=\tan t$，可以得到 $y'(t)=1+y^2$。现在从推论即得结论。

## 证据与强度

- 证据类型：源文给出简短的完整证明（使用前一 finding 的推论）。
- 结构说明：该例是「比较解给出精确的下界」的示范：比较解 $y=\tan t$ 本身就是不等式 $F\ge 1+x^2$ 的下界函数 $1+x^2$ 的解，因此解 $x$ 至少以 $\tan t$ 的速度增长，从而必定在 $\pi/2$ 之前（或其后不久）破裂。
- 置信度：推导完全可复算，置信度高。
- 注意区分：本例给的是**破裂下界**（解不慢于 $\tan t$），并非证明 $x$ 恰好等于 $\tan t$；源文 1.12.1 节的 [[findings/有限时间爆炸解tant]] 讨论的是方程本身其解即为 $\tan t$ 的情形，二者证据来源不同。
