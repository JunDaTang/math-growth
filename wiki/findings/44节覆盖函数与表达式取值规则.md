# 44 节：覆盖函数与表达式取值规则

**直接证据**

覆盖函数是映射 $b: \{q_1, q_2, \dots\} \to \{\mathrm{T}, \mathrm{F}\}$，为每个命题变元指派真值。给定 $b$ 后，表达式按下述规则取值（源文原貌）：

```
(i)   value(q_j) := b(q_j)
      value(¬A) := non(value(A))
(iii) value(A ∧ B) := et(value(A), value(B))
(iv)  value(A ∨ B) := vel(value(A), value(B))
(v)   value(A → B) := seq(value(A), value(B))
(vi)  value(A ↔ B) := eq(value(A), value(B))
```

例 1：$b(q) = \mathrm{T}$、$b(p) = \mathrm{F}$ 时，$\operatorname{value}(\neg p) = \operatorname{non}(\mathrm{F}) = \mathrm{T}$，$\operatorname{value}(q \to \neg p) = \operatorname{seq}(\mathrm{T}, \mathrm{T}) = \mathrm{T}$。

**观察**

- 规则列表中第二行缺少编号 (ii)，从 (i) 直接跳到 (iii)，见 [[queries/44节记法编号讹误与未落地引用]]。
- 由于每个表达式都是有限符号串，这一递归指派在有限步内终止，这是重言式可判定性（源文 4.4.1.3 (iv)）的基础。
