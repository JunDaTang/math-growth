# 闵可夫斯基-哈塞定理陈述与局部-整体原理

## 陈述

来自《数学指南——实用数学手册》2.7.10.3 节。

考虑方程

```
a_1 x_1^2 + … + a_n x_n^2 = 0          (2.98)
```

其中 a_1, …, a_n 是有理数，全不为零。

定理：如果对于 K = R 及 K = Q_p（p 是任意素数）方程 (2.98) 有非平凡解 x_1, …, x_n ∈ K (2.99)，那么它也有非平凡解 x_1, …, x_n ∈ Q (2.100)。

附注：称 (2.99) 中的解是局部的，(2.100) 中的解是整体的；定理表明由方程 (2.98) 的局部可解性可推出它的整体可解性。这是数论中一般的局部-整体原理的一个特殊情形，并表明了 p 进数域的基本性质。

## 范围限定（直接证据）

源文将该定理的适用范围**明确限定**于形如 (2.98) 的二次型方程，系数为全不为零的有理数。该断言不应被外推为对任意方程成立的普适结论。

## 证据强度

- 定理陈述直接引自源文，无证明、无条件限定（除系数非零外）；记为高置信度的陈述性内容。
- 附注中的「一般的局部-整体原理」为概念性归纳，属源文的推广性表述；本页仅记录源文的表述，不额外推广。

## 边界提示

该定理与 [[concepts/闵可夫斯基格点定理]]（同属闵可夫斯基名下，但属数的几何）是不同主题，不应混同。
