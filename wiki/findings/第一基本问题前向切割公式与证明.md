# 第一基本问题（前向切割）的公式与源文件证明

## 观察

《数学指南——实用数学手册》3.2.2.1 节的问题设定：已知两点 $A$、$B$ 及其坐标 $(x_A, y_A)$、$(x_B, y_B)$，测得角 $\alpha$ 与 $\beta$，求第三点 $P$ 的坐标 $(x, y)$。计算由下式确定 $b$ 与 $\delta$：

```
c = √((x_B − x_A)² + (y_B − y_A)²)
b = c · sin β / sin(α + β)
δ = arctan((y_B − y_A) / (x_B − x_A))
```

并得到

```
x = x_A + b · cos(α + δ)
y = y_A + b · sin(α + δ)
```

## 源文件给出的证明

利用图 3.12 中的直角三角形 $APQ$，有 $x = x_A + \Delta x = x_A + b\sin\varepsilon$ 与 $y = y_A + \Delta y = y_A + b\cos\varepsilon$。由 $\varepsilon = \pi/2 - \alpha - \delta$ 得到 $\sin\varepsilon = \cos(\alpha+\delta)$、$\cos\varepsilon = \sin(\alpha+\delta)$；由[[正弦定律]]得到 $b = c\,\sin\beta/\sin\gamma$；最后对 $\gamma = \pi - \alpha - \beta$（三角形的和角，见[[和角定律]]）得到 $\sin\gamma = \sin(\alpha+\beta)$。

## 证据强度

源文件给出的是自洽的完整证明，各步骤之间无跳步，证据充分。这是本节三个基本问题中唯一附带证明的一个。
