# 向量除法无意义使经典导数定义无法直接推广到多元

## 结论

经典定义

```latex
f'(p) = \lim_{h \to 0} \frac{f(p+h)-f(p)}{h}
```

**绝对不方便**推广导数概念到多元函数，因为此时 $h$ 是一个属于 $\mathbb{R}^N$ 的向量，**除以这样的向量没有意义**。而分解公式

```latex
f(p + h) - f(p) = f'(p)h + r(h)
```

总是有意义的。

## 理由

- 差商（见 [[差商]]）在一维时是实数之比，在多元时成为「向量 / 向量」或「向量值函数增量 / 向量」，缺乏定义。
- 分解式只涉及矩阵乘法与范数，不涉及除法，因而可以逐字推广到 $\mathbb{R}^N \to \mathbb{R}^k$，甚至推广到无穷维希尔伯特空间与巴拿赫空间上的算子。

## 直接证据与推断的区分

- 直接证据：本源原文的这段「现代观点」论述，是本源的**方法论性论断**，非可验证的数学命题。
- 由此得出的必然结论（属直接陈述）：现代微分理论基于 (1.45) 及一般策略 (1.47)，见 [[可导意味着线性化]]、[[弗雷歇导数]]。
