# 线性算子方程的解集与叠加原理

2.3.3.2 节。方程 $Au = v$ (2.50)。叠加原理：如果 $u_0$ 是 (2.50) 的一个特解，那么集合 $u_0 + \mathrm{Ker}(A)$ 是 (2.50) 的全部解的集合。

特别地，对 $v = 0$，子空间 $\mathrm{Ker}(A)$ 是 (2.50) 的解空间。因此，若 u 与 w 是齐次方程 (2.50)（$v = 0$）的解，则每个线性组合 $\alpha u + \beta w$ 也是其解。
