# 三角形四个基本求解问题的步骤与分情形判别

## 观察（直接证据）

源文档 3.2.1.3 节按已知量组合给出四种解法。

**问题一（c, α, β）**：$\gamma = \pi-\alpha-\beta$；$a = c\frac{\sin\alpha}{\sin\gamma}$，$b = c\frac{\sin\beta}{\sin\gamma}$；$A = \frac{1}{2}ab\sin\gamma$。

**问题二（a, b, γ）**：由正切定律 $\tan\frac{\alpha-\beta}{2} = \frac{a-b}{a+b}\cot\frac{\gamma}{2}$（$-\frac{\pi}{4} < \frac{\alpha-\beta}{2} < \frac{\pi}{4}$）唯一确定半差角，再由和角公式得 α、β，由 $c = \frac{\sin\gamma}{\sin\alpha}a$ 得第三边。

**问题三（a, b, c）**：求 $s$ 与 $r = \sqrt{\frac{(s-a)(s-b)(s-c)}{s}}$，由 $\tan\frac{\alpha}{2} = \frac{r}{s-a}$、$\tan\frac{\beta}{2} = \frac{r}{s-b}$（$0 < \frac{\alpha}{2}, \frac{\beta}{2} < \frac{\pi}{2}$）唯一确定角，面积 $A = rs$。

**问题四（a, b, α，SSA 情形）**：先由 $\sin\beta = \frac{b}{a}\sin\alpha$ (3.8) 定 β，分三种情形：

- $a > b$：$\beta < 90^{\circ}$，β 由 (3.8) 唯一决定；
- $a = b$：$\alpha = \beta$；
- $a < b$：若 $b\sin\alpha < a$，(3.8) 有两个解（一锐角一钝角）；**源文原文写「当 $b\sin\alpha = b$ 时我们有 $\beta = 90^{\circ}$」**；若 $b\sin\alpha > a$ 则无满足条件的三角形。

## 评估

前三问的步骤与标准解三角形流程一致，逻辑完整。问题四中「$b\sin\alpha = b$」这一临界条件与标准判别式 $b\sin\alpha = a$ 不符：正确的情形应为 $b\sin\alpha = a$ 时 β 为直角（对边恰等于高的特殊情况），源文写法疑为排印或 OCR 讹误，且与同段上一行使用的量纲（a 而非 b）不一致。参见 [[queries/321节第四问题SSA判别条件疑似讹误]]。
