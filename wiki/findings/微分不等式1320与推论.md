# 微分不等式 (1.320) 的定理与推论

## 命题

源文 1.12.9.5 节考虑方程组 (1.320)：

```text
x'(t) ≤ f(x(t)),   在 J 上,
y'(t) = f(y(t)),   在 J 上,
x(0) ≤ y(0),
```

其中 $J:=[0,T]$，并且 $f$ 是 $C^1$ 型的严格单调增函数。

定理：如果 $x$ 和 $y$ 是满足 (1.320) 的 $C^1$ 函数，且在 $J$ 上 $x(t)\ge 0$，那么

```text
x(t) ≤ y(t),   在 J 上.
```

推论：如果 $x$ 和 $y$ 满足 $x'(t)\ge f(x(t))$（在 $J$ 上）、$y'(t)=f(y(t))$（在 $J$ 上）、$0\le y(0)\le x(0)$，并且在 $J$ 上 $x(t)\ge 0$，那么 $0\le y(t)\le x(t)$ 在 $J$ 上成立。

## 证据与强度

- 证据类型：定理与推论陈述，无证明、无出处。
- 关键条件：$f$ **严格单调增**（用于比较不等式两侧）、$x(t)\ge 0$（保证与 $f$ 的作用域相容）；推论额外要求初值有序 $0\le y(0)\le x(0)$。
- 置信度：转录置信度高；$f$ 的定义域在源文中写法残缺（参见 [[queries/1129节微分不等式函数f定义域残缺]]）。

## 关联

- 定理给出上界比较（$x\le y$），推论给出双侧夹逼（$0\le y\le x$），两者合起来构成一类上下解方法的雏形。
- 源文末尾指出先验估计也可借助微分不等式获得。
