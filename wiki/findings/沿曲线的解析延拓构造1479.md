# 沿曲线的解析延拓构造 (1.479)

## 源文陈述

假设给定幂级数

$$
f(z) = a_0 + a_1 (z-a) + a_2 (z-a)^2 + \dots, \tag{1.479}
$$

它的收敛域为 $D = \{z \in \mathbb{C} : |z-a| < r\}$。选一个点 $b \in D$，并令 $z - a = (z-b) + b - a$。对级数 (1.479) 重新排序，得到新的幂级数

$$
g(z) = b_0 + b_1 (z-b) + b_2 (z-b)^2 + \dots,
$$

其收敛域为 $D' = \{z \in \mathbb{C} : |z-b| < R\}$（图 1.191(a)）。这里，在交集 $D \cap D'$ 上有 $f = g$。如果 $D'$ 包含不在 $D$ 里的点，令

$$
\text{在 } D \text{ 上 } F := f, \quad \text{在 } D' \text{ 上 } F := g,
$$

那么就得到了并集 $D \cup D'$ 上 $f$ 的一个解析延拓 $F$。可以尝试继续这个过程（图 1.191(b)）。

## 要点

- 构造的关键是「在收敛圆盘内部换心」：新圆盘 $D'$ 可以越出原圆盘 $D$ 的边界。
- 在 $D \cap D'$ 上 $f = g$ 保证分段定义的 $F$ 在重叠区无缝衔接，这正是 [[恒等原理]] 的用武之地。
- 迭代该过程即「沿一条曲线延拓」；迭代结果的路径无关性由 [[单值性定理]] 在单连通区域上保证。
