# 第二基本问题（后向切割）的公式与不共圆可解条件

## 观察

《数学指南——实用数学手册》3.2.2.2 节的问题设定：已知三个点 $A$、$B$、$C$ 及其[[笛卡儿坐标]]，测得待定点 $P$ 处的角 $\alpha$ 与 $\beta$（图 3.13），求 $P$ 的坐标 $(x, y)$。

**可解性条件**：源文件明确指出，这个问题只能在这四点不共圆时才有解。

计算先由辅助量出发：

```
x₁ = x_A + (y_C − y_A) · cot α
y₁ = y_A + (x_C − x_A) · cot α

x₂ = x_B + (y_B − y_C) · cot β
y₂ = y_B + (x_B − x_C) · cot β
```

再由

```
μ = (y₂ − y₁) / (x₂ − x₁),   η = 1 / μ
```

得到

```
y = y₁ + (x_C − x₁ + (y_C − y₁) · μ) / (μ + η)

x = { x_C − (y − y_C) · μ,   当 μ < η
    { x₁ + (y − y₁) · η,     当 η < μ
```

## 证据强度与未决点

源文件**未给出证明**，仅列出计算步骤，因此该公式的正确性在本源的证据链上属推断而非直接证据。此外存在两处待核验之处：辅助量中 $x$ 与 $y$ 两式对 $\cot\alpha$ 的搭配不对称（$x_1$ 用 $y_C - y_A$，$y_1$ 用 $x_C - x_A$），以及 $\mu < \eta$ 与 $\eta < \mu$ 两支的取解式是否与判据自洽。详见 [[queries/322节第二基本问题公式对称性与分支条件存疑]]。
