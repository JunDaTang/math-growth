# 化学反应动理学方程 (1.218) 与计量系数、反应阶、反问题

**反应形式**：给定 $m$ 种化学物质 $A_1,\dots,A_m$，
```latex
\sum_{j=1}^{m} \nu_j A_j = 0,
```
$\nu_j$ 为计量系数。分子数 $N_j$，密度 $c_j := N_j/V$。

**基本方程**：

```latex
\begin{array}{l}
\frac{1}{\nu_j}\frac{\mathrm{d}c_j}{\mathrm{d}t} = k c_1^{n_1} c_2^{n_2}\dots c_m^{n_m}, \quad j = 1,\dots,m, \\
c_j(0) = c_{j0} \quad (\text{初始条件}),
\end{array}                                       \tag{1.218}
```

$k$ 为正的反应速度常量（依赖 $p,T$），$n_1,n_2,\dots$ 为反应的阶。

**具体实例**：$2A_1+A_2\to 2A_3$ 对应 $\nu_1=-2,\nu_2=-1,\nu_3=2$；化学实例 $2\mathrm H_2+\mathrm O_2\to 2\mathrm H_2\mathrm O$。

**反问题（源文「注」）**：实际反应包含诸多子反应，人们常不知道子反应、$k$ 或 $n_j$，需由 $c_j(t)$ 的计量反推常量和 $c_j(t)$，这就是 [[反问题]]。

**跨领域应用（源文明确说明）**：这类方程及其变形经常出现在生物学中，此时 $N_j$ 是某种生物的数目，源文并提示与增长方程 (1.206) 和阻抗增长方程 (1.208) 比较。
