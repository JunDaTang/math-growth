# 体积位势与向量位势的定义式

## 定义

在 $D = \mathbb{R}^3$、$\rho$ 与 $J$ 为 $C^3$ 类且在某一球外为零、且 $\operatorname{div} J \equiv 0$ 的条件下：

```
V(x) := ∫_{R^3} ρ(y) dy / (4π|x − y|)
```

```
C(x) = ∫_{R^3} J(y) dy / (4π|x − y|).
```

前者称 [[体积位势]]，后者称 [[向量位势]]。

## 证据与推断

- 直接证据：来源「解的显式公式」一段。
- 推断：核 $1/(4\pi|x-y|)$ 为三维 [[拉普拉斯算子]] 的基本解（相差符号），故 $V$ 是泊松方程意义上的位势；来源未展开这一联系，属按标准结果的补充推断。
