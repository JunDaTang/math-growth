# 向量序列极限等价于终点距离趋于零

**陈述.** 设 (aₙ) 是向量序列，a 是固定向量，所有 aₙ 与 a 的基点同为点 O，则

```
a = lim_{n→∞} a_n   ⟺   lim_{n→∞} |a_n − a| = 0
```

即：当 n → ∞ 时，aₙ 与 a 的**终点间的距离**趋向于 0。

**来源.** [[sources/10-数学指南实用数学手册--10-191-速度和加速度--1kt6qq]]（1.9.1 节「极限」，图 1.94）。

**性质.** 这是一个**定义性陈述**（把向量的收敛归约为标量距离的收敛），而非经验发现，故不带经验证据；置信度按定义给出定为 high，复制状态不适用（null）。

**用途.** 该定义使得实值函数的全部极限性质可以照搬到 [[concepts/向量值函数]]，从而支撑 [[concepts/向量函数的连续性]]、[[concepts/速度向量]] 与 [[concepts/加速度向量]] 的定义。
