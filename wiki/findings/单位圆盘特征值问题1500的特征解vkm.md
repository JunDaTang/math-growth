# 特征值问题 (1.500) 的特征解 v_km

## 结论

对开单位圆盘 $D := \{(x, y) \in \mathbb{R}^2 \mid x^2 + y^2 < 1\}$ 上的 Dirichlet 特征值问题

```
−v_xx − v_yy = λ v ,   在 D 上
v = 0 ,               在 ∂D 上                                        (1.500)
```

来源《数学指南——实用数学手册》1.14.22 给出的特征解为

$$v_{km}(x, y) := \frac{1}{\sqrt{\pi}\,|J_k'(\lambda_{km})|} J_k(\lambda_{km} r)\, \mathrm{e}^{\mathrm{i} k \varphi}, \qquad \lambda = \lambda_{km},$$

其中 $k = 0, 1, \cdots$，$m = 1, 2, \cdots$，$x = r\cos\varphi$、$y = r\sin\varphi$；$0 < \lambda_{k1} < \lambda_{k2} < \cdots$ 是 [[贝塞尔函数]] $J_k$ 的零点。

## 证据与结构

- 结论由来源直接给出，未附推导。
- 结构上对应极坐标分离变量：径向部分为 $J_k(\lambda_{km} r)$（由 [[贝塞尔微分方程]] 得到），角向部分为 $\mathrm{e}^{\mathrm{i}k\varphi}$；边界条件 $v|_{\partial D} = 0$ 强制 $\lambda_{km}$ 取 $J_k$ 的零点。
- 归一化因子 $1/(\sqrt{\pi}|J_k'(\lambda_{km})|)$ 是把 $v_{km}$ 化为规范（单位长度）函数所需的常数，来源直接给出。
- 来源把特征参数写作 $\lambda = \lambda_{km}$，而 $\lambda_{km}$ 同时是 $J_k$ 的零点；这一记号的严格解释需要核对，见 [[11422节特征值疑应为lambda-km平方]]。
