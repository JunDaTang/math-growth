# 不等式两边乘除负数时不等号变向

## 观察

1.1.5 节区分了不等式的三种保持方向的运算（加减任意数、乘除正数）与两种改变方向的运算：

```latex
a \leqslant b,\ c < 0 \Rightarrow ac \geqslant bc, \qquad
a \leqslant b,\ c < 0 \Rightarrow \frac{a}{c} \geqslant \frac{b}{c}.
```

倒数法则 `0 < a ≤ b ⇒ 1/b ≤ 1/a` 也可视为同类现象的另一种表现。

## 证据与推论

该法则直接决定了例 3（线性不等式 ax − b ≥ 0）按 a > 0 与 a < 0 分情况讨论：

- a > 0：成立当且仅当 x ≥ b/a；
- a < 0：成立当且仅当 x ≤ b/a。

同理，二次不等式 (1.17) 的解集在 a > 0 的假设下写成含除法形式 x ≤ (−b − √D)/a 或 x ≥ (−b + √D)/a。

## 评估

教科书级结论；手册的贡献在于把「变号」与后续两类不等式的分类讨论明确挂钩。
