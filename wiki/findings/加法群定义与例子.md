# 加法群定义与例子

加法群 $(G,+)$ 满足：

```
(i)   g + (h + k) = (g + h) + k
(ii)  存在唯一 0，0 + g = g + 0 = g
(iii) 对每个 g 存在唯一 -g，(-g) + g = g + (-g) = 0
(iv)  g + h = h + g
```

例 3：所有实数 $\mathbb{R}$ 关于通常加法是加法群，整数集 $\mathbb{Z}$ 是 $\mathbb{R}$ 的加法子群。例 4：每个线性空间是加法群。

> 源文 (i) 写作 $g+(h+k)=(g+h)+h$，末项应为 $+k$，疑为 OCR 讹误。信心：定义高；措辞疑点见 query。
