# 例 3：线性方程组无解

源给出「不可解」情形的算例。设方程组

$$
\left\{ \begin{array}{l} 3 x _ {1} + 3 x _ {2} + 3 x _ {3} = 6, \\ 2 x _ {1} + 2 x _ {2} + 2 x _ {3} = 8 \end{array} \right.\tag{2.12}
$$

有解 $x_1,x_2,x_3$。应用例 1 中的方法（即以 $-2/3$ 乘第一行后与第二行相加）将导致矛盾

$$
\left\{ \begin{array}{c} 3 x _ {1} + 3 x _ {2} + 3 x _ {3} = 6, \\ 0 = 4, \end{array} \right.
$$

因此 (2.12) 确实没有解。

## 定位

该例是「形如 $0 = \beta_{r+1}$ 且 $\beta_{r+1} \neq 0$」这一无解标志的最简实例，对应 [[concepts/高斯算法]] 的情形 1；其理论判定由 [[concepts/秩判别法]]（$\operatorname{rank}(A) \neq \operatorname{rank}(A,b)$）与 [[concepts/弗雷德霍姆择一定理]] 给出。注意 (2.12) 左侧两行成比例而右端项不成同一比例，这正是矛盾之源。
