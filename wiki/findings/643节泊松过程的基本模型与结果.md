# 6.4.3 节：泊松过程的基本模型、三条假定与泊松分布结果

## 结论

在三条基本假定下，区间 $[t,s]$ 内恰好发生 $n$ 个事件 $\mathcal{E}$ 的概率为泊松分布：

$$
P_{n}(t,s) = \mathrm{e}^{-\mu(s-t)} \frac{\mu^{n}(s-t)^{n}}{n!}, \quad n = 0, 1, 2, \dots
$$

对于一个给定的固定区间 $[t,s]$，这是一个 [[concepts/泊松分布]]。

## 前提（三条基本假定）

```text
(i)   过程是时齐的，即 P_n(t, s) 只依赖于时间差 s − t，而不依赖于起始时刻 t。
(ii)  当 s − t → 0 时，P_1(t, s) = μ(s − t) + o(s − t)。
(iii) 当 s − t → 0 时，对于所有的 n = 2, 3, …，都有 P_n(t, s) = o(s − t)。
```

## 计数的均值与标准差

设 $X_{s-t}$ 为时间区间 $[t,s]$ 内事件 $\mathcal{E}$ 发生的次数，则

$$
\overline{X}_{s-t} = \mu(s-t), \quad \Delta X_{s-t} = \sqrt{\mu(s-t)}.
$$

即计数变量的方差等于其均值。

## 证据与推断的区分

- **直接陈述**：上述三条假定、泊松分布公式、均值与标准差公式，均为源文档原文给出（手册式陈述，以「结果 于是，有……」直接引出，**不含推导**）。
- **外部补充（非本节原文）**：把 $\mu$ 解释为「单位时间内的平均发生率」；把泊松过程视为连续时间马尔可夫过程的特例（与 [[concepts/马尔可夫链]] 关联）。这些是标准理论中的常见说法，但《数学指南——实用数学手册》6.4.3 节正文并未陈述。
- **边界**：均值与标准差公式针对的是**固定区间的计数变量** $X_{s-t}$，不可直接移用到过程本身，也不可与 [[concepts/泊松逼近定理]]（二项分布的泊松极限）的结论互换。
