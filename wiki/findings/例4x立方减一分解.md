# 例 4：x³ − 1 的分解式

## 内容

来源给出分解式

```
x^3 - 1 = (x - 1)(x^2 + x + 1)
```

并称可由下列算式得到（原文竖式）：

```
x^3 - 1
x^3 - x^2
---------
      x^2 - 1
      x^2 - x
      -------
            x - 1
```

## 说明与保留意见

- 分解式本身正确，等价于余项为零的带余除法（$N = x^3 - 1$，$D = x - 1$，$Q = x^2 + x + 1$，$R = 0$）。
- 来源中该竖式排版较简略（行序似有跳跃），属**排版呈现问题**，不构成数学错误。
