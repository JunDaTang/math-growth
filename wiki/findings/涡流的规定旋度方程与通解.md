# 涡流的规定：旋度方程及其通解（含唯一性张力）

## 陈述

给定 $\mathbb{R}^3$ 中 [[可缩区域]] $D$ 上的 $C^1$ 类向量场 $J$，则在 $D$ 上存在唯一一个 $C^2$ 类向量场 $H$，使得如果在 $D$ 上 $\operatorname{div} J = 0$ 时 $H$ 满足

```
curl H = J,  在 D 上.
```

前提 $\operatorname{div} J = 0$ 是 [[相容性条件]] 的一部分。

## 通解

```
H = H_par + grad U,
```

其中 $H_{par}$ 是特解，$U : D \to \mathbb{R}$ 是任意 $C^3$ 类函数。

- 直接证据：来源正文的「涡流的规定」一段，含「存在唯一」表述与通解公式。
