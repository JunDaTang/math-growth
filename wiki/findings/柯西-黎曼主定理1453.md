# 柯西(1814) 和黎曼(1851) 的主定理与 (1.453)

## 陈述（源文逐字保留）

复值函数 $f: U \subseteq \mathbb{C} \to \mathbb{C}$ 在 $z_0 \in \mathbb{C}$ 处[[复可微与复导数|复可微]]，**当且仅当** $u$ 与 $v$ 在点 $(x_0, y_0)$ 处[[弗雷歇可微]]，并且柯西-黎曼微分方程

```latex
u_x = v_y, \quad u_y = -v_x \tag{1.453}
```

在点 $(x_0, y_0)$ 处成立。这时有

```latex
f'(z_0) = u_x(x_0, y_0) + \mathrm{i} v_x(x_0, y_0).
```

其中 $z = x + \mathrm{i}y$，$f(z) = u(x,y) + \mathrm{i}v(x,y)$。

## 证据强度与性质

源文以「主定理」形式给出，未附证明，属手册式引用陈述；两个年份分别归属于柯西（1814）与黎曼（1851），是人物与结论的对应关系。该定理建立了复微分与偏微分方程理论之间的联系。

## 属主限定

结论针对复值函数 $f$（及其分量 $u, v$）；两个前提（弗雷歇可微、方程 (1.453)）缺一不可。
