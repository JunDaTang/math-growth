# 第二解：w₂(z) = z^{1−γ} 乘参数平移后的 F

## 陈述

对 [[高斯超几何微分方程]] (1.498) 取指数 $\rho_2 = 1 - \gamma$，在点 $z = 0$ 的某个邻域内，除了有 $w_1(z) = F(z;\alpha,\beta,\gamma)$，还得到 (1.498) 的第二个线性无关解

$$
w_2 (z) = z^{1 - \gamma} F (z; \alpha - \gamma + 1, \beta - \gamma + 1, 2 - \gamma).
$$

## 说明

- 解的形态是「幂因子 $z^{\rho_2} = z^{1-\gamma}$」乘「参数平移后的 [[高斯超几何函数]]」，三个参数的位移为 $\alpha \mapsto \alpha - \gamma + 1$、$\beta \mapsto \beta - \gamma + 1$、$\gamma \mapsto 2 - \gamma$。
- 指数 $\rho_2 = 1-\gamma$ 的来源见 [[超几何方程在z等于0处的指数方程与两根]]；两个解的构造方法同属 [[Frobenius幂级数解法]]。
- 本节声明 $w_1$ 与 $w_2$ 线性无关，但未给出 Wronskian 或其它独立性检验。

## 前提与边界

- 本节在 $\gamma$ 不是整数的前提下陈述该结果；若 $\gamma$ 为整数，两根之差 $\gamma-1$ 为整数，按 [[奇异微分方程]] 的情形 2，第二解将出现对数项，本式不再直接适用。
- 公式中第三个参数取 $2-\gamma$，与 [[高斯超几何函数]] 级数分母要求一致：当 $2-\gamma$ 为零或负整数（即 $\gamma$ 为不小于 $2$ 的整数）时分母 $(\gamma)_k$ 失效。
