# 质量平衡的基本方程 (1.166)

1.9.7 节以方框形式给出：

```
ρ_t + div J = F,  在 Ω 上                                       (1.166)
```

**符号约定（原文照录）**：

```
ρ(x,t)  在时刻 t 时在点 x 处的质量密度（单位体积的质量）
J(x,t)  在时刻 t 时在点 x 处的质量流的通量密度向量（单位面积与时间的质量）
F(x,t)  在时刻 t 时在点 x 处产生物质的力密度（单位体积单位时间生成的质量）
```

**适用范围**：原文的动机推导明确针对「能相互起化学反应的物质 $S$」，属理想均质连续介质模型。

**证据强度**：教材级结论，未给证明与出处。
