# 高斯定理（散度定理）公式

1.9.7 节以方框形式给出 [[concepts/高斯定理]]：

```
∫_D div J dx = ∫_{∂D} J_n dF
```

**条件（直接来自原文）**：$D$ 是 $\mathbb{R}^3$ 中的有界区域，有逐段光滑的边界 $^{1)}$ 及外法线单位向量 $\boldsymbol{n}$（图 1.103）；$\boldsymbol{J}$ 为 $\bar{D}$ 上的 $C^1$ 类向量场。

**来源与证据强度**：陈述性结论，教材级公认结果，未给证明与出处；脚注 $^{1)}$ 未录，疑含边界光滑性条件说明，见 [[queries/197节脚注1边界光滑性说明未录]]。
