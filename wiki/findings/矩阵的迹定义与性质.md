# 矩阵的迹的定义与性质

## 定义

`n × n` 矩阵 `A = (a_jk)` 的**迹**，记作 `tr A`，是 A 的对角元素之和：

```
tr A := a_11 + a_22 + ... + a_nn
```

来源例 9：`tr(a 2; 3 b) = a + b`。

## 性质

对于所有的复数 `α, β` 及所有的 `n × n` 矩阵 A, B：

```
tr(αA + βB) = α tr A + β tr B
tr(AB) = tr(BA)
tr A^T = tr A
tr A* = conj(tr A)
```
