# 4.2 节：存在性的构造证明——迭代序列收敛于 √2

**来源**：《数学指南——实用数学手册》4.2.4 节「存在性的构造证明」。

**直接证据（来源明述）**：证明迭代

$$a_{n+1} = \frac{a_n}{2} + \frac{1}{a_n}, \quad n = 1, 2, \dots \quad (4.10)$$

收敛于 $\sqrt{2}$，其中 $a_1 := 2$。

- 步骤 1：对 $n=1$ 显然 $a_n>0$；由 $a_n>0$ 与 (4.10) 得 $a_{n+1}>0$，据归纳法原理对所有 $n$ 成立。
- 步骤 2：$a_1^2 \geqslant 2$ 成立；若 $a_n^2 \geqslant 2$，则由[[concepts/伯努利不等式]]得
  $$a_{n+1}^2 = a_n^2\left(1 + \frac{2-a_n^2}{2a_n^2}\right)^2 \geqslant a_n^2\left(1 + \frac{2-a_n^2}{a_n^2}\right) = 2,$$
  故据归纳法原理 $a_n^2 \geqslant 2$ 对一切 $n$ 成立。
- 步骤 3：$a_n - a_{n+1} = a_n - \frac{1}{2}\left(a_n + \frac{2}{a_n}\right) = \frac{1}{2a_n}(a_n^2-2) \geqslant 0$，故 $(a_n)$ 递减有下界；据 1.2.4.1 关于递减序列的收敛性判据存在极限 $x$；在 (4.10) 中取极限得 $x = x/2 + 1/x$，即 $x^2 = 2$；又 $a_n \geqslant 0$ 故 $x \geqslant 0$，于是 $x = \sqrt{2}$。

**关联**：同一迭代在 4.2.5 节被用作误差估计与收敛速度讨论的实例（见 [[concepts/二次收敛]]）。
