# 系统宏观量的定义式

**来源**：《数学指南——实用数学手册》1.9.6 节。原文以「定义」为标题逐条给出以下量（此处照录）：

- 总质量 $M := \sum_{j=1}^{N} m_{j}$
- 重心 $r_{cm} := \frac{1}{M} \sum_{j=1}^{N} m_{j} r_{j}$
- 总动量 $P := \sum_{j=1}^{N} m_{j} r_{j}'$
- 总角动量 $A := \sum_{j=1}^{N} r_{j} \times m_{j} r_{j}'$
- 合力 $F := \sum_{j=1}^{N} F_{j}$
- 总力矩 $T := \sum_{j = 1}^{N} r_{j} \times F_{j}$
- 总动能 $T := \sum_{j = 1}^{N} \frac{1}{2} m_j r'_2$
- 总势能 $U$

**备注（转录疑义）**：总动能公式右端的 $r'_2$ 与总力矩使用了同一符号 $T$，两处均存在疑义，见 [[queries/196节总动能公式r2转写与符号T冲突]]。

**证据强度**：定义性陈述，直接来自原文；其中总角动量与总力矩含[[concepts/向量积]]。
