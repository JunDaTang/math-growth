# 反双曲函数的导数为代数函数

## 结论

原文给出的四个导数公式中，右端只出现根式 $\sqrt{1+x^{2}}$、$\sqrt{1-x^{2}}$ 与有理式 $\frac{1}{1-x^{2}}$，均不含双曲函数、指数函数或对数。因此，反双曲函数在其实数定义域内的导数都是代数函数。

## 依据

原文照录：

```
d(arsinh x)/dx = 1/√(1 + x²)
d(arcosh x)/dx = 1/√(1 - x²)
d(artanh x)/dx = 1/(1 - x²)
d(arcoth x)/dx = 1/(1 - x²)
```

这与 [[反双曲函数的对数表示]] 相符：对 $\ln$ 复合式求导，结果自然落在代数函数范畴。

## 限定与说明

- 该结论「导数为代数函数」只依赖导数式右端的函数类型，不依赖各式中被标注的区间条件；即使 [[反双曲函数导数公式的条件疑误]] 中指出的 $\operatorname{arcosh}$ 分母形式与 $\operatorname{artanh}$/$\operatorname{arcoth}$ 区间标注存在疑点，也不会改变右端为代数函数这一事实。
- $\operatorname{artanh}$ 与 $\operatorname{arcoth}$ 的导数表达式在原文中完全相同（$\frac{1}{1-x^{2}}$），二者仅在定义区间上互补。
- 这与 [[反三角函数的导数为代数函数]] 是平行结论。
