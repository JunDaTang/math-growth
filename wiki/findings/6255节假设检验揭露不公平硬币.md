# 6.2.5.5 节：以假设检验揭露不公平硬币（含 n = 10 000 算例）

## 方法论要点

原文明确：数理统计「认为『揭露一个骗子』只能在一定的**残概率**（比方说 $\alpha$）下才能进行」，残概率即所作结论不正确的概率。对 $\alpha = 0.05$，如果我们试图揭露一个骗子 100 次，平均约 5 次会作出错误结论，把无辜者当成骗子。

## 检验规则

假设 (H)：硬币是公平的，即 $p = 1/2$。记 $h_n = k/n$ 为频率 $H_n$ 的实现。

判决规则 (6.25)：如果

```
h_n 不在置信区间 [1/2 − z_α ΔH_n, 1/2 + z_α ΔH_n] 内，
```

则以残概率 $\alpha$ 放弃假设 (H)。其中

```
ΔH_n := 1/(2√n),   z_α 由 2Φ_0(z_α) = 1 − α 查表 0.34 确定。
```

原文给出的取值：对 $\alpha = 0.01$（相应地 0.05 和 0.1），$z_\alpha = 1.6$（相应地 2.0 和 2.6）——该对应关系与本 wiki 公认的标准正态分位数不同，见 [[queries/625节z-alpha取值与残概率对应疑点]]。

## 推理链

由 (6.24)：$n$ 很大时，$h_n$ 落入上述区间的概率为 $\Phi_0(z_\alpha) - \Phi_0(-z_\alpha) = 1 - \alpha$；若未落入则放弃 (H)，此时作出错误结论的概率是 $\alpha$。

## 数值算例（$n = 10\,000$）

```
ΔH_n = 1/200 = 0.05,  α = 0.05 → 置信区间 [0.49, 0.51]。        (6.26)
```

| 观测 | $h_n$ | 是否落入 (6.26) | 结论 |
|------|-------|------------------|------|
| 正面向上 5200 次 | 0.52 | 否 | 以 0.05 的出错概率下结论：硬币不公平 |
| 正面向上 5050 次 | 0.505 | 是 | 相信硬币其实是公平的；该结论正确概率 95%，错误概率 $\alpha = 0.05$ |

## 证据性质说明

- 直接证据：以上规则、$z_\alpha$ 取值、区间 (6.26) 与两个算例均逐字出自原文。
- 解释性推断：「放宽至 5200 次即判不公平」的力度取决于 $\alpha = 0.05$ 的选择，原文未讨论提高 $n$ 或降低 $\alpha$ 后的灵敏度变化。
