# 代数的定义与两条公理

**类型**：定义性陈述（非经验发现，不可证伪）。

## 陈述

定义 $\mathbb{K}$ 上的代数 $\mathcal{A}$ 是一个 [[线性空间]]，其中定义了乘法分配律和结合律。

更明显地说，这表明对于每个 $\mathcal{A}$ 中元素 $a$ 和 $b$ 的有序对 $(a, b)$，$\mathcal{A}$ 中存在唯一确定的与它们相关的第三个元素，将它记作 $ab$，使得对于所有 $a, b, c \in \mathcal{A}$ 及 $\alpha, \beta \in \mathbb{K}$，有

$$
(\mathrm{i})\; (\alpha a + \beta b) c = \alpha (a c) + \beta (b c), \quad c (\alpha a + \beta b) = \alpha (c a) + \beta (c b).
$$

$$
(\mathrm{ii})\; a(bc) = (ab)c.
$$

## 解读与边界

- 公理 (i) 刻画**双线性（左、右分配律）**；公理 (ii) 是**结合律**。将 (i) 仅称为「分配律」是不精确的。
- 该定义只覆盖**结合代数**；非结合代数（李代数、约当代数）不满足 (ii)，本节未涉及。
- 由定义可见，代数 = 线性空间 + 乘法，因而线性空间的一切结论对代数底层结构成立。

## 直接证据与推断

- **直接证据**：本节原文逐字给出上述定义与 (i)(ii) 两条公理。
- **推断**（非原文）：本节所定义的代数在 2.4 后续小节中扮演上位框架角色，张量代数、外代数、克利福德代数是其特例。此推断依据 [[多线性代数]] 的组织结构。
