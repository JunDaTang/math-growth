# 字问题与变形字问题公式

## 结论

- **字问题（有重组合，考虑顺序）**：从 $k$ 个字母着手，恰好可以形成 $k^n$ 个不同的长为 $n$ 的字。原文此式以图片形式给出（`images/a36e7e8b6f70dd7511931b82695bba8d1d034ab584ac84d602cd96e887f967c1.jpg`，图中为方框内的 $k^n$）。
- **变形字问题（有重组合，不考虑顺序）**：若两个字的差别仅在于字母的排列即视为等价，则等价字的频数等于

$$
\binom {n + k - 1} {n}.
$$

## 证据

**例 4** 以 0 与 1 为例：

- $n=k=2$：共 $2^2=4$ 个字（$0 0, 0 1, 1 0, 1 1$），等价字频数 $A=\binom{3}{2}=3$，代表为 $0 0, 0 1, 1 1$；
- $n=3, k=2$：共 $2^3=8$ 个字，等价字频数 $A=\binom{4}{3}=4$，代表为 $0 0 0, 0 0 1, 0 1 1, 1 1 1$。
