# 例 1：线性方程组依赖参数的解

源用小规模算例演示「解依赖于参数」的情形。给定

$$
\left\{ \begin{array}{l l} 3 x _ {1} + 3 x _ {2} + 3 x _ {3} = 6, \\ 2 x _ {1} + 4 x _ {2} + 4 x _ {3} = 8. \end{array} \right.\tag{2.9}
$$

## 计算过程

1. 用 $-2/3$ 乘第一行，得 $-2x_1-2x_2-2x_3=-4$；
2. 将该式与第二行相加，得

$$
\left\{ \begin{array}{c} 3 x _ {1} + 3 x _ {2} + 3 x _ {3} = 6, \\ 2 x _ {2} + 2 x _ {3} = 4. \end{array} \right.\tag{2.10}
$$

3. 由 (2.10) 第二式得 $x_2 = 2 - x_3$，代回第一式得 $x_1 = 2 - x_2 - x_3 = 0$。

## 结论

$$
x_1 = 0, \quad x_2 = 2 - p, \quad x_3 = p,\tag{2.11}
$$

其中 $p$ 是实数；若取 $p$ 为任意复数，则 (2.11) 是 (2.9) 在复数范围内的一般解。

## 备注

源用脚注 1) 补充了双向验证：一方面，这些考查确立了 (2.9) 的任何解必然有 (2.11) 的形式（即没有遗漏解）；另一方面，可以验证 (2.11) 确实是 (2.9) 的解。该脚注在源文件中保留完整，与 2.1.4 节中「用 Mathematica 求线性方程组的解」处的脚注情形不同。
