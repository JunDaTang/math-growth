# 矩阵定义与 Mat(m,n) 集合

## 陈述

来源（2.1.3 节）定义：`(m,n)` 型的矩阵 A 是一个有 m 行和 n 列的长方形的数表

```
A = ( a_11  a_12  a_13  ...  a_1n
      a_21  a_22  a_23  ...  a_2n
       ⋮     ⋮     ⋮           ⋮
      a_m1  a_m2  a_m3  ...  a_mn )
```

其中元素 `a_jk` 可以是实数或复数。`m = n` 的矩阵 A 称为**方阵**。所有 `(m,n)` 型的矩阵的集合记作 `Mat(m,n)`。

## 补充约定（来源脚注）

- 若所有的 `a_jk` 是实数，则称矩阵 A 是**实的**。
- `(m,n)` 型矩阵 A 的另一个记号是 `m × n` 矩阵。

## 证据类型

直接定义，非推断。见 [[矩阵]]、[[Mat-m-n]]。
