# 第三基本问题：跨越障碍的距离公式

## 观察

《数学指南——实用数学手册》3.2.2.3 节的问题设定：求图 3.14 中标出的两点 $P$ 与 $Q$ 之间的距离 $\overline{PQ}$，例如它们被一个湖分隔，因而不能直接测量。被测量的量是基线 $c = \overline{AB}$，以及四个角 $\alpha$、$\beta$（在 $A$ 处）与 $\gamma$、$\delta$（在 $B$ 处）。

计算由辅助量

```
ρ = 1 / (cot α + cot δ)
σ = 1 / (cot β + cot γ)
```

以及 $x = \sigma\cot\beta - \rho\cot\alpha$、$y = \sigma - \rho$，得到

```
d = √(x² + y²)
```

## 证据强度

源文件**未给出证明**，仅列出公式，因此该结果在本源中属未加推导的陈述。公式结构上把 $P$、$Q$ 的位置表达为两组余切组合之差，再取欧氏范数得到距离。
