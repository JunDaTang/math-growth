# 例：sin x 的误差估计不超过 (Δx)²/2

## 结论

对 $f(x) := \sin x$，因 $f''(x) = -\sin x$，故由一元误差估计得

```text
|Δf − Δx·cos x| ≤ (Δx)²/2
```

数值示例：当 $\Delta x = 10^{-3}$ 时，$(\Delta x)^{2} = 10^{-6}$。

## 说明

该例是 [[一元误差估计的泰勒二阶界]] 的具体化：因为 $|{-}\sin x| \le 1$，上确界项退化为 1，界简化为 $(\Delta x)^2/2$。示例中的具体数值（$10^{-6}$）仅用于说明量级，不构成本例的独立主张。
