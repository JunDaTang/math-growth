# 6.1.3 节：棣莫弗极限定理与二项分布的正态渐近

## 直接证据（来源陈述）

- 设 $A_{n,k}$ 为由恰好有 $k$ 个下标为「1」的所有基本事件 $e_{i_1 i_2 \cdots i_n}$ 组成的集合，则对 $A_{n,k}$ 中每个基本事件有 $H_n = k/n$，且

```
P(H_n = k/n) = C(n,k) · 1/2^n
```

- **棣莫弗定理（1730）**：当 $n$ 很大时，

```
P(H_n = k/n) ~ (1/(σ√(2π))) e^{−(k−μ)²/(2σ²)},  k = 1,2,…,n        (6.5)
```

其中 $\mu = n/2$，$\sigma = \sqrt{n/4}$。
- (6.5) 右边的函数就是高斯正态分布的概率密度；当 $k = n/2$ 时 (6.5) 中的概率 $P$ 取最大值。
- 定位：文中称得到 $n \to \infty$ 极限情形的易于理解的结果，是「概率论中最重要、最深刻的研究之一」。

## 推断（非来源直述）

- (6.5) 给出的是二项分布取单点频率值的局部渐近（局部极限定理）形式，其峰值位置与宽度分别由 $\mu = n/2$、$\sigma = \sqrt{n/4}$ 决定，与二项分布的均值 $np$、标准差 $\sqrt{np(1-p)}$ 在 $p = 1/2$ 时一致。
- 由 (6.5) 的离散概率向连续密度的过渡，是本节从[[concepts/古典概型]]走向[[concepts/高斯正态分布]]的关键桥梁。
