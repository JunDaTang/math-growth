# 高斯二次互反律（1796）、勒让德符号定义与补充公式

## 直接证据（源文 2.7.8.2 节）

**待研究的两个方程**：

```
x^2 ≡ q mod p        (2.96)
x^2 ≡ p mod q        (2.97)
```

**勒让德符号**：

```
( q / p ) := 1,   如 (2.96) 有解;
( q / p ) := −1,  如 (2.96) 无解.
```

**高斯二次互反律（1796）**：如果 $p$ 和 $q$ 是大于 2 的素数，那么

```
( q / p ) = (−1)^((p−1)(q−1)/4) ( p / q ).
```

**补充公式**：

```
( −1 / p ) = (−1)^((p−1)/2),   ( 2 / p ) = (−1)^((p^2−1)/8).
```

**历史评注**：该定理是 [[欧拉]]（1722）、[[勒让德]]（1785）及 [[高斯]] 独立地凭借经验发现的；[[高斯]] 给出第一个完全的证明。源文称「这个定律及其许多推广表述了我们熟知的数论中最深刻的基本性质」。

**示例**：设 $p = 4n + 1$ 是素数（$n$ 为某正自然数），则 $x^2 \equiv -1 \bmod p$ 有解，因为 $\left(\frac{-1}{p}\right)=1$。

## 评注

源文对三次互反律或更高次互反律未作展开，仅以「及其许多推广」一句带过。示例是补充公式 $\left(\frac{-1}{p}\right)$ 的直接应用：$p \equiv 1 \pmod 4$ 时指数 $(p-1)/2$ 为偶数，符号取 $+1$。
