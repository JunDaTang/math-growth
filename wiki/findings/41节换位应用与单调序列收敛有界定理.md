# 4.1 节：换位应用与单调序列收敛有界定理

**来源**：[[10-数学指南实用数学手册--8-41-数学的语言--1n7fdxn]]（4.1.2 例 3、例 4）

## 结果

1. **蕴涵的换位（例 3）**：由 (4.2) 得到「如果 m 不能被 2 整除，则 m 也不能被 6 整除」。
2. **逻辑等值的换位（例 4）**：设 $(a_n)$ 为递增（或递减）实数序列，定理

$$
(a _ {n}) \text {   是收敛的   } \Leftrightarrow (a _ {n}) \text {   是有界的.   }
$$

换位后得

$$
(a _ {n}) \text {   是不收敛的   } \Leftrightarrow (a _ {n}) \text {   不是有界的.   }
$$

即 (i) 一个递增（或递减）序列收敛当且仅当它是有界的；(ii) 一个递增（或递减）序列不收敛当且仅当它不是有界的。
