# 带余除法 (2.19) 与 (2.20)

## 内容

设 $N(x)$ 和 $D(x)$ 是两个多项式，并设 $D(x)$ 的次数至少是 $1$。那么存在**唯一确定**的多项式 $Q(x)$ 和 $R(x)$ 使得

```
N(x) = D(x)Q(x) + R(x),    (2.19)
```

其中余项多项式 $R(x)$ 的次数严格小于分母 $D(x)$ 的次数。代替 (2.19) 也可写成

```
N(x)/D(x) = Q(x) + R(x)/D(x).    (2.20)
```

## 归类与证据强度

- 这是多项式理论中的定理性陈述（存在唯一性），不是经验性结论。
- 证据来源为教科书标准内容，无外部实验或文献支撑。
- **独立断言**：唯一性是关于 $Q$ 与 $R$ 的，不涉及后续欧几里得算法中「末项非零余项即 gcd」的结论；二者须分开引用。
