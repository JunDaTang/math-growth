# 赋值定义与两例（平凡赋值、ν_∞ 与 ν_p）

## 陈述

来自《数学指南——实用数学手册》2.7.10.1 节。定义：设 K 是一个给定的域，域 K 上的（实）赋值对每个元素 x ∈ K 相伴一个实数 ν(x) ≥ 0，且满足：

(i) ν(x) = 0 当且仅当 x = 0；

(ii) ν(xy) = ν(x)ν(y) 及 ν(x + y) ≤ ν(x) + ν(y) 对所有 x, y ∈ K。

例 1（平凡赋值）：ν(0) = 0 及 ν(x) = 1（对所有 x ≠ 0）。

例 2a（Q 上的绝对值赋值）：ν_∞(x) := |x|，它产生 Q 上的一个赋值。

例 2b（Q 上的 p 进赋值）：若 p 是素数，Q 中的每个数可写成 x = (a/b)p^m（m 为整数，a、b 不能被 p 整除），令 ν_p(x) := p^(−m)。

## 证据类型

直接引自教材的定义与例证，属陈述性内容，无外部实验或数值数据支撑。

## 讹误提示

源文定义 (ii) 写作 `ν(xg) = ν(x)ν(y)`，左端应为 `ν(xy)`（乘法性），`xg` 为 OCR 讹误。参见 [[queries/2710节享泽尔写法与奥斯特罗夫斯基定理主语疑似讹误]]。
