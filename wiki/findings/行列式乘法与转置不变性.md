# 行列式乘法 det A det B = det(AB) 与转置不变性

**主张**：如果 $A = (a_{jk})$ 和 $B = (b_{jk})$ 是两个有 $n$ 行和 $n$ 列的方阵，那么

```latex
\det \boldsymbol{A} \det \boldsymbol{B} = \det(\boldsymbol{AB}).
```

并且

```latex
\det \boldsymbol{A} = \det \boldsymbol{A}^{\mathrm{T}},
```

其中 $A^{T}$ 表示 $A$ 的转置。

**记号说明**：$\det A$ 表示 $A$ 的行列式（即 (2.5) 中的 $D$）；$AB$ 表示两个矩阵的积。

**依赖**：方阵、矩阵积与转置的定义均置于 **2.1.3** 节（尚未入库），见 [[queries/212节引用213与153节未入库]]。

**推论用法**：乘法性质被直接用于函数行列式的链式法则，见 [[函数行列式]]。
