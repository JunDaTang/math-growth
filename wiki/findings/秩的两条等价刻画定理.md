# 秩的两条等价刻画定理

**定理（源 2.1.4.5）**

```
(i)  矩阵的秩等于其线性无关的行的最大个数，换言之，我们有 rank(A) = rank(Aᵀ)。
(ii) 矩阵的秩等于其不为零的子行列式的最大阶。
```

## 解读

- (i) 说明**行秩等于列秩**，并直接给出 $\operatorname{rank}(A) = \operatorname{rank}(A^{\mathrm{T}})$；转置矩阵见 [[concepts/转置矩阵]]。
- (ii) 把秩的计算归结为对 [[concepts/子行列式]] 的检验，是「行列式判别法」的理论依据（见 [[findings/秩定理与例2]] (ii)）。
- 两条刻画的共同前提是 [[concepts/行矩阵的线性无关性]] 的定义，其中的组合系数在复系数情形下要求为复数。

## 用途

这两条定理使 $r = \operatorname{rank}(A)$ 可以从不同角度获得：既可由消元（[[concepts/确定秩的算法]]）得到，也可由子行列式的阶判定。
