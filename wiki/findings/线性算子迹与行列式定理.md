# 线性算子迹与行列式定理

2.3.3.4 节。设 $\dim X < \infty$，定义线性算子 $A: X \to X$ 的迹和行列式为 $\operatorname{tr} A := \operatorname{tr}(a_{jk})$、$\det A := \det(a_{jk})$，二者均与基的选取无关。定理：对 $A, B: X \to X$，

```text
(i)   det(AB) = (det A)(det B)
(ii)  A 是双射 ⇔ det A ≠ 0
(iii) tr(αA + βB) = α tr A + β tr B
(iv)  tr(AB) = tr(BA)
(v)   tr I_X = dim X
```
