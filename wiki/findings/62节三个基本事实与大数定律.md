# 6.2 节：三个基本事实与由大数定律推出 (ii)(iii) 的断言

## 观察

源文列出「我们所体验到的三个事实」：

```
(i) 概率很小的事件极少会发生.
(ii) 概率可以用频率来估计.
(iii) 当完成并记录一定数量的试验之后，事件的频率是稳定的.
```

并断言：「大数定律从数学上说明，事实上，上述 (ii) 和 (iii) 可以由 (i) 推出。」

## 证据强度

该断言在源文中**未附推导**，属断言式概括，故本页置信度记为 medium。源文没有给出「(i) ⇒ (ii)」的具体概率模型或估计误差形式。

## 相关张力

- 与 [[concepts/频率]] 的经验定义之间：源文同时主张频率是后验的实验观测产物，而公理化模型假定的概率是先验的（与 [[entities/康德]] 哲学一致），由先验事实推出后验事实需要额外论证。
- 源文另作强历史判断：「在历史上，也曾经有人试图建立基于试验结果以及由试验得到的频率的概率理论，但没有取得任何成功。」该判断同样未附证据，见 [[queries/62节频率概率理论历史判断]]。
- 本节未复述 [[concepts/伯努利大数定律]] 的证明，6.1.2 节为本 wiki 中该定律的主要来源。
