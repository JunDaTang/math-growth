# 线性分式函数可经坐标平移化为标准形式 $y = -\Delta/(c^{2}x)$

## 陈述

对

```latex
y = \frac{ax+b}{cx+d}, \quad c \neq 0,\ \Delta := ad-bc \neq 0, \tag{0.44}
```

在坐标变换

```latex
x = u - \frac{d}{c}, \qquad y = w + \frac{a}{c}
```

之下化为

```latex
w = -\frac{\Delta}{c^{2}u}.
```

该变换把点 $(0,0)$ 变成点 $P\left(-\dfrac{d}{c}, \dfrac{a}{c}\right)$，即把标准等轴双曲线的渐近线交点平移到 $P$。

## 支持证据

代数变形推导（本书 0.2.15.2），并配图 0.38 分 $\Delta<0$、$\Delta>0$ 两情形。结论充分建立。

## 条件与边界

推导显式要求 $\Delta \neq 0$；$\Delta = 0$ 的退化情形源文未讨论（见 [[queries/线性分式函数Delta等于零的退化情形]]）。
