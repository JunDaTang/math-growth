# 由反函数法则导出 ln x 的导数

## 结论

在《数学指南——实用数学手册》0.8.2 节中，手册用 [[反函数求导法则]] 导出了自然对数的导数：

$$\frac{\mathrm{d}\ln y}{\mathrm{d}y} = \frac{\mathrm{d}x}{\mathrm{d}y} = \frac{1}{\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)} = \frac{1}{\mathrm{e}^{x}} = \frac{1}{y},\quad y > 0$$

## 推导路径（直接证据）

1. 取 $y = \mathrm{e}^{x}$，$-\infty < x < \infty$；
2. 其反函数为 $x = \ln y$，$y > 0$；
3. 由反函数法则 $\frac{\mathrm{d}x}{\mathrm{d}y} = \frac{1}{\mathrm{d}y/\mathrm{d}x}$，而 $\frac{\mathrm{d}y}{\mathrm{d}x} = \mathrm{e}^{x}$（表 0.35 中 $\mathrm{e}^{x}$ 的导数）；
4. 回代 $y = \mathrm{e}^{x}$ 得 $\frac{\mathrm{d}\ln y}{\mathrm{d}y} = \frac{1}{y}$。

## 与表 0.35 的关系

该结果正是表 0.35（[[一阶导数表]]）中 $\ln x$ 一行「导数 $= \frac{1}{x}$」的依据。手册在 0.8.1 节只是列出结果，在 0.8.2 节才给出推导，两者互为印证。

## 推断与限制

- 上述推导是手册原文给出的直接证据，不涉及推断。
- 手册未在此处讨论 $y$ 的复变量情形；表 0.35 对 $\ln x$ 的复范围要求 $x \neq 0,\ -\pi < \arg x < \pi$，该条件与本节推导所用分支无关，属于表外补充。
