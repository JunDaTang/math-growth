# 例 4：2×2 矩阵乘积的逐项计算

## 陈述

来源例 4：设

```
A := ( 1 2 )      B := ( 2 1 )
     ( 3 4 )           ( 4 1 )
```

则按公式 (2.8)：

```
c_11 = (1,2)·(2;4) = 1·2 + 2·4 = 10
c_12 = (1,2)·(1;1) = 1·1 + 2·1 = 3
c_21 = (3,4)·(2;4) = 3·2 + 4·4 = 22
c_22 = (3,4)·(1;1) = 3·1 + 4·1 = 7
```

于是

```
AB = C = ( 10  3 )
         ( 22  7 )
```

来源另给一例：

```
( 1 2 ) ( 1 0 2 )   ( 1 2 4 )
( 0 1 ) ( 0 1 1 ) = ( 0 1 1 )
```

## 证据类型

来源中的算例，用于验证公式 (2.8)。见 [[矩阵乘法]]。
