# 极坐标下拉普拉斯算子取形式 f_rr + (1/r²)f_φφ + (1/r)f_r

**结论：** 对 $f(r, \varphi) := F(x(r, \varphi), y(r, \varphi))$，在 $r > 0$ 下

```
Δf = f_rr + (1/r²) f_φφ + (1/r) f_r
```

**来源：** 《数学指南——实用数学手册》1.5.4 节公式 (1.64)。

**证据类型：** 直接证据。源文档给出两条相互独立的推导链（方法一从 $F(x,y) = f(r(x,y), \varphi(x,y))$ 出发并用逆公式 (1.61)；方法二从 $f(r,\varphi) = F(x(r,\varphi), y(r,\varphi))$ 出发、通过算子等式平方展开，不用逆公式），两条链都收敛到同一结果，可自洽复核。

**边界条件：** 结果在 $r > 0$ 上成立。方法一先对 $x \neq 0$ 证明，再取极限 $x \to 0$ 覆盖 $x = 0, y \neq 0$ 的情形。

**注意：** 该结论描述的是同一拉普拉斯算子在极坐标下的表达，而非另一个不同的算子。
