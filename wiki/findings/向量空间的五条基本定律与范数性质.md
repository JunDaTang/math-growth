# 向量空间的五条基本定律与范数性质

本手册 1.8 节以公式 (1.156) 给出以点 $O$ 为基的向量的运算定律。令 $a, b, c$ 是以点 $O$ 为基的向量，$\alpha, \beta$ 为实数，则

```latex
a + b = b + a,  (a + b) + c = a + (b + c),
α(βa) = (αβ)a,  (α + β)a = αa + βa,  α(a + b) = αa + αb.    (1.156)
```

原书明确说明：这五条定律的意思就是 $V(O)$ 是一个**实向量空间**（参看 2.3.2）。

与之配套地，公式 (1.157) 给出长度（范数）的三条性质：

```latex
|a| = 0 当且仅当 a = 0;
|αa| = |α||a|;
||a| − |b|| ≤ |a ± b| ≤ |a| + |b|.    (1.157)
```

原书指出：方程 (1.157) 蕴涵着 $V(O)$ 是**赋范向量空间**（参看 [212]）。

直接证据：以上公式与判断均直接见于 1.8.1 节正文；对「实向量空间」「赋范向量空间」的指认亦为该节原文表述。
