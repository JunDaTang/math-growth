# 二次曲面经旋转化为法式（含源文件证明）

## 定理

对三维二次型

$$
a_{11}x_{1}^{2} + 2a_{12}x_{1}x_{2} + 2a_{13}x_{1}x_{3} + 2a_{23}x_{2}x_{3} + a_{22}x_{2}^{2} + a_{33}x_{3}^{2} = b\tag{3.20}
$$

（设 $\det A \neq 0$，$\operatorname{tr}A = a_{11} + a_{22} + a_{33}$），应用一个旋转可化为

$$
\lambda x^{2} + \mu y^{2} + \zeta z^{2} = b,
$$

$\lambda, \mu, \zeta$ 为 $A$ 的特征值，且 $\det A = \lambda\mu\zeta$，$\operatorname{tr}A = \lambda + \mu + \zeta$。

## 源文件给出的证明

取三个特征向量 $u, v, w$，满足 $Au = \lambda u$、$Av = \mu v$、$Aw = \zeta w$；选取使得 $u^{T}v = u^{T}w = v^{T}w = 0$、$u^{T}u = v^{T}v = w^{T}w = 1$。令 $D := (u, v, w)$，则 $\boldsymbol{x} = D\boldsymbol{x}'$ 为旋转，且

$$
b = \boldsymbol{x}^{\mathrm{T}}\boldsymbol{A}\boldsymbol{x} = \boldsymbol{x}'^{\mathrm{T}}(D^{\mathrm{T}}AD)\boldsymbol{x}' = \boldsymbol{x}'^{\mathrm{T}}\operatorname{diag}(\lambda, \mu, \zeta)\boldsymbol{x}' = \lambda x_{1}'^{2} + \mu x_{2}'^{2} + \zeta x_{3}'^{2}.
$$

## 文本问题

定理陈述中特征值由 $\det(A - \gamma E) = 0$ 确定，随即又写"其中 $\nu = \lambda, \mu$ 或 $\zeta$"，$\gamma$ 与 $\nu$ 记号混用，疑为排印问题。见 [[queries/34节证明中特征向量等式与γν记号疑似讹误]]。
