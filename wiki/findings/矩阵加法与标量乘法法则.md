# 矩阵加法与标量乘法及其运算法则

## 陈述

**加法**：`A, B ∈ Mat(m,n)` 时，`A + B` 由逐元素相加定义，仍属于 `Mat(m,n)`。
**标量乘法**：`A ∈ Mat(m,n)`、`α` 为数时，`αA` 由逐元素相乘定义，仍属于 `Mat(m,n)`。

来源例 1、例 2：

```
( a b c )   ( α β γ )   ( a+α  b+β  c+γ )
( d e z ) + ( δ ε ζ ) = ( d+δ  e+ε  z+ζ )

(a, b) + (α, β) = (a+α, b+β),      (1, 2) + (3, 1) = (4, 3)

    ( a b c )   ( αa αb αc )
α   ( d e z ) = ( αd αe αz )

    ( 1 3 2 )   ( 4 12 8 )
4   ( 1 2 1 ) = ( 4  8 4 )
```

**零矩阵**：所有元素均为 0 的 `m × n` 矩阵记作 `O`。

**运算法则**：对 `A, B, C ∈ Mat(m,n)` 及标量 `α`，有 `A + B = B + A`、`(A + B) + C = A + (B + C)`、`A + O = A`、`α(A + B) = αA + αB`。

## 结论

来源据此得出：集合 `Mat(m,n)` 形成一个**复数域上的线性空间**（来源指向 2.3.2 节）。

定义为直接陈述；线性空间结论为来源明确给出的推论。见 [[矩阵加法与标量乘法]]。
