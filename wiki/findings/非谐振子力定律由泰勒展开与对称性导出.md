# 非谐振子力定律由泰勒展开与对称性导出

**陈述.** 由 1.9.1 节脚注 1 的一般考虑可导出运动定律

```
F(x) = −k x i − l x³ i
```

（k, l 为正的常数），称为非谐振子；谐振子是 l = 0 的特例。

**推导链条（原文脚注）：**

1. 根据泰勒定理，对 x 的足够小的值（小振幅）有近似展开
   ```
   F(x) = F(0) + x a + x² b + x³ c + …
   ```
2. 如果没有运动，那么也就没有力：**F(0) = 0**；
3. 期望有对称性 **F(−x) = −F(x)**，由此即得 **b = 0**；
4. 因为力的方向与运动方向相反，它的作用方向一定是 −i，因此对正的常数 k, l 有 **a = −k i, c = −l i**。

**来源.** [[sources/10-数学指南实用数学手册--10-191-速度和加速度--1kt6qq]]（1.9.1 节脚注 1）。

**性质与证据强度.** 这是**量纲／对称性层面的建模论证**，依赖「小振幅」近似与对称性假设，而非实验数据，故置信度记为 medium。

**相关疑点.** 正文中「这称为非谐（anharmonic）振子」一句的位置与内容不符，见 [[queries/191节谐振子例中非谐振子一句归属是否讹误]]。
