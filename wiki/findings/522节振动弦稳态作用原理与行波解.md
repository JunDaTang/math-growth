# 5.2.2 节：振动弦的稳态作用原理与行波解 (5.58)(5.59)

## 观察

5.2.2 最后一例把 (5.45) 的稳态提法用于振动弦。

**设定**：$q=q(x,t)$ 为弦在 $t$ 时刻点 $x$ 处的位移，

```latex
D:=\{(x,t)\in\mathbb{R}^{2}: 0\leqslant x\leqslant l,\ t_{0}\leqslant t\leqslant t_{1}\}.
```

**拉格朗日函数**：

```latex
L=\text{动能}-\text{势能}=\frac{1}{2}\rho q_{t}^{2}-\frac{1}{2}kq_{x}^{2}
```

（$\rho$ 为密度，$k$ 为材料常数）。

**稳态作用原理**：

```latex
\begin{array}{l}
\int_{D}L\,\mathrm{d}x \stackrel{!}{=} \text{平稳}, \\
q\ \text{沿着边界}\ \partial D\ \text{给定}.
\end{array}
```

**导出方程**：欧拉-拉格朗日方程 $(L_{q_{t}})_{t}+(L_{q_{x}})_{x}=0$ 给出弦振动方程

```latex
\frac{1}{c^{2}}q_{tt}-q_{xx}=0, \tag{5.58}
```

其中 $c^{2}=k/\rho$。

**一般解定理**：(5.58) 的最一般的 $C^{2}$ 解是

```latex
q(x,t)=a(x-ct)+b(x+ct), \tag{5.59}
```

$a,b$ 为任意 $C^{2}$ 函数；它对应于以速度 $c$ 在相反方向传播的两个波的叠加（一个从左到右，另一个从右到左）。

## 直接证据

- 泛函、拉格朗日函数、方程 (5.58) 与通解 (5.59) 均由原文给出，$c^{2}=k/\rho$ 亦有明示。
- 图 5.21(a)(b) 用于说明该稳态作用原理，两幅子图均未能加载。

## 推断（非直接证据）

- 原文未点名 (5.59) 的通常归属（达朗贝尔），故本 wiki 不据此建立额外实体页。
- 泛函记作 $\int_{D}L\,\mathrm{d}x$，而 $D$ 是 $(x,t)$ 平面上的矩形，$\mathrm{d}x$ 疑为 $\mathrm{d}x\,\mathrm{d}t$ 的简写或记号残留。
