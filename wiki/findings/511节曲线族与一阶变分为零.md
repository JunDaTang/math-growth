# 5.1.1 节：曲线族 (5.5)、一阶变分为零与二阶变分定义

**直接证据（本书陈述）**：

- 曲线族 $q = q(t) + \varepsilon h(t)$（(5.5)），通过两定点等价于 $h(t_0) = h(t_1) = 0$（对应图 5.1）。
- 定义 $\varphi(\varepsilon) := \int_{t_0}^{t_1} L(q + \varepsilon h, q' + \varepsilon h', t)\,\mathrm{d}t$，则 $\varphi(\varepsilon) = J(q + \varepsilon h)$。
- (i) 若 $q$ 是极小化问题 (5.1) 的解，则 $\varphi$ 在 $\varepsilon = 0$ 达极小，故 $\varphi'(0) = 0$（(5.6)）。
- (ii) 对稳态问题 (5.2)，按定义 $\varepsilon = 0$ 是 $\varphi$ 的临界点，同样得到 (5.6)。
- 由此推出 [[欧拉-拉格朗日方程]]，详细证明见文献 [212]。
- 定义一阶变分 $\delta J(q)h := \varphi'(0)$，故 (5.6) 等价于 $\delta J(q)h = 0$（物理中记作 $\delta J = 0$）；二阶变分 $\delta^2 J(q)h^2 := \varphi''(0)$。
- 范数 $\| q \|_k := \sum_{j=0}^{k} \max_{t_0 \leqslant t \leqslant t_1} |q^{(j)}(t)|$，$q^{(0)}(t) = q(t)$。

**推断**：由 (5.6) 到 (5.3) 的分部积分推导本节未给出，仅指向 [212]；文献 [212] 在本书中无完整条目信息，见 [[511节图51未能加载与参考文献212条目缺失]]。
