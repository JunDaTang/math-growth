# 例 1：多项式的加法与乘法

## 内容

来源通过合并同次项、应用自然法则 (1.1.4) 进行加法与乘法，并给出算例：

```
(x^2 + 1) + (2x^3 + 4x^2 + 3x + 2) = 2x^3 + 5x^2 + 3x + 3,

(x + 1)(x^2 - 2x + 2) = x^3 - 2x^2 + 2x + x^2 - 2x + 2 = x^3 - x^2 + 2.
```

## 说明

- 加法例中，两个多项式的次数分别为 2 与 3，和为 3 次多项式。
- 乘法例给出逐项展开的中间步骤 $x^3 - 2x^2 + 2x + x^2 - 2x + 2$，合并同次项后得 $x^3 - x^2 + 2$。
- 该算例为验算性示例，属直接证据，无可复现性问题。
