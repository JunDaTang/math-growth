# 6.3.6 节：多元分析的五种方法与因子概念

## 核心断言

- **断言 1（中心问题）**：面对大量数据，中心问题是判断测量值「是完全随机的，还是依赖于有限个某种类型的随机变量」。（证据类型：教科书级框架陈述）
- **断言 2（来源）**：多元分析方法起源于美国统计学家 R. 费希尔（Fisher, 1890—1962）的工作；多元分析中最重要的影响量称为**因子**。
- **断言 3（工具）**：使用统计软件 SPSS 或 SAS 公司的各种软件包可以将这些方法用于解决具体问题。

## 五种方法

### 1. 方差分析（6.3.6.1）

- 对象：**已知因子**对数据集的影响。
- 手段：对测量结果划分为**聚类**。
- 基本思想：因子的标准差（或方差）比数据的随机扰动的标准差（或方差）要**大得多**。
- 理论联系：与 $F$ 检验有关（参见 6.3.3.4）。
- 例（谷物年产量）：因子为各类肥料 $F_1, \dots, F_n$；观测量为所有试验田的年产量；聚类为以相同浓度施用相同肥料的试验田。结论可判断年产量是否受肥料影响，并据此求肥料的最佳配比。

### 2. 因子分析（6.3.6.2）

- 对象：**事先不知道的因子**，与方差分析形成对照。
- 目的：寻找能尽可能好地确定数据、且数量尽可能少的背景变量；$n$ 个强相关变量集中/组合成一个因子。
- 例（森林损害）：性质 $M_1, \dots, M_k$（树叶数、树皮厚度等），确定 $n$ 个因子 $F_1, \dots, F_n$ 是否有本质影响；可用计算机程序试验 $n$ 的不同取值。
- **Caveat**：方法本身不对因子类型作任何表述；甄别因子重要性是研究者的工作，需要经验和技巧。
- 辅助量：[[因子权]] 描述各因子对性质的影响强度。

### 3. 聚类分析（6.3.6.3）

- 目的：将给定数据集合进行聚类划分；聚类 = 聚集具有相似性质的数据，也指这类数据的集合。
- 例（银行客户）：聚类为 $G_1, G_2, G_3, G_4$，分别对应非常值得信任、值得信任、部分值得信任、不可信任；需借助其他渠道信息（他行、年龄、收入等）。

### 4. 判别分析（6.3.6.4）

- 使用时机：应用聚类分析进行聚类划分**之后**。
- 功能：以最优方式确定刻画聚类的原始特性，从而立即将新数据划入现有聚类。
- 重要假设：**已有一个聚类划分**。
- 例 1（银行客户）：确定刻画不同聚类的可测量因子，对新客户定级。
- 例 2（药品研究）：按病人对药物的反应聚类，以温度、血液成分等为聚类特征，帮助医生开方。

### 5. 多元回归（6.3.6.5）

- 设定：随机变量 $X_1, \dots, X_n$ 与 $Y_1, \dots, Y_m$；寻找 $Y_j = F_j(X_1, \dots, X_n) + \varepsilon_j$，$\varepsilon_j$ 为微扰。
- 线性情形：$Y_j = \sum_{k=1}^{m} a_{jk} X_k + b_j + \varepsilon_j$，系数取实数值并需由观测数据估计。
- 定位：把 6.2.3.3 讨论过的回归度与相关系数概念**推广**到多变量。
- 计算技巧：程序可通过删掉充分小的系数 $a_{jk}$、$b_j$ 确定最重要的因子。

## 实践警示

每种统计方法都依赖于一些**特定的假设**，而这些假设**通常只是近似满足**。若不确定应如何选择方法，最好的办法是咨询有应用统计方法解决实际问题经验的专家（可在大学计算机中心或其他科学研究机构联系到）。

这一警示与 6.3 节的 [[数理统计金箴]] 主线一致，属于「负责任的统计实践」在多元方法上的具体化。
