# 7.2.3.1–7.2.3.2 节：特征多项式法的数值不可用性与雅可比方法

## 直接证据

### 特征多项式法（7.2.3.1）

- 理论途径：求 $P_{\mathbf{A}}(\lambda) = \det(\mathbf{A}-\lambda\mathbf{E})$ 的根得特征值，再解 $(\mathbf{A}-\lambda_j\mathbf{E})\mathbf{x}_j = \mathbf{0}$ 得特征向量。
- 源文结论：**不能用于实际数值计算**；系数计算中的舍入误差可能强烈影响特征值（原书引用 [432]），该步一般相当不稳定。

### 雅可比方法（7.2.3.2）

- 适用对象：$n \times n$ 实对称矩阵；特征值为**实数**，特征向量构成正交向量系。
- 目标形式：$\boldsymbol{X}^{-1}\boldsymbol{A}\boldsymbol{X} = \boldsymbol{X}^{\mathrm{T}}\boldsymbol{A}\boldsymbol{X} = \boldsymbol{D} = \operatorname{diag}(\lambda_1,\dots,\lambda_n)$。
- 工具：基本雅可比旋转矩阵 $U(p,q,\varphi)$，$1 \leqslant q < p \leqslant n$，$\varphi$ 满足 $\cot(2\varphi) = (a_{qq}-a_{pp})/(2a_{pq})$，$-\pi/4 < \varphi \leqslant \pi/4$。
- 迭代：$\boldsymbol{A}^{(k)} = \boldsymbol{U}_k^{\mathrm{T}}\boldsymbol{A}^{(k-1)}\boldsymbol{U}_k$；源文提示新产生的零元素一般会被后续旋转破坏。
- 旋转对顺序：经典雅可比方法不限定顺序；特殊雅可比方法按 $(1,2),\dots,(1,n),(2,3),\dots,(2,n),(3,4),\dots,(n-1,n)$ 逐行消零。
- 收敛判据：非对角元素平方和 $S(A^{(k)})$ 为零序列；$S(A^{(k)}) \leqslant \varepsilon^2$ 时对角元给出绝对精度 $\varepsilon$ 的特征值，$V = U_1\cdots U_k$ 的列给出特征向量的规范正交逼近。

## 推断

- 源文对「零元素会被后续旋转破坏」的提醒，解释了为何雅可比方法必须依赖整体判据 $S(A^{(k)})$ 而非单元素判据——此为对源文两段陈述的合理联结。
- $\varphi$ 的取值区间 $(- \pi/4, \pi/4]$ 与 $\cot(2\varphi)$ 的符号约定共同保证旋转角度唯一且数值稳定；源文未展开说明。
