# 多项式相等的定义

## 内容

来源按定义规定：

```
a_0 + a_1 x + ... + a_n x^n = b_0 + b_1 x + ... + b_m x^m
```

当且仅当 $n = m$，并且 $a_j = b_j$（对所有 $j$）。亦即两个多项式相等，当且仅当它们有相同的次数和相同的系数。

## 归属与性质

- 定义性陈述，无经验性主张。
- 该定义是带余除法「唯一性」表述的意义基础：唯一性是在这种逐系数相等的意义下成立的。
