# 线性空间定义的六条性质

2.3.2 节给出：K 上的线性空间 X 需对所有 $u,v,w \in X$ 及 $\alpha,\beta \in K$ 满足

```text
(i)   u + v = v + u                 (交换性)
(ii)  (u + v) + w = u + (v + w)     (结合性)
(iii) 存在唯一 0 ∈ X 使 z + 0 = z   (中性元)
(iv)  对每个 z 存在唯一 −z 使 z + (−z) = 0  (逆元)
(v)   α(u + v) = αu + αv,  (α + β)u = αu + βu  (分配性)
(vi)  (αβ)u = α(βu) 及 1u = u       (结合性)
```

注：脚注说明，代替 $u + (-v)$ 写作 $u - v$；可证明 $0u = 0$ 及 $\alpha 0 = 0$，故 K 中的 0 与 X 中的中性元 o 统一用符号 0 表示。任意域 K 上的线性空间（参看 2.5.3）可类似定义。
