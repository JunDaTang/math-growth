# 隐式曲线奇点判别与奇点形态分类

## 判别条件

对隐式曲线 $F(x,y) = 0$ 上满足 $F(x_0,y_0) = 0$ 的点，$(x_0,y_0)$ 为奇点当且仅当

$$
F_x(x_0,y_0) = F_y(x_0,y_0) = 0 .
$$

对参数式曲线 $x = x(t), y = y(t)$，等价条件为 $x'(t_0) = y'(t_0) = 0$，此时**切线不能确切定义**。

## 二阶判别：$D := ac - b^2$

以

$$
F(x,y) = a(x-x_0)^2 + 2b(x-x_0)(y-y_0) + c(y-y_0)^2 + \dots,
$$

$a := \tfrac12 F_{xx}(x_0,y_0)$，$b := F_{xy}(x_0,y_0)$，$c := \tfrac12 F_{yy}(x_0,y_0)$，并令 $D := ac - b^2$，则：

| 条件 | 几何结论 | 源文件图号 |
|---|---|---|
| $D > 0$ | 孤立点 | 图 3.48(a) |
| $D < 0$ | 曲线在该点有两个分支（二重点） | 图 3.48(b) |
| $D = 0$ | 需考察高阶项：切触点、返回点、终点、三重点或更一般的 $n$ 重点 | 图 3.47、图 3.48 |

## 参数式形态实例

- 返回点：$x = x_0 + (t-t_0)^2 + \dots$，$y = y_0 + (t-t_0)^3 + \dots$（图 3.47(a)）。
- 终点：$x = x_0 + (t-t_0)^2 + \dots$，$y = y_0 + (t-t_0)^2 + \dots$（图 3.47(b)）。
