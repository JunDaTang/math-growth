# 矩阵乘积存在当且仅当 A 与 B 相配

## 陈述

> 矩阵乘积 `AB` 存在，当且仅当 A 与 B 相配，亦即 A 的列数等于 B 的行数。

## 说明

该条件决定了乘积的型：`A ∈ Mat(m,n)` 与 `B ∈ Mat(n,l)` 之积属 `Mat(m,l)`。来源的转置/伴随性质表也重复引用此条件（「设矩阵乘积 CD 存在（记住这要求 C 和 D 相配）」）。
