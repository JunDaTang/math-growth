# 商空间与结构定理

2.3.4.2 节。$X/Y$ 为 X 中所有平行于子空间 Y 的线性流形的集合，通过 $\alpha(u + Y) + \beta(v + Y) = (\alpha u + \beta v) + Y$ 成为线性空间。对 $\dim X < \infty$：

```text
dim X/Y = dim X − dim Y
```

结构定理：若 Y、Z 是 X 的子空间，则

```text
(Y + Z)/Z ≅ Y/(Y ∩ Z)
X/Y ≅ (X/Z)/(Z/Y)   (Y ⊆ Z ⊆ X)
```

等价关系替代定义：$u \sim w$ 当且仅当 $u - w \in Y$；等价类 $[u] := u + Y$；映射 $u \to [u]$ 为典范映射。
