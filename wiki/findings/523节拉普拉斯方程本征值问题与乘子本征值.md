# 5.2.3 节：拉普拉斯方程本征值问题与乘子成为本征值

## 观察

5.2.3「带约束的问题和拉格朗日乘子」用一个例子展示乘子法在多元情形的推广。

**变分问题**：

```latex
\begin{array}{l}
\int_{D}(q_{x}^{2}+q_{y}^{2})\,\mathrm{d}x\,\mathrm{d}y \stackrel{!}{=} \min,\quad q=0\ \text{在}\ \partial D\ \text{上}, \\
\int_{\partial D}q^{2}\,\mathrm{d}s=1.
\end{array} \tag{5.60}
```

**乘子法**：类似于 5.1.6，选择

```latex
\mathcal{L}:=L+\lambda q^{2}=q_{x}^{2}+q_{y}^{2}+\lambda q^{2},
```

实数 $\lambda$ 称为拉格朗日乘子。$\mathcal{L}$ 的欧拉-拉格朗日方程为

```latex
\frac{\partial}{\partial x}\mathcal{L}_{q_{x}}+\frac{\partial}{\partial y}\mathcal{L}_{q_{y}}-\mathcal{L}_{q}=0,
```

**结果**：本征值问题

```latex
q_{xx}+q_{yy}=\lambda q,\ \text{在}\ D\ \text{上},\quad q=0,\ \text{在}\ \partial D\ \text{上}. \tag{5.61}
```

原文结论：可以证明 (5.61) 是 (5.60) 存在 $C^{2}$ 解的一个必要条件；在这种情形下拉格朗日乘子成为一个本征值。

## 直接证据

- 泛函 (5.60)、修正拉格朗日函数 $\mathcal{L}$、欧拉-拉格朗日表达式与方程 (5.61) 均由原文给出。
- 原文明确写明与 5.1.6 的类比关系。

## 推断（非直接证据）

- 约束写成边界积分 $\int_{\partial D}q^{2}\,\mathrm{d}s=1$，而极小化的能量是区域积分；在常见提法中此类归一化条件取区域积分 $\int_{D}q^{2}\,\mathrm{d}x\,\mathrm{d}y=1$。此点依原文照录，未作改动。
- 原文对 $\mathcal{L}$ 使用了花体字母记号，与 5.1.6 中「用花体 $\mathcal{L}$ 代替 $L$」的提法一致（参见 [[516节用花体L代替L表述讹误]]）。
