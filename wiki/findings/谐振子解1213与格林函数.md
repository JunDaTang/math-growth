# 谐振子解 (1.213) 与格林函数 G(t,τ)

对 (1.212)

```latex
\begin{array}{c}
x''(t) + \omega^2 x(t) = F(t), \\
x(0) = x_0, \\
x'(0) = v,
\end{array}                                       \tag{1.212}
```

（$\omega := \sqrt{k/m}$，$F := \mathcal F/m$，$F$ 连续），源文声称「对于所有时刻有一个唯一解」

```latex
x(t) = x_0 \cos \omega t + \frac{v}{\omega}\sin \omega t + \int_0^t G(t,\tau) F(\tau)\,\mathrm{d}\tau,  \tag{1.213}
```

其中 [[格林函数]] $G(t,\tau) := \frac{1}{\omega}\sin \omega(t-\tau)$。

**适定性不等式**（对两个解 $x,x_*$）：
```latex
\|x-x_*\| \le |x(0)-x_*(0)| + \frac{1}{\omega}|x'(0)-x_*'(0)|
+ \frac{\mathcal F}{\omega}\max_{0\le t\le \mathcal T}|F(t)-F_*(t)|,
```
其中 $\|x-x_*\|:=\max_{0\le t\le\mathcal T}|x(t)-x_*(t)|$，$[0,\mathcal T]$ 为任意时间区间。

**注意**：源文对「对所有时刻有一个唯一解」加脚注标记 1)，但该脚注内容未在源中转录（见 [[queries/1121节脚注内容未录]]）。
