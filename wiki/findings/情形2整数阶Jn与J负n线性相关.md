# 情形 2：整数阶时 J_{−n} 与 J_n 线性相关

## 结论

若 $\alpha = n$，其中 $n = 0, 1, 2, \cdots$，则有

$$J_{-n}(z) = (-1)^n J_n(z).$$

因此函数 $J_{-n}$ 与 $J_n$ 线性相关，不能作为 [[贝塞尔微分方程]] (1.499) 的基本解组。这时改取

$$w_1 = J_n, \qquad w_2 = N_n,$$

其中 $N_n$ 为 [[诺伊曼函数]]。

## 证据与推理

- $J_{-n}(z) = (-1)^n J_n(z)$ 由来源直接给出。
- 线性相关性的后果（需要另找一个与 $J_n$ 线性无关的第二解）也是来源的明确陈述。
- 该情形的结构（$\rho_1 - \rho_2 = 2n$ 为整数、第二解含 $\ln z$）与 1.14.20 中「情形 2」的理论预测相符；$N_n$ 显式公式中确实出现 $\ln z$ 项，见 [[诺伊曼函数定义与显式公式]]。
