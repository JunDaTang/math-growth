# 商域的构造与有理函数域

设 $P$ 为非零整环，则存在域 $Q(P)$ 含 $P$，且是任何含 $P$ 的域中最小的含 $P$ 子域，称为 $P$ 的**商域**（分式域）。

构造：取有序对 $(a,b)$（$b\ne0$），定义 $(a,b)\sim(c,d)\iff ad=bc$，等价类 $[(a,b)]$ 关于

```
[(a,b)][(c,d)] := [(ac, bd)]
[(a,b)] + [(c,d)] := [(ad + bc, bd)]
```

构成域。写 $\frac{a}{b}$，计算按通常分式规则，且 $\frac{a}{b}=ab^{-1}$。由 $\varphi(a):=\frac{ar}{r}$（$r\ne0$）得同态 $P\to Q(P)$，与 $r$ 无关。

例 3：$\mathbb{Z}$ 的商域是 $\mathbb{Q}$。例 4：整环 $P\ne\{0\}$ 上多项式环 $P[x]$ 的商域 $Q(P[x])$ 记作 $P(x)$，即有理函数域，其元素为 $\frac{p(x)}{q(x)}$（$q\ne0$）。
