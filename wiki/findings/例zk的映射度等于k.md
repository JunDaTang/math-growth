# 例：$f(z) = z^k$ 在圆盘上的映射度等于 $k$

## 陈述（原文逐字保留）

```text
对于 f(z) := z^k 和圆盘 Ω := {z ∈ C : |z| < R}，有
    deg(f, Ω) = k,   k = 0, ±1, ±2, …
```

$$
\deg (f, \varOmega) = k, \quad k = 0, \pm 1, \pm 2, \dots
$$

## 验证

该结果直接由 [[concepts/映射度]] 的定义 $\deg(f,\Omega) = N - P$ 计算得到，与解析函数的零点/极点重数结构一致：

- $k \geqslant 1$：$z=0$ 是 $k$ 阶零点，$N=k$，$P=0$，故 $\deg = k$；
- $k \leqslant -1$：$z=0$ 是 $|k|$ 阶极点，$N=0$，$P=-k$，故 $\deg = k$；
- $k = 0$：$f \equiv 1$，$N=P=0$，故 $\deg = 0$。

## 边界与限制

该结论的适用范围严格限于 **$f(z)=z^k$ 与以原点为中心的圆盘 $\Omega=\{z:|z|<R\}$** 这一组合，源文档未将其外推到其他区域或其他函数。对一般区域或其他函数，需回到定义或使用表示公式计算。
