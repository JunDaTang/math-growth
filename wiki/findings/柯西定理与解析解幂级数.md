# 柯西定理与解析解幂级数（含例 x' = x）

## 命题

源文 1.12.9.3 节：

- **柯西定理**：如果 $f$ 是解析的（原书脚注 2)），那么 (1.316) 的最大解 $x=x(t)$ 也是解析的。
- $x=x(t)$ 的局部幂级数展开由**比较系数法**得到。
- **注**：对于复变量 $t,x_1,\cdots,x_n$ 和复值函数 $f_1,\cdots,f_n$，柯西定理仍然成立。

## 例题

对初值问题 $x'=x$、$x(0)=1$：由方程得 $x'(0)=1$，类似地，对所有 $n$ 有 $x^{(n)}(0)=1$。由此得到解

```text
x(t) = x(0) + x'(0) t + x''(0) t²/2! + ...
     = 1 + t + t²/2! + ... = e^t.
```

## 证据与强度

- 证据类型：定理 + 一个可自行验证的例题；例题通过逐次求导并代入初值给出系数，属完全可复算的操作。
- 置信度：转录置信度高；「原书脚注 2)」对「解析」的定义未转录。
- 复变量推广在源文中仅以「注」的形式给出，未附条件细节（例如解析域的选取）。
