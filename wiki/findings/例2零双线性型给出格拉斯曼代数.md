# 例 2：零双线性型 B ≡ 0 时 C(X) 同构于格拉斯曼代数 ∧(X)

**设定**：设 $b_{1}, \cdots, b_{n}$ 是 $\mathbb{K}$ 上的线性空间 $X$ 的基。取 $B \equiv 0$（即 $B(b_{j}, b_{k}) = 0$ 对所有 $j,k$）。

**结果**：此时 $\mathcal{C}(X)$ 的乘法法则退化为

$$
b_{j} \vee b_{k} + b_{k} \vee b_{j} = 0, \quad \text{对所有 } j, k = 1, \dots, n,
$$

即完全反称。$\mathcal{C}(X)$ 同构于格拉斯曼代数 $\wedge(X)$，因此源文档干脆用 $\wedge$ 代替 $\vee$ 乘积符号。

**意义**：这表明外代数只是克利福德代数在 $B \equiv 0$ 时的特例，把 2.4.3.3 与 2.4.3.4 两节统一到同一框架之下。

**证据类型**：示例（直接来自源文档）。
