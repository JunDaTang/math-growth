# 欧拉乘积的零点为全体整数

《数学指南——实用数学手册》0.7.5 节首行给出

$$\sin \pi x = \pi x \prod_{k=1}^{\infty}\left(1 - \frac{x^{2}}{k^{2}}\right), \qquad \lvert x \rvert < \infty$$

直接读取该式的结构即可得到一个观察：乘积的因子 $1 - x^{2}/k^{2}$ 恰在 $x = \pm k$（$k = 1, 2, \dots$）处为零，而前置因子 $\pi x$ 提供 $x = 0$ 处的零点；合起来零点集就是全体整数 $\mathbb{Z}$。这与 $\sin \pi x$ 在整数处取零、在非整数处非零的已知事实一致。

- 证据类型：直接证据（源中显式写出的恒等式）。
- 本节未讨论这些零点的重数，也未讨论收敛性的证明。
- 相关表示见 [[sin-πx-的无穷乘积表示]]，派生特值见 [[平方因子无穷乘积的若干特值]]。
