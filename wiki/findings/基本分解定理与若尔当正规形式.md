# 基本分解定理与若尔当正规形式

2.3.4.4 节。若 $\dim X < \infty$，则对每个算子 A 存在分解

```text
X = X₁ ⊕ X₂ ⊕ … ⊕ X_k
```

其中 $X_1,\dots,X_k$ 是（非平凡）不可约不变子空间。若 X 为复线性空间，可在每个子空间中选取基使 A 限制在 $X_j$ 时由若尔当块矩阵给出，于是 A 的矩阵是若尔当正规形式。若尔当块的阶等于 $X_j$ 的维数，可通过 2.2.2.3 的初等因子方法计算。
