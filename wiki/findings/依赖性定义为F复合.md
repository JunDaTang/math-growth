# 函数相关性的定义：f_{K+1} = F(f_1, …, f_K)

## 陈述

设 $f_k: G \to \mathbb{R}$ 是 $C^1$ 类函数，$k = 1, \dots, K+1$，$G$ 为 $\mathbb{R}^N$ 的非空开集。$f_{K+1}$ 依赖于 $f_1, \dots, f_K$，当且仅当存在 $C^1$ 类函数 $F: \mathbb{R}^K \to \mathbb{R}$ 使

```
f_{K+1}(x) = F(f_1(x), ..., f_K(x)) 对所有的 x ∈ G.
```

## 证据类型

直接证据：这是本节以加框公式给出的正式定义，文字完整、无缺损。

## 说明

定义同时要求两个 $C^1$ 前提——各 $f_k$ 是 $C^1$ 类，且关系函数 $F$ 本身也是 $C^1$ 类。右端是 [[concepts/复合映射的线性化]] 意义下的复合映射，因而 [[concepts/多元链式法则]] 可用于分析其导数，这是后续 [[concepts/相关性秩条件]] 的出发点。
