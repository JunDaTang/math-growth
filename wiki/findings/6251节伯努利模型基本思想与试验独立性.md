# 6.2.5.1–6.2.5.2 节：伯努利模型的基本思想、概率空间与试验独立性

## 观察

原文指出该模型由 [[雅各布-伯努利]] 提出并研究，「可广泛应用于许多情形，是概率论中最重要的模型之一」；特别地，利用它可以得到**理论概率与频率之间的关系**。

模型的构造为三步：比较试验（结果 $e_1, e_2$，概率 $p_j$，$p := p_1$，$p_2 = 1-p$）→ 独立重复 $n$ 次 → 各次结果彼此互不影响。

## 结构要点

**概率空间的显式给出**：全部事件 $E$ 由基本事件 $e_{i_1 i_2 \ldots i_n}$（$i_j = 1,2$，$j = 1,\ldots,n$）组成，概率由

```
P(e_{i_1 i_2 ... i_n}) := p_{i_1} p_{i_2} ... p_{i_n}        (6.18)
```

定义。原文以 $e_{121}$ 为例：$P(e_{121}) = p(1-p)p = p^2(1-p)$。

**独立性是定理而非假设**：定义 $A_i^{(k)}$ 为「$e_i$ 在第 $k$ 次试验中发生」，则对一切下标，$A_{i_1}^{(1)}, \ldots, A_{i_n}^{(n)}$ 相互独立。原文只证 $n=2$ 的情形：

```
P(A_i^{(1)}) = p_i p_1 + p_i p_2 = p_i,
A_i^{(1)} ∩ A_j^{(2)} = {e_{ij}},  P(e_{ij}) = p_i p_j = P(A_i^{(1)}) P(A_j^{(2)})。
```

这是由 (6.18) 的概率规定**推出**的结论，说明「独立重复」在该模型中是由乘积型基本概率实现的结构性事实。

## 直接证据与推断的区分

- 直接证据：以上构造、公式与 $n=2$ 的证明均逐字见于原文。
- 推断：原文未证明一般 $n$ 的情形，只以「对于所有可能的下标」陈述；$n=2$ 的论证方式是本节给出的证明模式，一般情形应可归纳推广。此项为合理推断，非原文直接陈述。
