# 共变/反变张量代数 T(X) 与例 3

《数学指南》2.4.2.2 节把各阶张量空间作（外）直和

$$
\mathcal{T}(X) := \bigoplus_{p, q = 0}^{\infty} \mathcal{T}_{q}^{p}(X),
$$

它关于运算 $+$ 与 $\otimes$ 成为一个代数，即 $X$ 上共变/反变张量的张量代数。

**例 3**：由 $M = t_{k}^{j} b^{k} \otimes b_{j}$ 和 $N = s_{k}^{j} b^{k} \otimes b_{j}$ 得到

$$
M + N = (t_{k}^{j} + s_{k}^{j})(b^{k} \otimes b_{j})
$$

及

$$
M \otimes N = t_{k}^{j} s_{q}^{p} (b^{k} \otimes b^{q} \otimes b_{j} \otimes b_{p}).
$$

例中 $M \otimes N$ 的阶数为 $(1+1)$ 共变、$(1+1)$ 反变，符合 $\mathcal{T}_{q}^{p} \otimes \mathcal{T}_{s}^{r} \to \mathcal{T}_{q+s}^{p+r}$。
