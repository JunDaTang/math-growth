# 一元误差估计给出二阶量级的界

## 结论

对一元实变量函数 $y = f(x)$，由泰勒定理可得

```text
Δf = f′(x)Δx + (f″(x + ϑΔx)/2)(Δx)²,   0 < ϑ < 1
```

从而误差估计为

```text
|Δf − f′(x)Δx| ≤ (Δx)²/2 · sup_{0<η<1} |f″(x + ηΔx)|
```

## 证据与推理

该结论由泰勒余项的 Lagrange 型直接推出：一阶项 $f'(x)\Delta x$ 是近似值，剩余误差由二阶导数在 $[x, x+\Delta x]$ 上的上确界控制，量级为 $(\Delta x)^2$。证据链清晰，属直接推导。

## 适用范围

适用于任意满足泰勒定理前提的一元函数 $f$；结论只依赖二阶导数的有界性，不依赖具体函数形式。
