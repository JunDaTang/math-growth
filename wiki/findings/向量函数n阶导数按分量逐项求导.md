# 向量函数 n 阶导数按分量逐项求导

**陈述.** 在笛卡儿坐标系 (x, y, z) 中，点 O 为原点时

```
r(t) = x(t) i + y(t) j + z(t) k

r⁽ⁿ⁾(t) = x⁽ⁿ⁾(t) i + y⁽ⁿ⁾(t) j + z⁽ⁿ⁾(t) k
|r⁽ⁿ⁾(t)| = √( x⁽ⁿ⁾(t)² + y⁽ⁿ⁾(t)² + z⁽ⁿ⁾(t)² )
```

特别地 r′(t) = r⁽¹⁾(t)，r″(t) = r⁽²⁾(t) 等。

**推论.** 当 n 阶导数 x⁽ⁿ⁾(t), y⁽ⁿ⁾(t), z⁽ⁿ⁾(t) 存在时，n 阶导数 r⁽ⁿ⁾(t) 确实存在。因此向量函数的求导可完全**逐分量**处理。
