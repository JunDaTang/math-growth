# 6.2.5.6 节：概率 p 的置信区间公式与示例

## 结果

在错误概率 $\alpha$ 下，假定未知的 $p$ 落在 $[p_-, p_+]$ 内，其中

```
(1 + z_α²/n) p_± = h_n + z_α²/(2n) ± √( h_n z_α²/n + z_α²/(4n²) )。
```

原文断言：一般来说，对于 6.2.5.2 中伯努利模型的概率 $p$ 的估计，这个结论是正确的。

## 推导核心

由 (6.24) 得 $|(h_n - p)/\Delta H_n| < z_\alpha$ 成立的概率为 $1 - \alpha$；代入 $(\Delta H_n)^2 = p(1-p)/n$ 化为二次不等式

```
p²(1 + z_α²/n) − (2h_n + z_α²/n) p + h_n² < 0,        (6.28)
```

其成立范围即二次方程两个根 $p_-$、$p_+$ 之间。

关键之处：$\Delta H_n$ 依赖未知参数 $p$，因此不能直接使用正态区间，必须解关于 $p$ 的二次不等式。

## 示例及其内部张力

抛 10 000 次，正面向上出现 5010 次，$h_n = 0.501$：

- 原文先说 $p$ 落在 **[0.36, 0.64]** 中（残概率 $\alpha = 0.05$）；
- 紧接着说这个估计「还是十分粗糙的」，并断定在同一残概率下 $p$ 落在 **[0.500, 0.503]** 内。

两段区间宽度相差两个数量级，与公式给出的量级（约 $[0.487, 0.515]$）均不一致；已记为 [[queries/6256节置信区间例数值与公式不符]]。因该数值存在明显不一致，本条的 confidence 定为 medium。
