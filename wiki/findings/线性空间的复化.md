# 线性空间的复化：结构、单射与维数

**陈述**：若 $X$ 是实线性空间，则张量积 $X \otimes \mathbb{C}$（复线性空间）称为实线性空间的复化。

**结构化结果**：

1. 因 $u \otimes (\alpha + \beta \mathrm{i}) = (\alpha u) \otimes 1 + (\beta u) \otimes \mathrm{i}$，$X \otimes \mathbb{C}$ 由所有 $u \otimes 1 + v \otimes \mathrm{i}$（$u, v \in X$）组成。
2. $u \otimes 1 + v \otimes \mathrm{i} = u' \otimes 1 + v' \otimes \mathrm{i}$ 当且仅当 $u = u'$ 且 $v = v'$（表示唯一）。
3. $\varphi(u) := u \otimes 1$ 给出线性单射 $\varphi: X \to X \otimes \mathbb{C}$，故可把 $u$ 等同为 $u \otimes 1$。
4. $\dim(X \otimes \mathbb{C}) = \dim X$，注意左边是复向量空间维数，右边是实向量空间维数。

**证据类型**：定义与命题陈述（直接来自源文档）。
