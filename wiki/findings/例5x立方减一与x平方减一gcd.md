# 例 5：x³ − 1 与 x² − 1 的最大公因子

## 内容

对于 $N(x) := x^3 - 1$ 和 $D(x) := x^2 - 1$，来源得到

```
x^3 - 1 = (x^2 - 1)x + x - 1,
x^2 - 1 = (x - 1)(x + 1).
```

因此 $x - 1$ 是 $x^3 - 1$ 和 $x^2 - 1$ 的最大公因子。

## 说明

- 第一次带余除法：$Q = x$，$R_1 = x - 1$（次数 1 < 2）。
- 第二次带余除法：余项为零，故 gcd 取上一非零余项 $R_1 = x - 1$。
- 本例与 [[findings/例4x立方减一分解]] 共享分解式 $x^3 - 1 = (x-1)(x^2+x+1)$，但本例关注的是两多项式的 gcd，而非单纯分解。
