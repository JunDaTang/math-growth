# 例 1：1/(z−1) − 2/(z+1) 的两个极点与积分 −2πi

## 内容

对函数

```text
f(z) = 1/(z − 1) − 2/(z + 1)
```

有

```text
Res_{z=1} f = 1,   Res_{z=−1} f = −2.
```

对围绕两点 $z = \pm 1$ 的圆周 $C$，由 [[柯西留数定理]] 得

```text
∫_C f dz = 2πi ( Res_{z=1} f + Res_{z=−1} f ) = −2πi.
```

## 证据类型与边界

- 这是**直接陈述**的算例（源文档正文，非推断）。
- 该结果**仅针对上述具体函数与上述具体围道**；不可外推到其它函数或其它围道。
- 源文档未给出该算例的额外证明，只作为定理 (1.462) 的验证。
