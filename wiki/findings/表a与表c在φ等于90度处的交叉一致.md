# 表 a 与表 c 在 φ = 90° 处的交叉一致

## 观察

在源文 0.5.4 节中，[[表a第一类椭圆积分]] 的 $\varphi = 90^\circ$ 行与 [[表c完全椭圆积分]] 的 $K$ 列在共同具有的 $\alpha$ 取值（0°、10°、…、80°）上逐项一致：

| α | 表 a，φ=90° | 表 c，K |
|---|---|---|
| 0° | 1.570 8 | 1.5708 |
| 10° | 1.582 8 | 1.5828 |
| 20° | 1.620 0 | 1.6200 |
| 30° | 1.685 8 | 1.6858 |
| 40° | 1.786 8 | 1.7868 |
| 50° | 1.935 6 | 1.9356 |
| 60° | 2.156 5 | 2.1565 |
| 70° | 2.504 6 | 2.5046 |
| 80° | 3.153 4 | 3.1534 |

## 解释

这与定义 $K = F(k, \pi/2)$ 相符：$\varphi = 90^\circ$ 即 $\pi/2$，表 a 的该行本应等于完全椭圆积分 $K$。此一致性为两张表互为独立校核提供了直接证据。

## 证据类型

直接证据（源文两张表数值的逐项比对），非推断。
