# 欧拉常数的无穷乘积表示

《数学指南——实用数学手册》0.7.5 节「进一步的几个例子」的最后一条，把 [[欧拉常数]] $C$ 写成一个无穷乘积的结果：

$$\prod_{k=1}^{\infty}\frac{\sqrt[k]{\mathrm{e}}}{1 + 1/k} = \mathrm{e}^{C} \qquad (\text{欧拉常数 } C = 0.577215\dots)$$

说明：

- 源中以 $\sqrt[k]{\mathrm{e}}$ 表示 $\mathrm{e}^{1/k}$，即每个因子为 $\mathrm{e}^{1/k}/(1 + 1/k)$。
- 源中给出欧拉常数的数值 $C = 0.577215\dots$，与已有 [[欧拉常数]] 页的取值一致。
- 该式与主表中魏尔斯特拉斯行的指数因子 $\mathrm{e}^{-Cx}$ 是本节中 $C$ 出现的两处，见 [[伽马函数的无穷乘积表示]]。
- 证据类型：直接证据（源中列出的等式）；本节未给出推导。
