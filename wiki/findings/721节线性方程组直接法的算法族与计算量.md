# 7.2.1 节：线性方程组直接法的六种算法与条件数

## 观察（直接来自源文档）

《数学指南——实用数学手册》7.2.1 节在同一前提（$A$ 为 $n \times n$ 正则矩阵，解唯一，见 **2.1.4.3**）下给出直接解法的完整谱系，并给出各算法的计算量：

| 算法（节号） | 关键形式 | 计算量 |
|---|---|---|
| 高斯算法（7.2.1.1） | $PA = LR$，消元 + 回代，可复用同一 $A$ 的分解 | $Z_{\mathrm{Gauss}} = \frac{1}{3}(n^3 + 3n^2 - n)$ |
| 高斯-若尔当方法（7.2.1.2） | 全消元为对角形，$x_k = -b_k/a_{kk}$ | $Z_{\mathrm{GJ}} = \frac{1}{2}(n^3 + 2n^2 - n)$ |
| 行列式计算（7.2.1.3） | $\det A = (-1)^V \prod_k r_{kk}$ | 依附于 LR 分解 |
| 交换法求逆（7.2.1.4） | 交换 $x_q$ 与 $y_p$，逐步更新矩阵元素 | 每步 $n^2$，共计 $n^3$ |
| 楚列斯基算法（7.2.1.5） | $A = LL^{\mathrm{T}}$，仅限对称正定 | $Z_{LL^{\mathrm{T}}} = \frac{1}{6}(n^3 + 3n^2 - 4n)$ + $n$ 个平方根；代换 $n^2 + n$ |
| 三对角线方程组（7.2.1.6） | $L$、$R$ 均为二对角线 | $Z_{trid} = 5n - 4$（与 $n$ 线性） |

**补充事实**：

1. 分解型的三种算法（高斯、楚列斯基）共享「分解 → 向前代换 → 逆代换」的三步模板；对同一 $A$、不同 $b$ 只需分解一次。
2. 楚列斯基分解的计算量约为一般 $LR$ 分解的一半，原因是不同元素个数减半；它是稳定的，因为 $L$ 的元素绝对值有界。
3. 高斯-若尔当方法虽计算量更大（约 1.5 倍于高斯算法），但算法更简单，尤其适用于**向量计算机**。
4. 行列式的 LR 分解算法「有效且稳定」，优于手册 **2.1.2** 的方法（后者计算代价大且因抵消而不稳定）。
5. 稳定性依赖[[主元选取策略]]：对角线策略仅对[[对角占优]]矩阵可靠；最大排队策略假定行尺度；实际常用相对排队策略。
6. 精度由[[线性方程组的条件数]] $\kappa(A) = \|A\|\cdot\|A^{-1}\|$ 控制：剩余大小一般不表示计算解的精度；$d$ 位精度下若 $\kappa(A)\sim 10^{\alpha}$，解的最大分量只有 $d - \alpha - 1$ 位有效数字。

## 推理（本文档的归纳，非源文档原文）

- 计算量对 $n$ 的阶数均为 $n^3/3$ 至 $n^3/2$，而三对角特例为 $O(n)$，说明稀疏结构对直接法的效率影响是数量级的。
- 源文档把「稳定性（算法属性）」与「条件数（问题属性）」分列于 7.2.1.1 与 7.2.1.7，二者互补：主元策略改善前者，条件数决定后者的下界。
