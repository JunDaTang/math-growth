# 正合序列判定三定理

2.3.3.3 节。对于线性算子 A，

```text
(i)   A 是满射 ⇔ X --A--> Y → 0 是正合的
(ii)  A 是单射 ⇔ 0 → X --A--> Y 是正合的
(iii) A 是双射 ⇔ 0 → X --A--> Y → 0 是正合的
```

其中 0 表示仅由中性元组成的平凡线性空间 $\{0\}$，$0 \to X$ 与 $Y \to 0$ 表示零算子。
