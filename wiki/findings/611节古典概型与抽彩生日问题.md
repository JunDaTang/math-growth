# 6.1.1 节：古典概型及其三个典型例子

## 直接证据（来源陈述）

《数学指南——实用数学手册》6.1.1 节给出古典概型的完整定义：

- 随机试验的全部可能结果 $e_1,\dots,e_n$ 称为基本事件；全体事件 $E$ 由所有 $e_j$ 组成；事件 $A$ 是 $E$ 的子集。
- 概率定义 (6.1)：$P(A) := A$ 所包含元素的个数 $/ n$。
- 古典文献表述 (6.2)：$P(A) :=$ 有利结果数 / 可能结果数。
- 归属：概率概念的这个定义式是雅各布·伯努利在 17 世纪末引入的。

三个例子：

1. **掷一粒骰子**：$P(\{e_1\}) = 1/6$；偶数点事件 $B = \{e_2,e_4,e_6\}$ 的概率为 $1/2$。
2. **掷两粒骰子**：$e_{ij}$（$i,j = 1,\dots,6$），共 36 个基本事件；$P(\{e_{ij}\}) = 1/36$；点数相同的概率为 $6/36 = 1/6$。
3. **抽彩问题（45 取 6）**：基本事件为 $e_{i_1 i_2 \dots i_6}$（$i_1 < \dots < i_6$），共 $\binom{45}{6}$ 个；记 $a := 1/\binom{45}{6} = 10^{-7}$，抽中 5、4、3 个正确数字的概率分别为 $\binom{6}{5}39a = 2\cdot 10^{-5}$、$\binom{6}{4}\binom{39}{2}a = 10^{-3}$、$\binom{6}{3}\binom{39}{3}a = 2\cdot 10^{-2}$。
4. **生日问题**：基本事件 $e_{i_1\dots i_n}$（$i_j = 1,\dots,365$），共 $365^n$ 个；至少两人生日相同的概率为 (6.3)

```
p = [365^n − 365·364·…·(365 − n + 1)] / 365^n
```

表中给出 $n = 20, 23, 30, 40$ 时 $p$ 约为 0.4、0.5、0.7、0.9。

## 推断（非来源直述）

- 抽彩表中「1000 万个抽奖者中获胜的人数」列，是由参加人数乘以各概率得到的期望人数，来源在正文中明确说明这一算法。
- 生日问题表中「客人只有 30 位，也可以相当有把握地打赌说至少有两个人的生日在同一天」是对 $p \approx 0.7$ 的通俗解读。
