# 积分理论四个关键词（卡瓦列里、代换、高斯-斯托克斯、分部积分）

## 观察

《数学指南》1.7 节以「下面的关键词概述了积分理论中最重要的结果」引出四项：

```
(i)   卡瓦列里(Cavalieri) 原理(富比尼(Fubini) 定理),
(ii)  代换法则,
(iii) 微积分基本定理(高斯-斯托克斯定理),
(iv)  分部积分 ((iii) 的特殊情形).
```

## 来源附加的两条关系断言

1. 原理 (i) 允许累次积分（多变量函数的积分）的计算归结为一维积分的计算（见 [[findings/卡瓦列里原理使多变量积分归结为一维积分]]）。
2. (iv) 是 (iii) 的特殊情形；同时来源用括注把「卡瓦列里原理」与「富比尼定理」等同。

## 证据强度

目录性罗列，无证明，无定义。四条目的主体归属明确，但 (i) 的等同断言与 (iii) 的名称含义均需另行核实（见 [[queries/卡瓦列里原理与富比尼定理是否等同]]、[[queries/17节微积分基本定理与16节是否同名异物]]）。
