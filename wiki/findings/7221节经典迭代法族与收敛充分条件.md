# 7.2.2.1 节：经典迭代法族、迭代矩阵与收敛充分条件

## 结论

《数学指南——实用数学手册》7.2.2.1 节在统一的分解 $A = -L + D - U$ 下给出四个经典迭代方法，并给出各自的迭代矩阵与收敛充分条件。这是对迭代法的一次**族化整理**：两个基本方法各自加上松弛因子，即得两个推广。

## 直接证据（源文明确陈述）

1. **统一分解**：矩阵 $A$ 分解为 $A = -L + D - U$，$L$ 为严格下三角、$U$ 为严格上三角、$D = \operatorname{diag}(a_{11}, \dots, a_{nn})$ 且 $a_{kk} \neq 0$；$L$、$U$ 中存放的是 $A$ 的非对角元之相反数。
2. **雅可比（组合步方法）**：$Dx^{(k+1)} = (L+U)x^{(k)} - b$，迭代矩阵 $T_{\mathrm{J}} := D^{-1}(L+U)$；收敛的**一个充分条件**是 $A$ 为[[concepts/对角占优]]矩阵。
3. **高斯-赛德尔（单步方法）**：$(D-L)x^{(k+1)} = Ux^{(k)} - b$，不动点迭代单元 $T_E := (D-L)^{-1}U$、$c_E := (D-L)^{-1}b$；收敛的**充分条件**是 $A$ 对角占优**或对称正定**。
4. **分量形式**：$x_i^{(k+1)} = -\left(b_i + \sum_{j=1}^{i-1} a_{ij}x_j^{(k+1)} + \sum_{j=i+1}^{n} a_{ij}x_j^{(k)}\right) / a_{ii}$。
5. **松弛因子**：$\omega \neq 1$ 时「常可使算法性能（收敛速度）好得多」；$\omega > 1$ 为超松弛，$\omega \leqslant 1$ 为低松弛。
6. **JOR**：$T_{\mathrm{JOR}}(\omega) := (1-\omega)E + \omega D^{-1}(L+U)$、$c_{\mathrm{JOR}} := -\omega D^{-1}b$。
7. **SOR**：$T_{\mathrm{SOR}}(\omega) := (D-\omega L)^{-1}[(1-\omega)D + \omega U]$、$c_{\mathrm{SOR}} := -\omega(D-\omega L)^{-1}b$。
8. **最优松弛因子**：$\omega_{opt}$ 使 $\rho(T_{\mathrm{JOR}}(\omega))$、$\rho(T_{\mathrm{SOR}}(\omega))$ **分别最小**；因 $A$ 性质不同，理论上选取方法也不同。

## 由源文直接推得的对照

以下对照由源文方程直接推得，属**推断**而非源文原句：

- 当 $\omega = 1$ 时 $T_{\mathrm{JOR}}(1) = T_{\mathrm{J}}$，JOR 退化为雅可比方法；
- 当 $\omega = 1$ 时 SOR 退化为高斯-赛德尔方法（符号约定上 $c_{\mathrm{SOR}} = -c_E$）；
- 高斯-赛德尔方法的充分条件集合**严格宽于**雅可比方法（多出「对称正定」情形）。

## 未决/未展开之处

- 源文未给出 JOR 与 SOR 各自的收敛充分条件，只给出谱半径最小化这一最优性目标；
- 源文未给出 $\omega_{opt}$ 的具体计算公式或算法流程；
- 源文公式中的 $E$ 未定义（见[[queries/7221节JOR与SOR公式中E记号未定义]]）。
