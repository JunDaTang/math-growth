# π 的连分数及其推导与最佳有理逼近

**主体：$\pi$ 本身。**

源文结论 (2.86)：

$$
\pi = [3, 7, 15, 1, 292, 1, 1, 1, \dots]
$$

典范近似分数：

```
3, 22/7, 333/106, 355/113, 103993/33102, ...
```

## 推导依据

由十进估计 (2.88)

$$
3.1415926535\mathbf{8} < \pi < 3.1415926535\mathbf{9}
$$

应用连分数算法 (2.79) 得到两个展开

$$
3.14159265358 = [3,7,15,1,292,1,1,1,1,\dots], \quad
3.14159265359 = [3,7,15,1,292,1,1,1,2,\dots],
$$

在第八项之前一致，故得 (2.86)。

## 最佳逼近断言

- 分母 $\leqslant 7$ 时 $\frac{22}{7}$ 最佳（与阿基米德估计一致）。
- 分母 $\leqslant 113$ 时 $\frac{355}{113}$ 最佳，误差 $\leqslant \frac{1}{113\cdot33102} < 10^{-6}$。

依据均为 **2.7.5.3 的主要定理**。相关：[[π的连分数]]、[[最佳有理逼近]]。
