# π 的早期近似值：旧约、古埃及、阿基米德与祖冲之

《数学指南——实用数学手册》2.7.7 节列出的早期 $\pi$ 近似值（均为教科书级转述的历史事实陈述）：

| 主体 | 近似值 | 出处/时间 |
|---|---|---|
| 《旧约全书·列王纪（上）》7:23 | 3 | 经文「径 10 肘，周 30 肘」 |
| 古埃及纸草书 | $\pi=(16/9)^2=3.16,\dots$ | 约公元前 1650 年起，由「从直径中去掉 1/9」的作图法给出 |
| [[阿基米德]]（前 287–前 212） | $\frac{223}{71} < \pi < \frac{22}{7}$ | 正 96 边形；其中 $\frac{22}{7}=3.14,\dots$ |
| 1766 年日本 | $\frac{5419351}{1725033} < \pi < \frac{428224593349304}{136308121570117}$ | 双侧估计 |
| [[祖冲之]]（430—501） | $\frac{355}{113}$（式 (2.87)） | 源文称「同样令人惊讶的是」该分数已作为 $\pi$ 的近似值 |

## 与最佳有理逼近的衔接

源文指出 $\frac{22}{7}$ 是 $\pi$ 连分数 (2.86) 的第二个典范近似分数，$\frac{355}{113}$ 是第四个；在分母分别限定 $\leqslant 7$ 与 $\leqslant 113$ 时，它们都是最佳有理逼近，误差满足 $\left|\pi-\frac{355}{113}\right| \leqslant \frac{1}{113\cdot33102} < 10^{-6}$。
