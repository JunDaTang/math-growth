# 6.1.2 节：伯努利大数定律（以抛硬币为模型）

## 直接证据（来源陈述）

- 抛一枚硬币的基本事件为 $e_1, e_2$（(6.4)），$e_1$ 表示「正面向上」、$e_2$ 表示「反面向上」；$A = \{e_1\}$，由 (6.1) 得 $P(A) = 1/2$。
- 抛 $n$ 次硬币的基本事件为 $e_{i_1 i_2 \dots i_n}$（$i_j = 1,2$）。
- 频率定义为

```
H(e_{i_1 i_2 … i_n}) := (正面向上发生的次数) / (试验次数 n)
```

- 大数定律：设 $\varepsilon > 0$ 任意给定，$A_n$ 为满足 $|H(e\dots) - 1/2| < \varepsilon$ 的所有基本事件组成的集合，则

```
lim_{n→∞} P(A_n) = 1
```

亦可写作 $\lim_{n\to\infty} P(|H_n - 1/2| < \varepsilon) = 1$。
- 归属：文中称「大数定律是由雅各布·伯努利最早提出并证明的」，且「伯努利利用公式 (6.1) 计算了概率 $P(A_n)$」。

## 推断（非来源直述）

- 本节把「频率趋近概率」这一经验事实提升为数学定理，其证明工具仍是古典概型的计数公式 (6.1)，即计算 $2^n$ 个等可能基本事件中「1」的占比落在 $1/2$ 附近 $\varepsilon$ 邻域内的那部分。
- 来源仅处理 $P(A) = 1/2$ 的二值特例，一般情形的陈述与证明超出本节范围。
