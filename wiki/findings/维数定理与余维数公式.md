# 维数定理与余维数公式

2.3.2 节：若 Y 和 Z 是线性空间 X 的子空间，则

```text
dim(Y + Z) + dim(Y ∩ Z) = dim Y + dim Z
```

其中 Y + Z 及 Y ∩ Z 仍是 X 的子空间。

余维数：设 Y 是 X 的子空间，$\operatorname{codim} Y := \dim X/Y$；当 $\dim X < \infty$ 时

```text
codim Y = dim X − dim Y
```
