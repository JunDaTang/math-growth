# 分部积分公式 (1.108) 及其三个例题

## 公式与证明

对 $C^1$ 类函数 $u, v: [a,b] \to \mathbb{C}$，

$$
\int_{a}^{b} u'v\,\mathrm{d}x = uv\big|_{a}^{b} - \int_{a}^{b} uv'\,\mathrm{d}x. \tag{1.108}
$$

书中给出证明：由微积分基本定理及微分乘法法则，$\int_a^b (u'v + uv')\,\mathrm{d}x = \int_a^b (uv)'\,\mathrm{d}x = uv\big|_a^b$。

## 三个例题

- 例 1：$A := \int_1^2 2x\ln x\,\mathrm{d}x$，取 $u' = 2x$、$v = \ln x$，得 $A = x^2\ln x\big|_1^2 - \int_1^2 x\,\mathrm{d}x = 4\ln 2 - \frac{3}{2}$。
- 例 2：$A = \int_a^b x\sin x\,\mathrm{d}x$，取 $u' = \sin x$、$v = x$，得 $A = -x\cos x\big|_a^b + \int_a^b \cos x\,\mathrm{d}x = -x\cos x + \sin x\big|_a^b$。
- 例 3（叠分部积分）：$B = \int_a^b \frac{1}{2}x^2\cos x\,\mathrm{d}x$，取 $u' = \cos x$、$v = \frac{1}{2}x^2$，得 $B = \frac{1}{2}x^2\sin x\big|_a^b - \int_a^b x\sin x\,\mathrm{d}x$，后者再按例 2 分部。

## 备注

书中例 1 的积分上下限印刷为 $\int_a^2$，从计算过程看应为 $\int_1^2$（见 [[queries/171节公式与文字转写疑误汇总]]）。例 2、例 3 的下限 $a$ 为一般参数，属正常写法。
