# 比热容定义方程 ΔQ = s μ ΔV ΔT

1.9.7 节以方框形式给出

```
ΔQ = s μ ΔV ΔT
```

并明确称其为「比热容 $s$ 的定义方程」。式中 $\Delta Q$ 为热量改变，$\Delta T$ 为温度改变，$\Delta V$ 为所考察小片区域的体积，$\mu$ 为质量密度。

**在推导中的用法**：令 $\Delta Q = Q(t+\Delta t)-Q(t)$、$\Delta T = T(x,t+\Delta t)-T(x,t)$，配合一级近似 $Q(t)=\rho(x,t)\Delta V$，除以 $\Delta t$ 后取极限即得 $\rho_t = s\mu T_t$。
