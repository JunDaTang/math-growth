# 6.3.5 节：最大似然方程组 (6.37)(6.38) 及正态、伯努利、泊松三类算例

## 直接证据（原书正文）

1. **连续型最大似然方程组 (6.37)**：对密度 $\varphi(x, \boldsymbol\beta)$，估计值由
   $\sum_{j=1}^{n} \frac{1}{\varphi(x_j, \boldsymbol\beta)}\frac{\partial \varphi(x_j, \boldsymbol\beta)}{\partial \beta_r} = 0$ 解出。
2. **连续型的正态特例**：$\mu$ 与 $\sigma$ 的估计值为
   $\mu = \frac{1}{n}\sum x_j$，$\sigma^2 = \frac{1}{n}\sum (x_j - \mu)^2$。
3. **离散型最大似然方程组 (6.38)**：以频率 $h_j$ 与概率 $p_j(\boldsymbol\beta)$ 表达，形式与连续型对偶。
4. **例 2（伯努利型）**：$X$ 取 1/0 表示 $A$ 发生/不发生，得到最大似然估计值 $p = h_1$，即概率可由频率估计。
5. **例 3（泊松型）**：$p_j = \frac{\beta^j}{j!}\mathrm{e}^{-\beta}$，最大似然估计值 $\beta = \frac{1}{n}\sum_{j=1}^{n} x_j$（即 (6.39)）。
6. **脚注 1)**：以似然函数 $L = \prod_j \varphi(x_j, \beta)$ 的极大化条件 $L \stackrel{!}{=} \max$ 导出 $\partial L/\partial \beta_r = 0$，并指出其除以 $L$ 后等价于 (6.37)。

## 本节的推断性结论（需注明为推理而非正文直述）

- 正态分布方差的**最大似然估计** $\frac{1}{n}\sum (x_j - \mu)^2$ 用系数 $1/n$，与 6.3.2 节的无偏估计量 $S^2 = \frac{1}{n-1}\sum (x_j - M)^2$ 系数不同，说明最大似然估计在此处**有偏**。这是由两节公式直接对比得出的结论，原书 6.3.5 节本身并未就此展开讨论。
- 泊松例的推理「$nh_j$ 是等于 $j$ 的观测值 $x_r$ 的个数」将频率还原为频数，从而把 $\sum_j h_j j$ 改写为 $\frac{1}{n}\sum_{r=1}^{n} x_r$。
