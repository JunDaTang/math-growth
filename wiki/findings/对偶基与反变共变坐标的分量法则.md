# 对偶基与反变共变坐标的分量法则

本手册 1.8.3 节末给出一般坐标系下的完整分量体系。设 $e_1, e_2, e_3$ 为任意线性无关向量，则对偶基为

```latex
e^1 := (e_2 × e_3) / (e_1 e_2 e_3),
e^2 := (e_3 × e_1) / (e_1 e_2 e_3),
e^3 := (e_1 × e_2) / (e_1 e_2 e_3).
```

每个向量 $a$ 有唯一分解式 $a = a^1 e_1 + a^2 e_2 + a^3 e_3$ 及 $a = a_1 e^1 + a_2 e^2 + a_3 e^3$，前者系数为**反变坐标**，后者为**共变坐标**。在此记号下

```latex
a b = a_1 b^1 + a_2 b^2 + a_3 b^3,

a × b = (e_1 e_2 e_3) | e^1  e^2  e^3 |
                      | a^1  a^2  a^3 |
                      | b^1  b^2  b^3 |

(a b c) = (e_1 e_2 e_3) | a^1  a^2  a^3 |
                        | b^1  b^2  b^3 |
                        | c^1  c^2  c^3 |
```

原书随后指出特例：在笛卡儿坐标系中 $i = e_1 = e^1$、$j = e_2 = e^2$、$k = e_3 = e^3$ 且 $a_j = a^j$（$j = 1, 2, 3$），特别地此时反变坐标与共变坐标相等。

直接证据：以上公式与特例陈述均为 1.8.3 节原文，未附推导。
