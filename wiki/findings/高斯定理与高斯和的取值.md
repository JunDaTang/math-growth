# 高斯定理（1808）：高斯和的取值只取 ±√p 或 ±i√p

## 直接证据（源文 2.7.8.2 节末）

**高斯定理（1808）**：设 $\varepsilon := e^{2\pi i/p}$，其中 $p$ 是素数。那么有

```
Σ_{k=1}^{p−1} ( k / p ) ε^k = √p,   当 p ≡ 1 mod 4;
Σ_{k=1}^{p−1} ( k / p ) ε^k = i√p,  当 p ≡ 3 mod 4.
```

源文说明：「这种类型的和称为**高斯和**。高斯甚至花费很长时间去证明这个结果。」

## 评注

- 结论表明该和完全由 $p \bmod 4$ 决定，取值为 $\pm\sqrt{p}$ 型（含纯虚情形），不依赖于求和过程中的中间项。
- 源文将互反律标注为 1796、高斯和定理标注为 1808，作为 [[高斯]] 在二次剩余理论上的两项成果分别记年。
- 与 [[高斯二次互反律与勒让德符号补充公式]] 同属 2.7.8.2 节的结论，但对象不同：前者是关于符号 $(q/p)$ 的关系式，本条是关于加权指数和的具体取值。
