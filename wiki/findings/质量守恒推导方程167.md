# 质量守恒推导与方程 (1.167)

1.9.7 节对 [[concepts/质量平衡方程]] 的动机推导如下（原文照录）：

```
A(t+Δt) − A(t) = −( B(t+Δt) − B(t) ) + ( C(t+Δt) − C(t) )
```

除以 $\Delta t$，并取极限 $\Delta t \to 0$，得

```
A′(t) = −B′(t) + C′(t)                                          (1.167)
```

密度表示为

```
A(t)   = ∫_D ρ(x,t) dx
B′(t)  = ∫_{∂D} J_n dF
C′(t)  = ∫_D F(x,t) dx
```

由 [[concepts/高斯定理]] 得 $B(t) = \int_{\partial D} J_n \mathrm{d}F = \int_D \mathrm{div}\,\boldsymbol{J}\,\mathrm{d}x$，故

```
∫_D ρ_t dx = −∫_D div J dx + ∫_D F(x,t) dx
```

再由 [[concepts/体积的导数]] 即得 (1.166)。

**量的定义（原文照录）**：$A(t)$ 为在时刻 $t$、$D$ 中化学物质 $S$ 的质量；$B(t)$ 为在时间段 $[0,t]$ 内流出 $D$ 外的物质 $S$ 的质量；$C(t)$ 为在时间段 $[0,t]$ 内在 $D$ 中由化学反应生成的物质 $S$ 的质量。
