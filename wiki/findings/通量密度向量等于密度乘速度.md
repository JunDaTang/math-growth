# 通量密度向量等于密度乘速度 (1.168)

1.9.7 节「液体流」段给出：

```
J = ρ v                                                          (1.168)
```

**条件（原文照录）**：$\boldsymbol{v}=\boldsymbol{v}(x,t)$ 是化学物质 $S$ 在液体中流动形成的速度场；此时 (1.166) 对通量密度向量成立。

**证据强度**：教材级结论，未给证明与出处。
