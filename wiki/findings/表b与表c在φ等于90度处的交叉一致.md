# 表 b 与表 c 在 φ = 90° 处的交叉一致

## 观察

在源文 0.5.4 节中，[[表b第二类椭圆积分]] 的 $\varphi = 90^\circ$ 行与 [[表c完全椭圆积分]] 的 $E$ 列在 $\alpha = 0^\circ, 10^\circ, \ldots, 90^\circ$ 上逐项一致：

| α | 表 b，φ=90° | 表 c，E |
|---|---|---|
| 0° | 1.570 8 | 1.5708 |
| 10° | 1.558 9 | 1.5589 |
| 20° | 1.523 8 | 1.5238 |
| 30° | 1.467 5 | 1.4675 |
| 40° | 1.393 1 | 1.3931 |
| 50° | 1.305 5 | 1.3055 |
| 60° | 1.211 1 | 1.2111 |
| 70° | 1.118 4 | 1.1184 |
| 80° | 1.040 1 | 1.0401 |
| 90° | 1.000 0 | 1（源文规定） |

## 解释

这与定义 $\mathrm{E} = E(k, \pi/2)$ 相符。注意 $\alpha = 90^\circ$ 一行在表 c 中未列入（表 c 止于 89°），但源文在表 c 标题中规定该点 $E = 1$，与表 b 的 `1.000 0` 一致。

## 证据类型

直接证据（源文两张表数值的逐项比对），非推断。
