# 欧拉公式建立指数函数与三角函数的关系

## 观察

1.1.2 节：欧拉发现对所有实数 x, y 有

```latex
\mathrm{e}^{x + \mathrm{i}y} = \mathrm{e}^{x}(\cos y + \mathrm{i}\cdot\sin y).\tag{1.7}
```

手册评价这得到了指数函数与三角函数之间「一个意想不到的关系」，并说明该公式通常应用到振动理论（比较 1.1.3 节）。

## 直接推论（手册内）

- 复数的指数表示 `z = r e^{iφ}`（见 [[concepts/复数的极坐标表示]]）。
- 复数的 n 次根的三角—指数混合表达式（见 [[concepts/复数的n次根]]）。
- 正弦式波的复函数表示 `Y(x, t) = C e^{i(ωt − kx)}`，其虚部即实值波函数 (1.10)（见 [[concepts/正弦式波]]）。

## 评估

属标准结论；手册强调的是它在**振荡/波动表示**中的作用，而非公式本身的证明。
