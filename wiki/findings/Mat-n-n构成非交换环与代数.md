# Mat(n,n) 构成复数域上的非交换环与代数

## 陈述

设 `A, B, C ∈ Mat(n,n)`，`E` 为 `n × n` 单位矩阵，`O` 为 `n × n` 零矩阵，则

```
A(BC) = (AB)C
A(B + C) = AB + AC
AE = EA = A
AO = OA = O
A + O = A
```

来源结论：集合 `Mat(n,n)` 形成**复数域上的（非交换）环**，并且是**复数域上的代数**（来源指向 2.4.1 和 2.5.2 两节）。

对照：集合 `Mat(m,n)` 只是复数域上的**线性空间**（见 [[矩阵加法与标量乘法]]），因为一般 `m ≠ n` 时没有矩阵乘法。

## 证据类型

来源明确陈述的代数定位；非交换性与零因子另有独立算例支撑（见 [[矩阵乘法的非交换性]]、[[零因子-矩阵环]]）。见 [[矩阵环与矩阵代数]]。
