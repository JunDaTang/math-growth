# 球面三角形面积公式与球面角盈

## 结果

- 球面三角形面积：$S = (\alpha + \beta + \gamma - \pi) R^{2}$；
- 等式命名：差 $\alpha + \beta + \gamma - \pi$ 称为**球面角盈**；
- 角的和范围：由 $0 < S < 4\pi R^{2}$ 得 $\pi < \alpha + \beta + \gamma < 3\pi$；
- 三角不等式：$|a - b| < c < a + b$；
- 边的比率（大边对大角）：$\alpha < \beta \Leftrightarrow a < b$，$\alpha > \beta \Leftrightarrow a > b$，$\alpha = \beta \Leftrightarrow a = b$；
- 循环置换规则：$a \to b \to c \to a$ 与 $\alpha \to \beta \to \gamma \to \alpha$ 下公式保持不变。

## 判据意义

源文件特别强调：若无法确认身处球面还是平面，可测量三角形角的和——平面三角形恒有 $\alpha + \beta + \gamma = \pi$。

## 例

北极 $C$ 与赤道上两点 $A$、$B$ 构成的球面三角形有 $\alpha = \beta = \frac{\pi}{2}$，从而角和为 $\pi + \gamma$，面积 $S = R^{2}\gamma$。

## 直接证据与推断

面积公式与角盈定义均为源文件直接陈述（直接证据）。由球面对角形面积 $S = 2R^{2}\alpha$ 拼合推出面积公式的过程在源文件中未展开（推断关系）。
