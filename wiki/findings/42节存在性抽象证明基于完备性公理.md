# 4.2 节：存在性的抽象证明基于完备性公理

**来源**：《数学指南——实用数学手册》4.2.4 节，例「方程 $x^2 = 2$ 有一个实数解」。

**直接证据（来源明述）**：定义

$$A := \{a \in \mathbb{R} : a < 0 \text{ 或 } (a \geqslant 0 \text{ 且 } a^2 \leqslant 2)\}, \quad B := \{a \in \mathbb{R} : a \geqslant 0 \text{ 且 } a^2 > 2\}.$$

每个实数属于 $A$ 或 $B$ 之一，$0 \in A$、$2 \in B$ 使两者非空。**根据 1.2.2.1 中的完备性公理**，存在实数 $\alpha$ 使对所有 $a \in A$、$b \in B$ 有 $a \leqslant \alpha \leqslant b$（4.9）。

随后以反证法证明 $\alpha^2 = 2$：否则由 $(\pm\alpha)^2 = \alpha^2$ 只有情形 1（$\alpha^2<2$ 且 $\alpha>0$）与情形 2（$\alpha^2>2$ 且 $\alpha>0$）。情形 1 中取足够小的 $\varepsilon>0$（例如 $\varepsilon = \min\left(\frac{2-\alpha^2}{2\alpha+1}, 1\right)$）使 $(\alpha+\varepsilon)^2 < 2$，于是 $\alpha+\varepsilon \in A$，由 (4.9) 推出 $\alpha+\varepsilon \leqslant \alpha$，不可能；情形 2 类似。故 $\alpha^2 \neq 2$ 的假设为假。

**推断（非来源明述）**：该证明是「不构造解而只断言存在」的典型形态，与 4.2.4 后续的构造性证明形成对照。
