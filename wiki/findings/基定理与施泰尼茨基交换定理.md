# 基定理与施泰尼茨基交换定理

2.3.2 节两条定理：

基定理：设 n 是正整数。如果每 n 个线性无关的元素都形成 X 的基，那么 $\dim X = n$。

施泰尼茨基交换定理：如果 $b_1,\dots,b_n$ 形成线性空间 X 的基，并且 $u_1,\dots,u_r$ 是 X 中的线性无关的元素，那么 $u_1,\dots,u_r,b_{r+1},\dots,b_n$（必要时重新编号）形成 X 的新基。
