# 6.4.2 节：马尔可夫链基本模型、转移矩阵与查普曼-科尔莫戈罗夫方程

## 观察（直接来自来源）

1. **定位**：来源把[[马尔可夫链]]表述为[[伯努利模型]]（6.2.5 节）对**相依随机事件**情形「最简单可行的推广」；并记载该链最早由 [[马尔可夫]]（Markov，1856—1922）于 1906 年研究。
2. **基本模型 (i)–(iv)**：离散时间点 $t = 0, \Delta t, 2\Delta t, \dots$；状态 $Z_1, \dots, Z_k$；[[转移概率]] $p_{ij}$（由状态 $Z_i$ 在一步后转到 $Z_j$ 的条件概率）；以及由 $p_{ij}$ 排成的转移矩阵 $\boldsymbol{P}$。
3. **时齐性**：来源明确指出马尔可夫链的典型特征是转移概率不依赖于所考虑的时间点（时齐）。
4. **随机矩阵**：$\boldsymbol{P}$ 被视为[[随机矩阵]]，即 $0 \leqslant p_{ij} \leqslant 1$ 且对每个 $i$ 有 $\sum_{j=1}^{k} p_{ij} = 1$（行和为 1）。
5. **k 步转移矩阵**：$p_{ij}^{(k)}$ 表示 $t = n\Delta t$ 处于 $Z_i$、$t = (n+k)\Delta t$ 转到 $Z_j$ 的概率，其矩阵记作 $\boldsymbol{P}^{(k)}$，称为[[k步转移矩阵]]。
6. **查普曼-科尔莫戈罗夫方程**：对 $k, m = 1, 2, \cdots$，
   $\boldsymbol{P}^{(k+m)} = \boldsymbol{P}^{(k)}\boldsymbol{P}^{(m)}$（式 (6.46)）。
7. **推论与特例**：$\boldsymbol{P}^{(k)} = \boldsymbol{P}^{k}$；$m = 1$（或 $k = 1$）时 (6.46) 称为前进方程（或[[前进方程与后退方程|后退方程]]）。

## 推断（非来源原文）

- 式 (6.46) 依赖时齐性：若 $p_{ij}$ 随 $n$ 变化，$\boldsymbol{P}^{(k+m)} = \boldsymbol{P}^{(k)}\boldsymbol{P}^{(m)}$ 的一般形式将不成立。来源未展开该限制条件，但由其「时齐」表述可推知。
- 推论 $\boldsymbol{P}^{(k)} = \boldsymbol{P}^{k}$ 可由对 (6.46) 反复分解（$k$ 个单步）归纳得到，来源直接以「推论」形式给出而未证明。
