# 7.3.1.2 节：牛顿插值公式、均差与差分格式

## 观察

1. [[牛顿插值公式]] $I_{n}(x) = \sum_{i=0}^{n} c_{i} N_{i}(x)$，其中 $N_{i}(x) = \prod_{j=0}^{i-1}(x - x_{j})$ 是 $i$ 个线性因子之积。
2. 系数 $c_{i}$ 为第 $i$ 阶 [[均差]] $[x_{0} x_{1} \dots x_{i}]$，递归定义见 [[均差]] 页；$c_{i}$ 是 [[均差格式]] 下斜对角线上的值。
3. 嵌套求值（自内向外）计算 $I_{n}(x)$ 只需 $n$ 次乘法：源文档以 $n = 4$ 的括号表达式为例。
4. 等距节点下均差化为差分：$[x_{i} \cdots x_{i+k}] = \Delta^{k} y_{i}/(k! h^{k})$；向前差分沿格式下斜对角线，向后差分沿上斜对角线。
5. 由此得 [[牛顿-格雷戈里插值公式]]：I 型以 $x = x_{0} + th$ 表达（系数 $\binom{t}{k}\Delta^{k} y_{0}$），II 型以 $x = x_{n} + sh$ 表达（系数 $\binom{s}{k}\nabla^{k} y_{n}$）。

## 直接证据与推断

- 直接证据：公式、递归定义与两个差分格式表均由源文档显式给出。
- 推断：源文档称牛顿公式「最有效计算 $x$ 点插值」的方法计算量为 $n$ 次乘法，这是相对于逐项展开的定性比较，未给出与其他表示形式的完整计算量对比。
