# 当 x → +∞ 时指数函数增长快于任意幂函数

## 陈述

手册 1.3.1.4 例 4(v)：当 $x \to +\infty$ 时

```
x^n = o(e^x),    n = 1, 2, …
```

手册的解读是：函数 $y = \mathrm{e}^x$ 比任何幂函数 $x^n$ 增长得快。

## 同一结论的其他出现形式

- 1.3.1.3 例 2 与例 3 通过洛必达法则重复应用得到 $\lim_{x\to+\infty} \mathrm{e}^x / x = +\infty$ 与 $\lim_{x\to+\infty} \mathrm{e}^x / x^2 = +\infty$（见 [[洛必达法则]]）。
- 例 5 用同一事实得出 $\lim_{x\to+\infty}(\mathrm{e}^x - x) = +\infty$。

## 证据与强度

以 $o$ 记号形式陈述，并可由洛必达法则（对 $\mathrm{e}^x / x^n$ 反复求导 $n$ 次）直接验证，证据强度高；本节未给逐条数值验算。
