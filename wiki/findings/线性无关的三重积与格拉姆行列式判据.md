# 线性无关的三重积与格拉姆行列式判据

本手册 1.8.3 节给出三个向量 $a, b, c$ 线性无关的两条等价判据：

(a) $(abc) \neq 0$，即 [[三重积]] 非零；

(b) **格拉姆行列式**非零：

```latex
| a a  a b  a c |
| b a  b b  b c |  ≠ 0
| c a  c b  c c |
```

原书措辞为「当且仅当满足下面两个条件之一」，即二者互为替代判据。

与此对照，1.8.1 节给出的线性无关几何判据是：两个非零向量线性无关当且仅当不共线；三个非零向量线性无关当且仅当不共面。两者是一致的（三重积恰为平行六面体体积）。

直接证据：判据 (a)(b) 与其行列式形式均为 1.8.3 节原文；未附证明与出处。
