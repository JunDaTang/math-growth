# 5.1.6 节：拉格朗日乘子思想与修正欧拉-拉格朗日方程

## 观察（直接证据）

本节以「隐藏在拉格朗日乘子背后的思想」为标题给出构造：(1) 用修正的拉格朗日函数代替原拉格朗日函数 $L$：

```latex
\boxed{\mathscr{L} := L + \sum_{k=1}^{K} \lambda_k(t) N_k}
```

(2) 在欧拉-拉格朗日方程中用 $\mathscr{L}$ 代替 $L$，得 (5.41)：

```latex
\boxed{\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k} - \mathscr{L}_{q_k} = 0,\quad k = 1,\dots,K.}\tag{5.41}
```

原文脚注 1) 给出 (5.41) 的显式写法：

```latex
\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k}(q(t), q'(t), t)
- \mathscr{L}_{q_k}(q(t), q'(t), t) = 0.
```

本节还给出求解目标：由 (5.41)、约束条件与边界条件确定 $q_k=q_k(t)$ 与 $\lambda_k=\lambda_k(t)$，$k=1,\cdots,K$；并称函数 $\lambda_{k}=\lambda_{k}(t)$ 为拉格朗日乘子。

## 说明（推断）

- (5.41) 在形式上与普通的[[concepts/欧拉-拉格朗日方程]]一致，差别仅在于被变分的函数是 $\mathscr{L}$。这正是乘子法的技术要点：以引入未知乘子为代价，把约束问题形式化归为无约束问题。
- (5.41) 的指标范围在源文本中写作 $k=1,\dots,K$，而 $q$ 有 $F$ 个分量，二者未必相同，见 [[queries/516节修正欧拉-拉格朗日方程索引k范围是否为F]]。
- 原文「在欧拉-拉格朗日方程中用 L 代替 L」一句两个符号相同，属排印讹误，见 [[queries/516节用花体L代替L表述讹误]]。
