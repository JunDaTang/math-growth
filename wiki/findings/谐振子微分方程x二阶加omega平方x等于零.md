# 谐振子微分方程 x″ + ω²x = 0

**陈述.** 质量为 m 的弹簧沿一条直线放置，其终点的运动由 r(t) = x(t) i 给出，作用力为 F := −k x i（k > 0 为描述弹簧物理性质的常量）。代入 [[concepts/牛顿基本运动定律]] 得

```
m x″(t) i = −k x i
```

令 ω² = k/m，即得谐振子的微分方程

```
x″ + ω² x = 0
```

**来源.** [[sources/10-数学指南实用数学手册--10-191-速度和加速度--1kt6qq]]（1.9.1 节例「谐振子」，图 1.96）。
