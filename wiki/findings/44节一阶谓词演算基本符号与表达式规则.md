# 44 节：一阶谓词演算的基本符号与表达式规则

**直接证据（4.4.2 基本符号与表达式）**

```
(a) 个体变元 x_1, x_2, …
(b) 关系变元 R_1^(k), R_2^(k), …，其中 k = 1, 2, …
(c) 逻辑函子：¬, ∧, ∨, →, ↔
(d) 全称量词符 ∀ 和存在量词符 ∃
(e) 括号 (，)
```

关系变元 $R_n^{(k)}$ 按定义应用于 $n$ 个个体变元，如 $R_2^{(k)} x_1 x_2$。

表达式规则：

```
(i)   任何符号串 R_n^(k) x_{i1} x_{i2} … x_{in}  (k, n = 1, 2, …) 是一个表达式。
(ii)  如果 A 和 B 是表达式，则 ¬A, (A ∧ B), (A ∨ B), (A → B), (A ↔ B) 也是表达式。
(iii) 如果 A(x_j) 是一个表达式，其中个体变元 x_j 全部自由地出现，则 ∀x_j A(x_j) 和 ∃x_j A(x_j) 也是表达式。
(iv)  一个符号串只有当它是由上面的 (i) 到 (iii) 形成的时才是一个表达式。
```

**例证（源文直接给出）**：个体域取 $\mathbb{R}$，$R$ 为自然数集时 $a \in R$ 表示「$a$ 是自然数」；取 $R := \{(a, a) \mid a \in \mathbb{R}\}$ 时 $\forall a \forall b (R a b \to R b a)$ 表示「对实数 $a, b$，$a = b$ 意味着 $b = a$」。

**观察**：规则 (iii) 以「$x_j$ 全部自由地出现」为加量词的前提，本节未展开约束／自由出现的完整定义。例 2 中 $R$ 既作关系变元又作实数集，记号冲突见 [[queries/44节记法编号讹误与未落地引用]]。
