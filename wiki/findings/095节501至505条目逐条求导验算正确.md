# 0.9.5 节条目 501–505 逐条求导验算正确

## 结论

对 0.9.5 节第 501–505 号条目（见 [[entities/表095不定积分表-4]]）逐条求导回到被积函数，**五条全部通过验算**，未发现转写错误。

## 验算要点

### 501（`arccot` 降幂递推）

分部积分取

```latex
u = \operatorname{arccot}\frac{x}{\alpha},\quad
\mathrm{d}v = x^{-n}\,\mathrm{d}x,\quad
v = -\frac{1}{(n-1)x^{n-1}},\quad
\mathrm{d}u = -\frac{\alpha\,\mathrm{d}x}{\alpha^{2}+x^{2}}
```

代回 $\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u$ 即得手册所示递推式，余项为 $-1/x^{n-1}$ 与 $-\alpha/(\alpha^{2}+x^{2})$ 的乘积积分，与原文的 $\frac{\alpha}{n-1}\int \frac{\mathrm{d}x}{x^{n-1}(\alpha^{2}+x^{2})}$ 一致。✅

### 502–505（反双曲函数）

四条的关键是：$x\,u(x)$ 的导数产生的「多余项」恰被结果中根式项或对数项的导数抵消。

- **502**：$x\operatorname{arsinh}(x/\alpha)$ 的导数为 $\operatorname{arsinh}(x/\alpha) + x/\sqrt{x^{2}+\alpha^{2}}$，减 $\sqrt{x^{2}+\alpha^{2}}$ 的导数 $x/\sqrt{x^{2}+\alpha^{2}}$，余 $\operatorname{arsinh}(x/\alpha)$。✅
- **503**：同理，多余项 $x/\sqrt{x^{2}-\alpha^{2}}$ 与 $-\sqrt{x^{2}-\alpha^{2}}$ 的导数相消。✅
- **504**：多余项 $\alpha x/(\alpha^{2}-x^{2})$ 与 $\frac{\alpha}{2}\ln(\alpha^{2}-x^{2})$ 的导数 $-\alpha x/(\alpha^{2}-x^{2})$ 相消。✅
- **505**：同理，多余项与 $\frac{\alpha}{2}\ln(x^{2}-\alpha^{2})$ 的导数 $+\alpha x/(x^{2}-\alpha^{2})$ 相消（注意 $\operatorname{arcoth}$ 导数为负，两负号相乘）。✅

## 边界与说明

- 本验算只涉及代数恒等变形与初等导数，无近似或数值误差来源。
- 验算针对的是**手册公式的转写文本**，因此结论同时构成对该段转写正确性的旁证；与 [[queries/094节公式转写疑误汇总]] 记录的前一子节转写问题并无冲突——两段独立。
- 501 的完整验算依赖「第 498 个积分」的具体形式，该条目位于已入库的 342–500 段（[[entities/表095不定积分表-3]]），本源仅以文字引用。

## 置信度与重复性

- 置信度：高。
- 重复性：验算可完全机械复现，判定为已复现（replicated = true）。
