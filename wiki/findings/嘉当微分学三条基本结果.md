# 嘉当微分学三条基本结果

《数学指南——实用数学手册》1.9.11 节陈述：嘉当微分学包含了 $\mathbb{R}^n$ 中微分式的如下基本结果（逐字保留）：

```
(i)   斯托克斯定理:  ∫_M dω = ∫_{∂M} ω .
(ii)  庞加莱法则:    ddω = 0 .
(iii) 庞加莱引理:    可缩区域 D 上的方程 dω = b 有解 ω , 当且仅当 db = 0.
```

## 说明

- 三条结果分别对应 [[斯托克斯定理微分式形式]]、[[庞加莱法则]]、[[庞加莱引理]] 三个概念页。
- 本节把经典向量分析的全部主要积分定理与微分恒等式都归为这三条的特例，构成"经典向量分析 ⊂ 嘉当微分学"的框架主张。
