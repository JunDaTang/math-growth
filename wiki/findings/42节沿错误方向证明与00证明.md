# 4.2 节：沿错误方向的证明与「0 = 0」证明

**来源**：《数学指南——实用数学手册》4.2.6.2 节。

**直接证据（来源明述）**：常犯的错误是试图通过证明逆蕴涵 $\mathcal{B} \Rightarrow \mathcal{A}$ 来证明 $\mathcal{A} \Rightarrow \mathcal{B}$；所谓「0 = 0」证明属于此类。错误断言为「每个实数 $x$ 都是方程 $x^2 - 4x + 3x + 1 = (x-1)^2 + 3x$（4.13）的一个解」。

其「证明」构造了正确的正向蕴涵链：

$$(4.13) \Rightarrow (4.14) \Rightarrow (4.15) \Rightarrow (4.16) \Rightarrow (4.17),$$

其中 (4.14) 为 $x^2 - x + 1 = x^2 - 2x + 1 + 3x = x^2 + x + 1$，(4.15) 为 $-x = x$，(4.16) 为 $x^2 = x^2$，(4.17) 为 $0 = 0$。

**错误定位**：这不是原断言的证明，需要的是反方向链条 $(4.17) \Rightarrow (4.16) \Rightarrow (4.15) \Rightarrow (4.14) \Rightarrow (4.13)$，而蕴涵 $(4.15) \Rightarrow (4.16)$ 不能逆过来——$(4.16) \Rightarrow (4.15)$ 仅对 $x = 0$ 为真。

**正确断言与证明**：方程 (4.13) 有唯一解 $x = 0$。步骤 1 由正向链条得至多一个解 $x=0$；步骤 2 验证 $x = 0 \Rightarrow (4.15) \Rightarrow (4.14) \Rightarrow (4.13)$。来源补充：更复杂的情形下人们常试图只作逻辑等值处理，即证明 $(4.13) \Leftrightarrow (4.14) \Leftrightarrow (4.15) \Leftrightarrow x = 0$。
