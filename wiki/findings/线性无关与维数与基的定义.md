# 线性无关、维数与基的定义

2.3.2 节给出三个相连定义：

线性无关：$u_1,\dots,u_n$ 线性无关当且仅当 $\alpha_1 u_1 + \dots + \alpha_n u_n = 0$ 总蕴涵 $\alpha_1 = \dots = \alpha_n = 0$；否则线性相关。

维数：X 的线性无关元素的最大个数称为 $\dim X$；$\dim X = \infty$ 表示存在任意多个线性无关元素；若 X 仅由中性元组成，$\dim X = 0$。

基：设 $\dim X < \infty$，$b_1,\dots,b_n$ 称为 X 的基，如果每个 $u \in X$ 可唯一地写成 $u = \alpha_1 b_1 + \dots + \alpha_n b_n$，$\alpha_1,\dots,\alpha_n \in K$，此时 $\alpha_1,\dots,\alpha_n$ 称为 u 关于此基的坐标。
