# 拉普拉斯展开法则 (2.6)

**主张**：对 (2.5) 中的行列式，有

```latex
D = a_{k1} A_{k1} + a_{k2} A_{k2} + \dots + a_{kn} A_{kn}, \tag{2.6}
```

其中 $k$ 是某个固定的行数，$A_{jk}$ 表示元素 $a_{jk}$ 的伴随行列式，即去掉第 $k$ 行和第 $j$ 列所得的行列式乘以 $(-1)^{j+k}$。

**特殊情形**：公式 (2.4) 是本公式在三阶、固定 $k = 1$ 时的特例（原文例 6）。

**依赖与注意**：$A_{jk}$ 即通行的代数余子式，术语歧义见 [[queries/212节Ajk称伴随行列式是否宜称代数余子式]]；原文中「$k$ 是某个固定的行数」处带脚注 `1)`，与本节另一处脚注编号重复，见 [[queries/212节两处脚注均编号1]]。

**来源**：《数学指南——实用数学手册》2.1.2 行列式，公式 (2.6) 与例 6。
