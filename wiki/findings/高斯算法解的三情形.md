# 高斯算法解的三情形

源在 2.1.4.2 中由三角形形式 (2.15) 出发，区分三种情形：

```
情形 1: 我们有 r < m，并且 β_{r+1}, β_{r+2}, ⋯, β_m 不全为零。
        那么方程组 (2.15) 因而方程组 (2.13) 无解。

情形 2: 我们有 r = m。由 α_{rr} ≠ 0 我们可解 (2.15) 中的第 r 个方程得出 y_r，
        其中将 y_{r+1},⋯,y_n 看作参数。然后应用第 r − 1 个方程解出 y_{r−1}。
        类似地解出 y_{r−2},⋯,y_1。
        这表明 (2.15) 及 (2.13) 的一般解依赖于 n − r 个实参数。

情形 3: 我们有 r < m，并且 β_{r+1} = ⋯ = β_m = 0，此时我们如情形 2 那样操作
        并得到 (2.15) 和 (2.13) 的一般解，它依赖于 n − r 个实参数。
```

## 观察

- 情形 1 与情形 2/3 的分界在于**尾部的 $0 = \beta_j$ 是否出现非零右端**；这与 [[concepts/秩判别法]] 中 $\operatorname{rank}(A)$ 与 $\operatorname{rank}(A,b)$ 是否相等完全对应。
- 情形 2 与情形 3 在求解操作上相同（都作回代并得到 $n-r$ 个参数），差别只在 $r$ 与 $m$ 的大小关系，即方程个数是否被完全用尽。
- 情形 1 的具体实例见 [[findings/例3无解]]。
