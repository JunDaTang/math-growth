# 伽马函数定义与函数方程 (1.480)

**证据类型**：教科书级定义与直接推论（非实验性结论）。

源文以阶乘定义伽马函数：

$$\Gamma(n+1) := n!, \quad n = 0, 1, 2, \dots,$$

并指出这显然蕴含

$$\Gamma(z+1) = z\Gamma(z), \tag{1.480}$$

其中先只声明 $z = 1, 2, \cdots$ 成立。源文随后陈述[[欧拉]]的问题：对 $z$ 的其他值能否合理定义 $n!$；为此欧拉求出函数方程 (1.480) 的一个解，即[[欧拉积分表示]] (1.481)。相关条目见[[伽马函数方程]]。
