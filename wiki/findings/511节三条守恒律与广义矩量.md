# 5.1.1 节：三条守恒律 (5.8)(5.9)(5.10) 与广义矩量

**直接证据（本书陈述）**：

- 拉格朗日方程可写作展开形式 $L_{q'q'} q'' + L_{q'q} q' + L_{q't} - L_q = 0$（(5.7)）。
- 广义矩量定义为 $p(t) := L_{q'}(q(t), q'(t), t)$。
- **(i) 能量守恒**：若 $L$ 与 $t$ 无关（时间齐性），则 $\dfrac{\mathrm{d}}{\mathrm{d}t}(q' L_{q'} - L) = 0$，即 $q'(t)p(t) - L(q, q', t) = \text{常数}$（(5.8)）；左端对应力学中系统的能量。
- **(ii) 矩量守恒**：若 $L$ 不依赖 $q$（位置齐性），则 $\dfrac{\mathrm{d}}{\mathrm{d}t} L_{q'} = 0$，即 $p(t) = \text{常数}$（(5.9)）。
- **(iii) 速度守恒**：若 $L$ 既不依赖 $q$ 也不依赖 $t$，则 $L_{q'}(q'(t)) = \text{常数}$，解得 $q'(t) = \text{常数}$（(5.10)）；由此曲线族 $q(t) = \alpha + \beta t$ 是 (5.7) 的解。

**判断项**：三条守恒律各自对应拉格朗日函数的一种齐性（时间齐性、位置齐性、两者兼有），构成 [[concepts/拉斯克-诺特定理]] 的具体实例。
