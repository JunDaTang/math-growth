# 5.1.6 节：带约束极小化问题的提法与两类约束

## 观察（直接证据）

5.1.6 节以 $q=(q_{1},\cdots,q_{F})$ 为未知函数向量，给出的带约束极小化问题提法为 (5.38)：

```latex
\boxed{\begin{array}{c}
  \int_{t_0}^{t_1} L(q(t), q'(t), t)\,\mathrm{d}t \stackrel{!}{=} \min, \\
  q(t_0) = a,\quad q(t_1) = b \quad (\text{边界条件}),
\end{array}}\tag{5.38}
```

约束条件被明确分为两类：

1. **积分约束**（5.39）：

```latex
\int_{t_0}^{t_1} N_k(q(t), q'(t), t)\,\mathrm{d}t = \text{常数}, \quad k = 1,\dots,K.
```

2. **隐约束**（5.40）：

```latex
N_k(q(t), q'(t), t)\,\mathrm{d}t = 0 \quad \text{在}\ [t_0,t_1]\ \text{上},\quad k = 1,\dots,K.
```

本节同时假定函数 $L$ 和 $N_{k}$ 充分光滑。

## 说明（推断）

- 边界条件为固定端点条件：$q(t_0)=a$、$q(t_1)=b$，即与 [[findings/511节曲线族与一阶变分为零]] 中讨论的固定端点变分问题同一类型。
- 两类约束的区分是后续乘子类型（实数 vs 函数）差异的根源，见 [[findings/516节主定理乘子存在性与积分约束附注]]。
