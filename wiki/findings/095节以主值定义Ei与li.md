# 0.9.5 以广义积分的主值定义 Ei(x) 与 li(x)

## 观察

表 0.9.5 的第 3 部分是「不定积分表」，其中绝大多数条目的原函数都是初等函数；但 420 与 438 两条例外，它们把 ∫ e^{αx}/x dx 与 ∫ dx/ln x 的讨论引向两个以发散广义积分定义的函数：

```latex
420：广义积分 ∫_{−∞}^{x} e^t/t dt 称为积分指数函数，记为 Ei(x)。
     当 x > 0 时，该积分在 t = 0 处发散，此时 Ei(x) 是这个广义积分的主值。
438：积分 ∫ dt/ln t 称为对数积分，记为 li(x)。当 x > 1 时，它在点 t = 1 处发散。
     此时，函数 li(x) 的值是这个广义积分的主值。
```

两处都注明了「参看 0.5.5 和 0.7.2」，即严格定义与级数表示分别在手册的特殊函数节与幂级数节给出。

## 判断

- 这是本部分唯一引入新「函数对象」的地方，说明 0.9.5 并非纯初等积分表，而与 0.5 节特殊函数体系存在接口。
- 「主值」是这两处定义的共同技术手段，[[广义积分的主值]]因此成为理解本条目的关键概念。
- 由此也解释了为什么 427、445、456 号条目不能给出初等闭式：它们都归结到 420（即 Ei）。

## 直接证据与推断的区分

- 直接证据：420、438 两段文字与其级数展开式在源中原文给出。
- 推断：li(x) 定义中的积分上限「∞」应为「x」（或等价的上限形式），因为 li 是 x 的函数；该推断基于定义必须依赖 x 这一逻辑要求，尚需核对原书。
