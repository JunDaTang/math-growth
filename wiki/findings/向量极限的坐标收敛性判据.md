# 向量极限的坐标收敛性判据

**陈述.** 令 aₙ = αₙ i + βₙ j + γₙ k，a = α i + β j + γ k，则有

```
lim_{n→∞} a_n = a
```

当且仅当 n → ∞ 时 αₙ → α, βₙ → β, γₙ → γ（坐标的收敛性，或称按坐标收敛）。

**来源.** [[sources/10-数学指南实用数学手册--10-191-速度和加速度--1kt6qq]]（1.9.1 节「坐标表示」）。

**说明.** 这是向量极限与三个独立的实数列极限之间的等价关系，是 [[concepts/向量函数的坐标表示]] 的直接推论，也是「向量函数的微分运算可逐分量进行」这一整套做法的合法性基础。

**转录疑点.** 原文此处的第三个分量写作 `r_n → ν`，从上下文（αₙ → α, βₙ → β 之后）看疑应为 `γ_n → γ`，已记为 [[queries/191节坐标收敛性中r_n到nu是否应为gamma_n到gamma]]。
