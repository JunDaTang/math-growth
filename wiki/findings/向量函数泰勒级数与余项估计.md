# 向量函数泰勒级数与余项估计

**陈述.** 如果区间 [a, b] 上的 r = r(t) 是 C^{n+1} 类的，那么对所有的 t, t + h ∈ [a, b] 有

```
r(t + h) = r(t) + h r′(t) + (h²/2) r″(t) + … + (hⁿ/n!) r⁽ⁿ⁾(t) + R_{n+1}
```

其中误差估计为

```
|R_{n+1}| ≤ h^{n+1}/(n+1)! · sup_{s ∈ [a, b]} |r⁽ⁿ⁺¹⁾(s)|
```

**来源.** [[sources/10-数学指南实用数学手册--10-191-速度和加速度--1kt6qq]]（1.9.1 节「泰勒级数」）。

**说明.** 系数与实值泰勒公式一致；上确界取在整段区间上。可视为实值泰勒公式在 [[concepts/向量函数的Ck光滑性]] 条件下按分量推广的结果（参见 [[concepts/向量函数的坐标表示]]）。

**性质.** 定理性陈述，非经验发现；置信度 high，复制状态不适用（null）。
