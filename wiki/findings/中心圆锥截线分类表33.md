# 中心圆锥截线分类（表 3.3）

## 前提

对一般圆锥截线 $x^{\mathrm{T}}Ax + x^{\mathrm{T}}a + a_{33} = 0$，当 $\det A \neq 0$（有中心）时，线性方程组

$$
a_{11}\alpha_{1} + a_{12}\alpha_{2} + a_{13} = 0, \quad a_{21}\alpha_{1} + a_{22}\alpha_{2} + a_{23} = 0
$$

有唯一解 $(\alpha_{1}, \alpha_{2})$。平移 $X_{j} := x_{j} - \alpha_{j}$ 后得 $a_{11}X_{1}^{2} + 2a_{12}X_{1}X_{2} + a_{22}X_{2}^{2} = -\dfrac{\det\mathcal{A}}{\det A}$，再由旋转得

$$
\lambda x^{2} + \mu y^{2} = -\frac{\det\mathcal{A}}{\det A}.
$$

## 表 3.3 中心圆锥截线

| det A | det 𝒜 | 法式 (a>0, b>0, c>0) | 名称 |
|-------|-------|----------------------|------|
| >0 | < 0 | $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1$ | 椭圆 |
| >0 | >0 | $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=-1$ | 虚椭圆 |
| >0 | =0 | $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=0$ | 二重点 |
| <0 | < 0 | $\frac{x^{2}}{a^{2}}-\frac{y^{2}}{b^{2}}=1$ | 双曲线 |
| <0 | >0 | $\frac{y^{2}}{b^{2}}-\frac{x^{2}}{a^{2}}=1$ | 双曲线 |
| <0 | =0 | $\frac{x^{2}}{a^{2}}-\frac{y^{2}}{b^{2}}=0$ | 二重直线 |

## 说明

分类由 $\det A$ 的符号与 $\det\mathcal{A}$ 的符号共同决定。源文件表头两列在 OCR 结果中均显示为 `det A`；正文实际使用二阶矩阵 $A$ 与三阶扩充矩阵 $\mathcal{A}$，见 [[queries/34节表33表头两列均为detA]]。原表另含"图示"列。
