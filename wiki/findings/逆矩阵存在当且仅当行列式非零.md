# 逆矩阵存在当且仅当 det A ≠ 0

## 陈述

设 `A ∈ Mat(n,n)`。A 的逆矩阵定义为满足 `AB = BA = E` 的矩阵 `B ∈ Mat(n,n)`，其中 E 是 `n × n` [[单位矩阵]]。

> 这种矩阵 B 存在，当且仅当 `det A ≠ 0`，亦即 A 的行列式非零。此时 B 唯一确定并记作 `A^{-1}`。

因此当 `det A ≠ 0` 时：

```
A A^{-1} = A^{-1} A = E
```

## 证据类型

来源直接陈述的判定定理，条件为充分必要，并附带唯一性断言。见 [[逆矩阵]]、[[行列式]]、[[正则矩阵]]。
