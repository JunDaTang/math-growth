# 7.3.1.1 节：拉格朗日插值公式、局部系数与重心公式

## 观察

本节给出插值多项式的第一种表示。核心链条为：

1. 定义 $n+1$ 个 [[拉格朗日多项式]] $L_{i}(x) = \prod_{j \neq i}(x - x_{j})/(x_{i} - x_{j})$，满足 $L_{i}(x_{i}) = 1$、$L_{i}(x_{k}) = 0\ (k \neq i)$。
2. 由此得 [[拉格朗日插值公式]] $I_{n}(x) = \sum_{i=0}^{n} y_{i} L_{i}(x)$。
3. 为在非插值点求值，引入 [[局部系数与插值权重]] $\lambda_{i} = 1/\prod_{j\neq i}(x_{i} - x_{j})$ 与 $\mu_{i} = \lambda_{i}/(x - x_{i})$。
4. 因 $\prod_{k}(x - x_{k})$ 等于 $\sum_{i}\mu_{i}$ 的倒数，得到 [[重心公式]] $I_{n}(x) = \{\sum y_{i}\mu_{i}\} / \{\sum \mu_{i}\}$，源文档评价其「对数值计算是有用的」。
5. 等距插值点（步长 $h$）下 $\lambda_{i} = (-1)^{n-i}\binom{n}{i}/(h^{n} n!)$；去掉可约的公共因子后可用等价的符号交错二项式系数 $\lambda_{i}^{*} = (-1)^{i}\binom{n}{i}$。

## 直接证据与推断

- 直接证据：公式 (1)–(5) 均由源文档显式给出。
- 推断：源文档未展开重心公式相对其他形式的数值稳定性讨论，只给出「对数值计算有用」的定性评价。
