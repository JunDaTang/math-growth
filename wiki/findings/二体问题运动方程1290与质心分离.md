# 二体问题运动方程 (1.290) 与质心分离

## 结论

对分别具有质量 $m_1$ 与 $m_2$、总质量 $m = m_1 + m_2$ 的两个天体，运动定律为

```text
m₁ x₁'' = F,   m₂ x₂'' = -F,
x_j(0) = x_{j0},   x_j'(0) = v_j,   j = 1, 2            (1.290)
F = G m₁ m₂ (x₂ - x₁) / |x₂ - x₁|³
```

其中力 F 与 −F 成对出现，相应于牛顿定律「作用力 = 反作用力」。

质心 $\boldsymbol{y} := \frac{1}{m}(m_1\boldsymbol{x}_1 + m_2\boldsymbol{x}_2)$ 满足总动量守恒

```text
P' = 0,   P = m y',
```

故 $m y'' = 0$，解为

```text
y(t) = y(0) + t y'(0),
y(0)  = (1/m)( m₁ x₁₀ + m₂ x₂₀ ),
y'(0) = (1/m)( m₁ v₁ + m₂ v₂ ).
```

质心以常速度沿一直线运动。在太阳—行星系统中，质心 y 位于太阳的内部。

## 证据与推理

- 直接证据：本源给出 (1.290)、引力表达式以及质心分离的完整推导。
- 交叉印证：该结论与 1.9.6 节 [[太阳系质心沿直线常速运动]] 一致。
- 附注：本源未给出牛顿引力常数 G 的数值。
