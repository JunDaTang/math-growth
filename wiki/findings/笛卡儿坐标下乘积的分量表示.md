# 笛卡儿坐标下乘积的分量表示

本手册 1.8.3 节给出笛卡儿坐标下的乘积公式。设

```latex
a = a_1 i + a_2 j + a_3 k,  b = b_1 i + b_2 j + b_3 k,  c = c_1 i + c_2 j + c_3 k,
```

则

```latex
a b = a_1 b_1 + a_2 b_2 + a_3 b_3,

a × b = | i    j    k   |
        | a_1  a_2  a_3 |
        | b_1  b_2  b_3 |
      = (a_2 b_3 − a_3 b_2) i + (a_3 b_1 − a_1 b_3) j + (a_1 b_2 − a_2 b_1) k,

(a b c) = | a_1  a_2  a_3 |
          | b_1  b_2  b_3 |
          | c_1  c_2  c_3 |
```

即：标量积为坐标对应相乘再相加；向量积与三重积均为行列式，行列式的行（或列）为参与向量的坐标。

原书同时给出一般坐标系下的对应公式（见 [[对偶基与反变共变坐标的分量法则]]），并指出笛卡儿坐标系中 $a_j = a^j$，反变坐标与共变坐标相等，故上述简洁形式成立。

直接证据：三条公式均为 1.8.3 节原文，未附推导。
