# 体积的导数公式 (1.165)

1.9.7 节给出：

```
g(P) = lim_{n→∞} ( ∫_{D_n} g(x) dx ) / ( meas D_n )        (1.165)
```

**条件**：$g$ 是在点 $P$ 的一个邻域内连续的一实值函数；$(D_n)$ 是 [[concepts/容许区域]]（例如球）序列，均包含 $P$，且直径趋于零；$\mathrm{meas}\,D_n$ 表示 [[concepts/勒贝格测度]]。

**用途（直接证据）**：本节用它把由 [[concepts/高斯定理]] 得到的积分恒等式化为点态方程 (1.166)。

**证据强度**：教材级结论，未给证明与出处。
