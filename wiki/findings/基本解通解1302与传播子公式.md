# 基本解的通解 (1.302) 与传播子公式 P=XX⁻¹

## 陈述

设 $\boldsymbol{X}(t)$ 为齐次方程 $x'=A(t)x$ 的[[基本解]]（列向量 $X_j$ 满足 $X'_j = AX_j$，且 $\det X(t_0)\neq 0$）。则定理给出：

(i) 通解

```latex
\boldsymbol {x} (t) = \sum_ {j = 1} ^ {n} C _ {j} \boldsymbol {X} _ {j} (t),\tag{1.302}
```

$C_1,\cdots,C_n$ 为任意常数；

(ii) 传播子

```latex
\boxed {\boldsymbol {P} (t, \tau) = \boldsymbol {X} (t) \boldsymbol {X} (\tau) ^ {- 1}.}
```

## 证据与限制

- 原文以「定理」形式给出两条性质，未给证明；脚注 2) 说明 (1.301) 可由 (1.302) 形式的解施以[[拉格朗日]][[常数变易法]]得到。
- 原文强调这套经典构造只适用于线性组 (1.300) 的特殊结构，「不能被推广」（与[[戴森公式]]的可推广性形成对照）。
- $\operatorname{det}\boldsymbol{X}(t)$ 即[[朗斯基行列式]]；由 $\det X(t_0)\neq 0$ 可推得对所有 $t$ 有 $\det X(t)\neq 0$（原文脚注 1) 断言，未给证明）。
