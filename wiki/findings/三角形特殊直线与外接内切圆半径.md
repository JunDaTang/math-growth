# 中线、中垂线、角平分线及外接圆与内切圆半径公式

## 观察（直接证据）

源文档 3.2.1.4 节的内容：

- 中线：通过一边中点与此边相对顶点的直线；三条中线交于中心，中心把中线分成从顶点开始度量的 2:1 两部分。c 边上中线长
  $$s_c = \frac{1}{2}\sqrt{a^{2}+b^{2}+2ab\cos\gamma} = \frac{1}{2}\sqrt{2(a^{2}+b^{2}) - c^{2}} .$$
- 中垂线（源中又称等距垂线）：垂直于一条边并通过该边中点的线段；三条交于外接圆圆心，外接圆半径
  $$R = \frac{a}{2\sin\alpha}.$$
- 角平分线：通过一个顶点和它的对边并把该角分成两个相等的角；三条交于内切圆中心，内切圆半径
  $$r = (s-a)\tan\frac{\alpha}{2} = \frac{A}{s} = \sqrt{\frac{(s-a)(s-b)(s-c)}{s}},$$
  $$r = s\tan\frac{\alpha}{2}\tan\frac{\beta}{2}\tan\frac{\gamma}{2} = 4R\sin\frac{\alpha}{2}\sin\frac{\beta}{2}\sin\frac{\gamma}{2}.$$
- 角 γ 的平分线长
  $$w_\gamma = \frac{2ab}{a+b}\cos\frac{\gamma}{2} = \frac{\sqrt{ab\left((a+b)^{2} - c^{2}\right)}}{a+b}.$$

个别地，节首还定义外接圆为含整个三角形的最小圆、内切圆为三角形内最大圆。

## 评估

公式本身与标准结果一致。术语层面存在不统一：同一条中垂线在同段内被称作「中垂线」与「等距垂线」；三角形的三条中线交点被称作「中心」，而中文几何教材通常称「重心」（或形心）。源中「从顶点开始度量」这一措辞明确指出了 2:1 的度量起点，属直接证据。相关讨论见 [[queries/321节术语与排印疑似讹误]]。
