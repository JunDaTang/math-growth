# 例 3：∫_{−∞}^{∞} dx/(1+x²) = π 的留数计算

## 结论

```text
∫_{−∞}^{∞} dx/(1 + x²) = π.
```

## 源文档给出的证明

多项式 $h(z) := 1 + z^2$ 可分解为

```text
h(z) = (z − i)(z + i),
```

所以 $h(z)$ 在**上半平面**中点 $z = i$ 处有一个一阶零点。由 [[留数计算法则]] (1.463) 的 $m=1$ 一支：

```text
Res_i [1/(1 + z²)] = lim_{z→i} (z − i)/[(z + i)(z − i)] = 1/(2i).
```

因而由 [[有理函数实积分的留数公式]] (1.464)：

```text
∫_{−∞}^{∞} dx/(1 + x²) = 2πi · Res_i [1/(1 + z²)] = π.
```

## 证据类型

- **直接陈述并给出证明**（源文完整给出）。
- 该结论是 (1.464) 的一个具体实例；上半平面零点 $z = i$ 与下半平面零点 $z = -i$ 只取前者，是公式适用条件的体现。
