# 球面三角学核心公式组

## 公式清单（3.2.3.3 节）

| 编号 | 名称 | 形式要点 |
|------|------|----------|
| (3.9) | 正弦定律 | $\dfrac{\sin \alpha}{\sin \beta} = \dfrac{\sin a_{*}}{\sin b_{*}}$ |
| (3.10) | 边的余弦定律 | $\cos c_{*} = \cos a_{*}\cos b_{*} + \sin a_{*}\sin b_{*}\cos\gamma$ |
| (3.11) | 角的余弦定律 | $\cos\gamma = \sin\alpha\sin\beta\cos c_{*} - \cos\alpha\cos\beta$ |
| (3.12) | 半角定律 | $\tan\dfrac{\gamma}{2} = \sqrt{\dfrac{\sin(s_{*}-a_{*})\sin(s_{*}-b_{*})}{\sin s_{*}\sin(s_{*}-c_{*})}}$，$0<\gamma<\pi$ |
| (3.13) | 半边定律 | $\tan\dfrac{c_{*}}{2} = \sqrt{\dfrac{-\cos\sigma\cos(\sigma-\gamma)}{\cos(\sigma-\alpha)\cos(\sigma-\beta)}}$，$0<c_{*}<\pi$ |
| (3.14) | 半边定律（第三基本问题用） | $\tan\dfrac{a_{*}}{2} = \sqrt{\dfrac{-\cos\sigma\cos(\sigma-\alpha)}{\cos(\sigma-\beta)\cos(\sigma-\gamma)}}$ |
| — | 广义海伦公式 | $\tan\dfrac{A}{4} = \sqrt{\tan\dfrac{s_{*}}{2}\tan\dfrac{s_{*}-a_{*}}{2}\tan\dfrac{s_{*}-b_{*}}{2}\tan\dfrac{s_{*}-c_{*}}{2}}$ |
| — | 纳皮尔公式 | 4 条含半角、半边的 tan/cot 恒等式 |
| — | 莫尔韦德公式 | 4 条含半角、半边的 sin/cos 恒等式 |
| — | 内切圆/外接圆半径 | $\tan r$、$\cot\rho$ 公式（见[[球面三角形的内切圆与外接圆]]） |

## 记号

$a_{*} := a/R$，$b_{*} := b/R$，$c_{*} := c/R$；$s_{*} = \frac{1}{2}(a_{*}+b_{*}+c_{*})$；$\sigma = \frac{1}{2}(\alpha+\beta+\gamma)$。源文件脚注说明常取 $R = 1$，保留 $R$ 是为了取 $R \to \infty$ 与 $R \mapsto \mathrm{i}R$ 两种极限。

## 备注

- 正弦定律脚注：若 $\alpha$ 为直角，则 $\sin\alpha = 1$、$\cos\alpha = 0$；
- 源文件中半角定律的说明记号写作 $S_{*}$ 而公式中写作 $s_{*}$，见 [[323节球面对角形术语与记号疑似讹误]]。
