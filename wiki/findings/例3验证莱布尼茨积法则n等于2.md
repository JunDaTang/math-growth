# 例 3：h''(x) = 2cos x − x sin x 验证莱布尼茨积法则 n=2

## 内容

考虑 $h(x) := x \cdot \sin x$。令 $f(x) := x,\ g(x) := \sin x$，则 $f'(x) = 1,\ f''(x) = 0$，且 $g'(x) = \cos x,\ g''(x) = -\sin x$。因此 1.4.1 节得到

$$
h''(x) = 2\cos x - x\sin x.
$$

## 验证

直接对 $h(x) = x\sin x$ 求导两次：$h'(x) = \sin x + x\cos x$，$h''(x) = \cos x + \cos x - x\sin x = 2\cos x - x\sin x$。与源文档结论一致。

代入 [[莱布尼茨积法则]] 的 $n = 2$ 形式：$f''g + 2f'g' + fg'' = 0 \cdot \sin x + 2 \cdot 1 \cdot \cos x + x \cdot (-\sin x)$，同样得到 $2\cos x - x\sin x$。

## 证据强度

结论可独立验算且两条路径一致，属**强证据**。本例同时验证了 1.4.1 节所给 $n=2$ 形式的正确性（该形式本身未见转写疑点，与通则公式的疑误不同）。
