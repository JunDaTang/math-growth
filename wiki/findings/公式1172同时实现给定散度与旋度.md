# 公式 (1.172)：D_par + H_par 同时实现给定散度与旋度

## 公式

令 $v := D_{par} + H_{par}$，则在 $\mathbb{R}^3$ 上

```
div v = ρ  和  curl v = J.        (1.172)
```

## 推导要点（源文档给出）

由 [[体积位势与向量位势定义式]] 与 [[特解D-par与H-par的性质]]，$D_{par}$ 贡献散度 $\rho$ 而不贡献旋度，$H_{par}$ 贡献旋度 $J$ 而不贡献散度，两者叠加即同时满足两个方程。散度与旋度均为线性算子，故叠加后两个分量互不干扰。

## 证据与推断

- 直接证据：来源中的公式 (1.172) 及紧邻其前的两组性质式。
- 推断：叠加有效性依赖散度/旋度的线性性，属明确但来源未逐句写出的理由。
