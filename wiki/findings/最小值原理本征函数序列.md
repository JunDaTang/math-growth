# 最小值原理：逐次正交约束下的本征函数序列

**来源**：《数学指南——实用数学手册》1.12.8.3 节（[[10-数学指南实用数学手册--14-1128-边值问题和格林函数--1qd4d88]]）。

## 直接陈述（源中明确给出）

令

$$
F(y) := \frac{1}{2} \int_{a}^{b} (p y'^{2} + q y^{2}) \mathrm{d} x, \quad (y \mid z) := \int_{a}^{b} y z \, \mathrm{d} x,
$$

$Y$ 为满足 $y(a) = y(b) = 0$ 的所有 $C^2$ 函数 $y:[a,b] \to \mathbb{R}$ 的集合。

- (i) $y_1$ 是 $F(y) \stackrel{!}{=} \min$，$(y \mid y) = 1$，$y \in Y$ 的解；
- (ii) $y_2$ 从 $F(y) \stackrel{!}{=} \min$，$(y \mid y) = 1$，$(y \mid y_1) = 0$，$y \in Y$ 而得到；
- (iii) $y_n$ 是 $F(y) \stackrel{!}{=} \min$，$(y \mid y) = 1$，$(y \mid y_k) = 0$（$k = 1, \dots, n-1$），$y \in Y$ 的解；
- (iv) 对于第 $n$ 个本征值有 $\lambda_n := F(y_n)$。

## 备注

注意这里的 $F$ 与 1.12.8.2 节的泛函不同：**不含载荷项 $-2fy$**，且带因子 $1/2$，并附加规范化条件 $(y \mid y) = 1$。因此不宜把本条与 [[findings/变分问题1309等价于边值问题1306]] 的泛函混用。
