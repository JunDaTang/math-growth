# 6.2.5.3 节：泊松分布与泊松逼近定理（1837）

## 引入动机

原文先给出误差界 (6.23)：若 $p$ 非常小，则只有当 $n$ 非常大时用正态分布逼近 $\Phi_n$ 才有效。S. D. [[泊松]]（Poisson, 1781—1840）发现，当 $p$ 的值较小时有一个**更好的逼近公式**。

## 泊松分布的定义

在实数轴上的点 $x = 0, 1, 2, \cdots$ 处分别赋予质量 $m_0, m_1, \cdots$：

```
m_r := (λ^r / r!) e^{−λ},  r = 0, 1, ...,   λ > 0 为参数。
```

相应质量分布函数 $\Phi(x) :=$ 区间 $]-\infty, x[$ 所包含的质量，称为泊松分布函数（原文图 6.15）。

**定理**：若随机变量 $X$ 服从上述泊松分布，则 $\overline{X} = \lambda$（均值）、$\Delta X = \sqrt{\lambda}$（标准差）。

## 泊松逼近定理（1837）

若比较试验的概率 $p$ 非常小，则对频数 $A_n$ 近似有

```
(i) P(A_n = r) = (λ^r / r!) e^{−λ},  其中 λ = np, r = 0, 1, ..., n;
(ii) A_n 的分布函数 Φ_n 近似等于参数 λ = np 的泊松分布的分布函数，更精确地
     sup_{x∈ℝ} |Φ_n(x) − Φ(x)| ≤ 3√(λ/n)。
```

原文注：$\frac{\lambda^r}{r!}\mathrm{e}^{-\lambda}$ 的值可以在 0.4.6.9 中查到。

## 与原书的表述一致性

- 该定理的年份 **1837** 由原文标题直接给出。
- 误差界 $3\sqrt{\lambda/n} = 3\sqrt{p}$ 与 (6.23) 的 $1/\sqrt{np(1-p)}$ 给出两种逼近适用性的定量分界。
