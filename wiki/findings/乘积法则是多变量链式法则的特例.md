# 乘积法则与商法则都是多变量链式法则的特例

## 结论

《数学指南——实用数学手册》0.8.3 节表明：表 0.37（[[单变量微分法则]]）中的乘积法则与商法则，都可以由表 0.38（[[多变量链式法则]]）沿单一参数 $t$ 取全微分后还原出来。

## 例 5：还原乘积法则（直接证据）

令 $f(t) := x(t)y(t)$。由 0.8.3 节例 3（$f(x,y)=xy$ 给出 $f_x = y$、$f_y = x$），全微分为

$$\mathrm{d}f = f_x\mathrm{d}x + f_y\mathrm{d}y = y\,\mathrm{d}x + x\,\mathrm{d}y$$

于是

$$f'(t) = \frac{\mathrm{d}f}{\mathrm{d}t} = y\frac{\mathrm{d}x}{\mathrm{d}t} + x\frac{\mathrm{d}y}{\mathrm{d}t} = y(t)x'(t) + x(t)y'(t)$$

即乘积法则。手册原文的措辞是：「这是一个乘积法则，因此我们可以把乘积法则看成是多变量函数的链式法则的特例。」

## 例 6：还原商法则（直接证据）

令 $f(t) := \frac{x(t)}{y(t)}$。由 0.8.3 节例 4（$f(x,y)=xy^{-1}$ 给出 $f_x = y^{-1}$、$f_y = -xy^{-2}$），全微分为

$$\mathrm{d}f = y^{-1}\mathrm{d}x - xy^{-2}\mathrm{d}y$$

于是

$$f'(t) = \frac{x'(t)}{y(t)} - \frac{x(t)y'(t)}{y(t)^{2}} = \frac{x'(t)y(t) - x(t)y'(t)}{y(t)^{2}}$$

即商法则。

## 意义与限制

- 这两个还原过程揭示了单变量微分法则的「来源」：它们是多变量链式法则沿一条路径（此处为参数 $t$）的特例。
- 手册只在 $f = f(x,y)$ 与单参数 $t$ 的情形演示，未讨论 $n$ 元、多参数的一般特例；一般形式仅以公式给出（见 [[多变量链式法则]]）。
