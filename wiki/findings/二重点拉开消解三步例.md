# 二重点拉开消解三步例（曲线 x²−y²=0）

## 观察

《数学指南——实用数学手册》3.8.8 节「例（图 3.91）」给出一个可显式核验的消解过程。考虑曲线

```text
X: x² − y² = 0,   (x, y) ∈ ℂ²,        (3.71)
```

它在 $P = (0,0)$ 有一个二重点（[[二重点与尖点]]）。消解分三步：

### 第 1 步：拉开二重点 $P$ 为直线 $g_P$

即将此点换成一条射影直线。利用参数化

```text
(x, y) = f(u, v),   (u, v) ∈ ℂ²       (3.72)
```

其中 $f(u,v) := (u, uv)$。由 (3.71) 得到方程

```text
v²(1 − u²) = 0,   (u, v) ∈ ℂ².
```

这引出了三条直线 $g_{\pm}: u = \pm 1$ 和 $g_P: u = 0$。直线 $g_+$、$g_-$（分别地，$g_P$）由 (3.72) 变换为 $X$ 的两条分支直线（分别地，$X$ 的二重点）。

### 第 2 步：把 $g_P$ 嵌入三维空间

得到 $\mathbb{C}^3$ 中的直线 $G_P$：

```text
G_P := {(u, v, w) ∈ ℂ³ : v = 0, w = 1},
g_± := {(u, v, w) ∈ ℂ³ : u = ±1, w = 0}
```

### 第 3 步：构造分解

选取参数空间 $T$ 为三条不相交的直线 $g_+, g_-, G_P$，分解映射由

```text
π : 𝒯 --π--> ℂ² --f--> X
```

给出，其中投射 $\pi(u,v,w) := (u,v)$。

## 证据强度

- 这是**可显式代数核对**的具体例子（例如把 $f(u,v)=(u,uv)$ 代入 $x^2-y^2$ 即得 $v^2(1-u^2)$），证据强度评为 `high`。
- 命名主体为**曲线 $x^2 - y^2 = 0$** 及其消解过程。「二重点」「拉开」「嵌入」三步操作是该书针对此例给出的，不构成对一般定理的证明。
- 书中评注：「一般的拉开的构造的优点是它可扩张到一个普遍适用的构造上。」该普适化论断在正文中未展开证明。

## 直接证据与推论之分

- **直接证据**：(3.71)、(3.72)、$f(u,v)=(u,uv)$、$v^2(1-u^2)=0$、$G_P$ 与 $g_\pm$ 的集合定义、投影 $\pi(u,v,w)=(u,v)$，均为源文原文。
