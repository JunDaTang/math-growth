# 阻尼方程 (1.216) 与阻尼振动解 (1.217)

由 $m\mathbf x''=-k\mathbf x-\gamma\mathbf x'$（$\gamma>0$）得

```latex
\begin{array}{l}
x''(t) + \omega^2 x(t) + 2\beta x'(t) = 0, \\
x(0) = x_0, \quad x'(0) = v,
\end{array}                                       \tag{1.216}
```

$\beta := \gamma/2m$。**指数假设** $x=\mathrm e^{\lambda t}$ 给出特征方程

```latex
\lambda^2 + \omega^2 + 2\beta\lambda = 0,
```

其解 $\lambda_\pm = -\beta\pm\mathrm i\sqrt{\omega^2-\beta^2}$；解族 $x=C\mathrm e^{\lambda_+t}+D\mathrm e^{\lambda_-t}$，常数 $C,D$ 由初始条件确定，亦可用欧拉公式 $\mathrm e^{(a+\mathrm ib)t}=\mathrm e^{at}(\cos bt+\mathrm i\sin bt)$。

当 $0<\beta<\omega$ 时，对所有 $t$ 的唯一解为

```latex
x = x_0 \mathrm{e}^{-\beta t}\cos \omega_* t
+ \frac{v+\beta x_0}{\omega_*} \mathrm{e}^{-\beta t}\sin \omega_* t,  \tag{1.217}
```

其中 $\omega_* := \sqrt{\omega^2-\beta^2}$，即阻尼振动。

**注意**：源文对「问题 (1.216) 有唯一解」加脚注标记 1)，脚注内容未转录（见 [[queries/1121节脚注内容未录]]）。源文仅讨论 $0<\beta<\omega$（欠阻尼）情形，未涉及 $\beta=\omega$ 与 $\beta>\omega$。
