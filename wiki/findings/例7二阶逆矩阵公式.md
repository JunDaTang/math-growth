# 例 7：2×2 矩阵逆矩阵公式

## 陈述

矩阵 `A := (a b; c d)` 的逆矩阵 `A^{-1}` 存在，当且仅当 `det A ≠ 0`，亦即 `ad − bc ≠ 0`。此时逆矩阵由

```
A^{-1} = 1/(ad − bc) · ( d  −b )
                       ( −c  a )
```

给出。来源验证：计算表明 `A A^{-1} = A^{-1} A = (1 0; 0 1)`。

## 证据类型

来源中的显式算例，用于支撑「存在当且仅当 det A ≠ 0」的定理。见 [[逆矩阵]]。
