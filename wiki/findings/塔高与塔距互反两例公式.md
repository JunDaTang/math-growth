# 塔高与塔距互反两例公式

## 观察

《数学指南——实用数学手册》3.2.2 节用一对互为反解的例子说明[[倾角]]的用法（图 3.10）。

**一、塔的高度**：一个人试图确定一个塔的高 $h$。被测量的量是测量点到塔的距离 $d$ 与倾角 $\alpha$，计算为

```
h = d · tan α
```

**二、到一个塔的距离**：已知塔的高度 $h$，要确定到该塔的距离 $d$。被测量的量是倾角 $\alpha$ 并已知塔高 $h$，计算为

```
d = h · cot α
```

## 证据强度

两式直接来自直角三角形的边角定义，$d$ 与 $h$ 的角色互换即得，属充分证据，无须额外推导。$h$ 与 $d$ 在塔高水位线、仪器高度等实际修正上的处理，源文件未涉及。
