# 0.9.6 节以欧拉常数 C 给出若干定积分值

## 观察

0.9.6 节共 6 个条目的结果显式含欧拉常数 C，分布在两个子节中，且呈现对数幂次的规律：

| 条目 | 积分 | 结果 |
|------|------|------|
| 9 | ∫₀^∞ e^{−x} ln x dx | −C |
| 10 | ∫₀^∞ e^{−x²} ln x dx | ¼Γ′(½) = −(√π/4)(C + 2 ln 2) |
| 11 | ∫₀^∞ e^{−x²} ln²x dx | (√π/8)[(C + 2 ln 2)² + π²/2] |
| 33 | ∫₀¹ ln ln x dx | −C |
| 44 | ∫₀^∞ (sin x/x) ln x dx | −(π/2)C |
| 45 | ∫₀^∞ (sin x/x) ln²x dx | (π/2)C² + π³/24 |

## 规律

- 对数因子为一次幂时（9、10、33、44），C 以一次项出现；对数因子为二次幂时（11、45），C 以平方项出现并附带一个纯 π 幂的修正（π²/2 配系数 √π/8，π³/24 配系数 π/2）。
- 三组内核分别为 e^{−x}、e^{−x²}、sin x/x，对应三种不同的权重函数，但对数矩的展开模式一致。
- 条目 33 的 −C 与条目 9 的 −C 数值相同，说明 ∫₀¹ ln ln x dx 与 ∫₀^∞ e^{−x} ln x dx 有相同取值。

## 直接证据与推断的区分

C 在上述条目中的出现是**直接证据**（源文档明写）。而「C 的幂次与对数幂次匹配」这一概括是本文的**推断**，源文档未加说明；该规律在概率论中对应 Γ 与 Digamma 函数在对数矩上的展开，但本手册此处未展开论述。

## 依赖

所有条目均指向 0.1.1 节以获取 C 的定义，该节尚未入库。
