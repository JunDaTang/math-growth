# 《数学指南——实用数学手册》0.9.5 不定积分表（首段，条目 1–180）

## 来源定位

本页是手册 0.9 节积分表中的 0.9.5 小节首段，收录不定积分条目 1–180，正文分为两个子节：

- 0.9.5.1 有理函数的积分（条目 1–98）
- 0.9.5.2 无理函数的积分（条目 99–180）

源文件末尾给出三个续页链接（续2、续3、续4），说明 0.9.5 小节被切分为多个入库单元。已入库的后续单元见 [[sources/10-数学指南实用数学手册--11-095-不定积分表-3--9czogv]]（条目 342–500）与 [[sources/10-数学指南实用数学手册--11-095-不定积分表-4--1xsa9lg]]（条目 501–505）。上级页面为 [[sources/10-数学指南实用数学手册--8-09-积-分-表--aqg9sr]]（0.9 积分表），整体概念见 [[concepts/不定积分表]]。

## 使用注意事项（原文照录）

1. 为了简明起见, 省略掉了积分常数, $\ln f(x)$ 应该理解成 $\ln |f(x)|$ .
2. 如果主函数可以用幂级数表示, 那么不存在这个函数的初等表示.
3. 带有 \* 号的公式表示对复变量的函数也成立.
4. 记号: N 表示自然数集, Z 表示整数集, R 表示实数集.

这四条约定构成整张不定积分表的读法基础：省略常数、对数一律取绝对值、带 \* 号者可解析延拓到复变量、集合记号固定为 N/Z/R。详见 [[concepts/不定积分表的记号与适用范围约定]]。

## 关键定义（原文照录）

```
L = ax + b, a ≠ 0

含两个线性函数：
L1 = ax + b, L2 = cx + d, D = bc − ad, a, c ≠ 0, D ≠ 0
（若 D = 0，则存在 s 使 L2 = s · L1）

含二次函数 Q = ax^2 + bx + c：
Q = ax^2 + bx + c, D = 4ac − b^2, a ≠ 0, D ≠ 0
（D = 0 时 Q 是线性函数的平方；若 Q 在分母中，则积分区间内不含 Q 的零点）

含二次函数 a^2 ± x^2：
Q = a^2 ± x^2
P = arctan(x/a)                                   若取 “+”
  = artanh(x/a) = 1/2 · ln((a + x)/(a − x))       若取 “−”，且 |x| < a
  = arcoth(x/a) = 1/2 · ln((x + a)/(x − a))       若取 “−”，且 |x| > a

含三次函数：
K = a^3 ± x^3
（重号中上符号为 K = a^3 + x^3，下符号为 K = a^3 − x^3）

含平方根 √x 与线性 a^2 ± b^2 x：
L = a^2 ± b^2 x
M = arctan(b√x / a)                               若取 “+”
  = 1/2 · ln((a + b√x)/(a − b√x))                 若取 “−”

含 √(ax+b) 与 √(cx+d)：
L1 = ax + b, L2 = cx + d, D = bc − ad, D ≠ 0
```

## 结构观察

- 有理函数部分（1–98）以 $L$、$L_1 L_2$、$Q = ax^2+bx+c$、$a^2 \pm x^2$、$a^3 \pm x^3$、$a^4 \pm x^4$ 六类分母组织，绝大多数高次或高幂条目写作归约公式，指向前一条更简单的条目（如 9 指向 5，18 之后统一归到 1–6，73 成为三次函数族的公共终点）。参见 [[concepts/积分递推公式]] 与 [[concepts/有理函数的积分]]。
- 无理函数部分（99–180）先按根式形态分组，再按幂次或分母结构展开；111–129 的具体幂次条目在 130–135 被 $L^{\pm n/2}$ 的通用式一并覆盖。参见 [[concepts/无理函数的积分]]。
- 正负两种情形普遍用重号 $\pm/\mp$ 合并书写，并在条目旁注明适用范围（如 $|2ax+b|$ 与 $\sqrt{-D}$ 的大小关系、$|x|$ 与 $a$ 的大小关系）。
- 本段存在若干编号与转写层面的异常：条目 7 未标号、第 40 个积分以 `(40.)` 形式出现、174 与 175 未标号、122–124 的标签与被积函数不匹配等，另有若干疑似转写错误。集中记录见 [[findings/095节首段条目编号缺号与重号]] 与 [[queries/095节首段公式转写疑误汇总]]。
