# 《数学指南——实用数学手册》1.14.7 留数计算与积分计算

## 章节定位

本节是《数学指南——实用数学手册》1.14「复变函数」的第七小节。它给出整个复积分计算的核心工具——**柯西留数定理（1826）**，并把它应用于实积分（有理函数在 $(-\infty,\infty)$ 上的积分）。本节承接 1.14.6 关于洛朗展开与孤立奇点的内容（留数的定义即来自洛朗展开的 $a_{-1}$ 系数），并在 1.14.5「微分式的语言」所建立的积分框架之上给出可操作的计算法则。

节首引语为民间传说中的一句话：

> 数学是避免计算的艺术.

随后作者评论，柯西留数定理「在很多情况下把计算量降到最低」，并把这一技巧归功于柯西：「一定是上帝把留数计算这一漂亮技巧送给柯西去发现的」。

## 柯西留数定理 (1826)

定理原文（式 1.462）：

```text
∫_C f dz = 2πi Σ_{k=1}^{n} Res_{z_k} f.        (1.462)
```

设定：令函数 $f: U \subseteq \mathbb{C} \to \mathbb{C}$ 除有限个极点 $z_1, \cdots, z_n$ 外在开集 $U$ 上全纯。其中 $C$ 是 $U$ 中 $C^{1}$ 型闭若尔当曲线，所有点 $z_1, \cdots, z_n$ 在其内部，而且它是**正定向**的（数学意义上的，参看图 1.176）。

即：只需知道被积函数在积分路径内奇点处的行为，就足以计算整个复积分。

## 例 1：两个极点的围道积分

```text
f(z) = 1/(z − 1) − 2/(z + 1),
Res_{z=1} f = 1,   Res_{z=−1} f = −2.
对围绕 z = ±1 两点的圆周 C：
∫_C f dz = 2πi ( Res_{z=1} f + Res_{z=−1} f ) = −2πi.
```

要点：该结论只针对 $f(z)=\frac{1}{z-1}-\frac{2}{z+1}$ 这一个具体函数，不可外推。

## 计算法则（式 1.463）

如果函数 $f$ 在点 $a$ 处有 $m$ 阶极点，那么

```text
Res_a f = lim_{z→a} (z − a) f(z),                             对于 m = 1   (1.463)

Res_a f = lim_{z→a} F^{(m−1)}(z),                             对于 m ≥ 2,
其中 F(z) := (z − a)^m f(z) / (m − 1)!
```

**易错细节（须原样保留）**：$m \ge 2$ 的一支把常数因子 $1/(m-1)!$ 吸收进了 $F$ 的定义之中，因此对 $F$ 求 $m-1$ 阶导之后**不再**另乘 $1/(m-1)!$。

## 例 2：有理函数的极点阶数判据

有理函数 $\dfrac{g(z)}{h(z)}$（其中 $g(a) \neq 0$）在点 $a$ 处有一个 $m$ 阶极点，当且仅当分母 $h$ 在点 $a$ 处有一个 $m$ 阶零点。

## 典型例子：有理函数在实轴上的积分（式 1.464）

```text
∫_{−∞}^{∞} g(x)/h(x) dx = 2πi Σ_{k=1}^{n} Res_{z_k} (g/h).        (1.464)
```

计算实积分时的假设：

- $g, h$ 是多项式；
- $\deg h \geqslant \deg g + 2$；
- 分母 $h$ 在实轴上没有零点；
- $z_1, \cdots, z_n$ 表示 $h$ 在**上半平面**（复平面中具有正虚部的复数的集合）中的零点。

### 例 3

```text
∫_{−∞}^{∞} dx/(1 + x²) = π.
```

证明：多项式 $h(z) := 1 + z^2$ 分解为 $h(z) = (z - \mathrm{i})(z + \mathrm{i})$，故 $h(z)$ 在上半平面中点 $z = \mathrm{i}$ 处有一个一阶零点。由 (1.463) 得

```text
Res_i [1/(1 + z²)] = lim_{z→i} (z − i)/[(z + i)(z − i)] = 1/(2i).
```

因而由 (1.464)：

```text
∫_{−∞}^{∞} dx/(1 + x²) = 2πi · Res_i [1/(1 + z²)] = π.
```

## (1.464) 的证明概述

令 $f := \dfrac{g}{h}$。图 1.177 中半圆的边界 $A_R + B_R$ 选得足够大，使得上半平面中 $h$ 的所有零点都包含在半圆内部。由 (1.462) 得

```text
∫_{A_R} f dz + ∫_{B_R} f dz = ∫_{A_R + B_R} f dz = 2πi Σ_{k=1}^{n} Res_{z_k} f.    (1.465)
```

此外，有

```text
lim_{R→∞} ∫_{A_R} f dz = ∫_{−∞}^{∞} f(x) dx,
lim_{R→∞} ∫_{B_R} f dz = 0.                                                        (1.466)
```

当 $R \to \infty$ 时，由 (1.465) 即得断言 (1.464)。

极限关系式 (1.466) 可从估计¹⁾

```text
|f(z)| ≤ 常数 / |z²| = 常数 / R²,   对所有满足 |z| = R 的 z
```

得到，而此估计从次数关系式 $\deg h \geqslant \deg g + 2$ 即得；再由周线积分的三角不等式得到

```text
|∫_{B_R} f dz| ≤ (半圆周 B_R 的长度) · sup_{z ∈ B_R} |f(z)|
              ≤ (πR · 常数) / R² → 0,  当 R → ∞ 时。
```

¹⁾ 这里的常数与 $R$ 无关。
