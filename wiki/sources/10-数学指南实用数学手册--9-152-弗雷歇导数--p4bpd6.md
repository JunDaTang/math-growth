# 《数学指南——实用数学手册》1.5.2 弗雷歇导数

## 概述

本节（1.5.2）是《数学指南——实用数学手册》1.5 节「多元实变函数的导数」下的第二个子节，给出**多元导数（弗雷歇导数，简称 F 导数）的现代定义**。其核心是把一维导数概念推广到映射 $f: M \subseteq \mathbb{R}^N \to \mathbb{R}^k$：不再使用差商，而使用**分解式**（余项为高阶无穷小）来定义可微性，其背后的原理表述为「可导意味着线性化」。

本节的主要定理指出：$C^1$ 类函数的 F 导数存在，且恰好由各分量的一阶偏导数组成，即**雅可比矩阵**；当 $N=K$ 时其行列式即**雅可比行列式**。

本节由 [[15节各子节正文尚未入库]] 中列出的子节目录所引出，它的入库推进了该 query；本节还两次引用参考文献 [212]，与已有 query [[13节参考文献212尚未识别]] 相呼应。

## 基本思想与定义

出发点是对原点的一个邻域 $U(0)$ 中所有 $h$ 成立的关系式：

```latex
\boxed{f(p + h) - f(p) = f'(p)h + r(h),}   \tag{1.45}
```

其中 $r(h)$ 满足

```latex
\boxed{\lim_{h \to 0} \frac{r(h)}{|h|} = 0.}   \tag{1.46}
```

隐藏在这个定义背后的现代数学一般原理是

```latex
\mathrm{可导意味着线性化}.   \tag{1.47}
```

设 $M$ 是 $\mathbb{R}^N$ 的子集，包含点 $\boldsymbol{p}$ 的一个邻域。映射为

```latex
\boxed{\boldsymbol{f}: M \subseteq \mathbb{R}^N \to \mathbb{R}^k}   \tag{1.49}
```

形为 $\boldsymbol{y} = \boldsymbol{f}(\boldsymbol{x})$，且列向量为

```latex
\boldsymbol{x} = \begin{pmatrix} x_1 \\ \vdots \\ x_N \end{pmatrix}, \quad
\boldsymbol{f}(\boldsymbol{x}) = \begin{pmatrix} f_1(\boldsymbol{x}) \\ \vdots \\ f_K(\boldsymbol{x}) \end{pmatrix}, \quad
\boldsymbol{y} = \begin{pmatrix} y_1 \\ \vdots \\ y_K \end{pmatrix}, \quad
\boldsymbol{h} = \begin{pmatrix} h_1 \\ \vdots \\ h_N \end{pmatrix}.
```

$h$ 的欧几里得范数定义为

```latex
|\boldsymbol{h}| := \left(\sum_{j=1}^{N} h_j^2\right)^{1/2}.
```

**定义（弗雷歇可微）**：定义 (1.49) 中的映射 $f$ 在点 $\boldsymbol{p}$ 处是弗雷歇可微的，如果存在一个

```latex
\left| K \times N \text{ 阶矩阵 } \boldsymbol{f}'(p), \right|
```

使得满足 (1.46) 的分解式 (1.45) 成立。这时矩阵 $f'(p)$ 称为 $f$ 在点 $p$ 处的**弗雷歇导数**。

**约定**：以后把弗雷歇导数称为 **F 导数**。

## 一维经典特例

设 $J$ 为一个区间，$p \in J$。函数 $f: J \to \mathbb{R}$ 有导数 $f'(p)$，当且仅当满足 (1.46) 的分解式 (1.45) 成立。

**证明（正向）**：如果经典导数

```latex
f'(p) = \lim_{h \to 0} \frac{f(p+h)-f(p)}{h}   \tag{1.48}
```

存在，定义

```latex
\varepsilon(h) := \frac{f(p+h)-f(p)}{h} - f'(p), \quad \text{对于} \quad h \neq 0,
```

且 $\varepsilon(0) := 0$，$r(h) := h\varepsilon(h)$。那么 (1.48) 蕴涵 (1.45) 和 (1.46)。

**证明（反向）**：反之，如果对某一固定的 $f'(p)$，有一个像 (1.45) 一样的分解式，它满足 (1.46)，那么即得 (1.48)。

## 现代观点

经典定义 (1.48) 绝对不方便推广导数概念到多元函数，因为这时 $h$ 是一个属于 $\mathbb{R}^N$ 的向量；**除以这样的向量没有意义**。但是分解公式 (1.45) 总是有意义的。这就是现代微分理论基于 (1.45) 及一般策略 (1.47) 的原因。

## 主要定理

如果 (1.49) 中的函数 $f$ 在点 $p$ 的一个邻域中是 $C^1$ 类的，那么 F 导数 $f'(p)$ 存在，并满足 $f'(p) = (\partial_j f_k(p))$。显然它是 $f$ 的分量 $f_k$ 的一阶偏导数组成的矩阵：

```latex
\boxed{\boldsymbol{f}'(p) = \begin{pmatrix}
\partial_1 f_1(\boldsymbol{p}) & \partial_2 f_1(\boldsymbol{p}) & \dots & \partial_N f_1(\boldsymbol{p}) \\
\partial_1 f_2(\boldsymbol{p}) & \partial_2 f_2(\boldsymbol{p}) & \dots & \partial_N f_2(\boldsymbol{p}) \\
\vdots & \vdots & & \vdots \\
\partial_1 f_K(\boldsymbol{p}) & \partial_2 f_K(\boldsymbol{p}) & \dots & \partial_N f_K(\boldsymbol{p})
\end{pmatrix}.}
```

矩阵 $f'(p)$ 也称作 $f$ 在点 $p$ 处的**雅可比（Jacobi）矩阵**。（书中仅陈述该定理，未给出证明。）

## 雅可比行列式

假设 $N = K$，那么矩阵 $\boldsymbol{f}'(\boldsymbol{p})$ 的行列式 $\det \boldsymbol{f}'(\boldsymbol{p})$ 称为 $\boldsymbol{f}$ 的**雅可比（函数）行列式**，记作

```latex
\boxed{\frac{\partial(f_1, \cdots, f_N)}{\partial(x_1, \cdots, x_N)} = \det \boldsymbol{f}'(\boldsymbol{p}).}
```

## 例 1（K = 1）：实值函数

对于 $N$ 个实变量的实值函数 $f: M \subseteq \mathbb{R}^N \to \mathbb{R}$ 有

```latex
\boldsymbol{f}'(\boldsymbol{p}) = \left(\partial_1 \boldsymbol{f}(\boldsymbol{p}), \dots, \partial_N \boldsymbol{f}(\boldsymbol{p})\right).
```

如果设 $f(\boldsymbol{x}) := x_1 \cos x_2$，那么有 $\partial_1 f(\boldsymbol{x}) = \cos x_2$，$\partial_2 f(\boldsymbol{x}) = -x_1 \sin x_2$，因此

```latex
\boldsymbol{f}'(0, 0) = \left(\partial_1 f(0, 0), \partial_2 f(0, 0)\right) = (1, 0).
```

为了与线性化的思想联系起来，用泰勒展开式

```latex
\cos h_2 = 1 - \frac{(h_2)^2}{2} + \dots .
```

对于 $\boldsymbol{p} = (0,0)^{\mathrm{T}}$，$\boldsymbol{h} = (h_1, h_2)^{\mathrm{T}}$，以及 $h_1, h_2$ 为很小的值，那么有

```latex
\boxed{f(\boldsymbol{p} + \boldsymbol{h}) - f(\boldsymbol{h}) = h_1 + r(\boldsymbol{h}),}
```

其中 $r$ 表示高阶的项。由 $f'(p) = (1,0)$ 也可得

```latex
\boxed{f(\boldsymbol{p} + \boldsymbol{h}) - f(\boldsymbol{p}) = f'(\boldsymbol{p})\boldsymbol{h} + r(\boldsymbol{h}) = (1, 0) \binom{h_1}{h_2} + r(\boldsymbol{h}).}
```

可以把 $f'(p)h = h_1$ 看成 $f(h) = h_1 \cos h_2$ 的线性近似，如果 $h_1, h_2$ 足够小。

## 例 2：二维到二维的映射

令

```latex
\boldsymbol{x} = \binom{x_1}{x_2}, \quad \boldsymbol{f}(\boldsymbol{x}) = \binom{f_1(\boldsymbol{x})}{f_2(\boldsymbol{x})},
```

则有

```latex
\boldsymbol{f}'(\boldsymbol{p}) = \begin{pmatrix}
\partial_1 f_1(\boldsymbol{p}) & \partial_2 f_1(\boldsymbol{p}) \\
\partial_1 f_2(\boldsymbol{p}) & \partial_2 f_2(\boldsymbol{p})
\end{pmatrix}
```

以及

```latex
\frac{\partial(f_1, f_2)}{\partial(x_1, x_2)} = \det \boldsymbol{f}'(\boldsymbol{p}) = \begin{vmatrix}
\partial_1 f_1(\boldsymbol{p}) & \partial_2 f_1(\boldsymbol{p}) \\
\partial_1 f_2(\boldsymbol{p}) & \partial_2 f_2(\boldsymbol{p})
\end{vmatrix},
```

因此

```latex
\det \boldsymbol{f}'(\boldsymbol{p}) = \partial_1 f_1(\boldsymbol{p}) \partial_2 f_2(\boldsymbol{p}) - \partial_2 f_1(\boldsymbol{p}) \cdot \partial_1 f_2(\boldsymbol{p}).
```

在 $f_1(\boldsymbol{x}) = ax_1 + bx_2$，$f_2(\boldsymbol{x}) = cx_1 + dx_2$ 的特殊情形，我们有

```latex
\boldsymbol{f}(\boldsymbol{x}) = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \cdot \binom{x_1}{x_2}.
```

以及

```latex
\boldsymbol{f}(\boldsymbol{p}) = \begin{pmatrix} a & b \\ c & d \end{pmatrix}, \quad \det \boldsymbol{f}'(\boldsymbol{p}) = \begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc.
```

和预期的一样，线性映射的线性化就是映射本身，因此 $f'(p)x = f(x)$。

## 脚注

- **脚注 1)（首次出现）**：这个观点可以立即推广到无穷维希尔伯特空间和巴拿赫空间的算子上，它还是泛函分析中解决非线性微分和积分方程的重要工具（参看 [212]）。
- **脚注 1)（第二次出现）**：为了能够把 (1.45) 写成一个矩阵方程的形式，使用了列向量；2.1 节介绍了矩阵和行列式。利用转置矩阵，也可以记作 $\boldsymbol{x} = (x_1, \cdots, x_N)^{\mathrm{T}}$ 及 $\boldsymbol{f}(\boldsymbol{x}) = (f_1(\boldsymbol{x}), \cdots, f_K(\boldsymbol{x}))^{\mathrm{T}}$。
- **脚注 2)**：这个导数的符号是由法国数学家 R. M. 弗雷歇（René Maurice Fréchet, 1878—1956）于 20 世纪初引入的。弗雷歇与希尔伯特是现代解析思想之父（见 [212]），弗雷歇还对度量空间理论作出了贡献。
