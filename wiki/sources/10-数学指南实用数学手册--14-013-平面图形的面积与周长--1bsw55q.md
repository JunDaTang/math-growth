# 《数学指南——实用数学手册》0.1.3 平面图形的面积与周长

本页是 [[数学指南-实用数学手册]] 0.1 节（初等数学中的基本公式）第 3 子节的源文档摘要。该节属**公式汇编型**内容，以表 0.4 汇总最重要平面图形的面积 $A$ 与周长 $C$，随后单列椭圆周长的椭圆积分表示、正 $n$ 边形的几何关系，以及正 $n$ 边形尺规可作图的高斯定理。文中三角函数 $\sin\alpha$、$\cos\alpha$ 的含义见 0.2.8。

## 表 0.4 多边形的面积与周长（逐字保留）

| 图形 | 面积 A | 周长 C |
|---|---|---|
| 正方形 | $A = a^{2}$（a 为一边的长度） | $C = 4a$ |
| 矩形 | $A = ab$（a,b 为边长） | $C = 2a + 2b$ |
| 平行四边形 | $A = ah = ab\sin\gamma$（a 为底长，b 为边长，h 为高） | $C = 2a + 2b$ |
| 菱形（等边平行四边形） | $A = a^{2}\sin\gamma$ | $C = 4a$ |
| 梯形（有两个边相平行的四边形） | $A = \frac{1}{2}(a + b)h$（a,b 为两平行边的长度，h 为高） | $C = a + b + c + d$ |
| 三角形 | $A = \frac{1}{2}ah = \frac{1}{2}ab\sin\gamma$（a 为底长，b,c 为其他两边的长，h 为高，$s := C/2$）；面积的海伦公式为 $A = \sqrt{s(s - a)(s - b)(s - c)}$ | $C = a + b + c$ |
| 直角三角形 | $A = \frac{1}{2}ab$；边角关系：$a = c\sin\alpha,\ b = c\cos\alpha,\ a = b\tan\alpha$（c 为斜边，a 为对边，b 为邻边）；毕达哥拉斯定理：$a^{2} + b^{2} = c^{2}$；高的欧几里得关系：$h^{2} = pq$ | $C = a + b + c$ |
| 等边三角形 | $A = \frac{\sqrt{3}}{4}a^{2}$ | $C = 3a$ |
| 圆 | $A = \pi r^{2}$（r 为半径） | $C = 2\pi r$ |
| 扇形 | $A = \frac{1}{2}\alpha r^{2}$ | $C = L + 2r,\ L = \alpha r$ |
| 圆环 | $A = \pi(r^{2} - \rho^{2})$（r 为外圆的半径，$\rho$ 为内圆的半径） | $C = 2\pi(r + \rho)$ |
| 抛物扇形 | $A = \frac{1}{3}xy$ | （原表未给出） |
| 双曲扇形 | $A = \frac{1}{2}\left(xy - ab\cdot\operatorname{arcosh}\frac{x}{a}\right)$（$b = a\tan\alpha$） | （原表未给出） |
| 椭圆扇形 | $A = \frac{1}{2}ab\cdot\operatorname{arcosh}\frac{x}{a}$ | （原表未给出） |
| 椭圆 | $A = \pi ab$（a,b 为轴长，$b < a$，$\varepsilon$ 为数值离心率） | $C = 4aE(\varepsilon)$（参看 (0.5)） |

原表脚注（保留原文表述）：

1) 直角三角形中直角的对边称为斜边，其他两条边称为直角边或侧边。
2) 即勾股定理。人们认为萨摩斯岛的毕达哥拉斯（Pythagoras，公元前 500 年）是古希腊最著名的学派（毕达哥拉斯学派）的创立者。然而早在距那时大约 1000 年之前，汉谟拉比（Hammurapi，公元前 1728—前 1686）国王统治下的巴比伦人就知道了毕达哥拉斯定理。
3) 0.1.7 中将考虑抛物线、双曲线和椭圆；0.2.12 中介绍函数 arcosh。

表中"椭圆扇形"的面积同样写作 $\operatorname{arcosh}$ 形式，见下文"存疑与待核验"。

## 椭圆周长与椭圆积分

椭圆的数值离心率定义为

$$\varepsilon = \sqrt{1 - \frac{b^{2}}{a^{2}}}.$$

几何解释：椭圆焦点到椭圆中心的距离为 $\varepsilon a$。对圆而言 $\varepsilon = 0$；椭圆越扁，数值离心率 $\varepsilon$ 越大。

文中指出：早在 18 世纪，人们就已经注意到**不可能用初等方法计算出椭圆的周长**。椭圆周长公式为 $C = 4aE(\varepsilon)$，其中

$$E(\varepsilon) := \int_{0}^{\pi/2}\sqrt{1 - \varepsilon^{2}\sin^{2}\varphi}\,\mathrm{d}\varphi \tag{0.5}$$

表示 [[勒让德第二类完全椭圆积分]]。本书给出该积分的表值（参看 0.5.4）。对椭圆总有 $0 \leqslant \varepsilon < 1$。作为近似，有级数

$$E(\varepsilon) = 1 - \left(\frac{1}{2}\right)^{2}\varepsilon^{2} - \left(\frac{1\cdot3}{2\cdot4}\right)\frac{\varepsilon^{4}}{3} - \left(\frac{1\cdot3\cdot5}{2\cdot4\cdot6}\right)\frac{\varepsilon^{6}}{5} - \dots = 1 - \frac{\varepsilon^{2}}{4} - \frac{3\varepsilon^{4}}{64} - \frac{5\varepsilon^{6}}{256} - \dots$$

19 世纪创立了椭圆积分的一般理论（参看 1.14.19）。

## 正 n 边形的几何关系

一个 n 边形称为正 n 边形，若它的所有边和角都相等（图 0.7，示例 n = 3, 4, 5, 6）。设正 n 边形的中心到各个角的距离为 $r$：

- 中心角：$\varphi = \frac{2\pi}{n}$
- 补角：$\alpha = \pi - \varphi$
- 边长：$a = 2r\sin\frac{\varphi}{2}$
- 周长：$C = na$
- 面积：$A = \frac{1}{2}nr^{2}\sin\varphi$

## 高斯定理（尺规可作图）

一个 $n$（$n \leqslant 20$）边形可以用尺规作出，当且仅当

$$n = 3, 4, 5, 6, 8, 10, 12, 15, 16, 17, 20.$$

特别地，当 $n = 7, 9, 11, 13, 14, 18, 19$ 时，不可能由尺规作出正 n 边形。该结果是伽罗瓦理论的一个推论，2.6.6 中将更详细地讨论。详见 [[正多边形尺规作图]]。

本节全部内容为教科书级既定数学结果，属高置信度，但**并非经验证据**——其"证据"即公式本身，被视为数学事实。椭圆扇形面积公式存在内部疑点，见下。

## 存疑与待核验

- **椭圆扇形面积公式存疑**：原表将"椭圆扇形"面积写作 $A = \frac{1}{2}ab\cdot\operatorname{arcosh}\frac{x}{a}$，与"双曲扇形"共用 $\operatorname{arcosh}$。椭圆（闭曲线）扇形面积通常涉及 $\arcsin/\arccos$ 或参数角，此处沿用 $\operatorname{arcosh}$ 较可疑，可能是排版/OCR 问题或特定参数化约定。**本文不在 wiki 中将其作为确证结论传播**，建议核对原书。
- 原表椭圆扇形行的 `(参看(0.5))` 及椭圆行的 `(参看(0.5))` 括号不闭合，属排版细节，不影响语义。
- **归属限定（须保留）**：毕达哥拉斯定理的命名与巴比伦人的更早认知并存，源文已显式指出汉谟拉比时期巴比伦人早约 1000 年已知该定理，wiki 表述时须保留此历史限定，不记为某一方独家贡献。
