# 《数学指南——实用数学手册》6.4.3 泊松过程

## 本节定位

本节是 6.4 节「随机过程」下的一个小节，在 [[concepts/随机过程]] 框架内引入 **泊松过程**：一种用于描述「在给定的较短时间间隔中很少发生的事件」的计数过程。本节隶属的父级来源为 [[sources/10-数学指南实用数学手册--7-64-随机过程--1pfaczw]]。

本节为手册式陈述：直接给出三条基本假定与最终分布公式，**未给出推导过程**。

## 基本模型

考虑一个事件 $\mathcal{E}$（原文示例为「电话交换台收到电话呼叫」），并定义：

```text
P_n(t, s) := 在时间段 [t, s] 中恰好有 n 个事件 E 发生。
```

## 三条基本假定（关于泊松过程本身）

```text
(i)   过程是时齐的，即 P_n(t, s) 只依赖于时间差 s − t，而不依赖于起始时刻 t。
(ii)  当 s − t → 0 时，P_1(t, s) = μ(s − t) + o(s − t)。
(iii) 当 s − t → 0 时，对于所有的 n = 2, 3, …，都有 P_n(t, s) = o(s − t)。
```

## 结果：事件数的泊松分布

于是有

$$
P_n(t,s) = \mathrm{e}^{-\mu(s-t)} \frac{\mu^{n}(s-t)^{n}}{n!}, \quad n = 0, 1, 2, \dots
$$

对于一个给定的固定区间 $[t, s]$，这是一个泊松分布（参见 [[concepts/泊松分布]]）。

## 计数的期望与标准差

若用 $X_{s-t}$ 表示在时间区间 $[t, s]$ 中事件 $\mathcal{E}$ 发生的次数，则对于期望（均值）和标准差，有

$$
\overline{X}_{s-t} = \mu (s-t), \quad \Delta X_{s-t} = \sqrt{\mu (s-t)}.
$$

注意：这两个量刻画的是**固定区间内的计数变量** $X_{s-t}$，而非过程本身（参见 [[concepts/期望值]]、[[concepts/方差与标准差]]）。

## 与现有 wiki 的连接

- 泊松族来源：与 [[concepts/泊松分布]]、[[concepts/泊松逼近定理]] 同族。但需注意 [[concepts/泊松逼近定理]] 讲的是二项分布的极限逼近，本节的泊松分布来自连续时间过程的三条假定，二者来源不同，结论不可互移。
- 记号一致性：本节沿用 6.2.2 节的均值记号 $\overline{X}$ 与标准差记号 $\Delta X$；与 6.2.5 节的 $\mathrm{e}^{-\lambda}\lambda^{n}/n!$ 形式一致，此处参数为 $\mu(s-t)$，相当于 $\lambda$。
- 姐妹章节：[[concepts/马尔可夫链]]、[[concepts/转移概率]]、[[concepts/查普曼-科尔莫戈罗夫方程]] 同属 6.4 节的过程论内容；泊松过程在标准理论中是连续时间马尔可夫过程的特例，但**本节原文并未提及马尔可夫性**，该联系属外部知识。

## 待澄清之处

1. 原文以「结果 于是，有……」直接给出分布公式，**省略了由 (i)(ii)(iii) 导出泊松分布的推导**。
2. 参数 $\mu$ 的物理含义（单位时间内的平均发生率）**未在本节明确定义**，仅隐含于假定 (ii)。
3. 三条假定中未显式列出「有限时间区间上的独立增量性/可加性」这一通常的关键假定。
4. 记号层面：$X_{s-t}$ 用下标表示「$s-t$」，而 $P_n(t,s)$ 用两个参数表示区间，两种参数化在同一节中并存。
