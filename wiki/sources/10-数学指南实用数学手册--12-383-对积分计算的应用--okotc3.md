# 《数学指南——实用数学手册》3.8.3 对积分计算的应用

本页是《数学指南——实用数学手册》第 3.8 节「代数几何学」下的第 3.8.3 小节正文摘要。该小节把代数曲线的有理参数化问题直接用于一类积分的计算，给出「亏格为零 ⇔ 有理表示存在」的经验判据，并通过圆（亏格 0）与三次曲线（亏格 1）两个例子说明有理替换的适用边界，以及椭圆积分为何必须借助双周期椭圆函数求解。

本文件是 [[38节正文是否待下级小节补全]] 这一悬置问题的直接证据：3.8 节至少在本下级小节存在实质正文。3.8 节的父级来源页为 [[10-数学指南实用数学手册--8-38-代数几何学--1ojbsmq]]。

## 核心归约框架

考虑积分

```latex
J = \int R(x, w)\,\mathrm{d}x \tag{3.54}
```

其中 $R$ 是变量 $x$ 与 $w$ 的有理函数，$w$ 是 $x$ 的代数函数，即点偶 $(x, w)$ 落在平面代数曲线

```latex
C: p(x, w) = 0
```

之上。若曲线 $C$ 给出参数表示

```latex
x = x(t), \quad w = w(t) \tag{3.55}
```

则通过替换，积分 (3.54) 化为

```latex
J = \int R(x(t), w(t))\, x'(t)\,\mathrm{d}t \tag{3.56}
```

形如 (3.56) 的含有理函数之积分可借助部分分式分解计算。

## 判据（经验法则）

源文把下述断言标注为**经验法则**（脚注 1)）：

> 曲线 $C$ 有如在 (3.55) 中那样的有理表示当且仅当这条曲线的亏格为零。

脚注进一步指出：准确的答案由 3.8.5 中描述的庞加莱定理给出，为此需要曲线 $C$ 的射影形式。该断言的主体是「曲线 $C$」这一几何对象，与具体积分形式无关。详见 [[亏格判据有理表示等价]]。

历史背景：大约在 1700 年，早在牛顿和莱布尼茨的时代，人们就已在寻找新的有理替换，把形如 (3.54) 的积分变换为具有理被积函数的形如 (3.56) 的积分；此后一段时间，「对哪些积分确实存在有理替换」成为关键论点。

## 例 1：圆（亏格为零）

积分

```latex
J = \int R(x, \sqrt{1 - x^{2}})\,\mathrm{d}x \tag{3.57}
```

可写为 $\int R(x, w)\,\mathrm{d}x$ 的形式，其中 $C: x^{2} + w^{2} = 1$。这是一个圆，其亏格为零。圆的一个有理参数化为

```latex
x = \frac{t^{2} - 1}{t^{2} + 1}, \quad w = \frac{2t}{t^{2} + 1}
```

令

```latex
t = \tan\frac{\varphi}{2} \tag{3.58}
```

则有

```latex
x = \cos\varphi, \quad y = \sin\varphi \tag{3.59}
```

这便解释了替换 (3.58) 对形如 $\int R(\cos\varphi, \sin\varphi)\,\mathrm{d}\varphi$ 的积分是「万能」的原因。详见 [[圆的有理参数化与万能替换]] 与 [[万能替换]]。

（注意：式 (3.59) 在源文中把第二分量写作 $y$，而前文参数化与积分均使用 $w$，记号疑似讹误，见 [[383节式359的y与w记号疑似讹误]]。）

## 例 2：无奇点三次曲线（亏格为 1）

设 $-\infty < e_{1} < e_{2},\, e_{3} < \infty$。积分

```latex
\int R\left(x, \sqrt{(x - e_{1})(x - e_{2})(x - e_{3})}\right)\,\mathrm{d}x \tag{3.60}
```

可写为 $\int R(x, w)\,\mathrm{d}x$ 的形式，其中

```latex
w^{2} = (x - e_{1})(x - e_{2})(x - e_{3})
```

这是个没有奇点的三次曲线，因此它的亏格为 1。这就是椭圆积分不能由有理替换解决的深层次原因。该事实在 18 世纪的过程中被逐步意识到，从而导致了 19 世纪中椭圆函数理论的发展。

积分 (3.60) 的计算需要替换

```latex
x = \mathcal{G}(t), \quad w = \mathcal{G}'(t)
```

即以双周期（椭圆）魏尔斯特拉斯 G 函数解决（参看 1.14.17.3）。详见 [[三次曲线亏格1与椭圆积分不可有理化]]、[[椭圆积分]]、[[椭圆函数]]、[[魏尔斯特拉斯G函数]]。

## 对照小结

- 积分 (3.57)（圆，亏格 0）可用 (3.58) 替换，以（单）周期三角函数解决。
- 积分 (3.60)（无奇点三次曲线，亏格 1）需以双周期（椭圆）魏尔斯特拉斯 G 函数解决。

二者的统一解释框架是「亏格」：亏格为零则存在有理参数化，亏格为 1 则不存有理参数化。
