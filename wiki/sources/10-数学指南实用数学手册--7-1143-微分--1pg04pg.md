# 《数学指南——实用数学手册》1.14.3 微分

## 章节定位

本节是《数学指南——实用数学手册》第 1.14 章「[[复变函数]]」的第三小节，承接同章的 1.14.1「基本思想」与 1.14.2「[[复数列]]」。全节主题为**复可微性（复导数）及其与实偏微分方程的联系**：先给出复可微与复导数的定义，再给出柯西（1814）与黎曼（1851）的主定理，即复可微等价于分量函数弗雷歇可微且成立柯西-黎曼微分方程；随后陈述全纯函数定义、微分法则与幂级数逐项求导；最后引入庞加莱微分算子 $\partial z,\ \partial \bar z$，把柯西-黎曼方程改写成 $\partial \bar z f(z_0) = 0$，并给出一阶微分形式的分解 $\mathrm{d}f = \partial z f\, \mathrm{d}z + \partial \bar z f\, \mathrm{d}\bar z$。

全节篇幅短、公式密集，属于工具性定义与定理汇编，其中反函数求导法则明确留待 1.14.10 讨论。

## 定义：复可微与复导数

源文定义（逐字保留）：给定函数 $f: U \subseteq \mathbb{C} \to \mathbb{C}$，它定义在点 $z_0$ 的一个邻域 $U$ 中，如果极限

```latex
f'(z_0) := \lim_{h \to 0} \frac{f(z_0 + h) - f(z_0)}{h}
```

存在，则称 $f$ 在 $z_0$ 点处是**复可微的**。复数 $f'(z_0)$ 称为 $f$ 在点 $z_0$ 处的（复）**导数**。令

```latex
\frac{\mathrm{d} f(z_0)}{\mathrm{d} z} := f'(z_0).
```

例 1：对 $f(z) := z$，有 $f'(z) = 1$。

## 柯西(1814) 和黎曼(1851) 的主定理

令 $z = x + \mathrm{i}y$，其中 $x, y \in \mathbb{R}$，并令

```latex
f(z) = u(x, y) + \mathrm{i} v(x, y),
```

即 $u(x,y)$（相应地 $v(x,y)$）是 $f(z)$ 的实部（相应地虚部）。

源文主定理（逐字保留）：复值函数 $f: U \subseteq \mathbb{C} \to \mathbb{C}$ 在 $z_0 \in \mathbb{C}$ 处复可微，**当且仅当** $u$ 与 $v$ 在点 $(x_0, y_0)$ 处[[弗雷歇可微]]，并且柯西-黎曼微分方程

```latex
u_x = v_y, \quad u_y = -v_x \tag{1.453}
```

在点 $(x_0, y_0)$ 处成立。这时有

```latex
f'(z_0) = u_x(x_0, y_0) + \mathrm{i} v_x(x_0, y_0).
```

源文未给出该定理的证明，属手册式引用陈述。详见 [[柯西-黎曼微分方程]]。

## 全纯函数

设开集 $U \subseteq \mathbb{C}$。函数 $f: U \subseteq \mathbb{C} \to \mathbb{C}$ 被称为在 $U$ 上是**全纯的**，如果 $f$ 在 $U$ 的每个点 $z$ 处都是复可微的。详见 [[全纯函数]]。

## 微分法则

与实值可微函数的法则一样，求和、求积、求商的法则及链式法则对复导数都成立（源文引 0.8.2）。反函数的求导法则在后面的 1.14.10 中讨论。上述引用的小节在源文中未展开，见 [[1143节引用的082与1103与11410未入库]]。

## 幂级数

函数

```latex
f(z) = a_0 + a_1(z - a) + a_2(z - a)^2 + a_3(z - a)^3 + \dots
```

在[[收敛圆|收敛域]]内部的每个点处都可微（参看 1.10.3）。可以通过对幂级数逐项求导得到函数的导数，即

```latex
f'(z) = a_1 + 2a_2(z - a) + 3a_3(z - a)^2 + \dots .
```

详见 [[幂级数逐项求导]]。

### 例 2

令 $f(z) := \mathrm{e}^{z}$。由关系式

```latex
f(z) = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \dots
```

即得

```latex
f'(z) = 1 + z + \frac{z^2}{2!} + \dots = \mathrm{e}^{z}, \quad \text{对所有} z \in \mathbb{C}.
```

## 导数表

源文陈述：「对所有可以展成幂级数的函数，实导数与复导数一致。重要的初等函数的导数表可见 0.8.1。」该断言的适用范围（可展成幂级数的函数类）源文未作界定，见 [[1143节实导数与复导数一致断言的适用范围未界定]]。

## 庞加莱微分算子 $\partial z$ 与 $\partial \bar z$

源文定义（逐字保留）：如果令

```latex
\partial z := \frac{1}{2}\left(\frac{\partial}{\partial x} - \mathrm{i}\frac{\partial}{\partial y}\right)
\quad \text{和} \quad
\partial \bar z := \frac{1}{2}\left(\frac{\partial}{\partial x} + \mathrm{i}\frac{\partial}{\partial y}\right),
```

那么柯西-黎曼微分方程 (1.453) 可以写成如下优美的形式：

```latex
\partial \bar z\, f(z_0) = 0.
```

详见 [[庞加莱微分算子]]。

## 微分形式分解

令 $f: U \subseteq \mathbb{C} \to \mathbb{C}$ 是任一复值函数，令 $z = x + \mathrm{i}y$，$\bar z = x - \mathrm{i}y$ 及

```latex
\mathrm{d}z := \mathrm{d}x + \mathrm{i}\,\mathrm{d}y, \quad \mathrm{d}\bar z := \mathrm{d}x - \mathrm{i}\,\mathrm{d}y.
```

如果把 $f(z)$ 记为 $f(x,y)$，那么有

```latex
\mathrm{d}f = u_x\,\mathrm{d}x + u_y\,\mathrm{d}y + \mathrm{i}(v_x\,\mathrm{d}x + v_y\,\mathrm{d}y).
```

由此即得

```latex
\mathrm{d}f = \partial z f\; \mathrm{d}z + \partial \bar z f\; \mathrm{d}\bar z.
```

如果 $f$ 在点 $z_0$ 处复可微，那么有

```latex
\mathrm{d}f = \partial z f\; \mathrm{d}z.
```
