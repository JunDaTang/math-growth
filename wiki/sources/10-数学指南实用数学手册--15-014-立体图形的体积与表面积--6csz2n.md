# 《数学指南——实用数学手册》0.1.4 立体图形的体积与表面积

本页是《数学指南——实用数学手册》0.1 节「初等数学中的基本公式」下第 0.1.4 小节的摘录，内容为**表 0.5 某些立体图形的体积与表面积**，以及用于椭球表面积的**勒让德公式 (L)**。原文性质为公式汇编，不含推导；表中每条公式互不依赖，引用时须逐条对应各自图形。

## 表 0.5 某些立体图形的体积与表面积

| 立体图形 | 体积 V | 表面积 O / 侧面积 M |
|---|---|---|
| 立方体 | $V = a^{3}$（a 为边长） | $O = 6a^{2}$ |
| 长方体 | $V = abc$（a,b,c 为边长） | $O = 2(ab + bc + ca)$ |
| 球 | $V = \frac{4}{3}\pi r^{3}$（r 为半径，原书加框） | $O = 4\pi r^{2}$（原书加框） |
| 棱柱 | $V = Gh$（G 为底面积，h 为高，原书加框） | — |
| 圆柱 | $V = \pi r^{2}h$（r 为半径，h 为高） | $O = M + 2\pi r^{2},\ M = 2\pi rh$ |
| 立体圆环 | $V = \pi h(r^{2} - \rho^{2})$（r 为外半径，$\rho$ 为内半径，h 为高） | — |
| 棱锥 | $V = \frac{1}{3}Gh$（G 为底面积，h 为高，原书加框） | — |
| 圆锥 | $V = \frac{1}{3}\pi r^{2}h$（r 为半径，h 为高，s 为母线长） | $O = M + \pi r^{2},\ M = \pi rs$ |
| 棱台 | $V = \frac{h}{3}(G + \sqrt{Gg} + g)$（G 为下底面积，g 为上底面积） | — |
| 圆台 | $V = \frac{\pi h}{3}(r^{2} + r\rho + \rho^{2})$（$r, \rho$ 为半径，$h$ 为高，$s$ 为母线长） | $O = M + \pi(r^{2} + \rho^{2}),\ M = \pi s(r + \rho)$ |
| 方尖形 | $V = \frac{1}{6}\left(ab + (a + c)(b + d) + cd\right)$（$a, b, c, d$ 为边长） | — |
| 楔形（侧面为等边三角形） | $V = \frac{\pi}{6}bh(2a + c)$（$a, b$ 为底边长，$c$ 为上边，$h$ 为高） | — |
| （由纬线所界定的）球冠 | $V = \frac{\pi}{3}h^{2}(3r - h)$（$r$ 为球的半径，$h$ 为高） | $O = 2\pi rh$（顶部） |
| （由两条纬线所界定的）球台 | $V = \frac{\pi h}{6}(3R^{2} + 3\rho^{2} + h^{2})$（$r$ 为球的半径，$h$ 为高，$R$ 和 $\rho$ 为两条纬线圈的半径） | $O = 2\pi rh$（中部） |
| 圆环 | $V = 2\pi r^{2}\rho$（$r$ 为圆环的半径，$\rho$ 为截面半径） | $O = 4\pi^{2}r\rho$ |
| 桶形（圆形截面） | $V = 0.0873h(2D + 2r)^{2}$（$D$ 为直径，$r$ 为顶的半径，$h$ 为高；这是一个近似公式） | — |
| 椭球 | $V = \frac{4}{3}\pi abc$（$a, b, c$ 为轴长，$c < b < a$） | 对于 O，见勒让德公式 (L) |

原文说明：表 0.5 中列出了最重要的三维图形。表中「球」「棱柱」「棱锥」的条目在原书排版中加框强调。

## 勒让德椭球表面积公式

原文陈述：用于计算椭球表面积的椭圆积分的含义——**我们不可能用初等方法计算出椭球的表面积**，还需要用到椭圆积分。为此，有勒让德公式

$$
\boxed{O = 2\pi c^{2} + \frac{2\pi b}{\sqrt{a^{2} - c^{2}}}\left(c^{2}F(k,\varphi) + (a^{2} - c^{2})E(k,\varphi)\right)} \tag{L}
$$

其中

$$
k = \frac{a}{b}\frac{\sqrt{b^{2} - c^{2}}}{\sqrt{a^{2} - c^{2}}}, \qquad \varphi = \arcsin\frac{\sqrt{a^{2} - c^{2}}}{a}.
$$

原文指出：椭圆积分公式 $E(k,\varphi)$ 和 $F(k,\varphi)$ 见 0.5.4 节。

- 本页是 0.1 节几何公式体系的立体部分，与 [[初等几何公式]] 所承载的平面公式互为补充。
- 与 [[正多面体]]、[[n维球的体积与表面积]] 共同构成「空间度量」知识簇。
- 椭球表面积公式把 [[勒让德]] 与椭圆积分工具（[[勒让德第二类完全椭圆积分]]）联系起来；它与 [[椭圆周长的椭圆积分]] 共享同一类不完全椭圆积分 $E$。

## 待核对事项

表 0.5 中有若干条目的字面记法可疑（如圆环体积的 $\pi$ 次幂、桶形公式系数、方尖形体积缺高 $h$、楔形体积中出现 $\pi$、球冠与球台表面积均记为 $O = 2\pi rh$ 但变量含义不同）。这些都属同一图形内部的记法问题，本页照录原文，疑点登记在 [[立体图形公式表中的记法疑问]]。
