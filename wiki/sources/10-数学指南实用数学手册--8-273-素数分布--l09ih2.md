# 《数学指南——实用数学手册》2.7.3 素数分布

## 来源定位

本页是《数学指南——实用数学手册》2.7 节「数论」下第 2.7.3 小节的入库摘要。该小节以「揭示素数分布的规律」为主线，串联起间隙定理、狄利克雷算术级数定理、素数定理、黎曼 ζ 函数、黎曼猜想、ζ 函数与统计物理和重正规化的联系、狄利克雷局部化原理以及孪生素数猜想，是全书中最集中处理解析数论材料的段落之一。既有页面 [[素数分布]] 与 [[黎曼猜想]] 提供上位背景，本页补充其细节、人物与公式。

## 引文

小节以 B. 黎曼 1859 年的一段自述开篇：黎曼致谢柏林科学院授予其通讯员身份，使他得以提交「关于素数频率」的研究结果，并称这是高斯与狄利克雷长期感兴趣的问题（见 [[柏林科学院]]）。

## 间隙定理

数 $n! + 2, n! + 3, \cdots, n! + n (n = 2, 3, 4, \cdots)$ 不是素数，并且当 n 增长时非素数集合（素数集合中的间隙）越来越长。详见 [[间隙定理]]。

## 狄利克雷算术级数定理（1837）

若 a 与 d 是两个互素的自然数，则算术级数（原文公式 (2.70)）

```text
a, a + d, a + 2d, a + 3d, …
```

含有无穷多个素数。例 1 取 $a = 3$、$d = 5$，得到序列 $3, 8, 13, 18, 23, \dots$，其中含无穷多个素数。详见 [[狄利克雷算术级数定理]]。

推论（原文公式 (P)）：对任意实数 $x \geqslant 2$，令 $P_{a,d}(x)$ 为 (2.70) 中所有满足 $p \leqslant x$ 的素数 p 的集合，则

```text
∑_{p ∈ P_{a,d}(x)} (ln p)/p = (1/φ(d))·ln x + O(1),  x → +∞
```

其中 φ 为 [[欧拉φ函数]]（参看 2.7.2），余项 O(1) 与 a 无关；例 1 中 $\varphi(d) = 4$。该公式说明所有具有常数公差 d 的数列含有「渐近」相等个数且与 a 无关的素数；特别地 a = 2、d = 1 时数列含有所有素数，此时 $\varphi(d) = 1$。

## 解析数论

在证明上述定理时，狄利克雷把傅里叶级数、狄利克雷级数及 L 级数等全新方法引入数论，它们在代数数论中同样是基本的，由此开创了新的数学分支——[[解析数论]]。

## 2.7.3.1 素数定理

素数分布函数定义为不超过 x 的素数个数，见 [[素数分布函数]]。勒让德定理（1798）给出

```text
lim_{x→∞} π(x)/x = 0
```

说明素数相比自然数相当稀少。素数基本定理（即通常所称 [[素数定理]]）为

```text
π(x) ~ x/ln x ~ li x,  x → +∞
```

文中称这是「数学中最著名的渐近公式」；对数积分 li x 的定义见 [[对数积分]]。表 2.5 比较了 $\pi(x)$ 与 li x：

| x | π(x) | li x |
|---|---|---|
| $10^3$ | 168 | 178 |
| $10^6$ | 78498 | 78628 |
| $10^9$ | 50847534 | 50849235 |

发现史方面：欧拉还相信素数完全不规则地分布；π(x) 的渐近分布由 33 岁的勒让德于 1785 年、14 岁的高斯于 1792 年通过深入研究对数表独立发现；严格证明由 30 岁的 J. 阿达马与 30 岁的 C. J. 德拉瓦莱普桑于 1896 年独立给出（见 [[concepts/素数定理]]）。若 $p_n$ 为第 n 个素数，则有 $p_n \sim n \ln n$。

误差估计：存在正常数 A、B，使对所有 $x \geqslant 2$

```text
π(x) = (x/ln x)·(1 + r(x)),  A/ln x ≤ r(x) ≤ B/ln x
```

黎曼陈述：若 [[黎曼猜想]] (2.72) 成立，则

```text
|π(x) − li x| ≤ 常数 · √x · ln x,  对所有 x ≥ 2
```

## 2.7.3.2 著名的黎曼猜想

1859 年黎曼提出：ζ 函数的所有非平凡零点都在复平面中的临界线 $\mathrm{Re}\,s = 1/2$ 上（原文公式 (2.72)）。相关表述要素见 [[临界线与平凡零点]]，完整讨论见 [[黎曼猜想]]。

哈代定理（1914）：临界线 $\mathrm{Re}\,s = 1/2$ 上有黎曼 ζ 函数的无穷多个零点。文中还提到，现已有一系列彼此等价于黎曼猜想的命题，借助超级计算机的大量方案与试验从未给出猜想不成立的迹象，已计算出临界线上数十亿个零点；精密的渐近估计表明 ζ 函数全部零点中至少有 1/3 在临界线上。

## 2.7.3.3 黎曼 ζ 函数与统计物理学

统计物理学借助配分函数

```text
L = ∑_{n=1}^{∞} E^{−E_n/kT}          (2.73)
```

从固定个数粒子的能量状态 $E_1, E_2, \dots$ 得出统计系统的所有物理性质，其中 T 为绝对温度、k 为波尔兹曼常量（见 [[玻尔兹曼]]）。若令 $E_n := k t s \cdot \ln n$，则得到

```text
L = ζ(s)
```

即黎曼 ζ 函数是一个特殊的配分函数，说明与 ζ 函数类似类型的函数对处理统计物理模型是重要的。详见 [[concepts/ζ函数]]；配分函数的一般背景见 [[配分函数与分拆数]]。

## 2.7.3.4 黎曼 ζ 函数与物理学中的重正规化

发散表达式常在统计物理学与量子场论中出现，物理学家发展出范围广阔的 [[重正规化]] 方法使发散表达式获得意义；在量子电动力学和标准模型中，尽管数学推理有含糊性，它们与实验证据在现象上符合得很好。

小节的算例：$n \times n$ 单位方阵 $I_n$ 的迹为 $\operatorname{tr} I_n = 1 + 1 + \dots + 1 = n$；对无穷单位方阵 I 有 $\operatorname{tr} I = \lim_{n\to\infty} n = \infty$。把 (2.74) $\zeta(s) = \sum_{n=1}^{\infty} 1/n^s$ 的右边按黎曼定理延拓后的值重新定义，得

```text
tr I_ren := ζ(0) = −1/2
```

即正数的「无穷和」$1 + 1 + 1 + \cdots$ 经重正规化后给出负数。详见 [[concepts/单位矩阵]] 与 [[黎曼ζ函数]]。

## 2.7.3.5 素数 mod m 的狄利克雷局部化原理

设 m 为正自然数。为证明其素数分布基本定理，狄利克雷把欧拉定理 (2.71) 写成

```text
∏_p (1 − χ_m(p)/p^s)^{−1} = L(s, χ_m),  对所有 s > 1
```

其中乘积展布在所有素数 p 上，且

```text
L(s, χ_m) := ∑_{n=1}^{∞} χ_m(n)/n^s
```

称为狄利克雷 L 级数（见 [[狄利克雷L级数]]）。符号 $\chi_m$ 表示 [[狄利克雷特征]]：它由模 m 的群同态 $\chi' : \mathbb{Z}/m\mathbb{Z} \to \mathbb{C} - \{0\}$ 定义，并对 $g \in \mathbb{Z}$ 令

```text
χ_m(g) := χ'([g])，当 gcd(g, m) = 1；否则 χ_m(g) := 0
```

例：m = 1 时 $\chi_1(g) = 1$ 对所有 g 成立，于是 $L(s, \chi_1) = \zeta(s)$，即狄利克雷 L 级数推广了黎曼 ζ 函数；粗略地说，$L(\cdot, \chi_m)$ 解密了素数 (mod m) 集合的结构。L 函数理论可推广到其他代数对象，特别是代数数域。详见 [[素数模m的狄利克雷局部化原理]] 与 [[concepts/狄利克雷L级数]]。

## 2.7.3.6 孪生素数猜想

恰好相差 2 的两个不同素数称为孪生素数，例如 3 与 5、5 与 7、11 与 13；一般猜想存在无穷多对孪生素数。详见 [[concepts/素数]]。

## 关键公式原文摘录

```text
(2.70)  a, a + d, a + 2d, a + 3d, …
(P)     ∑_{p ∈ P_{a,d}(x)} (ln p)/p = (1/φ(d))·ln x + O(1)
        π(x) := 不超过 x 的素数的个数
        π(x) ~ x/ln x ~ li x
        li x := PV ∫_0^x dt/ln t = lim_{ε→+0} (∫_0^{1−ε} dt/ln t + ∫_{1+ε}^{x} dt/ln t)
        p_n ~ n ln n
        π(x) = (x/ln x)(1 + r(x)),  A/ln x ≤ r(x) ≤ B/ln x
        |π(x) − li x| ≤ 常数·√x·ln x（若 (2.72) 成立）
(2.71)  ∏_p (1 − 1/p^s)^{−1} = ζ(s),  s > 1
        ζ(s) := ∑_{n=1}^{∞} 1/n^s,  Re s > 1
        ζ(s) = 1/(s − 1) + 在点 s 附近的幂级数,  ζ(0) = −1/2
        π^{−s/2} Γ(s/2) ζ(s) = π^{(s−1)/2} Γ(1/2 − s/2) ζ(1 − s)
(2.72)  ζ 函数的所有非平凡零点都在临界线 Re s = 1/2 上
(2.73)  L = ∑_{n=1}^{∞} E^{−E_n/kT}；令 E_n := k·t·s·ln n，则 L = ζ(s)
(2.74)  ζ(s) = ∑_{n=1}^{∞} 1/n^s；tr I_ren := ζ(0) = −1/2
```

## 讹误与疑问

- 阿达马的生卒年被印作「1865—1893」，与 1896 年完成素数定理证明的事实存在时序冲突，见 [[queries/273节阿达马生卒年1865-1893疑似讹误]]。
- 配分函数 (2.73) 中的指数底数、能量式中的符号组合，以及黎曼定理 (i) 中写作 $\zeta(x)$ 的自变量，均疑为排印或 OCR 讹误，见 [[queries/273节配分函数与黎曼定理公式ocr讹误]]。
- 小节标题以 2.7.3.5「素数 mod m 的狄利克雷局部化原理」命名，但正文内容既包含 L 级数与狄利克雷特征的定义，也包含对 ζ 函数的推广论断，标题与内容的覆盖范围略有错位。
