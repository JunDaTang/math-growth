# 《数学指南——实用数学手册》2.7.10 数论中局部—整体基本原理

本页汇总《数学指南——实用数学手册》第 2.7.10 节的内容。该节以「赋值 → 完备化 → 赋值分类 → 局部-整体原理」为主线，用统一的分析框架把实数域 R 与 p 进数域 Q_p 并列起来，并以闵可夫斯基-哈塞定理给出数论中局部-整体原理的一个特例。

## 逻辑主线

1. **2.7.10.1 赋值**：在任意域 K 上定义实赋值 ν，给出平凡赋值、绝对值赋值 ν_∞ 与 p 进赋值 ν_p 三个例子。
2. **2.7.10.2 p 进数**：任意度量空间可唯一（等距同构意义下）完备化；对 Q 取不同赋值诱导的度量，完备化分别得到 R 与 Q_p；继而给出奥斯特罗夫斯基定理（1918），说明非平凡赋值的完备化只有这两种可能。
3. **2.7.10.3 闵可夫斯基-哈塞定理**：对二次型方程 (2.98)，局部可解性（在 R 与全部 Q_p 上）蕴含整体可解性（在 Q 上），此即局部-整体原理的一个特殊情形。

## 结构化内容

### 2.7.10.1 赋值

定义：设 K 是一个给定的域。域 K 上的（实）赋值对每个元素 x ∈ K 相伴一个实数 ν(x) ≥ 0，且具有下列性质：

(i) ν(x) = 0 当且仅当 x = 0。

(ii) ν(xy) = ν(x)ν(y) 及 ν(x + y) ≤ ν(x) + ν(y) 对所有 x, y ∈ K。

> 源文写作 `ν(xg) = ν(x)ν(y)`，其中 `xg` 显系 `xy` 的 OCR 讹误（乘法性）。参见 [[queries/2710节享泽尔写法与奥斯特罗夫斯基定理主语疑似讹误]]。

例 1：ν(0) = 0 及 ν(x) = 1（对所有 x ≠ 0），这是一个平凡的赋值。

例 2：设 Q 是有理数域。令

```
ν_∞(x) := |x|,
```

它产生 Q 上的一个赋值。

如果 p 是素数，那么 Q 中的每个数可以写成

```
x = (a/b) p^m,
```

其中 m 是整数，且数 a 和 b 不能被 p 整除。如果令

```
ν_p(x) := p^(−m),
```

那么得到所谓 Q 上的 p 进赋值。

### 2.7.10.2 p 进数

每个度量空间都可以扩张为完全度量空间。这个扩张在等距同构的意义下是唯一的（参看 [212]）。

有理数域 Q 借助定义

```
d(x, y) := ν_∞(x − y)
```

成为一个度量空间，这个度量空间的完备化产生实数域 R。

如果在上述过程中应用 p 进赋值，那么 Q 关于度量

```
d(x, y) := ν_p(x − y)
```

的完备化产生 p 进数域 Q_p。

例：无穷级数 ∑_{n=0}^{∞} a_n 在 Q_p 中收敛，当且仅当 (a_n) 收敛于 0。具有如此简单性的结果在 R 中不成立。

**奥斯特罗夫斯基定理（1918）** 如果有一个有理数域上的非平凡赋值 ν，那么 R 关于度量 d(x, y) := ν(x − y) 的完备化或者是域 R，或者是某个 p 进数域 Q_p。

> 源文此处的主语作「R」，但被完备化的对象应为 Q（由 Q 完备化得到 R 或 Q_p），写成 R 与「完备化产生 R」自相矛盾。疑为「Q」之讹；措辞「如果有一个有理数域上的非平凡赋值 ν」亦不畅。参见 [[queries/2710节享泽尔写法与奥斯特罗夫斯基定理主语疑似讹误]]。

附注：如果采纳「有理数由自然数唯一确定」的观点，那么奥斯特罗夫斯基定理表明经典的由 Q 到 R 的抽象化就是不必要的；更确切地说，所有的 p 进域 Q_p 是同一个域（度量空间）的可能的完备化。

p 进数是 K. 享泽尔（Hensel）于 1904 年引进数论中的，并从此证明它们是基本的。有许多数学家和物理学家认为理论物理至今如此不完全，是因为由于历史的原因直到现在它仍然限于实数而不考虑其他的域 Q_p。

> 该物理性论断属观念性主张/推测，并非数学定理；源文「至令」应为「至今」，「享泽尔」通行译名为「亨泽尔」。

### 2.7.10.3 闵可夫斯基-哈塞定理

考虑方程

```
a_1 x_1^2 + … + a_n x_n^2 = 0          (2.98)
```

其中 a_1, …, a_n 是有理数，全不为零。

**定理** 如果对于 K = R 及 K = Q_p（p 是任意素数）方程 (2.98) 有非平凡解

```
x_1, …, x_n ∈ K                        (2.99)
```

那么它也有非平凡解

```
x_1, …, x_n ∈ Q.                       (2.100)
```

附注：称 (2.99) 中的解是局部的，而 (2.100) 中的解是整体的。于是这个定理告诉我们，由方程 (2.98) 的局部可解性可推出它的整体可解性。这是数论中一般的局部-整体原理的一个特殊情形，并表明了 p 进数域的基本性质。

## 范围限定

闵可夫斯基-哈塞定理在源文中被**明确限定**于形如 (2.98) 的二次型方程。这是局部-整体原理的一个特殊情形，不应外推为「对任意方程，局部可解必蕴含整体可解」的普适结论。

## 已识别的讹误与开放问题

1. 定义 (ii) 中 `ν(xg)` 应为 `ν(xy)`。
2. 奥斯特罗夫斯基定理陈述的主语「R」疑应为「Q」。
3. 「如果有一个有理数域上的非平凡赋值 ν」措辞不畅。
4. 人名「享泽尔」疑为「亨泽尔」（Hensel）之讹。
5. 「至令如此不完全」应为「至今」。
