# 《数学指南——实用数学手册》3.9.6 旋量几何和费米子

## 源文档定位

本节属于《数学指南——实用数学手册》第 3 章（物理学中的数学方法）3.9 小节（相对论与量子力学相关的数学结构），编号 3.9.6。它把相对论电子、自旋、旋量、手征性与克利福德代数统一在同一个数学框架下，是连接**抽象代数（四元数、克利福德代数、李群）**与**量子场论（狄拉克方程、费米子、标准模型）**的桥梁性文本。

## 一、总体结构

全文分为三个子节，层层递推：

1. **3.9.6.1 闵可夫斯基空间的克利福德代数** —— 建立 $\mathcal{C}(M_4)$，给出其 16 维基，并引入泡利矩阵、李代数 $su(2)$ 与泡利-狄拉克矩阵。
2. **3.9.6.2 狄拉克方程及相对论的电子** —— 用 $\mathcal{C}(M_4)$ 表示自由电子方程，讨论其在洛伦兹变换、空间反射 $P$、时间反射 $T$、负荷对偶 $C$ 下的性态，导出电子自旋与手征性，进而讨论费米子、玻色子与标准模型。
3. **3.9.6.3 希尔伯特空间的克利福德代数和旋量群** —— 推广到一般 $n$ 维实希尔伯特空间 $X$，构造 $\mathcal{C}(X)$、克利福德范数、共轭算子、$*$ 算子，重建哈密顿四元数代数，定义 $\mathrm{Spin}(n,X)$ 群，给出布饶尔-外尔定理，并以椭圆狄拉克算子与拉普拉斯算子收尾。

## 二、关键概念

### 2.1 闵可夫斯基空间的克利福德代数 $\mathcal{C}(M_4)$

对 $\pmb{u}, \pmb{v} \in M_4$，定义式为

$$\boldsymbol{u} \vee \boldsymbol{v} + \boldsymbol{v} \vee \boldsymbol{u} = 2 \boldsymbol{u} \boldsymbol{v}.$$

取伪法正交基 $e_1, \dots, e_4$，则

$$e_j \vee e_k + e_k \vee e_j = 2 e_j e_k \tag{3.100}$$

其中 $e_1 \vee e_1 = e_2 \vee e_2 = e_3 \vee e_3 = 1$，而 $e_4 \vee e_4 = -1$。$\mathcal{C}(M_4)$ 的维数为 $16$，基由四类元素构成：

- (i) $1, e_1, e_2, e_3, e_4$；
- (ii) 六个二重积 $e_1 \vee e_2, \dots, e_3 \vee e_4$；
- (iii) 四个三重积；
- (iv) 一个四重积 $e_1 \vee e_2 \vee e_3 \vee e_4$。

### 2.2 泡利矩阵与李代数 $su(2)$

$$\boldsymbol{\sigma}_1 := \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \quad \boldsymbol{\sigma}_2 := \begin{pmatrix} 0 & -\mathrm{i} \\ \mathrm{i} & 0 \end{pmatrix}, \quad \boldsymbol{\sigma}_3 := \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}, \quad \boldsymbol{\sigma}_4 := \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}.$$

$i\sigma_1, i\sigma_2, i\sigma_3$ 张成实线性空间 $su(2)$，配合对易子 $[A,B] := AB - BA$ 使其成为李代数。

### 2.3 泡利-狄拉克矩阵 $\gamma_\alpha$

复 $4\times 4$ 矩阵：

$$\gamma_\alpha = \mathrm{i}\begin{pmatrix} 0 & -\sigma_\alpha \\ \sigma_\alpha & 0 \end{pmatrix},\quad \gamma_4 := \mathrm{i}\begin{pmatrix} 0 & \sigma_4 \\ \sigma_4 & 0 \end{pmatrix},\quad \alpha = 1,2,3,$$

并令 $\gamma^\alpha := \gamma_\alpha\;(\alpha=1,2,3)$、$\gamma^4 := -\gamma_4$。满足

$$\gamma_j \gamma_k + \gamma_k \gamma_j = 2 \gamma_j \gamma_k,\quad j=1,2,3,4 \tag{3.101}$$

即关系 (3.101) 与 (3.100) 在形式上一致。

**定理.** 相对于矩阵乘法，$\mathbf{Mat}(4,4)$ 是一个克利福德代数。相伴关系 $e_j \mapsto \gamma_j$ 给出 $\mathcal{C}(M_4)$ 与 $\mathbf{Mat}(4,4)$ 间的同构。

### 2.4 狄拉克方程

狄拉克 1928 年对自由电子推导的方程为

$$\partial \vee \Psi + \frac{m_0 c}{\hbar} \Psi = 0 \tag{3.102}$$

其中波函数 $\Psi = (\varphi_1, \varphi_2, \mathrm{i}x_1, \mathrm{i}x_2)^{\mathrm{T}} = (\varphi, \mathrm{i}x)^{\mathrm{T}}$，$\partial \vee \psi := \gamma^k \partial_k$，$x^4 = ct$。等价的分量形式为

$$
\begin{array}{c}
\sigma_\alpha \partial_\alpha \varphi - \sigma_4 \partial_4 \varphi + \dfrac{m_0 c}{\hbar} \chi = 0, \\
\sigma_\alpha \partial_\alpha \chi + \sigma_4 \partial_4 \chi + \dfrac{m_0 c}{\hbar} \varphi = 0.
\end{array} \tag{3.103}
$$

$\varphi$、$\chi$ 分别称为**旋量**与**双旋量**。

**变换性态.** 正常洛伦兹变换 $x' = L(A)x$ 下 $\varphi' = A^*\varphi,\ \chi' = A^{-1}\chi$，其中 $A \in SL(2,\mathbb{C})$，且

$$\sigma_j x^{j'} = A^{-1}(\sigma_j x^j)(A^*)^{-1}.$$

**定理.**

- (i) 相伴关系 $A \mapsto L(A)$ 是 $SL(2,\mathbb{C}) \to SO^+(3,1)$ 的同态，核为 $N=\{E,-E\}$。
- (ii) $SL(2,\mathbb{C})/N \simeq SO^+(3,1)$。
- (iii) 若 $A$ 还是酉矩阵，则 $x' = L(A)x$ 对应空间旋转；$A \mapsto L(A)$ 给出 $SU(2) \to SO(3)$ 的同态。
- (iv) $SU(2)/N \cong SO(3)$。

**三类变换.**

- 空间反射 $P$：$x^{\alpha'} = -x^\alpha,\ x^{4'}=x^4$，且 $\varphi' = \chi,\ \chi' = -\varphi$。
- 时间反射 $T$：$x^{4'} = -x^4$，且 $\varphi' = \chi,\ \chi' = \varphi$。
- 负荷对偶 $C$：$\varphi' = -\sigma_2\overline{\chi},\ \chi' = \sigma_2\overline{\varphi}$。

狄拉克方程在这三种变换下均不变；一般过程在复合变换 **PCT** 下保持不变，这对应"过程 $\mathcal{P}$ 可能则反射+反粒子过程 $\mathcal{P}'$ 也可能"的直观原理。

### 2.5 电子自旋

总角动量算子

$$D\Psi = (\boldsymbol{x} \times \boldsymbol{p})\Psi + \frac{\mathrm{h}}{2} s\Psi,$$

其中 $\boldsymbol{p} := \frac{\hbar}{\mathrm{i}} e_\alpha \partial_\alpha$，$\boldsymbol{s} := \begin{pmatrix}\sigma_\alpha & 0 \\ 0 & \sigma_\alpha\end{pmatrix} e_\alpha$。将 (3.102) 写成 $i\hbar\partial_4 \Psi = H\Psi$，得

$$HD - DH = 0 \tag{3.104}$$

即 $D$ 守恒。对 $s_3$：

$$s_3 \Psi_\pm = \pm \frac{\hbar}{2} \psi_\pm,$$

特征态 $\Psi_+ = 2^{-1/2}(1,0,1,0)^{\mathrm{T}}$，$\Psi_- = 2^{-1/2}(0,1,0,1)^{\mathrm{T}}$，分别对应 $e_3$ 轴方向自旋 $\pm\hbar/2$。**总动量守恒 (3.104) 因此强使电子自旋存在。**

### 2.6 手征性

手征算子

$$P := \frac{1}{2}(1 + \gamma_5),\quad \gamma_5 := -\mathrm{i}\gamma_1\gamma_2\gamma_3\gamma_4,$$

$\gamma_5^2 = I$ 且 $P^2 = P$（投影算子）。$P\Psi = \Psi$ 的状态手征为 $+1$，$(I-P)\Psi = \Psi$ 的状态手征为 $-1$。显式地

$$\gamma_5 = \begin{pmatrix} \sigma_4 & 0 \\ 0 & -\sigma_4 \end{pmatrix}.$$

在空间反射下手征变号。1956 年**李政道和杨振宁**假设中微子天然以手征 $-1$ 出现，即涉及中微子的过程不出现空间反射，对应**弱相互作用的宇称不守恒**；**吴健雄** 1957 年在钴 $\beta$ 衰变实验中证实；李、杨同年获诺贝尔物理奖。

### 2.7 费米子、玻色子与标准模型

- **费米子**：半整自旋 $k\hbar/2,\ k=1,3,5,\dots$。
- **玻色子**：整自旋 $m\hbar,\ m=0,1,\dots$。

现代标准理论取 **6 个夸克和 6 个轻子**（如电子、中微子）及其反粒子作为基本粒子。它们都是费米子，由同一类型（狄拉克型）方程描述。根据局部规范不变性原理，这些狄拉克方程必须与对应规范玻色子的场相结合。**反粒子**的存在性在狄拉克方程**第二量子化**后才被需要。**超对称性 (SUSY)** 假定爆炸初期物理是超对称的，每个玻色子有对应的费米子（例如引力子的相伴粒子是旋量 $3\hbar/2$ 的引力微子），但至今未被观测。

**表 3.11 四个基本力的胶子**

| 自然界中出现的相互作用 | 规范玻色子 | 旋量 |
|------------------------|------------|------|
| 电磁力 | 光子 | $\hbar$ |
| 强（核力） | 8 个胶子 | $\hbar$ |
| 弱（放射衰变） | $W^\pm, Z$ | $\hbar$ |
| 引力 | 引力子 | $2\hbar$ |

### 2.8 希尔伯特空间的克利福德代数与旋量群

设 $X$ 为实希尔伯特空间，$\dim X = n$。其克利福德代数 $\mathcal{C}(X) \subset X$ 满足

$$u \vee v + v \vee u = -2(u,v)_X.$$

取法正交基 $e_1,\dots,e_n$ 得 $e_j \vee e_k + e_k \vee e_j = -2\delta_{jk}$，尤其

$$e_j \vee e_j = -1,\quad j=1,\dots,n,$$

是 $i^2 = -1$ 的推广。

**基本定理.** $\dim \mathcal{C}(X) = 2^n$，基由 $e_0:=1$ 与所有 $e_\alpha$ 组成。

- 例 1：$\dim X = 1$ 时 $\mathcal{C}(X) \cong \mathcal{C}(\mathbb{R}) \cong \mathbb{C}$。
- **克利福德范数**：$|u| := \sup\{\|u \vee w\|_{\mathcal{C}(X)} : \|w\|_{\mathcal{C}(X)} \le 1\}$，例中 $|a + be_1| = \sqrt{a^2+b^2}$。
- **共轭算子**：$\varphi(e_0) = e_0,\ \varphi(e_j) = -e_j$，记 $\bar{u}$。
- **$*$ 算子**：反转乘积中因子次序。

**哈密顿四元数代数 (1843).** 考虑形式 $a + \boldsymbol{v}$，定义为

$$(a + \boldsymbol{v}) \vee (b + \boldsymbol{w}) := ab + a\boldsymbol{w} + b\boldsymbol{v} + (\boldsymbol{v} \times \boldsymbol{w}) - \boldsymbol{v}\boldsymbol{w},$$

其中 $\times$ 为经典向量积、$\boldsymbol{v}\boldsymbol{w}$ 为经典内积。$\overline{a+\boldsymbol{v}} := a - \boldsymbol{v}$，$|a+\boldsymbol{v}| = \sqrt{a^2+\boldsymbol{v}^2}$，逆元 $(a+\boldsymbol{v})^{-1} = \frac{a-\boldsymbol{v}}{|a+\boldsymbol{v}|}$。对法正交基 $i,j,k$：

$$i \vee j = -j \vee i = k,\quad i \vee i = -1 \tag{3.105}$$

其余乘积通过循环置换 $i \to j \to k \to i$ 得到。

**定理.** 若 $\dim X = 2$ 且基为 $i,j$，则 $\mathcal{C}(X)$ 与哈密顿四元数代数同构，映射为

$$a + \alpha i + \beta i + \gamma(i \vee j) \mapsto a + \alpha i + \beta j + \gamma k,$$

保范数且保持共轭。

**哈密顿旋转公式.** 令 $Q := \cos\frac{\varphi}{2} + e\sin\frac{\varphi}{2}$（$e^2=1$），则

$$\boldsymbol{x}' = Q \vee \boldsymbol{x} \vee \bar{Q} \tag{3.106}$$

表示向量 $\boldsymbol{x}$ 绕轴 $e$ 以角 $\varphi$ 按数学正向旋转。

### 2.9 旋量群 $\mathrm{Spin}(n,X)$ 与布饶尔-外尔定理

$\mathrm{Spin}(n,X)$ 由偶数个因子的乘积 $a = u_1 \vee u_2 \vee \dots \vee u_{2k}$ 中满足 $a \vee a^* = 1$ 且 $|a| = 1$ 者组成，对積 "$\vee$" 构成群。

**布饶尔和外尔的定理 (1955).** 每个 $a \in \mathrm{Spin}(n,X)$ 通过 $D(a)u := a \vee u \vee a^*$ 生成酉变换（旋转）。$a \mapsto D(a)$ 是 $\mathrm{Spin}(n,X) \to SO(n,X)$ 的同态，核 $N = \{I,-I\}$，因此

$$\mathrm{Spin}(n,X)/N \cong SO(n,X).$$

对 $X = \mathbb{R}^n$ 记 $\mathrm{Spin}(n)$。**例 8** 列出若干例外同构：

- (i) $SO(2) \cong U(1),\ \mathbb{R}/\mathbb{Z} \cong SO(2)$；
- (ii) $\mathrm{Spin}(3) \cong SU(2)$；
- (iii) $\mathrm{Spin}(4) \cong SU(2) \times SU(2)$；
- (iv) $\mathrm{Spin}(n,X) \cong \mathrm{Spin}(n)$。

**注.** 对 $n \geq 2$，$\mathrm{Spin}(n,X)$ 是 $n(n-1)/2$ 维紧实李群；对 $n \geq 3$ 它是 $SO(n,X)$ 的万有覆叠群。

### 2.10 椭圆狄拉克算子与拉普拉斯算子

$$D_4 := \sum_{j=1}^n e_j \partial_j \psi,\quad \Delta := \sum_{j=1}^n \partial_j^2.$$

**定理.** $D \vee D = -\Delta$。

**注.** 此关系表明拉普拉斯算子可通过狄拉克算子构造，这是狄拉克算子在现代分析中极其基础的原因之一。流形上狄拉克算子指标计算问题是导向 1960 年**阿蒂亚-辛格指标定理**的问题之一，被誉为 20 世纪最深刻的结果之一。

## 七、待追问题

1. 源文档把 $\gamma_5$ 定义为 $-\mathrm{i}\gamma_1\gamma_2\gamma_3\gamma_4$，与主流文献常采用的 $\gamma_5 := \mathrm{i}\gamma_0\gamma_1\gamma_2\gamma_3$ 差一个符号或指标约定，需核对多重符号一致性。
2. 表格 3.11 中"旋量"一列对光子、胶子、$W^\pm/Z$、引力子分别标 $\hbar, \hbar, \hbar, 2\hbar$，与这些粒子实际自旋（$1,1,1,2$）的对应关系需在物理语境下澄清。
3. 超对称粒子（如引力微子，旋量 $3\hbar/2$）至今未被观测，属开放实验问题。
4. 本节未展开 $n$ 维狄拉克算子的指标定理证明，可作为后续深挖方向。
