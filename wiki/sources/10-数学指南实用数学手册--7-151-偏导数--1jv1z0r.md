# 《数学指南——实用数学手册》1.5.1 偏导数

## 来源概况

本节是《数学指南——实用数学手册》第 1.5 节「多元实变函数的导数」的第一个子节，主题为**偏导数**。内容属于教科书式的定义与示例：先用一个二元函数的例子引入「固定其余变量、只对一个变量求导」的基本思想，随后给出偏导数在 $\mathbb{R}^N$ 上的严格极限定义、若干记号、多元 $C^k$ 类光滑函数的术语约定，以及关于混合偏导数次序可交换的**施瓦茨定理 (1.44)**。

本节无插图。正文中出现了两处对外部内容的引用：0.8.2（求导例子，用于铺垫单变量导数 (1.41)）与 1.3.2.2（闭包，用于定义 $C^k(\bar G)$）。

## 基本思想与引入

令 $C$ 为某一常数，对 $f(u) := u^2 C$，由 0.8.2 有导数

```text
(1.41)  df/du = 2uC
```

取

```text
f(u, v) := u^2 v^3
```

把 $v$ 看成常数、把 $f$ 看成 $u$ 的函数并对 $u$ 求导，即得关于 $u$ 的所谓**偏导数**：

```text
(1.42)  ∂f/∂u = 2uv^3
```

同理把 $u$ 看成常数、对 $v$ 求导，得

```text
(1.43)  ∂f/∂v = 3u^2 v^2
```

**总结**：把多元函数看成其中一个变量的函数，并把其他变量看成常数，就得到偏导数。

## 高阶偏导数

用同样的方式可得高阶偏导数。把 (1.42) 中的 $u$ 看成常数：

```text
∂²f/∂v∂u = ∂/∂v(∂f/∂u) = 6uv^2
```

把 (1.43) 中的 $v$ 看成常数：

```text
∂²f/∂u∂v = ∂/∂u(∂f/∂v) = 6uv^2
```

## 本节记号（逐字保留）

```text
f_u  := ∂f/∂u,   f_v  := ∂f/∂v
f_uv := (f_u)_v = ∂²f/∂v∂u
f_vu := (f_v)_u = ∂²f/∂u∂v
```

对于足够光滑的函数，有对称性 $f_{uv} = f_{vu}$（比较施瓦茨定理 (1.44)）。

简化符号（见下文「符号」小节）：

```text
∂_j f := ∂f/∂x_j
```

## 偏导数的定义（逐字保留）

令 $f: M \subseteq \mathbb{R}^N \to \mathbb{R}$ 为一个函数，$p$ 是 $M$ 的一个内点。如果极限

```text
∂f/∂x_1 (p) := lim_{h→0} [ f(p_1 + h, p_2, …, p_N) − f(p_1, …, p_N) ] / h
```

存在，则称 $f$ 有关于 $x_1$ 的偏导数。其他偏导数的定义类似。

## $C^k$ 类光滑函数（术语，逐字保留）

**$C^k(G)$ 类光滑函数**：令 $G$ 是 $\mathbb{R}^N$ 的一个开集。$C^k(G)$ 是有直到 $k$ 阶的连续偏导数的所有函数 $f: G \to \mathbb{R}$ 的集合。如果 $f \in C^k(G)$，则也称 $f$ 是 $C^k(G)$ 类的。

**$C^k(\bar G)$ 类**：令 $\bar G = G \cup \partial G$ 表示 $G$ 的闭包（见 1.3.2.2）。集合 $C^k(\bar G)$ 由所有属于 $C^k(G)$ 类的函数 $f: \bar G \to \mathbb{R}$ 组成，其中 $f$ 的所有直到 $k$ 阶的偏导数可以连续延拓到闭包 $\bar G$。$^{1)}$

**脚注 1)（逐字保留）**：省略上标 $k$ 或令 $k = 0$，则 $C(G)$ 或 $C^0(G)$（相应地，$C(\bar G$ 或 $C^0(\bar G)$）表示所有连续函数 $f: G \to \mathbb{R}$（相应地，$f: \bar G \to \mathbb{R}$）的空间。另外，$C^\infty(G)$（相应地，$C^\infty(\bar G)$）由对所有 $k$，属于 $C^k(G)$（相应地，$C^k(\bar G)$）的那些函数组成。

## 施瓦茨定理 (1.44)

如果 $f: M \subseteq \mathbb{R}^N \to \mathbb{R}$ 是 $p$ 的一个开邻域中的 $C^2$ 类函数，那么

```text
(1.44)  ∂²f(p)/∂x_j∂x_m = ∂²f(p)/∂x_m∂x_j,   j, m = 1, …, N
```

更一般地，如果 $f$ 是 $p$ 的某个开邻域中的 $C^k$ 类函数，$k \geqslant 2$，那么求直到 $k$ 阶的偏导数与其先后次序无关。

## 示例

**例 1**：对于 $f(u,v) = u^4 v^2$，有 $f_u = 4u^3 v^2$、$f_v = 2u^4 v$，以及

```text
f_uv = f_vu = 8u^3 v
```

此外 $f_{uu} = 12u^2 v^2$ 及

```text
f_uuv = f_uvu = 24u^2 v
```

**例 2**：方程 (1.44) 意为 $\partial_j \partial_m f(p) = \partial_m \partial_j f(p)$。
