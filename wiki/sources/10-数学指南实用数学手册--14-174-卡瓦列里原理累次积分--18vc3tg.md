# 《数学指南——实用数学手册》1.7.4 卡瓦列里原理（累次积分）

## 概述

本节是 1.7 节中直接承接 [[sources/10-数学指南实用数学手册--10-172-积分的存在性--il3nbl]]（1.7.2 节「积分的存在性」）的一节，主题是**把多变量积分化为累次积分**。全节围绕两条带编号的公式展开：

- **富比尼定理**（公式 (1.140)）：全空间 $\mathbb{R}^N$ 上的容许函数，其积分等于任一次序的累次积分；
- **卡瓦列里原理**（公式 (1.141)）：一般区域 $D \subseteq \mathbb{R}^N$ 上的容许函数，其积分等于「先沿 $z$ 截面做内层积分、再对 $z$ 做外层积分」的累次积分。

两条结果都以前一节的 [[concepts/容许函数]] 为前提，二者构成「全空间 / 一般区域」两个层次。本节另给出三个例子，其中例 2（高斯分布）与例 3（$\mathbb{R}^N$ 上的高斯积分）是经典结论。

## 记号与变量分裂

本节开篇把空间做直积分解：

```latex
令 R^{N} = R^{k} \times R^{M} ，即， R^{N} = {(y, z) | y \in R^{K}, z \in R^{M}} .
```

即把 $\mathbb{R}^N$ 上的点写成对 $(\boldsymbol{y}, \boldsymbol{z})$，其中 $\boldsymbol{y} \in \mathbb{R}^K$、$\boldsymbol{z} \in \mathbb{R}^M$。这一分裂是后面所有积分次序展开的基础。源文通篇用 `R^N` 记法而公式排版中写作 `\mathbb{R}^N`，属转写样式不统一。

## 富比尼定理（公式 1.140）

**陈述**：如果函数 $f: R^{N} \to C$ 是容许函数，那么

```latex
\int_{\mathbb{R}^{N}} f(\boldsymbol{y}, \boldsymbol{z}) \mathrm{d}\boldsymbol{y} \mathrm{d}\boldsymbol{z}
= \int_{\mathbb{R}^{M}} \left(\int_{\mathbb{R}^{K}} f(\boldsymbol{y}, \boldsymbol{z}) \mathrm{d}\boldsymbol{y}\right) \mathrm{d}\boldsymbol{z}
= \int_{\mathbb{R}^{K}} \left(\int_{\mathbb{R}^{M}} f(\boldsymbol{y}, \boldsymbol{z}) \mathrm{d}\boldsymbol{z}\right) \mathrm{d}\boldsymbol{y}.
\tag{1.140}
```

**要点**：两种积分次序（先对 $\boldsymbol{y}$ 或先对 $\boldsymbol{z}$）结果相同。手册未给出证明。

## 例 1：低维的累次展开

当 $N = 2,\ K = M = 1$ 时，

```latex
\int_{\mathbb{R}^{2}} f(y, z) \mathrm{d}y \mathrm{d}z
= \int_{-\infty}^{\infty} \left(\int_{-\infty}^{\infty} f(y, z) \mathrm{d}y\right) \mathrm{d}z.
```

当 $N = 3$ 时，公式 (1.140) 蕴涵着，对于变量 $x, y, z \in R$，

```latex
\begin{array}{l}
\int_{\mathbb{R}^{3}} f(x, y, z) \mathrm{d}x \mathrm{d}y \mathrm{d}z
= \int_{\mathbb{R}^{2}} \left(\int_{\mathbb{R}} f(x, y, z) \mathrm{d}x\right) \mathrm{d}y \mathrm{d}z \\
\qquad = \int_{-\infty}^{\infty} \left(\int_{-\infty}^{\infty} \left(\int_{-\infty}^{\infty} f(x, y, z) \mathrm{d}x\right) \mathrm{d}y\right) \mathrm{d}z.
\end{array}
```

源文随后指出：「类似地，$R^{N}$ 上的积分计算可以归结为一元积分的逐次运算。」这条例 1 的展开主要起示意作用。

## 乘积可分离函数的积分分解

如果 $f$ 可以写成乘积 $f(y, z) = a(y)b(z)$，那么

```latex
\int_{\mathbb{R}^{2}} a(y) b(z) \mathrm{d}y \mathrm{d}z
= \int_{-\infty}^{\infty} a(y) \mathrm{d}y \int_{-\infty}^{\infty} b(z) \mathrm{d}z.
```

源文注明：「$R^{N}$ 中类似的公式也成立。」这一推论是例 2 与例 3 证明的核心工具。

## 例 2（高斯分布）

源文给出

```latex
A := \int_{-\infty}^{\infty} \mathrm{e}^{-x^{2}} \mathrm{d}x = \sqrt{\pi}.
```

**证明路径**（源文称之为「一个优美、经典的技巧」）：

1. 令 $B := \int_{\mathbb{R}^{2}} \mathrm{e}^{-x^{2} - y^{2}} \mathrm{d}x \mathrm{d}y$，由乘积分解得 $B = A^2$；
2. 另一方面用极坐标计算 $B$：

```latex
B = \int_{r = 0}^{\infty} \left(\int_{0}^{2\pi} \mathrm{e}^{-r^{2}} r \mathrm{d}\varphi\right) \mathrm{d}r
= 2\pi \int_{0}^{\infty} \mathrm{e}^{-r^{2}} r \mathrm{d}r
= \lim_{r \rightarrow R} 2\pi \int_{0}^{R} \mathrm{e}^{-r^{2}} r \mathrm{d}r
```

```latex
= \lim_{R \to \infty} -\pi \mathrm{e}^{-r^{2}} |_{0}^{R}
= \lim_{R \to \infty} \pi (1 - \mathrm{e}^{-R^{2}}) = \pi .
```

3. 于是 $A^2 = \pi$，故 $A = \sqrt{\pi}$。

源文此处的记号存在若干转写／排版疑点（极限下标 `lim_{r→R}`、`B` 定义行的自我重复、原函数代入行 `r` 与 `R` 混用），详见 [[queries/174节例2极坐标推导与重复行是否转写讹误]]。

## 例 3：$\mathbb{R}^N$ 上的高斯积分

```latex
\int_{\mathbb{R}^{N}} \mathrm{e}^{-|x|^{2}} \mathrm{d}x = (\sqrt{\pi})^{N}.
```

**证明**（以 $N = 3$ 为例）：此时 $\mathrm{e}^{-|x|^{2}} = \mathrm{e}^{-u^{2}-v^{2}-w^{2}}$，因此

```latex
\begin{array}{l}
\int_{\mathbb{R}^{3}} \mathrm{e}^{-u^{2}} \mathrm{e}^{-v^{2}} \mathrm{e}^{-w^{2}} \mathrm{d}u \mathrm{d}v \mathrm{d}w \\
= \left(\int_{-\infty}^{\infty} \mathrm{e}^{-u^{2}} \mathrm{d}u\right)
  \left(\int_{-\infty}^{\infty} \mathrm{e}^{-v^{2}} \mathrm{d}v\right)
  \left(\int_{-\infty}^{\infty} \mathrm{e}^{-w^{2}} \mathrm{d}w\right) = (\sqrt{\pi})^{3}.
\end{array}
```

源文以「对任意 $N$，有完全类似的结论」结束本例。

**入库说明**：本结果此前已在 1.7.2 节被引用（见既有页 [[findings/高斯积分在RN上等于根号pi的N次方]]），但那份页面的来源是**转引**；本节是它的**原始证明出处**。相应悬置问题 [[queries/172节引用174例3尚未入库]] 由此得到解决。

## 卡瓦列里原理（公式 1.141）

**陈述**：如果函数 $f: D \subseteq R^{N} \to C$ 是容许函数，那么

```latex
\int_{D} f(\boldsymbol{y}, \boldsymbol{z}) \mathrm{d}\boldsymbol{y} \mathrm{d}\boldsymbol{z}
= \int_{\mathbb{R}^{M}} \left(\int_{D} f_{*}(\boldsymbol{y}, \boldsymbol{z}) \mathrm{d}\boldsymbol{y}\right) \mathrm{d}\boldsymbol{z}.
\tag{1.141}
```

公式中出现的两个对象是：

**$z$ 截面**（源文记作「$D$ 的 $z$ 截面 $D_z$ 如上定义」）：

```latex
D_{z} := \{\boldsymbol{y} \in \mathbb{R}^{K} : (\boldsymbol{y}, \boldsymbol{z}) \in D\}
```

**平凡扩张**：

```latex
f_{*}(\boldsymbol{y}, \boldsymbol{z}) :=
\left\{ \begin{array}{ll}
f(\boldsymbol{y}, \boldsymbol{z}), & \text{在} D \text{上}, \\
0, & \text{其他},
\end{array} \right.
```

**推导关系**：源文明确写道，把 (1.140) 中的函数 $f$ 替换成它的平凡扩张 $f_*$，「即从 (1.140) 推出卡瓦列里原理」。也就是说，卡瓦列里原理并非与富比尼定理并列的独立假设，而是富比尼定理在「区域 $D$ + 外部补零」情形下的推论——这与 [[concepts/归约原理]] 的思路一致。相关讨论见 [[queries/卡瓦列里原理与富比尼定理是否等同]]。

**末尾提示**：源文最后一句为「它的应用可见 1.7.1」。该指向在编号顺序上略显反常（1.7.1 在编号上先于 1.7.4），待核，见 [[queries/174节末尾应用可见171节的指向是否讹误]]。

## 本节的转写与排版疑点汇总

1. 例 2 中极限下标 `\lim_{r \rightarrow R}` 应为 `\lim_{R \to \infty}`，且与下一行 `\lim_{R \to \infty}` 写法不统一；
2. 例 2 中 $B$ 的定义行出现两次完全相同的 $\int_{\mathbb{R}^{2}} \mathrm{e}^{-x^{2}-y^{2}} \mathrm{d}x \mathrm{d}y$，疑为丢字；
3. 原函数代入行 `-\pi \mathrm{e}^{-r^{2}} |_{0}^{R}` 中 $r$ 与 $R$ 混用；
4. 通篇 `R^N`／`R^{k}`／`R^{K}` 大小写与 `\mathbb{R}^N` 排版不统一；
5. 末尾「它的应用可见 1.7.1」的指向待核。
