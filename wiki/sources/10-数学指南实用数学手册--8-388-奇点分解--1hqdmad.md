# 《数学指南——实用数学手册》3.8.8 奇点分解

## 主题与问题设置

设已知 $\mathbb{C}^n$ 中一个解析集 $X$，其在原点 $z=0$ 有一个孤立奇点。目标是找到集合 $X$ 的一个局部参数化

```text
z = π(t),   t ∈ 𝒯
```

使得参数空间 $T$ 没有奇点。以 $\mathcal{S} := \pi^{-1}(0)$ 记参量的临界点集。

本节是对 [[奇点分解]] 这一概念的详细展开：3.8.5 节仅在单值化意义下一句话式地提到「奇点分解」，本节则给出定理化的陈述、拉开这一基本操作，以及一个可显式核验的二重点消解例子。

## 广中平佑的局部单值化定理 (1964)

存在一个具下列性质的参数化 $\pi: T \rightarrow X$：

```text
(i)   参数空间 T 是个光滑复流形。
(ii)  π 为逆紧的、由 T 到 X 的原点邻域的全纯映射。
(iii) 映射 π: T \ S → X \ {0} 为双全纯。
(iv)  参数的临界点集 𝒮 是 𝒯 的一个余维为 1 的解析集，
      即 dim 𝒮 = dim 𝒯 − 1。
```

我们称 $\pi: \mathcal{T} \to X$ 为 $X$ 在原点（孤立奇点）的一个奇点分解。

关于性质 (ii) 中的「逆紧」与 (iii) 中的「双全纯」，见 [[逆紧映射]] 与 [[双全纯]]。性质 (iv) 的 $\mathcal{S}$ 是参数**空间**中的临界点集，需与 3.8.5 语境下的 [[参数值临界集]] 区分。

## 奇点的拉开

在奇点的分解过程中，奇点经过了有限次的拉开。现通过举例来描述这个过程，这对代数几何是很基本的东西。

## 例（图 3.91）：曲线 x² − y² = 0 的二重点消解

考虑曲线

```text
X: x² − y² = 0,   (x, y) ∈ ℂ²,        (3.71)
```

它在 $P = (0,0)$ 有一个二重点（参见 [[二重点与尖点]]）。

**第 1 步：拉开二重点 $P$ 为直线 $g_P$**（图 3.91(b)），即将此点换成一条射影直线。这可利用参数化

```text
(x, y) = f(u, v),   (u, v) ∈ ℂ²       (3.72)
```

得到，其中 $f(u,v) := (u, uv)$。由 (3.71) 得到方程

```text
v²(1 − u²) = 0,   (u, v) ∈ ℂ².
```

这引出了三条直线 $g_{\pm}: u = \pm 1$ 和 $g_P: u = 0$。直线 $g_+$ 和 $g_-$（分别地，直线 $g_P$）由 (3.72) 被变换为 $X$ 的两条分支直线（分别地，$X$ 的二重点）。

**第 2 步：嵌入。** 现在把直线 $g_P$ 嵌入到一个三维空间中从而得到在 $\mathbb{C}^3$ 中的一条直线，记其为 $G_P$（图 3.91(c)）。例如，可以由令

```text
G_P := {(u, v, w) ∈ ℂ³ : v = 0, w = 1},
g_± := {(u, v, w) ∈ ℂ³ : u = ±1, w = 0}
```

来做到这一点。

**第 3 步：构造分解。** 选取参数空间 $T$ 为三条不相交的直线 $g_+, g_-$ 和 $G_P$。分解映射 $\pi: T \rightarrow X$ 直接由令

```text
π : 𝒯 --π--> ℂ² --f--> X
```

给出，其中的投射 $\pi(u,v,w) := (u,v)$。

在这个例子中我们可以容易地用将局部结构融入三维空间的办法来显式地定义这个消解（图 3.92）。一般的拉开的构造的优点是它可扩张到一个普遍适用的构造上。

## 评注与张力

- 定理给出的是**存在性**，而例子给出的是**显式构造**；书中点明「一般的拉开的构造可扩张到一个普遍适用的构造上」，但未在正文详证。
- 记号 $\mathcal{T}$（花体）与 $T$（普通体）在正文中交替表示参数空间，疑为排印或 OCR 不一致，见 [[388节符号T与花体T混用]]。
- 图 3.91 的总标题「消解一个二重点」夹在子图标签 (b) 与 (c) 之间，三张子图与 (a)(b)(c) 的对应关系需核实，见 [[388节图391图注与图序对应存疑]]。
