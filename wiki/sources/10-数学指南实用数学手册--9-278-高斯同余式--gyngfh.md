# 《数学指南——实用数学手册》2.7.8 高斯同余式

## 概述

本节是《数学指南——实用数学手册》2.7「数论」章中的一个进阶小节，内容分三块：

1. **同余的定义、运算法则、模逆元定理与费马-欧拉定理**（正节部分）；
2. **2.7.8.1 费马-欧拉定理在编码理论中的应用**——即 RSA 公钥密码体制的完整描述；
3. **2.7.8.2 二次互反律**——勒让德符号、高斯二次互反律、补充公式与高斯和。

叙述路径从初等同余算术出发，直接跳接到现代密码学与代数数论，是本章中"应用性"最强的一节。

## 同余的定义与运算法则

定义（按照高斯）：设 $a, b$ 及 $m$ 是整数，记

```
a ≡ b mod m
```

当且仅当差 $a-b$ 被 $m$ 整除。此时 $a$ 和 $b$ 称为对于模 $m$ 同余。

例 1：$5 \equiv 2 \mod 3$，因为 3 整除 $5-2$。

运算法则：

```
(i)   a ≡ a mod m.
(ii)  由 a ≡ b mod m 可推出 b ≡ a mod m.
(iii) 由 a ≡ b mod m 及 b ≡ c mod m 可推出 a ≡ c mod m.
(iv)  由 a ≡ b mod m 及 c ≡ d mod m 可得
      a + c ≡ b + d mod m  及  ac ≡ bd mod m.
```

## 模逆元定理

定理：如果 $s$ 和 $m$ 是互素的正自然数，那么方程

```
t s ≡ 1 mod m
```

有正整数解 $t$。

这一存在性结论是后文 RSA 解密指数存在的依据。

## 费马-欧拉定理

费马（1640）和欧拉（1760）定理：对于正自然数 $a$ 和 $m$，如果它们互素，那么

```
a^φ(m) ≡ 1 mod m,
```

其中 $\varphi(m)$ 表示整数 $1,\cdots,m$ 中与 $m$ 互素的数的个数（即欧拉 $\varphi$ 函数，参看 2.7.2）。

例 2：对于不整除 $a$ 的素数 $p$ 有

```
a^(p−1) ≡ 1 mod p.
```

定理的这种形式最初是费马提出的。

## 2.7.8.1 费马-欧拉定理在编码理论中的应用

源文指出：200 多年前费马-欧拉定理仅被看成纯粹数学中的一个结果；然而在 1977 年里夫斯特（Rivest）、沙米尔（Shamir）及阿德莱曼（Adlemann）公布了"下列简单得令人难以置信但却非常安全的码"，它的基础就是上述定理，并且现在已被广泛地应用。

### 操作器的准备

```
(i)  取两个素数 p 和 q，它们的大小大约为 10^100，并且要予以保密.
(ii) 作乘积  m = p q
     并计算  φ(m) = (p−1)(q−1).
(iii) 取另一个自然数 s，使适合  1 < s < φ(m).
(iv) 发送信息的人（公开地）给出两个数 m 和 s.
```

### 信息编码

将信息简单地编码为单个自然数：将每个字母对应于（例如）一个两位数 $10, 11, 12, \cdots$，并将信息中的每个字母换为所对应的两位数；于是将它们连接起来就得到一个大数 $n$，然后用 $m$ 去除数 $n^s$，将余数 $r$ 输送到操作器中，亦即只将满足

```
n^s ≡ r mod m
```

的数 $r$ 作为发出的信息。

### 用操作器将信息译码

要从余数 $r$ 构造出原来的数 $n$。因为 $\varphi(m)$ 与 $s$ 互素，所以存在自然数 $t \geqslant 1$ 使

```
t s ≡ 1 mod φ(m).        (2.95)
```

定理：$r^t \equiv n \bmod m$。

现在操作器恰是用 $m$ 去除 $r^t$，这里的余数就是要找的数 $n$。注意从 $m$ 的大小可知总有 $n < m$。

定理的证明：由费马-欧拉定理有 $n^{\varphi(m)} \equiv 1 \bmod m$。由 (2.95) 知存在一个整数 $k$ 适合 $ts = 1 + k\varphi(m)$。由此推出

```
r^t ≡ n^(st) ≡ n^(1 + kφ(m)) ≡ n mod m.
```

### 方法的安全性

如果某个"入侵者"要破译信息，那么他必须知道数 $t$，亦即 $\varphi(m) = (p-1)(q-1)$。为得到这个数，他必须确定数 $m$ 的素数分解式，而数 $m$ 对他是已知的。这个方法的诀窍就在于所选取的数 $p$ 和 $q$ 的大小，使得还没有任何计算机能在合理的时间内确定出 $p$ 和 $q$ 的因数。

因为计算机始终在发展，功能越来越强大，因此只有当我们不断地选取新的更大的数 $p$ 和 $q$ 才能保证方法的安全性。

源文进一步断言：如果我们找到某个将大整数快速分解为素数之积的算法，那么上面的方法将变得不安全。由于这个原因，所有在这个领域从事研究的数学家都被国家安全委员会严密地监控。

## 2.7.8.2 二次互反律

源文研究下列两个方程的可解性：

```
x^2 ≡ q mod p        (2.96)
x^2 ≡ p mod q        (2.97)
```

### 勒让德符号

```
( q / p ) := 1,  如 (2.96) 有解;
( q / p ) := −1, 如 (2.96) 无解.
```

### 高斯二次互反律（1796）

如果 $p$ 和 $q$ 是大于 2 的素数，那么有

```
( q / p ) = (−1)^((p−1)(q−1)/4) ( p / q ).
```

另外，对于勒让德符号，有

```
( −1 / p ) = (−1)^((p−1)/2),   ( 2 / p ) = (−1)^((p^2−1)/8).
```

历史评注：这个定理是欧拉（1722）、勒让德（1785）及高斯独立地凭借经验发现的。高斯给出第一个完全的证明。这个定律及其许多推广表述了我们熟知的数论中最深刻的基本性质。

例：设 $p = 4n + 1$ 是素数，其中 $n$ 是某个正自然数，那么方程

```
x^2 ≡ −1 mod p
```

有一个解，这是因为 $\left(\frac{-1}{p}\right)=1$。

### 高斯定理（1808）与高斯和

设 $\varepsilon := e^{2\pi i/p}$，其中 $p$ 是素数。那么有

```
Σ_{k=1}^{p−1} ( k / p ) ε^k = √p,   当 p ≡ 1 mod 4;
Σ_{k=1}^{p−1} ( k / p ) ε^k = i√p,  当 p ≡ 3 mod 4.
```

这种类型的和称为高斯和。高斯甚至花费很长时间去证明这个结果。
