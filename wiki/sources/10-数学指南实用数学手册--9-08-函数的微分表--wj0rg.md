## 0.8.1 初等函数的微分

### 表 0.35 一阶导数

| 函数 $f(x)$ | 导数 $f'(x)$ | 对实数的取值范围 | 对复数的取值范围 |
|---|---|---|---|
| $C$（常数） | $0$ | $x \in \mathbb{R}$ | $x \in \mathbb{C}$ |
| $x$ | $1$ | $x \in \mathbb{R}$ | $x \in \mathbb{C}$ |
| $x^{2}$ | $2x$ | $x \in \mathbb{R}$ | $x \in \mathbb{C}$ |
| $x^{n}$（$n = 1,2,\cdots$） | $nx^{n-1}$ | $x \in \mathbb{R}$ | $x \in \mathbb{C}$ |
| $\frac{1}{x}$ | $-\frac{1}{x^{2}}$ | $x \neq 0$ | $x \neq 0$ |
| $\frac{1}{x^{n}}$（$n = 1,2,\cdots$） | $-\frac{n}{x^{n+1}}$ | $x \neq 0$ | $x \neq 0$ |
| $x^{\alpha} = \mathrm{e}^{\alpha \ln x}$（$\alpha$ 为实数） | $\alpha x^{\alpha-1}$ | $x > 0$ | $x \neq 0,\ -\pi < \arg x < \pi$ |
| $\sqrt{x} = x^{\frac{1}{2}}$ | $\frac{1}{2\sqrt{x}}$ | $x > 0$ | $x \neq 0,\ -\pi < \arg x < \pi$ |
| $\sqrt[n]{x} = x^{\frac{1}{n}}$（$n = 2,3,\cdots$） | $\frac{\sqrt[n]{x}}{nx}$ | $x > 0$ | $x \neq 0,\ -\pi < \arg x < \pi$ |
| $\ln x$ | $\frac{1}{x}$ | $x > 0$ | $x \neq 0,\ -\pi < \arg x < \pi$ |

1. 也可把 $f'(x)$ 写成 $\frac{\mathrm{d}f(x)}{\mathrm{d}x}$ 或 $\frac{\mathrm{d}y}{\mathrm{d}x}$ 的形式。
2. $x \in \mathbb{R}$（$x \in \mathbb{C}$）表示对所有实数（复数）导数存在。记号 $k \in \mathbb{Z}$ 表示 $k = 0, \pm 1, \pm 2, \cdots$。

## 0.8.2 单变量函数的微分法则

### 表 0.37 微分法则

| 法则 | 以[[莱布尼茨记号]]表示的公式 |
|---|---|
| 加法法则 | $\frac{\mathrm{d}(f+g)}{\mathrm{d}x} = \frac{\mathrm{d}f}{\mathrm{d}x} + \frac{\mathrm{d}g}{\mathrm{d}x}$ |
| 与常数的乘积法则 | $\frac{\mathrm{d}(Cf)}{\mathrm{d}x} = C\frac{\mathrm{d}f}{\mathrm{d}x}$（$C$ 为常数） |
| 乘积法则 | $\frac{\mathrm{d}(fg)}{\mathrm{d}x} = \frac{\mathrm{d}f}{\mathrm{d}x}g + f\frac{\mathrm{d}g}{\mathrm{d}x}$ |
| 商法则 | $\frac{\mathrm{d}\left(\frac{f}{g}\right)}{\mathrm{d}x} = \frac{\frac{\mathrm{d}f}{\mathrm{d}x}g - f\frac{\mathrm{d}g}{\mathrm{d}x}}{g^{2}}$ |
| 链式法则 | $\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}z}\frac{\mathrm{d}z}{\mathrm{d}x}$ |
| 反函数法则 | $\frac{\mathrm{d}x}{\mathrm{d}y} = \frac{1}{\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)}$ |

脚注：1.4 中介绍了这些公式成立所需要的具体假设条件。这些法则对具有一个实变量或复变量的函数成立。例 1～例 6 对复变量 $x$ 也成立。

### 例题（例 1～例 6 与反函数例题）

加法法则（例 1）：

$$(\mathrm{e}^{x} + \sin x)' = (\mathrm{e}^{x})' + (\sin x)' = \mathrm{e}^{x} + \cos x, \quad x \in \mathbb{R}$$
$$(x^{2} + \sinh x)' = (x^{2})' + (\sinh x)' = 2x + \cosh x, \quad x \in \mathbb{R}$$
$$(\ln x + \cos x)' = (\ln x)' + (\cos x)' = \frac{1}{x} - \sin x, \quad x > 0$$

与常数的乘积法则（例 2）：

$$(2\mathrm{e}^{x})' = 2(\mathrm{e}^{x})' = 2\mathrm{e}^{x}, \quad (3\sin x)' = 3(\sin x)' = 3\cos x, \quad x \in \mathbb{R}$$
$$(3x^{4} + 5)' = (3x^{4})' + (5)' = 3 \cdot 4x^{3} = 12x^{3}, \quad x \in \mathbb{R}$$

乘积法则（例 3）：

$$(x\mathrm{e}^{x})' = (x)'\mathrm{e}^{x} + x(\mathrm{e}^{x})' = (1 + x)\mathrm{e}^{x}, \quad x \in \mathbb{R}$$
$$(x^{2}\sin x)' = (x^{2})'\sin x + x^{2}(\sin x)' = 2x\sin x + x^{2}\cos x, \quad x \in \mathbb{R}$$
$$(x\ln x)' = (x)'\ln x + x(\ln x)' = \ln x + 1, \quad x > 0$$

商法则（例 4）：

$$(\tan x)' = \left(\frac{\sin x}{\cos x}\right)' = \frac{(\sin x)'\cos x - \sin x(\cos x)'}{\cos^{2} x} = \frac{\cos^{2} x + \sin^{2} x}{\cos^{2} x} = \frac{1}{\cos^{2} x}$$

对所有使分母 $\cos x$ 不为 0 的 $x$，该导数均存在，即只需 $x \neq k\pi + \frac{\pi}{2}$，$k = 0, \pm 1, \pm 2, \cdots$。

链式法则（例 5、例 6）：

$$y = \sin 2x,\quad y = \sin z,\ z = 2x \Rightarrow y' = (\cos z) \cdot 2 = 2\cos 2x$$
$$y = \cos(3x^{4} + 5),\quad y = \cos z,\ z = 3x^{4} + 5 \Rightarrow y' = (-\sin z) \cdot 12x^{3} = -12x^{3}\sin(3x^{4} + 5)$$

反函数求导法则的应用：

$$y = \mathrm{e}^{x}\ (-\infty < x < \infty) \text{ 的反函数为 } x = \ln y\ (y > 0)$$
$$\frac{\mathrm{d}\ln y}{\mathrm{d}y} = \frac{\mathrm{d}x}{\mathrm{d}y} = \frac{1}{\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)} = \frac{1}{\mathrm{e}^{x}} = \frac{1}{y}, \quad y > 0$$

## 0.8.3 多变量函数的微分法则

偏导数：若函数 $f = f(x, w, \cdots)$ 依赖于 $x$ 和其他几个变量 $w, \cdots$，则偏导数

$$\frac{\partial f}{\partial x}$$

是通过把其他变量看成常数、把 $f$ 只看成关于 $x$ 的函数而对 $x$ 求导数得到的。

例 1：令 $f(x) = Cx$（$C$ 为常数），则 $\frac{\mathrm{d}f(x)}{\mathrm{d}x} = C$。同样，对于 $f(x,u,v) = (\mathrm{e}^{v}\sin u)x$，有

$$\frac{\partial f(x,u,v)}{\partial x} = \mathrm{e}^{v}\sin u$$

这是因为把 $u, v$，因此也就是把 $C = \mathrm{e}^{v}\sin u$ 看成了常数。

例 2：令 $f(x) = \cos(3x^{4} + C)$（$C$ 为常数），由 0.8.2 的例 6 有 $\frac{\mathrm{d}f(x)}{\mathrm{d}x} = -12x^{3}\sin(3x^{4} + C)$。在 $f(x,u) = \cos(3x^{4} + \mathrm{e}^{u})$ 中把 $u$（即 $C = \mathrm{e}^{u}$）看成常数，有 $\frac{\partial f(x)}{\partial x} = -12x^{3}\sin(3x^{4} + \mathrm{e}^{u})$。

例 3：令 $f(x,y) := xy$，则 $f_x(x,y) = y$，$f_y(x,y) = x$。

例 4：令 $f(x,y) := \frac{x}{y} = xy^{-1}$，则 $f_x(x,y) = y^{-1}$，$f_y(x,y) = -xy^{-2}$。

### 表 0.38 链式法则

$f = f(x,y)$，$f_x := \frac{\partial f}{\partial x}$，$f_y := \frac{\partial f}{\partial y}$

| 名称 | 公式 |
|---|---|
| 全微分 | $\mathrm{d}f = f_x\mathrm{d}x + f_y\mathrm{d}y$ |
| 链式法则 | $\frac{\partial f}{\partial w} = f_x\frac{\partial x}{\partial w} + f_y\frac{\partial y}{\partial w}$ |

脚注：在表 0.38 的链式法则中，把 $x = x(w, \cdots)$、$y = y(w, \cdots)$ 看成是 $w$ 以及（可能还有）其他变量的函数。

对 $f = f(x_1, \cdots, x_n)$，存在类似的法则，有全微分

$$\mathrm{d}f = f_{x_1}\mathrm{d}x_1 + \cdots + f_{x_n}\mathrm{d}x_n$$

当函数 $x_1, \cdots, x_n$ 依赖于 $w$ 以及其他变量时，链式法则为

$$\frac{\partial f}{\partial w} = f_{x_1}\frac{\partial x_1}{\partial w} + \cdots + f_{x_n}\frac{\partial x_n}{\partial w}$$

若 $x_1, \cdots, x_n$ 只是 $w$ 的函数，用 $\frac{\mathrm{d}}{\mathrm{d}w}$ 代替 $\frac{\partial}{\partial w}$，得到特殊形式

$$\frac{\mathrm{d}f}{\mathrm{d}w} = f_{x_1}\frac{\mathrm{d}x_1}{\mathrm{d}w} + \cdots + f_{x_n}\frac{\mathrm{d}x_n}{\mathrm{d}w}$$

### 链式法则的应用

例 5：令 $f(t) := x(t)y(t)$，由例 3 有

$$\mathrm{d}f = f_x\mathrm{d}x + f_y\mathrm{d}y = y\,\mathrm{d}x + x\,\mathrm{d}y$$
$$f'(t) = \frac{\mathrm{d}f}{\mathrm{d}t} = y\frac{\mathrm{d}x}{\mathrm{d}t} + x\frac{\mathrm{d}y}{\mathrm{d}t} = y(t)x'(t) + x(t)y'(t)$$

这就是乘积法则，因此可以把乘积法则看成是多变量函数链式法则的特例。

例 6：令 $f(t) := \frac{x(t)}{y(t)}$，由例 4 有

$$\mathrm{d}f = f_x\mathrm{d}x + f_y\mathrm{d}y = y^{-1}\mathrm{d}x - xy^{-2}\mathrm{d}y$$
$$f'(t) = \frac{x'(t)}{y(t)} - \frac{x(t)y'(t)}{y(t)^{2}} = \frac{x'(t)y(t) - x(t)y'(t)}{y(t)^{2}}$$

这正是商法则。
