# 《数学指南——实用数学手册》2.1.5 多项式的计算

## 概述

本页是《数学指南——实用数学手册》第 2.1 节「初等代数」下辖子节 **2.1.5「多项式的计算」**。内容为多项式的定义与四则运算的代数框架：多项式定义 (2.18)、多项式的相等、加法与乘法、带余除法 (2.19)(2.20)，以及用欧几里得算法求两多项式的最大公因子 (gcd)。全文共 5 个算例（例 1–例 5），公式编号 (2.18)–(2.20)。整体为教科书式的「定义—公式—算例」结构，属标准内容，内部自洽，无经验性主张，与同书他节无冲突。

## 定义：多项式 (2.18)

$n$ 次实系数（或复系数）多项式是一个表达式

```
a_0 + a_1 x + a_2 x^2 + ... + a_n x^n,    (2.18)
```

其中 $a_0,\cdots,a_n$ 是实（或复）数，且 $a_n \neq 0$。

脚注 1)：用严格形式化的数学表达，(2.18) 是一个抽象表达式；如果用固定的复数代入 $a_0,\cdots,a_n,x$，那么它将与复数相联系，此时也说 $a_0,\cdots,a_n,x$ 取复数值。

## 多项式的相等

按定义

```
a_0 + a_1 x + ... + a_n x^n = b_0 + b_1 x + ... + b_m x^m
```

当且仅当 $n = m$，并且 $a_j = b_j$（对所有 $j$）——亦即两个多项式有相同的次数和相同的系数。

## 加法与乘法（例 1）

通过合并次数相同的项、应用自然法则 (1.1.4) 进行这些运算。

```
(x^2 + 1) + (2x^3 + 4x^2 + 3x + 2) = 2x^3 + 5x^2 + 3x + 3,

(x + 1)(x^2 - 2x + 2) = x^3 - 2x^2 + 2x + x^2 - 2x + 2 = x^3 - x^2 + 2.
```

## 带余除法 (2.19)(2.20)

代替 $7 \div 2 = 3$ 余 $1$（即 $7 = 2\cdot 3 + 1$ 或 $\tfrac{7}{2} = 3 + \tfrac{1}{2}$），在多项式情形也可这样做。

设 $N(x)$ 和 $D(x)$ 是两个多项式，并设 $D(x)$ 的次数至少是 $1$。那么存在**唯一确定**的多项式 $Q(x)$ 和 $R(x)$ 使得

```
N(x) = D(x)Q(x) + R(x),    (2.19)
```

其中余项多项式 $R(x)$ 的次数严格小于分母 $D(x)$ 的次数。代替 (2.19) 也可写成

```
N(x)/D(x) = Q(x) + R(x)/D(x).    (2.20)
```

术语：$N(x)$ 是分子，$Q(x)$ 是两个多项式的商。

**例 2（无余项除法）**：对于 $N(x) := x^2 - 1$ 及 $D(x) := x - 1$，取 $Q(x) = x + 1$ 及 $R(x) = 0$，(2.19) 即被满足。实际上 $x^2 - 1 = (x-1)(x+1)$，这意味着 $\frac{x^2-1}{x-1} = x+1$。

**例 3（带余项除法）**：

```
(3x^4 - 10x^3 + 22x^2 - 24x + 10) / (x^2 - 2x + 3)
  = 3x^2 - 4x + 5 + (-2x - 5)/(x^2 - 2x + 3)
```

相应分解式与余项多项式：

```
3x^4 - 10x^3 + 22x^2 - 24x + 10
  = (x^2 - 2x + 3)(3x^2 - 4x + 5) + (-2x - 5)
R(x) = -2x - 5
```

长除法算式（竖式）：

```
 3x^4 - 10x^3 + 22x^2 - 24x + 10        (除法: 3x^4 ÷ x^2 = 3x^2)
 3x^4 -  6x^3 +  9x^2                    (乘法: (x^2 - 2x + 3)·3x^2)
----------------------------------------
       -4x^3 + 13x^2 - 24x + 10          (减法+除法: -4x^3 ÷ x^2 = -4x)
       -4x^3 +  8x^2 - 12x                (乘法: (x^2 - 2x + 3)·(-4x))
----------------------------------------
                5x^2 - 12x + 10          (减法+除法: 5x^2 ÷ x^2 = 5)
                5x^2 - 10x + 15          (乘法: (x^2 - 2x + 3)·5)
----------------------------------------
                      -2x - 5             (减法)
```

该方法概括为：除以最高项，与除式相乘，作减法，除以所得到的最高项，等等；当所得最高项不能再相除时，计算结束。

**例 4**：分解式

```
x^3 - 1 = (x - 1)(x^2 + x + 1)
```

可由下列算式得到：

```
x^3 - 1
x^3 - x^2
---------
      x^2 - 1
      x^2 - x
      -------
            x - 1
```

## 最大公因子（gcd）与欧几里得算法

设 $N(x)$ 和 $D(x)$ 是两个次数至少为 $1$ 的多项式。类似于 (2.19) 得到带余项的除法链：

```
N(x)  = D(x)Q(x)    + R_1(x),
D(x)  = R_1(x)Q_1(x) + R_2(x),
R_1(x) = R_2(x)Q_2(x) + R_3(x),  等等。
```

由关系式 $\deg(R_{j+1}) < \deg(R_j)$，得知经有限步后将在某一步余项多项式为零，亦即

```
R_m(x) = R_{m+1}(x)Q_{m+1}(x).
```

于是 $R_{m+1}(x)$ 是 $N(x)$ 和 $D(x)$ 的最大公因子。

**例 5**：对于 $N(x) := x^3 - 1$ 和 $D(x) := x^2 - 1$ 得到

```
x^3 - 1 = (x^2 - 1)x + x - 1,
x^2 - 1 = (x - 1)(x + 1).
```

因此 $x - 1$ 是 $x^3 - 1$ 和 $x^2 - 1$ 的最大公因子。

## 原文要点与主体归属

- 全部论断均针对「（实系数或复系数）多项式」这一对象；除带余除法与 gcd 的**存在唯一性**外，无经验性主张，无外部实验或文献支撑。
- 两条独立断言须分开归属：① 带余除法的**唯一性**（$Q,R$ 由 $N,D$ 唯一确定）；② **gcd 由末项非零余项给出**（$R_{m+1}$）。二者不可互相移用。
- 例 4 的竖式在原文中排版较简略（$x^3-1$ 的竖式行序似有跳跃），但结论 $x^3-1=(x-1)(x^2+x+1)$ 正确，属排版呈现问题而非数学错误。
