# 《数学指南——实用数学手册》1.5.9 在误差估计上的应用

## 来源定位

本节是《数学指南——实用数学手册》第 1.5 节「多元实变函数的导数」系列的第 9 个子节，紧接 1.5.8 节（n 阶变分与泰勒定理）。主题是把**自变量的误差**与**函数值的误差**定量地联系起来，属于 1.5.8 泰勒定理结论的直接应用性延伸。全节由五个板块组成：一元函数的误差估计、多变量函数的线性近似、复合函数的误差传播（链式法则误差形式）、三条误差传播法则示例（加法／乘法／除法）、以及高斯误差传播定律。

## 一元实变量函数

原书考虑函数

```text
y = f(x)
```

并规定：

- $\Delta x$ = 自变量 $x$ 的误差；
- $\Delta f = f(x + \Delta x) - f(x)$ = 函数值 $f(x)$ 的误差；
- $\dfrac{\Delta f}{f(x)}$ = 函数值 $f(x)$ 的相对误差。

由泰勒定理即得

```text
Δf = f′(x)Δx + (f″(x + ϑΔx)/2)(Δx)²,   0 < ϑ < 1
```

由此可得误差估计：

```text
|Δf − f′(x)Δx| ≤ (Δx)²/2 · sup_{0<η<1} |f″(x + ηΔx)|
```

### 例 1

对于 $f(x) := \sin x$，有 $f''(x) = -\sin x$，因此

```text
|Δf − Δx·cos x| ≤ (Δx)²/2
```

例如当 $\Delta x = 10^{-3}$ 时，有 $(\Delta x)^{2} = 10^{-6}$。

对于足够小的误差 $\Delta x$，一般使用近似公式

```text
Δf = f′(x)Δx
```

## 多变量函数

对于函数 $y = f(x_{1}, \cdots, x_{N})$，令

```text
Δf := f(x₁ + Δx₁, …, x_N + Δx_N) − f(x₁, …, x_N)
```

此时的近似公式是

```text
Δf = Σ_{j=1}^{N} (∂f(x)/∂x_j) Δx_j
```

> 原书注（校者）：原文把 $\sum_{j=1}^{N}$ 误为 $\sum_{k=1}^{N}$。

## 链式法则（误差传播形式）

对于复合函数 $H(\boldsymbol{x}) = F(f_{1}(\boldsymbol{x}), \cdots, f_{m}(\boldsymbol{x}))$，其中 $\boldsymbol{x} = (x_{1}, \cdots, x_{N})$，有

```text
ΔH = Σ_{k=1}^{m} (∂F/∂f_k)(f₁(x), …, f_m(x)) Δf_k
```

### 例 2（加法法则）

对于 $H(\boldsymbol{x})=\sum_{k=1}^{m}f_{k}(\boldsymbol{x})$，有

```text
ΔH = Σ_{k=1}^{m} Δf_k
```

即**绝对误差相加**。

### 例 3（乘法法则）

对于 $H(x)=\prod_{k=1}^{m}f_{k}(x)$，有

```text
ΔH/H(x) = Σ_{k=1}^{m} Δf_k/f_k(x)
```

即**相对对数误差相加**。

### 例 4（除法法则）

对于 $H(\boldsymbol{x}) = \dfrac{f(\boldsymbol{x})}{g(\boldsymbol{x})}$，有

```text
ΔH/H(x) = Δf/f(x) − Δg/g(x)
```

即**相对对数误差相减**。

## 误差传播的高斯定律

考虑函数

```text
z = f(x, y)
```

假设给定 $x$ 和 $y$ 的测量数据

```text
x₁, …, x_n   和   y₁, …, y_m
```

由此就能得到 $z$ 的值，其中 $z_{jk} = f(x_j, y_k)$。由定义可得平均值 $\bar{x}, \bar{y}$ 与方差 $\sigma_x^2, \sigma_y^2$：

```text
x̄ = (1/n) Σ_{j=1}^{n} x_j,    ȳ = (1/m) Σ_{k=1}^{m} y_k
σ_x² = 1/(n−1) Σ_{j=1}^{n} (x_j − x̄)²
σ_y² = 1/(m−1) Σ_{k=1}^{m} (y_k − ȳ)²
```

依照高斯的工作，对于足够大的 $n$ 和 $m$，有如下近似关系式：

```text
z̄ = f(x̄, ȳ)
σ_z² = f_x(x̄, ȳ)² σ_x² + f_y(x̄, ȳ)² σ_y²
```

这个关系式称为**高斯误差传播定律**。

## 关键要点

1. 一元误差估计的实质是把泰勒展开截断到一阶，并用 Lagrange 型余项给出二阶量级的界。
2. 小误差下 $\Delta f \approx f'(x)\Delta x$——这是所有后续法则的共同出发点。
3. 链式法则误差形式与求导版链式法则结构相同，但把「导数」换成「误差量」，语义不同。
4. 加法法则作用于绝对误差，乘法与除法法则作用于相对对数误差。
5. 高斯误差传播定律把误差传播从「确定性误差量」推广到「统计量（均值与方差）」，并以 $n, m$ 足够大为适用前提。

## 原文标注与转写疑点

- 多变量近似公式的求和指标：原文写作 $\sum_{k=1}^{N}$，校者注明应为 $\sum_{j=1}^{N}$（见 [[159节多变量近似公式求和指标原文讹误]]）。
- 一元误差定义句中「$\Delta f = f(x + \Delta x) - f(x) = f(x)$ 的函数值的误差」语句不通，疑为转写排版问题（见 [[159节一元误差定义句是否转写讹误]]）。
- 「足够小」「足够大」均未给出定量阈值（见 [[159节足够小与足够大的定量阈值]]）。
- 本节链式法则为误差传播版，与 1.5.3 求导版同名异构（见 [[159节链式法则误差版是否同名异物]]）。
