# 《数学指南——实用数学手册》0.9.5 不定积分表-4（条目 501–505）

## 概要

本文件是 0.9.5 节「积分表」的第四段续篇，覆盖第 **501–505 号积分**。它是既有已入库段落（342–500，见 [[entities/表095不定积分表-3]]）之后的直接延续，篇幅极小（5 条公式加 1 句交叉引用），但在结构上跨越了两个子节：

- **501**：属于 **0.9.5.4 含反三角函数的积分**的收尾条目，给出 `arccot` 型积分的降幂递推公式。
- **502–505**：构成新子节 **0.9.5.5 含反双曲函数的积分**的全部条目，覆盖 `arsinh`、`arcosh`、`artanh`、`arcoth` 四个反双曲函数的基本不定积分。

本段首次在 0.9.5 节中引入「含反双曲函数的积分」这一族，与已入库的 [[concepts/含双曲函数的积分]]（被积函数为双曲函数本身）形成对照。

## 原文公式（逐字保留）

```latex
501. \int \frac{\operatorname{arccot} \frac{x}{\alpha} \mathrm{d}x}{x^{n}}
     = -\frac{1}{(n-1)x^{n-1}} \operatorname{arccot}\frac{x}{\alpha}
       - \frac{\alpha}{n-1} \int \frac{\mathrm{d}x}{x^{n-1}(\alpha^{2}+x^{2})}
```

$(n \in \mathbb{N}, \text{参看第 498 个积分}).$

0.9.5.5 含反双曲函数的积分

```latex
502. \int \operatorname{arsinh}\frac{x}{\alpha} \mathrm{d}x
     = x \operatorname{arsinh}\frac{x}{\alpha} - \sqrt{x^{2}+\alpha^{2}}.
```

```latex
503. \int \operatorname{arcosh}\frac{x}{\alpha} \mathrm{d}x
     = x \operatorname{arcosh}\frac{x}{\alpha} - \sqrt{x^{2}-\alpha^{2}}
       \quad (|\alpha| < |x|).
```

```latex
504. \int \operatorname{artanh}\frac{x}{\alpha} \mathrm{d}x
     = x \operatorname{artanh}\frac{x}{\alpha} + \frac{\alpha}{2}\ln(\alpha^{2}-x^{2})
       \quad (|x| < |\alpha|).
```

```latex
505. \int \operatorname{arcoth}\frac{x}{\alpha} \mathrm{d}x
     = x \operatorname{arcoth}\frac{x}{\alpha} + \frac{\alpha}{2}\ln(x^{2}-\alpha^{2})
       \quad (|\alpha| < |x|).
```

## 结构梳理

| 编号 | 所属子节 | 被积函数 | 方法 | 定义域限制 |
|------|----------|----------|------|------------|
| 501 | 0.9.5.4 含反三角函数的积分 | $\operatorname{arccot}(x/\alpha)/x^{n}$ | 降幂递推（分部积分） | $n \in \mathbb{N}$，参看第 498 个积分 |
| 502 | 0.9.5.5 含反双曲函数的积分 | $\operatorname{arsinh}(x/\alpha)$ | 分部积分（$v = x$） | 无显式限制 |
| 503 | 0.9.5.5 | $\operatorname{arcosh}(x/\alpha)$ | 分部积分（$v = x$） | $|\alpha| < |x|$ |
| 504 | 0.9.5.5 | $\operatorname{artanh}(x/\alpha)$ | 分部积分（$v = x$） | $|x| < |\alpha|$ |
| 505 | 0.9.5.5 | $\operatorname{arcoth}(x/\alpha)$ | 分部积分（$v = x$） | $|\alpha| < |x|$ |

## 主要论断与结果

### 501 是「第 498 个积分」的下游递推

501 明确以「参看第 498 个积分」为出口：递推右端的余项 $\int \mathrm{d}x/[x^{n-1}(\alpha^{2}+x^{2})]$ 本身是另一个已给出的积分形式，因此 501 的实用价值依赖于对第 498 号条目的引用。第 498 号条目位于已入库的 342–500 段（见 [[entities/表095不定积分表-3]]），本源只以文字引用它，未重抄公式。

### 502–505 由分部积分（令 $v = x$）统一导出

四条反双曲函数积分均为标准的分部积分结果：取 $u$ 为反双曲函数、$\mathrm{d}v = \mathrm{d}x$，得 $\int u\,\mathrm{d}x = xu - \int x\,\mathrm{d}u$，其中 $\int x\,\mathrm{d}u$ 恰是初等积分。这一模式与 [[concepts/分部积分公式]] 一致，并与 [[findings/积分基本定理由分部积分令v等于1得到]] 所记录的技巧同源。详见 [[findings/反双曲函数积分可由分部积分令v等于x得到]]。

### 逐条求导验算（分析所得，非原文）

对五条公式逐条求导回到被积函数，**全部正确**：

- **501**：分部积分取 $u = \operatorname{arccot}(x/\alpha)$，$\mathrm{d}v = x^{-n}\mathrm{d}x$，$v = -1/((n-1)x^{n-1})$，$\mathrm{d}u = -\alpha\,\mathrm{d}x/(\alpha^{2}+x^{2})$，代回即得原式。
- **502**：$\frac{\mathrm{d}}{\mathrm{d}x}[x\operatorname{arsinh}(x/\alpha)] = \operatorname{arsinh}(x/\alpha) + x/\sqrt{x^{2}+\alpha^{2}}$；再减去 $\frac{\mathrm{d}}{\mathrm{d}x}\sqrt{x^{2}+\alpha^{2}} = x/\sqrt{x^{2}+\alpha^{2}}$，恰余 $\operatorname{arsinh}(x/\alpha)$。
- **503**：同理，$x\operatorname{arcosh}(x/\alpha)$ 的额外项为 $x/\sqrt{x^{2}-\alpha^{2}}$，被 $-\sqrt{x^{2}-\alpha^{2}}$ 的导数抵消。
- **504**：$x\operatorname{artanh}(x/\alpha)$ 导数的额外项为 $\alpha x/(\alpha^{2}-x^{2})$，被 $\frac{\alpha}{2}\ln(\alpha^{2}-x^{2})$ 的导数 $-\alpha x/(\alpha^{2}-x^{2})$ 抵消。
- **505**：$\operatorname{arcoth}$ 的导数为负，$x\operatorname{arcoth}(x/\alpha)$ 的额外项与 $\frac{\alpha}{2}\ln(x^{2}-\alpha^{2})$ 的导数同样相互抵消。

验算结论见 [[findings/095节501至505条目逐条求导验算正确]]。所用导数工具汇总于 [[concepts/反双曲函数的导数]]。

### 定义域条件与端点

503、504、505 分别给出 $|\alpha| < |x|$、$|x| < |\alpha|$、$|\alpha| < |x|$ 的限制，恰好排除使根式为零或对数发散的点 $|x| = |\alpha|$；502 未给出显式限制，因其被积函数在全实轴上都有定义。这些不等式的严格性（是否应含端点）留待核对，见 [[queries/095节反双曲函数积分定义域的端点条件]]。
