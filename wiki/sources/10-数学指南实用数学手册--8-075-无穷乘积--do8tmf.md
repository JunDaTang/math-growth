# 《数学指南——实用数学手册》0.7.5 无穷乘积

本节是手册 0.7 节（级数与乘积公式）之下的子节，主题是用**无穷乘积**表示若干初等函数与特殊函数。正文只有一句导引：无穷乘积的收敛性将在 1.10.6 中讨论；因此本节实际给出的是**结果表加若干例题**，不重复收敛性判据。收敛性的一般语境见 [[收敛]] 与 [[收敛域]]，无穷乘积的一般定义见 [[无穷乘积]]。

## 主表：函数的无穷乘积表示

| 函数 | 无穷乘积 | 发现者 | 收敛域 ($x \in \mathbb{C}$) |
|---|---|---|---|
| $\sin \pi x$ | $\pi x \prod_{k=1}^{\infty}\left(1 - \frac{x^2}{k^2}\right)$ | （欧拉，1734） | $\lvert x \rvert < \infty$ |
| $\pi/2$ | $\prod_{k=1}^{\infty}\frac{(2k)^2}{4k^2-1}$ | （沃利斯，1655） | （原文空缺） |
| $\Gamma(x+1)$ | $\prod_{n=1}^{\infty}\frac{(1 + 1/n)^x}{1 + x/n}$ | （欧拉） | $\lvert x \rvert < \infty$（$x \ne -1, -2, \cdots$） |
| $\Gamma(x+1)$ | $\lim_{k \to \infty}\frac{k!\,k^x}{(x+1)(x+2)\cdots(x+k)}$ | （高斯） | （表中与上一行合并） |
| $\Gamma(x+1)$ | $\mathrm{e}^{-Cx}\prod_{n=1}^{\infty}\frac{\mathrm{e}^{x/n}}{1 + x/n}$ | （魏尔斯特拉斯；$C$ 表示欧拉常数） | （表中与上一行合并） |
| $\zeta(x)$ | $\prod_{p}\left(1 - \frac{1}{p^{x}}\right)^{-1}$ | （欧拉¹⁾） | $\lvert x \rvert > 1$ |

表中几个结构细节需要保留：

- $\Gamma(x+1)$ 的三行在原文中共用一格收敛域：$\lvert x \rvert < \infty$（$x \ne -1, -2, \cdots$）。
- $\pi/2$ 行（沃利斯乘积）的收敛域在原文中为空。
- $\zeta(x)$ 行的发现者「欧拉」带脚注标记 1)，而脚注正文未出现在本节，参见 [[075节表格空缺与脚注缺失]]。这一乘积即 [[欧拉乘积公式]]，其收敛条件在源中写作 $\lvert x \rvert > 1$，与通常的实部条件写法不同，参见 [[欧拉乘积收敛条件是x绝对值大于1还是实部大于1]]。

## 进一步的几个例子

原文以五个恒等式作为补充。第一个给出平方因子乘积的特值，同时给出一个几何级数的乘积表示：

```math
\prod_{k=2}^{\infty}\left(1 - \frac{1}{k^2}\right) = \frac{1}{2},
\qquad
\prod_{k=0}^{\infty}\left(1 + x^{2^k}\right) = \frac{1}{1-x}
\qquad (x \in \mathbb{C},\ \lvert x \rvert < 1),
```

第二个是韦达（源中写作「韦达」，1579）关于 $2/\pi$ 的嵌套根式公式。注意原文中第二个与第三个因子被排成完全相同的式子：

```math
\sqrt{\frac{1}{2}}\ \sqrt{\frac{1}{2} + \frac{1}{2}\sqrt{\frac{1}{2}}}\ \sqrt{\frac{1}{2} + \frac{1}{2}\sqrt{\frac{1}{2}}}\ \cdots = \frac{2}{\pi}
\qquad (\text{韦达, 1579}),
```

该重复被记为转写疑点，见 [[075节韦达公式中重复的根式因子]] 与 [[韦达公式]]。

第三个把沃利斯型的平方因子乘积按偶数项与奇数项拆开，分别得到 $2/\pi$ 与 $\pi/4$：

```math
\prod_{k=1}^{\infty}\left(1 - \frac{1}{(2k)^2}\right) = \frac{2}{\pi},
\qquad
\prod_{k=1}^{\infty}\left(1 - \frac{1}{(2k+1)^2}\right) = \frac{\pi}{4},
```

第四个是用幂次逐步加深的乘积表示常数 $\mathrm{e}$：

```math
\left(\frac{2}{1}\right)\left(\frac{4}{3}\right)^{1/2}
\left(\frac{6 \cdot 8}{5 \cdot 7}\right)^{1/4}
\left(\frac{10 \cdot 12 \cdot 14 \cdot 16}{9 \cdot 11 \cdot 13 \cdot 15}\right)^{1/8} \cdots = \mathrm{e},
```

第五个把欧拉常数 $C$ 写成一个无穷乘积的结果；源中以 $\sqrt[k]{\mathrm{e}}$ 记 $\mathrm{e}^{1/k}$：

```math
\prod_{k=1}^{\infty}\frac{\sqrt[k]{\mathrm{e}}}{1 + 1/k} = \mathrm{e}^{C}
\qquad (\text{欧拉常数 } C = 0.577215\dots).
```

- 沃利斯乘积行的收敛域在原文中空缺；$\zeta(x)$ 行的脚注 1) 正文不在本节。
