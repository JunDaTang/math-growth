# 《数学指南——实用数学手册》1.5.5 对函数相关性的应用

## 出处与定位

本节（1.5.5）是《数学指南——实用数学手册》1.5 节「多元实变函数的导数」系列的第 5 个子节，前接 1.5.4「对微分算子的变换的应用」。前一节用链式法则与坐标变换处理微分算子，本节转向一个不同方向的应用：**多个函数之间的相关性（依赖关系）判别**。全节篇幅很短，由一条定义、一条定理、一个例题和一条脚注构成。

本节依赖的既有知识：[[concepts/偏导数]]（$f_j'$ 的构成）、[[concepts/多元CK类光滑函数]] 与 [[concepts/局部Ck类]]（$C^1$ 类前提）、[[concepts/雅可比矩阵]] 与 [[concepts/雅可比行列式]]（梯度矩阵与行列式的记法），以及 [[concepts/复合映射的线性化]]、[[concepts/多元链式法则]]（依赖关系本质上是一个复合映射 $F\circ(f_1,\dots,f_K)$）。

## 定义：函数相关性（依赖关系）

设 $f_k: G \to \mathbb{R}$ 是 $C^1$ 类函数，$k = 1, \dots, K+1$，其中 $G$ 是 $\mathbb{R}^N$ 的非空开集。称 $f_{K+1}$ **依赖于** $f_1, \dots, f_K$，当且仅当存在 $C^1$ 类函数 $F: \mathbb{R}^K \to \mathbb{R}$ 满足

```
f_{K+1}(x) = F(f_1(x), ..., f_K(x)) 对所有的 x ∈ G.
```

（原文此式加框，并以「对所有的 $x \in G$」结尾。）

## 定理：相关性秩条件

原文表述为：假设两个矩阵 $^{1)}$

```
(f_1'(x), ..., f_{K+1}'(x)) 与 (f_1'(x), ..., f_K'(x))
```

的秩是常数，等于某个 $r$，$1 \leqslant r \leqslant K$，则满足上述相关性关系式。

需要指出：该表述在字面上没有明确写出「两个矩阵的秩相等」这一连接，也没有说明这是充分条件、必要条件还是充要条件，详见下节「转写疑点」。

## 例题：$e^{x_1}$、$e^{x_2}$ 与 $e^{x_1+x_2}$

设 $f_1(x) := \mathrm{e}^{x_1}$，$f_2(x) := \mathrm{e}^{x_2}$，$f_3(x) := \mathrm{e}^{x_1+x_2}$，则有

```
f_1'(x) = (∂_1 f_1(x), ∂_2 f_1(x))^T = (e^{x_1}, 0)^T,   f_2'(x) = (0, e^{x_2})^T.
```

因为

```
det(f_1'(x), f_2'(x)) := e^{x_1} e^{x_2} ≠ 0,
```

所以对所有的 $x = (x_1, x_2) \in \mathbb{R}^2$ 有

```
rank(f_1'(x), f_2'(x)) = rank(f_1'(x), f_2'(x), f_3'(x)) = 2.
```

因此 $f_3$ 在 $\mathbb{R}^2$ 中依赖于 $f_1, f_2$。事实上可以得到明确的关系式

```
f_3(x) = f_1(x) f_2(x).
```

该例题是本节唯一的经验性验证：由行列式恒不为零推出秩恒为常数 $2 = K$，再套用秩条件得出相关性，并给出显式关系式。它只覆盖「依赖成立」的正向情形，未给出秩变化或两矩阵秩不等导致不依赖的反面例子。

## 脚注

脚注 1) 说明记号约定：「我们把 $f_j'(x)$ 写为一个列矩阵。」即 $f_j'(x)$ 是 $f_j$ 的 $N$ 个一阶偏导排成的 $N$ 列矩阵（列向量），因此 $(f_1'(x), \dots, f_K'(x))$ 是 $N \times K$ 矩阵。参见 [[concepts/梯度矩阵]]。

## 转写疑点

1. **定理表述疑有缺损**：完整写法通常应要求两个梯度矩阵的秩相等且为常数。当前文本缺少该连接，且未标明条件类型（充分／必要／充要）。见 [[queries/155节定理表述是否缺少秩相等条件]]。
2. **秩的取值**：$1 \leqslant r \leqslant K$；例题中 $r = 2 = K$（满秩情形符合该区间）。但「秩是常数，等于某个 $r$」对两个矩阵是否共用同一个 $r$ 未加区分。
3. 本节文本以例题与脚注收尾，未见「注」、图示或更多例题，是否还有未录入正文待确认。
