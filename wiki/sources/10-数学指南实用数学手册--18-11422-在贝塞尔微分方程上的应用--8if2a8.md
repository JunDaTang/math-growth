# 《数学指南——实用数学手册》1.14.22 在贝塞尔微分方程上的应用

## 概述

本节是《数学指南——实用数学手册》第 1.14 章（复分析、常微分方程与特殊函数部分）的一节，主题是**贝塞尔微分方程** (1.499) 的解结构，以及它在两个具体问题上的应用：单位圆盘上拉普拉斯算子的 Dirichlet 特征值问题 (1.500)，以及圆形薄膜的振动初边值问题 (1.501)。

本节把 1.14.20 建立的「奇异微分方程 + Frobenius 幂级数解法」一般理论直接落到贝塞尔方程上：先由指数方程确定在 $z=0$ 处的两个指数，再按 $\alpha$ 是否为整数分情形给出两个线性无关解（[[贝塞尔函数]] $J_\alpha$、$J_{-\alpha}$，或 $J_n$ 与[[诺伊曼函数]] $N_n$），最后用这组解构造圆盘上的特征函数系并展开解初边值问题。相关的通用概念见 [[正则奇点]]、[[指数方程-奇异微分方程]]、[[Frobenius幂级数解法]] 与 [[无穷远点奇性分析]]。

## 原文核心公式（保留原式）

贝塞尔微分方程：

```
z^2 w'' + z w' + (z^2 − α^2) w = 0                                   (1.499)
```

指数方程与两根：$\rho^2 - \alpha^2 = 0$，$\rho_1 = \alpha$，$\rho_2 = -\alpha$。通解为 $w = C_1 w_1 + C_2 w_2$。

贝塞尔函数：

```
J_α(z) := (z/2)^α · Σ_{k=0..∞} (−1)^k / [k! Γ(k+α+1)] · (z/2)^{2k}
```

诺伊曼函数（定义式）：

```
N_n(z) := (1/π) · [ ∂J_α(z)/∂α − (−1)^n ∂J_{−α}(z)/∂α ] _{α = n}
```

诺伊曼函数显式公式：

```
N_n(z) = (2/π)(C + ln z − ln 2) J_n(z)
         − (1/π) Σ_{k=0..n−1} [(n−k−1)! / k!] · (2/z)^{n−2k}
         − (1/π) Σ_{k=0..∞} [(−1)^k / (k!(n+k)!)] · (z/2)^{n+2k} · (H_{n+k} + H_k)
```

其中欧拉常数 $C = 0.5772\cdots$，$H_k := \sum_{r=1}^{k} 1/r$，$H_0 := 0$（见 [[调和数]]、[[欧拉]]）。

特征值问题 (1.500)：$D := \{(x,y) \in \mathbb{R}^2 \mid x^2 + y^2 < 1\}$ 为开单位圆盘，

```
−v_xx − v_yy = λ v ,   在 D 上
v = 0 ,               在 ∂D 上                                        (1.500)
```

其特征解为

```
v_km(x, y) := 1 / (√π |J_k′(λ_km)|) · J_k(λ_km r) · e^{i k φ} ,   λ = λ_km
```

其中 $k = 0, 1, \cdots$，$m = 1, 2, \cdots$，且 $x = r\cos\varphi$、$y = r\sin\varphi$；$0 < \lambda_{k1} < \lambda_{k2} < \cdots$ 是 $J_k$ 的零点。

薄膜振动问题 (1.501)（取 $c = 1$）：

```
(1/c^2) u_tt − u_xx − u_yy = 0 ,   (x, y) ∈ D, t > 0
u = 0 ,                           在 ∂D 上（边界值）
u(x, y, 0) = u_0(x, y) ,  u_t(x, y, 0) = u_1(x, y)  （初始值）          (1.501)
```

其唯一解为

```
u(x, y) = Σ_{k,m} (a_km cos(λ_km t) + b_km sin(λ_km t)) v_km(x, y)
a_km = (u_0, v_km) ,   λ_km b_km = (u_1, v_km)
```

标量积定义为 $(u, v) := \int_D u(x,y) v(x,y)\, \mathrm{d}x\, \mathrm{d}y$。

## 内容结构

1. **奇点结构**：$z = 0$ 处为正则奇点，$z = \infty$ 处为非正则奇点；指数方程给出 $\rho_{1,2} = \pm\alpha$。详见 [[贝塞尔方程1499的奇点与指数方程]]。
2. **情形 1（$\alpha$ 不是整数）**：$w_1 = J_\alpha$、$w_2 = J_{-\alpha}$ 线性无关。详见 [[情形1非整数阶两解Jalpha与J负alpha]]、[[贝塞尔函数Jalpha幂级数对所有复数收敛]]。
3. **情形 2（$\alpha = n$ 为整数）**：$J_{-n}(z) = (-1)^n J_n(z)$，故 $J_{-n}$ 与 $J_n$ 线性相关，改取 $w_1 = J_n$、$w_2 = N_n$。详见 [[情形2整数阶Jn与J负n线性相关]]、[[诺伊曼函数定义与显式公式]]。
4. **应用一：Dirichlet 特征值问题**：特征解 $v_{km}$，且 $\{v_{km}\}$ 在 $L_2(D)$ 中构成完备规范正交系。详见 [[单位圆盘特征值问题1500的特征解vkm]]、[[vkm在L2D构成完备规范正交系]]。
5. **应用二：薄膜振动**：定理断言光滑连续初值 $u_0, u_1: \bar{D} \to \mathbb{R}$ 下 (1.501) 有唯一解，且解由考虑 (1.500)、「利用傅里叶方法」得到。详见 [[薄膜振动问题1501唯一解由傅里叶方法给出]]、[[傅里叶方法]]。

## 待澄清之处

- $\alpha$ 的取值条件写作「Re $\alpha \geqslant 0$」，而两解 $J_\alpha$、$J_{-\alpha}$ 的定义与区分又依赖 $\alpha$ 是否为整数，边界情形（如 $\alpha = 0$、$\mathrm{Re}\,\alpha = 0$ 且非整数）在正文中未单列讨论。
- 收敛性表述在同一段中先写「对所有复数 $z \in C$」，后又写「对所有复数 $z \in \mathbb{C}$」，字体不一致，见 [[11422节收敛性处C与黑板体C混用]]。
- 振动解求和写作 $\sum_{k,m=0}^{\infty}$，但 $v_{km}$ 的下标范围为 $k = 0,1,\cdots$、$m = 1,2,\cdots$，见 [[11422节振动解求和下标起点矛盾]]。
- 特征解写作 $\lambda = \lambda_{km}$，而 $\lambda_{km}$ 又是 $J_k$ 的零点，见 [[11422节特征值疑应为lambda-km平方]]。
- 图 1.208(a)(b) 的图像内容无法加载，见 [[11422节图1208不可加载]]。
