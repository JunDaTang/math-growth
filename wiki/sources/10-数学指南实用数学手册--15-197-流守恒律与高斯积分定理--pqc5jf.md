# 《数学指南——实用数学手册》1.9.7 流、守恒律与高斯积分定理

本节属于第 1.9 章「向量分析与物理学领域」，以 [[concepts/高斯定理]]（散度定理）为枢纽工具，从「质量平衡的基本方程」出发，依次推出液体流（连续性方程）、电流与热流（热传导方程）三类守恒型方程。全节以手册式陈述为主，除热流部分给出简短的动机推导外，高斯定理、体积的导数与 (1.166) 均只列结论，未给证明与出处。

## 高斯定理（散度定理）

设 $D$ 是 $\mathbb{R}^3$ 中的有界区域，具有逐段光滑的边界 $^{1)}$ 及外法线单位向量 $\boldsymbol{n}$（图 1.103）；$\boldsymbol{J}$ 为 $\bar{D}$ 上的 $C^1$ 类向量场，则

```
∫_D div J dx = ∫_{∂D} J_n dF
```

## 体积的导数 (1.165)

设 $g$ 是在点 $P$ 的一个邻域内连续的一实值函数，则

```
g(P) = lim_{n→∞} ( ∫_{D_n} g(x) dx ) / ( meas D_n )        (1.165)
```

其中 $(D_n)$ 是[[concepts/容许区域]]（例如球）序列，均包含点 $P$，且当 $n \to \infty$ 时直径趋于零；$\mathrm{meas}\,D_n$ 表示[[concepts/勒贝格测度]]。(1.165) 右边的表达式称为体积的导数。

## 质量平衡的基本方程 (1.166)

```
ρ_t + div J = F,  在 Ω 上                                       (1.166)
```

### 动机

令 $D$ 为参考区域 $\Omega$ 的子区域，$\Omega$ 中有若干能相互起化学反应的物质 $S,\cdots$。定义：

```
A(t)  为在时刻 t，D 中化学物质 S 的质量
B(t)  为在时间段 [0, t] 内流出 D 外的物质 S 的质量
C(t)  为在时间段 [0, t] 内在 D 中由化学反应生成的物质 S 的质量
```

质量守恒律推出

```
A(t+Δt) − A(t) = −( B(t+Δt) − B(t) ) + ( C(t+Δt) − C(t) )
```

除以 $\Delta t$ 并取极限 $\Delta t \to 0$，得

```
A′(t) = −B′(t) + C′(t)                                          (1.167)
```

设这些量可用密度描述：

```
A(t)   = ∫_D ρ(x,t) dx
B′(t)  = ∫_{∂D} J_n dF
C′(t)  = ∫_D F(x,t) dx
```

物理学中使用的符号：

```
ρ(x,t)  在时刻 t 时在点 x 处的质量密度（单位体积的质量）
J(x,t)  在时刻 t 时在点 x 处的质量流的通量密度向量（单位面积与时间的质量）
F(x,t)  在时刻 t 时在点 x 处产生物质的力密度（单位体积单位时间生成的质量）
```

高斯定理的基本性质在于

```
B(t) = ∫_{∂D} J_n dF = ∫_D div J dx
```

即边界积分可以写成体积积分。因此由 (1.167) 可得

```
∫_D ρ_t dx = −∫_D div J dx + ∫_D F(x,t) dx
```

再由体积的导数即得 (1.166)。

## 液体流 (1.168)(1.169)

若 $\boldsymbol{v}=\boldsymbol{v}(x,t)$ 是化学物质 $S$ 在液体中流动形成的速度场，则 (1.166) 对通量密度向量成立

```
J = ρ v                                                          (1.168)
```

若没有物质产生，则得到所谓的连续性方程：

```
ρ_t + div(ρ v) = 0                                               (1.169)
```

不可压缩液体的一个特例由「$\rho=$ 常量」给出，由此可得 $\mathrm{div}\,\boldsymbol{v} \equiv 0$，这说明不可压缩液体的体积不变。

## 电流

如果把质量换成电荷，且没有电荷生成，则得到关于电荷密度 $\rho$ 的 (1.169)。

## 热流 (1.170)

热流的基本方程是

```
s μ T_t − κ ΔT = F                                               (1.170)
```

其中 $T(x,t)$ 表示在时刻 $t$ 时在点 $x$ 处的温度，$F(x,t)$ 表示时刻 $t$ 在点 $x$ 放热的功率密度（单位时间内单位体积产生的热量）；常量 $\mu, s, \kappa$ 分别表示质量密度、比热容与热传导系数。

### 动机

考虑区域 $\Omega$ 中体积为 $\Delta V$ 的一小片区域，在时刻 $t$，$\Omega$ 中的热量记为 $Q(t)$。一级近似下有

```
Q(t) = ρ(x,t) ΔV            （ρ(x,t) 为时刻 t 在点 x 处的热密度）
```

对于热量的改变 $\Delta Q$ 与温度的改变 $\Delta T$，有

```
ΔQ = s μ ΔV ΔT              （比热容 s 的定义方程）
```

令 $\Delta Q = Q(t+\Delta t) − Q(t)$、$\Delta T = T(x,t+\Delta t) − T(x,t)$，则有

```
( ρ(x,t+Δt) − ρ(x,t) ) / Δt = s μ ( T(x,t+Δt) − T(x,t) ) / Δt
```

取极限 $\Delta t \to 0$，得

```
ρ_t = s μ T_t
```

根据傅里叶（Fourier, 1768—1830）的结论，可得热通量密度向量的一级近似

```
J = −κ grad T
```

这说明 $\boldsymbol{J}$ 正交于等温面、与温度的差成正比、指向温度下降的方向。把 $\rho_t$ 与 $\boldsymbol{J}$ 的上述表示代入平衡方程 (1.166)，就得到 (1.170)。
