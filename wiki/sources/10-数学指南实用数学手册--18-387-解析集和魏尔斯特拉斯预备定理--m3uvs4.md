# 《数学指南——实用数学手册》3.8.7 解析集和魏尔斯特拉斯预备定理

## 小节定位

本节是《数学指南——实用数学手册》3.8 代数几何学（[[10-数学指南实用数学手册--8-38-代数几何学--1ojbsmq]]）下的最小子节点之一，主题为**局部解析几何**：先给出解析集与解析簇的定义，再把概念迁移到光滑流形，最后陈述本节主定理——[[魏尔斯特拉斯预备定理]]。全节篇幅短小，属手册式的定义与定理汇编，**不含任何证明**。

本节与 wiki 中既有的代数曲线、亏格、奇点理论条目构成互补：既有内容偏「代数曲线与整体不变量」一侧，本节补上「局部解析集与零点集正规化」一侧。

## 一、解析集的定义

原文先给出提要句「解析集是有限个全纯函数的局部零点集」，随后给出正式定义。逐字保留：

```text
定义  称 n 维复空间 C^n 的一个子集 X 为解析的，
如果对每个点 x₀ ∈ X ，存在一个 z₀ 的开集 ∪ 和有限个全纯函数
f₁,…,f_k : ∪ ⩽ C^n → C ，使得 X ∩ U 是方程组
    f₁(z)=0, …, f_k(z)=0,  z ∈ U
的所有解的集合。
```

原文用方框标出方程组；此处以纯文本转录。**注意**：原文中的开集记号写作并集符号 $\cup$，且函数记法 `f_i: ∪ ≤ C^n → C` 明显乱码，按文义应为 `f_i: U ⊂ ℂⁿ → ℂ`。详见 [[387节解析集定义与例369的OCR讹误]]。

关键点：

- 定义是**局部**的：只要求在每个点 $x_0$ 的某个开邻域 $U$ 上成立；
- 函数个数 $k$ 有限，且要求是**全纯函数**（见 [[全纯函数]]）；
- 该定义是本节一切后续内容（解析簇、[[魏尔斯特拉斯预备定理]]）的出发点。

## 二、解析簇

原文一句话给出定义：

```text
解析簇  称不可约解析集为解析簇 ¹⁾ 。
```

即解析簇 = 不可约（irreducible）的解析集，它是可约解析集分解出的「分支」概念。原文在该定义处带脚注标记 `1)`，但该脚注**未落地**，与 3.8 章其他小节反复出现的同一类抽取缺陷一致，详见 [[387节解析簇脚注标记1未落地]]。

## 三、概念到光滑流形的迁移

原文指出：

```text
由于一个光滑流形 M 局部地同构于 C^n 中的一个开集，
故而解析集的概念自然地转移到 M 上。
```

这是纯过渡性陈述，未给出细节或证明。其作用是把 $\mathbb{C}^n$ 中定义的解析集推广为一般复流形（乃至 [[黎曼面]]）上的局部对象，从而与 wiki 中既有的 [[黎曼面]]、[[单值化定理]] 语境衔接。

## 四、因式分解问题与 sin z 例

原文以方程 (3.69) 说明「因式分解能把零点问题化简」的思路：

```text
例：方程
    sin z = 0,  z ∈ ℂ,                                  (3.69)
因为 sin z = z(1 - z²/31 + ⋯) ，故有因式分解
    z g(z) = 0,  z ∈ ℂ,
其中 g(0) ≠ 0 。因此原来的问题 (3.69) 在充分小的原点的邻域中
等价于更加简单的方程 z = 0 。
```

**注意**：原文将阶乘 $3!$ 讹排为 `31`（即写成 $1 - z^{2}/31$），按标准展开应为 $1 - z^{2}/3!$。详见 [[387节解析集定义与例369的OCR讹误]]。

这里的要点是：$\sin z$ 在原点有 $k=1$ 阶零点，抽出的因子 $z$ 正是「以 $t^k$ 开始」的最低次项，剩余因子 $g(z)$ 在原点非零（即为单位）。这正是 [[魏尔斯特拉斯预备定理]] 的雏形。

## 五、一般因式分解与魏尔斯特拉斯多项式

原文把上述例子推广为一般问题：

```text
更一般地，我们要对方程
    f(z,t) = 0,  z ∈ ℂ^{n-1}, t ∈ ℂ, n ≥ 1
寻找一个形如
    f(z,t) = p(z,t) g(z,t),  g(0,0) ≠ 0                (3.70)
的因式分解，其中全纯函数 g: V ⩽ ℂ^n → ℂ 在原点的一个邻域 V 上定义，
并见是一个 t 的多项式。
    p(z,t) := t^k + a_{k-1}(z) t^{k-1} + ⋯ + a_1(z) t + a_0(z),  k ≥ 1 。
系数 a_1,…,a_{k-1} 假设在原点的一个邻域中全纯。
```

结构化的对象为 [[魏尔斯特拉斯多项式]]：

$$p(z,t) := t^k + a_{k-1}(z) t^{k-1} + \dots + a_1(z) t + a_0(z), \quad k \ge 1,$$

即关于 $t$ 的首一多项式，其系数 $a_i(z)$ 在原点邻域全纯；分解式 (3.70) 中的 $g$ 是原点处非零的全纯函数（单位）。

原文存在两处表述问题：其一，「并见是一个 $t$ 的多项式」语义不通，按文义应为「并且 $p$ 是一个 $t$ 的多项式」；其二，系数列表只列出 $a_1,\dots,a_{k-1}$，**漏掉 $a_0$**，而按 $p$ 的定义应含 $a_0$。详见 [[387节预备定理陈述与系数列表讹误]]。

## 六、魏尔斯特拉斯预备定理

本节主定理，逐字保留：

```text
魏尔斯特拉斯预备定理
设 f: U ⩽ ℂ^n → ℂ 在原点的邻域 U 中全纯，使得函数
w = f(0,t) 是一个以项 t^k 开始的幂级数。
则存在一个唯一确定的形如 (3.70) 的分解。
```

定理给出的是**存在唯一性**断言：只要 $f(0,t)$ 的最低次非零项是 $t^k$（即 $f$ 关于 $t$ 在原点处为 $k$ 阶），就能把 $f$ 唯一地分解为「魏尔斯特拉斯多项式 × 单位」。

关键限定与证据强度：

- 定理**无证明**，且未给出文献出处，属手册条目惯例；作为标准数学事实可靠。
- 陈述中「函数 $w = f(0,t)$」的 $w$ 记号突兀且未被使用，疑为乱码或冗余，详见 [[387节预备定理陈述与系数列表讹误]]。
- 唯一性只在「形如 (3.70)」的规范分解类中成立，不能外推为任意因式分解的唯一性。

**归属边界**：上述解析集、解析簇、式 (3.69)、式 (3.70)、魏尔斯特拉斯多项式与预备定理的全部陈述，均只归属于本小节（3.8.7）。不得把这些陈述或其中的性质移用给同章其他主体，例如 3.8.3 节的魏尔斯特拉斯 G 函数（见 [[魏尔斯特拉斯G函数]]）。
