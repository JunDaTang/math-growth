# 《数学指南——实用数学手册》2.1.7 部分分式分解

## 概览

本节是《数学指南——实用数学手册》2.1「初等代数」下的第七个子节，主题为**部分分式分解**：用多项式与形如

```
A / (x − a)^k
```

的表达式给出有理函数的加法分解式。全节结构为「基本思想与待定系数示例 → 两种求系数方法 → 最低项有理函数的定义 → 部分分式分解定理 → 实系数情形 → 一般有理函数的欧几里得算法约化 → 复数情形算例 → 一句 Mathematica 说明」。

## 核心公式 (2.30)

为分解 $f(x) := \dfrac{x}{(x-1)(x-2)^2}$，从假设

```latex
f(x) = \frac{A}{x-1} + \frac{B}{x-2} + \frac{C}{(x-2)^{2}}
```

出发，两边乘以分母 $(x-1)(x-2)^2$ 得

```latex
x = A(x-2)^{2} + B(x-1)(x-2) + C(x-1).          \tag{2.30}
```

式 (2.30) 是本节的枢纽：两种求系数方法都从它出发。

## 方法一：比较系数

展开 (2.30)：

```latex
x = A(x^{2} - 4x + 4) + B(x^{2} - 3x + 2) + C(x - 1).
```

比较 $x^{2}$、$x$ 及常数项 1 的系数，得线性方程组

```latex
0 = A + B,      1 = -4A - 3B + C,      0 = 4A + 2B - C.
```

该方程组有解

```
A = 1,  B = -1,  C = 2.
```

## 方法二：代入特殊值

在 (2.30) 中取 $x = 2, 1, 0$，产生线性方程组

```latex
x = 2:\; 2 = C;      x = 1:\; 1 = A;      x = 0:\; 0 = 4A + 2B - C.
```

有解

```
A = 1,  C = 2,  B = -1.
```

两种方法给出同一组系数。原书评价：**通常，方法二要快一些。**

## 最低项有理函数（定义）

最低项有理函数是指表达式

```latex
f(x) := \frac{N(x)}{D(x)},
```

其中 $N$ 和 $D$（分别是分子和分母）是**复系数多项式**，满足条件

```latex
0 \leqslant \deg(N) < \deg(D).
```

## 分母的零点分解

设分母 $D$ 的两两互异的零点是 $x_1, \cdots, x_r$，其重数分别为 $\alpha_1, \cdots, \alpha_r$，则 $D$ 有表达式

```latex
D(x) = (x - x_1)^{\alpha_1} \cdots (x - x_r)^{\alpha_r}.
```

这里的重数概念直接沿用 [[concepts/多项式的零点与重数|多项式的零点与重数]]；分母能如此完全分解，以 [[concepts/代数学基本定理|代数学基本定理]] 为背景。

## 定理：部分分式分解

设 $f$ 是一个最低项有理函数。对于所有复数 $x \neq x_1, \cdots, x_r$ 有分解式

```latex
f(x) = \sum_{j=1}^{r} \left( \sum_{\beta=1}^{\alpha_j} \frac{A_{j\beta}}{(x - x_j)^{\beta}} \right),
```

其中复数 $A_{j\beta}$ **唯一确定**。

**实系数情形：** 如果 $N$ 和 $D$ 有实系数，那么 $D$ 的零点以复数共轭的形式成对出现且重数相同。此时对应的系数 $A_{j\beta}$ 也是复数共轭的。该结论以 [[concepts/实系数多项式共轭零点定理|实系数多项式共轭零点定理]] 为前提。

**系数计算：** 系数 $A_{j\beta}$ 总是可以应用上述两种方法之一计算。

## 一般有理函数：欧几里得算法约化

如果 $\deg(N) \geqslant \deg(D)$（即有理函数非最低项），那么欧几里得算法（参看 2.1.5）产生分解式

```latex
\frac{N(x)}{D(x)} = Q(x) + \frac{R(x)}{D(x)},
```

其中 $Q(x)$ 为多项式，$R(x)/D(x)$ 为最低项有理函数。这一步把任意有理函数的分解归约到最低项情形，所用工具即 [[concepts/欧几里得算法-多项式|欧几里得算法（多项式）]]。

## 例（复数情形）

```latex
\frac{x^{2}}{x^{2} + 1} = 1 - \frac{1}{x^{2} + 1} = 1 - \frac{1}{2\mathrm{i}} \left( \frac{1}{x - \mathrm{i}} - \frac{1}{x + \mathrm{i}} \right).
```

此例演示两件事：先用多项式除法（此处直接观察得商 $1$）分出多项式部分，再把最低项部分按分母的复零点 $\pm \mathrm{i}$ 拆成一次因子分式。

## 证据强度与结构说明

本节是教科书式的「定义—定理—算法—举例」结构：方法是**构造性演示加已验证算例**（两种方法得同一组系数 $A=1, B=-1, C=2$），可视为可靠但非独立的验证。定理的**唯一性**断言与**实系数时系数共轭**断言在本节内均**未给出证明**，属权威教科书陈述级别。原书引用 2.1.5（多项式的计算）作为欧几里得算法的出处，该小节已入库，见 [[sources/10-数学指南实用数学手册--10-215-多项式的计算--15slxr5|2.1.5 多项式的计算]]。
