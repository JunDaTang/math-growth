# 《数学指南——实用数学手册》6.3.5 参数估计的最大似然方法

## 小节定位

本节是 6.3 数理统计中承接 [[参数估计]] 主题的方法性小节，位置在 6.3.2（重要的估计量）与 6.3.3（正态分布测量值的研究）之后。全节介绍**最大似然法**：通过求解一族方程（连续型为 (6.37)，离散型为 (6.38)）获得未知参数的**最大似然估计值**。开篇给出的定位是：

> 最大似然法是数理统计中的基本方法，这种方法使获得某种意义下最优的未知参数的估计成为可能。

## 连续型随机变量：最大似然方程组 (6.37)

设 $\varphi = \varphi(x, \boldsymbol\beta)$ 是随机变量 $X$ 的概率密度，它依赖于参数 $(\beta_1, \cdots, \beta_k)$，简记为 $\boldsymbol\beta$。则最大似然估计值由下列方程组解得（$x_1, \cdots, x_n$ 为观测值）：

```latex
\sum_{j=1}^{n} \frac{1}{\varphi(x_j, \boldsymbol\beta)}
  \frac{\partial \varphi(x_j, \boldsymbol\beta)}{\partial \beta_r} = 0,
\quad r - 1, \dots, k,   \tag{6.37}
```

原书 (6.37) 用方框标出。式中 `r - 1, …, k` 疑为 `r = 1, …, k` 之误，详见 [[635节最大似然方程组中r减1疑为r等于1]]。

## 脚注 1)：名称来源与似然函数

原书以脚注 1) 解释「最大似然」这一名称的来历：对于所谓的**似然函数**

```latex
L = \varphi(x_1, \beta)\,\varphi(x_2, \beta) \cdots \varphi(x_n, \beta),
```

条件

```latex
L \stackrel{!}{=} \max
```

导出方程

```latex
\frac{\partial L}{\partial \beta_r} = 0, \quad r = 1, \dots, k,
```

而它们除以 $L$ 后就等价于 (6.37)。这一脚注把「极大化联合密度」与「求解 (6.37)」两种表述联系起来，见 [[似然函数]]。

## 正态分布的特例

文中取正态分布的概率密度

```latex
\varphi(x, \mu, \sigma) = \frac{1}{\sigma\sqrt{2\pi}}\,\mathrm{e}^{-(x-\mu)^2 / 2\sigma^2},
```

即均值为 $\mu$、标准差为 $\sigma$ 的正态分布密度。因 $\beta_1 = \mu$、$\beta_2 = \sigma$，其偏导为

```latex
\frac{\partial \varphi}{\partial \mu} = \frac{\mu - x}{\sigma^2}\,\varphi,
\qquad
\frac{\partial \varphi}{\partial \sigma}
  = \left(-\frac{1}{\sigma} + \frac{(\mu - x)^2}{\sigma^3}\right)\varphi,
```

故方程组 (6.37) 相当于

```latex
\sum_{j=1}^{n} \left(\mu - x_j\right) = 0,
\qquad
-\frac{n}{\sigma} + \sum_{j=1}^{n} \frac{\left(x_j - \sigma\right)^2}{\sigma^3} = 0.
```

由此得到最大似然估计值（原书以方框标出）：

```latex
\mu = \frac{1}{n} \sum_{j=1}^{n} x_j,
\qquad
\sigma^2 = \frac{1}{n} \sum_{j=1}^{n} (x_j - \mu)^2.
```

第二个方程分子中的 $(x_j - \sigma)^2$ 疑为 $(x_j - \mu)^2$，详见 [[635节正态分布第二方程中x_j减sigma疑为x_j减mu]]。

**与 6.3.2 节的对照**：这里 $\sigma^2$ 的系数是 $1/n$，属于**有偏**估计；而 6.3.2 节给出的无偏估计量 $S^2 = \frac{1}{n-1}\sum (x_j - M)^2$ 用系数 $1/(n-1)$。两者并列见 [[估计量的无偏性]] 与 [[方差的估计量S2]]。

## 离散型随机变量：最大似然方程组 (6.38)

设随机变量 $X$ 分别以概率 $p_1(\boldsymbol\beta), \cdots, p_k(\boldsymbol\beta)$ 取有限多个值 $a_1, \cdots, a_k$。用 $h_j$ 表示 $a_j$ 在[[变列与顺序统计量序列|变异序列]] $x_1, \cdots, x_n$ 中出现的[[频率]]。则最大似然估计值 $\beta_r = \beta_r(x_1, \cdots, x_k),\; r = 1, \cdots, k$，可由方程组

```latex
\sum_{j=1}^{k} \frac{h_j}{p_j(\boldsymbol\beta)}
  \frac{\partial p_j(\boldsymbol\beta)}{\partial \beta_r} = 0,
\quad r = 1, \dots, k   \tag{6.38}
```

解得，这里 $h_1 + \cdots + h_k = 1$。式中估计值的自变量下标写作 $x_1, \cdots, x_k$，疑应为 $x_1, \cdots, x_n$，详见 [[635节离散型估计自变量下标及泊松例求和上限疑点]]。

## 例 2：伯努利型（概率 $p$ 由频率估计）

假设事件 $A$ 发生的概率为 $p$，令

```latex
X := \begin{cases} 1, & A \text{ 发生}, \\ 0, & A \text{ 不发生}, \end{cases}
```

则 $X$ 是随机变量，$P(X=1)=p$，$P(X=0)=1-p$，只含一个参数 $\beta = p$。由 (6.38) 得

```latex
\frac{h_1}{p} - \frac{h_2}{1-p} = 0, \quad h_1 + h_2 = 1.
```

由此得最大似然估计值

```latex
p = h_1.
```

即**概率 $p$ 可以由 $A$ 发生的频率 $h_1$ 来估计**。这一结论与 6.2.5 节伯努利模型中频率与概率的关系相呼应。

## 例 3：泊松型（参数 $\beta$ 的估计为样本均值）

设随机变量 $X$ 以概率

```latex
p_j := \frac{\beta^j}{j!}\,\mathrm{e}^{-\beta}, \quad j = 0, 1, \dots
```

取值 $j = 0, 1, \cdots$，即 $X$ 服从[[泊松分布]]。若用 $h_j$ 表示 $j$ 在 $X$ 的观测值 $x_1, \cdots, x_n$ 中出现的频率，则 $\beta$ 的最大似然估计值为

```latex
\beta = \frac{1}{n} \sum_{j=1}^{n} x_j.   \tag{6.39}
```

**原文推理**：此处方程 (6.38) 为

```latex
\sum_{j=0}^{n} \left(\frac{j}{\beta} - 1\right) h_j = 0,
```

由此可得 $\beta = \sum_{j=1}^{n} h_j\, j$。由于 $n h_j$ 是等于 $j$ 的观测值 $x_r$ 的个数，因此这个表达式等价于 (6.39)。

## 本节的印刷与记号疑点

- (6.37) 中的 `r - 1, …, k` 应为 `r = 1, …, k`。
- 正态分布特例第二方程分子中的 $(x_j - \sigma)^2$ 应为 $(x_j - \mu)^2$。
- (6.38) 后估计值写作 $\beta_r(x_1, \cdots, x_k)$，下标疑应为 $n$。
- 泊松例推理的求和 $\sum_{j=0}^{n}$ 上限为 $n$，而 $j$ 的取值本为 $0, 1, \dots$（即上限应为 $\infty$）。

以上四点分别由指向的 query 页面跟踪。

## 关键结论一览

| 情形 | 方程组 | 最大似然估计值 |
|------|--------|----------------|
| 连续型（一般） | (6.37) | 由 $\sum_j \frac{1}{\varphi}\frac{\partial \varphi}{\partial \beta_r} = 0$ 解出 |
| 正态分布 | (6.37) 特化 | $\mu = \frac{1}{n}\sum x_j$，$\sigma^2 = \frac{1}{n}\sum (x_j-\mu)^2$ |
| 离散型（一般） | (6.38) | 由 $\sum_j \frac{h_j}{p_j}\frac{\partial p_j}{\partial \beta_r} = 0$ 解出 |
| 伯努利型 | (6.38) 特化 | $p = h_1$ |
| 泊松型 | (6.38) 特化 | $\beta = \frac{1}{n}\sum_{j=1}^{n} x_j$ |
