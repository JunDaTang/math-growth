# 《数学指南——实用数学手册》6.2.5 应用于独立重复试验的伯努利模型

## 本节定位

本节属于《数学指南——实用数学手册》第 6 章「概率论」的 6.2 节「科尔莫戈罗夫的概率论公理化基础」之下，是继 [[随机向量]]（6.2.3）、[[极限定理]]（6.2.4）之后的收束性一节。它讨论**雅各布·伯努利提出并研究**的独立重复试验模型，并以此模型为统一框架，把此前各节的工具（切比雪夫不等式、中心极限定理、强大数定律）落到一个具体、可计算的模型上。原文称该模型「可广泛应用于许多情形，是概率论中最重要的模型之一」，特别地，利用它可以得到**理论概率与频率之间的关系**。

## 6.2.5.1 基本思想

(i) 先做一个试验（比较试验或基本试验），它有两个可能结果

```
e_1, e_2.
```

结果 $e_j$ 出现的概率为 $p_j$；规定 $p := p_1$，于是 $p_2 = 1-p$。称 $p$ 为该基本试验的概率。

(ii) 将该试验进行 $n$ 次。

(iii) 所有这些试验相互独立，即它们的结果彼此互不影响。

原文以抛硬币为例：$e_1$ 表示「正面向上」，$e_2$ 表示「反面向上」。$p = 1/2$ 时硬币被认为是公平的；$p \neq 1/2$ 时显然不公平。6.2.5.5 将说明如何通过分析一系列试验揭露使用不公平硬币行骗的骗子。

## 6.2.5.2 概率模型

**概率空间** 全部事件 $E$ 由基本事件

```
e_{i_1 i_2 ... i_n},   i_j = 1, 2,  j = 1, ..., n
```

组成，相应概率规定为

```
P(e_{i_1 i_2 ... i_n}) := p_{i_1} p_{i_2} ... p_{i_n}.        (6.18)
```

解释：$e_{121}$ 表示试验序列的结果依次为 $e_1, e_2, e_1, \cdots$，例如 $P(e_{121}) = p(1-p)p = p^2(1-p)$。

**试验的独立性** 定义事件 $A_i^{(k)}$：事件 $e_i$ 在第 $k$ 次试验中发生。则对所有可能的下标 $i_1, \cdots, i_n$，事件

```
A_{i_1}^{(1)}, A_{i_2}^{(2)}, ..., A_{i_n}^{(n)}
```

相互独立。

证明（原文给出 $n=2$ 的特例）：$A_i^{(1)} = \{e_{i1}, e_{i2}\}$，故

```
P(A_i^{(1)}) = P(e_{i1}) + P(e_{i2}) = p_i p_1 + p_i p_2 = p_i.
```

又 $A_j^{(2)} = \{e_{1j}, e_{2j}\}$，$A_i^{(1)} \cap A_j^{(2)} = \{e_{ij}\}$，由 (6.18) 得 $P(e_{ij}) = p_i p_j$；而 $P(A_i^{(1)})P(A_j^{(2)}) = p_i p_j$，故

```
P(A_i^{(1)} ∩ A_j^{(2)}) = P(A_i^{(1)}) P(A_j^{(2)}).
```

这正是独立事件所满足的概率乘法性质，因此 $A_i^{(1)}$ 与 $A_j^{(2)}$ 相互独立。$\square$

**作为 $E$ 上随机变量的频率** 由

```
H_n(e_{i_1} ... e_{i_n}) = (1/n) · (e ... 的等于 1 的脚标个数)
```

定义函数 $H_n : E \to \mathbb{R}$，则 $H_n$ 是事件 $e_1$ 在试验序列中发生的频率。

**定理 1**（关于 $H_n$）
(i) 对 $k = 0, \cdots, n$，有 $\left(H_n = \frac{k}{n}\right) = \binom{n}{k} p^k (1-p)^{n-k}$；
(ii) $\overline{H}_n = p$（期望）；
(iii) $\Delta H_n = \frac{\sqrt{p(1-p)}}{\sqrt{n}}$（标准差）；
(iv) $P(|H_n - p| \leqslant \varepsilon) \geqslant 1 - \frac{p(1-p)}{n \varepsilon^2}$（切比雪夫不等式）。

原文指出：(iv) 中数 $\varepsilon > 0$ 必须充分小；当试验次数 $n$ 增大时，频率与期望值的差会越来越小；该期望值正是 $e_1$ 在比较试验中发生的概率 $p$。

原文在此处给出方法论评注：(i) 中给出的概率计算公式**使用起来不方便**，为此[[棣莫弗]]、[[拉普拉斯]]和[[泊松]]都曾尝试寻找适当的逼近公式（见 6.2.5.3）；[[切比雪夫]]不等式对任意随机变量都成立。

**频数** 函数 $A_n := n H_n$ 刻画事件 $e_1$ 在试验序列中出现的次数。

**定理 2**（关于 $A_n$）
(i) 对 $k = 0, \cdots, n$，$P(A_n = k) = P\left(H_n = \frac{k}{n}\right) = \binom{n}{k} p^k (1-p)^{n-k}$；
(ii) $\overline{A}_n = n \overline{H}_n = np$；
(iii) $\Delta A_n = \sqrt{np(1-p)}$。

**示性函数** 由规则

```
X_j(e_{i_1 ... i_n}) = { 1, 若 i_j = 1;
                       { 0, 其他
```

定义随机变量 $X_j : E \to \mathbb{R}$；$X_j$ 等于 1 当且仅当 $e_1$ 在第 $j$ 次试验中发生。

**定理 3**
(i) $P(X_j = 1) = p$；
(ii) $\overline{X}_j = p$，$\Delta X_j = \sqrt{p(1-p)}$；
(iii) $X_1, \cdots, X_n$ 相互独立；
(iv) $H_n = \frac{1}{n}(X_1 + \cdots + X_n)$；
(v) $A_n = X_1 + \cdots + X_n$。

原文由此给出关键论证：频数 $A_n$ 是一些可以同样处理的独立随机变量的叠加；考虑到中心极限定理，预期 $n$ 很大时 $A_n$ 近似服从正态分布——这就是棣莫弗-拉普拉斯定理的内容。

## 6.2.5.3 逼近定理

**大数定律（伯努利）** 对任意 $\varepsilon > 0$，

```
lim_{n→∞} P(|H_n − p| < ε) = 1.        (6.19)
```

原文注：雅各布·伯努利通过大量计算发现了这条定律；(6.19) 可由切比雪夫不等式（6.2.5.2 定理 1）得到；若利用定理 3 的结论 (iv)，则 (6.19) 是切比雪夫弱大数定律（见 6.2.4.1）的一种特殊情况。

**棣莫弗-拉普拉斯局部极限定理** 当 $n \to \infty$ 时，关于频数有渐近关系式

```
P(A_n = k) ~ (1/(σ√(2π))) · e^{−(k−μ)²/(2σ²)}        (6.20)
其中 μ = A̅_n = np,  σ = ΔA_n = √(np(1−p)).
```

即对每个 $k = 0, 1, \cdots$，当 $n \to \infty$ 时 (6.20) 式两边表达式商的极限是 1（脚注 1）。

**标准化频率与标准化频数** 令

```
𝓗_n := (H_n − H̅_n) / ΔH_n,   有 𝓗̅_n = 0, Δ𝓗_n = 1;
𝓐_n := (A_n − A̅_n) / ΔA_n,
```

$\Phi_n$ 表示 $\mathfrak{H}_n$ 的分布函数；$\Phi$ 是标准高斯正态分布 $N(0,1)$ 的分布函数。原文指出 $\mathfrak{A}_n$ 等于标准化的频率 $H_n$，因此 $A_n$ 的分布函数也是 $\Phi_n$。

**棣莫弗-拉普拉斯全面极限定理**（脚注 2）对所有 $x \in \mathbb{R}$，

```
lim_{n→∞} Φ_n(x) = Φ(x).
```

从而对一切区间 $[a,b]$，

```
lim_{n→∞} P(a ≤ 𝓗_n ≤ b) = (1/√(2π)) ∫_a^b e^{−z²/2} dz.        (6.22)
```

此外还有非常精确的估计式

```
sup_{x∈ℝ} |Φ_n(x) − Φ(x)| ≤ (p² + (1−p)²) / √(np(1−p)),  n = 1,2,....   (6.23)
```

**注** 当 $n$ 较大时，频率近似服从期望 $\overline{H}_n = p$、标准差 $\Delta H_n = \sqrt{p(1-p)/n}$ 的正态分布。因此对每个区间 $[a,b]$ 有

```
P(p + aΔH_n ≤ H_n ≤ p + bΔH_n) = Φ_0(b) − Φ_0(a)
  = (1/√(2π)) ∫_a^b e^{−z²/2} dz.        (6.24)
```

原文指出该式左边是频率 $H_n$ 的观测值落在区间 $[p + a\Delta H_n, p + b\Delta H_n]$ 内的概率，并「给出了伯努利大数定律的一个精确表述」；$\Phi_0$ 的值可在表 0.34 中查到；当 $z$ 取负值时有 $\Phi_0(z) = -\Phi_0(-z)$。

(6.24) 等价于

```
P(x ≤ H_n ≤ y) = Φ_0((y − p)/ΔH_n) − Φ_0((x − p)/ΔH_n).
```

由于 $A_n = n H_n$，频数满足

```
P(u ≤ A_n ≤ v) = Φ_0((v − np)/√(np(1−p))) − Φ_0((u − np)/√(np(1−p))),
其中 −∞ < x < y < ∞, −∞ < u < v < ∞.
```

**比较试验中的小概率 $p$** 若 $p$ 非常小，则公式 (6.23) 表明只有当 $n$ 非常大时用正态分布逼近 $\Phi_n$ 才有效。泊松发现 $p$ 较小时有更好的逼近公式。

**泊松分布的定义** 在实数轴的点 $x = 0, 1, 2, \cdots$ 处分别赋予质量 $m_0, m_1, \cdots$，其中

```
m_r := (λ^r / r!) e^{−λ},  r = 0, 1, ...,     λ > 0 为参数。
```

相应质量分布函数 $\Phi(x) :=$ 区间 $]-\infty, x[$ 所包含的质量，称为泊松分布函数（图 6.15）。

![图 6.15 泊松分布函数](../media/10-数学指南实用数学手册--19-625-应用于独立重复试验的伯努利模型--89e2y0/001-a741172f399eb0a89ef201dee96b1fa461ba50cda9dcaa1f289cd645388c748d.jpg)

**定理** 若随机变量 $X$ 服从上述泊松分布，则

```
X̅ = λ (均值),   ΔX = √λ (标准差).
```

**泊松逼近定理（1837）** 若比较试验的概率 $p$ 非常小，则对频数 $A_n$ 近似有

```
(i) P(A_n = r) = (λ^r / r!) e^{−λ}, 其中 λ = np, r = 0, 1, ..., n。
(ii) A_n 的分布函数 Φ_n 近似等于参数 λ = np 的泊松分布的分布函数；更精确地
     sup_{x∈ℝ} |Φ_n(x) − Φ(x)| ≤ 3√(λ/n)。
```

原文注：$\frac{\lambda^r}{r!}\mathrm{e}^{-\lambda}$ 的值可以在 0.4.6.9 中查到。

## 6.2.5.4 在质量控制中的应用

设某工厂生产一种产品 $\mathcal{P}$（如灯泡），$\mathcal{P}$ 是次品的概率非常小，记为 $p$（例如 $p = 0.001$）；一个运输集装箱中装有 $n$ 件产品。

(i) 集装箱中恰好装有 $r$ 件次品的概率为

```
P(A_n = r) = C(n, r) p^r (1 − p)^{n−r}.
```

(ii) 次品数介于 $k$ 与 $m$ 之间的概率为

```
P(k ≤ A_n ≤ m) = Σ_{r=k}^{m} P(A_n = r).
```

**近似** 由于 $p$ 很小，可采用泊松逼近：

```
P(A_n = r) = (λ^r / r!) e^{−λ},   λ = np。
```

泊松分布的数值表见 0.4.6.9。若 $n$ 充分大，也可假定 $A_n$ 服从正态分布，由 (6.24) 及其后等式得到

```
P(k ≤ A_n ≤ m) = Φ_0((m − np)/√(np(1−p))) − Φ_0((k − np)/√(np(1−p))).
```

**例 1**：集装箱装 1000 只灯泡，次品概率 $p = 0.001$；由 0.4.6.9 及 $\lambda = np = 1$ 得

```
P(A_1000 = 0) = 0.37,  P(A_1000 = 1) = 0.37,  P(A_1000 = 2) = 0.18;
P(A_1000 ≤ 2) = 0.37 + 0.37 + 0.18 = 0.92.
```

即无残次灯泡的概率为 0.37（37%），至多两只残次灯泡的概率为 0.92。

**例 2**：设次品概率为 0.005，则在装载的 10 000 只灯泡中至多有 100 只次品的概率为

```
P(A_10000 ≤ 100) = Φ_0(7) − Φ_0(−7) = 2Φ_0(7) = 1.
```

原文结论：几乎可以肯定在这 10 000 只灯泡中至多有 100 只残次灯泡。

## 6.2.5.5 在假设检验中的应用

目标是仅通过一个实验的试验观测，揭露使用不均匀硬币行骗的骗子。原文说明数理统计的典型论证方式：认为「揭露一个骗子」只能在一定的**残概率**（记为 $\alpha$）下进行，残概率指所作结论不正确的概率。对 $\alpha = 0.05$，意味着若试图揭露骗子 100 次，平均约 5 次会作出错误结论，把无辜者当成骗子。

**揭露一枚不公平硬币（抛币者）的试验** 将硬币抛 $n$ 次，观察「正面向上出现 $k$ 次」。称 $h_n = k/n$ 为随机变量 $H_n$（频率）的实现；$p$ 表示一次试验中正面向上出现的概率。假设：

```
(H) 硬币是公平的，即 p = 1/2。
```

**数理统计基本原理** 如果

```
h_n 不在置信区间 [1/2 − z_α ΔH_n, 1/2 + z_α ΔH_n] 内,        (6.25)
```

便以残概率 $\alpha$ 放弃假设 (H)。这里 $\Delta H_n := 1/(2\sqrt{n})$，$z_\alpha$ 由等式 $2\Phi_0(z_\alpha) = 1 - \alpha$ 查表 0.34 确定；原文给出：对 $\alpha = 0.01$（或者 0.05 和 0.1），有 $z_\alpha = 1.6$（相应地 2.0 和 2.6）。

**推理** 由 (6.24)，当 $n$ 很大时，理论量 $H_n$ 的实测值 $h_n$ 落入 (6.25) 置信区间的概率是

```
Φ_0(z_α) − Φ_0(−z_α) = 1 − α.
```

若 $H_n$ 的实测值未落入该区间，则放弃假设 (H)，此时作出错误结论的概率是 $\alpha$。

**例**：$n = 10\,000$ 时 $\Delta H_n = 1/200 = 0.05$，相应于残概率 $\alpha = 0.05$ 的置信区间是

```
[0.49, 0.51].        (6.26)
```

若 10 000 次抛掷中有 5200 次「正面向上」，则 $h_n = 0.52$ 落在 (6.26) 之外，故以 0.05 的出错概率下结论：这枚硬币不公平。反之，若出现 5050 次，则 $h_n = 0.505$ 落在 (6.26) 内，故相信硬币其实是公平的；该结论正确的概率为 95%，错误概率为 $\alpha = 0.05$。

## 6.2.5.6 关于概率 $p$ 的置信区间的应用

考虑一枚硬币，$p$ 是一次比较试验中出现「正面向上」的概率。将硬币抛 $n$ 次，观测频率 $h_n$；现在 $p$ 未知，希望以一定置信度确定它。

**数理统计基本原理** 在错误概率 $\alpha$ 下，假定未知的 $p$ 值落在区间

```
[p_−, p_+]
```

内，其中（脚注 1）

```
(1 + z_α²/n) p_± = h_n + z_α²/(2n) ± √( h_n z_α²/n + z_α²/(4n²) ).
```

原文指出：一般来说，对于 6.2.5.2 中伯努利模型的概率 $p$ 的估计，这个结论是正确的。

**推理** 由 (6.24) 可知，当 $n$ 较大时不等式

```
|(h_n − p)/ΔH_n| < z_α        (6.27)
```

成立的概率为 $\Phi_0(z_\alpha) - \Phi_0(-z_\alpha) = 1 - \alpha$。因 $(\Delta H_n)^2 = p(1-p)/n$，(6.27) 等价于

```
(h_n − p)² < z_α² · p(1−p)/n,
```

即

```
p²(1 + z_α²/n) − (2h_n + z_α²/n) p + h_n² < 0.        (6.28)
```

当且仅当 $p$ 介于相应二次方程

```
p²(1 + z_α²/n) − (2h_n + z_α²/n) p + h_n² = 0
```

的两个根 $p_-$ 与 $p_+$ 之间时，(6.28) 成立。

**例**：抛硬币 10 000 次，若「正面向上」出现 5010 次，则 $h_n = 0.501$，原文称正面向上未知概率 $p$ 落在区间 $[0.36, 0.64]$ 中，残概率 $\alpha = 0.05$；随后又指出这个估计十分粗糙，并在相同的残概率 $\alpha = 0.05$ 下断定 $p$ 落在区间 $[0.500, 0.503]$ 内。

## 6.2.5.7 强大数定律

**无穷多重试验** 为系统阐述强大数定律，需将试验重数增加到无穷大。考虑由基本事件

```
e_{i_1 i_2} ...
```

组成的全体事件 $E$，其中每个 $i_j$ 取值 1 或 2；$e_{12}$ 表示第一次试验中 $e_1$ 发生、第二次试验中 $e_2$ 发生……用 $A_{i_1 \ldots i_n}$ 表示由所有形如 $e_{i_1 \ldots i_n}$ 的基本事件组成的集合，并规定

```
P(A_{i_1 i_2 ... i_n}) = p_{i_1 i_2 ... i_n},        (6.29)
```

其中 $p_1 := p$，$p_2 := 1 - p$（见 (6.18)）。用 $\mathcal{S}$ 表示对所有的 $n$ 包含一切集合 $A_{i_1 \ldots i_n}$ 的 $E$ 的最小 $\sigma$ 域。

**定理** 在 $\mathcal{S}$ 的子集上存在满足性质 (6.29) 的唯一确定的概率测度 $P$。于是 $(E, \mathcal{S}, P)$ 是一个概率空间。

**频率** 通过

```
H_n(e_{i_1 ... i_n} ...) = (1/n) × (e 的满足 i_j = 1 且 1 ≤ j ≤ n 的脚标 i_j 的个数)
```

定义随机变量 $H_n : E \to \mathbb{R}$。

**博雷尔（1909）-坎泰利（1917）强大数定律** 在 $E$ 上几乎必然成立（脚注 1）极限关系式

```
lim_{n→∞} H_n = p.
```
