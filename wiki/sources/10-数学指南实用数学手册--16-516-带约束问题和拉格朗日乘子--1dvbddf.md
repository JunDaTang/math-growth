# 《数学指南——实用数学手册》5.1.6 带约束问题和拉格朗日乘子

本节是《数学指南——实用数学手册》5.1 节「单变量函数的变分法」的第六个子节，讨论**带约束的极小化问题**以及处理它的**拉格朗日乘子法**。全节结构为：先给出问题提法 (5.38) 与两类约束 (5.39)、(5.40)，再说明拉格朗日乘子背后的构造思想（修正拉格朗日函数 𝓛 与修正欧拉-拉格朗日方程 (5.41)），最后给出乘子存在性的**主定理**及关于积分约束情形的附注。

## 问题提法 (5.38)

设 $q=(q_{1},\cdots,q_{F})$，考虑带约束的极小化问题

```latex
\boxed{\begin{array}{c}
  \int_{t_0}^{t_1} L(q(t), q'(t), t)\,\mathrm{d}t \stackrel{!}{=} \min, \\
  q(t_0) = a,\quad q(t_1) = b \quad (\text{边界条件}),
\end{array}}\tag{5.38}
```

其中 $L$ 为拉格朗日函数，$q=q(t)$ 为待求的 $F$ 维函数向量，$a,b$ 为给定的边界值。

## 约束条件

约束分两类。

**(i) 积分约束（等周约束）**

```latex
\int_{t_0}^{t_1} N_k(q(t), q'(t), t)\,\mathrm{d}t = \text{常数}, \quad k = 1,\dots,K.\tag{5.39}
```

**(ii) 隐约束（微分约束）**

```latex
N_k(q(t), q'(t), t)\,\mathrm{d}t = 0 \quad \text{在}\ [t_0,t_1]\ \text{上},\quad k = 1,\dots,K.\tag{5.40}
```

本节假定函数 $L$ 和 $N_{k}$ 充分光滑。

## 隐藏在拉格朗日乘子背后的思想

用**修正的拉格朗日函数**

```latex
\boxed{\mathscr{L} := L + \sum_{k=1}^{K} \lambda_k(t) N_k}
```

代替拉格朗日函数 $L$，并在欧拉-拉格朗日方程中用它代替 $L$：

```latex
\boxed{\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k} - \mathscr{L}_{q_k} = 0,\quad k = 1,\dots,K.}\tag{5.41}
```

原文脚注 1) 更明显地写出该方程：

```latex
\frac{\mathrm{d}}{\mathrm{d}t}\mathscr{L}_{q'_k}(q(t), q'(t), t)
- \mathscr{L}_{q_k}(q(t), q'(t), t) = 0.
```

函数 $\lambda_{k}=\lambda_{k}(t)$ 称为**拉格朗日乘子**。期望由 (5.41)、约束条件与边界条件共同确定函数 $q_{k}=q_{k}(t)$ 和 $\lambda_{k}=\lambda_{k}(t)$，$k=1,\cdots,K$。

## 主定理

> 设 $q=q(t)$ 是带有约束条件 (5.39) 或 (5.40) 的极小化问题 (5.38) 的 $C^{2}$ 解，并假定不是线性情形。$^{1)}$ 那么存在充分光滑的拉格朗日乘子 $\lambda_{k}$ 使得 (5.41) 成立。

**附注**：在积分约束 (5.39) 的情形，拉格朗日乘子是实数，而非函数。

主定理中的脚注标记 $^{1)}$ 所指向的「不是线性情形」的说明在本节源文本中缺失，见 [[queries/516节主定理不是线性情形脚注缺失]]。

## 本节的记号与表述疑点

源文本中出现的几处记号/表述问题已单独建条追踪：

1. 修正拉格朗日函数定义中 $\lambda_k(t)$ 被排作 `\lambda - k(t)`，见 [[queries/516节修正拉格朗日函数中lambda-k记号讹误]]。
2. (5.41) 的指标范围写作 $k=1,\dots,K$，而 $q$ 的分量数为 $F$，见 [[queries/516节修正欧拉-拉格朗日方程索引k范围是否为F]]。
3. 「在欧拉-拉格朗日方程中用 L 代替 L」一句中两个符号相同，疑为「用 𝓛 代替 L」，见 [[queries/516节用花体L代替L表述讹误]]。
4. 主定理「不是线性情形」的脚注内容缺失，见 [[queries/516节主定理不是线性情形脚注缺失]]。
