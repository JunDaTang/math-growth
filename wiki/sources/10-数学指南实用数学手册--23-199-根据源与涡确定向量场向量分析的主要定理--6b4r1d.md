# 《数学指南——实用数学手册》1.9.9 根据源与涡确定向量场（向量分析的主要定理）

本节是 1.9「向量分析与物理学领域」中承上启下的一节：前承 1.9.7 的 [[高斯定理]]（散度与源）与 1.9.8 的 [[斯托克斯积分定理]]（旋度与涡、环量），后接 1.9.10 与 1.9.11 的物理与几何解释。本节先分别讨论「源的规定」与「涡流的规定」，再给出 $\mathbb{R}^3$ 情形下的显式解，最后陈述并命名本节标题所指的最高结论——[[向量分析的主要定理]]，其结论是：向量场 $v$ 由它的源、涡以及边界上的法向分量唯一确定。

## 一、源的规定（散度方程）

假设在 $\mathbb{R}^3$ 中可缩[^1]区域 $D$ 上给定 $C^1$ 类函数 $\rho : D \to \mathbb{R}$，则在 $D$ 上总存在 $C^2$ 类向量场 $D$，满足方程

```
div D = ρ,  在 D 上.
```

这个方程的通解形为

```
D = D_par + curl A,
```

其中 $D_{par}$ 是特解，$A$ 是 $D$ 上任意 $C^3$ 类向量场。

## 二、涡流的规定（旋度方程）

假设给定 $\mathbb{R}^3$ 中可缩区域 $D$ 上的 $C^1$ 类向量场 $J$，则在 $D$ 上存在唯一一个 $C^2$ 类向量场 $H$，使得如果在 $D$ 上 $\operatorname{div} J = 0$ 时 $H$ 满足

```
curl H = J,  在 D 上.
```

通解的形式为

```
H = H_par + grad U,
```

其中 $H_{par}$ 是特解，$U : D \to \mathbb{R}$ 是任意 $C^3$ 类函数。

[^1]: 这个术语定义在 1.9.11 中。

> 注意：原文同段落先称 $H$「存在唯一」，随后给出含任意函数 $U$ 的通解 $H_{par} + \operatorname{grad} U$，二者存在张力。参见 [[queries/199节涡流规定唯一性与通解矛盾]]。

## 三、解的显式公式（$D = \mathbb{R}^3$ 情形）

令 $D = \mathbb{R}^3$，并且假设 $\rho$ 和 $J$ 在 $\mathbb{R}^3$ 上为 $C^3$ 类，并在某一球外为零。再设在 $\mathbb{R}^3$ 上 $\operatorname{div} J \equiv 0$。引进所谓的 [[体积位势]]：

```
V(x) := ∫_{R^3} ρ(y) dy / (4π|x − y|)
```

及 [[向量位势]]

```
C(x) = ∫_{R^3} J(y) dy / (4π|x − y|).
```

最后令

```
D_par := −grad V,   H_par := curl C,
```

则有

```
div D_par = ρ,  curl D_par = 0,  在 R^3 上
```

和

```
div H_par = 0,  curl H_par = J,  在 R^3 上.
```

因此场 $v := D_{par} + H_{par}$ 解决了两个方程

```
div v = ρ  和  curl v = J,  在 R^3 上.        (1.172)
```

## 四、向量分析的主要定理

问题

```
div v = ρ  与  curl v = J,  在 D 上,
v n = g,  在 ∂D 上                             (1.173)
```

在 $\bar{D}$ 上有唯一 $C^2$ 类解 $v$，如果满足下列假设：

(i) $D$ 是 $\mathbb{R}^3$ 中有光滑边界的有界区域；$n$ 是边界上的外法线单位向量。

(ii) $\bar{D}$ 上给定的函数 $\rho$ 与 $J$ 足够光滑，并且 $g$ 在 $\partial D$ 上足够光滑。

(iii) 在 $D$ 上有

```
div J = 0
```

和

```
∫_D ρ ds = ∫_{∂D} g dF.
```

条件 (iii) 中的两个等式即 [[相容性条件]]，是唯一可解性的必要条件。

## 五、物理解释

向量场 $v$（比如速度场）由它的源及涡及它在边界上的法向分量确定。

原文在此处中断于「（比如速度场」一句，物理阐释的后续内容未见于已转录文本。
