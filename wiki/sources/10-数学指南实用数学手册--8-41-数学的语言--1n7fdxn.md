# 《数学指南——实用数学手册》4.1 数学的语言

## 概览

本节是《数学指南——实用数学手册》第 4 章「数学的语言」的首节，是一份紧凑的命题逻辑入门。全节分三小节：4.1.1 真命题和假命题（命题与联结词、量词），4.1.2 蕴涵（推论、充分/必要条件、逻辑等值、换位），4.1.3 重言律和逻辑定律（十一条重言式清单）。作者反复强调：数学使用一种非常精确的语言，凡数学命题都须能以真值语义精确刻画。

本节处于手册第 4 章的起点，向下游章节存在多处前向引用：重言式 (iv)–(x) 用于 4.2.1「间接证明」；(i) 中的分配律是 4.3.2「集合论」中并、交分配律的根据。

## 4.1.1 真命题和假命题

**命题**被定义为「一种要么为真要么为假的有意义的语言结构」。

### 四个联结词

- **析取（或命题）**：「A 或 B」为真当且仅当 A、B 至少一个为真；两者皆假时为假。
  - 例 1：「2 整除 4 或 3 整除 5」为真（第一部分真）；「2 整除 5 或 3 整除 7」为假（两部分皆假）。
- **严格析取**：「要么 A 要么 B」为真当且仅当两者之一为真且另一个为假；其余情形皆为假。
  - 例 2：设 m 为整数，「要么 m 是偶数要么 m 是奇数」为真；「要么 m 是偶数要么 m 被 3 整除」为假。
- **合取（与命题）**：「A 且 B」为真当且仅当两部分都真，否则为假。
  - 例 3：「2 整除 4 且 3 整除 5」为假。
- **否定**：「非 𝒜」为真（假）当且仅当 𝒜 为假（真）。此处正文公式缺失，仅留图像占位（见下）。

### 量词

**存在命题**：设 D 为固定的对象集合，冗长表述「D 中存在具有性质 E 的一个对象 x」简写为

$$
\left| \exists_ {x \in D}: E (\text {或者} \exists_ {x \in D} | E). \right|
$$

该命题为真当且仅当 D 中存在具有性质 E 的对象 x；否则为假。
- 例 4：「存在具有性质 $x^{2} + 1 = 0$ 的一个实数 x」为假。

**概括命题（全称命题）**：命题「D 中的所有对象 x 都具有性质 E」简写为

$$
\left| \forall_ {x \in D}: E (\text {或者} \forall_ {x \in D} | E). \right|
$$

为真当且仅当 D 中所有对象都具有性质 E；若至少有一个对象不具有该性质则为假。
- 例 5：「所有的整数都是素数」为假，因为例如 4 不是素数。

## 4.1.2 蕴涵

对命题「A 蕴涵 B（或者 B 由 A 推出）」使用记号

$$
\boxed {\mathcal {A} \Rightarrow \mathcal {B}.}\tag{4.1}
$$

这样的复合命题称为一个推论（或蕴涵）。相关术语：
- (i) A 对于 B 是**充分的**；
- (ii) B 对于 A 是**必要的**。

**真值约定**：$A \Rightarrow B$ 为假当且仅当假设 A 真而推出的命题 B 假；否则为真。这与「从一个假的前提出发作出的任何结论都是真的」这一乍看令人惊讶的约定相符，即利用假假设可以证明任何事情。

**例 1**：设 m 为整数，A 为「m 能被 6 整除」，B 为「m 能被 2 整除」。蕴涵 (4.2) 表述为「由 m 关于 6 的可除性可以推出 m 关于 2 的可除性」。亦可表述为：
- (a) m 关于 6 的可除性对于 m 关于 2 的可除性来说是充分的；
- (b) m 关于 2 的可除性对于 m 关于 6 的可除性来说是必要的。

证明分两种情形：情形 1（m 能被 6 整除）取 $m = 6k$，则 $m = 2(3k)$，故 B 真；情形 2（m 不能被 6 整除）前提为假，蕴涵仍真。两情形合并即得 (4.2) 恒真。这一论证即所谓 (4.2) 的证明。

**逻辑等值**：从 $A \Rightarrow B$ 到 $B \Rightarrow A$ 的推论是假的（(4.2) 的反方向即为反例，即 m 关于 2 的可除性对 m 关于 6 的可除性是必要的但不是充分的）。形式为

$$
\boxed {\mathcal {A} \Leftrightarrow \mathcal {B}}\tag{4.3}
$$

的命题意指两个蕴涵 $A \Rightarrow B$ 与 $B \Rightarrow A$ 都为真。等价说法：
- (i) A 成立当且仅当 B 成立；
- (ii) A 对于 B 是充分必要的；
- (iii) B 对于 A 是充分必要的。

**例 2**：A 为「m 能被 6 整除」，B 为「m 能被 2 和 3 整除」，则 $A \Leftrightarrow B$；亦可谓 m 关于 2 和 3 的可除性对 m 关于 6 的可除性而言是充分必要的。

**蕴涵的换位**：给定 $A \Rightarrow B$ 总隐含并隐含于新的等价蕴涵

$$
\boxed {\text {非} \mathcal {B} \Rightarrow \text {非} \mathcal {A},}
$$

其中「非 A」意为假定 A 不成立。注意两个命题都被否定，且蕴涵方向逆转。此称为蕴涵的换位或否定。
- 例 3：由 (4.2) 得到「如果 m 不能被 2 整除，则 m 也不能被 6 整除」。

**逻辑等值的换位**：由 $A \Leftrightarrow B$ 得到

$$
\left| \text {非} \mathcal {A} \Leftrightarrow \text {非} \mathcal {B}. \right|
$$

- 例 4：设 $(a_n)$ 为递增（或递减）实数序列，定理

$$
(a _ {n}) \text {   是收敛的   } \Leftrightarrow (a _ {n}) \text {   是有界的.   }
$$

换位后得

$$
(a _ {n}) \text {   是不收敛的   } \Leftrightarrow (a _ {n}) \text {   不是有界的.   }
$$

## 4.1.3 重言律和逻辑定律

**重言式**是无论组成它的部分命题真值如何总为真的复合命题。全部逻辑思维（数学的根基）建立在重言式的应用之上；这些重言式也可看作逻辑定律。最重要者如下。

(i) 析取和合取的分配律：

$$
\mathcal {A} \text { 且 } (\mathcal {B} \text { 或 } \mathcal {C}) \Leftrightarrow (\mathcal {A} \text { 且 } \mathcal {B}) \text { 或 } (\mathcal {A} \text { 且 } \mathcal {C}),
$$

$$
\mathcal {A} \text {或} (\mathcal {B} \text {且} \mathcal {C}) \Leftrightarrow (\mathcal {A} \text {或} \mathcal {B}) \text {且} (\mathcal {A} \text {或} \mathcal {C}).
$$

(ii) 否定之否定：

$$
\text { 非 } (\mathcal {\text { 非 }} \mathcal {A}) \Leftrightarrow \mathcal {A}.
$$

(iii) 蕴涵的换位：

$$
(\mathcal {A} \Rightarrow \mathcal {B}) \Leftrightarrow (\text { 非 } \mathcal {B} \Rightarrow \text { 非 } \mathcal {A}).
$$

(iv) 逻辑等值的换位：

$$
(\mathcal {A} \Rightarrow \mathcal {B}) \Leftrightarrow (\text { 非 } \mathcal {B} \Rightarrow \text { 非 } \mathcal {A}).
$$

(v) 析取的否定（德摩根律）：

$$
\text { 非 } (\mathcal {A} \text { 或 } \mathcal {B}) \Leftrightarrow (\text { 非 } \mathcal {A} \text { 且非 } \mathcal {B}).
$$

(vi) 合取的否定（德摩根律）：

$$
\boxed {\text {非} (\mathcal {A} \text {且} \mathcal {B}) \Leftrightarrow (\text {非} \mathcal {A} \text {或非} \mathcal {B}).}
$$

(vii) 存在命题的否定：

$$
\boxed {\text {非} (\exists_ {x} | E) \Leftrightarrow (\forall_ {x} | \text {非} E).}
$$

(viii) 概括命题的否定：

$$
\boxed {\text {非} (\forall_ {x} | E) \Leftrightarrow (\exists_ {x} | \text {非} E).}
$$

(ix) 蕴涵的否定：

$$
\boxed {\text {非} (\mathcal {A} \Rightarrow \mathcal {B}) \Leftrightarrow (\mathcal {A} \text {且非} \mathcal {B}).}
$$

(x) 逻辑等值的否定：

$$
\text { 非 } (\mathcal {A} \Leftrightarrow \mathcal {B}) \Leftrightarrow \{(\mathcal {A} \text { 且非 } \mathcal {B}) \text { 或 } (\mathcal {B} \text { 且非 } \mathcal {A}) \}.
$$

(xi) 狄奥弗拉斯特（公元前 372—前 287）的分离基本规则（肯定前件式）：

$$
\boxed {\{(\mathcal {A} \Rightarrow \mathcal {B}) \text {且} \mathcal {A} \} \Rightarrow \mathcal {B}.}
$$

### 各重言式的文字释义与用途

- (i) 是集合论（4.3.2）中并、交分配律的根据。
- (ii) 意味着一个命题的双重否定逻辑等值于原命题。
- (iii)、(iv) 已在 4.1.2 的例 3、例 4 中使用。
- (iv) 到 (x) 经常被用于数学中的间接证明（见 4.2.1）。
- (xi) 分离规则蕴涵下列逻辑定律，在整个数学中经常使用，因此有时被称为**逻辑学基本定理**：「如果一个命题 B 由假设 A 推出，并且如果假设 A 被满足，那么命题 B 成立。」
- (v) 德摩根律蕴涵逻辑定律：「一个析取的否定逻辑等值于否定后的支命题的合取。」
  - 例：设 m 为整数。
    - (i) 若数 m 不满足「它是偶数或它能被 3 整除」，则 m 不是偶数且 m 不能被 3 整除。
    - (ii) 若数 m 不满足「它是偶数且它能被 3 整除」，则 m 不是偶数或 m 不能被 3 整除。
- (vii) 文字表述：若不存在具有性质 E 的对象 x，则所有对象都不具有性质 E，并且逆命题也成立。
- (viii) 文字表述：若「所有对象 x 具有性质 E」不是真的，则存在一个对象 x 它不具有性质 E，并且逆命题也成立。
