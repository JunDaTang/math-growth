# 《数学指南——实用数学手册》0.2.3 二次函数

来源为《数学指南——实用数学手册》第 0.2.3 节，属于 [[数学指南-实用数学手册]] 的一部分，位于 [[sources/10-数学指南实用数学手册--11-02-初等函数及其图示--1o4awf0]] 章节之下。本节以很短的篇幅给出二次函数的标准形式、一般形式的配方、二次方程求根公式与判别式的三种情形，并附三个数值例子。

本节最重要的结构性特征是**非标准记法**：一般二次函数写成 \(y = ax^{2} + 2bx + c\)，判别式定义为 \(D := b^{2} - ac\)，而非常见的 \(b^{2} - 4ac\)。这一约定在 [[二次函数判别式记法差异]] 中单独追踪。

## 最简二次函数与其图像

来源给出最简单的二次函数

```latex
y = a x^{2} \tag{0.30}
```

其中 \(a \neq 0\)，并称其图像是一条抛物线（图 0.27）。图 0.27 按 \(a > 0\) 与 \(a < 0\) 分别给出 (a)(b)(c)(d) 四种开口形态示意。

## 一般二次函数的配方与平移

一般二次函数写作

```latex
y = a x^{2} + 2 b x + c \tag{0.31}
```

由二次配方，可写成

```latex
y = a \left(x + \frac{b}{a}\right)^{2} - \frac{D}{a}, \tag{0.32}
```

其中判别式定义为

```latex
D := b^{2} - a c
```

来源由此断言：(0.31) 的图像可以通过把 (0.30) 的图像的**顶点** \((0,0)\) 平移到 \(\left(-\frac{b}{a}, -\frac{D}{a}\right)\) 得到。这一主张把“配方”这一代数操作与“图像平移”这一几何操作绑定起来，是本来源与既有 [[函数图像的平移]]、[[标准形式经三类变换生成全部函数图像]] 之间的主要连接点，详见 [[二次配方与顶点形式]] 与 [[二次函数的抛物线图像]]。

## 二次方程求根公式

对二次方程

```latex
a x^{2} + 2 b x + c = 0
```

（系数 \(a, b, c\) 为实数，\(a > 0\)），来源给出的解为

```latex
x_{\pm} = \frac{-b \pm \sqrt{D}}{a} = \frac{-b \pm \sqrt{b^{2} - a c}}{a}
```

注意根式内的 \(D\) 是本节定义的 \(b^{2} - ac\)，不是常见的 \(b^{2} - 4ac\)；两者的关系见 [[二次判别式]]。求根公式本身见 [[二次方程求根公式]]。

## 判别式的三种情形

| 情形 | 判别式 | 零点情况 | 抛物线与 \(x\) 轴的关系 | 图 |
|---|---|---|---|---|
| 情形 1 | \(D > 0\) | 两个不同的实零点 \(x_{+}\) 和 \(x_{-}\) | 两个不同交点 | 图 0.28(a) |
| 情形 2 | \(D = 0\) | 一个实零点 \(x_{+} = x_{-}\) | 相切 | 图 0.28(b) |
| 情形 3 | \(D < 0\) | 两个复零点 | （实）抛物线与 \(x\) 轴不相交 | 图 0.28(c) |

情形 3 的复零点写作

```latex
x_{\pm} = \frac{-b \pm \mathrm{i} \sqrt{-D}}{a} = \frac{-b \pm \mathrm{i} \sqrt{a c - b^{2}}}{a},
```

其中 \(\mathrm{i}\) 是虚数单位，满足 \(\mathrm{i}^{2} = -1\)（来源提示参看 1.1.2 节）。详见 [[二次方程的复零点]]。

## 数值例子

来源给出三个例子，分别对应三种情形：

例 1（\(D > 0\)）：方程 \(x^{2}-6x+8=0\) 有两个零点

```latex
x_{\pm} = 3 \pm \sqrt{3^{2} - 8} = 3 \pm 1,
```

即 \(x_{+}=4\)，\(x_{-}=2\)。

例 2（\(D = 0\)）：方程 \(x^{2}-2x+1=0\) 的零点为

```latex
x_{\pm} = 1 \pm \sqrt{1 - 1} = 1.
```

例 3（\(D < 0\)）：方程 \(x^{2}+2x+2=0\) 的零点为

```latex
x_{\pm} = -1 \pm \sqrt{1 - 2} = -1 \pm \mathrm{i}.
```

需要留意：三个例子中 \(x^{2}\) 的系数均为 1，故形如 \(x^{2} + Bx + C = 0\)，对应本节记法下 \(a = 1\)、\(2b = B\)、\(c = C\)，于是 \(D = (B/2)^{2} - C\)；例 1 中 \(D = 9 - 8 = 1\)，例 3 中 \(D = 1 - 2 = -1\)，与算式一致。
