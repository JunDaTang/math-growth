# 《数学指南——实用数学手册》7.2.2 线性方程组的迭代法

## 概览

本节是《数学指南——实用数学手册》第 7 章「线性代数」中 7.2「线性方程组」的第二部分，主题为**线性方程组的迭代法**。全文分为两个小节：

- **7.2.2.1 经典迭代法**：以分解 $A = -L + D - U$ 为基础，给出组合步方法（雅可比方法）、单步方法（高斯-赛德尔方法）以及它们的松弛推广 JOR 与 SOR。
- **7.2.2.2 共轭梯度法**：针对对称正定稀疏矩阵，给出基于二次泛函极小化的 CG 算法、收敛性估计与预条件思想。

本节承接 7.2.1 的[[concepts/线性方程组直接法|直接法]]，属于同一主题下的另一条求解路线；与直接法共用的概念包括[[concepts/对角占优]]与[[concepts/线性方程组的条件数]]。

## 迭代法的定位与收敛判据

迭代法特别适于求解系数矩阵 $A$ **稀疏**（多数元素为零）的**大型**方程组

$$
\boxed{Ax + b = 0,}
$$

迭代过程基于将给定方程 $Ax + b = 0$ 化为**不动点形式**

$$
\boxed{x = Tx + c,}
$$

或者通过对逼近泛函求极小。对给定的初始向量 $x^{(0)}$，**当且仅当**迭代矩阵 $T$ 的谱半径满足 $\rho(T) < 1$，不动点关系

$$
x^{(k+1)} = Tx^{(k)} + c
$$

生成的序列收敛到解 $x$。该充要条件详见[[concepts/谱半径收敛判据]]，其代数形式见[[concepts/不动点形式]]。

## 7.2.2.1 经典迭代法

### 矩阵分解与三个矩阵的定义

将矩阵 $A$ 分解为和 $A = -L + D - U$，其中 $L$ 为严格下三角矩阵，$U$ 为严格上三角矩阵，$D$ 为对角矩阵且其对角线元素 $a_{kk}$ 非零：

```
L := (  0      0      0    ...   0   )
     ( -a_21   0      0    ...   0   )
     ( -a_31  -a_32   0    ...   0   )
     (  ...    ...   ...          ... )
     ( -a_n1  -a_n2  -a_n3  ...   0   )

U := (  0    -a_12  -a_13  ...  -a_1n )
     (  0      0    -a_23  ...  -a_2n )
     (  0      0      0    ...  -a_3n )
     ( ...    ...    ...          ...  )
     (  0      0      0    ...    0    )

D := diag(a_11, a_22, ..., a_nn)
```

即 $L$ 的元素为 $-a_{ij}\ (i>j)$，$U$ 的元素为 $-a_{ij}\ (i<j)$，$D$ 为对角元 $a_{kk} \neq 0$ 的对角矩阵。

### 雅可比方法（组合步方法）

**组合步方法**（也称为**雅可比方法**）的迭代算法为

$$
Dx^{(k+1)} = (L + U)x^{(k)} - b, \qquad k = 0, 1, 2, \dots,
$$

其迭代矩阵由下式给出：

$$
\boxed{T_{\mathrm{J}} := D^{-1}(L + U).}
$$

雅可比方法收敛的**一个充分条件**是矩阵 $A$ 为[[concepts/对角占优]]矩阵。详见[[concepts/雅可比方法]]。

### 高斯-赛德尔方法（单步方法）

**单步方法**（也称为**高斯-赛德尔方法**）定义为

$$
(D - L)x^{(k+1)} = Ux^{(k)} - b, \qquad k = 0, 1, 2, \dots,
$$

其不动点迭代单元由下式给出：

$$
\boxed{T_E := (D - L)^{-1}U, \qquad c_E := (D - L)^{-1}b.}
$$

迭代也可以按分量写为

$$
x_i^{(k+1)} = -\left(b_i + \sum_{j=1}^{i-1} a_{ij}x_j^{(k+1)} + \sum_{j=i+1}^{n} a_{ij}x_j^{(k)}\right)\Big/ a_{ii}, \qquad i = 1, 2, \dots, n.
$$

单步方法收敛的**充分条件**是矩阵 $A$ 对角占优**或对称正定**。详见[[concepts/高斯-赛德尔方法]]。

### 松弛推广：JOR 与 SOR

若对单个分量乘以一个**松弛因子** $\omega \neq 1$，常可使算法性能（收敛速度）好得多。当 $\omega > 1$ 时称为**超松弛**，当 $\omega \leqslant 1$ 时称为**低松弛**。

组合步方法产生 **JOR** 算法如下：

$$
\begin{aligned}
x^{(k+1)} &= x^{(k)} + \omega\left[D^{-1}(L + U)x^{(k)} - D^{-1}b - x^{(k)}\right] \\
&= \left[(1 - \omega)E + \omega D^{-1}(L + U)\right]x^{(k)} - \omega D^{-1}b.
\end{aligned}
$$

因此不动点迭代的元素为

$$
\boxed{T_{\mathrm{JOR}}(\omega) := (1 - \omega)E + \omega D^{-1}(L + U), \qquad c_{\mathrm{JOR}} := -\omega D^{-1}b.}
$$

类似地，有 **SOR 逐次超松弛方法**：

$$
\begin{aligned}
x^{(k+1)} &= (D - \omega L)^{-1}\left[(1 - \omega)D + \omega U\right]x^{(k)} - \omega(D - \omega L)^{-1}b, \\
T_{\mathrm{SOR}}(\omega) &:= (D - \omega L)^{-1}\left[(1 - \omega)D + \omega U\right], \qquad c_{\mathrm{SOR}} := -\omega(D - \omega L)^{-1}b.
\end{aligned}
$$

**最优松弛因子** $\omega_{opt}$ 的选取要使得谱半径 $\rho(T_{\mathrm{JOR}}(\omega))$ 和 $\rho(T_{\mathrm{SOR}}(\omega))$ 分别最小。由于系数矩阵 $A$ 有不同的性质，选取 $\omega_{opt}$ 的方法理论上也有不同的可能性。详见[[concepts/JOR方法]]、[[concepts/SOR逐次超松弛方法]]与[[concepts/松弛因子与最优松弛因子]]。

## 7.2.2.2 共轭梯度法

若用迭代法求解很大的稀疏方程组 $Ax + b = 0$，其中 $A$ **对称正定**（这是椭圆边值问题离散化产生的矩阵类型），**共轭梯度法**尤为适用。该方法基于解 $x$ 是下列**二次泛函**取极小这一事实：

$$
\boxed{F(v) := \frac{1}{2}v^{\mathrm{T}}Av + b^{\mathrm{T}}v.}
$$

$F(v)$ 的极小是这样逐次确定的：从某个向量 $x^{(0)}$ 出发，沿着负梯度方向，找到第 $k$ 步的共轭下降方向 $p^{(k)}$，使 $F(v)$ 在该方向极小化。

### CG 算法（逐字保留）

```
开始：选取 x^(0), r^(0) = A x^(0) + b, p^(1) = -r^(0)
迭代 (k = 1, 2, ...)
  若 k > 1:
    e_{k-1} = r^{(k-1)^T} r^{(k-1)} / r^{(k-2)^T} r^{(k-2)},
    p^{(k)} = -r^{(k-1)} + e_{k-1} p^{(k-1)},
  z = A p^{(k)},   q_k = r^{(k-1)^T} r^{(k-1)} / p^{(k)^T} z,
  x^{(k)} = x^{(k-1)} + q_k p^{(k)},   r^{(k)} = x^{(k-1)} + q_k z,
  检验收敛.
```

### 正交性与有限终止性

在共轭梯度法（CG 方法）中，剩余向量 $r^{(k)}$ 是**两两正交**的，下降方向 $p^{(k)}$ 是**两两共轭**的，即有

$$
(p^{(k)})^{\mathrm{T}} A p^{(j)} = 0, \qquad j = 1, 2, \dots, k-1.
$$

因此该方法对 $n$ 个未知量的线性方程组 $Ax + b = 0$ **最多经过 $n$ 次迭代**就可以得到解 $x$。事实上，共轭梯度法第 $k$ 次迭代的解 $x^{(k)}$ 是泛函 $F(v)$ 关于子空间

$$
S_k := \operatorname{span}(\{p^{(1)}, p^{(2)}, \dots, p^{(k)}\}) = \operatorname{span}(\{p^{(0)}, p^{(1)}, \dots, p^{(k-1)}\})
$$

的全局极小，从而

$$
\boxed{F(x^{(k)}) = \min_{c_i} F\left(x^{(0)} + \sum_{i=1}^{k} c_i p^{(i)}\right).}
$$

由此可得误差 $e^{(k)} := x^{(k)} - x$ 类似地是按**能量范数** $\|z\|_A^2 = z^{\mathrm{T}}Az$ 的关于 $S_k$ 的极小。

### 收敛性估计

$$
\frac{\|e^{(k)}\|_A}{\|e^{(0)}\|_A} \leqslant 2\left(\frac{\sqrt{\kappa(A)} - 1}{\sqrt{\kappa(A)} + 1}\right)^{k}.
$$

由此可估计保证 $\|e^{(k)}\|_A / \|e^{(0)}\|_A \leqslant \varepsilon$ 的 CG 步数 $k$ 为

$$
k \leqslant \frac{1}{2}\sqrt{\kappa(A)} \cdot \ln\left(\frac{2}{\varepsilon}\right) + 1.
$$

该上界由容许值 $\varepsilon$ 和[[concepts/线性方程组的条件数|条件数]] $\kappa(A)$ 的**平方根**决定。

### 预条件

共轭梯度法的收敛性可以通过**预条件**而显著改进。这需要提前对要求解的方程组作变换，以得到具有较好条件数的矩阵 $\tilde{A}$。这是用一个 $n \times n$ 的正规矩阵 $C$ 变方程组 $Ax + b = 0$ 为 $\tilde{A}\tilde{x} + \tilde{b} = 0$，其中

$$
\tilde{A} := C^{-1}AC^{-\mathrm{T}}, \qquad \tilde{b} := C^{-1}b, \qquad \tilde{x} := C^{\mathrm{T}}x.
$$

这里 $\tilde{A}$ 是对称正定矩阵，且相似于

$$
K := C^{-\mathrm{T}}\tilde{A}C^{\mathrm{T}} = (CC^{\mathrm{T}})^{-1}A := M^{-1}A.
$$

为了使关于谱范数的条件数满足

$$
\kappa_2(\tilde{A}) = \kappa_2(K) = \kappa_2(M^{-1}A) \ll \kappa_2(A),
$$

预条件矩阵 $M = CC^{\mathrm{T}}$ 必须是 $A$ 的逼近。根据问题的不同特性，有多种选取预条件矩阵 $M$ 的方法，参见 [425]。详见[[concepts/预条件]]。
