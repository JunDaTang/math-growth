## 偏微分方程解的重要类型（原文例题）

原文：偏微分方程通常以函数作为其解。随后给出两个例题，以下 LaTeX 形式按原文逐字保留。

例 1：令 $\Omega$ 为 $R^{N}$ 中的一个非空开集, 微分方程

```
u _ {x _ {1}} (x) = 0, \quad \text { 在 } \Omega \text { 上 }
```

明显地以不依赖于 $x_{1}$ 的函数为其解。

例 2：微分方程

```
u _ {x y} = 0, \quad \text {在} \mathbb {R} ^ {2} \text {上}
```

明显地以形如

```
u (x, y) := f (x) + g (y)
```

的函数的集合作为其光滑解的集合, 其中 f 和 g 是光滑的。

对应的 finding 页：[[例1方程ux1等于0的解不依赖x1]]、[[例2方程uxy等于0的光滑解f加g]]。例 1 中定义域 $\Omega$ 的记号层面与既有概念 [[具有光滑边界的域]]、[[C0∞类函数]] 相关。

## 关于解的意义与附加条件（本节核心方法论论点）

原文：

> 对于物理问题, 不是去发现有意义的最一般的解, 而是去描述具体的过程. 为此, 我们对于微分方程附加某些限制, 它们在初始时刻 (初值) 或沿着边界 (边值) 描述了物理系统.

这是本节唯一给出的、连接 PDE 与物理问题的方法论要点：从「最一般的解族」转向「附加初值/边值条件挑出的具体过程」。它把常微分方程语境下的 [[初值问题]] 与 [[边值问题]] 推广到 PDE 语境，并与 [[适定性]] 的提问框架呼应。详见 finding：[[偏微分方程解的附加条件初值与边值]]。
