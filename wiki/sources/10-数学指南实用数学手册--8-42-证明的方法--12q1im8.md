# 《数学指南——实用数学手册》4.2 证明的方法

## 本节定位

本节紧接 4.1「数学的语言」，属于第 4 章「逻辑与证明」。4.1 提供命题、联结词、蕴涵、等值与换位等语言工具；4.2 则给出五类证明方法（间接证明、归纳法证明、唯一性证明、存在性证明、计算机时代证明的必要性），并用一节（4.2.6）专门剖析两类最常见的错误证明。本节正文首段即以「假设命题为假，于是该假设导致一个矛盾」刻画间接证明，正是 4.1 节遗留查询」[[queries/41节前向引用421与432未落地]]「中所等待落地的「4.2.1 间接证明」。

## 4.2.1 间接证明

核心机制：假设（试图证明的）命题为假，由此导出矛盾，从而该假设为假、原命题为真。

**例：$\sqrt{2}$ 不是有理数**（明确标注「下面的证明出自亚里士多德」）。证明是间接的：假设 $\sqrt{2}$ 为有理数并可写成

```
√2 = m/n        (4.4)
```

其中整数 $m$、$n$ 均不为 0，且可进一步假设 $m$ 与 $n$ 互素（否则约分）。

用到的两条基本事实（原文脚注 1) 给出其推导 $(2k)^2 = 4k^2$ 与 $(2k+1)^2 = 4k^2+4k+1$）：

- (i) 若 $p$ 是偶数，则 $p^2$ 能被 4 整除；
- (ii) 若 $p$ 是奇数，则 $p^2$ 也是奇数。

推理链：对 (4.4) 两边平方得

```
2n² = m²        (4.5)
```

于是 $m^2$ 为偶数；**根据 (ii) 的换位**知 $m$ 也一定是偶数（此处直接调用 [[concepts/换位]]）；又根据 (i) 知 $m^2$（原文写作「$m$」）一定能被 4 整除，而据 (4.5) 这意味着 $n^2$ 是偶数，故 $n$ 也是偶数。于是 $m$、$n$ 都是偶数，与「$m$ 与 $n$ 互素」矛盾。

## 4.2.2 归纳法证明

归纳法原理（出自 1.2.2.2）的使用方式：设命题 $\mathcal{A}(n)$ 对整数 $n \geqslant n_0$ 有定义，且满足

- (i) $\mathcal{A}(n)$ 对 $n = n_0$ 为真；
- (ii) $\mathcal{A}(n)$ 的正确性蕴涵 $\mathcal{A}(n+1)$ 的正确性，

则 $\mathcal{A}(n)$ 对所有 $n \geqslant n_0$ 的整数 $n$ 成立。

**例**：对一切正自然数 $n$，

```
1 + 2 + … + n = n(n+1)/2        (4.6)
```

证明分三步：步骤 1 验证 $n=1$；步骤 2 由 $\mathcal{A}(n)$ 推 $\mathcal{A}(n+1)$，其中关键计算为

$$\frac{(n+1)(n+2)}{2} = \frac{n^2+n+2n+2}{2} = \frac{n(n+1)}{2} + n + 1;$$

步骤 3 由归纳法原理断言 $\mathcal{A}(n)$ 对所有 $n \geqslant 1$ 成立。

## 4.2.3 唯一性证明

定义：一个唯一性命题表达了**仅存在有限多个**具有给定性质的对象这一事实。

**例**：至多有一个正实数 $x$ 使得

```
x² + 1 = 0        (4.7)
```

证明：假设有两个解 $a$ 与 $b$，则 $a^2+1=0$ 与 $b^2+1=0$ 意味着 $a^2-b^2=0$，即 $(a-b)(a+b)=0$。由于 $a>0$ 且 $b>0$，得 $a+b>0$；等式左边除以 $a+b$ 推出 $a-b=0$，即 $a=b$。

## 4.2.4 存在性证明

本节强调「解的唯一性」与「解的存在性」之间必须作明确区分。方程 (4.7) 至多有一个正实数解，这意味着它要么有一个解要么根本没有解；事实上 (4.7) 没有实数解——原文的论证是「假如 $x$ 是 (4.7) 的一个实数解，则由 $x \geqslant 0$ 我们立刻得到关系 $x^2+1>0$，这与 $x^2+1=0$ 矛盾」。

存在性证明有两种类型：(i) 存在性的抽象证明；(ii) 存在性的构造证明。一般而言，存在性的证明要比唯一性的证明困难得多。

**例：方程 $x^2 = 2$ 有一个实数解**（4.8）。

- **抽象证明**：定义集合 $A := \{a \in \mathbb{R} : a < 0 \text{ 或 } (a \geqslant 0 \text{ 且 } a^2 \leqslant 2)\}$ 与 $B := \{a \in \mathbb{R} : a \geqslant 0 \text{ 且 } a^2 > 2\}$。每个实数属于 $A$ 或 $B$ 之一，且 $0 \in A$、$2 \in B$，故两者非空。由 1.2.2.1 的完备性公理，存在实数 $\alpha$ 使

```
a ≤ α ≤ b   （对所有 a ∈ A 及所有 b ∈ B）      (4.9)
```

  继而证明 $\alpha^2 = 2$：否则在情形 1（$\alpha^2<2$ 且 $\alpha>0$）可取足够小的 $\varepsilon>0$，例如 $\varepsilon = \min\left(\frac{2-\alpha^2}{2\alpha+1}, 1\right)$，使 $(\alpha+\varepsilon)^2 < 2$，即 $\alpha+\varepsilon \in A$，由 (4.9) 得 $\alpha+\varepsilon \leqslant \alpha$，矛盾；情形 2（$\alpha^2>2$ 且 $\alpha>0$）类似不可行。故假设 $\alpha^2 \neq 2$ 为假。
- **唯一性证明**：同 4.2.3，可证 (4.8) 至多有一个正解。
- **结论**：(4.8) 有唯一正解，通常记作 $\sqrt{2}$。

**构造证明**：证明迭代

```
a_{n+1} = a_n/2 + 1/a_n,  n = 1, 2, …        (4.10)
```

收敛于 $\sqrt{2}$（取 $a_1 := 2$）。步骤 1 用归纳法证 $a_n>0$；步骤 2 用 [[concepts/伯努利不等式]]证 $a_n^2 \geqslant 2$，其中

$$a_{n+1}^2 = a_n^2\left(1 + \frac{2-a_n^2}{2a_n^2}\right)^2 \geqslant a_n^2\left(1 + \frac{2-a_n^2}{a_n^2}\right) = 2;$$

步骤 3 由

$$a_n - a_{n+1} = a_n - \frac{1}{2}\left(a_n + \frac{2}{a_n}\right) = \frac{1}{2a_n}(a_n^2-2) \geqslant 0$$

知 $(a_n)$ 递减且有下界，据 1.2.4.1 的收敛性判据存在极限 $x$；在 (4.10) 中取极限得 $x = x/2 + 1/x$，即 $x^2=2$，又 $a_n \geqslant 0$ 故 $x \geqslant 0$，于是 $x = \sqrt{2}$。

## 4.2.5 计算机时代证明的必要性

本节反对「计算机算力使理论研究多余」的看法，给出解决一个数学问题的流程：

1. 证明解的存在性（存在性的抽象证明）；
2. 证明解的唯一性；
3. 研究（已知存在的）解对问题参数小扰动的稳定性；
4. 开发在计算机上计算该解（的近似值）的算法；
5. 证明该算法的收敛性，即在适当假设下算法收敛于唯一解；
6. 检验算法所给近似值的一个估计；
7. 研究算法的收敛速度；
8. 证明算法的数值稳定性。

其中 (v) 与 (vi) 的关键前提是已知唯一解的存在性，否则计算机给出可能是**虚幻解**（貌似解但现实中不存在）。若 (i)、(ii)、(iii) 得到保证，该问题被称为**适定问题**。

近似值的估计分两类：(a) 先验估计；(b) 后验估计。原文把这些概念类比于康德（1724—1804）的哲学：先验估计在计算机作计算之前给出误差信息，后验估计使用已经作过的计算所获得的信息。作为实际经验，「后验估计比先验估计更精确」。算法必须数值稳定（关于舍入误差稳固），且迭代过程尤其适合数值计算。

**例**：对 (4.10) 产生的 $(a_n)$，记 $\Delta_n = a_n - \sqrt{2}$，则

```
Δ_{n+1} ≤ Δ_n²                      （收敛速度：二次收敛）
Δ_{n+2} ≤ 10^{−2^n}                 （先验估计）
2/a_n ≤ √2 ≤ a_n                    （后验估计）
```

由表 4.1 一眼看出 $\sqrt{2} = 1.414213562 \pm 10^{-9}$。

表 4.1 $\sqrt{2}$ 的逐次近似值（原文数据）

| n | $a_n$ | $2/a_n$ |

## 4.2.6 不正确的证明

证明中两个最主要的错误是「被零除」的一步，以及「沿错误的方向」证明命题。

**4.2.6.1 被零除**（详见 [[concepts/被零除错误]]）：错误断言方程 (4.11) 恰有一个实数解 $x=1$；错误在于由 (4.12) 除以 $x_0$，而这只能在 $x_0 \neq 0$ 的假定下进行。正确断言是 (4.11) 恰有两个解 $x=1$ 与 $x=0$。

**4.2.6.2 沿错误方向的证明**（详见 [[concepts/沿错误方向的证明]]）：常犯错误是试图通过证明逆蕴涵 $\mathcal{B} \Rightarrow \mathcal{A}$ 来证明 $\mathcal{A} \Rightarrow \mathcal{B}$，所谓「0 = 0」证明即属此类。

## 关键公式原始形式

```
√2 = m/n                                        (4.4)
2n² = m²                                        (4.5)
1 + 2 + … + n = n(n+1)/2                        (4.6)
x² + 1 = 0                                      (4.7)
x² = 2                                          (4.8)
a ≤ α ≤ b（对所有 a ∈ A 与所有 b ∈ B）          (4.9)
a_{n+1} = a_n/2 + 1/a_n,  n = 1, 2, …           (4.10)
(x−2)(x+1) + 2 = 0                              (4.11)
x₀(x₀−1) = 0                                    (4.12)
x² − 4x + 3x + 1 = (x−1)² + 3x                  (4.13)
x² − x + 1 = x² − 2x + 1 + 3x = x² + x + 1      (4.14)
−x = x                                          (4.15)
x² = x²                                         (4.16)
0 = 0                                           (4.17)
```

伯努利不等式（原文脚注）：对于满足 $r \geqslant -1$ 的一切实数 $r$ 以及一切自然数 $n$，有 $(1+r)^n \geqslant 1+nr$。
