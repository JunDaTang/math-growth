# 《数学指南——实用数学手册》1.4.2 链式法则

## 概述

本页是《数学指南——实用数学手册》1.4 节「一个实变量函数的微分法」第二个子节 **1.4.2 链式法则** 的入库摘要。该子节篇幅完整（非残片），主体由四部分构成：

1. 莱布尼茨符号下的链式法则公式 (1.30)；
2. 两个应用算例——$y = \sin x^{2}$ 与 $f(x) := b^{x}$（$b > 0$）；
3. 带两条前提假设的链式法则正式定理陈述；
4. 一段以「思想上的障碍」为小标题的方法论评注，讨论启发式法则与形式化阐述之间的落差。

全节**未给出定理证明**，两个算例的中间步骤全部援引 0.8.1 节（重要导数表）。

## 核心公式：莱布尼茨形式的链式法则 (1.30)

原文以方框标出，公式如下（逐字保留）：

```latex
\boxed{\frac{\mathrm{d} y}{\mathrm{d} x} = \frac{\mathrm{d} y}{\mathrm{d} u} \frac{\mathrm{d} u}{\mathrm{d} x}.}\tag{1.30}
```

原文说明该公式「用莱布尼茨符号很容易记住」，即该记法把链式法则呈现为分数相乘的形态。参见 [[莱布尼茨符号]]。

## 例 1：$y = f(x) = \sin x^{2}$ 的求导

原文逐字保留如下：

```latex
y = \sin u, \quad u = x^{2},

\frac{\mathrm{d} y}{\mathrm{d} u} = \cos u, \quad \frac{\mathrm{d} u}{\mathrm{d} x} = 2x,

f^{\prime}(x) = \frac{\mathrm{d} y}{\mathrm{d} x}
= \frac{\mathrm{d} y}{\mathrm{d} u} \frac{\mathrm{d} u}{\mathrm{d} x}
= 2x \cos u = 2x \cos x^{2}.
```

其中 $\dfrac{\mathrm{d} y}{\mathrm{d} u} = \cos u$ 与 $\dfrac{\mathrm{d} u}{\mathrm{d} x} = 2x$ 两个基本导数均标注「根据 0.8.1」。详见 [[链式法则例1求导sinx平方]]。

## 例 2：$f(x) := b^{x}$（$b > 0$）的求导

原文结论与证明逐字保留如下：

```latex
f^{\prime}(x) = b^{x} \ln b, \quad x \in \mathbb{R}.

f(x) = \mathrm{e}^{x \ln b}, \quad y = \mathrm{e}^{u}, \quad u = x \ln b.

\frac{\mathrm{d} y}{\mathrm{d} u} = \mathrm{e}^{u}, \quad \frac{\mathrm{d} u}{\mathrm{d} x} = \ln b,

f^{\prime}(x) = \frac{\mathrm{d} y}{\mathrm{d} x}
= \frac{\mathrm{d} y}{\mathrm{d} u} \frac{\mathrm{d} u}{\mathrm{d} x}
= \mathrm{e}^{u} \ln b = b^{x} \ln b.
```

此处同样标注「由 0.8.1」得到 $\dfrac{\mathrm{d} y}{\mathrm{d} u} = \mathrm{e}^{u}$ 与 $\dfrac{\mathrm{d} u}{\mathrm{d} x} = \ln b$。详见 [[链式法则例2给出b的x次幂的导数]]。

## 定理（链式法则）的正式陈述

原文「(1.30) 的明确阐述如下」，逐字保留：

```latex
F(x) := g(f(x)) \implies F^{\prime}(p) = g^{\prime}(f(p)) f^{\prime}(p)
```

前提假设：

```text
(i)   函数 f: M → ℝ 的定义域是 p 的邻域 U(p)，并且导数 f'(p) 存在。
(ii)  函数 g: N → ℝ 的定义域是 f(p) 的邻域 U(f(p))，并且导数 g'(f(p)) 存在。
```

即：复合函数 $F = g \circ f$ 在点 $p$ 处的导数存在，且等于外函数在 $f(p)$ 处的导数与内函数在 $p$ 处的导数之积。两条前提均以 [[邻域]] 用语表述定义域条件。详见 [[链式法则定理的两条邻域前提]]。

## 方法论评注：「思想上的障碍」

原文小标题为「思想上的障碍」，逐字保留其论点：

> 链式法则表明, 明确的数学阐述可能比启发性的法则更难使用. 遗憾的是, 它常常造成数学家、物理学家和工程师之间的障碍, 因此必须以某种方式解决. 事实上, 最好能同时知道启发性的法则和形式上的法则, 以及明确的数学阐述, 这样就可以以最小的工作量去作计算, 另一方面又知道形式法则可能出现的不正确的应用.

该段是本节独有的元层面论点：计算效率（启发式口诀）与严谨性（带前提的形式化定理）应同时掌握。详见 [[链式法则形式化阐述比启发式法则更难用]] 与 [[启发式法则与形式化阐述]]。
