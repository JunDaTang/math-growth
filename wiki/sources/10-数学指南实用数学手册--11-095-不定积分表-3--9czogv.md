# 《数学指南——实用数学手册》0.9.5 不定积分表-3

## 文档定位

本文件是《数学指南——实用数学手册》0.9 节积分表中 0.9.5「不定积分表」的第 3 部分，收录积分条目 **342–500**。它上承已入库的 0.9.4 节[[重要代换]]（其中表 0.44、0.45、0.46 与 [[欧拉代换]]、[[二项积分]] 等条目直接指向本表的若干公式），并与同属 0.9.5 的[[不定积分表]]前两部分（1–341 号）以及后续部分（501 号起）共同构成全表。

文档本身是纯公式表，没有新的人物、机构或数据集；其信息主体是[[表095不定积分表-3]]这一数据对象，以及由它引入的两个特殊函数 [[积分指数函数Ei]] 与 [[对数积分li]]。

## 关键公式（原文转写）

以下按主题摘录若干条目，其余条目见 [[表095不定积分表-3]]。

### 342–343：分母含 β² ± γ²cos²αx

```latex
342. ∫ dx/(β² + γ² cos²αx) = (1/(αβ√(β²+γ²))) arctan( β tan αx / √(β²+γ²) ),   (β > 0).

343. ∫ dx/(β² − γ² cos²αx)
   = (1/(αβ√(β²−γ²))) arctan( β tan αx / √(β²−γ²) ),   β² > γ², β > 0;
   = (1/(2αβ√(γ²−β²))) ln( (β tan αx − √(γ²−β²)) / (β tan αx + √(γ²−β²)) ),   γ² > β², β > 0.
```

### 348、359、370、381：幂型递推公式

```latex
348. ∫ sin^n αx cos^m αx dx
   = − sin^{n−1} αx cos^{m−1} αx / (α(n+m)) + ((n−1)/(n+m)) ∫ sin^{n−2} αx cos^m αx dx
   =   sin^{n+1} αx cos^{m−1} αx / (α(n+m)) + ((m−1)/(n+m)) ∫ sin^n αx cos^{m−2} αx dx
   (m, n ∈ ℕ; n > 0).

359. ∫ dx/(sin^n αx cos^m αx)
   = − 1/(α(n−1)) · 1/(sin^{n−1} αx cos^{m−1} αx) + ((n+m−2)/(n−1)) ∫ dx/(sin^{n−2} αx cos^m αx)
   =   1/(α(m−1)) · 1/(sin^{n−1} αx cos^{m−1} αx) + ((n+m−2)/(m−1)) ∫ dx/(sin^n αx cos^{m−2} αx).

370. ∫ sin^n αx / cos^m αx dx
   = sin^{n+1} αx / (α(m−1) cos^{m−1} αx) − ((n−m+2)/(m−1)) ∫ sin^n αx / cos^{m−2} αx dx
   = sin^{n−1} αx / (α(m−1) cos^{m−1} αx) + ((n−1)/(m−1)) ∫ sin^{n−2} αx / cos^{m−2} αx dx.

381. ∫ cos^n αx / sin^m αx dx
   = − cos^{n+1} αx / (α(m−1) sin^{m−1} αx) − ((n−m+2)/(m−1)) ∫ cos^n αx / sin^{m−2} αx dx
   =   cos^{n−1} αx / (α(n−m) sin^{m−1} αx) + ((n−1)/(n−m)) ∫ cos^{n−2} αx / sin^m αx dx
   = − cos^{n−1} αx / (α(m−1) sin^{m−1} αx) − ((n−1)/(m−1)) ∫ cos^{n−2} αx / sin^{m−2} αx dx.
```

### 403、404、412、413：正切与余切积分的伯努利数级数

```latex
403. ∫ x tan αx dx
   = αx³/3 + α³x⁵/15 + 2α⁵x⁷/105 + 17α⁷x⁹/2835 + …
   + 2^{2n}(2^{2n}−1) B_{2n} α^{2n−1} x^{2n+1} / (2n+1)! + …

404. ∫ tan αx / x dx
   = αx + (αx)³/9 + 2(αx)⁵/75 + 17(αx)⁷/2205 + …
   + 2^{2n}(2^{2n}−1) B_{2n} (αx)^{2n−1} / ((2n−1)(2n!)) + …
   （B_{2n} 为伯努利数，参看 0.1.10.4）

412. ∫ x cot αx dx
   = x/α − αx³/9 − α³x⁵/225 − …
   − 2^{2n} B_{2n} α^{2n−1} x^{2n+1} / (2n+1)! − …

413. ∫ cot αx / x dx
   = −1/(αx) − αx/3 − (αx)³/135 − 2(αx)⁵/4725 − …
   − 2^{2n} B_{2n} (αx)^{2n−1} / ((2n−1)(2n)!) − …
```

### 420：积分指数函数 Ei(x)

```latex
420. ∫ e^{αx}/x dx = ln x + αx/(1·1!) + (αx)²/(2·2!) + (αx)³/(3·3!) + …

广义积分 ∫_{−∞}^{x} e^t/t dt 称为积分指数函数，记为 Ei(x)。当 x > 0 时，
该积分在 t = 0 处发散，此时 Ei(x) 是这个广义积分的主值（参看 0.5.5 和 0.7.2）。

∫_{−∞}^{x} e^t/t dt = C + ln x + x/(1·1!) + x²/(2·2!) + x³/(3·3!) + … + x^n/(n·n!) + …
（C 为欧拉常数，参看 0.1.1）
```

### 438：对数积分 li(x)

```latex
438. ∫ dx/ln x = ln ln x + ln x + (ln x)²/(2·2!) + (ln x)³/(3·3!) + …

积分 ∫ dt/ln t 称为对数积分，记为 li(x)。当 x > 1 时，它在点 t = 1 处发散。
此时，函数 li(x) 的值是这个广义积分的主值（参看 0.5.5 和 0.7.2）。
```

### 451–453：含 ln sin x、ln cos x、ln tan x 的级数

```latex
451. ∫ ln sin x dx = x ln x − x − x³/18 − x⁵/900 − … − 2^{2n−1} B_{2n} x^{2n+1} / (n(2n+1)!) − …

452. ∫ ln cos x dx = −x³/6 − x⁵/60 − x⁷/315 − … − 2^{2n−1}(2^{2n−1}) B_{2n} x^{2n+1} / (n(2n+1)!) − …

453. ∫ ln tan x dx = x ln x − x + x³/9 + 7x⁵/450 + …
     + 2^{2n}(2^{2n−1}−1) B_{2n} x^{2n+1} / (n(2n+1)!) + …（B_{2n} 为伯努利数）
```

### 462：含双曲余弦幂的递推

```latex
462. ∫ cosh^n αx dx
   = (1/(αn)) sinh αx cosh^{n−1} αx + ((n−1)/n) ∫ cosh^{n−2} αx dx,   n ∈ ℕ, n > 0;
   = −(1/(α(n+1))) sinh αx cosh^{n+1} αx + ((n+2)/(n+1)) ∫ cosh^{n+2} αx dx,   n ∈ ℤ, n < −1.
```

### 478–500：含反三角函数（样例）

```latex
478. ∫ arcsin(x/α) dx = x arcsin(x/α) + √(α²−x²)   (|x| < |α|).

488. ∫ arctan(x/α) dx = x arctan(x/α) − (α/2) ln(α²+x²).

495. ∫ arccot(x/α) dx = x arccot(x/α) + (α/2) ln(α²+x²).

498. ∫ x^n arccot(x/α) dx = x^{n+1}/(n+1) · arccot(x/α) + (α/(n+1)) ∫ x^{n+1} dx/(α²+x²)
      (n ∈ ℕ, 参看第 501 个积分).
```

## 两个特殊函数

本部分首次在 0.9.5 中引入两个「非初等」对象，二者都以**广义积分的主值**方式定义：

- [[积分指数函数Ei]]：Ei(x) = PV ∫_{−∞}^{x} e^t/t dt，级数含[[欧拉常数]] C。
- [[对数积分li]]：li(x) = PV ∫ dt/ln t（源文写作 ∫_0^∞ dt/ln t，上限疑为转写错误，见 [[095节公式转写疑误汇总]]）。

两者都把 0.9.5 的积分表与手册 0.5.5（特殊函数）和 0.7.2（幂级数）两处前后呼应，也是本表中少数不能表为初等函数的条目。

## 交叉引用体系

本部分的显著特征是条目之间大量互指（「参看第 … 个积分」），把 344–500 号织成一张**递推网络**：

- 幂型三角积分互指：344 ↔ 398、346 ↔ 358、347 ↔ 357、348 ↔ 359/370/381。
- 递推式的落脚点集中在少数「基元」条目：279（∫dx/sin^n αx）、296、315/316/318（∫dx/cos^n αx）、416 ↔ 428/430、429/431、420 ↔ 427/445/456、438 ↔ 439、441/444/446/450、491 ↔ 494、498 → 501。
- 表外引用：0.1.1（欧拉常数）、0.1.10.4（伯努利数）、0.5.5、0.7.2。

具体分析见 [[095节递推公式网络形成交叉引用体系]]。

## 转写与编号疑点

- 编号错位：361 与 362 的位置互换（361 号条目被标为 362.），377 与 378 同样错位。
- 缺号：354、358、362（第二个 sin αx/cos^n αx 公式）、461 等条目在源中未带编号；461 只给出被积式而无结果。
- 公式疑误：345 的常数项、452 的伯努利数系数因子、471 的被积式、486 的 π/x、497 的 x³/α、363 一类条目缺积分常数等。
- 星号含义：344–348、416–419、428–433、457–460、463–469、473 等条目带「*」标记，但源未说明其含义。
