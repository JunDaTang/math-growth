# 《数学指南——实用数学手册》6.3.3 正态分布测量值的研究

## 本节定位

本节是《数学指南——实用数学手册》第 6 章「概率论与数理统计」中 6.3 节「数理统计」的第三个部分。它承接 [[数理统计基本策略]] 所确立的置信区间思路（见 [[631节置信区间定义与数理统计基本策略]]）与 [[632节期望与方差的估计量及其抽样分布]] 所给出的估计量及其抽样分布，把「估计量」推进到可直接执行的**区间估计与显著性检验程序**：两个置信区间（期望、标准差）与三个显著性检验（t 检验、F 检验、相关检验）。

全节的组织方式是「一个总前提 + 五个并列程序」，末尾以一句话指向 6.3.4.4 的正态分布检验。

## 总前提：正态假定

> 人们通常假定一个给定的随机变量服从正态分布. 这个结果理论上的合理性来自于中心极限定理 (见 6.2.4.3).

- 假定对象：给定的随机变量 $X$ 服从 [[高斯正态分布]] $N(\mu, \sigma)$。
- 理论依据：[[中心极限定理]]（6.2.4.3）。源文只引用章节号，未在本节内给出推导。
- 关于本节各程序的数值例子，源文指引读者查阅附录 0.4。

## 6.3.3.1 期望 $\mu$ 的置信区间

由测量值 $x_1, x_2, \cdots, x_n$ 计算经验期望与经验标准差：

```text
x̄      = (1/n) · Σ_{j=1}^{n} x_j
Δx     = sqrt( (1/(n-1)) · Σ_{j=1}^{n} (x_j - x̄)^2 )
```

关于期望 $\mu$ 的不等式

```text
| x̄ - μ | ≤ (Δx / sqrt(n)) · t_{α, n-1}          (6.30)
```

成立的概率为 $1 - \alpha$，其中 $t_{\alpha, n-1}$ 可在 0.4.6.3 中查到。

**推理**：随机变量 $\sqrt{n}(M - \mu)/S$ 服从自由度为 $n-1$ 的 [[t分布]]，由 $P(|T| \le t_{\alpha, n-1}) = 1 - \alpha$ 推出上式。

## 6.3.3.2 标准差 $\sigma$ 的置信区间

关于标准差的不等式

```text
(n-1)(Δx)^2 / b ≤ σ^2 ≤ (n-1)(Δx)^2 / a     (6.31)

其中  a := χ²_{1-α/2} ，b := χ²_{α/2}
分布自由度 m = n - 1
```

成立的概率为 $1 - \alpha$，$a$ 与 $b$ 的值可在 0.4.6.4 中查到。

**推理**：$A := (n-1)S^2/\sigma^2$ 服从自由度为 $n-1$ 的 [[卡方分布]]。由图 0.50 得

```text
P(a ≤ A ≤ b) = P(A ≥ a) - P(A ≥ b) = 1 - α/2 - α/2 = 1 - α
```

因此 $a \le (n-1)(\Delta x)^2/\sigma^2 \le b$ 成立的概率为 $1-\alpha$，由此导出 (6.31)。

## 6.3.3.3 基本显著性检验（t 检验）

**目的**：通过对随机变量 $X$ 和 $Y$ 的两个变异序列的研究，确定二者是否具有相同的期望，即 $X$ 与 $Y$ 之间是否有显著的差异。

**假定**：$X$ 和 $Y$ 服从**标准差相同**的正态分布（源文此处带脚注标记 1））。

**假设**：$X$ 和 $Y$ 具有相同的期望。

**变列**（6.32）：

```text
x_1, …, x_{n_1}  和  y_1, …, y_{n_2}          (6.32)
```

先算出经验期望 $\bar x, \bar y$ 与经验标准差 $\Delta x, \Delta y$，再计算统计量（6.33）：

```text
t := (x̄ - ȳ) / sqrt( (n_1 - 1)(Δx)^2 + (n_2 - 1)(Δy)^2 )
     · sqrt( n_1 n_2 (n_1 + n_2 - 2) / (n_1 + n_2) )     (6.33)
```

**统计说明**：如果

```text
| t | > t_{α, m}
```

则在错误概率 $\alpha$ 下拒绝上述假设，即认为 $X$ 与 $Y$ 的期望有显著差异。$t_{\alpha,m}$ 可在 0.4.6.3 中查到，自由度 $m = n_1 + n_2 - 2$。

**推理**：把 (6.33) 中的 $\bar x, \bar y, (\Delta x)^2, (\Delta y)^2$ 分别换为随机量 $\overline X, \overline Y, S_X^2, S_Y^2$，所得随机变量 $T$ 服从自由度为 $m$ 的 t 分布；由 $P(|T| > t_\alpha) = \alpha$，故当 $|t| > t_\alpha$ 时拒绝所作假设。

## 6.3.3.4 F 检验

**用途**：确定两个正态分布随机变量的标准差是否相同。

**假定**：随机变量 $X$ 和 $Y$ 均服从正态分布。

**假设**：$X$ 和 $Y$ 具有相同的标准差。

**变列**：由观测值 (6.32) 算出经验标准差 $\Delta x$ 与 $\Delta y$，不妨设 $\Delta x \ge \Delta y$。

**统计说明**：如果

```text
( Δx / Δy )^2 > F_α                            (6.34)
```

则拒绝所作假设，犯错误的概率为 $\alpha$。$F_\alpha$ 可在 0.4.6.5 中查到，其中 $m_1 = n_1 - 1$，$m_2 = n_2 - 1$。

另一方向：如果 (6.34) 的右边是「$\le F_\alpha$」，则观测结果与所作假设不矛盾，此时犯错误的概率为 $\alpha^{*}$。

**推理**：若假设成立，随机变量 $F := S_X^2 / S_Y^2$ 服从自由度为 $(m_1, m_2)$ 的 [[F分布]]；由 $P(F \ge F_\alpha) = \alpha$，故 (6.34) 成立时拒绝假设，犯错误概率为 $\alpha$。

## 6.3.3.5 相关检验

**用途**：检验两个随机变量 $X$ 和 $Y$ 是否相关。

**假定**：$X$ 和 $Y$ 均服从正态分布。

**假设**：相关系数 $r = 0$，即 $X$ 与 $Y$ 不相关。

**变列**：由测量值（6.35）

```text
x_1, …, x_n  和  y_1, …, y_n                    (6.35)
```

计算经验相关系数

```text
ρ = m_{XY} / (Δx · Δy)

经验协方差  m_{XY} := (1/(n-1)) · Σ_{j=1}^{n} (x_j - x̄)(y_j - ȳ)
```

**统计说明**：当

```text
ρ · sqrt(n - 2) / sqrt(1 - ρ^2) > t_{α, m}      (6.36)
```

成立时，拒绝 $X$ 与 $Y$ 不相关的假设，犯错误的概率为 $\alpha$。$t_{\alpha,m}$ 可在 0.4.6.3 中查到，其中 $m = n - 2$。

**推理**：令

```text
R := Σ (X_j - X̄)(Y_j - Ȳ)
     / ( Σ (X_j - X̄)^2 · Σ (Y_j - Ȳ)^2 )^{1/2}
```

则随机变量 $R\sqrt{n-2}/\sqrt{1-R^2}$ 服从自由度为 $n-2$ 的 t 分布。由观测值 (6.35) 可得 $R$ 的一个实现 $\rho$；由 $P(|R| \ge t_\alpha) = \alpha$，故 (6.36) 成立时拒绝所作假设，犯错误概率为 $\alpha$。
