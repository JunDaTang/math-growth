# 表 0.40（不定积分的计算法则）

《数学指南——实用数学手册》0.9.2.1 节给出的不定积分计算法则表，共五条。原文表述为「表 0.40 中介绍了不定积分的计算法则」，表带脚注标号 $^{1)}$，但脚注文字未在源文件中出现。

| 法则名称 | 公式 |
|---|---|
| 加法法则 | $\int (u + v) \mathrm{d}x = \int u \mathrm{d}x + \int v \mathrm{d}x$ |
| 与常数的乘积法则 | $\int \alpha u \mathrm{d}x = \alpha \int u \mathrm{d}x$（$\alpha$ 为常数） |
| 分部积分公式 | $\int u'v \mathrm{d}x = uv - \int uv'\mathrm{d}x$ |
| 代换公式 | $\int f(x) \mathrm{d}x = \int f(x(t)) \frac{\mathrm{d}x}{\mathrm{d}t} \mathrm{d}t$ |
| 对数导数 | $\int \frac{f'(x)}{f(x)} \mathrm{d}x = \ln \lvert f(x) \rvert$ |

## 相关条目

- 表中「加法法则」与「与常数的乘积法则」合起来即积分的线性性。
- 「分部积分公式」另见 [[concepts/分部积分公式]]；「代换公式」另见 [[concepts/代换公式]]。
- 「对数导数」另见 [[concepts/对数导数法则]]。
- 表中代换公式对应的记忆形式为 (0.56)，见 [[concepts/代换公式的记忆形式]]。
- 原表在讨论 (0.56) 时提到，本表为保证反函数 $t=t(x)$ 存在须事先假定 $x'(t)=0$，与上下文矛盾，见 [[queries/表040代换公式中x导数等于0的转写疑误]]。
