# 图 0.51（F 分布密度与上侧分位点）

0.4.6.6 节「$F$ 分布的值 $F_{0.05;m_1,m_2}$ 与 $F_{0.01,m_1,m_2}$ (粗体)」下的唯一图形，是 [[F分布]] 密度函数的示意图，用来说明 [[F分布上侧分位点]] $F_\alpha$ 的含义。

## 图面内容

- 一条右偏的概率密度曲线：自横轴原点附近迅速上升，达到单峰后向右拖出长尾。
- 横轴原点标注为「0」，并在轴上标出临界值 $F_\alpha$。
- $F_\alpha$ 右侧的尾部区域用斜线阴影填充，并以希腊字母 $\alpha$ 标注该阴影面积，即显著性水平对应的拒绝域。

## 用途

该图仅作几何说明，不含数值；具体临界值应由 0.4.6.6 的 $F_{0.05;m_1,m_2}$ 与 $F_{0.01;m_1,m_2}$ 数值表查得。本文件未包含这些数值表，见 [[queries/0466节f分布数值表正文缺失]]。
