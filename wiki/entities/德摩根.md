# 德摩根

**Augustus De Morgan（德摩根）**在《数学指南——实用数学手册》4.1.3 节中并未被正文展开介绍，仅以定律名出现：重言式 (v)「析取的否定（德摩根律）」与 (vi)「合取的否定（德摩根律）」两处各带脚注 1)，指向德摩根。

$$
\text { 非 } (\mathcal {A} \text { 或 } \mathcal {B}) \Leftrightarrow (\text { 非 } \mathcal {A} \text { 且非 } \mathcal {B}),
$$

$$
\text {非} (\mathcal {A} \text {且} \mathcal {B}) \Leftrightarrow (\text {非} \mathcal {A} \text {或非} \mathcal {B}).
$$
