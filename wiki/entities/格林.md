# 格林（George Green）

英国数学家，[[格林函数]] 的命名者。本节 1.12.1.5 中，谐振子初值问题 (1.212) 的唯一解 (1.213) 以格林函数为积分核：

```latex
x(t) = x_0 \cos \omega t + \frac{v}{\omega}\sin \omega t + \int_0^t G(t,\tau) F(\tau)\,\mathrm{d}\tau,  \tag{1.213}
```

其中
```latex
G(t,\tau) := \frac{1}{\omega}\sin \omega(t-\tau).
```

源文仅以「格林 (Green) 函数」这一术语形式提及，未给出其生卒年或更多背景。
