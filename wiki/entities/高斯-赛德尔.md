# 高斯-赛德尔（Gauss-Seidel）

「高斯-赛德尔」是高斯与赛德尔两人姓氏的复合命名，在《数学指南——实用数学手册》7.2.2.1 节中作为**算法命名者**出现：

- **单步方法**（Einzelschrittverfahren）**也称为高斯-赛德尔方法**，其迭代格式为 $(D - L)x^{(k+1)} = Ux^{(k)} - b$；
- 对应的不动点迭代单元记为 $T_E := (D-L)^{-1}U$、$c_E := (D-L)^{-1}b$；
- 按分量写出为 $x_i^{(k+1)} = -\left(b_i + \sum_{j=1}^{i-1} a_{ij}x_j^{(k+1)} + \sum_{j=i+1}^{n} a_{ij}x_j^{(k)}\right) / a_{ii}$，其特点是在同一次迭代中立即使用已经更新的分量值。

本节给出的收敛结论是：单步方法收敛的**充分条件**是 $A$ 为对角占优矩阵**或** $A$ 对称正定。
