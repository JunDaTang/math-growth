# 施泰尼茨（Steinitz）

与 [[施泰尼茨基交换定理]] 相关的数学家。2.3.2 节以该定理说明：若 $b_1,\dots,b_n$ 是线性空间 X 的基，而 $u_1,\dots,u_r$ 是 X 中线性无关的元素，则（必要时重新编号后）$u_1,\dots,u_r,b_{r+1},\dots,b_n$ 形成 X 的新基。
