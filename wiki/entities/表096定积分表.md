# 表 0.9.6（定积分表，条目 1–56）

表 0.9.6 是《数学指南——实用数学手册》第 0.9 节「积分表」下的第四个表组 [[定积分表]] 的首段，本节收录条目 1–56。表以被积函数类型为分节依据，共三个子节：

- **0.9.6.1 含指数函数的积分**（条目 1–32）：开篇说明其考察对象为「含指数函数、代数函数、三角函数和对数函数的积分」；既包含纯指数型（条目 1–7），也包含指数函数与三角函数、对数函数混合的积分（条目 8–11、21–26），以及三角函数系正交性与椭圆型积分（条目 12–20、27–32）。
- **0.9.6.2 含对数函数的积分**（条目 33–49）：对数函数与有理函数、三角函数混合的定积分，主区间为 [0,1]、[0,π/2]、[0,π]。
- **0.9.6.3 含代数函数的积分**（条目 50–56）：以 [[贝塔函数]] 形式出现的积分，以及含 x^α、x^β 的分式积分。

## 表达工具

表内反复出现的常函数与符号：

- [[伽马函数]] Γ(x)：条目 1、2、12、38、39、50、54；
- [[贝塔函数]] B(x,y)：条目 12、50，源文档在此明示其为第一类欧拉积分，Γ 为第二类欧拉积分，见 [[欧拉积分]]；
- [[欧拉常数]] C ≈ 0.5772：条目 9、10、11、33、44、45；
- [[克罗内克符号]] δ_{m,n}：条目 13、15；
- [[完全椭圆积分]] E、K：条目 30、31。

## 与不定积分表的对应

本表条目 12 与 0.9.5 节的 [[不定积分表]] 中同类条目同源；条目 1、2 的形式与 [[含指数函数的积分]] 中的不定积分条目互补。定积分表给出的是在固定上下限（多为 0 到 ∞ 或 0 到 π/2）上的确定值，因此大量结果只能用 Γ、B、C、E、K 等特殊常数表达。

## 编号与转写情况

条目 2、5、10、38、47 在入库文本中未印出序号；条目 12、29 的序号数字与小数点间存在排版间隙。详见 [[096节条目编号在多个公式处缺失]] 与 [[096节公式转写疑误汇总]]。
