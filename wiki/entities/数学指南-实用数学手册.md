# 《数学指南——实用数学手册》

## 概述

《数学指南——实用数学手册》是一部综合性数学参考手册，是本 wiki 中「数学指南_实用数学手册」文件夹内所有源文件的母体文献，也是本 wiki 的连续来源载体。

目前唯一已导入的部分是其第 0 章第 1 节（0.1「初等数学中的基本公式」）的内容与目录页，见 [[10-数学指南实用数学手册--13-01-初等数学中的基本公式--b2iuhy]]。其中 0.1.12 节「在行星运动中的应用——数学在太空中的一次胜利」是 0.1 节的组成部分，主题为：初等数学结果在历史上的艰难获得过程，以及数学在天文动力学中的应用。

（0.1.12 节的具体内容见 [[行星运动的数学描述]] 与 [[初等数学公式的历史代价]]。）

- **「第 0 章先行」**：在正式章节内容之前，先以第 0 章集中给出初等数学的基本公式备查。章节编号从 0 开始这一事实直接来自已导入的目录页结构，可信度高。
