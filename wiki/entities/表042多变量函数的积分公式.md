# 表 0.42（多变量函数的积分公式）

《数学指南——实用数学手册》0.9.2.3 节给出的多变量函数积分公式表，共五条。原文指出表 0.41 的一维积分法则与表 0.42 的多维积分法则相对应。表带脚注标号 $^{1)}$，但脚注文字未在源文件中出现。

| 法则名称 | 公式 |
|---|---|
| 代换公式 | $\int_{x(H)} f(x)\,\mathrm{d}x = \int_{H} f(x(t))\lvert \det x'(t) \rvert\,\mathrm{d}t$ |
| 分部积分公式 | $\int_{G} (\partial_{j} u)v\,\mathrm{d}x = \int_{\partial G} uvn_{j}\,\mathrm{d}F - \int_{G} u\partial_{j} v\,\mathrm{d}x$ |
| 高斯定理 | $\int_{G} \partial_{j} u\,\mathrm{d}x = \int_{\partial G} un_{j}\,\mathrm{d}F$ |
| 高斯-斯托克斯定理 | $\boxed{\int_{M} \mathrm{d}w = \int_{\partial M} \mathrm{d}w}$ |
| 富比尼定理（累次积分） | $\int_{\mathbb{R}^{2}} f(x,y)\,\mathrm{d}x\,\mathrm{d}y = \int_{-\infty}^{+\infty}\left(\int_{\infty}^{+\infty} f(x,y)\,\mathrm{d}x\right)\mathrm{d}y$ |

## 转写疑误记录

- 高斯-斯托克斯定理右端原文作 $\int_{\partial M}\mathrm{d}w$，与左端 $\int_M \mathrm{d}w$ 无法构成标准形式，应为 $\int_{\partial M} w$。见 [[queries/表042高斯-斯托克斯定理右端边界的转写疑误]]。
- 富比尼定理内层积分下限原文作 $\infty$，应为 $-\infty$。见 [[queries/表042富比尼定理内层积分下限的转写疑误]]。

## 相关条目

- 三条注解给出层级关系：令 $v=1$ 由分部积分得高斯定理；高斯-斯托克斯定理把积分基本定理推广到流形；分部积分与高斯定理均为高斯-斯托克斯定理的特例。见 [[findings/高斯定理由分部积分令v等于1得到]] 与 [[findings/分部积分与高斯定理都是高斯-斯托克斯定理的特例]]。
