# 表 c（完全椭圆积分 K 和 E）

源文 0.5.4 节 c) 项下的数值表，标题为「完全椭圆积分 K 和 E，$k = \sin\alpha$；当 $\alpha = 90^\circ$ 时，令 $K = \infty$，$E = 1$」。表以 $\alpha = 0^\circ, 1^\circ, \ldots, 89^\circ$（步长 1°）为行，每行给出 $K$ 与 $E$ 两列，整体按三组（三对列）排版。

源文未给出表号；本 wiki 按内容命名。完整数据见 [[10-数学指南实用数学手册--8-054-椭圆积分--3chh90]]。

## 特征

- $K$ 列自 `1.5708`（$\alpha = 0^\circ$）单调递增至 `5.4349`（$\alpha = 89^\circ$）；
- $E$ 列自 `1.5708`（$\alpha = 0^\circ$）单调递减至 `1.0008`（$\alpha = 89^\circ$）；
- 源文明确规定边界约定：$\alpha = 90^\circ$ 时 $K = \infty$，$E = 1$。

## 精度说明

表 c 的数值给到小数点后 4 位，步长 1°，其余两表（表 a、表 b）给到小数点后 4 位但步长 10°。表 c 因此可用于对表 a、表 b 在 $\varphi = 90^\circ$ 行的更精细校核。

## 交叉校核

$K$ 列与 [[表a第一类椭圆积分]] 的 $\varphi = 90^\circ$ 行一致；$E$ 列与 [[表b第二类椭圆积分]] 的 $\varphi = 90^\circ$ 行一致。详见 [[表a与表c在φ等于90度处的交叉一致]] 与 [[表b与表c在φ等于90度处的交叉一致]]。
