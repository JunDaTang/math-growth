# 棣莫弗（Abraham de Moivre, 1667—1754）

> **版本说明**：本页由三个来源合并而成。0.2.8 节版本给出棣莫弗的生卒年（1667—1754）、三角形式的[[棣莫弗公式]] (0.41) 以及一段关于公式发现史的论述；0.2.10 节版本仅记录该节把双曲形式的恒等式命名为「棣莫弗公式」，并明确指出该节源文档未提供生平、年代、其他工作或原始文献；6.1.3 节版本记录以「棣莫弗定理（1730）」为标题的二项分布渐近结果，并明确该节只涉及这一结果。各来源的取材范围不同，以下按来源分别标注，不做跨来源的合并断言。

## 名称与年代

- **0.2.8 节版本**：本页标题记为「棣莫弗（Abraham de Moivre, 1667—1754）」，即给出全名与生卒年 1667—1754。
- **0.2.10 节版本**：标题仅作「棣莫弗（De Moivre）」，并说明**该节源文档未提供其生平、年代、其他工作或原始文献**。此说明针对 0.2.10 节而言，与 0.2.8 节版本给出的年代信息并不冲突，只是来源不同。
- **6.1.3 节版本**：给出与棣莫弗相关的年代标记「1730」，但它标注的是二项分布渐近定理的年份（「棣莫弗定理（1730）」），并非人物生卒年；该节未提供任何生平信息。

## 0.2.8 节：三角形式的棣莫弗公式

《数学指南——实用数学手册》0.2.8 节的脚注中，棣莫弗是[[棣莫弗公式]] (0.41) 的命名者：

$$
\cos n x + \mathrm{i} \sin n x = \sum_{k=0}^{n} \mathrm{i}^{k} \binom{n}{k} \cos^{n-k} x \sin^{k} x, \quad n = 2, 3, \cdots
$$

## 0.2.10 节：双曲形式的命名性出现

在 0.2.10 节中，棣莫弗**仅以命名形式出现**：该节把

$$
(\cosh x \pm \sinh x)^{n} = \cosh n x \pm \sinh n x, \qquad n = 1, 2, \dots
$$

冠以「棣莫弗公式」之名（见 [[双曲棣莫弗公式]]）。

> **两处的公式不同，不应合并为同一断言**：0.2.8 节为三角形式的 $\cos nx + \mathrm{i}\sin nx$ 展开式（$n = 2, 3, \cdots$），0.2.10 节为双曲形式的 $(\cosh x \pm \sinh x)^n$ 恒等式（$n = 1, 2, \dots$）。

## 6.1.3 节：棣莫弗定理（1730）与二项分布的渐近高斯密度

6.1.3 节以「棣莫弗定理（1730）」为标题，给出二项分布在试验次数 $n \to \infty$ 时的渐近高斯密度。设 $H_n$ 为 $n$ 次抛硬币中正面向上的频率，则

```
P(H_n = k/n) ~ (1/(σ√(2π))) e^{−(k−μ)²/(2σ²)},  k = 1,2,…,n     (6.5)
```

其中 $\mu = n/2$，$\sigma = \sqrt{n/4}$。该结果在本书中被命名为 [[棣莫弗极限定理]]，并被描述为「概率论中最重要、最深刻的研究之一」的体现。

**该来源的边界**：6.1.3 节只把 1730 年的这一定理作为二项分布的局部渐近结果引入，未讨论棣莫弗的其他工作（例如棣莫弗公式 $(\cos\theta + \mathrm{i}\sin\theta)^n = \cos n\theta + \mathrm{i}\sin n\theta$）。出处见 [[10-数学指南实用数学手册--9-61-基本的随机性--1r43h9a]]。

## 历史因果的方向（0.2.8 节）

0.2.8 节原文给出一个有意味的历史细节：**是棣莫弗先得到该公式，欧拉受此启发才发现**著名公式

$$
\mathrm{e}^{\mathrm{i} x} = \cos x + \mathrm{i} \sin x .
$$

但手册同时指出，从现代叙述习惯看「反过来说更方便」：借助

$$
\cos n x + \mathrm{i} \sin n x = \mathrm{e}^{\mathrm{i} n x} = (\mathrm{e}^{\mathrm{i} x})^{n} = (\cos x + \mathrm{i} \sin x)^{n}
$$

与二项式公式，棣莫弗公式反倒成了[[欧拉公式]]的推论。这一「证明方向的倒置」是本源中少见的对数学史因果与教学呈现次序之差异的明确说明。

> **注意来源边界**：上述「棣莫弗先得到、欧拉受启发」的因果叙述仅见于 0.2.8 节；6.1.3 节只给出 1730 年的渐近定理，未涉及该发现史，也未给出两者的先后关系。
