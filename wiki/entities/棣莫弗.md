# 棣莫弗（Abraham de Moivre, 1667—1754）

> **版本说明**：本页由两个来源合并而成。0.2.8 节版本给出棣莫弗的生卒年（1667—1754）、三角形式的[[棣莫弗公式]] (0.41) 以及一段关于公式发现史的论述；0.2.10 节版本仅记录该节把双曲形式的恒等式命名为「棣莫弗公式」，并明确指出该节源文档未提供生平、年代、其他工作或原始文献。以下按来源分别标注。

## 名称与年代

- 0.2.8 节版本：本页标题记为「棣莫弗（Abraham de Moivre, 1667—1754）」，即给出全名与生卒年 1667—1754。
- 0.2.10 节版本：标题仅作「棣莫弗（De Moivre）」，并说明**该节源文档未提供其生平、年代、其他工作或原始文献**。此说明针对 0.2.10 节而言，与 0.2.8 节版本给出的年代信息并不冲突，只是来源不同。

## 在本源中的出场

### 0.2.8 节：三角形式的棣莫弗公式

《数学指南——实用数学手册》0.2.8 节的脚注中，棣莫弗是[[棣莫弗公式]] (0.41) 的命名者：

$$
\cos n x + \mathrm{i} \sin n x = \sum_{k=0}^{n} \mathrm{i}^{k} \binom{n}{k} \cos^{n-k} x \sin^{k} x, \quad n = 2, 3, \cdots
$$

### 0.2.10 节：双曲形式的命名性出现

在 0.2.10 节中，棣莫弗**仅以命名形式出现**：该节把

$$
(\cosh x \pm \sinh x)^{n} = \cosh n x \pm \sinh n x, \qquad n = 1, 2, \dots
$$

冠以「棣莫弗公式」之名（见 [[双曲棣莫弗公式]]）。

> 两处的公式不同：0.2.8 节为三角形式的 $\cos nx + \mathrm{i}\sin nx$ 展开式（$n = 2, 3, \cdots$），0.2.10 节为双曲形式的 $(\cosh x \pm \sinh x)^n$ 恒等式（$n = 1, 2, \dots$）。二者不应合并为同一断言。

## 历史因果的方向（0.2.8 节）

0.2.8 节原文给出一个有意味的历史细节：**是棣莫弗先得到该公式，欧拉受此启发才发现**著名公式

$$
\mathrm{e}^{\mathrm{i} x} = \cos x + \mathrm{i} \sin x .
$$

但手册同时指出，从现代叙述习惯看"反过来说更方便"：借助

$$
\cos n x + \mathrm{i} \sin n x = \mathrm{e}^{\mathrm{i} n x} = (\mathrm{e}^{\mathrm{i} x})^{n} = (\cos x + \mathrm{i} \sin x)^{n}
$$

与二项式公式，棣莫弗公式反倒成了[[欧拉公式]]的推论。这一"证明方向的倒置"是本源中少见的对数学史因果与教学呈现次序之差异的明确说明。
