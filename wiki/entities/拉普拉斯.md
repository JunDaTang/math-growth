# 拉普拉斯（Laplace）

在《数学指南——实用数学手册》中，拉普拉斯（Laplace）目前仅以「命名者」的身份出现，且分别来自四份不同的源文档：

- **1.5.4 节**将 $\Delta F := F_{xx} + F_{yy}$ 命名为拉普拉斯算子；
- **1.12.6 节**两次提到同名的拉普拉斯变换；
- **2.1.2 节**将行列式的一般展开法则称为「行列式展开的拉普拉斯法则」；
- **5.2 节**以其名命名「拉普拉斯方程」，用于 5.2.3 节带约束变分问题所导出的方程。

四处记载均未给出其生平、著作、年代或其他贡献。

> 说明：以下四条记载分别来自不同章节，彼此不构成对同一事实的重复陈述；本页按来源分开记录，不合并为一般化结论。

## 来源一：1.5.4 节——拉普拉斯算子的命名

《数学指南——实用数学手册》1.5.4 节中，拉普拉斯仅作为命名者被提及：该节称 $\Delta F := F_{xx} + F_{yy}$ 为「通常的**拉普拉斯（Laplace）算子**」。

该源文档未给出其生平或其他贡献，本页只记录该命名关联。该算子在极坐标下的形式见 [[拉普拉斯算子]]，相关方程见 [[拉普拉斯方程]]。

## 来源二：1.12.6 节——拉普拉斯变换的引用

在《数学指南——实用数学手册》1.12.6 节中，拉普拉斯仅以其同名的积分变换出现两次：

1. 章节开篇：在常系数的情形，拉普拉斯变换（参阅 1.11.1.2）是线性微分方程组的通用解法；
2. 在 (1.303) 例题的显式解之后：借助于拉普拉斯变换也能得到相同的结果。

原文引用的 1.11.1.2 节尚未入库（见 [[queries/1126节引用1124.5与1111.2尚未入库]]）。本页仅记录该引用关系，不展开拉普拉斯变换理论本身。

## 来源三：2.1.2 节——行列式展开的拉普拉斯法则

在《数学指南——实用数学手册》2.1.2 节中，拉普拉斯同样仅以命名形式出现：行列式的一般展开法则被称为**行列式展开的拉普拉斯法则**（公式 (2.6)）。

```latex
D = a_{k1} A_{k1} + a_{k2} A_{k2} + \dots + a_{kn} A_{kn}. \tag{2.6}
```

本节未给出其生平、著作或年代等背景信息，仅在命名层面出现。相关的形式化内容见 [[拉普拉斯展开法则]] 与 [[伴随行列式]]，背景见 [[行列式]]。

## 来源四：5.2 节——拉普拉斯方程本征值问题（带约束变分问题）

在《数学指南——实用数学手册》5.2 节中，拉普拉斯之名以「拉普拉斯方程」的形式出现，用于命名 5.2.3 的带约束变分问题所导出的方程。

5.2.3「带约束的问题和拉格朗日乘子」以**拉普拉斯方程的本征值问题**为例。变分提法为在边界条件 $q=0$ 于 $\partial D$ 上、并附加约束 $\int_{\partial D}q^{2}\,\mathrm{d}s=1$ 之下极小化 $\int_{D}(q_{x}^{2}+q_{y}^{2})\,\mathrm{d}x\,\mathrm{d}y$（(5.60)）。引入拉格朗日乘子 $\lambda$ 后，其欧拉-拉格朗日方程即本征值问题

```latex
q_{xx}+q_{yy}=\lambda q,\ \text{在}\ D\ \text{上},\quad q=0,\ \text{在}\ \partial D\ \text{上}. \tag{5.61}
```

在本例中拉格朗日乘子成为一个本征值——这是 5.1.6 乘子法在多元情形的直接推广。
