# 表 0.39（基本积分）

表 0.39「基本积分」出自《数学指南——实用数学手册》0.9.1 节，是该小节的核心结构化内容。全表以三栏（实为四列）列出函数 $f(x)$ 与其不定积分 $\int f(x)\mathrm{d}x$，并分别给出该原函数在**实数**与**复数**两种取值情形下成立所需的变量范围（即定义域条件）。

## 表结构

| 列 | 内容 |
|---|---|
| 第 1 列 | 函数 $f(x)$ |
| 第 2 列 | 不定积分 $\int f(x)\,\mathrm{d}x$（原文上标注 1)） |
| 第 3 列 | 对实数的取值范围（原文上标注 2)） |
| 第 4 列 | 对复数的取值范围（原文上标注 2)） |

原表在排版上被分成上下两段，两段的表头重复出现。上标 1) 与 2) 在原始文本中没有对应的脚注内容，见 [[queries/表039中复数取值范围空缺的含义]]。

## 内容分组

按被积函数的类型，表 0.39 可分为下列若干组：

- **幂函数与常数**：$C$、$x$、$x^{n}$（$n=1,2,\cdots$）、$\frac{1}{x^{n}}$（$n=2,3,\cdots$）、$\frac{1}{x}$、$x^{\alpha}$（$\alpha$ 实且 $\neq -1$）、$\sqrt{x}$。
- **指数函数**：$e^{x}$、$a^{x}$（$a>0,\ a\neq 1$）。
- **三角函数**：$\sin x$、$\cos x$、$\tan x$、$\cot x$、$\frac{1}{\cos^{2}x}$、$\frac{1}{\sin^{2}x}$。
- **双曲函数**：$\sinh x$、$\cosh x$、$\tanh x$、$\coth(x)$、$\frac{1}{\cosh^{2}x}$、$\frac{1}{\sinh^{2}x}$。
- **含参数 $a>0$ 的有理与无理型**：$\frac{1}{a^{2}+x^{2}}$、$\frac{1}{a^{2}-x^{2}}$（两行）、$\frac{1}{\sqrt{a^{2}+x^{2}}}$、$\frac{1}{\sqrt{x^{2}-a^{2}}$。

## 取值范围的两种情形

原表把定义域条件分成「实数」与「复数」两栏，体现出两种不同的分支处理：

- 对整函数型的被积函数（如 $x^{n}$、$e^{x}$、$a^{x}$、$\sin x$、$\cos x$、$\sinh x$），实数情形为 $x \in \mathbb{R}$，复数情形为 $x \in \mathbb{C}$。
- 对含对数或分数幂的被积函数（如 $\frac{1}{x}$、$x^{\alpha}$、$\sqrt{x}$），复数情形除 $x \neq 0$ 外还附加 $-\pi < \arg x < \pi$ 的辐角限制，即取定对数的主支。相关讨论见 [[不定积分的复数取值范围]]。
- 相当多的行（$\tan x$、$\cot x$、$\cosh x$、$\tanh x$、$\coth(x)$ 及所有含参数 $a>0$ 的行）在「对复数的取值范围」栏留空。

## 值得注意的细节

- 表中 $\coth$ 一行写作 $\coth(x)$，与相邻各行的记号风格不同。
- 表末两行使用反双曲函数记号 $\operatorname{arsinh}$ 与 $\operatorname{arcosh}$，见 [[反双曲函数记号]]。
- 被积函数 $\frac{1}{a^{2}-x^{2}}$ 出现两次，其中与 $\arcsin \frac{x}{a}$ 同行的被积函数与结果不匹配，见 [[findings/表039中arcsin行的被积函数与实数范围疑误]]。
