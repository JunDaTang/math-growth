# 表 0.9.5（不定积分表-3，条目 342–500）

## 是什么

表 0.9.5 是《数学指南——实用数学手册》0.9.5 节「[[不定积分表]]」的数据主体。本页对应其中的第 3 部分，覆盖编号 **342–500** 的 159 个[[原函数]]条目。整表的条目在 0.9.5 各部分之间连续编号，本部分不是独立编号体系。

## 收录范围

| 区间 | 主题 |
|---|---|
| 342–343 | 分母含 β² ± γ²cos²αx |
| 344–398 | 含 sin αx 与 cos αx 的积分（幂乘积、分式、线性分母组合、积化和差） |
| 399–407 | 含 tan αx 的积分 |
| 408–415 | 含 cot αx 的积分 |
| 416–427 | 含 e^{αx} 的积分 |
| 428–433 | e^{αx} 与 sin βx、cos βx 的乘积 |
| 434–456 | 含 ln x 的积分 |
| 457–477 | 含双曲函数的积分 |
| 478–500 | 含反三角函数的积分 |

其中 416 号之前出现小节标题「0.9.5.4 含其他超越函数的积分」，即 416–500 属于 0.9.5.4；342–415 属于 0.9.5.3（源中未给出该标题原文）。

## 记号约定

- 参数：α、β、γ、δ 表示常数，x 为自变量，n、m 为整数参数（多数条目要求 n, m ∈ ℕ，并附加 n > 0、m > 1、n > 1、n ≠ 1、n > 3 等条件）。
- 特殊常数：[[欧拉常数]] C（源中注明「参看 0.1.1」）；[[伯努利数]] B_{2n}（源中注明「参看 0.1.10.4」，但 453 号误写为 1.1.10.4）。
- 特殊函数：[[积分指数函数Ei]]（420 号）、[[对数积分li]]（438 号）。
- 条目右上角的「*」标记：344–348、416–419、428–433、457–460、463–469、473 等条目在源中转写为带星号，但源未给出该标记的定义说明，暂存疑。

## 使用特征

表内条目高度依赖彼此：大量条目以「参看第 N 个积分」的方式把结果落到同表或邻表的基元条目上，形成[[积分递推公式|递推网络]]。实际使用时通常先做[[重要代换]]把被积式化为本表某一行，再沿递推链归约到 0.9.5 前两部分或 0.9.1 [[表039基本积分]]中的基元积分。
