# 里茨（W. Ritz）

W. Ritz（1878—1909）。在《数学指南——实用数学手册》1.12.8.2 节中，里茨给出以他命名的 [[concepts/里茨逼近法]]：在有限维子空间 $y_1, \cdots, y_n \in Y$ 上极小化泛函 $F$（逼近问题 (1.310)），由 $\partial G(\boldsymbol{c}) / \partial c_j = 0$ 导出线性方程组 $A c = b$（式 (1.311)），逼近解为 $y = c_1 y_1 + \dots + c_n y_n$（式 (1.312)）。

同一子节还给出「本征值问题的里茨方法」：由矩阵本征值问题 $A c = \lambda c$ 的解按 (1.312) 得到本征值与本征函数的逼近。参见 [[findings/里茨逼近法方程组1311与1312]]。
