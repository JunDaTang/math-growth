# 洛必达（L'Hôpital）

洛必达的名字在《数学指南——实用数学手册》1.3.1.3 节中以**洛必达法则**（式 (1.28)）的形式出现。该法则把 $\frac{0}{0}$ 与 $\frac{\infty}{\infty}$ 型 [[不定式]] 的极限化为导数之比的极限，前提是四条假设（分子分母极限同为 $b = 0$ 或 $b = \pm\infty$、邻域内导数存在、分母导数非零、右端极限存在）同时成立。

手册同时给出可重复应用的变形

```
lim_{x→a} f(x)/g(x) = lim_{x→a} f'(x)/g'(x) = … = lim_{x→a} f^{(n)}(x)/g^{(n)}(x)
```

以及把 $0\cdot\infty$、$\infty-\infty$、$0^0$、$\infty^0$、$0^\infty$ 型转化为 $\frac{\infty}{\infty}$ 型的手法（后者借助 $a^x = e^{x \ln a}$）。
