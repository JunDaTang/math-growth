# 欧几里得（Euclid）

欧几里得是古希腊数学家，著有教科书《几何原本》（Elements）。在《数学指南——实用数学手册》中，他的名字出现在四个小节：2.1.5「多项式的计算」、2.7.2「欧几里得算法」、3.1「由克莱因的埃尔兰根纲领所概括的几何学的基本思想」和 4.5「公理方法及其与哲学认识论之关系的历史」。各来源中他的角色并不相同：

| 来源 | 欧几里得的角色 |
| --- | --- |
| 4.5 公理方法及其与哲学认识论之关系的历史 | 以《几何原本》作为「公理方法的一个闪光例子」的**著作作者** |
| 2.7.2 欧几里得算法 | 该小节的**中心人物**（算法与定理均以其命名） |
| 2.1.5 多项式的计算 | 仅以「欧几里得算法」这一算法命名的方式出现 |
| 3.1 几何学的基本思想 | **隐含的、边缘的**人物（以「欧几里得几何」作为历史起点） |

由于各来源各自覆盖不同侧面，下文按来源分节记述，不将不同来源的论断合并为单一结论。

## 来源 4.5：公理方法与《几何原本》

在来源 4.5 中，欧几里得所著的教科书《几何原本》被称为「公理方法的一个闪光例子」，并已为其后 2000 年的科学活动树立了榜样。该书大约写于公元前 325 年的亚历山大里亚。

《几何原本》以下列定义作为开始：

1. 点是没有部分的某种东西.
2. 线是广延的长.
3. ….

其中平行公理 (P) 尤其著名（见 [[平行公理]]）。19 世纪由 [[波尔约]]、[[高斯]] 和 [[罗巴切夫斯基]] 证明平行公理独立于其他欧几里得公理。

> **边界说明**：源文档 4.5 对欧几里得的描述限于上述内容；其与 19 世纪非欧几何的关系见 [[非欧几何]]。

## 来源 2.7.2：欧几里得算法与欧几里得定理

在来源 2.7.2 中，欧几里得是该小节的**中心人物**：该小节以其名字命名了两项内容——

- **[[欧几里得算法]]**：求两个非零整数最大公约数的带余除法迭代过程，最大公约数等于算法中最后一个不为零的余数。
- **[[欧几里得定理]]**：有无限多个[[素数]]。

### 与《几何原本》的关联

该来源明确指出，欧几里得定理是在欧几里得的 Elements（《几何原本》）中证明的；[[算术基本定理]]（每个自然数 $n \geqslant 2$ 都是素数之乘积，且按大小排序后分解唯一）也可在《几何原本》中找到，但仅是隐含着。详见 [[几何原本]]。

原文还称欧几里得算法为「求最大公约数的欧几里得算法」，并以 $m = 14$、$n = 24$ 的算例（$\gcd(14,24)=2$）演示。

## 来源 2.1.5：多项式的计算

在来源 2.1.5 中，欧几里得的名字仅以「欧几里得算法」这一算法命名的方式出现。该节使用「欧几里得算法」求两个多项式的最大公因子：对次数至少为 $1$ 的多项式 $N(x)$ 与 $D(x)$ 反复作带余除法，得到链

```
N(x)   = D(x)Q(x)    + R_1(x),
D(x)   = R_1(x)Q_1(x) + R_2(x),
R_1(x) = R_2(x)Q_2(x) + R_3(x),  等等。
```

由 $\deg(R_{j+1}) < \deg(R_j)$ 保证有限步终止，末项非零余项 $R_{m+1}(x)$ 即为 $N(x)$ 与 $D(x)$ 的最大公因子。

> **边界说明**：本来源并未提供欧几里得的生平资料、年代或其他著作信息，仅是把该算法归于其名。因此该来源中所有关于算法的内容均应视为对 [[欧几里得算法-多项式]] 的引用，而非对人物的独立论述。

## 来源 3.1：几何学的基本思想中的欧几里得几何

在来源 3.1 中，欧几里得是一个**隐含的、边缘的**人物：文本并未直接讨论其生平或著作，而是以「欧几里得几何」作为历史起点：

- 「古代所知道的几何学是欧几里得几何，它在 2000 多年来一直处于数学中的支配地位。」
- 19 世纪关于非欧几何存在问题的讨论，打破了这种支配地位，并引出一系列不同几何的描述。

欧几里得几何在本节中被正式表述为[[运动]]的几何，其变换群为 $\operatorname{Aut}(E)$（见[[欧氏几何]]）。
