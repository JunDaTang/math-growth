# 雅各布·伯努利（Jacob Bernoulli）

## 在 6.1 节中的角色

《数学指南——实用数学手册》6.1 节把雅各布·伯努利定位为概率论的两项奠基性贡献的提出者：

1. **古典概率定义**。文中指出，「概率概念的这个定义式是雅各布·伯努利在 17 世纪末引入的」，即 [[concepts/古典概型]] 中

```
P(A) := 有利结果数 / 可能结果数        (6.2)
```

2. **大数定律**。文中明确写道：「大数定律是由雅各布·伯努利最早提出并证明的」，并且「伯努利利用公式 (6.1) 计算了概率 $P(A_n)$，并且证明了」

```
lim_{n→∞} P(A_n) = 1
```

该结果在本书中被称为 [[concepts/伯努利大数定律]]，其陈述对象是以抛硬币为模型的频率 $H_n$ 与概率 1/2 之差。

## 出处与边界

以上两条贡献均出自《数学指南——实用数学手册》6.1.1 与 6.1.2 两节，来源页为 [[sources/10-数学指南实用数学手册--9-61-基本的随机性--1r43h9a]]。本节未涉及伯努利家族其他成员（如约翰·伯努利、丹尼尔·伯努利）的工作，也未讨论伯努利数或伯努利方程，不应据本节内容向这些方向外推。
